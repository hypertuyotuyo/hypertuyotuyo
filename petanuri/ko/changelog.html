v1.2.0 공개 준비 중

2026-10-10

설치 프로그램과 새 펜, 작은 창과 화면 회전, lilToon 설정 추가

이 페이지의 v1.2.0 내용은 공개 전 안내입니다. 현재 배포 버전은 v1.1.2입니다.

  • 설치 프로그램(모든 버전): Windows용 setup을 추가했습니다. 관리자 권한이 필요 없고(사용자별 설치), 시작 메뉴에 등록되며 작업 파일(.petanuri)을 더블클릭으로 열 수 있게 할 수도 있습니다. 새 버전의 setup을 실행하면 덮어써서 업데이트하며 설정·작업 파일·브러시·업그레이드는 그대로 쓸 수 있습니다. ZIP도 당분간 함께 배포합니다.
  • 앱에서 업데이트(Windows): 새 버전 알림에서 BOOTH 라이브러리를 열고, 다운로드한 setup을 앱이 찾으면 “설치하고 다시 시작”으로 교체할 수 있습니다(이 버전 다음 업데이트부터 사용 가능).
  • 필기감(모든 버전): 입·출을 필압만으로 만드는 “필압만으로 입·출”을 기본으로 하여, 시작의 뭉침·끝의 실 같은 꼬리가 잘 생기지 않습니다. 기존 사용자에게는 실행 시 한 번만 안내가 나옵니다. 환경 설정 → 펜·입력 → “필기감”에서 “길이로 입·출”로 되돌릴 수 있습니다.
  • 그리기 도구(모든 버전): 픽셀 유동화 펜(밀어내기·부풀리기·오므리기·소용돌이·복원)과 텍스처 화소에 맞춰 선명하게 칠하는 도트 펜을 추가. 텍스처 세트마다의 “도트 그대로 표시(보간 안 함)”(⋯·오른쪽 클릭. 256px 이하 세트는 처음부터 켜짐)로 작은 텍스처도 가장자리가 흐려지지 않습니다.
  • 칠하기(모든 버전): 올가미로 칠하기, 투명색으로 채우기·폴리곤 칠하기·도형·그라데이션, 3D 뷰에서 칠할 때도 패딩까지 칠하는 설정(패딩 128px까지·매끄럽게 퍼짐), Ctrl＋드래그로 브러시 값, 무늬·종이 질감의 무늬 각도, D 키로 기본 색, Alt/Ctrl＋Backspace로 채우기.
  • 선택 범위·레이어·마스크(모든 버전): 비슷한 색 모두 선택, 선택 범위 이동·변형을 대칭으로도, 레이어 좌우 미러 복사, 마스크 복사·붙여넣기·드래그, 마스크를 흑백으로 그리기·보기, 반복 무늬를 전경색으로 다시 칠하기.
  • 내보내기(모든 버전): 선택한 레이어를 PNG로 내보내기(한 장씩/겹쳐서 한 장으로), UV 맵을 PNG로 내보내기, 내보내기 해상도(512~8192). PSD에서는 테두리가 붙은 레이어와 클리핑 레이어를 한 장으로 합치지 않고 쓰게 했습니다(Standard·Pro).
  • 표시와 화면(모든 버전): 3D·UV 중 하나를 작은 창으로(패널 위에도 두고 잠금 가능), 3D 뷰 화면 회전과 UV 뷰의 자유 각도, 3D 내비와 UV 가이드 버튼 배치, 손바닥 도구, 정해진 배율(Ctrl＋1·2·3), 마지막으로 칠한 곳을 중심으로 회전, 도구 목록 패널, 투명한 곳의 체크무늬와 알파 빼기, 표시 프리셋.
  • 조작(모든 버전): Windows Ink에서도 펜 버튼(가운데 클릭)으로 3D를 돌릴 수 있게 했습니다. 같은 키를 여러 보조 도구에서 사용, 자 막대, 그릴 수 없을 때 이유 표시, 도움말 → “문의 (지원, 기능 요청, 버그 신고)”.
  • 필터·조정 레이어(Standard·Pro): 톤 커브·색상 균형·색온도·활기·특정 색 바꾸기·노출, 동작 흐림·방사형 흐림·하이 패스·노이즈·모자이크·선화 추출·엠보스를 추가하고 메뉴를 하위 메뉴로 정리했습니다. 조정 레이어의 마스크를 선택 범위로 만들 수 있습니다.
  • lilToon과 머티리얼(Pro): 림라이트 방향 영향도, 윤곽선 하이라이트, 광택 설정과 큐브맵, 글리터 모양, 매트캡 커스텀 노멀 맵, 그라데이션 맵, 발광 그라데이션, 이방성 반사, 디더, 디졸브, 시차, AudioLink를 추가하고 .mat 불러오기·내보내기에 대응했습니다. 칠하는 대상도 늘었습니다.
  • 노멀 맵·굽기·포즈(Pro): 노멀 맵 이미지 레이어, 무늬로 질감 넣기, 노멀 맵 색으로 보기, 툰 그림자·천사의 고리·선화 프리셋, UV 가장자리에서 칠하기, 포즈 프리셋, 블렌드 셰이프 값 복사·붙여넣기와 .anim 불러오기.
  • 모델과 가벼움(모든 버전): glTF·glb·VRM의 UV 방향을 고치고, 머티리얼이 없는 FBX를 오브젝트별 세트로 나눠 엽니다. 히트 판정·면을 따르는 브러시·실행 취소를 빠르게 하고, 자동 저장은 빠른 형식이 되었습니다.
  • 수정: ×로 닫히지 않는 경우가 있던 문제(멈췄을 때는 ×를 두 번), 절전 해제 후 자동 저장이 멈추던 문제, UV 뷰에서 확대해 그리면 선이 옅어지던 문제, 3D 변형(Ctrl＋T)에서 틀이 나오지 않거나 튀던 문제, 펜 끝에 커서가 남던 문제 등을 고쳤습니다.

주의: 이전 버전에서 저장한 glTF·glb·VRM 작업 파일을 열면 3D 모습은 그대로이고 UV 뷰의 그림은 위아래가 바뀌어 보입니다(내보내는 PNG는 원래 모델과 같은 방향이 됩니다).

주의: v1.2.0의 자동 저장은 새로운 빠른 형식으로 저장하므로 v1.1.2 이전의 PetaNuri3D에서는 레이어 그림을 읽을 수 없습니다. 직접 저장하는 작업 파일은 지금까지와 같은 형식입니다.

최신

2026-10-07

레이어 정리와 UV 칠하는 범위, 조작 설정 추가

  • 레이어 색 태그(모든 버전): 레이어와 폴더에 8가지 색 표시를 붙여 정리합니다. 여러 개를 선택해도 함께 붙고, 목록 위의 “색으로 표시”로 그 색의 레이어만 표시합니다. 작업 파일에 저장되며 PSD 내보내기·가져오기(Standard·Pro)에서는 Photoshop 레이어 색상과 연동합니다.
  • UV 뷰의 칠하는 범위와 패딩(모든 버전): 왼쪽 아래에서 UV 안/패딩 안/전체를 선택합니다. 펜·붓·지우개뿐 아니라 도형·채우기·그라데이션·스탬프·흐리기·손가락도 따릅니다. 패딩(0~32px·전부)은 내보내기와 같은 값이며 패딩 선을 표시합니다. 패딩을 새 레이어에 만드는 필터도 추가했습니다.
  • 반복 무늬(모든 버전): 레이어 속성에서 이미지 파일·참고 이미지·무늬를 상하좌우로 반복하는 무늬로 레이어에 깔 수 있습니다. UV 이음매에 맞출 수도 있습니다.
  • 카메라와 표시(모든 버전): 환경 설정 → 조작 → 카메라에 Unity 방식을 추가했습니다. 3D 뷰 오른쪽 위의 원근/평행 ▼에서 시야각을 5~120°로 바꿀 수 있고, 텍스처를 숨기고 메시 선만 보는 표시도 추가했습니다.
  • UI 배색(모든 버전): 환경 설정 → 인터페이스에서 화면·패널·버튼·글자·강조색·3D 배경·도구 막대의 색을 바꿉니다. 라이트와 다크를 따로 저장하며 초기 배색으로 되돌릴 수 있습니다.
  • 펜과 조작(모든 버전): 메뉴와 버튼을 펜으로 꾹 눌렀다 떼도 결정할 수 있습니다(버튼 위 길게 누르기 동작은 환경 설정에서 선택). 키를 길게 눌러 일시 전환하기까지의 시간(0.15~2초), 키 할당 내보내기·가져오기, 패널 배치 고정을 추가했습니다.
  • 화면 개선(모든 버전): 메뉴 바로 오른쪽에 새로 만들기·열기·저장과 실행 취소·다시 실행 버튼을 두었습니다. 화면에 다 들어가지 않는 긴 메뉴는 가장자리에서 넘길 수 있습니다. 대칭으로 그리는 동안 대칭선과 반대쪽 커서를 표시하며, 즐겨찾기 도구는 3D·UV에서 따로 표시할 수 있습니다.
  • 레이어와 세트(모든 버전): 썸네일 크기(작게~아주 크게), 버튼 줄을 위에 두는 설정, 여러 레이어를 한꺼번에 드래그, 이름 변경 중 드래그로 글자 선택. 텍스처 세트의 서브를 뺄 수 있고, 모델을 다시 불러올 때 텍스처가 바뀐 세트는 바탕을 바꿀지 묻습니다.
  • 그리기와 언어(모든 버전): 도형 선 굵기가 브러시 크기와 연동되고, 참고 이미지 스포이트 커서를 보기 쉽게 했습니다. 영어·한국어·중국어의 빠진 번역을 채우고 동봉된 사용법 텍스트에 v1.1.2 설명을 추가했습니다.
  • 수정: 폴리곤 칠하기와 3D 면 선택에서 떨어진 삼각형이 칠해지는 경우가 있던 문제, 영어·한국어·중국어에서 내보내기 창 등의 내용이 표시되지 않던 문제, 패딩 내보내기에서 이음매에 선이 생기던 문제, 클리핑 레이어에서 이웃 아일랜드에 색이 들어가던 문제, 불투명도 슬라이더 표시가 멈추던 문제 등을 고쳤습니다.

배포 완료

2026-10-05

그리기와 조작 선택지를 넓히는 업데이트

  • 3D 공간 그라데이션(모든 버전): 일반 그라데이션 도구로 모델 표면이나 빈 공간에 점을 놓고 점과의 거리로 칠합니다. 이동 핸들·XYZ 좌표·반경과 색/불투명도 프리셋을 조정해 선택한 레이어에서 미리 본 뒤 적용합니다. 한 번의 실행 취소로 되돌릴 수 있으며 취소하면 원래 그림으로 돌아갑니다. 일반 공간 그라데이션과 Pro의 점 거리 그라데이션 베이크에 거리의 링·색과 불투명도 띠·값 표시를 추가합니다. 흰색 핸들로 퍼지는 거리, 색 핸들로 각 색의 위치를 움직이면 숫자 설정과 색 편집에도 반영됩니다. 가이드는 숨길 수 있으며 베이크의 경계 위치와 혼합 폭도 반영합니다.
  • 32px부터의 텍스처(모든 버전): 새로 만들기와 해상도 변경에 32/64/128/256px를 추가했습니다. 작업 파일 저장·다시 열기와 PNG 출력도 지원하며 버전별 최대 해상도는 기존과 같습니다.
  • 색상 보조 슬라이더(모든 버전): 위의 색상 필드와 색상 막대를 유지하면서 아래 슬라이더를 RGB/HSV로 전환합니다. 선택은 다시 실행해도 유지됩니다.
  • 카메라 조작(모든 버전): 오른쪽 버튼식·가운데 버튼식·Alt 버튼식을 선택할 수 있습니다. 펜 측면 버튼이 가운데 클릭을 보내는 경우의 시점 조작도 개선했습니다.
  • 숨긴 쪽의 대칭 그리기(모든 버전): 대칭 설정에서 켜면 3D 펜·브러시·지우개·스탬프로 숨긴 대칭 쪽에도 그릴 수 있습니다. 기본값은 꺼짐이며 UV 그리기와 채우기는 제외됩니다.
  • VRM 투명 부분(모든 버전): VRM0/VRM1의 원본 이미지와 투명 설정·컷오프·불투명도를 유지합니다. 같은 이미지라도 투명 설정이 다른 재질은 별도의 텍스처 세트로 처리합니다.
  • 외부 브러시 끝 이미지(모든 버전): ABR·GBR·GIH·이미지·ZIP을 보조 도구로 등록합니다. SUT 안에서 읽을 수 있는 PNG 이미지도 끝 이미지로 가져옵니다. 원래 설정·색·혼색을 완전히 재현하지 않으며 SUT에는 축소 이미지나 끝 이미지 외의 소재가 포함될 수 있습니다.
  • MToon 미리보기(Pro·베타): 재질의 표시와 조명 설정에서 전환하여 VRM0/VRM1 재질을 보며 그릴 수 있습니다. 작업 파일 저장과 실행 취소·다시 실행을 지원합니다. UV 애니메이션은 정지 상태로 표시하며 MToon 재질의 완전한 왕복 출력은 지원하지 않습니다.
  • 혈색의 좌우 대칭(Pro): 간편 베이크의 혈색 위치에 좌우 대칭 옵션을 추가했습니다. 그리기와 같은 X 대칭 중심을 사용하며 점을 움직이면 반대쪽도 따라갑니다.
  • 레이어 목록의 세로 확장(모든 버전): 패널을 아래로 늘려도 목록이 일정 높이에서 멈추던 문제를 수정했습니다. 도킹·탭·독립 창에서도 높이에 맞춰 확장됩니다.
  • 그리기·조작·다국어 수정: 입력 중 브러시 크기의 급변과 기울어진 면에서의 브러시 중심 오차, 베이크 미리보기 중 Alt 카메라 조작, 영어 크기 버튼과 한국어 베이크 버튼의 줄바꿈, 외부 브러시 오류 알림과 대칭 중심 설명을 개선했습니다.
  • 설명 표시 정리(모든 에디션): 베이크, 그라데이션, 브러시, 카메라 조작 등의 긴 설명을 원형 물음표 아이콘에서 볼 수 있습니다. 마우스 올리기, 클릭, 터치, 키보드를 지원하며 현재 점 지정 안내와 경고는 화면에 계속 표시됩니다.

배포 완료

2026년 10월 4일

간편 베이크와 그리기 전 마무리

피부·의상·소품의 마무리를 선택하는 '간편 베이크(Easy Bake)'를 추가했습니다. 빛·광택·원단의 느낌을 조정한 후 바로 그릴 수 있습니다. 면을 따르는 그리기, 그라데이션, v1.0.2의 내보내기 개선도 포함됩니다.

간편 베이크(Easy Bake) Pro

  • 마무리 프리셋 12종: 희고 건강한 피부, 옅은 일러스트풍 피부, 부드러운 천·새틴·데님·가죽풍 의상, 단단한 소재의 소품 등. 원래 레이어를 유지하면서 각 효과를 편집 가능한 레이어로 만듭니다.
  • 혈색을 더할 위치 지정: 3D 뷰에 최대 16점을 놓고 퍼짐과 농도를 조정할 수 있습니다. 마무리 후 투명한 '덧그리기' 레이어가 선택되어 바로 브러시로 그릴 수 있습니다.
  • 새로 만들기에서 시작 가능: 바탕색 선택 화면에서 '생성 후 간편 베이크 열기'를 선택할 수 있습니다. 대상 세트를 선택하고 미리보기 후 확정할 수 있습니다.
  • 베이크 4종 추가: 가장자리 빛, 광택 하이라이트, 직물 결·색 얼룩, 얇은 부분의 투과색. 빛과 광택은 지정한 방향의 색으로 베이크되어 시점을 움직여도 바뀌지 않습니다. 투과색은 닫힌 형태의 얇은 부분에 색을 더하는 기능입니다.
  • 필터 메뉴 정리: 구분선 아래에 '간편 베이크'를 배치하고 개별 기능은 '베이크'에 모았습니다.

그리기·지우기·그라데이션

  • 3D 면을 따르는 채색 방식을 추가하고 기본값으로 설정했습니다. 기울어진 면이나 윤곽 부근에서 붓 자국이 덜 늘어나고 둥근 팁의 흐리기도 접힌 곳에서 덜 끊깁니다. 기존 '화면에 맞추기'도 선택할 수 있습니다.
  • 투명색으로 그리기기능을 추가했습니다. 색 패널의 체크무늬 버튼 또는 C 로 전환합니다. 브러시 팁·경도·필압을 살려 지울 수 있습니다.
  • 색과 투명도의 그라데이션을 추가했습니다. 최대 32점에서 색·위치·불투명도를 편집하고 투명색을 포함하는 프리셋 240종에서 선택할 수 있습니다. 3D·UV·2D 캔버스에서 사용할 수 있습니다.
  • 휘도를 투명도로 변환을 필터 메뉴에 추가했습니다. 흰 부분을 투명하게 하고 어두운 부분을 검은 그림자로 남겨 AO 그림자만 색을 바꾸기 쉬워집니다.
  • 곡선 자의 점을 놓는 동안 Ctrl＋Z 로 마지막 제어점을 취소할 수 있게 했습니다. 점을 취소할 때 그전에 그린 그림까지 지워지는 일을 방지합니다.

형태로 명암 만들기 Pro

  • 부드러운 음영 베이크: 면 방향과 빛 방향으로 넓고 부드러운 그림자를 만들 수 있습니다. 빛의 좌우·위아래, 그림자 범위·부드러움·색·농도를 조정하고 프리셋도 사용할 수 있습니다.
  • 상하·포인트 그라데이션 굽기: 면 방향, 높이, 지정한 점과의 거리로 색과 투명도 그라데이션을 만들 수 있습니다. 중심을 모델 위나 공간에 놓고 3D 손잡이 또는 XYZ 좌표로 이동할 수 있습니다.
  • 오목한 곳과 볼록한 곳 강조: 오목한 곳에 그림자, 볼록한 곳에 밝은 색을 넣을 수 있습니다. '음영 흐림'로 면의 연결을 따라 매끄럽게 하며 UV 이음매에 흰 선이 생기는 문제도 수정했습니다.
  • 부드러운 드리운 그림자: 빛 방향에 따라 드리우는 그림자를 만들 수 있습니다. 그림자를 만드는 세트와 받는 세트를 선택하며 머티리얼 투명도도 지원합니다.

명암은 새 투명 레이어에 베이크됩니다. 베이크 후에도 일반 레이어처럼 색·농도를 바꾸거나 지우고 덧그릴 수 있습니다.

스탬프용 캔버스와 추가 2D 페인트

  • 스탬프의 '2D 캔버스에서 그리기'를 일반 UV 뷰와 레이어에 통합했습니다. 전용 정사각형 캔버스에 그려 합성한 모습 그대로 스탬프에 등록할 수 있습니다.
  • 시작 화면의 '샘플로 해 보기' 아래에서 3D 모델 없이 2D 페인트을 시작할 수 있습니다. 레이어 포함 저장·재개, PNG 내보내기, 스탬프 등록을 지원합니다.
  • 스탬프용 캔버스는 작업 파일에 함께 저장하며 모델용 텍스처 내보내기에서는 제외합니다.

조작과 버그 수정

  • 명암 등의 미리보기를 연 채 종료하면 종료 확인 창을 조작할 수 없는 문제를 수정했습니다. 저장·종료·작업 전환 전에 미리보기를 확정하거나 취소할 수 있습니다.
  • 앞쪽 확인 창에서 Enter・Esc 를 눌렀을 때 뒤쪽 미리보기까지 확정·취소되는 문제를 수정했습니다.
  • 미리보기 중 표시·전경색·저장 등의 조작을 정리하여 충돌하는 조작은 비활성 표시했습니다. 다른 필터로 전환하거나 처리 실패 후 임시 레이어나 조작 제한이 남는 문제도 수정했습니다.
  • 명암 프리셋 선택 후 선택한 이름이 표시에 남도록 수정했습니다. 그라데이션 프리셋의 중복을 제거하고 약 3줄의 스크롤 목록으로 정리했습니다.
  • 2D 페인트 전용 버튼과 파일 메뉴가 같은 PNG 내보내기 처리를 사용하도록 수정했습니다.
  • 이용약관 (일본어)을 공개하고 모든 배포 ZIP에 포함했습니다. 만든 텍스처·일러스트의 이용과 앱 재배포에 관한 내용을 확인할 수 있습니다.
