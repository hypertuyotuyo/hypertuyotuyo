그리기와 조작 선택지를 넓히는 업데이트

  • 3D 공간 그라데이션(모든 버전): 일반 그라데이션 도구로 모델 표면이나 빈 공간에 점을 놓고 점과의 거리로 칠합니다. 이동 핸들·XYZ 좌표·반경과 색/불투명도 프리셋을 조정해 선택한 레이어에서 미리 본 뒤 적용합니다. 한 번의 실행 취소로 되돌릴 수 있으며 취소하면 원래 그림으로 돌아갑니다. 일반 공간 그라데이션과 Pro의 점 거리 그라데이션 베이크에 거리의 링·색과 불투명도 띠·값 표시를 추가합니다. 흰색 핸들로 퍼지는 거리, 색 핸들로 각 색의 위치를 움직이면 숫자 설정과 색 편집에도 반영됩니다. 가이드는 숨길 수 있으며 베이크의 경계 위치와 혼합 폭도 반영합니다.
  • 32px부터의 텍스처(모든 버전): 새로 만들기와 해상도 변경에 32/64/128/256px를 추가했습니다. 작업 파일 저장·다시 열기와 PNG 출력도 지원하며 버전별 최대 해상도는 기존과 같습니다.
  • 색상 보조 슬라이더(모든 버전): 위의 색상 필드와 색상 막대를 유지하면서 아래 슬라이더를 RGB/HSV로 전환합니다. 선택은 다시 실행해도 유지됩니다.
  • 카메라 조작(모든 버전): 오른쪽 버튼식·가운데 버튼식·Alt 버튼식을 선택할 수 있습니다. 펜 측면 버튼이 가운데 클릭을 보내는 경우의 시점 조작도 개선했습니다.
  • 숨긴 쪽의 대칭 그리기(모든 버전): 대칭 설정에서 켜면 3D 펜·브러시·지우개·스탬프로 숨긴 대칭 쪽에도 그릴 수 있습니다. 기본값은 꺼짐이며 UV 그리기와 채우기는 제외됩니다.
  • VRM 투명 부분(모든 버전): VRM0/VRM1의 원본 이미지와 투명 설정·컷오프·불투명도를 유지합니다. 같은 이미지라도 투명 설정이 다른 재질은 별도의 텍스처 세트로 처리합니다.
  • 외부 브러시 끝 이미지(모든 버전): ABR·GBR·GIH·이미지·ZIP을 보조 도구로 등록합니다. SUT 안에서 읽을 수 있는 PNG 이미지도 끝 이미지로 가져옵니다. 원래 설정·색·혼색을 완전히 재현하지 않으며 SUT에는 축소 이미지나 끝 이미지 외의 소재가 포함될 수 있습니다.
  • MToon 미리보기(Pro·베타): 재질의 표시와 조명 설정에서 전환하여 VRM0/VRM1 재질을 보며 그릴 수 있습니다. 작업 파일 저장과 실행 취소·다시 실행을 지원합니다. UV 애니메이션은 정지 상태로 표시하며 MToon 재질의 완전한 왕복 출력은 지원하지 않습니다.
  • 혈색의 좌우 대칭(Pro): 간편 베이크의 혈색 위치에 좌우 대칭 옵션을 추가했습니다. 그리기와 같은 X 대칭 중심을 사용하며 점을 움직이면 반대쪽도 따라갑니다.
  • 레이어 목록의 세로 확장(모든 버전): 패널을 아래로 늘려도 목록이 일정 높이에서 멈추던 문제를 수정했습니다. 도킹·탭·독립 창에서도 높이에 맞춰 확장됩니다.
  • 그리기·조작·다국어 수정: 입력 중 브러시 크기의 급변과 기울어진 면에서의 브러시 중심 오차, 베이크 미리보기 중 Alt 카메라 조작, 영어 크기 버튼과 한국어 베이크 버튼의 줄바꿈, 외부 브러시 오류 알림과 대칭 중심 설명을 개선했습니다.
  • 설명 표시 정리(모든 에디션): 베이크, 그라데이션, 브러시, 카메라 조작 등의 긴 설명을 원형 물음표 아이콘에서 볼 수 있습니다. 마우스 올리기, 클릭, 터치, 키보드를 지원하며 현재 점 지정 안내와 경고는 화면에 계속 표시됩니다.

펜의 가운데 버튼 조작은 합성 입력과 Huion 기기에서 확인했습니다. Wacom 실기기 검증은 아직 진행하지 못했습니다.

v1.1.0

배포 완료

2026년 10월 4일

간편 베이크와 그리기 전 마무리

피부·의상·소품의 마무리를 선택하는 '간편 베이크(Easy Bake)'를 추가했습니다. 빛·광택·원단의 느낌을 조정한 후 바로 그릴 수 있습니다. 면을 따르는 그리기, 그라데이션, v1.0.2의 내보내기 개선도 포함됩니다.

간편 베이크(Easy Bake) Pro

  • 마무리 프리셋 12종: 희고 건강한 피부, 옅은 일러스트풍 피부, 부드러운 천·새틴·데님·가죽풍 의상, 단단한 소재의 소품 등. 원래 레이어를 유지하면서 각 효과를 편집 가능한 레이어로 만듭니다.
  • 혈색을 더할 위치 지정: 3D 뷰에 최대 16점을 놓고 퍼짐과 농도를 조정할 수 있습니다. 마무리 후 투명한 '덧그리기' 레이어가 선택되어 바로 브러시로 그릴 수 있습니다.
  • 새로 만들기에서 시작 가능: 바탕색 선택 화면에서 '생성 후 간편 베이크 열기'를 선택할 수 있습니다. 대상 세트를 선택하고 미리보기 후 확정할 수 있습니다.
  • 베이크 4종 추가: 가장자리 빛, 광택 하이라이트, 직물 결·색 얼룩, 얇은 부분의 투과색. 빛과 광택은 지정한 방향의 색으로 베이크되어 시점을 움직여도 바뀌지 않습니다. 투과색은 닫힌 형태의 얇은 부분에 색을 더하는 기능입니다.
  • 필터 메뉴 정리: 구분선 아래에 '간편 베이크'를 배치하고 개별 기능은 '베이크'에 모았습니다.

그리기·지우기·그라데이션

  • 3D 면을 따르는 채색 방식을 추가하고 기본값으로 설정했습니다. 기울어진 면이나 윤곽 부근에서 붓 자국이 덜 늘어나고 둥근 팁의 흐리기도 접힌 곳에서 덜 끊깁니다. 기존 '화면에 맞추기'도 선택할 수 있습니다.
  • 투명색으로 그리기기능을 추가했습니다. 색 패널의 체크무늬 버튼 또는 C 로 전환합니다. 브러시 팁·경도·필압을 살려 지울 수 있습니다.
  • 색과 투명도의 그라데이션을 추가했습니다. 최대 32점에서 색·위치·불투명도를 편집하고 투명색을 포함하는 프리셋 240종에서 선택할 수 있습니다. 3D·UV·2D 캔버스에서 사용할 수 있습니다.
  • 휘도를 투명도로 변환을 필터 메뉴에 추가했습니다. 흰 부분을 투명하게 하고 어두운 부분을 검은 그림자로 남겨 AO 그림자만 색을 바꾸기 쉬워집니다.
  • 곡선 자의 점을 놓는 동안 Ctrl＋Z 로 마지막 제어점을 취소할 수 있게 했습니다. 점을 취소할 때 그전에 그린 그림까지 지워지는 일을 방지합니다.

형태로 명암 만들기 Pro

  • 부드러운 음영 베이크: 면 방향과 빛 방향으로 넓고 부드러운 그림자를 만들 수 있습니다. 빛의 좌우·위아래, 그림자 범위·부드러움·색·농도를 조정하고 프리셋도 사용할 수 있습니다.
  • 상하·포인트 그라데이션 굽기: 면 방향, 높이, 지정한 점과의 거리로 색과 투명도 그라데이션을 만들 수 있습니다. 중심을 모델 위나 공간에 놓고 3D 손잡이 또는 XYZ 좌표로 이동할 수 있습니다.
  • 오목한 곳과 볼록한 곳 강조: 오목한 곳에 그림자, 볼록한 곳에 밝은 색을 넣을 수 있습니다. '음영 흐림'로 면의 연결을 따라 매끄럽게 하며 UV 이음매에 흰 선이 생기는 문제도 수정했습니다.
  • 부드러운 드리운 그림자: 빛 방향에 따라 드리우는 그림자를 만들 수 있습니다. 그림자를 만드는 세트와 받는 세트를 선택하며 머티리얼 투명도도 지원합니다.

명암은 새 투명 레이어에 베이크됩니다. 베이크 후에도 일반 레이어처럼 색·농도를 바꾸거나 지우고 덧그릴 수 있습니다.

스탬프용 캔버스와 추가 2D 페인트

  • 스탬프의 '2D 캔버스에서 그리기'를 일반 UV 뷰와 레이어에 통합했습니다. 전용 정사각형 캔버스에 그려 합성한 모습 그대로 스탬프에 등록할 수 있습니다.
  • 시작 화면의 '샘플로 해 보기' 아래에서 3D 모델 없이 2D 페인트을 시작할 수 있습니다. 레이어 포함 저장·재개, PNG 내보내기, 스탬프 등록을 지원합니다.
  • 스탬프용 캔버스는 작업 파일에 함께 저장하며 모델용 텍스처 내보내기에서는 제외합니다.

조작과 버그 수정

  • 명암 등의 미리보기를 연 채 종료하면 종료 확인 창을 조작할 수 없는 문제를 수정했습니다. 저장·종료·작업 전환 전에 미리보기를 확정하거나 취소할 수 있습니다.
  • 앞쪽 확인 창에서 Enter・Esc 를 눌렀을 때 뒤쪽 미리보기까지 확정·취소되는 문제를 수정했습니다.
  • 미리보기 중 표시·전경색·저장 등의 조작을 정리하여 충돌하는 조작은 비활성 표시했습니다. 다른 필터로 전환하거나 처리 실패 후 임시 레이어나 조작 제한이 남는 문제도 수정했습니다.
  • 명암 프리셋 선택 후 선택한 이름이 표시에 남도록 수정했습니다. 그라데이션 프리셋의 중복을 제거하고 약 3줄의 스크롤 목록으로 정리했습니다.
  • 2D 페인트 전용 버튼과 파일 메뉴가 같은 PNG 내보내기 처리를 사용하도록 수정했습니다.
  • 이용약관 (일본어)을 공개하고 모든 배포 ZIP에 포함했습니다. 만든 텍스처·일러스트의 이용과 앱 재배포에 관한 내용을 확인할 수 있습니다.

v1.1.0에 통합

제작:2026년 10월 4일

내보내기 진행 상황과 아일랜드 밖 번짐

이 버전은 별도로 배포하지 않으며 개선 내용을 v1.1.0에 포함합니다.

  • PNG·PSD·AO·Unity용 파일 등을 내보내는 동안 파일 이름과 진행 상황을 표시하도록 했습니다.
  • 내보내기 후 저장한 파일이 선택된 상태로 폴더를 열도록 했습니다. 내보내기 창에서 끌 수 있습니다.
  • 번짐을 '아일랜드 바깥을 모두 채우기'로 설정할 때 4096px 텍스처에서 오류로 내보내지 못하는 문제와 아일랜드에서 먼 부분이 투명하게 남는 문제를 수정했습니다.

v1.0.1

배포 완료

2026년 10월 3일

텍스처 세트 묶기·Unity 연동 개선

  • 새로 만들 때 같은 이미지를 쓰는 머티리얼을 텍스처 세트 하나로 묶을 수 있게 했습니다. 그린 내용은 모든 대상에 반영되며 텍스처를 한 장으로 내보낼 수 있습니다.
  • 새로 만들기의 '묶기'에 텍스처 세트를 수동으로 묶고 다시 나누는 조작을 추가했습니다.
  • Unity 연동 창에 앱 위치, 칠할 메시와 텍스처, 실행·연결·저장 상태를 표시하도록 했습니다. 필요한 파일이 없는 exe를 선택할 수 있는 문제도 수정했습니다.
  • Lite에서 영어 전환이 반영되지 않는 문제를 수정했습니다.
  • 앱 업데이트 안내에서 BOOTH 상품 페이지를 열도록 했습니다.

v1.0.0

배포 완료

2026년 10월 3일

PetaNuri3D 출시

  • Lite·Standard·Pro와 Standard에서 Pro로 업그레이드를 BOOTH에 공개했습니다.
  • UV 뷰에 격자선과 이동·변형 시 격자 스냅을 추가했습니다.
  • Lite 레이어 상한을 바탕 포함 4장으로 설정했습니다.
  • 기울어진 면에서 선이 가늘어지고 농도가 고르지 않은 문제, 선택 범위 표시 위치, 레이어와 텍스처 세트 표시, 실행 취소 등의 버그를 수정했습니다.

업데이트 파일은 BOOTH에서

구매한 버전은 BOOTH 구매 내역에서, Lite는 상품 페이지에서 다운로드할 수 있습니다. 작업 파일을 저장하고 앱을 종료한 후 새 버전을 사용하세요.
