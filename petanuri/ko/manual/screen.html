화면·패널·환경 설정

패널과 도구 모음을 원하는 위치로 이동할 수 있습니다. 배치는 다음 실행에도 복원됩니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

Lite·Standard·Pro와 Pro 업그레이드를 BOOTH에서 배포하고 있습니다.

기본 배치

  • 왼쪽에 보조 도구·도구 속성·브러시 크기·참고 이미지.
  • 오른쪽은 3열: 3D 뷰 바로 오른쪽에 텍스처 세트·레이어 속성·레이어, 그 오른쪽에 색·색 값·컬러 세트 | 최근 사용한 색·작업 내역, 맨 오른쪽에 오브젝트와 Pro 패널(정점 그룹·머티리얼·블렌드 셰이프·포즈)을 아이콘 바로 접은 열.
  • 창 크기에 맞춰 열 너비를 정합니다. 너비 1400 미만(1280×720·1366×768 등)은 색 열도 맨 오른쪽 바로 묶어 3D 뷰를 넓게 유지합니다.
  • 기본 배치이면 창 크기가 바뀔 때 재구성합니다. 배치를 변경한 후에는 유지됩니다. 보기 → 창 → '창 배치 초기화'로 기본 배치로 돌아갑니다.

패널 이동

  • 패널 제목을 드래그하여 놓은 곳에 배치합니다.
  • 열·행 가운데: 해당 열·행에 삽입. 열·행 가장자리: 옆에 새 열·행 생성. 3D 뷰 가장자리('왼쪽에 열 추가' 등의 틀): 해당 쪽에 새 열·행 생성. 그 외: 플로팅 창.
  • 경계를 드래그하여 너비·높이를 바꿉니다(더블클릭으로 복원). 좌우 열 패널은 아래 끝 손잡이로도 높이를 바꿀 수 있습니다.
  • 플로팅 창은 제목으로 이동·오른쪽 아래 손잡이로 크기를 변경합니다. 표시·숨기기는 '보기' 메뉴에서 합니다(제목 우클릭의 '이 패널 숨기기'도 가능). 패널은 앱 창 안에 배치합니다.

탭·접기·아이콘 바

  • 접기: 제목을 클릭하면 제목만 남습니다. 사용하지 않는 패널을 접으면 다른 패널을 넓게 쓸 수 있습니다.
  • 탭으로 묶기: 제목을 다른 패널 제목 위로 드래그합니다('여기에 겹치면 탭으로 만듭니다' 표시 시 놓기). 탭을 밖으로 드래그하면 분리됩니다.
  • 아이콘 바: 열 위의 '<”“>'로 열을 아이콘만 있는 좁은 바로 만듭니다. 아이콘을 누르면 해당 패널만 옆에 표시됩니다(밖 누르기·Esc 로 접기).

도구 모음·자주 쓰는 도구

  • 위치: 도구 모음 손잡이를 드래그하면 작업 영역 네 변(왼쪽·오른쪽·위·아래)에 배치 위치가 표시되며 놓은 변에 붙습니다(위·아래는 가로 배열). 다른 곳에 놓으면 플로팅됩니다. 버튼 우클릭 → '도구 모음 위치'로도 선택합니다.
  • 아이콘 크기: 버튼 우클릭 → '도구 모음 아이콘 크기'에서 대·소.
  • 화면 색: 도구 모음 맨 끝 해·달 스위치로 라이트 ⇔ 다크.
  • 도구 재정렬: 버튼을 드래그하여(펜도 가능) 원하는 순서로 정합니다. 조금 움직인 후 놓으면 재정렬, 움직이지 않고 놓으면 도구 선택. 우클릭 '순서 초기화'로 원래 순서로 돌아갑니다.
  • 자주 쓰는 도구: 도구 모음 버튼 또는 보조 도구 우클릭 → '즐겨찾기에 등록'. 3D와 UV 영역 위의 작은 바에 표시되며 누르면 해당 도구·보조 도구로 전환합니다. 바의 '+'로 현재 보조 도구를 등록합니다(펜만으로도 가능).
메뉴 막대의 “파일”이 맨 왼쪽이 되고, 바로 오른쪽에 새로 만들기·열기·저장과 실행 취소·다시 실행 버튼이 있습니다(되돌릴 수 없을 때는 흐려집니다). 버전은 창 제목에서 알 수 있습니다.
즐겨찾기 도구 띠는 3D 뷰용과 UV 뷰용을 따로 표시하거나 숨길 수 있습니다(보기 → 창). 보기 → 창의 “패널 배치 고정”을 켜 둔 동안에는 패널을 옮기거나 크기를 바꾸지 않습니다.
화면에 다 들어가지 않는 긴 메뉴나 오른쪽 클릭 메뉴는 위아래 가장자리에 마우스나 펜을 두면 그쪽으로 넘어갑니다(항목이 더 있으면 가장자리에 ▲·▼ 표시가 나옵니다). 휠이나 위아래 키로도 넘길 수 있습니다.

3D 뷰 네 모서리

  • 왼쪽 위: 메시 선·표시 방식·단면/양면·대칭 그리기 X Y Z·표시 범위(▼가 있는 아이콘은 아래 ▼로 설정 열기).
  • 위 중앙: 페인트/포즈 전환(포즈 중 본 조작, 칠할 대상을 칠하는 동안 해당 대상 조작). 왼쪽 손잡이(⋮)로 원하는 위치로 이동할 수 있습니다.
  • 오른쪽 위: 정면·뒷면·오른쪽·왼쪽·위·아래·원근/평행·전체 보기(숫자 키패드도 사용 가능).
  • 오른쪽 아래: 3D 내비·다른 각도 작은 창(다른 카메라로 보는 작은 3D. 보기 전용).
  • 왼쪽 아래: 누른 곳으로 전환·메인과 서브 텍스처 세트·걸쳐 그리기(텍스처 세트).
  • 아래 중앙: 선택 범위 바·숨김 중 바.
  • 3D 뷰가 좁으면 오른쪽 위부터 아이콘을 '⋯' 패널에 넣습니다.
오른쪽 위 원근/평행 아이콘의 ▼에서 원근 투영의 시야각을 5~120°로 바꿀 수 있습니다. 작을수록 망원, 클수록 광각입니다(초기값 30°). 값은 다음 실행에도 유지됩니다.

표시 방식과 빛 방향

  • 표시 방식(3D 왼쪽 위): 칠한 색 그대로·2단계 툰·명암(요철이 보이도록 조명)·마무리 모습(lilToon 모습.Pro). 다음 실행도 같은 표시로 열립니다.
  • 표시 방식 아이콘 아래 ▼에서빛의 방향: 구를 드래그하여 빛이 오는 방향·좌우/높이 슬라이더·'카메라 따라가기'(시점을 돌려도 빛이 같게 비춤). 2단계 툰·명암·마무리 모습은 같은 빛을 사용합니다.
표시 형식 오른쪽 끝의 “선만 표시(와이어프레임)”로 텍스처를 숨기고 메시 선만 표시할 수 있습니다(보기 → 표시 형식에도 있습니다). 포즈·블렌드 셰이프·이동으로 모양이 바뀌어도 선이 따라갑니다.

우클릭 메뉴

누른 위치에 맞는 메뉴가 표시됩니다(3D 뷰·UV 영역·레이어·텍스처 세트·보조 도구·컬러 세트·작업 내역·패널 제목 등). 3D 뷰에서는 여기 색 가져오기·이 세트 선택·여기에 그린 레이어 선택·이 아일랜드만 표시·이 오브젝트 숨기기·시점·대칭 그리기 등을 바로 선택할 수 있습니다.

메뉴 항목 왼쪽에 아이콘, 오른쪽에 현재 키가 표시됩니다. 하위 메뉴는 ▶로 열고↑↓←→・Enter・Esc 로도 조작할 수 있습니다.

환경 설정

파일 → 환경 설정(Ctrl＋Alt＋Shift＋K). 왼쪽에 분류, 오른쪽에 접을 수 있는 항목이 표시됩니다. 항목 설명은 이름 위에 커서를 대면 표시됩니다.

카메라 조작: 파일 → 환경 설정 → 조작 → 카메라의 「카메라 조작」에서 오른쪽 버튼식·가운데 버튼식·Alt 버튼식·Unity 방식을 선택합니다. 선택한 방식은 다음 실행에도 유지됩니다. Space 조작과 휠도 계속 사용할 수 있습니다.
가운데 버튼식: 가운데 드래그로 회전, Shift+가운데 드래그로 이동, Ctrl+가운데 드래그로 확대·축소합니다. Alt 버튼식: 3D의 Alt+왼쪽은 회전, Alt+가운데는 이동, Alt+오른쪽은 확대·축소입니다.
긴 설명은 둥근 「?」에서 확인할 수 있습니다. 커서를 올리면 표시되고, 클릭하거나 탭하면 열린 상태로 유지됩니다. 다시 누르거나 바깥을 누르거나 Esc로 닫습니다. 키보드에서는 Tab으로 「?」에 이동하고 Enter 또는 Space로 열고 닫습니다. 점 지정 절차·현재 상태·경고는 화면에 남습니다.
Unity 방식: 오른쪽 드래그로 회전, 가운데 드래그로 이동. Alt+왼쪽은 회전·Alt+가운데는 이동·Alt+오른쪽은 확대·축소(3D 뷰). 3D 스포이트는 I 키로 사용합니다.
배색: 환경 설정 → 인터페이스에서 화면 바탕·패널·버튼·글자·주요 색·보조 색·3D 배경·도구 막대의 색을 바꿀 수 있습니다. 라이트와 다크를 따로 저장하며 초기 배색으로 되돌릴 수 있습니다.
펜 꾹 누르기: 메뉴 항목이나 버튼을 펜으로 꾹 눌렀다 떼도 결정할 수 있습니다(처음에는 켜짐). 버튼 위에서 길게 누르기는 “눌렀다 떼면 결정”(처음)과 “길게 누르면 오른쪽 클릭 메뉴” 중에서 고릅니다. 레이어 행 등 버튼이 아닌 곳은 어느 쪽이든 길게 누르면 오른쪽 클릭 메뉴가 나옵니다.
