화면·패널·환경 설정

화면의 어디에 무엇이 있는지, 패널과 도구 모음을 옮기는 방법, 3D 뷰의 보이는 방식 전환, 환경 설정의 모든 항목을 설명합니다. 패널 배치는 다음에 실행해도 그대로 복원됩니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

먼저 이것만
  1. 표시되지 않은 패널은 표시 → 창에서 표시합니다(자세히).
  2. 패널은 제목을 드래그하여 원하는 곳으로 옮길 수 있습니다(자세히).
  3. 3D가 보이는 방식은 3D 뷰 왼쪽 위의 표시 형식 아이콘으로 전환합니다(자세히).
  4. 배치를 알 수 없게 되면 표시 → 창 → "창 배치 초기화"를 선택합니다(자세히).
  5. 설정은 파일 → 환경 설정(Ctrl+Alt+Shift+K)입니다(자세히).

화면의 어디에 무엇이 있는지(처음 배치)

처음 실행했을 때의 배치입니다. 가운데가 그리는 곳(3D 뷰)이고, 좌우에 패널이 늘어서 있습니다.

  • 위: 메뉴 막대. "파일" 오른쪽에 새로 만들기·열기·저장과 실행 취소·다시 실행 버튼이 있습니다(되돌릴 수 없을 때는 흐리게 표시됩니다).
  • 왼쪽: 도구 모음과 보조 도구·도구 속성·브러시 크기·참고 이미지.
  • 오른쪽: 3열입니다. 3D 뷰 바로 오른쪽에 텍스처 세트·레이어 속성·레이어. 그 오른쪽에 색·색 값·컬러 세트|최근 사용한 색(탭)·작업 내역.
  • 맨 오른쪽: 오브젝트와 Pro 패널(정점 그룹·머티리얼·블렌드 셰이프·포즈)을 아이콘 띠로 접어 둔 열. 아이콘을 누르면 그 패널이 옆으로 나타납니다.

창 크기에 맞춘 배치

  • 창의 높이가 낮을 때(높이 860 미만)는 텍스처 세트 패널을 접습니다. 세트는 레이어 패널의 제목에서 전환합니다.
  • 너비가 1400 미만(1280×720·1366×768 등)이면 색 열도 맨 오른쪽 띠에 모아 3D 뷰를 넓게 남깁니다. 너비가 1100 미만이면 열을 더 좁히고 레이어 속성도 띠에 넣습니다.
  • 처음 배치 그대로라면 창 크기를 바꿀 때 배치를 다시 구성합니다. 패널을 옮기거나 접는 등 배치를 바꾼 뒤에는 다시 구성하지 않습니다.
  • 배치는 다음에 실행해도 그대로 복원됩니다.

처음 배치로 되돌리기

  1. 표시 → 창 → "창 배치 초기화"를 선택합니다.
  2. 패널이 현재 창 크기에 맞는 처음 배치로 돌아갑니다. 도구 모음도 왼쪽으로 돌아가고 도구의 순서도 원래대로 됩니다.

잘 안 될 때

  • 패널도 도구 모음도 전부 사라졌습니다: Tab으로 숨겨져 있습니다. Tab을 다시 누르거나 표시 → "팔레트 표시/숨기기"를 선택합니다.
  • 사용하려는 패널이 보이지 않습니다: 표시 → 창에서 그 패널에 ✓를 넣습니다(패널 목록). 맨 오른쪽 아이콘 띠에 접혀 있을 수도 있습니다.
  • 창을 넓혀도 배치가 바뀌지 않습니다: 배치를 바꾼 뒤에는 다시 구성하지 않습니다. "창 배치 초기화"로 현재 크기에 맞게 다시 맞춥니다.

패널 표시·숨기기(패널 목록)

패널은 메뉴의 표시 → 창에서 표시하거나 숨깁니다. ✓가 붙어 있는 것이 표시된 패널입니다.

  1. 표시 → 창을 엽니다.
  2. 표시할 패널의 이름을 선택합니다. ✓가 붙으면서 패널이 나타납니다.
  3. 숨길 때는 다시 선택합니다. 패널 제목을 우클릭 → "이 패널 숨기기"로도 숨길 수 있습니다.

  • Pro 패널은 Lite에서는 자물쇠 표시가 붙고 내용 대신 설명이 표시됩니다. Standard에서는 목록에 나오지 않습니다.

패널 이동하기

패널은 3D 뷰의 좌우(세로 열)와 상하(가로로 긴 단)에 몇 열·몇 단이든 배치할 수 있습니다. 어디에도 넣지 않고 띄워 둘 수도 있습니다.

  1. 패널 제목을 드래그합니다. 들어갈 곳에 선이나 틀이 나타납니다.
  2. 놓을 곳에서 손을 뗍니다. 뗀 곳에서 위치가 정해집니다.
놓는 곳결과
열·단의 가운데 부근그 열·단에 끼워 넣습니다(들어갈 곳에 선이 나타납니다. 단 안에서는 패널이 가로로 늘어섭니다)
열·단의 가장자리그 옆에 새 열·단을 만듭니다(가장자리에 굵은 선이 나타납니다)
3D 뷰 가장자리의 틀("왼쪽에 열 추가", "오른쪽에 열 추가", "위에 배치", "아래에 배치")그쪽에 새 열·단을 만듭니다
그 외(3D 뷰의 한가운데 등)떠 있는 창이 됩니다

너비·높이 바꾸기

  • 열과 열, 단과 단의 경계를 드래그하면 너비·높이가 바뀝니다. 경계를 더블클릭하면 원래대로 돌아갑니다.
  • 좌우 열의 패널은 아래쪽 가장자리의 손잡이를 드래그하여 높이를 바꿀 수 있습니다(더블클릭하면 자동으로 되돌립니다). 내용이 길면 패널 안에서 스크롤됩니다.
  • 비게 된 열·단은 사라지고 3D 뷰가 넓어집니다.
  • 보조 도구의 타일이나 브러시 크기는 패널의 너비와 높이에 맞춰 배열이 바뀝니다. 브러시 크기만 있는 열이나 떠 있는 창은 타일 1열 너비(약 64px)까지 좁힐 수 있습니다.

떠 있는 창

  • 제목을 드래그하여 옮기고 오른쪽 아래 손잡이로 크기를 바꿉니다. 제목을 클릭하면 접힙니다.
  • ×는 없습니다. 숨길 때는 표시 → 창에서 하거나 제목을 우클릭 → "이 패널 숨기기"로 합니다.
  • 패널은 앱 창 안에 둡니다. 앱 밖의 다른 창에는 표시할 수 없습니다.

배치 고정하기

  • 표시 → 창 → "패널 배치 고정"에 ✓를 넣으면 패널을 옮기거나 크기를 바꿀 수 없게 됩니다. 실수로 옮기는 것을 막을 수 있습니다.
  • 고정 중에도 떠 있는 창은 제목 드래그로 옮길 수 있고 크기도 바꿀 수 있습니다.
  • 떠 있는 창은 오른쪽 위의 자물쇠로 그 창만 고정·해제할 수 있습니다. 고정하면 움직이지 않고 크기도 바뀌지 않습니다(다음에 열 때도 기억합니다).

패널 접기·탭으로 묶기

쓰지 않는 패널을 작게 하면 다른 패널이나 3D 뷰를 넓게 쓸 수 있습니다.

하고 싶은 일조작
제목만 남기기(접기)패널 제목을 클릭합니다. 다시 클릭하면 돌아옵니다. 단 안에서 접은 패널은 제목만 있는 가늘고 긴 세로 모양이 됩니다
탭으로 묶기제목을 다른 패널의 제목 위로 드래그합니다. "여기에 겹치면 탭으로 만듭니다"가 표시되면 손을 뗍니다. 위쪽 탭으로 전환합니다
탭 접기선택 중인 탭을 한 번 더 누릅니다
탭 분리하기탭을 바깥으로 드래그합니다(탭을 우클릭 → "이 탭 분리"로도 가능합니다)
탭을 한꺼번에 옮기기탭 줄의 빈 곳을 드래그합니다
열을 아이콘 띠로 만들기열 위쪽의 "<" ">"를 누릅니다. 열이 아이콘만 있는 가는 띠가 됩니다. 다시 누르면 원래 열로 돌아옵니다
띠에서 패널 꺼내기띠의 아이콘을 누르면 그 패널만 옆으로 나타납니다. 바깥쪽을 누르거나 Esc를 누르거나 같은 아이콘을 누르면 닫힙니다

도구 모음·즐겨찾기 도구

도구 모음은 처음에는 왼쪽에 있습니다. 작업 영역의 위·아래·오른쪽에 붙이거나 띄울 수 있습니다.

  1. 도구 모음의 손잡이(세로일 때는 위쪽 끝, 가로일 때는 왼쪽 끝)를 드래그합니다. 작업 영역의 네 변에 붙일 수 있는 자리가 나타납니다.
  2. 그 자리에서 손을 떼면 그 가장자리에 붙습니다. 위·아래에서는 가로로 늘어서며, 다 들어가지 않으면 줄바꿈됩니다.
  • 붙일 수 있는 자리 이외의 곳에서 떼면 떠 있게 됩니다. 떠 있는 도구 모음은 "가로" "세로"로 배열을 전환하고, 손잡이를 더블클릭하면 이전 가장자리로 돌아갑니다.
  • 버튼을 우클릭 → "도구 모음 위치"에서 왼쪽·오른쪽·위·아래·띄우기도 선택할 수 있습니다. 위치는 다음에 실행해도 남습니다.
  • 버튼을 우클릭 → "도구 모음 아이콘 크기"에서 대·소, "도구 모음 열"에서 "열: 자동", "열: 항상 1열"을 선택할 수 있습니다. 다 들어가지 않는 도구는 휠·가장자리의 화살표·펜 드래그로 넘길 수 있습니다.
  • 순서 바꾸기: 버튼을 드래그(펜으로도 가능)하여 원하는 순서로 만듭니다. 조금 움직인 뒤 떼면 순서 변경, 움직이지 않고 떼면 그 도구를 선택합니다. 우클릭 "순서 초기화"로 원래 순서로 돌아갑니다.
  • 화면 색: 도구 모음 맨 끝의 해와 달 스위치로 라이트와 다크를 전환합니다(다크 모드).
  • 숨기기: 표시 → 창 → "도구 모음"의 ✓를 해제합니다.
  • 도구 목록: 표시 → 창 → "도구 목록"에서 도구 아이콘을 격자로 늘어놓은 패널을 표시할 수 있습니다. 다른 패널과 마찬가지로 열이나 탭에 넣을 수 있고 너비에 맞춰 줄바꿈됩니다. 아래의 전경색을 누르면 "색" 패널이 열리고, 배경색이나 ⇄를 누르면 서로 바뀌며, 작은 흑백 아이콘이나 D를 누르면 검정·흰색으로 돌아갑니다.

즐겨찾기 도구 띠

자주 쓰는 도구나 보조 도구를 3D 뷰와 UV 뷰 위의 작은 띠에 늘어놓고 바로 바꿔 쓸 수 있습니다.

  1. 도구 모음의 버튼이나 보조 도구(브러시 모음의 프리셋도)를 우클릭합니다.
  2. "즐겨찾기에 등록"을 선택합니다. 띠에 아이콘이 추가됩니다.
  3. 띠의 아이콘을 누르면 그 도구·보조 도구로 전환됩니다.
  • 띠의 "+"로 현재 보조 도구를 등록하고, 이미 등록되어 있으면 "-"로 제거합니다(펜만으로도 사용할 수 있습니다). 아이콘을 우클릭해도 제거할 수 있습니다.
  • 왼쪽의 점 모양 손잡이로 띠를 옮기고, 아이콘을 드래그하여 순서를 바꿉니다.
  • 띠를 우클릭하면 "세로로 배치", "위치 초기화", "이 막대 숨기기"가 나옵니다. ×로도 숨길 수 있습니다.
  • 숨긴 띠는 표시 → 창 → "즐겨찾기 도구(3D 뷰)", "즐겨찾기 도구(UV 뷰)"에서 각각 다시 표시할 수 있습니다.

3D 뷰 네 모서리의 아이콘

3D 뷰의 네 모서리에 표시 전환과 시점 아이콘이 늘어서 있습니다. ▼가 붙은 아이콘은 아래의 ▼를 누르면 설정이 열립니다(Esc를 누르거나 바깥쪽을 누르면 닫힙니다).

  • 위 중앙의 단은 왼쪽 손잡이(⋮)를 드래그하여 원하는 곳으로 옮길 수 있습니다. 손잡이를 더블클릭하면 원래 위치로 돌아갑니다.
  • 3D 뷰가 좁으면 오른쪽 위의 아이콘이 2단이 됩니다. 그래도 들어가지 않으면 시점 → 표시 범위 → 대칭 → 단면/양면 → 표시 형식 → 메시 선의 순서로 왼쪽 위의 "⋯" 판에 넣어집니다. "⋯"를 누르면 나타납니다.

시야각 바꾸기

오른쪽 위의 원근/평행 아이콘의 ▼에서 투영 방식과 원근 투영의 시야각을 5~120°로 바꿀 수 있습니다. 작을수록 망원, 클수록 광각입니다. "초기값으로 되돌리기"를 누르면 30°로 돌아갑니다.

3D 내비로 시점 움직이기

3D 내비는 마우스 버튼이나 키를 사용하지 않고 시점을 움직이는 도구입니다. 펜만으로 그릴 때 편리합니다.

축의 원(X·Y·Z)을 탭그 축의 시점(X=오른쪽, -Y=정면, Z=위). 한 번 더 탭하면 반대쪽
구를 드래그회전
돋보기를 위아래로 드래그줌
손바닥을 드래그평행 이동

구 아래의 ⟲·각도·⟳⟲·⟳로 15°씩 화면을 돌립니다. 각도를 누르면 0°로 돌아갑니다

  • 축의 시점에 맞추면 평행 투영이 되고, 회전하면 원근 투영으로 돌아갑니다(파일 → 환경 설정 → 조작 → "축 시점은 평행 투영"에서 끌 수 있습니다).
  • 키보드의 숫자패드로도 시점을 바꿀 수 있습니다(시점(숫자패드)).

카메라 방향 잠그기

자물쇠 버튼을 누르면 시점의 회전만 멈춥니다. 평행 이동과 확대/축소는 할 수 있습니다. 다시 누르면 해제됩니다. 정한 방향 그대로 다가가거나 움직이면서 칠할 때 사용합니다.

화면 기울이기(화면 회전)

3D 뷰를 종이처럼 기울여 그리기 쉬운 각도로 만들 수 있습니다.

  • Shift+휠로 5°씩, 3D 내비의 ⟲·⟳로 15°씩 회전합니다. 둥근 화살표를 좌우로 드래그해도 돌릴 수 있습니다.
  • 커서가 UV 영역 위에 있으면 UV를 돌립니다.
  • 돌린 채로 그리기·선택·평행 이동·오른쪽 드래그 회전을 그대로 사용할 수 있습니다. 드래그는 보이는 방향대로 움직입니다.
  • 키 할당의 "화면을 왼쪽으로 회전 (15°)", "화면을 오른쪽으로 회전 (15°)", "화면 회전을 초기값으로 되돌리기"에 키를 지정할 수도 있습니다(처음에는 키가 없습니다).

내비 옮기기·작게 만들기

  • 위쪽 손잡이(…)를 드래그하여 원하는 곳으로 옮깁니다. 더블클릭하면 오른쪽 위로 돌아갑니다.
  • 왼쪽 가장자리·아래쪽 가장자리·왼쪽 아래 모서리를 드래그하여 크기를 바꿉니다. 파일 → 환경 설정 → 인터페이스의 "3D 내비게이터 크기"에서도 바꿀 수 있습니다.
  • "—"로 작게 만들어 오른쪽 아래의 아이콘으로 만듭니다. 아이콘을 누르면 돌아옵니다(표시 → 창 → "3D 내비게이터(숨기면 오른쪽 아래 아이콘으로 복원)"로도 가능합니다).
  • 내비 아래에 회전과 확대/축소 슬라이더를 표시할 수 있습니다. 파일 → 환경 설정 → 인터페이스의 "내비게이터에 회전·확대/축소 슬라이더 표시"를 켭니다(처음에는 꺼짐). 3D 내비와 UV 가이드 양쪽에 표시됩니다.

다른 각도의 작은 창으로 동시에 보기

3D 뷰 안에 또 하나의 카메라로 본 작은 3D를 표시합니다. 그리면서 반대쪽이나 옆에서 보이는 모습을 확인할 수 있습니다. 작은 창은 보기 전용이며, 그리는 것은 큰 쪽입니다.

  1. 3D 뷰 오른쪽 아래의 다른 각도의 작은 창 아이콘을 누릅니다(표시 → 창 → "다른 각도의 작은 창"으로도 가능합니다).
  2. 작은 창의 제목에서 방향(정면·오른쪽·후면·왼쪽·위·반대)을 선택합니다. "반대"는 큰 쪽 시점의 반대편입니다.
  • 작은 창 안을 드래그하여 회전하고, 가운데 버튼이나 Shift+드래그로 평행 이동합니다.
  • 휠이나 Ctrl+드래그(위로 드래그하면 다가감. 펜용)로 다가가거나 멀어지고, 더블클릭하면 전체 보기입니다.
  • 제목으로 옮기고, 왼쪽·위쪽 가장자리와 왼쪽 위 모서리로 크기를 바꿉니다. ✕로 닫습니다.

3D와 UV를 작은 창으로 만들기

3D와 UV를 나란히 놓았을 때 한쪽을 작은 창으로 만들어 다른 쪽을 넓게 쓸 수 있습니다.

  1. U로 UV를 표시하여 3D와 나란히 놓습니다(UV 영역 표시).
  2. 작은 창으로 만들 쪽의 오른쪽 위 ✕ 아래에 있는 버튼을 누릅니다. 그쪽이 작은 창이 되고 다른 쪽이 전체로 넓어집니다.
  • 표시 → UV → "UV를 작은 창으로(3D는 전체)", "3D를 작은 창으로(UV는 전체)"나 UV 제목의 ⋯에서도 같은 일을 할 수 있습니다.
  • 작은 창은 제목 드래그로 옮기고 네 변·네 모서리로 크기를 바꿉니다. 앱 창 안이라면 패널 위에도 둘 수 있습니다.
  • ⇄로 작은 창과 전체를 서로 바꾸고, ▣로 나란히 놓은 표시로 되돌리며, ✕로 작은 창을 닫습니다.
  • 오른쪽 위의 자물쇠로 고정합니다(움직이지 않고 크기도 바뀌지 않습니다). Tab으로 팔레트를 숨겨도 작은 창은 남습니다.

보이는 방식 바꾸기(표시 형식·빛의 방향)

3D 뷰가 보이는 방식을 전환합니다. 바뀌는 것은 보이는 방식뿐이며, 칠한 그림과 내보내는 이미지는 바뀌지 않습니다.

  1. 3D 뷰 왼쪽 위의 표시 형식 아이콘을 누릅니다(표시 → 표시 형식에서도 선택할 수 있습니다).
  2. 사용할 형식을 선택합니다. 다음에 실행해도 같은 형식으로 열립니다.
표시 형식보이는 방식
칠한 색 그대로(unlit)빛을 비추지 않고 칠한 색을 그대로 보여 줍니다. 색을 확인할 때 사용합니다
2단계 툰빛이 닿는 곳과 그림자의 2색으로 보여 줍니다
음영 (요철이 보임)요철이 보이도록 빛을 비춥니다. 처음 사용할 때는 이 형식으로 열립니다
선만 표시(와이어프레임)텍스처를 숨기고 메시 선만 보여 줍니다. 포즈·블렌드 셰이프·이동으로 형태가 바뀌어도 선이 따라옵니다
마무리 모습(lilToon·MToon, 베타) Pro머티리얼 설정을 거친 모습입니다("마무리 모습"으로 보기)

단면 표시·양면 표시

같은 아이콘 줄이나 표시 → 표시 형식에서 선택합니다. "단면 표시(뒷면은 그리지 않음)"와 "양면 표시 (보이는 뒷면에도 칠함)"가 있습니다. 옷 안쪽 등 뒷면에 칠할 때는 양면으로 합니다(뒷면·가려진 면에도 칠하기).

빛의 방향 바꾸기

  1. 표시 형식 아이콘 아래의 ▼를 누릅니다.
  2. 구를 드래그하여 빛이 오는 방향을 정합니다. 좌우·높이 슬라이더로도 바꿀 수 있습니다.
  3. "카메라 따라가기"를 켜면 시점을 돌려도 빛이 닿는 방식이 같아집니다. "초기값으로 되돌리기"를 누르면 원래대로 돌아갑니다.
  • 2단계 툰·음영·마무리 모습에서 같은 빛을 사용합니다. "칠한 색 그대로"에서는 빛이 보이지 않습니다.
  • Pro 머티리얼 패널의 "표시와 빛"과 같은 값입니다.
  • 카메라 조작이 "Alt + 마우스 버튼"일 때는 Shift+오른쪽 드래그로 빛의 좌우를 돌릴 수 있습니다.

투명한 부분이 보이는 방식

  • 지우개나 투명색으로 칠한 곳은 3D에서 아래에 체크무늬가 보입니다. 표시 → 표시 형식 → "투명한 곳을 체크무늬로 표시"를 끄면 회색이 됩니다.
  • 텍스처 세트 행을 우클릭(또는 "…") → "알파 빼기(3D에서 투명을 뺌)"에서 투명이 보이는 방식을 선택할 수 있습니다. "없음", "컷아웃"(불투명도 50%보다 옅은 곳을 빼서 건너편을 보이게 함), "반투명"(불투명도 그대로 비치게 함)이 있습니다.
  • 알파 빼기도 보이는 방식일 뿐이며 내보내는 이미지는 바뀌지 않습니다. 작업 파일에 남고 실행 취소로 되돌릴 수 있습니다. 뺀 곳은 3D에서 누를 수 없으므로 UV 영역에서 칠합니다.

텍스처를 도트 그대로 표시하기

3D에서 텍스처를 보간하지 않고 픽셀 하나하나를 네모나게 보여 줍니다. 축소해서 잘게 보이는 곳은 보간합니다.

  • 텍스처 세트마다 세트 행의 ⋯나 우클릭 → "도트 그대로 표시(보간 안 함)"로 전환합니다. 켜져 있는 세트는 행에 네모 표시가 나타납니다(누르면 꺼집니다).
  • 모든 세트가 처음부터 켜져 있습니다. 직접 전환한 세트는 작업 파일에 남습니다. 표시만 바뀌며 칠한 그림과 내보내기는 바뀌지 않습니다.
  • 표시 → 표시 형식 → "모든 세트의 텍스처를 도트 그대로 표시(보간 안 함)"로 모든 세트를 한꺼번에 전환합니다.
  • UV 영역은 확대하면 항상 도트 그대로 보입니다.

잘 안 될 때

  • 그림자가 생겨 칠한 색을 알아보기 어렵습니다: 표시 형식을 "칠한 색 그대로"로 합니다.
  • 빛의 방향을 바꿔도 보이는 모습이 바뀌지 않습니다: "칠한 색 그대로"에서는 빛이 보이지 않습니다. 2단계 툰이나 음영으로 합니다.
  • 투명하게 한 곳이 회색·체크무늬로 보입니다: 보이는 방식일 뿐입니다. 건너편을 비쳐 보고 싶을 때는 텍스처 세트의 "알파 빼기"를 컷아웃이나 반투명으로 합니다.
  • 알파 빼기로 했더니 그 곳에 칠할 수 없습니다: 뺀 곳은 3D에서 누를 수 없습니다. UV 영역에서 칠하거나 알파 빼기를 "없음"으로 되돌립니다.
  • 낮은 해상도의 텍스처가 3D에서 흐릿합니다: 그 세트의 "도트 그대로 표시(보간 안 함)"를 켭니다.
  • "마무리 모습"을 선택할 수 없습니다: Pro 전용 표시입니다(에디션 비교).

우클릭 메뉴

누른 곳에 맞는 메뉴가 나타납니다. 펜이라면 펜 끝을 움직이지 않고 길게 눌러도 나타납니다. 오른쪽 드래그(3D 회전·UV 이동) 뒤에는 메뉴가 나타나지 않습니다.

잘 안 될 때

  • 세밀한 부분을 그리고 있으면 메뉴가 멋대로 나타납니다: 펜을 길게 눌러서 나타난 것입니다. 파일 → 환경 설정 → 펜·입력 → 메뉴와 버튼의 "펜으로 길게 누르면 메뉴 열기"를 끕니다. 오른쪽 클릭·펜 사이드 버튼으로 나타나는 메뉴는 바뀌지 않습니다.
  • 버튼을 길게 누르면 메뉴가 나타나서 누를 수 없습니다: 같은 곳의 "버튼 위에서 길게 누르기"를 "눌렀다 떼면 결정(기본)"으로 합니다.

팝업 팔레트(펜만으로 사용)

펜을 든 채 그 자리에서 색·보조 도구·브러시 크기를 바꿀 수 있는 둥근 팔레트입니다.

  1. 3D 뷰나 UV 영역 위에서 펜의 사이드 버튼을 누릅니다.
  2. 펜을 움직이지 않고 뗍니다. 그 자리에 둥근 팔레트가 나타납니다(움직이면 지금까지처럼 회전·평행 이동입니다).
  3. 다 썼으면 팔레트 바깥을 누릅니다(그려지지 않습니다). Esc를 누르거나 오른쪽 버튼을 한 번 더 탭해도 닫힙니다.
  • 바깥쪽: 자주 쓰는 보조 도구. 누르면 그 도구로 바꾸고 닫힙니다. "+"로 현재 보조 도구를 추가하고, 길게 누르거나 우클릭하여 제거합니다(10개까지).
  • 안쪽: 색상 고리와 채도·명도 사각형으로 전경색을 선택합니다. 위의 작은 원은 최근 사용한 색입니다.
  • 아래의 라벨: 위아래로 드래그하여 브러시 크기를 바꿉니다.
  • 마우스로 표시하려면 파일 → 환경 설정 → 조작 → 마우스의 "오른쪽 클릭"을 "팝업 팔레트"로 합니다(처음에는 "메뉴"). 우클릭 메뉴 맨 위의 "팝업 팔레트 표시"로도 열 수 있습니다.
  • 펜 태블릿 설정에서 Windows Ink를 끄고 있을 때는 사이드 버튼도 마우스 오른쪽 클릭으로 전달되므로 위의 "오른쪽 클릭" 설정을 따릅니다.

참고 이미지를 보면서 그리기

자료 이미지를 패널에 표시하고 보면서 그릴 수 있습니다. 이미지에서 색을 가져올 수도 있습니다.

  1. 참고 이미지 패널의 "열기"를 누르고 이미지를 선택합니다.
  2. 아래의 썸네일에서 열린 이미지를 전환합니다. ×로 닫습니다.
  • 파일 → 가져오기 → "참고 이미지 열기", 패널로 드래그 앤 드롭, 패널을 누른 뒤 Ctrl+V로도 열 수 있습니다.
  • 색 가져오기: 스포이트로 이미지를 클릭하거나 드래그합니다. 떼면 그 색이 최근 사용한 색에 들어갑니다.
  • 옮기기: 손바닥·가운데 버튼·오른쪽 버튼·Space+드래그로 이동하고, 휠로 확대/축소합니다.
  • 보는 방식: 위의 버튼으로 전체 보기·좌우 반전·90° 회전. 돋보기의 +·-로 확대/축소하고(펜만으로도 사용할 수 있습니다), "100%"로 이미지의 1픽셀을 화면의 1점으로 만듭니다.
  • 이미지는 긴 변 1600px로 저장되며, 다음에 실행해도 복원됩니다.

화면의 공통 조작

어느 패널·창에서나 똑같이 쓸 수 있는 조작입니다.

  • 버튼이나 항목의 설명은 커서(펜 끝)를 이름 위에 올리면 나타납니다.
  • 환경 설정·단축키 목록·확인 창은 제목을 드래그하여 옮길 수 있습니다. 오른쪽 위의 × 또는 Esc로 닫습니다.
  • 메뉴 항목이나 버튼은 펜으로 눌렀다 떼도 선택됩니다(펜·입력에서 바꿀 수 있습니다).
  • 펜의 더블 탭은 두 번째 위치가 조금 어긋나도(12px·0.5초까지) 더블클릭으로 인식합니다.
  • 펜의 지우개 쪽으로도 패널·창 조작(버튼·슬라이더·순서 바꾸기·드래그)이 펜 끝과 똑같이 작동합니다. 그리는 영역 안에서는 지우개가 됩니다.
  • 브라우저 조작 키(새로 고침·인쇄·페이지 확대 등)는 작동하지 않습니다. 화면의 글자는 선택할 수 없습니다(입력란은 선택할 수 있습니다).
  • 현재 에디션에서 사용할 수 없는 기능은 메뉴나 버튼이 흐려지고 자물쇠 표시가 붙습니다(에디션 비교).

다크 모드·배색·언어 바꾸기

화면 색을 밝은 "라이트"와 어두운 "다크"로 전환합니다.

  1. 도구 모음 맨 끝(세로일 때는 아래, 가로일 때는 오른쪽 끝)의 해와 달 스위치를 누릅니다.
  2. 라이트와 다크가 전환됩니다.
  • 파일 → 환경 설정 → 인터페이스 → 표시의 "화면 색"에서도 같습니다(처음에는 라이트).
  • 키로 전환하려면 키 할당의 분류 "표시"에 있는 "다크 모드"에 키를 지정합니다(키 할당하기).

배색 바꾸기

파일 → 환경 설정 → 인터페이스 → 표시의 "배색"에서 화면 바탕·패널·버튼·글자·주요 색·보조 색상·3D 배경·UV 배경·도구 모음 색을 바꿀 수 있습니다.

  • 라이트와 다크를 따로 저장합니다.
  • "기본 배색으로 되돌리기"를 누르면 원래 색으로 돌아갑니다.

화면 언어 바꾸기

파일 → 환경 설정 → 인터페이스 → 언어의 "언어 / Language"에서 선택합니다. 日本語·English·한국어·中文(简体)·中文(繁體)가 있습니다.

환경 설정

앱 전체의 설정입니다. 파일 → 환경 설정(Ctrl+Alt+Shift+K)에서 엽니다.

  • 왼쪽에 분류, 오른쪽에 절이 늘어서 있습니다. 절의 제목을 누르면 펼치기·접기가 전환됩니다(접어 둔 절은 다음에도 그대로입니다).
  • 항목의 설명은 이름 위에 커서를 올리면 나타납니다.
  • 설정은 다음에 실행해도 남습니다.

  • 입·출 만드는 방식: "필압만으로 입·출"은 가벼운 필압을 확 가늘게 하고, 선의 시작과 끝도 필압으로 가늘게 합니다(마우스는 항상 길이). "길이로 입·출"은 보조 도구의 "시작"·"끝" 길이로 끝을 가늘게 합니다.

  • 펜의 사이드 버튼은 펜 버튼·Windows Ink에 정리되어 있습니다.

환경 설정에 없는 설정

다음 설정은 사용하는 곳에만 있습니다.

  • 두 세트에 걸쳐 그리기: 3D 뷰 왼쪽 아래의 "걸쳐 그리기"(메인과 서브)
  • UV 아일랜드 바깥으로 이어서 칠하기: UV 영역의 제목·표시 → UV(아일랜드 밖으로 나갔을 때)
  • 펜 드래그로 레이어·보조 도구 옮기기: 레이어의 "…"
  • 내보내기 번짐과 내보내기 위치: 내보내기 창(내보내기 번짐)
  • 대칭 상대를 찾는 범위: 3D 뷰 왼쪽 위의 대칭 ▼(대칭으로 그리기)

잘 안 될 때

  • "3D 마우스" 절이 없습니다: 3D 마우스를 한 번도 연결한 적이 없으면 표시되지 않습니다. 연결하면 나타납니다.
  • "펜 선 먼저 표시"를 켜도 달라지지 않습니다: 펜(Windows Ink)으로 그릴 때만 적용됩니다. 마우스·터치·"필압 직접 읽기(WinTab)" 펜에서는 아무것도 하지 않습니다. 켜지지 않았을 때는 오른쪽 아래에 이유를 표시하고 꺼집니다.
  • 키 확대/축소가 화면 한가운데로 향합니다: 조작 → 카메라의 "키 확대/축소는 커서 중심"을 켭니다.
