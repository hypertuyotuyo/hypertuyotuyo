선택 범위·변형·텍스트·자

칠할 곳을 제한하고 그린 내용을 움직이며 텍스트나 이미지를 붙이는 기능입니다. 변형 틀은 3D 모델 위와 UV 영역 모두에 표시됩니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

이 페이지에서 “v1.2.0:”로 시작하는 설명은 공개 전 안내입니다. 현재 배포 버전은 v1.1.2입니다.

선택 범위

  1. '선택 범위' 도구(S)를 선택하고 보조 도구에서 모양을 선택합니다.
  2. 3D 뷰(또는 UV 영역)에서 드래그·그리기·클릭으로 선택합니다.
  3. 선택 중에는 그리기·칠하기·지우기·필터·그라데이션이 선택 범위 안에만 적용됩니다. 바깥은 조금 어두워지며 경계에 점선이 표시됩니다.
  4. Ctrl＋D 로 해제합니다.

선택 펜·선택 지우개브러시로 그어 추가·제거
  • 누르기 시작할 때 Shift= 추가·Alt= 제거·Shift＋Alt= 교차.
  • '뒷면·가려진 면도 선택'을 켜면 화면 모양에 해당하는 곳을 뒷면까지 모두 선택합니다.몸 둘레 전체를 선택하여 옷 줄무늬를 칠할 때 편리합니다.
  • '선택 범위' 메뉴: 모두 선택 Ctrl＋A·반전 Ctrl＋Shift＋I·확장/축소/경계 흐리기·레이어의 칠해진 곳 선택·선택 범위로 마스크 만들기·전경색으로 칠하기·안쪽 지우기(Delete)·점선 표시(Ctrl＋H)·선택 범위 복원(Ctrl＋Shift＋D).
  • 선택 중에는 선택하지 않은 텍스처 세트에 그릴 수 없습니다.
레이어 썸네일을 Ctrl+ 누르면 칠해진 곳을 선택 범위로 만들 수 있습니다(Shift 로 추가· Alt 로 제거).
v1.2.0: 비슷한 색 모두 선택(모든 버전): 선택 범위 → “비슷한 색 모두 선택(전경색)”으로 전경색에 가까운 색의 곳을 텍스처 전체에서 선택합니다(이어져 있지 않아도). 허용량·보는 그림(모든 레이어/지금 레이어)·선택 방식(새로·더하기·빼기)을 정할 수 있습니다. 밑칠 색마다 그림자 색을 바꿀 때 등에.

선택 범위 바

선택 중에는 3D 영역 아래에 선택 범위 바가 표시됩니다. 왼쪽 '선택 중' 표시 뒤에 아이콘 버튼이 있습니다(펜·커서를 대면 이름과 키 표시).

  • 해제(색 있는 버튼)·반전 | 확장·축소·경계 흐리기 | 칠하기·지우기 | 새 레이어로 ▾(복사/잘라내기)·기타 ▾(마스크·선택한 곳만 표시·숨기기·점선).
  • 좁은 화면에서는 확장·축소·경계 흐리기가 '범위 ▾'로 묶입니다.

이동·변형 도구

  1. '이동·변형' 도구(V)를 선택합니다.
  2. 3D 모델(또는 UV 영역)에서 움직일 그림을 누릅니다. 누른 곳에 그려진 가장 위 레이어가 선택되며 그림 틀이 표시됩니다('레이어 자동 선택'. 끄면 선택한 레이어).
  3. 누른 채 드래그하면 바로 움직입니다. 모서리로 크기, 위 원으로 회전합니다.
  4. Enter 또는 다른 도구로 바꾸면 확정하고,Esc 로 취소합니다. 틀 밖을 누르면 확정하고 누른 곳의 레이어로 이동합니다.
  • 선택 범위가 있으면 그 안만 움직입니다. 확정은 실행 취소 한 번에 해당합니다.
  • 도구 속성에서 틀 방식(확대·축소·회전/자유 변형/워프)과 워프 격자 수를 선택합니다.
  • 텍스트 레이어를 누르면 텍스트 틀이 됩니다(틀 안 드래그로 이동, 더블클릭으로 다시 입력).

변형(Ctrl+T)과 3D 위의 틀

  • 변형(Ctrl＋T): 선택 범위가 있으면 그 안, 없으면 레이어 전체를 움직이는 틀을 표시합니다.
  • 틀은 3D 영역(모델 위의 움직일 그림 주변)과 UV 영역 양쪽에 표시됩니다. 어느 틀을 잡아도 같게 움직이며 다른 쪽도 따라옵니다. 움직일 그림이 3D에서 보이면 UV 영역을 열지 않고 3D에서만 조작할 수 있습니다.
  • 틀 안을 드래그하여 이동·모서리로 확대/축소(Shift 로 가로세로 비율 변경 가능)·변으로 한쪽만·위 원으로 회전(Shift 로 15° 간격). 좌우·상하 반전도 가능합니다. 변이나 모서리를 반대편 너머로 끌면 뒤집힙니다.
  • 3D 틀 위에서도 오른쪽·가운데 드래그·휠· Space+ 드래그로 시점을 움직일 수 있습니다. 시점을 바꿔도 틀이 따라옵니다.
  • UV 영역에 격자선을 표시하면 틀이 격자에 스냅됩니다(격자선과 스냅).
v1.2.0: 3D 변형(모든 버전): 3D에서 보이는 작은 부분의 그림에도 3D 틀이 나오게 하고, 틀 안을 드래그했다가 놓아도 틀과 그림이 튀지 않게 했습니다(자유 변형·워프도).
v1.2.0: 대칭에도(모든 버전): 그리기 대칭이 켜져 있고 선택 범위가 한쪽에 있을 때 아래 막대에 “대칭에도”가 나옵니다. 켠 채로 움직이면 3D의 반대쪽도 거울에 비춰 함께 움직입니다(반대쪽의 원래 그림은 바뀝니다). 이동 도구도 같습니다.

자유 변형·워프

변형·이동·변형 도구·이미지 추가·붙여넣기·이미지를 3D/UV에 붙이기 틀 아래 바에 아이콘 3개(확대·축소·회전/자유 변형/워프)가 있습니다.

  • 자유 변형: 모서리 4개를 각각 드래그하여 모양을 바꿉니다(원근처럼 그림 적용).
  • 워프: 격자 점을 드래그하여 그림을 구부립니다. 격자는 3×3(바에서 4×4·5×5도 가능).
  • 둘 다 위 원 또는 모서리 조금 바깥을 드래그하여 회전합니다(Shift 로 15° 간격). 안쪽 드래그로 전체 이동.
  • 전환해도 형태가 유지됩니다. 확정은 실행 취소 한 번에 해당합니다(선택 범위 이동도 동일). 3D에 붙일 때는 화면 위 형태를 보이는 면에 투영합니다.

복사·잘라내기·붙여넣기

  • 복사(Ctrl＋C) · 잘라내기(Ctrl＋X): 선택 범위 안(없으면 레이어 전체). 여러 레이어를 선택해도 대상은 현재 선택한 1장뿐입니다.
  • 붙여넣기(Ctrl＋V): 같은 UV 위치에 새 레이어로 붙이고 바로 변형할 수 있습니다.
  • 잠긴·숨겨진·투명 픽셀을 잠근 레이어는 잘라내기·지우기를 하지 않습니다(이유 안내).

이미지 추가·이미지 붙이기

  • 이미지 추가(파일 → 가져오기 → 이미지를 레이어로 가져오기·이미지 드롭·외부에서 복사한 이미지의 Ctrl＋V): 이미지 배치 틀이 표시됩니다. UV 영역이 열려 있으면 UV 위, 닫혀 있으면 3D 중앙(보이는 면에 투영). 가로세로 비율과 투명한 부분이 유지됩니다.
  • 틀을 맞추고 Enter 로 파일 이름의 새 레이어에 적용합니다.Esc 로 취소하면 아무것도 남지 않습니다. 틀 아래 바의 '텍스처 전체에 붙이기'로 UV 전체에 늘려 넣을 수도 있습니다(UV 크기로 그린 이미지용).
  • 이미지를 3D에 붙이기(편집 → 이미지를 3D에 붙이기): 3D 위에서 틀을 맞추고 Enter 로 모델의 보이는 면에 투영하여 붙입니다. 시점을 움직이며 맞춰도 됩니다. '비스듬한 면도 진하게'로 기울어진 면이 옅어지지 않게 합니다.
  • 이미지를 UV에 붙이기(편집 → 이미지를 UV에 붙이기): UV 영역 위에서 틀을 맞춰 새 레이어에 붙입니다.
좌우 대칭과 선택 범위도 적용됩니다.

텍스트

  1. '텍스트' 도구(T)를 선택하고 3D 뷰(또는 UV 영역)를 누릅니다.
  2. 틀과 텍스트 창이 표시되며 바로 틀 위에서 입력할 수 있습니다 . 일본어 입력도 그대로 사용할 수 있으며 변환 후보는 글자 옆에 표시됩니다.
  3. Ctrl＋Enter 로 확정합니다(입력 중 Enter 는 줄바꿈).Esc 를 한 번 누르면 입력이 중단되고(틀 유지), 두 번 누르면 취소합니다.
  • 텍스트 창에서 글꼴·크기·색·굵게·기울임·세로쓰기·줄 간격·자간·정렬·테두리를 정합니다. 색은 색 패널의 전경색, 테두리는 배경색이 적용됩니다.
  • 글자별 변경: 글자를 선택한 후 색·크기·글꼴·굵게·기울임·자간·테두리를 바꾸면 그 글자만 바뀝니다. 선택 없이 바꾸면 이후 입력할 글자에 사용됩니다.
  • 입력 중에는 키 단축키(E 로 지우개 등)가 적용되지 않습니다. 틀 이동은 Ctrl 를 누른 채 드래그합니다.
  • 이 PC에 설치된 모든 글꼴을 선택할 수 있습니다. 글꼴 파일(.ttf·.otf)도 가져올 수 있습니다(현재 실행 동안만).

텍스트 다시 입력(텍스트 레이어)

  • '새 레이어에' 붙인 텍스트(UV에 붙인 텍스트는 항상)는 텍스트 레이어가 되며 레이어 목록에 'T' 표시가 생깁니다.
  • 레이어 목록 더블클릭·우클릭 → '텍스트 다시 입력'·텍스트 도구로 글자 누르기로 붙였을 때 상태로 다시 열 수 있습니다. 글자별 색·크기도 유지됩니다.
  • 텍스트 레이어에 펜 등으로 덧그리면 'T+' 표시가 됩니다. 다시 입력하면 덧그린 곳이 지워지므로 유지하려면 별도 레이어로 나누세요.
  • 우클릭 → '래스터화'으로 일반 레이어로 만듭니다(다시 입력 불가). 작업 파일에도 저장되므로 다시 열어도 텍스트를 다시 입력할 수 있습니다. PSD에는 일반 레이어로 씁니다.

자

  • 그리는 선을 자에 스냅합니다. 직선·곡선은 자 근처에서 시작한 선만, 동심원·방사선·평행선은 어디에서 그려도 적용됩니다.
  • 만들기: 직선·평행선은 드래그, 동심원·방사선은 누른 곳이 중심, 곡선은 점을 놓고 Enter 또는 더블클릭합니다. 자의 원은 드래그로 움직일 수 있습니다.
  • 3D 영역의 자는 시점을 움직여도 화면에 유지됩니다. UV 영역에도 별도로 놓을 수 있습니다.
  • 보기 → 선과 자 → 자에 스냅(Ctrl＋Alt＋R)으로 전환하며 자를 삭제할 수 있습니다.
곡선 제어점을 놓는 도중 에는 Ctrl＋Z 로 마지막 점 하나를 취소할 수 있습니다.Ctrl＋Y 또는 Ctrl＋Shift＋Z 로 점 취소를 다시 실행할 수 있습니다.Enter·더블클릭으로 자를 확정한 후에는 일반 내역 조작으로 돌아갑니다.
v1.2.0: 자가 있을 때는 그 영역 아래 가운데에 막대가 나옵니다(자 종류·달라붙기 켜고 끄기·지우기). 지우기는 그 영역의 자만 지웁니다.
