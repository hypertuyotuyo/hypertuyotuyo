선택 범위·변형·텍스트·자

칠할 곳을 선택 범위로 제한하는 방법, 그린 그림을 움직여 모양을 바꾸는 방법, 이미지나 텍스트를 모델에 붙이는 방법, 자로 선을 맞추는 방법을 설명합니다. 변형 틀은 3D 뷰의 모델 위와 UV 뷰 양쪽에 나타납니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

먼저 이것만
  1. "선택 범위" 도구(S)로 둘러싸면 그 안에만 칠할 수 있습니다. Ctrl+D로 해제합니다(자세히).
  2. "이동·변형" 도구(V)로 모델 위의 그림을 누른 채 그대로 드래그하면 움직입니다(자세히).
  3. 크기나 방향을 바꾸려면 Ctrl+T를 누릅니다. 모서리로 크기를, 위쪽 원으로 회전을 조절하고, Enter로 확정합니다(자세히).
  4. 이미지는 창에 끌어다 놓으면 틀을 맞춰 붙일 수 있습니다(자세히).
  5. "텍스트" 도구(T)로 모델을 누르면 그 자리에서 텍스트를 입력할 수 있습니다(자세히).

칠할 곳 고르기(선택 범위)

선택 범위를 만들면 그리기·칠하기·지우기·필터·그라데이션이 그 안에만 적용됩니다. 삐져나오면 안 되는 곳을 칠할 때 사용합니다.

  1. "선택 범위" 도구(S)를 선택합니다.
  2. 보조 도구에서 선택 방법(사각형·올가미 등)을 고릅니다.
  3. 3D 뷰나 UV 뷰에서 드래그하거나, 따라 그리거나, 클릭해서 선택합니다. 바깥쪽이 약간 어두워지고 경계에 점선이 나타납니다.
  4. 펜 등으로 도구를 바꿔 칠합니다. 선택 범위 밖에는 칠해지지 않습니다.
  5. Ctrl+D로 해제합니다.

보조 도구와 선택 방법

보조 도구선택 방법
사각형·타원드래그합니다.
올가미따라 그려서 둘러쌉니다.
꺾은선클릭해서 점을 찍습니다. 첫 번째 점을 클릭하거나, 더블클릭하거나, Enter를 누르면 닫힙니다.
자동 선택누른 곳과 색이 비슷하고 이어진 부분을 선택합니다.
아일랜드로 선택누른 UV 아일랜드를 통째로 선택합니다.
면으로 선택따라 그린 면을 통째로 선택합니다.
선택 펜·선택 지우개브러시로 따라 그려서 더하거나 뺍니다(Alt를 누르는 동안은 반대로 동작합니다).
  • 3D 뷰에서는 보이는 면만 선택합니다. 도구 속성에서 "뒷면·가려진 면도 선택"을 켜면, 화면에서 겹치는 부분을 뒷면까지 모두 선택합니다. 몸을 한 바퀴 빙 둘러 선택해서 옷의 줄무늬를 칠할 때 편리합니다.
  • 자동 선택은 도구 속성에서 "참조"(모든 레이어 / 선택한 레이어)·"허용 오차"·"안티에일리어싱 (가장자리를 1px 부드럽게)"을 정합니다.
  • 면으로 선택은 "인식 범위"와 "사각형 단위로 선택 (삼각형 2개를 1면으로)"을 정합니다.

선택 범위에 더하기·빼기

도구 속성의 "선택 방식"에서 새로·추가·삭제·교차 중에서 고릅니다. 누르기 시작할 때 키를 누르고 있으면 그 1회만 바꿀 수 있습니다.

누르기 시작할 때의 키선택 방식
없음새로(현재 선택 범위를 대체). 누르기만 하고 움직이지 않으면 해제
Shift추가(현재 선택 범위에 더함)
Alt삭제(현재 선택 범위에서 뺌)
Shift+Alt교차(겹친 부분만 남김)

그 밖의 선택 방법

  • 레이어 썸네일을 Ctrl+클릭하면 그 레이어의 칠해진 곳을 선택합니다(Shift로 더하기, Alt로 빼기).
  • 3D 뷰의 우클릭 → "이 아일랜드 선택 (선택 범위)"로 누른 곳의 아일랜드를 선택합니다. UV 뷰의 우클릭에는 "이 아일랜드를 선택에 추가"도 있습니다.
  • 전경색과 비슷한 색의 부분을 한꺼번에 선택할 때는 비슷한 색을 모두 선택하기를 사용합니다.

잘 안 될 때

  • 원하는 곳에 칠해지지 않습니다: 선택 범위가 남아 있으면 바깥에는 칠할 수 없습니다. Ctrl+D로 해제합니다.
  • 다른 텍스처 세트에 그릴 수 없습니다: 선택 중에는 선택 범위가 없는 텍스처 세트에 그릴 수 없습니다. 선택을 해제하거나, 모든 세트가 포함되는 "모두 선택"(Ctrl+A)을 합니다.
  • 뒷면이 선택되지 않습니다: 3D 뷰에서는 보이는 면만 선택합니다. "뒷면·가려진 면도 선택"을 켭니다.
  • 바깥이 어두워서 색을 알아보기 어렵습니다: 선택 범위 → "선택 범위 밖을 어둡게"를 끄면 점선만 남습니다(메뉴).

선택 범위 바로 조작하기

선택하고 있는 동안은 3D 뷰 아래에 선택 범위 바가 나타납니다(UV만 표시하고 있을 때는 UV 뷰 아래). 왼쪽의 "선택 중" 표시 뒤에 아이콘 버튼이 늘어서 있습니다. 버튼의 이름과 키는 펜 끝이나 커서를 올리면 표시됩니다.

버튼동작
해제(색이 있는 버튼)선택을 해제합니다. 해제한 뒤에도 "다시 선택"(Ctrl+Shift+D)으로 되돌릴 수 있습니다
반전선택 범위를 반전합니다
확장·축소·경계 흐리기선택 범위의 모양을 다듬습니다. 화면이 좁을 때는 "범위 ▾"로 합쳐집니다
칠하기선택 범위를 전경색으로 칠합니다
지우기선택 범위 안을 지웁니다
새 레이어로 ▾"복사하여 새 레이어로", "잘라내어 새 레이어로"
기타 ▾선택 범위로 마스크 만들기, 선택한 부분만 표시, 선택한 부분 숨기기, 선택 범위 점선 표시, 선택 범위 밖을 어둡게
숨기기 펜 바나 자 띠가 표시되어 있을 때는 선택 범위 바가 그 위에 나란히 놓입니다. "선택한 부분만 표시"와 "선택한 부분 숨기기"는 표시 범위의 기능입니다.

선택 범위 다듬기·활용하기(메뉴 "선택 범위")

"선택 범위" 메뉴에 선택 범위를 다듬거나 활용하는 항목이 있습니다. 3D 뷰 우클릭의 "선택 범위"에도 대부분의 항목이 있습니다.

항목키동작
모두 선택Ctrl+A모든 텍스처 세트 전체를 선택합니다
선택 해제Ctrl+D선택 범위를 해제합니다
다시 선택 (마지막으로 해제한 선택 범위)Ctrl+Shift+D마지막으로 해제한 선택 범위로 되돌립니다
선택 범위 반전Ctrl+Shift+I선택하지 않은 곳을 선택합니다
선택 범위 확장·선택 범위 축소—UV 위에서 1~64px 넓히거나 좁힙니다
경계 흐리기—가장자리를 1~64px 부드럽게 합니다
레이어의 칠해진 곳 선택—선택한 레이어에서 그려져 있는 곳을 선택합니다
비슷한 색 모두 선택(전경색)—전경색과 비슷한 색의 부분을 선택합니다(아래)
선택 범위로 마스크 만들기—선택한 레이어에 선택 범위 모양의 마스크를 붙입니다(마스크)
선택 범위를 복사하여 새 레이어로—안의 그림을 같은 위치의 새 레이어에 복사합니다
선택 범위를 잘라내어 새 레이어로—안의 그림을 새 레이어로 옮깁니다
선택 범위를 전경색으로 채우기—안쪽을 전경색으로 칠합니다
선택 범위 안 지우기Delete선택한 레이어의 안쪽 그림을 지웁니다

선택 범위 밖을 어둡게—끄면 점선만 남아, 바깥의 색을 그대로 보면서 칠할 수 있습니다. 다음에 실행할 때도 유지됩니다(처음에는 켜져 있음)

비슷한 색을 모두 선택하기

전경색과 비슷한 색의 부분을 텍스처 전체에서 선택합니다. 이어져 있지 않은 부분도 선택합니다. 밑칠 색마다 그림자 색을 바꿀 때 등에 사용합니다.

  1. 스포이트(I)로 선택하려는 색을 전경색으로 지정합니다.
  2. 선택 범위 → "비슷한 색 모두 선택(전경색)"을 선택합니다.
  3. "허용량(%)"으로 어디까지 비슷한 색을 선택할지 정합니다.
  4. "색을 볼 그림"에서 "모든 레이어"나 "현재 레이어"를 고릅니다.
  5. "선택 방식"에서 "새로", "더하기", "빼기" 중 하나를 고르고 "선택"을 누릅니다.

한 색으로 채우기·색 한꺼번에 바꾸기

"편집" 메뉴의 3개 항목입니다. 선택 범위가 있으면 그 안에, 없으면 선택한 레이어 전체에 적용됩니다.

항목키동작
전경색으로 채우기Alt+Backspace전경색으로 채웁니다
배경색으로 채우기Ctrl+Backspace배경색으로 채웁니다
전경색으로 변경 (투명도 유지)—그려져 있는 곳의 색만 현재 전경색으로 바꿉니다. 농도(투명도)와 투명한 부분은 그대로입니다
  • "전경색으로 변경"은 선화의 색을 한꺼번에 바꿀 때 사용합니다. 레이어 행의 우클릭에도 있습니다.
  • 마스크에 그리고 있을 때는 마스크를 색의 밝기로 칠합니다(흰색=보임, 검정=가림).
  • 노멀 맵 폴더 안에서는 회색으로 바꿉니다. 노멀 맵 이미지 레이어에는 사용할 수 없습니다(칠할 대상).

그린 그림 움직이기(이동·변형 도구)

3D 모델 위에서 그림을 눌러 그대로 움직일 수 있습니다. 어느 레이어에 그렸는지 찾지 않아도, 누른 곳의 레이어가 선택됩니다.

  1. "이동·변형" 도구(V)를 선택합니다.
  2. 3D 뷰(또는 UV 뷰)에서 움직이려는 그림을 누릅니다. 누른 곳에 그려진 가장 위의 레이어가 선택되고, 그 그림의 틀이 나타납니다.
  3. 누른 채 드래그하면 바로 움직입니다. 모서리로 크기를, 위쪽 원으로 회전을 조절합니다.
  4. Enter를 누르거나 다른 도구로 바꾸면 확정됩니다. Esc로 취소합니다.

세부 설정

  • 도구 속성에서 "레이어 자동 선택"을 끄면, 누른 곳이 아니라 선택해 둔 레이어를 움직입니다.
  • 틀 바깥을 누르면 확정되고, 누른 곳의 레이어로 옮겨 갑니다.
  • 선택 범위가 있으면 그 안만 움직입니다. 확정은 실행 취소 1회분입니다.
  • 도구 속성의 "도형"에서 틀의 모양(확대·축소·회전 / 자유 변형 / 워프)을, "워프 격자"에서 격자 수를 고를 수 있습니다(자유 변형·워프).
  • 텍스트 레이어를 누르면 텍스트 틀이 됩니다. 틀 안을 드래그하면 이동하고, 더블클릭하면 다시 입력할 수 있습니다(텍스트 다시 입력하기).

잘 안 될 때

  • "여기에 그려진 표시 중인 레이어가 없습니다"라고 표시됩니다: 숨긴 레이어, 마스크로 가려진 곳, 불투명도 0%인 그림은 선택되지 않습니다. 레이어 패널에서 선택한 뒤 "레이어 자동 선택"을 끄고 움직입니다.
  • 다른 레이어가 움직입니다: 겹쳐 있으면 가장 위의 레이어가 선택됩니다. 움직이려는 레이어를 선택하고 "레이어 자동 선택"을 끕니다.

크기·방향 바꾸기(변형)

선택 범위 안이나 레이어 전체의 그림에, 크기와 방향을 바꾸는 틀을 표시합니다. 틀은 3D 뷰의 모델 위와 UV 뷰 양쪽에 나타납니다.

  1. 바꾸려는 곳을 선택 범위로 둘러쌉니다(레이어 전체라면 필요 없습니다).
  2. 편집 → "변형 (3D·UV 위에서)"(Ctrl+T)를 선택합니다. 틀이 나타납니다.
  3. 틀 안을 드래그해 이동하고, 모서리로 확대·축소하고, 위쪽 원으로 회전합니다.
  4. Enter로 확정합니다. 취소할 때는 Esc를 누릅니다.

틀 조작

조작결과
틀 안을 드래그이동합니다
모서리를 드래그확대·축소합니다(Shift를 누르면 가로세로 비율을 바꿀 수 있습니다)
변을 드래그한쪽 방향으로만 늘어나거나 줄어듭니다
위쪽 원을 드래그회전합니다(Shift를 누르면 15° 단위)
변·모서리를 반대쪽을 넘어서까지 끌기뒤집힙니다
틀 아래의 바좌우 반전, 상하 반전, 불투명도, 틀의 모양(자유 변형·워프)
  • 3D와 UV 중 어느 쪽 틀을 잡아도 똑같이 움직이고, 다른 쪽도 따라옵니다. 움직이는 그림이 3D에서 보이면 UV 뷰를 열지 않고 3D만으로 조작할 수 있습니다. 보이지 않으면 UV 뷰가 열리고, 끝내면 닫힙니다.
  • 3D 틀 위에서도 오른쪽 드래그, 가운데 드래그, 휠, Space+드래그로 시점을 움직일 수 있습니다. 시점을 바꿔도 틀은 따라옵니다.
  • 3D 틀은 틀 한가운데에 있는 면에 맞춰 표시됩니다. UV의 이음매에 걸칠 때는 가운데에 있는 아일랜드에 맞춥니다.
  • UV 뷰에 그리드 선을 표시하고 있으면 틀이 칸에 스냅됩니다(그리드 선과 스냅).
  • 선택 범위도 함께 움직입니다.

반대쪽도 함께 움직이기(대칭으로도)

그리기 대칭이 켜져 있고 선택 범위가 한쪽에 있을 때는, 틀 아래 바에 "대칭에도"가 표시됩니다. 켠 채로 움직이면 3D의 반대쪽도 거울에 비친 것처럼 함께 움직입니다. 반대쪽의 원래 그림은 대체됩니다.

  • 이동·변형 도구에서도 같습니다.
  • 양쪽을 모두 선택했을 때, 선택 범위가 중심에 걸쳐 있을 때, 선택 범위가 없을 때는 표시되지 않습니다.
  • 대칭을 켜는 방법은 좌우 대칭으로 그리기를 보세요.

원근 주기·구부리기(자유 변형·워프)

틀 아래 바의 아이콘 3개로 틀의 모양을 전환합니다. 변형, 이동·변형 도구, 이미지 추가, 붙여넣기, 이미지를 3D/UV에 붙이기에서 사용할 수 있습니다(텍스트 틀에는 표시되지 않습니다).

틀의 모양조작
확대·축소·회전모서리로 크기, 위쪽 원으로 회전, 안쪽 드래그로 이동(틀 조작)
자유 변형네 모서리를 각각 드래그해 모양을 바꿉니다. 원근을 준 것처럼 그림이 변형됩니다. 모서리는 반대쪽을 넘지 않으며, 오목한 모양도 되지 않습니다
워프격자의 점을 드래그해 그림을 구부립니다. 격자는 3×3이며, 바에서 4×4·5×5로도 바꿀 수 있습니다
  • 자유 변형·워프도 위쪽 원이나 모서리의 조금 바깥쪽을 드래그해서 회전할 수 있습니다(Shift를 누르면 15° 단위). 안쪽을 드래그하면 전체가 이동합니다.
  • 확대·축소·회전 → 자유 변형 → 워프로 전환해도 모양은 그대로입니다. 확대·축소·회전으로 되돌리면 현재 모양을 그림에 그려 넣고, 그 바깥쪽의 사각형 틀이 됩니다.
  • 좌우 반전, 상하 반전, 불투명도도 사용할 수 있습니다. 확정은 실행 취소 1회분입니다(선택 범위를 움직였을 때도 마찬가지).
  • 3D에 붙일 때는 화면에서 구부린 모양을 보이는 면에 투영합니다.

복사·잘라내기·붙여넣기

선택 범위 안(없으면 레이어 전체)의 그림을 복사하거나 잘라내서 붙여넣습니다. 붙여넣은 그림은 새 레이어에 들어갑니다.

조작키동작
편집 → "복사 (선택 범위 안)"Ctrl+C선택한 레이어의 그림을 복사합니다
편집 → "잘라내기 (선택 범위 안)"Ctrl+X복사하고 원래 그림을 지웁니다
편집 → "붙여넣기"Ctrl+V같은 UV 위치에 새 레이어로 붙여넣습니다. 그대로 틀로 움직일 수 있습니다
선택 범위 → "선택 범위를 복사하여 새 레이어로", "선택 범위를 잘라내어 새 레이어로"—틀을 표시하지 않고 바로 같은 위치의 새 레이어에 넣습니다
  • 레이어를 여러 장 선택하고 있어도 대상은 선택 중인 1장뿐입니다.
  • 다른 앱에서 복사한 이미지를 Ctrl+V로 붙여넣으면 틀을 맞춰 붙일 수 있습니다(이미지 추가).

잘 안 될 때

  • 잘라내기·지우기가 되지 않습니다: 잠김·숨김·투명 픽셀 잠금 상태의 레이어는 잘라내기·지우기를 하지 않습니다(이유가 아래에 표시됩니다). 복사는 할 수 있습니다.
  • 새 레이어를 만들 수 없습니다(Lite): Lite는 텍스처 세트마다 바탕을 포함해 레이어 4장까지입니다(에디션).

이미지 붙이기

로고나 무늬 이미지를 틀로 크기와 위치를 맞춰 붙입니다. 붙이는 방법은 3가지입니다.

붙이는 방법시작 방법틀이 나타나는 곳
이미지 추가파일 → 가져오기 → "이미지를 레이어로 가져오기", 이미지를 창에 끌어다 놓기, 다른 앱에서 복사한 이미지를 Ctrl+VUV 뷰가 열려 있으면 UV 위, 닫혀 있으면 3D의 한가운데(보이는 면에 투영)
이미지를 3D에 붙이기편집 → "이미지를 3D에 붙이기"3D 뷰(보이는 면에 투영)
이미지를 UV에 붙이기편집 → "이미지를 UV에 붙이기"UV 뷰
  1. 이미지를 창에 끌어다 놓습니다. 이미지를 놓을 틀이 나타납니다.
  2. 틀을 움직여 크기와 위치를 맞춥니다. 시점을 움직이면서 맞춰도 됩니다.
  3. Enter로 확정합니다. 파일 이름의 새 레이어에 들어갑니다.

틀 아래의 바

  • 가로세로 비율은 그대로 두고, 보이는 곳에 들어가는 크기로 놓습니다. 투명한 부분은 투명한 채로 남습니다.
  • Esc로 취소하면 아무것도 남지 않습니다. 확정한 뒤에는 실행 취소 1회로 사라집니다.
  • "텍스처 전체에 붙이기"(이미지 추가일 때): UV 전체로 늘려서 새 레이어에 넣습니다. UV 크기로 그린 이미지에 사용합니다.
  • "새 레이어에"(3D에 붙일 때. 처음에는 켜져 있음): 붙인 텍스처 세트마다 새 레이어를 만듭니다. 끄면 현재 레이어에 붙입니다.
  • "비스듬한 면도 진하게": 옆을 향한 면에서도 흐려지지 않게 붙입니다.
  • 좌우 반전, 상하 반전, 불투명도와 틀의 모양(자유 변형·워프)도 사용할 수 있습니다.
  • 좌우 대칭과 선택 범위도 적용됩니다.

텍스트 넣기

모델 위에서 그 자리에서 텍스트를 입력해 붙입니다. 글꼴·크기·색은 글자마다 바꿀 수도 있습니다.

  1. "텍스트" 도구(T)를 선택합니다. 보조 도구에서 "가로쓰기"나 "세로쓰기"를 고릅니다.
  2. 3D 뷰(또는 UV 뷰)를 누릅니다. 틀과 텍스트 창이 나타납니다(편집 → "텍스트 넣기"로도 시작할 수 있습니다).
  3. 그대로 입력합니다. 일본어 입력도 사용할 수 있으며, 변환 후보는 글자 옆에 표시됩니다.
  4. Ctrl+Enter로 확정합니다(입력하는 동안의 Enter는 줄바꿈입니다).

텍스트 창

  • 글꼴·크기·색·굵게·기울임꼴·세로쓰기·행간·자간·정렬·테두리를 정합니다.
  • 텍스트 창을 열어 둔 동안은 색 패널의 전경색이 글자 색, 배경색이 테두리 색이 됩니다. 창의 색 사각형을 눌러서 골라도 됩니다.
  • 제목 줄의 "슬라이더로 조절"을 켜면 크기·테두리·행간·자간을 슬라이더로도 움직일 수 있습니다.
  • 글꼴 목록의 아래쪽에 "이 PC의 글꼴"로 PC에 설치된 글꼴이 모두 나열됩니다.
  • "글꼴 불러오기"로 글꼴 파일(.ttf·.otf)도 사용할 수 있습니다(그 실행 동안만).
  • 창이 틀과 겹칠 때는 창의 제목 줄("텍스트")을 잡고 움직일 수 있습니다. 위치는 다음에도 그대로입니다.
  • UV 뷰를 눌러 시작하면 UV 위에 붙입니다.

입력하는 동안의 조작

조작동작
틀 안을 누르기(더블클릭도 가능)누른 곳부터 입력합니다
← → ↑ ↓, Home, End입력 위치를 움직입니다(세로쓰기는 ↑ ↓로 글자의 앞뒤, ←로 다음 줄)
Shift+화살표, 틀 안에서 드래그글자를 선택합니다
Backspace, Delete글자를 지웁니다
Ctrl+드래그틀을 움직입니다(모서리·변·위쪽 원은 평소와 같습니다)
Esc첫 번째로 누르면 입력을 멈춥니다(틀은 남고, 드래그로 움직입니다). 두 번째로 누르면 텍스트를 취소합니다
입력하는 동안은 키 단축키(E로 지우개 등)가 작동하지 않습니다. 시작했을 때는 모든 글자가 선택되어 있으므로, 입력하면 대체됩니다.

글자마다 색이나 크기 바꾸기

  • 글자를 선택한 뒤 색(전경색·배경색)·크기·글꼴·굵게·기울임꼴·자간·테두리를 바꾸면 그 글자만 바뀝니다.
  • 선택하지 않고 바꾸면 이제부터 입력할 글자에 적용됩니다. 입력하고 있지 않을 때(Esc를 누른 뒤 등)는 모든 글자가 바뀝니다.
  • 어느 글자가 바뀌는지는 텍스트 창의 "색과 크기를 바꾸면:"에 표시됩니다.
  • 행간·정렬·세로쓰기는 모든 글자에 적용됩니다. 크기가 다른 글자는 아래쪽 선을 맞춰 나열됩니다.

텍스트 다시 입력하기(텍스트 레이어)

"새 레이어에"를 켠 채 붙인 텍스트는 텍스트 레이어가 되어, 레이어 목록에 "T" 표시가 붙습니다. UV에 붙인 텍스트는 항상 텍스트 레이어입니다. 나중에 글자·글꼴·색 등을 바꿔 다시 붙일 수 있습니다.

  1. 레이어 목록에서 텍스트 레이어를 더블클릭합니다(우클릭 → "텍스트 다시 입력"으로도 가능합니다).
  2. 텍스트 창과 틀이 붙였을 때의 상태로 열립니다. 글자별 색과 크기도 그대로입니다.
  3. 수정한 뒤 Ctrl+Enter로 다시 그립니다. 실행 취소로 되돌릴 수 있습니다.
  • 텍스트 도구로 글자 위를 누르거나, 도구 속성의 "선택한 텍스트 레이어를 다시 입력"으로도 시작할 수 있습니다.
  • 3D에 붙인 텍스트는 붙였을 때의 시점으로 되돌린 뒤 틀을 표시합니다. 끝내면 원래 시점으로 돌아갑니다.
  • 이름을 바꾸려면 우클릭 → "이름 바꾸기"를 선택합니다.
  • 우클릭 → "래스터화 (다시 입력할 수 없게 됨)"로 일반 레이어로 만듭니다.
  • 작업 파일에 들어가므로, 다시 열어도 다시 입력할 수 있습니다. PSD에는 일반 레이어로 기록합니다.

잘 안 될 때

  • 키를 눌러도 도구가 바뀌지 않습니다: 텍스트를 입력하는 동안은 단축키가 작동하지 않습니다. Esc를 눌러 입력을 멈춥니다.
  • 다시 입력했더니 덧그린 부분이 사라졌습니다: 텍스트 레이어에 덧그리면 표시가 "T+"로 바뀝니다. 다시 입력하면 덧그린 부분이 사라지므로, Ctrl+Z로 되돌리고 덧그린 부분을 다른 레이어로 나눈 뒤 다시 입력합니다.
  • "글꼴을 찾을 수 없습니다"라고 표시됩니다: 불러온 글꼴은 그 실행 동안만 사용할 수 있습니다. 다른 글꼴로 다시 입력되므로, 원래 글꼴로 하려면 "글꼴 불러오기"로 다시 불러옵니다.
  • 다시 입력할 수 없습니다: "새 레이어에"를 끄고 현재 레이어에 붙인 텍스트와 래스터화한 텍스트는 일반 그림입니다.

자로 선 맞추기

그리는 선을 자에 달라붙게 해서 곧은 선이나 중심을 향하는 선을 긋습니다. 3D 뷰에서도 UV 뷰에서도 사용할 수 있습니다.

  1. "자" 도구를 선택하고, 보조 도구에서 자의 종류를 고릅니다.
  2. 3D 뷰나 UV 뷰에서 자를 만듭니다(만드는 방법은 아래 표).
  3. 펜 등으로 도구를 바꿔 그립니다. 선이 자를 따라갑니다.
보조 도구만드는 방법적용되는 선
직선 자드래그가까운 곳(달라붙는 거리 안)에서 그리기 시작한 선이 직선이 됩니다
곡선 자점을 찍고, Enter나 더블클릭으로 끝냅니다(Esc로 취소)가까운 곳에서 그리기 시작한 선이 곡선을 따릅니다
동심원 자누른 곳이 중심어디서 그려도 중심에서의 거리를 유지한 원이 됩니다
방사선 자누른 곳이 중심어디서 그려도 중심을 향하는 선이 됩니다
평행선 자드래그로 방향을 정합니다어디서 그려도 그 방향의 선이 됩니다

자 옮기기·끄기·지우기

  • 자의 동그라미(끝·중심·점)는 드래그로 움직일 수 있습니다. 달라붙는 거리는 도구 속성에서 정합니다.
  • 3D 뷰의 자는 시점을 움직여도 화면에 남습니다. UV 뷰에도 따로 둘 수 있습니다.
  • 자가 있을 때는 그 영역 아래 가운데에 띠가 나타납니다(자의 종류·"달라붙기" 켜기/끄기·"지우기"). "지우기"는 그 영역의 자만 지웁니다.
  • 표시 → 선과 자 → "자에 붙이기"(Ctrl+Alt+R)로 전환합니다. 같은 곳의 "자 지우기"로 지웁니다.
  • 곡선 자의 점을 찍는 도중에는 Ctrl+Z로 마지막 점을 하나 되돌릴 수 있습니다. Ctrl+Y나 Ctrl+Shift+Z로 다시 실행합니다.

잘 안 될 때

  • 선이 제멋대로 곧아지거나 휘어집니다: 자가 남아 있습니다. 아래 띠의 "달라붙기"를 끄거나 "지우기"로 지웁니다(Ctrl+Alt+R로도 끌 수 있습니다).
  • 직선 자·곡선 자를 따라가지 않습니다: 자 가까이에서 그리기 시작한 선에만 적용됩니다. 도구 속성에서 달라붙는 거리를 넓힙니다.
