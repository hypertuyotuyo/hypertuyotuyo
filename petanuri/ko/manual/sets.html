텍스처 세트와 오브젝트

머티리얼별로 '텍스처 세트'가 생성됩니다. 각 세트에 레이어와 해상도가 있습니다. 모델 오브젝트(메시)별로 숨길 수도 있습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

Lite·Standard·Pro와 Pro 업그레이드를 BOOTH에서 배포하고 있습니다.

이 페이지에서 “v1.2.0:”로 시작하는 설명은 공개 전 안내입니다. 현재 배포 버전은 v1.1.2입니다.

이 페이지의 내용
  • 텍스처 세트 선택
  • 메인과 서브(두 세트에 걸쳐 그리기)
  • 바탕 이미지 교체·이미지나 PSD 추가
  • 오브젝트 표시·숨김
  • 메모리 절약
  • 대상이 없는 세트(! 표시)

텍스처 세트 선택

  • 3D 뷰에서 다른 세트 위에서 그리기 시작하면 해당 세트로 자동 전환한 후 그립니다 . 펜 옆에 세트 이름이 표시됩니다.
  • 쉬는 세트는 깨우는 동안 '텍스처 세트 변경 중…'이 표시됩니다. 그동안의 펜 움직임을 기억하고 깨어나면 그대로 그리므로 선이 빠지지 않습니다.
  • 자동 전환을 중지하려면 3D 뷰 왼쪽 아래 '터치한 곳으로 전환'을 끕니다(우클릭 메뉴에도 있음).
  • 수동 선택도 가능합니다: 패널 행 누르기·모델 위에서 Alt+ 우클릭·우클릭 '이 세트 선택'. 다시 선택하면 해당 세트가 3D에서 잠시 색으로 강조됩니다.
  • 체크로 세트 표시 여부를 바꾸고 오른쪽에서 해상도(32~4096, Lite는 최대 2048)를 선택합니다. 해상도를 변경하면 실행 취소 기록이 사라지므로 변경 전에 확인합니다.
  • 세트를 다시 선택해도 실행 취소·다시 실행을 이어서 사용할 수 있습니다.
스탬프용 2D 캔버스는 작업용 특수 세트입니다. 모델 목록에 섞지 않으며 편집 중에는 패널에 표시합니다. 모델 메인·서브와 별도로 편집하고 작업 파일에는 함께 저장합니다(스탬프용 2D 캔버스).
픽셀 아트용으로 32/64/128/256px도 선택할 수 있습니다. 낮은 해상도에서도 일반 레이어·저장·PNG 출력을 사용할 수 있습니다. 해상도 변경 전에 작업 파일을 저장하세요.
VRM의 투명 부분은 원본 이미지의 투명도와 재질의 투명 설정을 유지합니다. 같은 이미지라도 투명 설정이 다른 재질은 별도 세트가 됩니다. 그리기와 지우기로 수정한 투명도는 작업 파일에 저장됩니다.

메인과 서브(두 세트에 걸쳐 그리기)

  • 깨어 있어 그릴 수 있는 세트는 선택한 세트(메인)와 바로 전에 선택한 세트(서브) 두 개입니다. 3D 뷰 왼쪽 아래에 이름이 표시됩니다(서브를 누르면 메인과 교체). 패널에서 메인 행은 분홍색, 서브 행은 파란색입니다.
  • 이 두 세트에 한 번의 선으로 걸쳐 그릴 수 있습니다. 목 이음매처럼 얼굴과 몸 경계를 넘어 칠하려면 두 세트를 각각 한 번 누른 후 그립니다. 실행 취소 한 번으로 둘 다 되돌립니다.
  • 걸쳐 그리지 않고 시작한 세트에만 그리려면 왼쪽 아래 '걸쳐 그리기'를 끕니다(우클릭 메뉴에도 같은 전환 있음).
UV 영역에서는 메인 세트에만 그립니다. 오른쪽 아래 서브 UV가 작게 표시됩니다(누르면 서브가 메인이 됨).
텍스처 세트 패널에서 서브 행의 “서브” 표시 오른쪽 ×를 누르면 함께 그리는 세트(서브)를 뺄 수 있습니다(서브 행의 오른쪽 클릭으로도).

바탕 이미지 교체·이미지나 PSD 추가

텍스처 세트 패널 행의 우클릭 또는 행 오른쪽 '…'에서:

  • 바탕 이미지 교체: 해당 세트 바탕 레이어 그림을 선택한 이미지(PNG·JPEG·WebP·BMP·GIF·TGA)로 교체합니다. 크기가 다르면 해상도에 맞춥니다.
  • 이미지를 레이어로 가져오기: 선택한 이미지를 해당 세트 UV 위에 놓는 틀을 표시합니다(Enter 로 새 레이어에).
  • PSD 가져오기(레이어 교체): 해당 세트 레이어를 PSD 레이어로 교체합니다(Standard).
  • lilToon 머티리얼 불러오기: .mat·.unitypackage를 해당 세트에 가져옵니다(Pro).
  • 이미지·PSD·.mat를 행 위에 드롭해도 가져옵니다. 선택하지 않은 세트에도 가져올 수 있습니다. 모두 실행 취소할 수 있습니다.

오브젝트 표시·숨김

오른쪽 '오브젝트' 패널에 모델 오브젝트(머리카락·옷·소품 등의 메시)가 원래 계층의 들여쓰기로 표시됩니다. 각 행에 눈 버튼·이름·사용하는 텍스처 세트 표시가 있습니다.

  • 눈 버튼으로 숨기기·표시.Alt+ 누르면 '이것만 표시', 다시 누르면 전체 표시. 3D 우클릭에도 '이 오브젝트 숨기기'·'이 오브젝트만 표시'가 있습니다.
  • 이름을 누르면 오브젝트가 3D에서 잠시 강조됩니다. 세트 표시를 누르면 해당 텍스처 세트를 선택합니다.
  • 숨긴 오브젝트는 3D에 표시되지 않고 히트 판정·채색도 되지 않습니다(뒷면·가려진 면에도 칠하기·대칭 쪽·채우기·그라데이션도 동일). 안쪽 물체가 그대로 보여 칠할 수 있습니다.
  • 텍스처(레이어)는 유지되며 PNG·PSD·머티리얼 내보내기도 바뀌지 않습니다. 숨김 상태는 작업 파일에 저장됩니다. 전체 표시는 Alt＋H 입니다.
v1.2.0: 표시 프리셋(모든 버전): 패널 아래의 “현재 상태 저장”으로 숨긴 오브젝트(Pro에서는 셰이프 키 값도)를 묶어 이름을 붙여 기억합니다. “불러오기”로 그 상태로(실행 취소 한 번으로 되돌립니다)·“덮어쓰기”·이름 칸에서 이름 바꾸기·×로 지우기. 10개까지. 작업 파일에 들어갑니다.

메모리 절약

  • 선택하지 않은 세트는 모습이 유지된 채 GPU 메모리를 비워 쉬게 합니다.
  • 다시 선택하면 2048은 약 0.2초, 4096은 약 0.5~1.5초 후 그릴 수 있습니다.
  • 저장·내보내기·AO·모든 세트에 적용하는 필터는 쉬는 세트에도 그대로 적용됩니다.

대상이 없는 세트(! 표시)

모델을 다시 불러옴때 새 모델에 없는 머티리얼의 세트는 삭제하지 않고 ! 표시를 붙여 유지합니다.

  1. !가 있는 세트를 누릅니다.
  2. 이동할 레이어(기본은 전체)와 대상 세트를 선택하고 '옮기기'를 누릅니다.
  3. 대상 세트 레이어 맨 위에 같은 순서로 들어갑니다. '원래 세트에도 유지'는 복사만 합니다.
! 세트는 3D에 표시되지 않으며 그릴 수 없습니다. 내보내기와 AO에도 포함되지 않습니다. '이 세트 삭제'로 삭제할 수 있습니다.
