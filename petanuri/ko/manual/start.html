PetaNuri3D / 매뉴얼 / 시작 방법

시작 방법

PetaNuri3D를 설치하고 실행해 3D 모델을 열고, 칠한 작업을 저장하기까지의 과정입니다. 에디션(Lite·Standard·Pro)의 차이와 새 버전으로의 업데이트도 여기에 정리했습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

먼저 이것만
  1. ZIP의 압축을 모두 푼 뒤, "PetaNuri3D" 폴더의 setup.exe로 설치하거나 PetaNuri3D-win_x64.exe를 그대로 실행합니다(자세히).
  2. 처음이라면 시작 화면의 "샘플로 해 보기"로 연습용 모델을 열 수 있습니다(자세히).
  3. 내 모델은 "새로 만들기"에서 선택하고, 텍스처 세트마다 해상도와 시작 방식을 정합니다(자세히).
  4. 칠한 뒤에는 Ctrl+S로 작업 파일(.petanuri)에 저장합니다. 5분마다 자동 저장도 됩니다(자세히).
  5. 텍스처 이미지로 만드는 것은 "내보내기"입니다(내보내기).

실행 환경

Windows PC에서 작동합니다. VRChat이 실행되는 PC라면 대체로 작동합니다.

항목필요한 사양권장(기준)
OSWindows 11(64bit)—
GPUWebGL2를 사용할 수 있을 것(최근 몇 년 사이의 NVIDIA·AMD·Intel GPU와 최신 드라이버)GPU 메모리: 해상도 2048로 칠한다면 4GB 이상, 4096이라면 8GB 이상
기타Microsoft Edge WebView2 런타임(Windows 11에는 처음부터 설치되어 있습니다)PC 메모리 16GB 이상
  • Windows 10에서도 작동하지만 지원 대상은 아닙니다.
  • 현재 GPU 메모리 추정치는 텍스처 세트 패널 위쪽에 표시됩니다.

잘 안 될 때

  • 느림·그려지지 않게 됨: GPU 메모리가 부족합니다. 텍스처의 해상도를 낮추거나, 브라우저나 게임 등 다른 앱을 닫으세요(메모리 절약).

설치·실행하기

BOOTH에서 다운로드한 ZIP(PetaNuri3D-<에디션>-v<버전>.zip)의 압축을 먼저 모두 풉니다. "PetaNuri3D" 폴더에 본체와 setup.exe가 들어 있습니다. 사용 방법은 두 가지입니다.

setup.exe로 설치하기(권장)

  1. "PetaNuri3D" 폴더의 setup.exe를 더블클릭합니다.
  2. 설치 위치, 바탕 화면 아이콘, 작업 파일(.petanuri)을 더블클릭으로 열지 여부를 선택해 설치합니다. 관리자 권한은 필요 없습니다(현재 사용자에게만 설치됩니다).
  3. 시작 메뉴(와 바탕 화면)에서 실행합니다.
setup.exe는 같은 폴더의 본체를 설치합니다. setup.exe만 따로 꺼내지 말고 폴더째로 사용하세요. 설치 위치는 %LOCALAPPDATA%\Programs\PetaNuri3D입니다.

설치하지 않고 실행하기

  1. "PetaNuri3D" 폴더를 원하는 위치에 둡니다.
  2. 폴더 안의 PetaNuri3D-win_x64.exe를 더블클릭합니다.
exe 옆의 resources.neu·mcp·tools·unity도 사용합니다. 옮길 때는 폴더째로 옮기세요. 새 버전은 새 폴더에 압축을 풀어 사용합니다.

실행하면

가운데에 "새로 만들기"·"작업 파일 열기"·"샘플로 해 보기"가 표시되면 준비 완료입니다. 최근 사용한 파일과 자동 저장도 여기서 열 수 있습니다.

  • 3D 모델(FBX 등)이나 작업 파일(.petanuri)을 시작 화면 가운데의 입구에 끌어다 놓아도 시작할 수 있습니다. 3D 모델은 새로 만들기 화면으로 넘어가고, 작업 파일은 바로 열립니다.
  • 설정(보조 도구·키 할당·창 배치·컬러 세트·참고 이미지 등)은 %APPDATA%\PetaNuri3D에 저장되며, 다음 실행 때 복원됩니다.
  • 사용을 그만둘 때는 Windows의 "설정 → 앱 → 설치된 앱"에서 "PetaNuri3D"를 제거합니다. 설정과 작업 파일은 삭제되지 않습니다.

잘 안 될 때

  • "Windows의 PC 보호" 창이 나타남: "추가 정보" → "실행"을 누릅니다. 서명이 없는 앱이어서 처음에 나타날 수 있습니다.
  • 설치 위치를 바꿨더니 Unity 연동이 작동하지 않음: Unity 애드온이 기억하고 있는 exe의 위치를 한 번 다시 지정하세요(Unity에서 칠하기).

튜토리얼과 샘플 모델

처음 실행하면 조작 안내(튜토리얼)가 표시됩니다. 빛나는 곳을 실제로 만져 보며 진행합니다.

  • ← →로 앞뒤로 이동하고, "건너뛰기" 또는 Esc로 그만둘 수 있습니다.
  • 모델을 열지 않았을 때는 "샘플 모델로 해 보기" 또는 "내 모델로 (나중에 열기)"를 선택할 수 있습니다. 샘플이라면 회전, 그리기, 좌우 대칭, UV를 차례로 체험할 수 있습니다.
  • 다시 보려면 도움말 → "튜토리얼 (조작 안내)". 파일 → 환경 설정 → 시스템의 "다음 실행 시 튜토리얼 보기"로도 표시할 수 있습니다.

샘플 모델 "시노부"

시작 화면의 "샘플로 해 보기"로 열 수 있습니다. 어느 에디션에서나 사용할 수 있습니다. A 포즈이며 텍스처 세트가 7개 있고, 각 세트의 바탕에 원래 색의 이미지가 들어 있습니다.

샘플 모델은 PetaNuri3D를 사용해 보는 용도로만 사용할 수 있습니다. 다른 용도로 사용하거나 추출해서 배포하지 마세요.

처음이라면 처음 사용하는 분께에서 샘플을 한 번 칠해 보기를 추천합니다. 모델 없이 그릴 때는 시작 화면의 "2D 페인트로 그리기"에서 시작합니다(2D 페인트).

3D 모델 열기(새로 만들기)

내 3D 모델을 열고 칠할 준비를 합니다. 열 수 있는 형식은 FBX·glTF(파일 하나로 합친 것)·GLB·VRM·OBJ·DAE입니다.

  1. 시작 화면의 "새로 만들기" 또는 파일 → 새로 만들기(Ctrl+N)를 눌러 3D 모델을 선택합니다.
  2. 머티리얼별 텍스처 세트가 나열됩니다. 세트마다 해상도(32~4096px. Lite는 2048까지)를 선택합니다.
  3. 세트마다 시작(바탕)을 선택합니다. 서로 다른 시작을 섞어도 됩니다.
  4. "새로 만들기"를 누르면 3D 뷰에 모델이 표시됩니다. 그만두려면 "취소" 또는 Esc를 누릅니다.

시작(바탕)의 종류

시작내용
색바탕을 한 가지 색으로 칠하고 시작합니다. 기본은 흰색입니다. "모델 색"으로 머티리얼의 색으로 할 수도 있습니다.
이미지PNG·JPEG 등을 바탕으로 사용합니다.
PSD StandardPSD 레이어를 그대로 가져옵니다.
lilToon 머티리얼 Pro.mat 또는 그것이 들어 있는 .unitypackage에서 설정·텍스처·마스크를 불러옵니다(lilToon 머티리얼 불러오기).
  • 모델이 사용하는 이미지가 모델 옆(같은 폴더나 Texture 폴더)이나 모델 안에 있으면 자동으로 찾아서 "이미지"로 시작합니다.
  • 위쪽의 "일괄"에서 모든 세트의 해상도 맞추기, 모든 세트를 흰색 바탕으로 시작하기, 이미지나 PSD를 한꺼번에 선택하기를 할 수 있습니다. 파일 이름이 세트 이름과 같은 것(body.psd → body)은 그 세트에 들어갑니다. 이 화면에 이미지·PSD·.mat을 끌어다 놓아도 알아서 나누어 줍니다.
  • 같은 이미지를 사용하는 머티리얼은 하나의 텍스처 세트로 합쳐집니다(행의 "합치기 ▾"에서 직접 합치거나 해제할 수도 있습니다). 합치면 한 장의 텍스처에 그려서 모든 머티리얼에 반영됩니다.
  • Pro "생성 후 간편 베이크 열기"를 켜고 대상 세트를 선택하면, 연 뒤에 간편 베이크 창이 나타나 피부나 옷의 밑칠을 만든 다음 그려 넣을 수 있습니다(간편 베이크).

잘 안 될 때

  • 모델을 창에 끌어다 놓아도 열리지 않음: 모델을 연 뒤에는 끌어다 놓아도 열리지 않습니다. 파일 → 새로 만들기 또는 파일 → 모델 다시 불러오기에서 여세요.
  • "텍스처를 찾을 수 없다"고 표시됨: 행의 "○○ 선택"에서 이미지를 선택합니다.
  • 칠할 수 없는 곳이 있음: UV가 없는 면 등 칠할 수 없는 곳이 있는 모델은 열 때 오른쪽 아래에 알려 줍니다. UV가 0~1 바깥에 있는 곳은 반복했을 때 같은 색이 되는 위치에 칠합니다.

저장·이어 열기

작업은 작업 파일(.petanuri)에 저장합니다. 모델과 모든 레이어·설정이 하나의 파일에 들어갑니다. 텍스처 이미지(PNG·PSD)로 만드는 것은 별도의 "내보내기"입니다.

하고 싶은 일조작
저장하기파일 → 작업 파일 저장(Ctrl+S)
다른 이름으로 저장하기파일 → 다른 이름으로 저장(Ctrl+Shift+S)
이어서 열기파일 → 작업 파일 열기(Ctrl+O). 창에 끌어다 놓아도 열 수 있습니다
최근 작업 열기파일 → 최근 사용한 파일
앱이 종료된 뒤에 복구하기파일 → 자동 저장에서 열기(작업별로 최신 3개까지)
모델을 빼고 전달하기파일 → 모델(FBX) 없이 저장(열 때 가지고 있는 모델을 선택합니다)
  • 제목의 "*"는 저장하지 않은 변경이 있다는 표시입니다. 변경이 있는 채로 닫으면 "저장하고 종료/저장하지 않고 종료/취소"를 묻습니다.
  • 5분마다 자동 저장합니다.
  • 메뉴 바 오른쪽의 아이콘으로도 새로 만들기·열기·저장·실행 취소·다시 실행을 할 수 있습니다.

빠른 형식으로 저장하기

자동 저장은 레이어의 투명한 부분을 쓰지 않는 "빠른 형식"으로 저장합니다. 선만 있는 레이어가 많으면 훨씬 빠르게 저장됩니다. 직접 저장하는 작업 파일도 파일 → 환경 설정 → 그리기 → 성능에서 "작업 파일을 빠른 형식으로 저장(v1.2.0 이후에서 열 수 있음)"을 켜면 같은 형식이 됩니다.

잘 안 될 때

  • 앱이 종료되었음·멈췄음: ×를 한 번 더 누르면 종료됩니다(저장하지 않은 변경은 남지 않습니다). 다시 실행해서 파일 → 자동 저장에서 열기로 직전의 자동 저장을 엽니다.
  • "앱 내부의 읽기·쓰기가 멈췄습니다"라고 표시됨: 절전 상태에서 돌아온 뒤 등에 일어납니다. 일단 종료했다가 다시 실행해서 파일 → 자동 저장에서 열기로 복구하세요.
  • 이름에 （欠けあり）가 붙은 채 열림: 일부를 읽지 못한 작업 파일입니다. 원본 파일을 덮어쓰지 않도록 저장은 "다른 이름으로 저장"이 됩니다.
  • 저장 창이 응답하지 않음: 저장 위치를 선택하는 창이 다른 창 뒤에 숨어 있지 않은지 확인하세요. 30초보다 길게 이어지면 ×나 Ctrl+S로 "기다리기/이전 저장을 멈추고 계속"을 선택할 수 있습니다.
  • 미리 보기 중에 저장했더니 확인이 나타남: 변형·필터 등의 미리 보기 중에는 먼저 "적용 후 계속/미리보기 취소 후 계속/취소"를 묻습니다.

모델 다시 불러오기

3D 모델(FBX 등)을 수정했을 때, 그린 내용은 그대로 두고 형태만 새로 바꿉니다.

  1. 파일 → 모델 다시 불러오기(그린 것 유지)를 선택합니다.
  2. "같은 파일 다시 불러오기" 또는 "파일 선택"을 누릅니다.
  3. 텍스처 세트는 머티리얼 이름으로 맞춥니다. 같은 이름의 세트는 레이어도 설정도 그대로 남습니다.

다시 불러올 때 묻는 내용

이럴 때표시되는 확인과 선택 방법
UV가 바뀐 세트가 있음"그림을 맞춰서 업데이트"=그린 그림을 새 UV 위치로 옮김/"맞추지 않고 업데이트"=그림은 이전 UV 위치 그대로/"업데이트 취소"=다시 불러오기를 취소
새 머티리얼이 늘어남새로 만들기와 같은 화면이 새 세트의 행만 표시됩니다. 해상도와 시작 방식을 정하고 "불러오기"를 누릅니다
모델의 텍스처(이미지)가 바뀜"바탕을 새 텍스처로 바꿀까요?"라고 세트마다 묻습니다. 바꾸면 바탕에 직접 그린 내용도 교체됩니다
새 모델에 없는 머티리얼이 있음그 세트는 삭제되지 않고 ! 표시로 남습니다. 누르면 레이어를 다른 세트로 옮길 수 있습니다(대상이 없는 세트)
다시 불러오기는 Ctrl+Z 한 번으로 되돌릴 수 있습니다(이전 모델의 내용이 남아 있을 때). 단, 다시 불러오기 전의 조작 기록은 사라집니다.

에디션(Lite·Standard·Pro)

PetaNuri3D에는 3가지 에디션이 있습니다. 현재 에디션은 창 제목, 시작 화면의 표시, 도움말 → "PetaNuri3D 정보"에서 알 수 있습니다. 이 매뉴얼에서는 Standard 이상의 기능에 Standard, Pro 전용 기능에 Pro 표시를 붙였습니다. 표시가 없는 기능은 Lite부터 사용할 수 있습니다.

  • Lite에서 사용할 수 없는 기능은 메뉴나 버튼이 흐리게 표시되고 작은 자물쇠 표시가 붙습니다. 누르면 어느 에디션에서 사용할 수 있는지 표시됩니다.
  • Standard에서는 Pro 전용 기능의 진입 항목이 표시되지 않습니다(도움말 → "Pro로 업그레이드"는 표시됩니다).
  • 워터마크는 들어가지 않습니다. 텍스처 세트 수에 제한은 없습니다.
  • 어느 에디션에서 만든 작업 파일이든 열 수 있습니다. 제한을 넘는 레이어나 그 에디션에서 사용할 수 없는 기능의 설정도 삭제하지 않고 보관하며, 저장해도 남습니다.
  • 가격과 구입 방법은 소개 페이지의 가격을 참고하세요. Lite·Standard·Pro와 Pro 업그레이드를 BOOTH에서 배포하고 있습니다.

잘 안 될 때

  • 레이어를 추가할 수 없음(Lite): Lite는 텍스처 세트마다 바탕을 포함해 4장까지입니다. 레이어 패널 아래에 "레이어 4 / 4장"이라고 표시됩니다. 레이어를 삭제하거나 병합하면 다시 추가할 수 있습니다.

Pro로 업그레이드하기 Pro

Standard에서 Pro로 바꿀 때는 BOOTH의 "Pro 업그레이드"를 사용합니다.

  1. BOOTH에서 "Pro 업그레이드"를 구입해 업그레이드 파일(PetaNuri3D-Pro.petapack)을 받습니다.
  2. 도움말 → "Pro로 업그레이드" → "파일 선택"에서 그 파일을 선택합니다. 창에 끌어다 놓거나 exe와 같은 폴더에 두어도 됩니다.
  3. 그 자리에서 Pro가 됩니다. 다시 실행할 필요는 없습니다. 작업 파일과 설정은 그대로이며, 다음 실행부터도 Pro입니다.
업그레이드는 Standard일 때만 사용할 수 있습니다(Lite에서는 사용할 수 없습니다).
업그레이드 파일은 버전에 묶여 있지 않습니다. 한 번 적용하면 PetaNuri3D를 새 버전으로 바꿔도 Pro 그대로입니다.

새 버전으로 업데이트하기

현재 버전은 시작 화면의 제목 옆과 도움말 → "PetaNuri3D 정보"에서 알 수 있습니다. 바뀐 내용은 업데이트 내역에 정리해 두었습니다.

  1. 실행했을 때(하루에 한 번까지) 새 버전이 있으면 화면 오른쪽 아래에 알려 줍니다.
  2. "지금 업데이트"를 누르면 공식 사이트에서 새 버전을 받아 확인한 뒤, 확인 한 번으로 교체하고 다시 실행합니다. 저장하지 않은 변경이 있으면 닫기 전에 묻습니다.
  • 도움말 → "새 버전 확인"으로 언제든지 확인할 수 있습니다.
  • 파일 → 환경 설정 → 시스템의 "새 버전이 있으면 자동으로 다운로드하여 교체"는 처음부터 켜져 있습니다. 켜져 있으면 실행했을 때 받아 와서 "설치하고 다시 시작"을 묻습니다(받는 동안에는 "그만두기"로 멈출 수 있습니다). 끄면 "지금 업데이트"를 눌렀을 때만 받으러 갑니다.
  • "시작할 때 새 버전 확인"을 끄면 실행할 때는 확인하지 않습니다.
  • 직접 업데이트할 때는 새 ZIP의 압축을 풀고 setup.exe를 실행합니다(덮어쓰기로 설치됩니다). 에디션을 바꿀 때도 같습니다. 설정·작업 파일·브러시·업그레이드는 그대로 사용할 수 있습니다.
확인하는 것은 버전 번호뿐입니다. 작품이나 설정은 어디에도 전송하지 않습니다. 인터넷에 연결되어 있지 않을 때는 아무것도 표시되지 않습니다.

잘 안 될 때

  • 앱 안에서 업데이트할 수 없음: 공식 사이트에서 받을 수 없을 때는 "BOOTH에서 다운로드" 안내가 표시됩니다. BOOTH에서 ZIP을 받아 직접 업데이트하세요. v1.2.1 이전의 PetaNuri3D도 앱 안에서는 업데이트할 수 없으므로 직접 업데이트합니다.

문제가 생겼거나 요청할 것이 있을 때는 도움말 → "문의 (지원, 기능 요청, 버그 신고)"에서 보낼 수 있습니다(문의하는 방법).
