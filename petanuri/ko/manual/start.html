PetaNuri3D ／ 매뉴얼 / 시작 방법

시작 방법

PetaNuri3D 실행부터 3D 모델 열기·칠한 작업 저장까지의 과정과 버전(Lite·Standard·Pro) 차이입니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

Lite·Standard·Pro와 Pro 업그레이드를 BOOTH에서 배포하고 있습니다.

실행

  1. 다운로드한 zip을 풀고 PetaNuri3D 폴더를 원하는 위치에 둡니다(설치 불필요).
  2. 폴더 안의 PetaNuri3D-win_x64.exe 를 더블클릭합니다. 같은 폴더의 resources.neu도 사용하므로 옮길 때는 폴더 전체를 이동하세요.
  3. 'Windows의 PC 보호'가 표시되면 '추가 정보' → '실행'을 누릅니다(서명 없는 앱이므로 처음에 표시될 수 있음).
  4. 중앙에 '새로 만들기'·'작업 파일 열기'·'샘플로 해 보기'가 표시되면 준비 완료입니다(최근 사용한 파일·자동 저장도 여기서 열 수 있음).
실행 환경은 Windows 11(64bit)입니다. Windows 10에서도 실행되지만 지원 대상이 아닙니다.
설정(보조 도구·키 할당·창 배치·컬러 세트·참고 이미지 등)은 %APPDATA%\PetaNuri3D에 저장되며 다음 실행에 복원됩니다.

튜토리얼과 샘플 모델

  • 처음 실행하면 조작 안내(튜토리얼·12단계)가 표시됩니다.← → 로 이전·다음 이동, '건너뛰기' 또는 Esc 로 종료할 수 있습니다.
  • 다시 보려면 도움말 → '튜토리얼'. 파일 → 환경 설정 → 시스템의 '다음 실행 시 튜토리얼 보기'로도 표시할 수 있습니다.
  • 모델을 열지 않은 상태에서 튜토리얼을 시작하면 '샘플 모델로 해 보기' 또는 '내 모델로 (나중에 열기)'를 선택합니다. 샘플은 회전·그리기·좌우 대칭·UV를 실제 조작하며 진행합니다.
  • 샘플 모델(獄門しのぶ)은 시작 화면의 '샘플로 해 보기'로 열 수 있습니다(Lite도 가능). A 포즈·텍스처 세트 7개이며 각 세트 바탕에 원래 색 이미지(2048px)가 적용됩니다.
샘플 모델은 PetaNuri3D 시험 용도로만 사용할 수 있습니다. 다른 용도로 사용하거나 추출하여 배포하지 마세요.

모델 없이 그리려면 시작 화면의 '샘플로 해 보기' 아래 '2D 페인트로 그리기'에서 시작합니다(2D 페인트).

새로 만들기(3D 모델 열기)

  1. '새로 만들기'(파일 → 새로 만들기·Ctrl＋N)를 누르고 3D 모델을 선택합니다. FBX·glTF(한 파일로 묶인 것)·GLB·VRM·OBJ·DAE를 열 수 있습니다.
  2. 머티리얼별 텍스처 세트가 표시됩니다. 세트별로 해상도(32~4096, Lite는 최대 2048)와시작을 정합니다.
  3. 시작은 '색'(바탕을 단색으로 칠하기. 기본 흰색, '모델 색'도 선택 가능)·'이미지'(PNG·JPEG 등)·'PSD'(레이어 포함.Standard)·'lilToon 머티리얼'(.mat 또는 이를 포함한 .unitypackage.Pro) 중 선택합니다. 세트마다 다른 시작 방식을 섞어도 됩니다.
  4. '새로 만들기'를 누르면 3D 뷰에 모델이 표시됩니다. 취소하려면 '취소' 또는 Esc.
모델이 쓰는 이미지가 주변(같은 폴더나 Texture 폴더)에 있거나 모델 안에 포함되어 있으면 자동으로 찾아 '이미지'로 시작합니다.
위 '일괄'로 해상도를 통일하거나 이미지·PSD·lilToon 머티리얼을 한꺼번에 선택합니다. 파일 이름이 세트 이름과 같으면(body.psd → body) 해당 세트에 적용합니다. 이 화면에 이미지·PSD·.mat를 드롭해도 분류합니다.
3D 모델은 창에 드롭해도 열리지 않습니다. 파일 → 새로 만들기 또는 모델 다시 불러오기에서 여세요. UV가 0~1 밖에 있는 모델은 텍스처 반복으로 같은 색이 되는 위치에 대응시켜 칠합니다(모델 파일은 변경하지 않음). 칠할 수 없는 곳이 있는 모델은 불러올 때 오른쪽 아래에서 알려줍니다.
Pro 바탕을 정한 후 '생성 후 간편 베이크 열기'를 체크하고 대상 세트를 선택할 수 있습니다. 생성 후 피부·의상 등의 마무리를 선택하고 그릴 수 있습니다. 자동 베이크가 아닌 미리보기를 확인하고 확정하는 방식입니다(간편 베이크).

저장·이어 열기

  • 파일 → 작업 파일 저장(Ctrl＋S)으로 모델과 모든 레이어·설정이 하나의 .petanuri 파일에 저장됩니다. 다른 이름으로 저장은 Ctrl＋Shift＋S.
  • 이어서 작업하려면 파일 → 작업 파일 열기(Ctrl＋O)로 .petanuri를 엽니다(창에 드롭도 가능). 파일 → 최근 사용한 파일에서도 가능합니다.
  • 여는 동안 화면 중앙에 '불러오는 중…'과 파일 이름·진행 상황이 표시됩니다.
  • 제목의 '*'는 저장하지 않은 변경 사항이 있다는 표시입니다.
  • 5분마다 자동 저장합니다. 앱이 종료되었다면 파일 → 자동 저장에서 열기로 복원합니다(작업별 최신 3개까지).
일부를 읽지 못한 작업 파일은 이름에 '(누락 있음)'이 붙어 열립니다. 원본을 덮어쓰지 않도록 저장은 '다른 이름으로 저장'이 됩니다.

모델 다시 불러오기(그린 것 유지)

3D 모델(FBX 등)을 수정했을 때 그린 내용을 유지하면서 형태만 갱신할 수 있습니다.

  1. 파일 → 모델 다시 불러오기를 선택합니다.
  2. '같은 파일 다시 불러오기' 또는 '파일 선택'을 누릅니다.
  3. 텍스처 세트는 머티리얼 이름으로 맞춥니다. 같은 이름의 세트는 레이어와 설정이 그대로 유지됩니다.
  • UV가 바뀌어도 그린 그림은 UV 위의 위치 그대로 새 형태에 적용합니다(UV를 크게 이동한 곳은 그림이 어긋나 보임).
  • 새 모델에 없는 머티리얼 세트는 지우지 않고 ! 표시를 붙여 유지합니다. 누르면 레이어를 다른 세트로 옮길 수 있습니다(대상이 없는 세트).
  • 새 머티리얼이 추가되면 다시 불러오기 전에 새로 만들기와 같은 화면이 새 세트 행만 표시됩니다. 해상도와 시작 방식을 정하고 '다시 불러오기'를 누릅니다.
다시 불러오면 실행 취소(내역)가 지워집니다.
다시 불러온 뒤 모델의 텍스처(이미지)가 이전과 달라진 세트가 있으면 세트마다 “바탕을 새 텍스처로 바꿀까요?”라고 묻습니다. 바꾸면 바탕에 직접 그린 것도 바뀝니다. 바꾸기는 다시 불러온 뒤의 한 단계로 실행 취소할 수 있습니다.

Standard를 Pro로 변경(업그레이드) Pro

  1. BOOTH에서 'Pro로 업그레이드'를 구매하면 업그레이드 파일(PetaNuri3D-Pro.petapack)을 받습니다.
  2. 도움말 → 'Pro로 업그레이드' → '파일 선택'으로 해당 파일을 선택합니다(창에 드롭하거나 exe와 같은 폴더에 두어도 됨).
  3. PetaNuri3D를 닫고 다시 실행하면 Pro가 됩니다. 재설치가 필요 없습니다. 작업 파일과 설정이 유지되며 이후 실행에서도 Pro입니다.
업그레이드는 Standard에서만 가능합니다(Lite 불가). 업그레이드 파일은 같은 버전의 PetaNuri3D에만 적용됩니다. PetaNuri3D를 새 버전으로 바꿨다면 같은 버전의 업그레이드 파일을 다시 다운로드하여 넣으세요(맞지 않으면 실행 시 안내하고 Standard로 실행).

버전과 새 버전 안내

  • 현재 버전은 시작 화면 제목 옆(v1.1.0 등)과 도움말 → 'PetaNuri3D 정보'에서 확인합니다.
  • 실행 시(하루 최대 1회) 공식 사이트에서 새 버전이 있는지 확인합니다. 새 버전이 있으면 화면 오른쪽 아래에 안내합니다('배포처 열기'·'나중에'·'이 버전 알리지 않기').
  • 도움말 → '새 버전 확인'으로 언제든 확인할 수 있습니다. 파일 → 환경 설정 → 시스템의 '시작할 때 새 버전 확인'을 해제하면 실행 시 확인하지 않습니다.
버전 번호만 확인합니다. 작품이나 설정은 어디에도 전송하지 않습니다. 인터넷에 연결되지 않으면 아무것도 표시하지 않습니다.
