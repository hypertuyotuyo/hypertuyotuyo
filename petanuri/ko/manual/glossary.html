용어집

PetaNuri3D의 화면과 이 매뉴얼에 나오는 용어의 뜻입니다. 모든 항목에서 첫 문장이 정의입니다. 자세한 사용법은 각 항목 끝의 링크에서 확인하세요.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

영문·숫자ㄱㄴㄷㄹㅁㅂㅅㅇㅈㅊㅋㅌㅍㅎ

영문·숫자

2D 캔버스·2D 페인트
3D 모델을 사용하지 않고 그리는, 사각형 2D 작업 공간입니다. 스탬프 이미지를 만들기 위한 "스탬프용 2D 캔버스"와, 모델 없이 그림을 그리는 "2D 페인트"가 있습니다. → 스탬프용 2D 캔버스·2D 페인트
AO Pro
빛이 닿기 어려운 곳(움푹 들어간 곳·겹친 곳·틈새)의 어두운 정도입니다. PetaNuri3D가 모델의 형태에서 계산해 레이어에 굽습니다. → AO 굽기
lilToon
VRChat 아바타에서 많이 쓰는 Unity 셰이더(보이는 모습을 계산하는 방식)입니다. Pro에서는 그 모습으로 확인하거나, 머티리얼을 가져오고 내보낼 수 있습니다. → 마무리 모습과 lilToon 머티리얼
MCP(AI 연동)
AI 앱에서 PetaNuri3D를 조작하기 위한 구조입니다. 파일 → 환경 설정 → AI 연동에서 켭니다(처음에는 꺼져 있음). → AI 연동
MToon Pro
VRM 모델에서 사용하는 셰이더입니다. Pro에서는 그 모습으로 마무리를 확인할 수 있습니다(베타 버전). → 마무리 모습과 lilToon 머티리얼
PSD Standard
레이어를 나눈 채로 저장할 수 있는 이미지 형식입니다. PetaNuri3D에서는 새로 만들기의 바탕으로 쓸 때와 내보내기에서 사용할 수 있습니다(Standard 이상). → PSD로 내보내기
UV
3D 모델의 면이 평평한 텍스처의 어디에 대응하는지 정한 전개도입니다. PetaNuri3D에서는 UV를 3D 옆에 표시하고, 그 위에도 그릴 수 있습니다. → UV를 표시해 직접 칠하기

ㄱ

간편 베이크 Pro
피부·의상·소품용 12종의 마무리 중에서 골라, 음영이나 그라데이션 밑칠을 한꺼번에 만드는 기능입니다. → 간편 베이크

ㄴ

내보내기
텍스처 이미지(PNG·PSD)나 머티리얼을 다른 앱에서 쓸 수 있는 형태로 만드는 것입니다. 작업 파일 저장과는 다른 조작입니다. → 내보내기
노멀 맵
면의 방향을 픽셀마다 바꿔서 요철이 있는 것처럼 보이게 하는 이미지입니다. 스티치의 주름·볼록함은 노멀 맵 폴더에 높이로 그립니다(Pro). → 스티치

ㄷ

대상이 없는 세트
모델을 다시 불러왔을 때, 새 모델에는 없는 머티리얼의 텍스처 세트입니다. 지우지 않고 ! 표시로 남으며, 레이어를 다른 세트로 옮길 수 있습니다. → 대상이 없는 세트
대칭으로 그리기
한쪽에 그리면 접은 반대쪽에도 똑같이 그려지는 기능입니다. X(좌우)·Y(앞뒤)·Z(상하)가 있으며, M으로 X를 전환합니다. → 대칭으로 그리기
도구 속성
선택한 보조 도구의 설정입니다(크기·불투명도·경도·손떨림 보정·필압 등). 보조 도구마다 기억합니다. → 브러시 세부 설정
뒷면·가려진 면에도 칠하기
브러시가 닿는 곳이라면 보이지 않는 뒷면이나 안쪽 면에도 칠할지를 정하는 설정입니다. 도구 속성의 불투명도 바로 아래에 있으며, 보조 도구마다 기억합니다. → 뒷면에도 칠하기

ㄹ

레이어
투명한 필름처럼 겹쳐서 그리는, 그림 한 장 한 장입니다. 텍스처 세트마다 가장 아래에 바탕 레이어가 있습니다. → 레이어
레이어 속성
선택한 레이어의 설정을 늘어놓은 패널입니다. 조정 레이어의 값이나 테두리 켜기/끄기도 여기서 바꿉니다. → 레이어 속성
레이어 쉬게 하기
한동안 건드리지 않은 레이어를, 보이는 모습은 그대로 두고 GPU 메모리에서 빼 두는 구조입니다. 4096 레이어를 많이 겹칠 때 효과가 있습니다(처음부터 켜짐). → 레이어 쉬게 하기

ㅁ

마무리 모습 Pro
3D 표시 형식 중 하나로, lilToon과 같은 계산으로 그림자나 림 라이트 등을 더한 모습을 보여 줍니다(베타 버전). → 마무리 모습
마스크(레이어 마스크)
레이어의 어디를 보이게 하고 어디를 숨길지를 흑백으로 그려서 정하는 것입니다. 그림 자체를 지우지 않고 숨길 수 있습니다(흰색=보임, 검정=가림). → 레이어 마스크
메시 선
모델 면의 변을 3D 위에 겹쳐 표시하는 것입니다. 아일랜드 가장자리만 표시하는 것은 "이음선"입니다. → 메시 선
메인과 서브(텍스처 세트)
바로 그릴 수 있는 상태의 텍스처 세트 2개입니다. 선택 중인 세트가 메인, 그 직전에 선택했던 세트가 서브이며, 선 하나로 걸쳐 그릴 수 있습니다. → 두 세트에 걸쳐 그리기
무늬
전경색으로 무늬 부분만 칠할 수 있는 펜입니다(세로 줄무늬·물방울무늬·깅엄 체크 등 15종). → 무늬

ㅂ

번짐(패딩)
내보낼 때 UV 아일랜드 바깥으로 가장자리 색을 넓히는 것입니다. 넓히지 않으면 축소했을 때 이음매에 선이 보일 수 있습니다(기본값은 8px). → 번짐
보조 도구
하나의 도구 안에 있는, 설정이 다른 도구입니다(펜이라면 G펜·둥근 펜·밀리펜 등). 복제해서 자신의 설정을 만들 수 있습니다. → 보조 도구
블렌드 셰이프 Pro
표정 등 모델 형태의 변화입니다. 그 형태로 만든 다음 칠할 수 있습니다. → 블렌드 셰이프

ㅅ

색 혼합
이미 그려진 색을 흐리게 하거나, 손가락으로 늘이거나, 섞기 위한 도구입니다(키 J). 보조 도구에 "흐리기", "손가락", "색 혼합" 등이 있습니다. → 색 혼합
선택 범위
그릴 수 있는 곳을 둘러싸서 정한 것입니다. 선택 범위가 있을 때는 그 안에만 그릴 수 있습니다. → 선택 범위
숨기기 펜
따라 그린 면이나 아일랜드를 3D 표시에서 숨기는 도구입니다. 앞쪽을 숨기면 겹쳐서 칠할 수 없었던 안쪽 면을 칠할 수 있습니다. Alt+H로 모두 표시 상태로 돌아갑니다. → 숨기기 펜

ㅇ

아일랜드(UV 아일랜드)
UV 위에서 하나로 이어져 있는 면의 덩어리입니다. 채우기의 "아일랜드 칠하기"는 누른 곳의 아일랜드를 통째로 칠합니다. → UV를 표시해 직접 칠하기
에디션(Lite·Standard·Pro)
PetaNuri3D의 3가지 종류입니다. 이 매뉴얼에서는 Standard 이상의 기능에 Standard, Pro 전용 기능에 Pro 표시를 붙였습니다. → 에디션
오브젝트
모델 안의 부품(머리카락·옷·소품 등의 메시)입니다. 오브젝트 패널에서 부품별로 숨기거나 그것만 표시할 수 있습니다. → 오브젝트
우클릭 메뉴
마우스로 우클릭했을 때 나타나는, 그 위치에서 쓸 수 있는 조작의 목록입니다. 3D 뷰·레이어·텍스처 세트 등에서 내용이 달라집니다. → 우클릭 메뉴
이음매
3D에서는 이어져 있는데 UV 위에서는 떨어져 있는 곳(아일랜드 가장자리)입니다. 이음선은 Alt+W로 표시를 전환합니다. → 이음선

ㅈ

자동 저장
5분마다 작업을 자동으로 저장하는 구조입니다. 작업마다 최신 3개까지 남으며, 파일 → 자동 저장에서 열기로 되돌릴 수 있습니다. → 저장·이어 열기
자동 채색
선화와 색 "힌트"로, 선으로 구분된 영역마다 밑칠을 만드는 기능입니다(레이어 → 자동 채색). → 자동 채색
작업 내역
실행 취소할 수 있는 조작이 오래된 순서로 늘어선 패널입니다. 행을 누르면 그 조작 이후까지 한 번에 되돌아갑니다(최대 30단계). → 작업 내역
작업 파일(.petanuri)
PetaNuri3D의 작업을 저장하는 파일입니다. 모델과 모든 레이어·설정이 하나에 들어 있어, 열면 이어서 그릴 수 있습니다. → 저장·이어 열기
전경색·배경색
전경색은 그릴 때의 색, 배경색은 하나 더 대기시켜 두는 색입니다. X로 서로 바꾸고, D로 검정·흰색으로 되돌립니다. → 색 선택 방법
조정 레이어 Standard
아래 그림을 바꾸지 않고 색상·밝기 등의 보정을 거는 레이어입니다. 나중에 값을 고칠 수 있습니다. → 조정 레이어

ㅊ

칠할 대상 Pro
메인 컬러 이외의 그림자 색·마스크·노멀 맵 등 lilToon의 텍스처에, 평소의 도구로 그릴 때의 그릴 대상입니다. 레이어 패널의 폴더가 됩니다. → 칠할 대상

ㅋ

클리핑
아래 레이어의 그려진 곳에만 그 레이어를 보이게 하는 설정입니다. 삐져나오지 않게 그림자나 무늬를 겹칠 때 사용합니다. → 클리핑

ㅌ

테두리 Standard
레이어의 그림을 바꾸지 않고, 겹칠 때 가장자리 선을 붙이는 효과입니다. 나중에 굵기나 색을 고치거나 끌 수 있습니다. → 테두리
텍스처
3D 모델의 표면에 붙이는 이미지입니다. PetaNuri3D에서는 모델에 그린 그림이 텍스처에 기록됩니다. → 내보내기
텍스처 세트
머티리얼마다 만들어지는, 텍스처 1장과 그 레이어의 묶음입니다. 같은 이미지를 사용하는 머티리얼은 하나의 세트로 묶입니다. → 텍스처 세트
투명 픽셀 잠금
그 레이어에서 그려져 있는 곳에만 그릴 수 있고, 투명한 곳에는 그릴 수 없게 하는 설정입니다. 칠한 색을 모양은 그대로 두고 다시 칠할 때 사용합니다. → 투명 픽셀 잠금

ㅍ

팝업 팔레트
펜의 사이드 버튼(오른쪽 버튼)을 움직이지 않고 놓으면 나타나는 작은 창입니다. 펜만으로 도구나 색을 고를 수 있습니다. → 팝업 팔레트
패널
색·레이어·도구 속성 등이 들어 있는 화면의 창입니다. 옮기거나, 탭으로 묶거나, 띄우거나, 접을 수 있습니다. → 패널 이동하기
포즈 모드 Pro
본을 움직여 포즈를 잡고, 그 모양 그대로 칠하는 모드입니다. 겨드랑이처럼 원래 자세로는 칠하기 어려운 곳에 사용합니다. → 포즈 모드
표시 범위
선택한 아일랜드나 면만 3D에 표시하고 나머지를 숨기는 구조입니다. 숨긴 곳 안쪽의 면이 보이게 되어 칠할 수 있습니다. → 표시 범위
표시 형식
3D 뷰가 보이는 방식의 종류입니다(칠한 색 그대로·2단계 툰·음영·마무리 모습 등). 3D 뷰의 왼쪽 위에서 전환합니다. → 3D 뷰 네 모서리
필터 Standard
선택한 레이어의 그림 자체에 색조 보정·흐리기·노이즈 등을 적용하는 기능입니다(메뉴 "필터"). → 필터

ㅎ

합성 모드
레이어의 그림을 아래 그림에 어떻게 겹칠지 정하는 규칙입니다(표준·곱하기·스크린·오버레이 등 28종). → 합성 모드
해상도
텍스처 한 변의 픽셀 수입니다. 새로 만들기에서 텍스처 세트마다 32~4096 중에서 고릅니다(Lite는 2048까지). → 해상도 바꾸기
