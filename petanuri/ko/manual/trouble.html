문제가 생겼을 때

자주 겪는 문제를 증상으로 찾을 수 있도록 정리했습니다. 각 줄의 링크를 따라가면 원인과 해결 방법이 나옵니다. 여기에 없으면 위쪽 검색창에 증상을 나타내는 말을 입력해 보세요.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

먼저 이것만
  1. 조작을 잘못했을 때는 Ctrl+Z로 한 단계 되돌립니다. 여러 단계 전으로 돌아가려면 작업 내역을 이용하세요.
  2. 앱이 종료되었거나 멈췄을 때는 다시 실행한 뒤 파일 → 자동 저장에서 열기를 선택합니다(자세히).
  3. 그려지지 않을 때는 선택한 레이어와 선택 범위가 남아 있지 않은지 먼저 확인합니다(그려지지 않을 때).
  4. 해결되지 않으면 도움말 → "문의 (지원, 기능 요청, 버그 신고)"에서 보낼 수 있습니다(문의하기).

실행·모델 열기

  • "Windows의 PC 보호" 창이 나타남: 서명이 없는 앱이어서 처음에 나타날 수 있습니다. "추가 정보" → "실행"을 선택해 실행합니다(설치·실행하기).
  • 모델을 창에 끌어다 놓아도 열리지 않음: 모델을 연 뒤에는 끌어다 놓아도 열리지 않습니다. 파일 → 새로 만들기에서 엽니다(모델 열기).
  • "텍스처를 찾을 수 없다"거나 "칠할 수 없는 곳이 있다"고 표시됨: 새로 만들기 창에서 이미지를 다시 선택합니다. UV가 없는 면 등은 칠할 수 없습니다(모델 열기).
  • PetaNuri3D를 옮기거나 업데이트했더니 Unity에서 실행되지 않음: Unity 쪽에서 PetaNuri3D의 위치를 다시 지정합니다(위치 다시 지정하기).
  • 패널도 도구 모음도 전부 사라짐: Tab으로 숨겨진 상태입니다. Tab을 한 번 더 누르면 돌아옵니다(화면의 각 부분).
  • 사용하려는 패널이 보이지 않음·배치가 흐트러짐: 표시 → 창에서 패널을 표시하거나 배치를 되돌립니다(패널 목록·배치 되돌리기).
  • 투명한 부분이 회색이나 바둑판 무늬로 보임·해상도가 낮은 텍스처가 흐릿하게 보임: 표시 설정 때문입니다(빛과 투명이 보이는 방식).
  • 앱 안에서 새 버전으로 업데이트할 수 없음: BOOTH에서 ZIP을 받아 직접 업데이트합니다(새 버전으로 업데이트하기).

그려지지 않음·원하는 곳에 칠해지지 않음

  • 문질러도 색이 칠해지지 않음·일부만 칠해지지 않음: 레이어가 숨겨져 있거나 잠겨 있는 경우, 선택 범위가 남아 있는 경우 등이 원인입니다(첫 번째 선 그리기).
  • 선택 범위 밖에 칠할 수 없음·원하는 곳에 칠해지지 않음: 선택 범위가 남아 있습니다. 해제한 뒤에 그립니다(선택 범위).
  • 그려도 그림이 바뀌지 않음: 그릴 대상이 레이어 마스크로 되어 있습니다(레이어 마스크).
  • 색을 골라도 회색으로만 칠해짐: 칠할 대상(그림자 색·마스크 등)을 칠하는 상태 그대로입니다. "컬러로 돌아가기"로 되돌립니다(칠할 대상).
  • 레이어를 추가할 수 없음(Lite): Lite는 텍스처 세트마다 바탕을 포함해 4장까지입니다(레이어).
  • 그렸더니 다른 텍스처 세트로 넘어가 버림: 그리기 시작한 곳의 세트로 자동 전환되는 기능입니다. 끌 수도 있습니다(그릴 세트 선택하기).
  • 다른 텍스처 세트 위에서 그릴 수 없음·목의 경계에서 선이 끊김: 두 세트에 걸쳐 그리는 설정을 확인합니다(두 세트에 걸쳐 그리기·그려지지 않을 때).
  • 옷 아래나 머리카락 안쪽에 칠할 수 없음: 앞쪽 면을 숨기면 안쪽에 칠할 수 있습니다(표시 범위·숨기기 펜).
  • 모델의 일부가 사라진 채 돌아오지 않음: 숨긴 부분입니다. Alt+H를 누르면 모두 표시 상태로 돌아옵니다. 숨기는 조작은 실행 취소 대상에 포함되지 않습니다(표시 범위).
  • 두께의 반대쪽까지 색이 칠해짐: "뒷면·가려진 면에도 칠하기"가 켜져 있습니다(뒷면·가려진 면에도 칠하기).
  • 포즈 모드에서 그릴 수 없음: 포즈 모드를 확인하세요.

선·브러시·도구가 이상함

  • 펜의 필압이 작동하지 않음·굵기가 변하지 않음·이상함: 필압이 작동하지 않을 때의 순서대로 확인합니다.
  • WinTab으로 바꿨더니 펜이 반응하지 않음·"WinTab에 빈자리가 없습니다"라고 표시됨: 필압이 작동하지 않을 때를 확인하세요.
  • 사이드 버튼을 놓아도 3D가 계속 회전함: 펜 버튼을 확인하세요.
  • 세밀한 부분을 그리고 있으면 우클릭 메뉴가 멋대로 나타남: 우클릭 메뉴를 확인하세요.
  • 키가 작동하지 않음·의도하지 않은 조작이 일어남: 키 할당을 확인합니다(키 할당).
  • 가까이 가면 선이 가늘어짐·비스듬한 면에서 선이 늘어남·선이 늦게 따라옴: 브러시 크기 기준 등의 설정 때문입니다(그리는 느낌 정하기).
  • 선이 저절로 곧게 되거나 휨: 자에 달라붙어 있습니다(자).
  • 좌우 대칭인데 반대쪽이 어긋남·그려지지 않음: 대칭의 중심과 대칭이 적용되지 않는 도구를 확인합니다(좌우 대칭으로 그리기).
  • 채우기가 선 밖으로 번짐·선 가장자리에 흰 틈이 남음: 틈 메우기와 확장/축소로 해결합니다(채우기).
  • 스탬프가 붙지 않음·흰 사각형까지 붙음: 스탬프를 확인하세요.
  • 무늬의 방향이 거꾸로이거나 옆으로 누움: 무늬를 확인하세요.
  • 텍스트를 입력한 뒤 키를 눌러도 도구가 바뀌지 않음: 텍스트를 입력하는 중입니다(텍스트).
  • 이동 도구에서 "여기에 그려진 표시 중인 레이어가 없습니다"라고 표시됨: 이동·변형 도구를 확인하세요.

실행 취소·효과가 이상함

  • Ctrl+Z로 되돌아가지 않는 조작이 있음: 실행 취소에 포함되지 않는 조작이 있습니다(실행 취소할 수 없는 조작).
  • 필터를 적용해도 변하지 않음: 필터를 확인하세요.
  • 베이크한 그림자가 이중으로 겹침·너무 진함: 굽고 난 뒤 조정을 확인하세요.
  • AO를 구웠더니 옷 아래의 몸이 새까맣게 됨: AO 굽기를 확인하세요.

느림·멈춤·저장

  • 느림·그려지지 않음·"표시 처리가 멈췄습니다"라고 표시됨: GPU 메모리가 부족합니다(메모리 절약하기).
  • 앱이 종료되었음·멈췄음: 다시 실행해서 파일 → 자동 저장에서 열기로 복구합니다(저장하기).
  • "앱 내부의 읽기·쓰기가 멈췄습니다"라고 표시됨·저장 창이 응답하지 않음: 저장·이어 열기를 확인하세요.
  • 작업 파일 이름에 （欠けあり）가 붙음: 일부를 읽지 못한 파일입니다. 다른 이름으로 저장합니다(저장하기).
  • 텍스처 세트에 !가 붙음·다시 불러왔더니 그린 그림이 보이지 않음: 대상이 없는 세트입니다. 레이어를 다른 세트로 옮길 수 있습니다.

내보내기·Unity·AI 연동

  • Unity·VRChat에서 UV의 이음선이 보임: 내보내기 번짐(패딩)을 넓힙니다(번짐).
  • 내보낼 수 없음("~ 표시 중에는 내보낼 수 없습니다" 등): PNG로 내보내기를 확인하세요.
  • 내보낸 머티리얼이 Unity에서 분홍색이 됨: 머티리얼 내보내기를 확인하세요.
  • "더 이상 추가할 수 없습니다"라고 표시됨(칠할 대상): 칠할 대상을 확인하세요.
  • Unity에서 칠했는데 보이는 모습이 바뀌지 않음: Unity에서 칠하기를 확인하세요.
  • AI 앱이 "연결되지 않는다"고 함: AI 연동이 OFF일 수 있습니다(AI 연동).

문의하기

이 매뉴얼로 해결되지 않을 때나 요청·버그 신고는 앱 안에서 보낼 수 있습니다. 조사에 필요한 정보(버전·에디션·환경)는 문장에 자동으로 들어갑니다.

  1. 도움말 → "문의 (지원, 기능 요청, 버그 신고)"를 선택합니다.
  2. 종류를 선택합니다. 작성할 곳과 버전 등이 들어간 문장이 나타납니다.
  3. 비어 있는 곳을 작성합니다.
  4. "BOOTH 숍 열기(문장은 복사됨)" 또는 "Discord 열기(문장은 복사됨)"를 누릅니다. 문장이 복사되고 보낼 곳이 열립니다.
  5. 보낼 곳에 붙여넣어 보냅니다. BOOTH는 숍 페이지 아래의 "숍에 문의하기"에서, Discord는 서버에 참가한 뒤 문의 채널에 보냅니다.
접수한 요청의 대응 현황은 요청과 대응 현황 페이지에 정리해 두었습니다.
