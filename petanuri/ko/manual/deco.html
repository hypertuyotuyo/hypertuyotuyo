스탬프·무늬·스티치·2D 캔버스

장식·이미지·옷 무늬·바느질 선처럼 반복이 많은 덧그리기 도구입니다. 그린 그림을 스탬프로 만드는 2D 캔버스와 모델을 사용하지 않는 2D 페인트도 여기에 모아 두었습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

먼저 이것만
  1. 장식을 흩뿌릴 때는 도구 모음의 "데코레이션"에서 반짝이 등을 골라 따라 그립니다(자세히).
  2. 이미지를 붙일 때는 "스탬프"의 "이미지 가져오기"로 PNG를 추가하고 3D 뷰 위를 누릅니다(자세히).
  3. 옷 무늬는 "무늬", 바느질 선은 "스티치"를 선택하고 전경색으로 따라 그립니다(무늬·스티치).
  4. 직접 그린 그림을 스탬프로 만들 때는 스탬프의 "2D 캔버스에서 그리기"로 그린 다음 "스탬프로 등록"을 누릅니다(자세히).
  5. 모델 없이 그릴 때는 시작 화면의 "2D 페인트로 그리기"부터 시작합니다(자세히).
이 페이지의 내용
  • 장식 흩뿌리기(데코레이션)
  • 이미지 붙이기(스탬프)
  • 옷에 무늬 넣기(무늬 도구)
  • 바느질 선 그리기(스티치)
  • 그린 그림을 스탬프로 만들기(2D 캔버스)
  • 모델 없이 2D로 그리기(2D 페인트)

장식 흩뿌리기(데코레이션)

따라 그린 곳에 작은 장식을 전경색으로 흩뿌립니다. 크기와 방향은 조금씩 달라집니다.

  1. 도구 모음의 "데코레이션"을 누릅니다.
  2. 보조 도구에서 장식을 고릅니다.
  3. 전경색을 고른 다음 3D 뷰 위를 따라 그립니다.
  • 장식은 반짝이·별·하트·꽃·벚꽃·음표·눈 결정·물방울무늬·거품·초승달·마름모·네잎클로버·물방울, 그리고 레이스 4종입니다.
  • 3D·UV 뷰 위에 커서를 올리면 브러시 끝의 모양이 표시됩니다.
  • 크기·흩뿌리기·무작위 회전 등은 펜과 마찬가지로 도구 속성에서 바꿉니다(그리는 느낌 정하기).
  • "뒷면·가려진 면에도 칠하기"는 처음에는 꺼져 있습니다. 좌우 대칭으로 그리기도 적용됩니다.

레이스 그리기

"레이스(스캘럽)", "레이스(피코)", "레이스(작은 꽃)", "레이스(그물코)"는 선을 따라 무늬가 띠처럼 이어집니다. 곡선이나 뾰족한 모서리, 3D 위에서도 끊기지 않고 이어집니다.

  • 구멍은 투명하며, 전경색으로 칠합니다. 굵기가 무늬의 크기입니다.
  • 도형 도구의 브러시 끝으로 선택하면 직사각형이나 타원의 윤곽을 따라 레이스를 그릴 수 있습니다(도형).

이미지 붙이기(스탬프)

가져온 이미지를 3D 위에 붙입니다. 로고나 와펜, 무늬 소재 등에 사용합니다.

  1. 도구 모음의 "스탬프"를 누릅니다.
  2. 도구 속성의 "이미지 가져오기"로 PNG·JPEG 등을 추가합니다(몇 장이든 가능합니다).
  3. 목록에서 이미지를 선택합니다.
  4. 3D 뷰 위를 누르면 그 이미지가 하나 붙습니다. 드래그하면 간격마다 이어서 붙입니다.
  • 3D·UV 뷰 위에 커서를 올리면 붙을 이미지가 그 크기·각도·색·불투명도 그대로 반투명하게 표시됩니다. 칠하기 전의 미리보기이며, 텍스처에는 들어가지 않습니다.
  • 커서를 움직이는 방향의 앞쪽에는 다음에 놓일 위치도 흐리게 표시됩니다. "다음에 놓일 위치를 흐리게 표시"를 끄면 현재 위치의 미리보기만 표시됩니다.
  • 이미지의 색 그대로 붙입니다(투명한 부분은 붙이지 않습니다). "전경색으로 칠하기"를 켜면 이미지의 모양만 사용하여 전경색으로 칠합니다.
  • 보조 도구의 "스탬프(흩뿌리기)"는 방향과 위치를 다르게 하여 흩뿌립니다.
  • 보이는 면에만 붙으며, 선 한 번이 실행 취소 1회분입니다. UV 뷰 위에서도 붙일 수 있습니다.
  • 좌우 대칭은 3D·UV 뷰 모두에서 적용됩니다. 반대쪽은 이미지도 거울에 비친 방향이 됩니다.

도구 속성 맨 위에 현재 이미지의 큰 미리보기·목록·크기·각도가 표시됩니다.

  • 눌러도 아무것도 붙지 않습니다: 이미지가 선택되어 있지 않습니다. "이미지 가져오기"로 추가하고 목록에서 선택하세요. 모델의 보이는 면 위를 누르세요.
  • 이미지 주위의 하얀 사각형까지 붙습니다: 이미지에 투명한 부분이 없습니다. 배경을 투명하게 만든 PNG를 사용하세요.
  • 미리보기와 붙는 모양이 조금 다릅니다: 무작위 회전·흩뿌리기·편차는 미리보기에 반영되지 않습니다.

옷에 무늬 넣기(무늬 도구)

전경색으로 무늬 부분만 칠하는 펜입니다. 무늬는 텍스처 위에서 반복되므로 시점을 움직여도 어긋나지 않습니다.

  1. 도구 모음의 "무늬"를 누릅니다.
  2. 보조 도구나 도구 속성 맨 위의 미리보기 목록에서 무늬를 고릅니다.
  3. 전경색을 고른 다음 옷 위를 따라 그립니다.
  • 무늬는 세로 줄무늬·가로 줄무늬·사선 줄무늬·물방울무늬·작은 물방울무늬·체커보드·깅엄 체크·타탄 체크·아가일·헤링본·데님(능직)·니트·하트·별·크로스해치의 15종입니다.
  • 3D·UV 뷰 위에 커서를 올리면 브러시 원 안에 입혀질 무늬가 전경색으로 반투명하게 표시됩니다.
  • "패턴 이미지 불러오기"로 원하는 이미지를 무늬로 쓸 수 있습니다(밝은 곳일수록 잘 칠해집니다).
  • 같은 무늬는 다른 펜·붓의 "종이 질감"에서도 선택할 수 있습니다(종이 질감).

  • 무늬가 일그러집니다: UV가 일그러진 곳에서는 무늬도 일그러집니다.

바느질 선 그리기(스티치)

바느질 선처럼 선을 따라 반복되는 장식을 그립니다. 선의 방향에 맞춰 바느질 선이 회전합니다.

  1. 도구 모음의 "스티치"를 누릅니다.
  2. 보조 도구에서 바느질 선의 종류를 고릅니다.
  3. 전경색을 고른 다음 바느질 선을 넣고 싶은 곳을 따라 그립니다.
보조 도구그리는 것
스티치(점선)·바늘땀(도톰)·봉제선·파이핑·크로스 스티치·지그재그 스티치·징(리벳)전경색으로 현재 레이어에 바느질 선을 그립니다. 2D 캔버스에서도 사용할 수 있습니다
주름(부드러운 홈)·볼록함(부드러운 돋움) Pro노멀 맵 폴더에 높이로 요철을 그립니다
  • 크기 기준은 "화면 기준 가변"으로 정해져 있습니다.
  • 도형 도구의 브러시 끝으로 스티치를 선택하면 직사각형이나 곡선의 윤곽을 따라 바느질 선을 배열할 수 있습니다(도형).

바느질 선을 요철로 만들기(노멀 맵) Pro

  1. 도구 속성의 "노멀 맵 폴더에 그리기"를 켭니다.
  2. "높이 (0 파기, 50 평평, 100 쌓기)"로 높이를 정합니다(켜 놓았을 때만 표시됩니다).
  3. 따라 그립니다. 레이어 패널의 "노멀 맵" 폴더(없으면 새로 만들어집니다) 안으로 이동하여 높이로 그려집니다.
  4. 그리기를 마치면 3D 뷰 위쪽 가운데의 "◀ 원래 레이어로 돌아가기"를 누릅니다. 이동하기 전의 레이어·표시·도구로 돌아갑니다.
  • 주름·볼록함은 항상 노멀 맵 폴더에 높이로 그립니다.
  • 요철은 마무리 모습 표시에서 보입니다. 잘 보이지 않을 때는 머티리얼 패널의 "노멀 맵 강도"를 높입니다.
  • 내보내면 노멀 맵 이미지가 됩니다(칠할 대상).

그린 그림을 스탬프로 만들기(2D 캔버스)

스탬프용 정사각형 캔버스에 평소 쓰던 도구와 레이어로 그린 뒤 그대로 스탬프로 등록할 수 있습니다.

  1. 도구 모음의 "스탬프"를 누릅니다.
  2. 도구 속성의 "2D 캔버스에서 그리기"를 누릅니다. 3D 뷰가 숨겨지고 정사각형 캔버스가 UV 뷰에 표시됩니다.
  3. 펜·지우개·채우기·그라데이션 등으로 그립니다.
  4. 아래쪽의 "스탬프로 등록"을 누르고 이름을 붙입니다. 표시 중인 레이어를 합친 모습이 그대로 스탬프가 됩니다.
  5. 모델 편집으로 돌아가면 그 스탬프로 그릴 수 있습니다.
  • 레이어·폴더·마스크·선택 범위·실행 취소는 평소처럼 사용할 수 있습니다. 에디션별 상한(Lite는 레이어 4장까지)도 같습니다.
  • 캔버스 해상도는 아래쪽 칸에서 선택합니다(32~4096. Lite는 2048까지).
  • 등록하지 않고 돌아갈 때는 "모델 편집으로 돌아가기"를 누릅니다. 그린 내용은 그대로 남습니다.
  • 등록한 스탬프를 수정할 때는 스탬프의 도구 속성에서 "이 이미지 다시 그리기"를 누르거나, 목록의 이미지를 우클릭 → "2D 캔버스에서 다시 그리기"를 누릅니다. 다시 등록할 때 "덮어쓰기" 또는 "다른 이름으로 등록"을 선택합니다.
  • 목록에서 우클릭 → "2D 캔버스에서 새로 그리기"로도 열 수 있습니다.
  • 캔버스의 레이어는 작업 파일(.petanuri)과 자동 저장에 함께 저장됩니다.
텍스처 세트 패널에 2D 캔버스를 편집 중이라는 표시가 나옵니다. 이 캔버스는 모델의 텍스처 세트 목록에도, PNG·PSD 내보내기에도 포함되지 않습니다.

모델 없이 2D로 그리기(2D 페인트)

3D 모델을 열지 않고 정사각형 캔버스에 그리는 모드입니다. 투명한 바탕에서 평소 쓰던 도구와 레이어로 그릴 수 있습니다.

  1. 시작 화면의 "2D 페인트로 그리기"를 누릅니다("샘플로 해 보기" 아래에 있습니다).
  2. "새 2D 페인트 만들기" 창에서 캔버스 크기(32 × 32~4096 × 4096)를 선택합니다.
  3. 펜·붓·그라데이션 등으로 그립니다.
  4. 아래쪽의 "PNG 내보내기"를 누르면 표시 중인 레이어를 합친 그림이 투명 영역이 있는 PNG로 저장됩니다.
  • 작업 파일(.petanuri)로 저장하면 2D 페인트 상태 그대로 레이어째 이어서 그릴 수 있습니다.
  • "스탬프로 등록"도 사용할 수 있습니다. 등록한 뒤에도 2D 페인트를 계속할 수 있습니다.
  • Standard 파일 → 내보내기 → "PSD로 내보내기(선택 중인 세트)"로 레이어·폴더 그대로 PSD로 만들 수 있습니다.
  • Lite는 해상도 2048까지, 바탕을 포함해 레이어 4장까지입니다. Standard·Pro는 4096까지이며 레이어 수의 제한은 없습니다.
3D 뷰와 모델의 형태를 사용하는 기능(베이크·포즈·머티리얼 등)은 표시되지 않습니다.
