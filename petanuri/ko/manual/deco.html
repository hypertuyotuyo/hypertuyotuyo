스탬프·패턴·요철·2D 캔버스

장식·무늬·봉제선처럼 반복되는 그리기를 위한 도구입니다. 모두 칠하기 전에 3D 위에서 적용 모습을 확인할 수 있습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

이 페이지의 내용
  • 데코레이션
  • 스탬프
  • 패턴 펜(옷 무늬)
  • 요철(봉제선·주름)
  • 스탬프용 2D 캔버스
  • 모델 없는 2D 페인트

데코레이션

  • 반짝임·별·하트·꽃·벚꽃·음표·눈 결정·물방울무늬·거품·초승달·마름모·네잎클로버·물방울을 그은 곳에 흩뿌립니다. 크기와 방향이 조금씩 달라집니다.
  • 전경색으로 칠합니다. 3D·UV 위에 커서를 대면 팁 모양이 표시됩니다.

스탬프

  • 도구 속성의 '이미지 가져오기'로 PNG 등을 추가하고 목록에서 선택한 후 3D 위를 누르면 이미지를 붙입니다. 드래그하면 일정 간격으로 연속해서 붙입니다.
  • 도구 속성 맨 위에 현재 이미지의 큰 미리보기·목록·크기·각도가 표시됩니다.
  • 3D·UV 위에 커서를 대면 붙일 이미지가 해당 크기·각도·색·불투명도 그대로 반투명하게 표시됩니다(칠하기 전 미리보기. 텍스처에 적용되지 않음). 움직이는 방향 앞쪽에 다음 이미지 하나도 옅게 표시됩니다.
  • 이미지 색 그대로 붙입니다(투명한 곳은 붙이지 않음). '전경색으로 칠하기'를 켜면 이미지 형태만 사용하여 전경색으로 칠합니다.
  • 크기·불투명도·간격·각도·무작위 회전·크기 변화·흩뿌리기·선 방향으로 회전·필압으로 크기. 가져온 이미지는 다음 실행에도 유지됩니다(최대 60장).
  • 좌우 대칭은 3D·UV 영역 모두 적용됩니다(대칭 쪽 이미지도 거울 방향).

패턴 펜(옷 무늬)

  • 스트라이프·가로 줄무늬·대각선 줄무늬·물방울·작은 물방울·체크무늬·깅엄 체크·타탄 체크·아가일·헤링본·데님(능직)·니트·하트·별·크로스 해치 15종.
  • 무늬 부분만 전경색으로 칠하는 펜입니다. 무늬는 텍스처 위에서 반복되므로 시점을 움직여도 어긋나지 않습니다(UV가 왜곡된 곳은 무늬도 왜곡됨).
  • 도구 속성 맨 위에 패턴 미리보기 목록·'무늬 크기'·'패턴 강도'·명암 반전·적용 방식이 있습니다.
  • 3D·UV 위에 커서를 대면 브러시 원 안에 해당 크기의 무늬가 반투명하게 표시됩니다. '무늬 크기'를 움직이는 동안은 마지막 커서 위치에 큰 원으로 미리보기가 표시됩니다.
  • 같은 패턴을 다른 펜·붓의 '종이 질감' → '무늬'에서도 선택할 수 있습니다.
무늬 각도(모든 버전): 무늬 펜·종이 질감의 무늬를 도구 속성의 “무늬 각도”로 돌릴 수 있습니다(거꾸로·옆으로 놓인 아일랜드에서도 무늬 방향을 맞출 수 있습니다).

요철(봉제선·주름) Pro

  • 봉제선(점선·오목)·봉제선(도톰)·봉합선(홈)·파이핑(볼록)·크로스 스티치·지그재그 봉제·징(리벳)·주름·볼록함 9종.
  • 그리면 레이어 패널의 '노멀 맵' 폴더(없으면 생성)로 이동하여 정해진 높이로 그립니다. 색 레이어에 검은 봉제선이 생기지 않습니다. 높이는 도구 속성에서 바꿀 수 있습니다.
  • 그린 후 3D 뷰 위 중앙의 '◀ 원래 레이어로 돌아가기'로 이동 전 레이어·표시·도구로 돌아갑니다.
  • 요철은 마무리 모습 표시에서 보입니다(잘 보이지 않으면 '머티리얼' 패널의 노멀 맵 강도를 높이세요). 내보내면 노멀 맵 이미지가 됩니다(칠할 대상).

스탬프용 2D 캔버스

스탬프 도구 속성의 '2D 캔버스에서 그리기'를 누르면 스탬프 전용 작업용 텍스처 세트가 열립니다. 3D 뷰가 숨겨지며 정사각형 캔버스를 UV 뷰에서 편집합니다.

  1. 펜·지우개·채우기·그라데이션 등으로 그립니다. 일반 레이어·폴더·선택 범위·실행 취소·다시 실행을 사용할 수 있습니다.
  2. 아래에서 정사각형 해상도를 선택할 수 있습니다(256~4096. Lite는 최대 2048).
  3. '스탬프로 등록'을 누르고 이름을 정합니다. 표시 중인 레이어를 합성한 모습 그대로 스탬프가 됩니다. 모델 편집으로 돌아가 해당 스탬프로 그릴 수 있습니다.
  4. 등록하지 않고 돌아가려면 '모델 편집으로 돌아가기'를 누릅니다. 그린 레이어는 .petanuri 작업 파일에 함께 저장됩니다.
  • 텍스처 세트 패널에 스탬프용 캔버스 편집 중임을 표시합니다. 모델의 메인·서브 지정과 별도로 취급합니다.
  • 이 작업용 세트는 모델 텍스처 세트 목록에 섞지 않으며 모델 텍스처 내보내기에서도 제외합니다.
  • 스탬프의 '이 이미지 다시 그리기' 또는 목록 우클릭 → '2D 캔버스에서 다시 그리기'로 등록한 스탬프도 편집할 수 있습니다. 다시 등록할 때 덮어쓰기 또는 다른 이름으로 등록을 선택합니다.

모델 없는 2D 페인트

시작 화면 '샘플로 해 보기' 아래의 '2D 페인트로 그리기'를 누르고 해상도를 선택합니다. 3D 모델 없이 투명한 바탕의 정사각형 캔버스에 그리는 추가 페인트 모드입니다. '새로 만들기'의 모델 설정에서 선택하는 방식이 아닙니다.

  • 레이어에 그리고 .petanuri로 저장·재개할 수 있습니다.
  • 캔버스 아래 'PNG 내보내기'로 표시 중인 레이어를 합성한 이미지를 저장할 수 있습니다.
  • '스탬프로 등록'도 사용할 수 있습니다. 이 모드에서는 등록 후에도 2D 페인트를 계속할 수 있습니다.
  • Lite는 최대 해상도 2048·바탕 포함 레이어 4장, Standard와 Pro는 최대 해상도 4096입니다.
3D 모델 형태를 사용하는 베이크·포즈·머티리얼 등은 2D 페인트에서 사용하지 않습니다.
