그리기

3D 뷰 위에 펜으로 직접 그립니다. 왼쪽 도구 모음에서 도구를 선택하고 보조 도구와 도구 속성에서 그리기 느낌을 정합니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

먼저 그려 보기

  1. 3D 뷰의 모델 위에서 그리기 시작하면 해당 텍스처 세트(예: body)로 자동 전환한 후 그립니다(오른쪽 텍스처 세트 패널에서 선택해도 됩니다).
  2. 왼쪽 도구 모음에서 펜(P)을 선택하고 보조 도구에서 'G펜' 등을 선택합니다.
  3. 색 패널에서 색을 선택하고 3D 뷰의 모델 위를 그립니다.
  4. 회전은 오른쪽 드래그(펜 사이드 버튼) 또는 Space+ 드래그, 확대는 휠입니다.
모델 위에서 Alt+ 우클릭으로도 해당 세트를 선택할 수 있습니다. 자세한 내용은 텍스처 세트페이지를 참고하세요.

뒷면·가려진 면에도 칠하기

도구 속성에서 불투명도 바로 아래의 '뒷면·가려진 면에도 칠하기'(지우개는 '뒷면·가려진 면도 지우기')는 펜 아래에 보이는 면을 중심으로 브러시 원과 같은 겉보기 크기의 구 안에 있는, 카메라에서 보이지 않는 뒷면·안쪽 면에도 칠합니다. 머리카락 안쪽·겹친 옷·손가락 사이 등 돌아가서 보기 어려운 곳을 한 번에 칠할 수 있습니다.

  • 펜·붓·브러시 모음·지우개·그라데이션은 기본적으로 켜져 있습니다. 끄면 보이는 면에만 칠합니다.
  • 장식·패턴·요철에도 있습니다(기본 꺼짐). 흐리기·손가락·색 혼합·스탬프는 화면에 보이는 색·이미지를 사용하므로 보이는 면에만 적용됩니다.
  • 경도에 따라 가장자리가 흐려집니다. 이미지 팁(연필·분필·스프레이·브러시 모음 다수 등)도 사용할 수 있습니다. '표면을 따라 칠하기'는 면 방향에 맞추고 '화면에 맞추기'는 화면에 보이는 팁 모양을 안쪽으로 투영합니다.
  • 선택 범위·숨긴 면·대칭·투명 픽셀 잠금은 평소대로 적용됩니다. UV 영역에서 칠할 때는 관계없습니다(원래 모든 면에 적용).
두께가 있는 곳을 칠하면 반대쪽까지 닿을 수 있습니다. 브러시 크기에 주의하세요.

브러시 세부 설정

  • 위의 '~' 선은 현재 설정으로 그린 예시입니다. 설정을 바꾸면 즉시 바뀝니다.
  • 크기 기준: 보조 도구별 '설정대로/텍스처로 고정/화면에 따라 가변'. 텍스처로 고정하면 확대·축소해도 텍스처에 같은 굵기로 칠합니다. 설정대로는 파일 → 환경 설정 → 그리기의 '브러시 크기 단위'(화면 px/텍스처 px)를 따릅니다.
  • 브러시 끝: 원·사각형·평붓·연필·분필·스프레이·수채화·모필·반짝임·별·하트와 포함된 팁 31개. '불러오기'로 이미지(흰 바탕에 검게 그린 모양)나 다른 페인트 소프트웨어의 브러시 파일(.abr·.gbr·.gih, 묶은 .zip)도 사용할 수 있습니다.
  • 덧칠: 같은 곳에 겹칠수록 진해집니다(에어브러시용).
  • 렌더링 모드: 곱하기·스크린·오버레이 등 26종으로 칠할 수 있습니다. '뒤에 그리기(아직 칠하지 않은 곳만)'·'밝게'·'어둡게'도 있습니다.
  • 보정 종류: 매끄럽게(늦게 따라옴)/1€(느리게 그릴 때 흔들림을 강하게 억제하고 빠르게 그릴 때 지연 감소)/끈 당기기(펜에서 조금 떨어져 따라옴. 손떨림 제거).
  • 시작·끝: 선의 시작과 끝을 가늘게 합니다. 끝은 펜을 놓을 때 선 마지막을 가늘게 다시 그리므로 그리는 동안 지연이 생기지 않습니다.
  • 움직임: 속도에 따른 굵기·굵기와 농도 변화·눕힘에 따른 굵기와 농도·펜 기울기나 회전에 따른 팁 회전(눕힘·회전은 해당 정보를 보내는 펜만 지원).
  • 필압 곡선: 굵기·농도 각각 점을 움직여 반응을 정합니다.
  • 종이 질감: 칠하는 농도에 종이나 캔버스 결이 더해집니다(포함 6장·패턴 15종·원하는 이미지). 면에 붙으므로 시점을 움직여도 어긋나지 않습니다.
왼쪽 '브러시 크기' 패널에서 자주 쓰는 크기를 한 번에 선택할 수 있습니다. 크기는 원과 숫자의 작은 타일이며 패널을 좁히면 1열까지 줄일 수 있습니다. 마지막 연필 아이콘 또는 우클릭으로 현재 크기를 추가·제거합니다.[ ] 로도 크기를 바꿀 수 있습니다(1~1000).
3D 칠하기 방식: '표면을 따라 칠하기'는 기울어진 면에서도 붓 자국이 덜 늘어나며 v1.1.0에서 미설정 브러시의 기본값입니다. '화면에 맞추기'는 카메라에서 투영하므로 기울어진 면에서 붓 자국이 늘어납니다. 보조 도구별로 선택할 수 있습니다. 저장된 설정은 유지되며 UV 뷰의 그리기 방식은 바뀌지 않습니다.

흐리기·손가락·색 혼합

  • 흐리기: 그은 곳을 매끄럽게 합니다. '흐리기 범위'으로 적용 범위가 바뀝니다.
  • 손가락: 색을 끌어 늘입니다.
  • 색 혼합: 그은 곳의 색을 가져와 전경색과 혼합하며 칠합니다. '물감 양'이 0이면 칠해진 색만 섞습니다. '색 늘이기'를 높이면 길게 늘어납니다.
모두 3D 위에서 계산하므로 UV 이음매에서 끊기지 않습니다. 흐리기·손가락은 UV 영역에서도 사용할 수 있습니다(색 혼합은 3D 영역만).

채우기·그라데이션·도형

  • 아일랜드 칠하기: 누른 UV 아일랜드 전체를 칠합니다.머티리얼 전체: 해당 머티리얼 전체를 칠합니다.
  • 둘러싸인 곳 칠하기: 선으로 둘러싸인 곳을 누르면 해당 아일랜드 안에서 색이 가까운 연결 영역을 칠합니다. 참조(모든 레이어/선택한 레이어)·허용치·'틈 메우기'(끊어진 선에서 멈춤)·'확장'(선 아래까지 확장).
  • 폴리곤 칠하기: 그은 면 전체를 전경색으로 칠합니다.
  • 그라데이션: 3D 뷰에서 시작점부터 끝점까지 드래그합니다. '뒷면·가려진 면에도 칠하기'(기본 켜짐)를 켜면 누른 곳과 놓은 곳을 잇는 3D 선을 따라 뒷면·안쪽 면에도 적용됩니다(머리카락 뿌리부터 끝까지 등).Shift 로 45° 간격.
  • 도형: 직선·사각형·타원·다각형(3~12각)을 채우기 또는 윤곽선으로 그립니다.Shift 로 정사각형·정원, '중심에서 그리기'는 시작점이 중심입니다. 곡선은 드래그 후 놓고 움직여 구부린 다음 다시 눌러 확정합니다. 곡선(점 연결)은 누를 때마다 점을 놓고 더블클릭 또는 Enter 로 확정합니다('닫기'로 고리를 만들어 채울 수 있음).
채색 레이어를 선 레이어 아래에 만들면 선이 깔끔하게 남습니다.

여러 색·투명도를 사용하는 과정은 색과 투명도의 그라데이션을 참고하세요.

색과 투명도의 그라데이션

그라데이션 그리기 도구는 Lite부터 사용할 수 있습니다. 도구 속성의 '색'에서 '색과 불투명도 지점'을 선택하면 두 색뿐 아니라 색과 투명도를 조합한 그라데이션으로 그릴 수 있습니다. '전경색→배경색'·'전경색→투명'도 선택할 수 있습니다.

  1. 프리셋을 선택하거나 바의 빈 곳을 클릭하여 색 점을 추가합니다. 점은 2~32개입니다.
  2. 점을 선택하여 색·위치·불투명도를 바꿉니다. 위치는 드래그로도 바꿀 수 있습니다. 선택한 점을 다시 탭하거나 더블클릭하면 색을 선택할 수 있습니다.
  3. 불필요한 점은 '정지점 삭제'· Delete·바 밖으로 끌어내기로 지웁니다. '전경색 넣기'·'균등하게 배치'·'좌우 바꾸기'도 사용할 수 있습니다.
  4. 프리셋 240종을 그룹과 이름으로 찾을 수 있습니다. 투명색을 포함한 프리셋도 있습니다. 목록은 스크롤할 수 있습니다. 이름을 정하고 '현재 것 저장'으로 나만의 프리셋을 남길 수 있습니다.
  5. 선형 또는 원형을 선택하고 3D 뷰나 UV 위에서 시작점부터 끝점까지 드래그하여 그립니다.
그라데이션 불투명도가 0인 부분은 아래 색이 유지됩니다. 이미 그린 색을 지우려면 투명색으로 그리기을 사용합니다. 모델 전체를 높이나 점과의 거리로 칠하려면 Pro의 그라데이션 베이크가 편리합니다.

색 선택·스포이트

  • 색패널: 위 버튼으로 색 선택 방식 5종을 전환합니다(링 + 사각형·링 + 삼각형·사각형 + 색상 바·원판 + 명도 바·슬라이더).
  • 색 값패널: 전경색/배경색·HEX·화면에서 색 가져오기·RGB/HSV 값·불투명도.
  • 최근 사용한 색: 실제 칠한 색·가져온 색 12개입니다. 누르면 전경색이 됩니다.
  • X 로 전경색과 배경색을 바꿉니다.
  • 스포이트：Alt 를 누르는 동안 어느 도구에서든 스포이트가 됩니다.
  • 화면에서 색 가져오기(Shift＋I): 창 밖을 포함하여 화면 어디에서든 색을 가져올 수 있습니다.
  • 컬러 세트: 견본을 탭하면 전경색이 됩니다. '+현재 전경색'으로 추가하고 드래그로 재정렬합니다. 견본 삭제는 실행 취소할 수 있습니다. .gpl 팔레트도 읽고 쓸 수 있습니다.
  • 참고 이미지: 열기·드롭·붙여넣기(Ctrl＋V)로 표시하고 스포이트로 색을 가져올 수 있습니다. 위 돋보기로 확대·축소, '100%'로 실제 크기, 모서리 표시로 전체 보기를 합니다(펜만으로도 사용 가능).

투명색으로 그리기 (같은 브러시로 지우기)

색 값 패널의 체크무늬 버튼 또는 C 로 투명색으로 전환합니다. 펜·붓·브러시 모음 등의 브러시로 팁 모양·경도·필압·흐름을 살리면서 선택한 그리기 레이어의 색을 지울 수 있습니다.

다시 C 를 누르거나 일반 전경색을 선택하면 돌아갑니다. 투명 픽셀을 잠근 레이어는 지울 수 없으므로 지우려면 투명 픽셀 잠금을 해제합니다.

투명색은 브러시로 지우기 위한 전환입니다. 모든 도구를 지우기로 바꾸는 기능은 아닙니다.

좌우 대칭 그리기

  1. 3D 뷰 왼쪽 위의 X(좌우)를 누릅니다(M 키도 가능).
  2. 그대로 그리면 반대쪽에도 같은 내용이 적용됩니다.
  • Y(앞뒤)·Z(위아래)도 여러 축을 동시에 사용할 수 있습니다(X와 Z는 4곳에 적용).
  • ▼에서 대칭 중심을 '모델 중심'·'원점'·'지정' 중 선택합니다. '지정'은 수치(cm) 입력 또는 '모델 위를 눌러서 정하기'으로 정합니다. '정점에 맞추기'는 누른 곳에 가장 가까운 버텍스 위치가 됩니다. 3D 우클릭 → '대칭으로 그리기' → '여기를 대칭 중심으로'로도 정할 수 있습니다.
  • '모델 중심'의 좌우는 형태가 가장 좌우 대칭인 위치입니다(한쪽에만 장식이나 소품이 있어도 몸 중앙).
  • ▼의 '대칭 상대를 찾는 범위'(0~3%, 기본 1%): 좌우 모양이 조금 다른 옷 등에서 반사된 위치에 면이 없으면 이 범위의 가장 가까운 면을 반대쪽으로 칠합니다.
  • 도구 속성 맨 위 와 UV 영역 제목 에도 '대칭 X·Y·Z'가 있습니다(3D 왼쪽 위와 같은 전환). 대칭이 적용되지 않는 도구는 대칭 항목이 없으며 3D 왼쪽 위 X·Y·Z에 사선이 표시됩니다. 색 혼합처럼 UV 영역에서만 적용되지 않는 도구는 이유가 표시됩니다.

팝업 팔레트(펜만으로 사용)

  • 3D·UV 위에서 펜 사이드 버튼을 누르고 움직이지 않고 놓으면 그 자리에 원형 팔레트가 표시됩니다(드래그하면 기존처럼 회전).
  • 바깥쪽: 자주 쓰는 보조 도구('+'로 현재 보조 도구 추가, 길게 누르기·우클릭으로 제거. 최대 10개). 안쪽: 색상 링과 사각형으로 전경색, 위 작은 원은 최근 사용한 색, 아래 표시를 위아래로 드래그하여 브러시 크기 조정.
  • 팔레트 밖 누르기· Esc 로 닫습니다. 마우스로 사용할 때는 파일 → 환경 설정 → 조작의 '오른쪽 클릭'을 팝업 팔레트로 설정합니다(우클릭 메뉴 맨 위 '팝업 팔레트 표시'로도 표시 가능).
