그리기

3D 모델 위에 펜으로 직접 그립니다. 도구 선택 방법, 그리는 느낌 정하기, 색 고르는 법, 채우기·그라데이션·도형, 좌우 대칭으로 그리기까지 정리했습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

먼저 이것만
  1. 왼쪽 도구 모음에서 펜(P)을 누르고, 보조 도구에서 "G펜"을 선택합니다(자세히).
  2. 색 패널에서 색을 고르고 3D 뷰의 모델 위를 따라 그립니다. 그리기 시작한 곳의 텍스처 세트로 자동 전환됩니다(자세히).
  3. 굵기는 [ ]나 왼쪽의 브러시 크기 패널에서 바꿉니다(자세히).
  4. 지울 때는 지우개(E)를 쓰거나, C로 투명색으로 바꿔 같은 브러시로 지웁니다(자세히).
  5. 좌우에 똑같이 그릴 때는 3D 뷰 왼쪽 위의 "X"를 누릅니다(M) (자세히).

첫 번째 선 그리기

모델을 열면 바로 그릴 수 있습니다. 그리기 전에 텍스처 세트를 선택하지 않아도, 그리기 시작한 곳의 텍스처 세트(예: body)로 자동 전환됩니다.

  1. 왼쪽 도구 모음에서 "펜"을 누릅니다(P).
  2. 보조 도구 패널에서 "G펜"을 선택합니다.
  3. 색 패널에서 전경색을 선택합니다.
  4. 3D 뷰의 모델 위를 따라 그립니다. 그은 곳에 선이 들어갑니다.
  5. 돌릴 때는 오른쪽 드래그(펜의 사이드 버튼) 또는 Space+드래그, 가까이 갈 때는 휠을 사용합니다.
  6. 잘못 그렸다면 Ctrl+Z로 한 획씩 되돌립니다.

그릴 때 쓸 수 있는 조작

  • Shift+클릭: 앞에 그린 선이 끝난 곳에서 곧은 선을 긋습니다.
  • Ctrl+Alt+좌우로 드래그: 브러시 크기를 바꿉니다.
  • Ctrl+오른쪽 드래그(펜의 사이드 버튼): 좌우로 브러시 크기, 상하로 경도를 바꿉니다. Ctrl+펜 끝 드래그는 좌우로 불투명도, 상하로 브러시 끝의 각도입니다.
  • 펜의 지우개 쪽으로 그으면 지우개로 지울 수 있습니다.
  • 모델 위에서 Alt+오른쪽 클릭하면 그곳의 텍스처 세트를 선택할 수 있습니다(텍스처 세트 선택하기).
  • UV 뷰 위에서도 같은 도구로 그릴 수 있습니다(UV와 표시 범위).

카메라 조작 방식과 다른 키는 펜·마우스 조작을 보세요.

잘 안 될 때

  • 그어도 색이 칠해지지 않음: 화면 아래쪽 띠에 이유가 표시됩니다. 숨긴 레이어·잠긴 레이어·폴더에는 그릴 수 없습니다. 레이어 패널에서 그릴 수 있는 레이어를 선택하세요(레이어).
  • 일부에만 색이 칠해지지 않음: 선택 범위 바깥과 숨긴 부분에는 그릴 수 없습니다. 투명 픽셀 잠금을 켠 레이어에서는 투명한 곳에 그릴 수 없습니다.
  • 다른 텍스처 세트 위에서 그려지지 않음: "그리기 시작한 곳의 세트로 자동 전환"이 꺼져 있습니다. 3D 뷰에서 오른쪽 클릭 → "그리기 시작한 곳의 세트로 자동 전환"을 켭니다. 선택 범위가 있을 때는 선택되지 않은 세트에는 그릴 수 없습니다.
  • 필압으로 굵기가 변하지 않음: 도구 속성의 "필압으로 크기"가 켜져 있는지 확인하세요. 켜져 있는데도 변하지 않으면 필압이 작동하지 않을 때를 보세요.

보조 도구 늘리기·순서 바꾸기·키 지정하기

도구 속성의 값은 보조 도구별로 기억합니다. 같은 펜을 굵기만 다르게 쓰려면 복제해서 다른 이름을 붙이세요.

  • 보조 도구 목록 아래의 아이콘으로 왼쪽부터 "복제" "이름" "삭제" "초기화" "내보내기" "모두 내보내기" "가져오기"를 할 수 있습니다. 오른쪽 클릭으로도 같습니다.
  • 이름은 더블클릭으로도 바꿀 수 있습니다. 순서는 드래그로 바꿉니다(펜으로도 그대로 움직일 수 있습니다).
  • 목록 위쪽의 "소 중 대"로 타일 크기를 바꿉니다. 작게 하면 아래의 도구 속성이 넓게 보입니다.
  • 도구 모음의 버튼이나 보조 도구 타일을 오른쪽 클릭 → "키 할당"으로 원하는 키를 지정할 수 있습니다. 같은 키를 여러 보조 도구에 지정할 때는 "함께 사용(누를 때마다 전환)"을 선택하면, 누를 때마다 다음 보조 도구로 넘어갑니다.
  • Standard "내보내기" "모두 내보내기" "가져오기"로 브러시 설정을 .petabrush 파일로 주고받을 수 있습니다. 가져온 브러시 끝 이미지도 함께 들어갑니다. .petabrush는 창에 끌어다 놓아도 가져올 수 있습니다.
보조 도구 삭제는 실행 취소할 수 없습니다. Standard 이상이라면 먼저 "내보내기"로 남겨 둘 수 있습니다.

다른 페인트 소프트웨어의 브러시 불러오기

  1. 보조 도구 목록 아래의 "가져오기"를 누릅니다.
  2. .abr·.gbr·.gih·.sut·이미지(PNG 등)·이를 묶은 .zip을 선택합니다. 몇 개든 선택할 수 있습니다.
  3. 브러시 끝을 사용하는 보조 도구가 추가되고 선택됩니다. 그대로 그릴 수 있습니다.
  • 보조 도구 패널에 끌어다 놓아도 가져올 수 있습니다. 이미지를 3D·UV 뷰에 끌어다 놓았을 때는 브러시가 아니라 이미지로 처리합니다.
  • 가져오는 것은 브러시 끝의 모양과 이름·초기 크기, 가져올 수 있을 때는 간격과 안티에일리어싱입니다. 원래 소프트웨어의 그리는 느낌·혼색·색은 이어받지 않으므로 도구 속성에서 다듬으세요.
  • .abr은 버전 1·2·6의 이미지 브러시 끝, .gbr은 버전 1·2를 지원합니다. .gih는 128프레임까지 무작위로 사용합니다. .sut는 안에 든 이미지로 브러시 끝을 만듭니다(축소 이미지 등이 들어 있는 경우가 있습니다).
  • 파일 하나당 64MB까지, .zip은 512개 파일·압축 해제 후 64MB까지입니다. 읽을 수 없는 형식은 이유가 표시됩니다.
  • 어느 에디션에서든 가져올 수 있습니다. 가져온 브러시 끝과 보조 도구는 다음 실행 때도 남아 있습니다.

뒷면·가려진 면에도 칠하기

머리카락 안쪽·옷이 겹친 곳·손가락 사이 등 돌아가서 보기 어려운 곳을 한 번에 칠합니다. 도구 속성의 불투명도 바로 아래에 있는 "뒷면·가려진 면에도 칠하기"(지우개는 "뒷면·가려진 면도 지우기")로 켜고 끕니다.

  • 펜 끝 아래에 보이는 면을 중심으로, 브러시 원과 겉보기 크기가 같은 구 안에서, 카메라에서 보이지 않는 뒷면·안쪽 면에도 칠합니다.
  • 펜·붓·브러시 모음·지우개·그라데이션은 처음부터 켜져 있습니다. 데코레이션·무늬·스티치는 처음에는 꺼져 있습니다. 끄면 보이는 면에만 칠합니다.
  • 흐리기·손가락·색 혼합·스탬프에는 없습니다(화면에 비친 색·이미지를 사용하기 때문). UV 뷰에서는 관계없습니다(원래 모든 면에 칠해집니다).
  • 경도로 가장자리가 흐려집니다. 이미지 브러시 끝은 화면에 보이는 모양 그대로 안쪽으로 붙습니다.
  • 선택 범위·숨긴 부분·대칭·투명 픽셀 잠금은 평소처럼 적용됩니다.
두께가 있는 곳을 칠하면 반대쪽까지 닿습니다. 브러시를 작게 하거나, 기능을 꺼서 보이는 면에만 칠하세요.

표시의 "단면"·"양면"과의 차이

3D 뷰 왼쪽 위의 "단면" "양면"은 표시 전환입니다. "양면"으로 하면 뒤집힌 면도 표시되고, 보이는 뒷면에도 칠할 수 있습니다. 카메라에서 보이지 않는 면까지 칠하는 것은 "뒷면·가려진 면에도 칠하기"입니다(3D 뷰의 네 모서리).

색 선택·스포이트

그리는 색(전경색)은 색 패널·색 값 패널·최근 사용한 색·컬러 세트에서 선택합니다. 어느 것으로 선택해도 같은 전경색이 됩니다.

  • 색: 위쪽 버튼으로 선택 방식을 전환합니다. "링＋사각형" "링＋삼각형" "사각형＋색상 막대" "원판＋명도 막대" "슬라이더(RGB, HSV)"의 5가지입니다.
  • 색 값: 전경색과 배경색·HEX·화면에서 색 가져오기·RGB/HSV 숫자·불투명도. 오른쪽의 ▾로 숫자를 펼치고 ▴로 작게 접습니다.
  • 최근 사용한 색: 실제로 칠한 색·가져온 색 12개(최신순). 누르면 전경색이 됩니다.
  • 색 선택 방식 아래에 RGB/HSV 슬라이더를 표시했을 때는 "RGB" "HSV" 버튼으로 전환합니다. 선택한 형식은 다음 실행 때도 남습니다.

전경색과 배경색

  • X(또는 ⇄)로 전경색과 배경색을 서로 바꿉니다.
  • D(두 사각형의 왼쪽 아래 작은 버튼으로도)로 전경색을 검정, 배경색을 흰색으로 되돌립니다.
  • Alt+Backspace로 전경색, Ctrl+Backspace로 배경색으로 채웁니다. 선택 범위가 있으면 그 안을, 없으면 선택한 레이어의 전체를 채웁니다.

스포이트로 색 가져오기

  • 스포이트(I)로 누른 곳의 색을 가져옵니다. 보조 도구는 "표시 색 가져오기"(보이는 색)와 "레이어에서 가져오기"(선택한 레이어의 색)입니다.
  • Alt를 누르고 있는 동안은 어느 도구에서든 스포이트가 됩니다. 카메라 조작이 Alt + 마우스 버튼 방식일 때는 3D 뷰에서 I를 사용합니다.
  • 3D 뷰에서 오른쪽 클릭 → "여기 색 가져오기"로도 가져올 수 있습니다.
  • "평균 범위"를 올리면 주변 색의 평균을 가져옵니다.
  • 스포이트를 쓰는 동안은 커서 위치에 둥근 확대경이 표시됩니다. 가운데 틀이 가져올 위치이고, 바깥쪽 링이 가져올 색입니다. 도구 속성의 "확대경 표시"로 끌 수 있습니다.
  • 카메라 조작이 Alt + 마우스 버튼·Unity 방식일 때는 3D 위에서 Alt를 눌러도 확대경이 표시되지 않습니다(I 키 스포이트에서는 표시됩니다. UV 영역에서는 Alt로도 표시됩니다).

화면 어디에서든 색 가져오기

  1. 색 값 패널의 스포이트 아이콘을 누릅니다(Shift+I). 확대 화면과 색 값 돋보기가 표시됩니다.
  2. 가져올 곳을 클릭합니다. 창 바깥에서도 가져올 수 있습니다. Enter·Space로도 가져올 수 있습니다.
  • 화살표 키로 1화소씩(Shift를 누르면 10화소씩) 움직일 수 있습니다. Esc·오른쪽 클릭으로 취소합니다.
  • 시작했을 때의 화면을 캡처해서 색을 가져오므로, 동영상 등은 멈춰 보입니다.

컬러 세트

  • 견본을 누르면 전경색이 됩니다. "+현재 전경색"으로 추가하고, 드래그로 순서를 바꾸고, 더블클릭으로 견본에 이름을 붙입니다.
  • "바꾸기" "삭제"는 선택한 견본에 적용됩니다. 견본 삭제는 Ctrl+Z로 되돌릴 수 있습니다. "소" "중" "대"로 견본 크기를 바꿉니다.
  • "…"로 세트의 새로 만들기·복제·이름·삭제, 내보내기(JSON/.gpl 팔레트), 가져오기를 할 수 있습니다. .gpl은 창의 어디에 끌어다 놓아도 가져옵니다.
  • Space를 누른 채 드래그하면 목록을 스크롤할 수 있습니다(펜용).

참고 이미지에서 색 가져오기

  • 참고 이미지 패널에서 "열기", 패널에 끌어다 놓기, 패널을 누른 뒤 Ctrl+V 중 하나로 이미지를 표시합니다.
  • 이미지를 클릭하거나 드래그하면 그 색을 가져옵니다. 떼면 최근 사용한 색에 들어갑니다.
  • 위쪽 돋보기로 확대·축소하고, "100%"로 실제 크기, 네 모서리 아이콘으로 전체에 맞춥니다. 펜만으로도 조작할 수 있습니다.
  • 표시한 이미지는 다음 실행 때도 복원됩니다.

투명색으로 그리기(같은 브러시로 지우기)

색 값 패널의 체크무늬 버튼이나 C로 전경색을 투명색으로 바꿉니다. 펜·붓·브러시 모음 등의 브러시 끝·경도·필압 그대로, 현재 레이어의 색을 지울 수 있습니다.

  • 되돌릴 때는 C나 체크무늬 버튼을 한 번 더 누릅니다. 전경색 사각형을 누르거나 색을 선택해도 돌아옵니다.
  • 채우기(아일랜드 칠하기·머티리얼 전체·둘러싸인 곳 칠하기)·폴리곤 칠하기·도형도 투명색이면 칠하는 곳을 지웁니다.
  • 그라데이션은 전경색 쪽일수록 강하게 지웁니다.
  • 스탬프는 투명색으로 해도 지우지 않습니다.
투명 픽셀 잠금을 켠 레이어에서는 지울 수 없습니다. 지울 때는 먼저 투명 픽셀 잠금을 해제하세요.

좌우 대칭으로 그리기

한쪽에 그리면 반대쪽에도 똑같이 들어갑니다. 얼굴이나 옷의 좌우처럼 같은 모양을 양쪽에 그릴 때 사용합니다.

  1. 3D 뷰 왼쪽 위의 "X"(좌우)를 누릅니다(M).
  2. 모델의 한쪽에 그립니다. 반대쪽에도 똑같이 들어갑니다.
  • "Y"(앞뒤)·"Z"(위아래)도 몇 개든 동시에 쓸 수 있습니다(X와 Z라면 4곳에 들어갑니다).
  • 편집 메뉴나 3D 뷰의 오른쪽 클릭 → "대칭으로 그리기"로도 전환할 수 있습니다.
  • 도구 속성 맨 위와 UV 뷰의 제목 줄에도 "대칭 X·Y·Z"가 있습니다(3D 뷰 왼쪽 위와 같은 전환입니다).
  • 실행 취소는 반대쪽 몫까지 합쳐서 한 번입니다.

접는 중심 정하기

X·Y·Z 옆의 ▼에서 접는 중심을 "모델 중심" "원점" "지정" 중에서 선택합니다. 의상만 있는 FBX 등에서 중심이 몸의 한가운데에서 어긋날 때 사용합니다.

  • 모델 중심: 좌우는 형태가 가장 좌우 대칭이 되는 곳입니다. 한쪽에만 장식이나 소품이 있어도 몸의 한가운데가 됩니다.
  • 원점: 좌표의 원점에서 접습니다.
  • 지정: 중심을 X·Y·Z의 cm로 입력하거나, "모델 위를 눌러서 정하기"로 누른 곳으로 합니다. "정점에 맞추기"(처음에는 켜짐)를 켜면, 누른 곳에서 가장 가까운 정점의 위치가 됩니다.
  • 3D 뷰의 오른쪽 클릭 → "대칭으로 그리기" → "여기를 대칭 중심으로"로도 정할 수 있습니다.
  • 정하면 대칭 면이 3D에 2초 정도 반투명으로 표시됩니다. 지정한 위치는 작업 파일에 남습니다.

  • 한쪽을 숨기면 반대쪽에 들어가지 않음: ▼의 "숨긴 쪽에도 대칭 그리기(3D 브러시)"를 켭니다.
  • UV 뷰에서 그리면 반대쪽에 들어가지 않음: 반대쪽이 다른 텍스처 세트(머티리얼)에 있으면 UV 뷰에서는 들어가지 않습니다. 3D 뷰에서 그리세요.
  • X·Y·Z에 빗금이 붙어 있음: 현재 도구에서는 대칭이 적용되지 않습니다(어떤 도구에서 적용되는지).

  • 흐리기·손가락은 UV 뷰에서도 쓸 수 있습니다. 색 혼합은 3D 뷰에서만 쓸 수 있습니다.

선으로 둘러싸인 곳 칠하기

  1. 선화 레이어 아래에 칠하는 용도의 레이어를 만들어 선택합니다.
  2. 채우기의 보조 도구 "둘러싸인 곳 칠하기"를 선택합니다.
  3. 도구 속성의 "참조"를 "모든 레이어"로 합니다(선을 다른 레이어에 그렸을 때).
  4. 칠하고 싶은 곳을 누릅니다. 선에서 멈추어 전경색으로 칠해집니다.
설정내용
참조"모든 레이어"나 "선택한 레이어"의 그림에서 멈출 선을 찾습니다
허용 오차어디까지의 색 차이를 같은 색으로 볼지

올가미로 둘러싸 칠하기

3D·UV 뷰·2D 캔버스 위를 드래그로 둘러싸면, 둘러싼 곳을 전경색으로 칠합니다. 현재 선택 범위는 그대로 남고, 실행 취소 한 번으로 되돌립니다.

3D 뷰에서 다른 텍스처 세트 위를 둘러쌌을 때는, 둘러싼 곳에 가장 많이 비친 세트로 이동한 뒤에 칠합니다.

면별로 칠하기(폴리곤 칠하기)

문지른 면을 통째로 전경색으로 칠합니다. 인식 범위는 펜 끝 원의 크기입니다. "사각형 단위로 칠하기 (삼각형 2개를 1면으로)"를 끄면 삼각형별로 칠합니다.

3D 뷰 왼쪽 위의 "메시 선"을 표시하면 면의 구분이 보입니다(메시 선).

잘 안 될 때

  • 선 바깥까지 칠해짐: 선에 끊어진 곳이 있습니다. "틈 메우기"를 올립니다.
  • 선 가장자리에 흰 틈이 남음: "확장/축소"를 +로 합니다.
  • 다른 레이어의 선에서 멈추지 않음: "참조"를 "모든 레이어"로 합니다.
  • 선이 가늘어지거나 끊김: 선과 같은 레이어에 칠하면 "확장/축소"만큼 선 위까지 칠해집니다. Ctrl+Z로 되돌리고, 선 아래에 칠하는 용도의 레이어를 만든 뒤에 칠하세요.

그라데이션으로 칠하기

색이 변해 가도록 칠합니다. 3D 뷰 위에서 시작점에서 끝점까지 드래그합니다.

  1. 도구 모음의 "그라데이션"을 누릅니다.
  2. 보조 도구를 선택합니다("색과 불투명도" "전경색→배경색" "전경색→투명" "원형(전경색→투명)").
  3. 도구 속성의 "도형"에서 "선형" 또는 "원형"을 선택합니다.
  4. 3D 뷰에서 시작점에서 끝점까지 드래그합니다. 떼면 칠해집니다.
  • 선형은 시작점에서 끝점 방향, 원형은 시작점이 중심이고 드래그한 길이가 반지름입니다. Shift를 누르면서 하면 45° 단위가 됩니다.
  • "뒷면·가려진 면에도 칠하기"(처음에는 켜짐)이면, 누른 곳과 뗀 곳을 잇는 3D 선을 따라 뒷면·안쪽 면에도 붙습니다(머리카락 뿌리에서 끝으로 등). 끄면 보이는 면에만 칠합니다.
  • 칠하는 대상은 선택한 텍스처 세트의 선택한 레이어입니다. 선택 범위 바깥과 숨긴 부분은 바뀌지 않습니다.
  • UV 뷰 위에서도 드래그로 그릴 수 있습니다.

색과 불투명도 지점으로 만들기

도구 속성의 "색"을 "색과 불투명도 지점"으로 하면, 여러 개의 색과 불투명도를 나열한 그라데이션으로 칠할 수 있습니다.

  1. 막대의 빈 곳을 눌러 색 지점을 추가합니다(2~32개).
  2. 지점을 선택하고 위치와 불투명도를 바꿉니다. 위치는 지점을 드래그해서도 바꿀 수 있습니다.
  3. 선택한 지점을 한 번 더 누르거나 더블클릭해서 색을 선택합니다.
  • 지점은 "정지점 삭제"·Delete·막대에서 아래로 끌어내기로 삭제합니다. "전경색 넣기" "균등하게 배치" "좌우 바꾸기"도 사용할 수 있습니다.
  • "프리셋 ▾"에서 240종류의 프리셋 중에서 선택할 수 있습니다(투명이 들어간 것도 있습니다). 그룹과 이름으로 찾을 수 있습니다.
  • "현재 것 저장"으로 나만의 프리셋("내 프리셋")에 남길 수 있습니다.
  • 불투명도를 0으로 한 곳은 아래의 색이 남습니다. 그린 색을 지울 때는 투명색을 사용합니다.
높이나 면의 방향을 따르는 음영을 새 레이어에 굽고 싶을 때는 Pro의 그라데이션 베이크가 편리합니다.

3D 공간의 한 점에서 퍼뜨리기

모델의 면이나 모델 바깥의 공간에 중심을 두고, 거기서부터의 3D 거리로 색을 퍼뜨립니다. 시점을 움직여도 색은 변하지 않습니다.

  1. 칠할 레이어를 선택합니다.
  2. 그라데이션의 도구 속성에서 "3D 공간의 점에서 칠하기"를 누릅니다. "3D 공간 그라데이션" 창이 열립니다.
  3. 3D 뷰에서 모델의 면이나 빈 곳을 눌러 중심을 둡니다.
  4. "퍼지는 거리"와, 색과 불투명도 지점·프리셋으로 색이 퍼지는 모습을 정합니다. 선택한 레이어에 바로 반영됩니다.
  5. "레이어에 칠하기"를 눌러 확정합니다.
  • 확정한 뒤에는 실행 취소 한 번으로 되돌릴 수 있습니다. 취소하면 레이어는 원래 그림으로 돌아갑니다.
  • 3D 모델용 조작입니다. 2D 캔버스에서는 보통의 드래그로 그립니다.

중심 옮기기·퍼지는 거리 정하기

  • 중심은 화살표·평면·가운데 손잡이를 드래그하거나, X·Y·Z 좌표를 입력해서 움직입니다.
  • "3D 뷰에서 중심 지정"으로 다시 두고, "중심 지우기"로 지웁니다. 점을 두는 도중에는 Esc로 취소합니다.
  • 공간에 둘 때는 현재 중심(아직 없으면 모델의 중심)과 같은 깊이에 둡니다.
  • "퍼지는 거리"는 모델 높이에 대한 비율(%)입니다.
  • 선택 범위·숨긴 부분·투명 픽셀 잠금·마스크를 지킵니다.

도형 그리기

도형 도구로 직선·사각형·타원·다각형·곡선을 전경색으로 그립니다. 3D 뷰에서도 UV 뷰에서도 그릴 수 있습니다.

  1. 도구 모음의 "도형"을 누르고, 보조 도구에서 모양을 선택합니다.
  2. 3D 뷰에서 시작점에서 끝점까지 드래그합니다.
  3. 떼면 전경색으로 그려집니다.
보조 도구그리는 방법
직선드래그한 2점을 잇습니다. Shift로 45° 단위
사각형·타원·다각형안을 칠합니다. Shift로 정사각형·정원·찌그러지지 않는 정다각형
직사각형(테두리)·타원(테두리)·다각형(테두리)윤곽만 그립니다
곡선드래그해서 뗀 뒤 마우스를 움직이면 휘어집니다. 한 번 더 누르거나 Enter로 확정합니다
곡선(점 잇기)누를 때마다 점을 찍고(24개까지), 점을 지나는 매끄러운 선으로 만듭니다. 더블클릭이나 Enter로 확정하고, Backspace로 하나 되돌립니다
  • "중심에서 그리기"를 켜면 시작점이 중심이 됩니다.
  • 다각형의 "꼭짓점 수"는 3~12입니다. 위쪽이 꼭짓점이고, 짝수면 위아래가 평평합니다.
  • 곡선(점 잇기)에서 "닫기(고리로 만들기)"를 켜면 고리가 되고, "채색 방식"을 "칠"로 하면 안쪽을 칠할 수 있습니다. 자유로운 모양의 채우기에 쓸 수 있습니다.
  • "선 굵기"는 브러시 크기와 연동됩니다(상한 500). 브러시 크기 목록·[ ]·팝업 팔레트로 바꿔도 같습니다. 도형 보조 도구별로 남으며, 펜의 크기는 바뀌지 않습니다.
  • 도구 속성에서 브러시 끝 이미지를 선택하면, 도형의 윤곽을 따라 늘어놓아 그립니다(스티치·레이스 등). "원형"을 선택하면 보통의 선으로 돌아갑니다.
  • 보이는 면에만 붙고, 실행 취소 한 번 분량입니다. 그리는 도중에는 Esc로 취소합니다.

펜만으로 색과 크기 바꾸기(팝업 팔레트)

펜의 사이드 버튼을 펜을 움직이지 않고 눌렀다 떼면, 그 자리에 둥근 팔레트가 나타납니다. 자주 쓰는 보조 도구·전경색·브러시 크기를 펜을 든 채로 선택할 수 있습니다.

표시하는 법·각 부분의 사용법·마우스로 표시하는 설정은 팝업 팔레트에 정리했습니다.
