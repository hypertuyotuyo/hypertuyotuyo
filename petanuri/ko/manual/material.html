마무리 모습과 lilToon 머티리얼 Pro

lilToon과 같은 계산의 모습(그림자·매트캡·림 라이트·윤곽선 등)을 확인하며 칠하고 설정과 함께 머티리얼로 내보낼 수 있습니다. 이 페이지의 기능은 Pro에서 사용할 수 있습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

Lite·Standard·Pro와 Pro 업그레이드를 BOOTH에서 배포하고 있습니다.

'마무리 모습(lilToon)'은 β 버전입니다. lilToon(2.3 계열)과 같은 계산으로 표시하지만 Unity 안의 모습과 조금 다를 수 있습니다.

'마무리 모습'으로 보기

  • 3D 뷰 왼쪽 위 표시 방식 아이콘 4개의 오른쪽 끝(우클릭 → 보기)에서 '마무리 모습'으로 설정합니다.
  • 그림자(그림자 색 1·그림자 색 2·경계 색)·노멀 맵·매트캡·매트캡 2nd·림 라이트·역광 라이트·림 셰이드·발광·윤곽선을 lilToon(2.3 계열)과 같은 계산으로 표시합니다.
  • 빛 방향은 표시 방식의 ▼ 또는 '머티리얼' 패널의 '표시와 빛'에서 설정합니다. '카메라를 따라가는 빛'은 시점을 돌려도 빛이 같게 비추어 칠하기 쉬워집니다.
  • '머티리얼' 패널 항목 이름은 lilToon 설정 화면 명칭에 맞췄습니다. '다른 머티리얼에도 복사'로 모두 같은 설정을 적용할 수 있습니다.
MToon 완성 모습 미리보기(Pro·베타): 재질 → 표시와 조명에서 MToon을 선택합니다. VRM0/VRM1에서 읽은 그림자·림·발광·윤곽선 등을 참고해 그릴 수 있습니다. 조정은 실행 취소·다시 실행이 가능하며 작업 파일에도 저장됩니다.
그리는 동안 모습을 확인하는 기능입니다. MToon 재질의 완전한 왕복 출력은 지원하지 않으며 PNG/PSD와 기존 lilToon 재질 출력은 그대로입니다. UV 애니메이션은 정지 표시하고 지원하지 않는 UV 설정은 이유를 알린 뒤 일반 표시로 돌아갑니다.
lilToon 설정 추가(Pro): 림라이트의 “빛 방향 영향도”(직접광·간접광), 윤곽선의 “하이라이트”“빛 밝기 반영”, 광택 설정(매끄러움·금속도·반사율·리얼/툰 광택·환경광 반사·큐브맵), 글리터 모양, 매트캡의 “커스텀 노멀 맵”“노멀 맵 강도”, 색조 보정의 그라데이션 맵, 발광 그라데이션, 이방성 반사, 디더, 디졸브, 시차, AudioLink를 lilToon과 같은 계산으로 보여 줍니다.
소리나 시간으로 바뀌는 것은 “소리 강도(이 표시 전용)”“표시 시각” 값으로 멈춰서 보여 줍니다(내보내기에는 들어가지 않습니다). 윤곽선 방향·메인 컬러 2nd/3rd의 디졸브 등 표시에 들어가지 않는 설정도 값과 이미지를 .mat에 읽고 씁니다.

그림자 색·마스크 등 칠하기(칠할 대상)

  1. 패널의 '칠하기:' 버튼(우클릭 → 칠할 대상도 가능)으로 칠할 대상을 선택합니다.
  2. 레이어 패널의 메인 컬러 위에 칠할 대상 폴더(예: '그림자 색 1')가 생성되고 안의 레이어가 선택됩니다. 안에서는 일반 레이어처럼 추가·삭제·겹치기·마스크·클리핑을 사용할 수 있습니다.
  3. 평소의 펜·붓·채우기·그라데이션·흐리기·필터로 그대로 칠합니다.
  4. 위 중앙 '컬러로 돌아가기'(또는 폴더 밖 레이어 누르기)로 일반 색 채색으로 돌아갑니다.
칠할 대상어떻게 적용되나요?
그림자 색 1·그림자 색 2칠한 곳의 그림자가 해당 색이 됩니다(피부 붉은 기·머리카락 그림자 푸른 기 등)
그림자 마스크흰색 = 그림자 적용·검은색 = 그림자 미적용
그림자 AO검을수록 그림자가 나타나기 쉬움(목 주변·머리카락 안쪽·겹친 옷)
노멀 맵높이로 칠합니다. 흰색으로 볼록하게·검은색으로 파기(옷 주름·봉제선·머리카락 결에 사용.요철도구도 가능)
매트캡 마스크·윤곽선 폭흰색 = 적용·검은색 = 미적용
림 라이트 색·발광 텍스처칠한 색을 곱하기/칠한 곳만 칠한 색으로 발광
  • 그 외에도 그림자 색 3·그림자 흐리기 마스크·색조 보정 마스크·알파 마스크·발광 마스크·발광 2nd·역광 라이트 색·림 셰이드 마스크·윤곽선 색·노멀 맵 2nd 마스크·글리터 색을 칠할 수 있습니다(우클릭 → 칠할 대상 → 기타 마스크).
  • 밝기만 읽는 칠할 대상은 위 중앙 흰색·회색·검은색으로 전환할 수 있습니다. '이것만 보기'로 해당 대상 그림만 표시합니다. '삭제'로 칠하지 않은 상태로 되돌립니다.
  • 한 머티리얼의 마무리 모습 표시에 동시에 사용할 수 있는 텍스처는 최대 16개입니다(초과하면 '더 이상 추가할 수 없습니다' 표시).
칠하는 대상 추가(Pro): “기타 마스크”에 매끄러움·금속도·광택 색·이방성 반사 마스크·이방성 반사 노이즈·디졸브 마스크·디졸브 노이즈·시차 높이·AudioLink 마스크를 추가했습니다(각 설정을 사용할 때).
노멀 맵 이미지 레이어(Pro): 다른 소프트웨어로 만든 노멀 맵 이미지도 노멀 맵 폴더 안에 레이어로 넣을 수 있습니다(패널 “머티리얼”의 “노멀 맵 이미지 추가”, 또는 폴더 안 레이어를 선택하고 이미지를 창에 드롭). DirectX 방향 이미지는 레이어 속성의 “DirectX 방향(녹색 반전)”을 켭니다. 불러온 .mat의 노멀 맵도 이 레이어가 됩니다.
무늬로 질감 넣기(Pro): 머티리얼의 노멀 맵 항목의 “무늬로 질감 넣기”로 니트·데님·캔버스·헤링본 등의 무늬를 반복되는 요철로 폴더에 깔 수 있습니다(크기·회전·이음매는 레이어 속성의 “반복 무늬”, 세기는 “노멀 맵 강도”). 폴더 안 레이어를 선택하고 있으면 UV 영역은 높이(회색) 대신 노멀 맵 색으로 보여 줍니다(보기 → “노멀 맵 폴더를 높이(회색)로 보기(UV)”로 되돌릴 수 있습니다).

메인 컬러 2nd·메인 컬러 3rd

  • '머티리얼' 패널의 '메인 컬러 2nd'·'메인 컬러 3rd'에서 '사용'을 켜면 레이어 패널 맨 위에 같은 이름의 폴더가 생성됩니다.
  • 폴더 안의 레이어만 메인 컬러 2nd(3rd) 텍스처가 됩니다(메인 그림에 섞이지 않음). 겹치는 방식(색·불투명도·합성 모드·마스크)은 패널에서 정합니다.
  • 내보내기에서는 별도 이미지(<이름>_main2nd.png 등)가 되며 머티리얼에서는 lilToon의 '메인 컬러 2nd/3rd'에 적용됩니다.

머티리얼 나누기

  • 처음에는 텍스처 세트마다 같은 이름의 머티리얼 하나가 있습니다. 나누지 않으면 아무것도 바뀌지 않습니다.
  • 같은 텍스처(칠할 그림)를 유지하면서 오브젝트별로 그림자 색·매트캡·림 라이트·윤곽선 등의 설정을 바꿀 수 있습니다(예: 머리카락 텍스처를 유지하며 동물 귀만 빨간 그림자).
  • 나누기: 오브젝트 패널의 행 또는 3D의 해당 오브젝트 우클릭 → '이 오브젝트만 별도 머티리얼로'. '머티리얼 할당'으로 사용할 머티리얼을 선택할 수 있습니다.
  • '머티리얼' 패널 위 목록에서 추가·이름 변경·삭제·재정렬합니다(순서 = 겹친 곳의 우선순위). 3D에서 누른 곳의 머티리얼로 패널이 전환되며 아래 상태 바에 '머티리얼: 이름(텍스처 세트 이름)'이 표시됩니다.
  • 내보내기는 머티리얼마다 .mat 하나입니다(같은 텍스처 참조).

lilToon 머티리얼 불러오기

  • 파일 → 가져오기 → lilToon 머티리얼 가져오기로 .mat 또는 해당 .mat를 포함한 .unitypackage를 선택합니다(창에 드롭도 가능). 새로 만들기의 '시작'에서도 선택할 수 있습니다.
  • 그리기 모드·그림자·노멀 맵·매트캡·림 라이트·발광·윤곽선·메인 컬러 2nd/3rd 등의 설정과 텍스처(메인 컬러 → 바탕, 그림자 색·마스크 등 → 칠할 대상)를 가져옵니다.
  • 텍스처는 .mat 주변 프로젝트에서 찾습니다. 찾지 못한 텍스처는 목록에 표시되므로 이미지를 선택합니다.
  • PetaNuri3D가 재현하지 않는 설정(광택·퍼·스텐실 등)은 값을 유지하며 내보낼 때 원래대로 돌아갑니다.
  • 내보내면 원래 .mat와 같은 위치·같은 ID를 유지하며 변경한 설정과 다시 그린 텍스처만 덮어씁니다.
.mat 불러오기·내보내기는 추가한 설정에도 대응합니다. 메인 이미지는 URP·HDRP용 별명(_BaseMap·_BaseColorMap)으로도 읽고, 내보낼 때도 넣습니다.

머티리얼 내보내기

  1. 파일 → 내보내기 → 머티리얼 내보내기(패널의 '내보내기'도 가능)를 선택합니다.
  2. 내보낼 머티리얼·폴더 이름·내보내기 번짐을 선택합니다.
  3. .unitypackage로 내보내거나 폴더(프로젝트 Assets)에 직접 씁니다. .unitypackage는 더블클릭 또는 드래그로 프로젝트에 가져올 수 있습니다.
  • 머티리얼(.mat)과 메인 컬러 이미지·그림자 색·마스크·노멀 맵·매트캡 이미지가 포함되며 할당도 완료됩니다.
  • 같은 작업을 같은 폴더 이름으로 다시 내보내면 이전에 가져온 내용을 덮어씁니다(모델 할당 유지).
내보내는 것은 lilToon용 머티리얼입니다. 가져오는 프로젝트에 lilToon을 설치해 두세요(없으면 머티리얼이 분홍색으로 표시).
