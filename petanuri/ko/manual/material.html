마무리 모습과 lilToon 머티리얼 Pro

lilToon과 같은 계산의 모습(그림자·매트캡·림 라이트·윤곽선 등)을 보면서 칠할 수 있습니다. 그림자 색이나 마스크도 칠하고, 설정째 lilToon 머티리얼로 Unity에 넘길 수 있습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

Pro 기능입니다. Lite에서는 메뉴와 아이콘에 자물쇠 표시가 붙고, "머티리얼" 패널에는 설명만 표시됩니다. Standard에서는 이 기능의 진입점이 표시되지 않습니다(에디션 비교). "마무리 모습"은 베타판이므로 Unity 안에서의 모습과 조금 다를 수 있습니다.

먼저 이것만
  1. 3D 뷰 왼쪽 위의 표시 형식 아이콘에서 "마무리 모습"으로 바꾸면 lilToon의 외형으로 칠할 수 있습니다(자세히).
  2. 그림자·림 라이트·윤곽선 등의 설정은 오른쪽의 "머티리얼" 패널에서 바꿉니다(자세히).
  3. 그림자 색이나 마스크를 칠할 때는 패널의 "칠하기:" 버튼에서 칠할 대상을 선택합니다. 끝나면 "컬러로 돌아가기"를 누릅니다(자세히).
  4. 가지고 있는 lilToon 머티리얼은 파일 → 가져오기 → lilToon 머티리얼 불러오기로 설정째 들어옵니다(자세히).
  5. Unity에는 파일 → 내보내기 → 머티리얼 내보내기로 .unitypackage를 만들어 넘깁니다(자세히).
이 페이지의 내용
  • lilToon의 외형으로 확인하며 칠하기
  • 그림자 색·마스크·요철 칠하기(칠할 대상)
  • 메인 컬러 2nd·3rd 겹치기
  • 일부 오브젝트만 설정 바꾸기(머티리얼 나누기)
  • lilToon 머티리얼 불러오기
  • 머티리얼을 내보내 Unity로 넘기기

lilToon의 외형으로 확인하며 칠하기

표시 형식을 "마무리 모습"으로 하면, 칠한 색에 lilToon과 같은 계산의 그림자와 빛이 얹혀 보입니다. Unity에 가져가기 전에 마무리 모습을 보면서 칠할 수 있습니다.

  1. 3D 뷰 왼쪽 위의 표시 형식 아이콘 5개 중 오른쪽에서 두 번째(마무리 모습)를 누릅니다.
  2. 평소처럼 그립니다. 그린 색에 그림자·림 라이트·윤곽선 등이 얹혀 보입니다.
  3. 칠한 색만 확인하고 싶을 때는 맨 왼쪽의 "칠한 색 그대로"로 되돌립니다.
  • 다른 진입 경로: 표시 → 표시 형식 → "마무리 모습(lilToon·MToon, 베타)", 3D 뷰 우클릭 → 표시, "머티리얼" 패널의 "마무리 모습(lilToon, 베타) 표시".
  • 표시되는 것: 그림자(그림자 색 1·그림자 색 2·그림자 색 3·경계 색)·노멀 맵·매트캡·매트캡 2nd·림 라이트·역광 라이트·림 셰이드·발광·윤곽선·리플렉션·글리터·이방성 반사·디더·디졸브·시차·AudioLink·색조 보정.

설정은 머티리얼별입니다. 항목 이름은 lilToon 설정 화면의 명칭에 맞추었습니다. 바꿀 때마다 실행 취소할 수 있습니다.

빛의 방향 바꾸기

  • "머티리얼" 패널의 "표시와 빛"에 있는 "빛의 좌우", "빛의 높이", "빛의 세기"로 바꿉니다. 표시 형식 아이콘 옆의 ▼에서도 바꿀 수 있습니다(빛의 방향).
  • "카메라를 따라가는 빛"을 켜면 시점을 돌려도 빛이 닿는 방식이 같아서 칠하기 쉽습니다. 끄면 빛은 모델에 고정됩니다.
  • 이 빛은 모습 확인용입니다. 내보낸 머티리얼의 빛은 Unity에서 배치한 위치의 빛으로 정해집니다.

MToon의 외형으로 확인하기

VRM 모델을 MToon의 외형으로 확인하면서 칠할 수 있습니다(표시용 미리 보기·베타판).

  1. "머티리얼" 패널의 "표시와 빛"에서 "MToon"을 누릅니다.
  2. "마무리 모습(MToon, 베타) 표시"를 누릅니다.
  3. MToon용 색·그림자 위치·선명도·환경광·림·발광·윤곽을 조정하면서 칠합니다.
  • VRM0·VRM1에 MToon 설정이 있으면 그 색·그림자·림·발광·윤곽과 보조 이미지에서 시작합니다. 없는 모델은 기본 모습에서 시작합니다.
  • "원본 MToon 설정으로 되돌리기"는 모습 조정만 되돌립니다. 그린 레이어는 사라지지 않습니다. "lilToon"을 누르면 lilToon의 외형으로 돌아갑니다.
  • 조정은 실행 취소·다시 실행할 수 있고 작업 파일에도 저장됩니다.
MToon은 확인용 표시입니다. PNG·PSD는 그린 색 그대로 내보내고, 머티리얼 내보내기는 계속 lilToon용입니다. MToon 머티리얼이나 VRM은 내보내지 않습니다.

잘 안 될 때

  • "마무리 모습" 아이콘에 자물쇠가 붙어 있거나 아이콘이 없음: Pro 기능입니다. Lite에서는 자물쇠가 붙고, Standard에서는 표시되지 않습니다.
  • Unity에서 본 것과 조금 다름: 베타판이라 빛이나 배경의 차이로 차이가 날 수 있습니다. 빛은 확인용이며, Unity에서는 배치한 위치의 빛으로 정해집니다.
  • MToon으로 바꿨더니 일반 표시로 돌아감: 메인 이미지의 위치·배율·회전을 바꾼 UV 설정이나 UV0 이외를 쓰는 이미지에는 대응하지 않습니다. 돌아갈 때 이유를 알려 줍니다. UV 애니메이션은 멈춘 상태로 표시합니다.
  • 투명하게 하고 싶은 곳이 빠지지 않음: "기본"의 렌더링 모드를 "컷아웃"이나 "반투명"으로 합니다. "불투명"에서는 투명도를 보지 않습니다.

그림자 색·마스크·요철 칠하기(칠할 대상)

메인 색뿐 아니라 그림자 색·그림자 마스크·노멀 맵(요철)·발광 등의 이미지도 평소 쓰는 펜으로 칠할 수 있습니다. 칠할 대상마다 레이어 패널에 폴더가 만들어집니다.

  1. "머티리얼" 패널 각 섹션의 "칠하기:" 버튼을 눌러 칠할 대상을 선택합니다(우클릭 → 칠할 대상에서도 선택할 수 있습니다).
  2. 레이어 패널의 메인 컬러 위에 그 칠할 대상의 폴더(예: "그림자 색 1")가 만들어지고, 안의 레이어가 선택됩니다.
  3. 평소 쓰는 펜·붓·채우기·그라데이션·흐리기·필터로 칠합니다.
  4. 3D 뷰 위쪽 가운데의 "컬러로 돌아가기"를 누르면 일반 색 칠하기로 돌아갑니다. 폴더 밖의 레이어를 눌러도 돌아갑니다.
칠할 대상어떻게 적용되나요?
그림자 색 1·그림자 색 2칠한 곳의 그림자가 그 색이 됩니다(피부의 붉은기·머리카락 그림자의 푸른기 등). 칠하지 않은 곳은 원래 색에 설정의 그림자 색을 곱한 색입니다
그림자 마스크흰색 = 그림자가 붙음·검은색 = 그림자를 붙이지 않음
그림자 AO검을수록 그림자가 나오기 쉽습니다(목 부근·머리카락 안쪽·옷이 겹친 곳). AO 굽기를 하면 여기에도 넣을 수 있습니다
노멀 맵높이로 칠합니다. 흰색으로 올리고 검은색으로 파며, 회색이 평평합니다(옷 주름·바느질 선·머리카락 결에. 노멀 맵 칠하기)
매트캡 마스크·매트캡 2nd 마스크·윤곽선 폭흰색 = 적용·검은색 = 미적용
림 라이트 색칠한 색을 곱합니다(검은색이면 사라짐)
발광 텍스처칠한 곳만 칠한 색으로 빛납니다(설정의 "발광 색"을 곱함)

그 밖의 칠할 대상

우클릭 → 칠할 대상 → 기타 마스크(그림자 색 3, 색조 보정, 글리터 등)에도 나열됩니다. 그 기능을 사용하고 있을 때 칠할 수 있습니다.

  • 그림자: 그림자 색 3·그림자 흐림 마스크(칠한 곳일수록 그림자의 경계가 부드러움)
  • 색과 투명: 색조 보정 마스크(칠한 곳만 보정)·알파 마스크(투명도를 칠함)
  • 발광: 발광 마스크·발광 2nd 텍스처·발광 2nd 마스크
  • 가장자리와 윤곽: 역광 라이트 색·림 셰이드 마스크·윤곽선 색
  • 질감: 노멀 맵 2nd 마스크·글리터 색(검은색이면 글리터가 나오지 않음)·매끄러움·메탈릭(흰색 = 설정대로·검은색 = 0)·리플렉션 색·이방성 반사 마스크·이방성 반사 노이즈
  • 기타: 디졸브 마스크·디졸브 노이즈·시차 높이(흰색 = 앞·검은색 = 뒤)·AudioLink 마스크

칠하는 동안 위쪽 가운데의 줄

버튼하는 일
흰색·회색·검정전경색을 바꿔 듭니다. 밝기만 읽는 칠할 대상(마스크·그림자 AO·노멀 맵·윤곽선 폭)은 색을 선택해도 밝기로 칠합니다. 컬러로 돌아가면 이전 전경색으로 돌아갑니다
전체 칠하기폴더 안의 그리고 있는 레이어를 전경색으로 전부 칠합니다
이것만 보기그 칠할 대상의 그림만 표시합니다
지우기폴더를 내용째 지우고 칠하지 않은 상태로 되돌립니다(Ctrl+Z로 되돌릴 수 있습니다)
컬러로 돌아가기일반 색 칠하기로 돌아갑니다(편집 → "칠할 대상을 컬러로 되돌리기"로도 됩니다)
  • 폴더 안은 일반 레이어와 같아서 추가·삭제·순서 바꾸기·불투명도·합성 모드·마스크·클리핑·테두리·아래 레이어와 병합을 쓸 수 있습니다. 안의 레이어를 겹친 그림이 그 칠할 대상의 이미지가 됩니다.
  • 폴더는 사용 중인 칠할 대상만 표시됩니다. 폴더 자체는 옮길 수 없고 삭제할 수도 없습니다(지울 때는 "지우기").
  • 폴더 안의 레이어는 Lite의 레이어 수에 포함되지 않습니다. 지우개로 지운 곳은 칠하지 않은 상태로 돌아갑니다.
  • UV 영역에도 칠하고 있는 칠할 대상의 그림이 표시됩니다.

노멀 맵(요철) 칠하기

  1. "머티리얼" 패널의 "노멀 맵"에서 "노멀 맵 사용"을 켭니다.
  2. "칠하기:"의 "노멀 맵"을 누릅니다. 레이어 맨 위에 "노멀 맵" 폴더가 만들어집니다.
  3. 흰색으로 올리고 검은색으로 팝니다. 흐리기로 부드러워집니다. 강도는 "노멀 맵 강도"에서 나중에 바꿀 수 있습니다.
  • 다른 소프트웨어에서 만든 노멀 맵 이미지: "노멀 맵 이미지 추가"를 누르거나, 폴더 안의 레이어를 선택하고 이미지를 창에 드롭합니다. 높이가 아니라 법선 그대로 들어갑니다(레이어에 "법선" 라벨). DirectX 방향의 이미지는 레이어 속성의 "DirectX 방향(녹색 반전)"을 켭니다.
  • 무늬로 질감 넣기: 니트·데님·캔버스·헤링본 등의 무늬를 반복되는 요철로 깝니다. 크기·회전·이음매는 레이어 속성의 "반복 무늬"에서 바꿉니다. 마스크로 적용할 곳을 정할 수 있습니다.
  • 폴더 안의 레이어를 선택하고 있는 동안 UV 영역은 높이(회색)가 아니라 노멀 맵의 색(청자색)으로 보여 줍니다. 우클릭 → 표시 → "노멀 맵 폴더를 높이(회색)로 보기(UV)"로 회색으로 되돌릴 수 있습니다.
  • 요철을 그리는 도구도 있습니다(요철).
  • 내보내면 PNG는 <이름>_normal.png 한 장, PSD는 "노멀 맵" 그룹 안에 레이어를 나눈 채로 저장됩니다.

잘 안 될 때

  • "더 이상 추가할 수 없습니다"라고 표시됨: 머티리얼 하나의 마무리 모습 표시에서 동시에 쓸 수 있는 텍스처는 16개까지입니다. 다른 기능을 끄거나 사용하지 않는 칠할 대상을 "지우기"하면 쓸 수 있습니다.
  • 색을 선택해도 회색으로만 칠해짐: 밝기만 읽는 칠할 대상을 칠하고 있습니다. 일반 색으로 돌아가려면 "컬러로 돌아가기"를 누릅니다.
  • 칠할 대상 폴더를 지울 수 없거나 옮길 수 없음: 폴더는 지울 수 없습니다. 칠할 대상째 지울 때는 위쪽 가운데의 "지우기"를 누릅니다.

메인 컬러 2nd·3rd 겹치기

lilToon의 "메인 컬러 2nd", "메인 컬러 3rd"용 그림을 메인 그림과 따로 그릴 수 있습니다. 무늬나 문양을 다른 이미지로 겹치고 싶을 때 사용합니다.

  1. "머티리얼" 패널의 "메인 컬러 2nd"에서 "메인 컬러 2nd 사용"을 켭니다.
  2. 레이어 패널 맨 위에 "메인 컬러 2nd" 폴더가 만들어집니다.
  3. 폴더를 선택하고 레이어를 추가해서 그립니다. 일반 레이어를 드래그해서 안에 넣어도 됩니다.
  4. 겹치는 방식(색·불투명도·합성 모드·라이트 밝기 반영)을 패널에서 정합니다.
  • 폴더 안의 레이어만 2nd(3rd)의 텍스처가 되며, 메인 그림에는 섞이지 않습니다. 합성 모드는 표준·더하기·스크린·곱하기입니다.
  • 칠할 대상 "메인 컬러 2nd 마스크"로 겹치는 곳(흰색)과 겹치지 않는 곳(검은색)을 칠할 수 있습니다.
  • 폴더는 옮기거나 지우거나 복제할 수 없습니다. 안에 레이어가 있는 동안은 "사용"을 끌 수 없습니다(안을 비우면 끌 수 있고, 폴더도 사라집니다).
  • 내보내기에서는 별도의 이미지(<이름>_main2nd.png·<이름>_main3rd.png와 칠한 마스크)가 됩니다. PSD에서는 폴더 그대로이며, 다시 가져오면 이 폴더로 돌아옵니다. 머티리얼에서는 lilToon의 "메인 컬러 2nd/3rd"에 들어갑니다.

일부 오브젝트만 설정 바꾸기(머티리얼 나누기)

같은 텍스처(칠하는 그림)를 그대로 두고 오브젝트별로 그림자 색·매트캡·림 라이트·윤곽선 등의 설정을 바꿀 수 있습니다. 예를 들어 머리카락 텍스처 그대로 짐승 귀만 그림자를 붉게 할 수 있습니다.

  1. 3D 뷰에서 그 오브젝트 위를 우클릭하거나, 오브젝트 패널의 행을 우클릭합니다.
  2. "이 오브젝트만 별도 머티리얼로"를 선택합니다. 현재 머티리얼의 복사본이 오브젝트 이름으로 추가되어 할당됩니다.
  3. "머티리얼" 패널에서 그 머티리얼의 설정을 바꿉니다.
  • 처음에는 텍스처 세트 하나당 같은 이름의 머티리얼이 하나입니다. 나누지 않으면 아무것도 바뀌지 않습니다.
  • 우클릭의 "머티리얼 할당"이나 패널의 "오브젝트에 할당"에서 어떤 머티리얼을 쓸지 선택할 수 있습니다. 선택할 수 있는 것은 같은 텍스처 세트를 쓰는 머티리얼뿐입니다.
  • 패널 위쪽의 목록에서 추가(현재 머티리얼의 복사본)·이름 바꾸기·삭제·위로·아래로를 할 수 있습니다. 텍스처 세트의 원래 머티리얼은 삭제할 수 없습니다.
  • 목록의 순서가 우선순위입니다. 같은 곳에 오브젝트가 겹쳐 있을 때는 위쪽 머티리얼이 선택됩니다.
  • 3D에서 건드린 곳의 머티리얼로 패널이 전환되고, 아래 상태 표시줄에 "머티리얼: 이름(텍스처 세트 이름)"이 표시됩니다.
  • 내보내기는 머티리얼마다 .mat가 하나입니다. 텍스처는 텍스처 세트마다 한 세트이며 같은 것을 가리킵니다.

lilToon 머티리얼 불러오기

아바타에 붙어 있는 lilToon 머티리얼을 불러와서 설정과 이미지를 그대로 이어서 칠할 수 있습니다. 내보내면 원래 머티리얼에 다시 그린 부분만 들어갑니다.

  1. 파일 → 가져오기 → "lilToon 머티리얼 불러오기(.mat, .unitypackage)"를 선택합니다.
  2. .mat나 그것이 들어 있는 .unitypackage를 선택합니다. 창에 드롭해도 됩니다.
  3. 여러 개를 선택했을 때는 표시된 창에서 넣을 텍스처 세트를 확인합니다(이름이 맞는 세트에 들어갑니다).
  4. 찾을 수 없는 텍스처가 있으면 목록에 표시되므로 이미지를 선택합니다(선택하지 않으면 넣지 않고 불러옵니다).
  • 새로 만들기의 "시작"에서도 선택할 수 있습니다(시작의 종류).
  • 들어오는 설정: 렌더링 모드·렌더링 면·메인 컬러·그림자·노멀 맵·매트캡/2nd·림 라이트·역광 라이트·림 셰이드·발광·윤곽선·메인 컬러 2nd/3rd 등.
  • 들어오는 이미지: 메인 컬러 → 바탕 레이어(PSD라면 레이어째), 2nd/3rd → 그 폴더, 그림자 색·마스크·림 라이트 색·발광·윤곽선 폭·AO → 칠할 대상, 매트캡 → 매트캡, 노멀 맵 → 노멀 맵 폴더(법선 그대로).
  • 텍스처는 .mat 옆의 프로젝트(Assets·Packages)에서 찾습니다. 처음에는 몇 초에서 십여 초 걸립니다. .unitypackage라면 안에서 찾습니다.
  • 같은 텍스처를 쓰는 .mat를 여러 개 선택하면 같은 텍스처 세트에 들어가며, 두 번째부터는 별도의 머티리얼이 됩니다.
  • 불러오기는 실행 취소할 수 있습니다(1단계). 그 세트의 머티리얼 설정·칠할 대상·바탕 그림·메인 컬러 2nd/3rd는 교체됩니다.

재현하지 않은 설정

PetaNuri3D가 재현하지 않는 설정(스텐실·거리 페이드·UV 애니메이션·텍스처 타일링 등)은 불러온 뒤에 "재현하지 않은 설정" 목록으로 알려 줍니다. 값은 그대로 남아 있고, 내보내면 원래대로 돌아갑니다. 목록은 패널의 "lilToon: ○○.mat" 섹션에서도 볼 수 있습니다.

원래 머티리얼에 다시 쓰기

  • 불러온 머티리얼을 내보내면 원래 .mat와 같은 위치·같은 ID 그대로, 바꾼 설정의 행과 다시 그린 텍스처만 갱신됩니다. 바꾸지 않은 텍스처는 내보내지 않습니다.
  • .unitypackage를 프로젝트에 가져오면 원래 머티리얼과 텍스처가 그 자리에서 덮어써집니다(모델에 대한 할당은 그대로).
  • 원래 PNG가 아니거나 찾지 못했던 텍스처를 다시 그렸을 때는 .mat 옆에 새 PNG를 만들어 교체합니다.
  • 새 머티리얼로 내보내고 싶을 때는 패널의 "불러온 원본과의 연결 해제"를 누릅니다.
원래 프로젝트의 파일을 덮어씁니다. 구입한 아바타의 머티리얼을 직접 고치고 싶지 않을 때는 먼저 프로젝트를 복사해 두거나, "불러온 원본과의 연결 해제"를 누른 뒤에 내보내세요.

머티리얼을 내보내 Unity로 넘기기

lilToon용 머티리얼(.mat)과 칠한 이미지를 한꺼번에 내보냅니다. Unity에 가져오면 텍스처가 할당된 머티리얼이 됩니다.

  1. 파일 → 내보내기 → "머티리얼 내보내기(.unitypackage/폴더)"를 선택합니다("머티리얼" 패널의 "머티리얼 내보내기"로도 됩니다).
  2. "내보낼 머티리얼"에 체크합니다.
  3. "내보낼 폴더 이름(Assets 아래)"·해상도·"번짐(패딩)"을 정합니다.
  4. ".unitypackage로 내보내기"를 누르고 저장 위치를 선택합니다.
  5. Unity에서 만들어진 .unitypackage를 더블클릭하거나 Project 창으로 드래그해서 가져옵니다.
  • 들어가는 것: 머티리얼(.mat)과 메인 컬러·그림자 색·마스크·노멀 맵·매트캡 등의 이미지. 칠할 대상은 그 기능을 사용하고 있을 때만 들어갑니다.
  • "폴더로 내보내기": Unity 프로젝트의 Assets를 선택하면 .meta와 함께 직접 씁니다(앱(exe)에서만).
  • 이미지는 아일랜드 밖으로 "번짐(패딩)" 폭만큼 색을 넓힙니다(내보내기 번짐).
  • 같은 작업을 같은 폴더 이름으로 다시 내보내면 이전에 가져온 것이 그대로 덮어써집니다(모델에 대한 할당은 그대로).
  • !가 붙은 세트(모델에 없는 세트)는 내보내지 않습니다.
내보내는 것은 lilToon(2.3 계열)용 머티리얼입니다. 가져오는 쪽 프로젝트에 lilToon을 넣어 두세요.

잘 안 될 때

  • Unity에서 머티리얼이 핑크색이 됨: 그 프로젝트에 lilToon이 들어 있지 않습니다. lilToon을 넣으면 해결됩니다.
  • "폴더로 내보내기"를 쓸 수 없음: 앱(exe)에서만 쓸 수 있습니다. .unitypackage로 내보내세요.
  • 아바타에 반영되지 않음: 내보낸 머티리얼을 모델의 머티리얼 칸에 할당하세요. 원래 .mat를 불러와서 내보냈을 때는 원래 머티리얼이 그대로 덮어써집니다.
