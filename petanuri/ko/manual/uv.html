UV 영역과 표시 범위

3D 뷰 옆에 UV(텍스처의 전개도)를 나란히 놓고 어느 쪽에서든 칠할 수 있습니다. 옷 아래의 몸이나 머리카락 안쪽 같은 안쪽 면은, 표시 범위로 앞쪽을 숨기고 칠합니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

먼저 이것만
  1. U로 3D 옆에 UV를 나란히 표시합니다. UV 위에서도 그대로 칠할 수 있습니다(자세히).
  2. UV 영역 왼쪽 아래의 "칠하는 범위"에서, 아일랜드 안쪽만 칠할지 바깥의 패딩까지 칠할지 선택합니다(자세히).
  3. 안쪽을 칠할 때는 아일랜드나 면을 선택하고 Shift+H(선택한 곳만 표시) 또는 H(선택한 곳 숨기기)를 누릅니다. Alt+H로 모두 표시로 돌아갑니다(자세히).
  4. 겹친 천은 "숨기기 펜"으로 그어서 숨길 수 있습니다(자세히).
  5. UV의 이음매 위치는 Alt+W(이음선)로 3D에 표시됩니다(자세히).

UV를 표시해 직접 칠하기

UV 영역에서는 텍스처의 전개도 위에 직접 칠할 수 있습니다. 3D에서는 닿기 어려운 곳이나 곧은 선을 긋고 싶은 곳에 사용합니다.

  1. U를 누릅니다(3D 뷰 오른쪽 끝의 "UV"나, 표시 → UV → UV(3D 옆에 나란히)로도 됩니다). 3D 옆에 UV 영역이 표시됩니다.
  2. 경계를 드래그해서 너비를 맞춥니다.
  3. UV 영역 위에서 3D와 같은 방식으로 그립니다.
  • 표시되는 것은 선택한 텍스처 세트의 UV입니다(왼쪽 위에 이름). 세트를 다시 선택하면 바뀝니다(텍스처 세트 선택하기).
  • 사용할 수 있는 도구: 펜·붓·지우개·폴리곤 칠하기·채우기·둘러싸인 곳 칠하기·그라데이션·도형·스탬프·스포이트·흐리기·손가락.
  • UV 영역을 만지는 동안 3D 뷰에서는 브러시 원에 들어가는 면이 붉게 빛납니다. 3D를 만지는 동안은 UV 영역에 칠하는 위치가 붉은 점으로 표시됩니다.
  • 제목 줄의 "대칭 X·Y·Z"는 3D 왼쪽 위와 같은 전환입니다. UV에서 칠해도 3D의 같은 축으로 접은 위치에 칠합니다(좌우 대칭으로 그리기).
  • 오른쪽 아래에는 서브 텍스처 세트의 UV가 작게 표시됩니다. 누르면 서브가 메인이 됩니다. ✕로 숨기고 "서브 표시"로 되돌릴 수 있습니다(메인과 서브).

표시 방식 전환하기(3D만·나란히·UV만·작은 창)

표시 방식조작
3D와 UV를 나란히U·3D 뷰 오른쪽 끝의 "UV"·UV만 표시 중일 때는 UV 영역 왼쪽 끝의 "3D"
3D만UV 영역 오른쪽 위의 ✕(다시 U를 눌러도 됩니다)
UV만3D 뷰 오른쪽 위의 ✕·Shift+U(표시 → UV → UV만(3D 숨기기))
한쪽을 작은 창으로나란히 표시 중에 오른쪽 위 ✕ 아래의 버튼. 표시 → UV → "UV를 작은 창으로(3D는 전체)", "3D를 작은 창으로(UV는 전체)"로도 됩니다
  • 마지막으로 사용한 표시 방식은 다음에 열 때도 같습니다.
  • 작은 창은 앱 창 안이라면 패널 위에도 둘 수 있습니다. 제목 줄을 드래그해서 이동하고, 네 변과 네 모서리로 크기를 바꿉니다.
  • 작은 창의 ⇄로 전체와 바꾸고, ▣로 나란히 표시로 되돌리며, ✕로 작은 창 쪽을 닫습니다. 오른쪽 위의 자물쇠로 움직이지 않게 고정할 수 있습니다(다시 누르면 해제).
  • Tab으로 패널을 숨겨도 작은 창은 남습니다. 2D 캔버스는 작은 창으로 만들 수 없습니다.

UV 선·아일랜드 가장자리·패딩 선 표시하기

  • 제목 줄의 "UV 선"으로 UV의 선을, "섬 가장자리"로 아일랜드의 윤곽을, "패딩 선"으로 아일랜드 가장자리에서 패딩 폭만큼 바깥의 선을 표시하거나 숨깁니다(패딩).
  • 옆의 ▼로 세 선의 색과 농도(5~100%)를 바꿉니다. "기본 색으로 되돌리기"로 원래대로 돌아갑니다.
  • UV 영역의 우클릭에도 같은 전환이 있습니다.
  • UV의 선을 이미지로 만들어 다른 소프트웨어에서 밑그림으로 쓸 때는 "UV 맵을 PNG로 내보내기"입니다(자세히).

노멀 맵 폴더를 높이로 보기

Pro 칠할 대상이 노멀 맵일 때, UV 영역은 평소 노멀 맵의 색으로 보입니다. 3D 우클릭 → 표시 → "노멀 맵 폴더를 높이(회색)로 보기(UV)"를 켜면 그린 높이 그대로 회색으로 보입니다. 흰색이 솟은 곳이고, 검은색이 파인 곳입니다(칠할 대상).

잘 안 될 때

  • 제목 줄의 버튼이 보이지 않음: UV 영역이 좁으면 들어가지 않는 버튼을 "⋯"에 넣어 둡니다. "⋯"를 누르면 표시됩니다.
  • UV가 표시되지 않음: 3D 모델을 열면 표시할 수 있습니다. 먼저 모델을 여세요.
  • 칠할 수 없는 곳이 있음: UV가 한 점에 붙어 있는 면, 0~1 바깥에 걸친 면, 4장보다 많이 겹친 곳은 칠할 수 없습니다. 열었을 때 오른쪽 아래에서 알려 줍니다.
  • 아일랜드가 0~1 바깥에 놓여 있음: 텍스처가 반복되어 같은 색이 되는 0~1 안의 위치로 옮겨서 칠합니다. 모델의 파일은 바꾸지 않습니다.

UV 표시 움직이기(확대/축소·이동·회전)

UV 영역은 마우스로도 펜만으로도 움직일 수 있습니다. 오른쪽 위의 가이드는 3D 내비와 같은 모양입니다.

하고 싶은 일조작
확대·축소휠·가이드의 돋보기를 위아래로 드래그(위로 하면 확대)
이동가운데 버튼으로 드래그·Space+드래그·가이드의 손바닥을 드래그
전체 표시가이드의 사각형·우클릭의 "UV 전체 보기"
회전가이드 아래 줄의 ⟲·⟳로 15°씩·Shift+휠로 5°씩
원하는 각도로 회전가이드의 회전 버튼을 좌우로 드래그·Space+Shift를 누른 채 영역을 드래그
회전 초기화가이드의 각도를 누름(회전 버튼을 더블클릭해도 0°)
정해진 배율로 맞추기Ctrl+1·2·3(처음에는 100%·200%·50%)
  • 회전한 채로도 칠할 수 있습니다.
  • 100%는 텍스처의 1픽셀이 화면의 1px입니다. 배율은 파일 → 환경 설정 → 조작의 "정해진 배율(UV·2D)"에서 바꿉니다. 2D 캔버스를 열고 있을 때는 그쪽에 적용됩니다. 3D 뷰에서는 쓸 수 없습니다.
  • 가이드는 위쪽 손잡이로 원하는 곳으로 옮기고, 왼쪽·아래쪽 가장자리와 왼쪽 아래 모서리로 크기를 바꿉니다. "—"로 작은 둥근 아이콘으로 접고, 누르면 되돌아옵니다(표시 → UV → UV 가이드(확대/이동)로도 됩니다).
  • 파일 → 환경 설정 → 인터페이스 → 표시의 "내비게이터에 회전·확대/축소 슬라이더 표시"를 켜면 가이드 아래에 슬라이더가 표시됩니다(3D 내비에도).

그리드 선과 스냅

눈금을 표시해서 무늬나 와펜의 위치를 맞춥니다. 틀을 움직이면 눈금선에 달라붙습니다.

  1. UV 영역 제목 줄의 "그리드"를 누릅니다. 눈금이 표시됩니다.
  2. 옆의 ▼에서 "칸 수"를 선택합니다. 텍스처의 한 변을 2·4·8·16·32·64·128로 나눕니다.
  3. 이동·변형 틀을 움직이면 틀의 네 모서리나 가운데가 가까운 눈금선에 달라붙습니다.
  • 한 칸이 몇 px인지는 ▼ 안에 표시됩니다(2048px을 16으로 나누면 128px).
  • 선은 표시용일 뿐이며, 그리는 그림·저장·내보내기에는 들어가지 않습니다. 확대해도 선은 굵어지지 않습니다.
  • "이동·변형 시 그리드에 스냅"은 처음부터 켜져 있습니다. 그리드를 표시하고 있을 때만 작동합니다.
  • 달라붙는 것은 이동·변형 도구, 변형(Ctrl+T), 이미지를 UV에 붙이기의 틀입니다. 모서리·변의 손잡이, 자유 변형의 모서리, 워프의 점도 달라붙습니다(변형).
  • Ctrl을 누르고 있는 동안은 달라붙지 않습니다. 3D 영역 위의 틀도 달라붙지 않습니다.
  • 표시 → UV → "UV 그리드"로도 표시할 수 있습니다. 스냅 켜기/끄기에 키를 지정할 수도 있습니다(단축키).

칠하는 범위와 패딩(아일랜드 밖까지 칠하기)

UV 아일랜드 바깥쪽에 가장자리 색을 조금 넓혀 두면, 게임 안에서 이음매에 선이 잘 생기지 않습니다. 이 넓힌 띠를 패딩이라고 부릅니다. UV 영역 왼쪽 아래에서 어디까지 칠할지 선택합니다.

  1. UV 영역 왼쪽 아래의 "칠하는 범위"에서 "UV 안", "패딩 안", "전체" 중 하나를 누릅니다.
  2. "패딩 안"이라면 아래의 슬라이더로 패딩 폭(0~128px)을 정합니다.
  3. UV 영역에서 칠합니다.
칠하는 범위칠할 수 있는 곳
UV 안(처음 설정)UV 아일랜드 안쪽만. "이어서 칠하기"를 쓸 수 있습니다(자세히)
패딩 안아일랜드와 그 바깥의 패딩 띠 안. 펜·도형 등은 옆 아일랜드로도 넘칩니다
전체텍스처 어디에나. 아일랜드 바깥·옆 아일랜드로도 넘칩니다
  • 펜·붓·지우개·폴리곤 칠하기 외에 도형·채우기·그라데이션·스탬프·흐리기·손가락도 이 범위를 따릅니다. 3D 뷰에서 칠할 때는 바뀌지 않습니다.
  • "패딩 안", "전체"의 채우기는 칠한 곳을 아일랜드 바깥으로 넓힙니다.
  • 패딩 값은 내보내기 번짐과 같은 값입니다("내보내기와 공통"). 어느 쪽에서 바꿔도 둘 다 바뀝니다. "전부"는 내보내기 창의 "아일랜드 바깥을 모두 채우기"입니다(내보내기 번짐).
  • 왼쪽 아래 칸은 ▼로 작게 접을 수 있습니다. 작게 접어도 칠하는 범위와 이어서 칠하기는 쓸 수 있습니다.

3D에서 그린 선도 패딩까지 넓히기

펜·붓·지우개의 도구 속성에서 "3D에서도 섬 바깥 패딩까지 칠하기"를 켭니다. 3D에서 그리기를 마쳤을 때 선을 아일랜드 바깥으로 패딩 폭만큼 넓힙니다.

  • 옆 아일랜드 안에는 들어가지 않습니다. 실행 취소 한 번으로 선째 되돌아갑니다.
  • 폭은 도구 속성의 "패딩 폭(px)"입니다. UV 영역 왼쪽 아래·내보내기 번짐과 같은 값입니다.
  • 꺼 두면 아일랜드 가장자리에서 조금만 넓힙니다.

패딩만 있는 레이어 만들기

필터 → "패딩을 새 레이어에 만들기"로, 현재 그림(모든 레이어를 겹친 색)의 가장자리 색을 아일랜드 바깥으로 넓힌 부분만 새 레이어로 만듭니다. 아일랜드 안쪽은 투명하며, 선택한 레이어 바로 위에 들어갑니다.

붓 가장자리의 옅은 부분은 그린 곳으로 간주하지 않고, 불투명한 부분의 색을 아일랜드 바깥으로 넓힙니다. 아일랜드 바깥의 픽셀은 직선 거리로 가장 가까운 아일랜드 픽셀의 색이 되므로, 비스듬한 가장자리에서도 매끄럽게 퍼집니다.

아일랜드 밖으로 나갔을 때(이어 칠하기)

UV에서는 떨어져 있어도 3D에서는 이어져 있는 곳이 있습니다. 이음매에서 삐져나간 부분을 3D에서 이어진 면에 계속 칠할 수 있습니다.

  • UV 영역에서 칠할 때, 원이 아일랜드 바깥으로 나가도 UV 상에서 옆에 있을 뿐인 다른 아일랜드(3D에서는 떨어진 곳)에는 칠하지 않습니다.
  • 왼쪽 아래의 "이어서 칠하기"(처음에는 켜짐): 아일랜드 가장자리의 이음매에서 삐져나간 부분은 3D에서 그 이음매 너머로 이어지는 면에 계속 칠합니다. 이음매에서 선이 끊어지지 않습니다.
  • 끄면 그리고 있는 아일랜드 안에만 칠합니다. 우클릭의 "아일랜드 밖은 3D에서 이어진 옆으로 이어서 칠하기", 표시 → UV에도 같은 전환이 있습니다.
  • 이어서 칠하기는 칠하는 범위가 "UV 안"일 때만 쓸 수 있습니다.

아일랜드 밖에서 그리기 시작했을 때

  • 칠하는 범위가 "UV 안"일 때 어떤 면에도 쓰이지 않는 곳에서는 브러시 원이 옅은 점선이 되고 ×가 붙습니다. 펜·붓·지우개·폴리곤 칠하기로는 그릴 수 없습니다.
  • 아일랜드 밖에서 그리기 시작한 선은 아일랜드에 들어온 곳부터 그려집니다.
  • 텍스트·도형·스탬프·그라데이션은 아일랜드 밖에서도 놓을 수 있습니다(색이 칠해지는 것은 아일랜드 안쪽).

잘 안 될 때

  • "이 레이어에서는 이음매를 넘어 칠할 수 없습니다"라고 표시됨: 클리핑 레이어(와 그 마스크)는 아래 레이어의 형태에 맞춰 칠하므로 이음매 너머로는 이어지지 않습니다.
  • "이어서 칠하기"를 누를 수 없음: 칠하는 범위를 "UV 안"으로 하세요.

표시 범위(선택한 곳만 표시·숨기기)

옷 아래의 몸이나 머리카락 안쪽은 앞쪽 면이 방해가 되어 칠할 수 없습니다. 표시 범위로 앞쪽을 숨기면 안쪽 면이 그대로 보이고 칠할 수 있습니다.

  1. UV 영역이나 3D에서 아일랜드나 면을 선택합니다(선택 범위의 "아일랜드로 선택"·"면으로 선택"·올가미·정점 그룹 등).
  2. Shift+H를 누릅니다(3D 뷰 왼쪽 위의 표시 범위 아이콘, UV 제목 줄의 "선택한 부분만 표시"로도 됩니다). 선택한 곳만 3D에 표시됩니다.
  3. 앞쪽만 숨길 때는 H("선택한 부분 숨기기")를 누릅니다. 몇 번이든 더해서 숨길 수 있습니다.
  4. 칠하기를 마치면 Alt+H로 모두 표시로 되돌립니다.
조작내용
선택한 부분만 표시(Shift+H)선택한 아일랜드·면만 표시합니다. 켠 채로 다시 선택하면 다시 누르지 않아도 표시가 바뀝니다. 다시 누르면 모두 표시
선택한 부분 숨기기(H)선택한 아일랜드·면을 숨깁니다. 숨기면 선택 범위가 해제되므로 보이는 곳에 그대로 칠할 수 있습니다
선택한 부분도 표시숨긴 곳 중 선택한 곳을 다시 보이게 합니다
표시 범위 반전보이는 곳과 숨긴 곳을 서로 바꿉니다
넓히기·좁히기보이는 곳을 UV 상에서 정한 px(1~64)만큼 넓히거나 좁힙니다
모두 표시(Alt+H)숨긴 곳과 숨긴 오브젝트를 모두 표시 상태로 되돌립니다
  • 어느 것이든 표시 → 표시 범위와, 3D·UV 우클릭의 "표시 범위"에 있습니다.
  • 해제된 선택 범위는 3D 아래 바의 [다시 선택]이나 Ctrl+Shift+D로 되돌릴 수 있습니다.
  • 숨기고 있는 곳은 UV 영역에 빗금이 표시됩니다. 숨기고 있는 동안은 "모두 표시"가 눈에 띄는 색이 됩니다.
  • 오브젝트(메시)별로 숨길 수도 있습니다(오브젝트 표시·숨기기).

누른 아일랜드만 숨기기·표시하기(우클릭)

  • 3D 우클릭의 "이 아일랜드 숨기기", "이 아일랜드만 표시"는 누른 곳의 아일랜드를 그대로 숨기거나 표시합니다. 선택 범위와 실행 취소 기록은 바뀌지 않습니다.
  • 3D 우클릭의 "이 아일랜드 선택 (선택 범위)"는 누른 아일랜드를 선택 범위로 만듭니다.
  • UV 영역의 우클릭에는 "이 아일랜드 선택 (선택 범위)", "이 아일랜드를 선택에 추가", "이 아일랜드만 3D에 표시", "이 아일랜드를 3D에서 숨기기"가 있습니다. 이쪽은 그 아일랜드를 선택한 뒤에 표시하거나 숨기므로 선택 범위가 바뀝니다.

표시 범위 ▼ 창

3D 뷰 왼쪽 위의 표시 범위 아이콘 아래 ▼에서 표시 범위 조작을 모은 창이 열립니다. 아무것도 숨기고 있지 않을 때는 여기서 조작합니다.

  • 왼쪽 위 "선택 범위에서": 선택한 부분만 표시·선택한 부분 숨기기·선택한 부분도 표시. "직접" 아래에 숨기기 펜.
  • 왼쪽 아래 "숨긴 부분": 반전·모두 표시·넓이(px)와 넓히기·좁히기·주변 흐리게 표시.
  • 오른쪽 "숨기기 방식": 현재 숨김 상태의 이름과 저장한 숨김 프리셋 목록(숨김 프리셋 저장하기).
숨긴 곳은 깊이에도 들어가지 않으므로 안쪽 면이 그대로 보이고 칠할 수 있습니다. 숨긴 곳에는 직접 그릴 수 없으며, 스포이트나 채우기로도 가져오지 않습니다.대칭 ▼에서 "숨긴 쪽에도 대칭 그리기(3D 브러시)"를 켜면, 3D의 펜·브러시·지우개·스탬프로 숨긴 반대쪽에도 대칭으로 그릴 수 있습니다(좌우 대칭으로 그리기).
숨기기·표시 조작은 실행 취소(Ctrl+Z) 기록에 들어가지 않습니다. 되돌릴 때는 모두 표시로 하거나 저장한 숨김 프리셋을 불러옵니다.

잘 안 될 때

  • "먼저 아일랜드나 면을 선택하세요"라고 표시됨: 아무것도 선택하지 않았습니다. 선택 범위 도구의 "아일랜드로 선택", "면으로 선택"으로 3D나 UV 영역을 누르거나, 우클릭의 "이 아일랜드 선택 (선택 범위)"로 선택한 뒤에 누릅니다. UV 제목 줄의 버튼은 선택할 때까지 옅게 표시됩니다.
  • Ctrl+Z로 표시가 돌아오지 않음: 숨기기 조작은 기록에 들어가지 않습니다. Alt+H나 3D 아래 바의 "모두 표시"로 되돌립니다.
  • 숨겼더니 선택 범위가 사라짐: 숨기면 선택 범위가 해제됩니다. Ctrl+Shift+D(다시 선택)로 되돌아옵니다.
  • 모델의 일부가 나타나지 않음: 표시 범위나 오브젝트로 숨긴 채입니다. Alt+H로 모두 표시로 되돌립니다. 숨긴 상태는 작업 파일에 저장되므로 다시 열어도 숨겨진 채입니다.

그려서 숨기기(숨기기 펜)와 3D 아래의 바

겹친 천의 안쪽을 칠할 때 그은 곳을 그대로 숨길 수 있습니다. 먼저 선택 범위를 만들지 않아도 됩니다.

  1. 왼쪽 도구 모음에서 "숨기기 펜"을 선택합니다(3D 아래 바의 [숨기기 펜]으로도 켜고 끌 수 있습니다).
  2. 보조 도구에서 "면으로 숨기기"(사각형 면은 삼각형 2장을 한꺼번에) 또는 "아일랜드로 숨기기"(UV 아일랜드 통째로. 천 한 장, 부품 하나 등)를 선택합니다.
  3. 3D에서 그으면 그은 곳이 숨겨집니다. UV 영역에서 눌러도 숨길 수 있습니다.
  4. [숨기기 펜]을 다시 누르면 이전 도구로 돌아갑니다.
한 번 그을 때는, 앞쪽을 숨겨서 새로 드러난 안쪽 면까지는 숨기지 않습니다. 안쪽도 숨기고 싶을 때는 한 번 더 긋습니다.

3D 아래의 바

3D 뷰 아래 가운데의 바는 숨기고 있는 동안과 숨기기 펜을 사용하는 동안에만 표시됩니다.

  • [숨기기 펜] [면|아일랜드] [숨기기 방식 ▼] [다시 선택] [주변 흐리게 표시]와 현재 상태, [모두 표시]가 나열됩니다.
  • 현재 상태는 "숨기기 방식: ○○"(저장한 숨김 프리셋 그대로), "일부를 숨기고 있습니다 (저장하지 않은 숨김 상태)", "선택한 곳만 표시하고 있습니다" 중 하나입니다. 오브젝트를 숨기고 있을 때는 "오브젝트를 n개 숨기고 있습니다"도 표시됩니다.
  • [모두 표시]를 누르면 한 번에 모두 표시로 돌아갑니다.

숨긴 부분을 흐리게 보이기

숨긴 곳을 반투명으로 보이게 해서 주변을 확인하며 그릴 수 있습니다.

  1. 숨기고 있는 동안 3D 아래 바의 [주변 흐리게 표시]를 누릅니다. 숨긴 곳이 반투명으로 표시됩니다.
  2. 옆의 슬라이더로 농도(5~80%)를 바꿉니다.
  • 표시 범위 ▼ 창의 "숨긴 부분"에 있는 "주변 흐리게 표시"에서도 같습니다(0%면 표시하지 않음).
  • 흐리게 보여도 숨긴 곳에는 직접 그릴 수 없습니다.

숨김 프리셋 저장하기

자주 쓰는 숨김 상태에 이름을 붙여 보관해 두고, 언제든 같은 상태로 되돌릴 수 있습니다.

  1. 숨기고 싶은 곳을 숨깁니다.
  2. 3D 아래 바의 [숨기기 방식 ▼] → "현재 숨김 상태 저장"을 누르고 이름을 붙입니다(같은 이름이면 덮어쓰기). 표시 범위 ▼ 창에서도 저장할 수 있습니다.
  3. 같은 목록에서 이름을 누르면 그 숨김 상태로 돌아갑니다.
  • "숨김 프리셋 관리 (이름, 삭제)"에서 이름 변경과 삭제를 할 수 있습니다.
  • 저장한 숨김 프리셋과 현재 숨김 상태는 작업 파일(.petanuri)에 저장됩니다. 다시 열어도 쓸 수 있습니다.

메시 선·이음선 표시하기

폴리곤의 선이나 UV의 이음매(아일랜드 가장자리)를 3D에 겹쳐서 표시합니다. 이음매 근처를 칠할 때의 기준이 됩니다.

  1. 3D 뷰 왼쪽 위의 선 아이콘을 누릅니다(표시 → 선과 자 → 메시 선으로도 됩니다). 폴리곤의 선이 표시됩니다.
  2. 이음선은 옆의 버튼이나 Alt+W로 표시합니다(표시 → 선과 자 → 이음선(UV 이음매·아일랜드 가장자리)).
  • 아이콘 아래 ▼에서 선 표시·농도(5~100%)·색(파랑·검정·흰색)·뒤쪽·안쪽 선도 표시(비쳐 보임)·이음선을 선택할 수 있습니다.
  • 평소에는 보이는 면의 선만 표시합니다. 단면 표시에서는 뒤를 향한 면의 선도 표시하지 않습니다.
  • 3D 우클릭 → 표시에도 같은 전환이 있습니다.
  • 텍스처를 숨기고 선만으로 볼 때는 표시 → 표시 형식 → "선만 표시(와이어프레임)"입니다.
  • 이음선은 레이어의 "테두리"(가장자리 선 넣기)와는 별개입니다.

UV 가장자리를 따라 칠하기(UV 가장자리에서 칠하기) Pro

UV 아일랜드의 가장자리에서의 거리에 따라 선이나 그라데이션을 새 레이어에 만듭니다. 옷 끝의 테두리나 끝만 진하게 하는 칠하기에 사용합니다.

  1. 필터 → "UV 가장자리에서 칠하기(새 레이어)"를 선택합니다. 창을 열고 있는 동안은 UV와 3D에 임시 선이 표시됩니다.
  2. "도형"(선·그라데이션)과 "방향"(아일랜드 안쪽·아일랜드 바깥쪽·양쪽)을 선택합니다.
  3. "폭", "가장자리에서 시작", "흐리기", "불투명도"를 맞춥니다. 값을 바꾸면 임시 선이 바로 바뀝니다.
  4. "색"에서 전경색이나 "색 선택"을 선택하고 "만들기"를 누릅니다. 새 레이어가 만들어집니다.
  • 거리는 텍스처의 px입니다. 그라데이션은 가장자리에서 진하고, 폭이 끝나는 곳에서 투명해집니다.
  • 아일랜드끼리 맞닿은 곳은 가장자리가 되지 않습니다. 선택 범위가 있으면 그 안에만 만듭니다.
  • "아일랜드 안쪽"에서는 아일랜드 바깥 가장자리(패딩 폭)에도 가장 가까운 아일랜드 픽셀과 같은 농도로 칠합니다. "아일랜드 바깥 가장자리(패딩)에도 칠하기"를 끄면 칠하지 않습니다.
  • "색 선택"에서는 컬러 세트의 견본이나 색 칸에서 고를 수 있습니다. 투명색일 때는 새 레이어를 만들지 않고 현재 레이어에서 이 가장자리를 지웁니다.
  • 취소나 Esc로 임시 선이 사라집니다. 만든 뒤에는 실행 취소 한 번으로 되돌립니다.

glTF·glb·VRM의 UV 방향

glTF는 이미지의 상하를 세는 방식이 FBX 등과 반대입니다. PetaNuri3D는 glTF·glb·VRM을 열 때 UV를 상하로 뒤집어 FBX와 같은 방향으로 맞춥니다. Blender·UniVRM으로 불러왔을 때와 같은 방향입니다.

  • 모델에 들어 있는 이미지는 원래 방향 그대로 바탕에 들어갑니다.
  • UV 영역의 그림, 내보내는 PNG·PSD·UV 맵은 원래 이미지와 같은 방향입니다. 다른 3D 소프트웨어에서 그대로 맞습니다.
  • 이미지·PSD 가져오기도 상하를 뒤집지 않고 그대로 가져옵니다.
