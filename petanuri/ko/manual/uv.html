UV 영역과 표시 범위

3D 뷰 옆에 UV(텍스처 펼침도)를 배치하여 어느 쪽에서든 칠할 수 있습니다. 옷 아래의 몸이나 머리카락 안쪽은 표시 범위로 앞쪽을 숨기고 칠합니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

Lite·Standard·Pro와 Pro 업그레이드를 BOOTH에서 배포하고 있습니다.

UV 영역 표시

  • UV 표시 방법 3종: 3D만·3D와 UV 나란히·UV만. 3D만일 때는 3D 뷰 오른쪽 끝의 'UV'(U·보기 → UV)로 나란히 배치합니다. 경계 드래그로 너비를 바꿀 수 있습니다.
  • 나란히 배치할 때 UV 영역 오른쪽 위 ×로 UV를 닫고(3D만), 3D 뷰 오른쪽 위 ×로 3D를 닫습니다(UV만).Shift＋U 로 UV만 ⇔ 나란히를 전환합니다. 마지막 표시 방식은 다음에도 유지됩니다.
  • 선택한 텍스처 세트의 UV가 표시됩니다(왼쪽 위에 이름). 세트를 다시 선택하면 전환됩니다.
  • UV 영역 위에서도 펜·붓·지우개·폴리곤 칠하기·채우기·둘러싸인 곳·그라데이션·도형·스탬프·스포이트·흐리기·손가락을 사용할 수 있습니다.
  • UV 영역을 조작하는 동안 3D 뷰에서 브러시 원 안의 면이 빨갛게 강조됩니다 . 3D를 조작하는 동안 UV 영역에 칠할 위치가 빨간 점으로 표시됩니다.
  • 휠로 확대/축소, 가운데 드래그· Space+ 드래그로 이동, '전체'로 전체 보기. '선'으로 UV 선, '아일랜드 가장자리'로 아일랜드 윤곽(▼로 색과 농도).
  • 제목의 ⟲·⟳로 15°씩 회전합니다(회전한 채 칠하기 가능).
  • 제목의 '대칭 X·Y·Z'는 3D 왼쪽 위와 같은 전환입니다(좌우 대칭 그리기).
  • UV 영역이 좁으면 제목에 들어가지 않는 버튼을 '⋯' 패널에 넣습니다.

격자선과 스냅

  • UV 영역 제목의 '그리드'로 격자를 표시·숨깁니다. 옆 ▼에서 칸 수(텍스처 한 변을 2·4·8·16·32·64·128로 분할)와 스냅을 선택합니다. 한 칸이 몇 px인지도 ▼ 안에 표시됩니다.
  • 선은 표시 전용이며 그림·저장·내보내기에 포함되지 않습니다.
  • '이동·변형 시 그리드에 스냅'(기본 켜짐. 격자가 표시될 때만): UV 영역에서 이동·변형 도구·변형(Ctrl＋T)·이미지를 UV에 붙이기의 틀을 움직이면 네 모서리 또는 중앙이 격자선 근처에 스냅됩니다. 모서리·변 손잡이, 자유 변형 모서리, 워프 점도 스냅됩니다.
  • Ctrl 를 누르는 동안 스냅하지 않습니다. 3D 영역 위의 틀은 스냅하지 않습니다.

UV 가이드(확대/이동)

UV 영역 오른쪽 위에 3D 내비와 같은 형태의 가이드가 표시됩니다. 펜만으로 조작할 수 있습니다.

  • 돋보기를 위아래로 드래그하여 확대·축소합니다(위로 확대).손바닥를 드래그하여 이동합니다.사각형로 전체 보기.
  • 위 손잡이로 원하는 위치로 이동하고 왼쪽·아래 가장자리와 왼쪽 아래 모서리로 크기를 바꿉니다.
  • '—'로 작은 원형 아이콘으로 접고 누르면 복원됩니다(보기 → UV → UV 가이드도 가능).

아일랜드 밖으로 나갔을 때(이어 칠하기)

  • UV 영역에 칠할 때 원이 UV 아일랜드 밖으로 나가도 UV 위에서 옆에 있을 뿐인 다른 아일랜드(3D에서는 먼 곳)에는 칠하지 않습니다.
  • 제목의 '이어서 칠하기'(기본 켜짐): 아일랜드 가장자리 이음매에서 벗어난 부분은 3D에서 해당 이음매 너머로 연결된 면에 이어 칠합니다. 이음매에서 끊기지 않습니다. 끄면 그리는 아일랜드 안에만 칠합니다(우클릭 메뉴·보기 → UV에도 같은 전환).
  • UV 아일랜드 밖(어느 면에도 사용되지 않는 곳)에서는 브러시 원이 옅은 점선과 ×가 됩니다. 밖에서 시작한 선은 아일랜드에 들어온 곳부터 적용됩니다. 텍스트·도형·스탬프·그라데이션은 밖에서도 배치할 수 있습니다.

표시 범위(선택한 곳만 표시·숨기기)

  1. UV 영역 또는 3D에서 아일랜드·면을 선택합니다(아일랜드 선택·면 선택·올가미·정점 그룹 등).
  2. 3D 뷰 왼쪽 위 표시 범위 아이콘· Shift＋H·UV 제목의 '선택한 부분만 표시'로 선택한 곳만 3D에 표시합니다.
  3. H(UV 제목의 '선택한 부분 숨기기')로 선택한 곳을 숨깁니다. 여러 번 추가하여 숨길 수 있습니다.
  4. Alt＋H 로 전체 표시로 돌아갑니다.
  • '선택한 부분만 표시' 후에는 선택 범위를 다시 선택하면 다시 누르지 않아도 표시가 바뀝니다(다시 누르면 전체 표시).
  • 숨기면 선택 범위가 해제됩니다 . 보이는 곳에 그대로 칠할 수 있습니다. 해제한 선택 범위는 3D 아래 바의 [선택 범위 복원] 또는 Ctrl＋Shift＋D 로 되돌릴 수 있습니다.
  • 3D 우클릭의 '이 아일랜드 숨기기'·'이 아일랜드만 표시'는 누른 곳의 아일랜드를 그대로 숨기거나 표시합니다(선택 범위·실행 취소 내역은 변경하지 않음).
  • 표시 범위 아이콘의 ▼ : 왼쪽에 '선택 범위에서'(선택한 곳만 표시·선택한 곳 숨기기·선택한 곳도 표시·숨기기 펜)와 '숨긴 부분'(반전·전체 표시·확장/축소·옅게 표시), 오른쪽에 '숨기기 방식'(저장한 숨김 상태 목록)가 있습니다. 숨긴 것이 없을 때는 여기서 조작합니다.
숨긴 부분은 깊이를 가리지 않아 옷 아래의 몸이나 머리카락 안쪽을 보며 칠할 수 있습니다. 숨긴 부분에 직접 그리거나 스포이트·채우기로 선택할 수는 없습니다. 숨긴 쪽 대칭 그리기를 켜면 3D 그리기가 숨긴 대칭 쪽에도 적용됩니다. 오브젝트(메시) 전체도 숨길 수 있습니다(오브젝트 표시·숨김).
숨기기·표시 조작은 실행 취소(Ctrl＋Z) 내역에 포함되지 않습니다. 복원하려면 전체 표시하거나 저장한 숨김 상태를 불러옵니다.

숨기기 펜·3D 아래 바

겹친 천 안쪽을 칠할 때 등 그은 곳을 그대로 숨길 수 있습니다.

  1. 왼쪽 도구 모음 '숨기기 펜'을 선택합니다(3D 아래 바 [숨기기 펜]으로도 전환).
  2. 보조 도구에서 '면으로 숨기기'(사각형 면은 삼각형 2개 함께) 또는 '아일랜드로 숨기기'(UV 아일랜드별)를 선택합니다.
  3. 3D에서 그은 곳이 숨겨집니다. UV 영역을 눌러도 숨길 수 있습니다.
  4. [숨기기 펜]을 다시 누르면 이전 도구로 돌아갑니다.
한 번 그으면 앞쪽을 숨겨 드러난 안쪽 면까지는 숨기지 않습니다. 안쪽도 숨기려면 다시 그으세요.

3D 아래 중앙 바 는 숨김 중과 숨기기 펜 사용 중에만 표시됩니다. [숨기기 펜] [면 | 아일랜드] [숨김 상태 ▼]와 현재 숨김 상태('숨김 상태: ○○'·'일부를 숨기고 있습니다 (저장하지 않은 숨김 상태)'·'선택한 곳만 표시하고 있습니다')·[전체 표시]가 있습니다.

주변 흐리게 표시

  • 숨김 중 3D 아래 바 [주변 흐리게 표시]로 숨긴 곳을 반투명하게 표시합니다. 주변을 확인하며 그릴 수 있습니다.
  • 옆 슬라이더로 농도(5~80%)를 바꿉니다. ▼ 창의 '숨긴 부분' → '흐리게 보기'도 같습니다.
희미하게 보여도 숨긴 부분에 직접 그릴 수는 없습니다. 숨긴 쪽 대칭 그리기를 켜면 3D에서 반대쪽을 칠할 때 숨긴 쪽에도 그려집니다.

숨김 상태 저장

자주 쓰는 숨김 상태에 이름을 붙여 저장하고 언제든 같은 상태로 돌아갈 수 있습니다.

  1. 원하는 곳을 숨깁니다.
  2. 3D 아래 바의 [숨김 상태 ▼](또는 표시 범위 ▼ 창) → '현재 숨김 상태 저장'으로 이름을 정합니다(같은 이름이면 덮어쓰기).
  3. 같은 목록에서 이름을 누르면 해당 숨김 상태로 돌아갑니다.
  • '숨김 프리셋 관리 (이름, 삭제)'로 이름 변경·삭제를 할 수 있습니다.
  • 저장한 숨김 상태와 현재 상태는 작업 파일(.petanuri)에 포함됩니다. 다시 열어도 사용할 수 있습니다.

메시 선·이음선

  • 3D 뷰 왼쪽 위 아이콘(보기 → 선과 자 → 메시 선/이음선)으로 폴리곤 선과 UV 이음매·아일랜드 가장자리를 표시합니다. 이음선은 Alt＋W 로도 전환할 수 있습니다.
  • 아이콘 아래 ▼에서 농도·색(파랑·검정·흰색)·뒷면/안쪽 선도 표시할지 선택합니다.
