레이어

레이어는 텍스처 세트마다 겹쳐져 있습니다. 밑칠·그림자·무늬를 레이어로 나눠 두면 나중에 색이나 농도를 고칠 수 있습니다. 겹치는 방식·마스크·필터 등 레이어에 적용하는 기능도 여기에 정리했습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

먼저 이것만
  1. 레이어 패널의 "추가"(Ctrl+Shift+N)로 새 레이어를 추가합니다(자세히).
  2. 행을 눌러 선택한 레이어에 그립니다. 눈 아이콘으로 표시·숨김을, 불투명도로 농도를 바꿉니다(자세히).
  3. 그림자는 밑칠 위의 레이어에 "클리핑"을 켜고 합성 모드를 "곱하기"로 하면 삐져나오지 않게 칠할 수 있습니다(자세히).
  4. 일부를 지우지 않고 가릴 때는 레이어 마스크를 사용합니다(자세히).
  5. 실수했을 때는 Ctrl+Z를 누릅니다. 작업 내역 패널에서는 여러 단계 전까지 한 번에 되돌릴 수 있습니다(자세히).

레이어를 추가해 나누어 그리기

그린 내용은 선택한 레이어에 들어갑니다. 부분별로 레이어를 나누면 나중에 지우거나 색을 바꾸기 쉬워집니다.

  1. 레이어 패널 아래의 "추가"를 누릅니다. 선택한 레이어 위에 새 레이어가 만들어집니다.
  2. 그리려는 레이어의 행을 눌러 선택합니다.
  3. 그립니다.
  4. 눈 아이콘을 누르면 표시·숨김이 전환됩니다.
  5. 이름을 더블클릭하면 이름을 바꿀 수 있습니다(Enter로 확정).
Lite는 텍스처 세트마다 바탕을 포함해 레이어 4장까지입니다(그리는 레이어와 조정 레이어를 셉니다. 폴더·마스크는 세지 않습니다). 4장이 되면 패널 아래에 "레이어 4 / 4장(바탕 포함, Lite)"이라고 표시되고, "추가"와 "복제"에 자물쇠 표시가 붙습니다.

여러 장 한꺼번에 선택하기

  • 이름을 Ctrl+클릭하면 한 장씩 추가·해제하고, Shift+클릭하면 그 사이를 한꺼번에 선택합니다(썸네일의 Ctrl+클릭은 선택 범위이므로 다릅니다).
  • 선택한 동안에는 표시·합성 모드·불투명도·클리핑·투명 픽셀 잠금·잠금·색 태그·삭제·복제·폴더에 넣기(Ctrl+Shift+G)·병합이 한꺼번에 적용됩니다. 실행 취소는 한 번에 됩니다.
  • 선택한 것 중 하나를 드래그하면 전부가 순서를 유지한 채 움직입니다. 폴더 행의 가운데에서 놓으면 전부가 폴더 안으로 들어갑니다.
  • "한 단계 위로"·"한 단계 아래로"는 한 장씩 적용됩니다. 복사·잘라내기도 선택 중인 한 장에만 적용됩니다.

키나 3D에서 선택하기

  • Alt+]로 위 레이어를, Alt+[로 아래 레이어를 선택합니다.
  • 3D 뷰나 UV 뷰의 우클릭 → "여기에 그린 레이어 선택"을 고르면, 누른 곳에 그려져 있는 표시 중인 레이어가 나열됩니다. 맨 위에는 표시가 붙습니다. 마스크로 가린 곳이나 불투명도 0% 등 보이지 않는 것은 나오지 않습니다.
  • 이동·변형 도구의 "레이어 자동 선택"으로도 선택할 수 있습니다(이동·변형 도구).
  • 이렇게 선택한 행이 보이지 않으면 목록이 보이는 곳까지 이동합니다(닫힌 폴더는 열립니다). 끄려면 …(기타) 또는 목록 우클릭의 "키 등으로 선택한 레이어가 보일 때까지 목록 이동"을 해제합니다.

잘 안 될 때

  • 레이어를 추가할 수 없음(Lite): Lite는 텍스처 세트마다 바탕을 포함해 4장까지입니다. 레이어를 삭제하거나 병합하면 다시 추가할 수 있습니다(에디션).
  • 그려도 색이 나오지 않음: 선택한 레이어가 숨겨져 있거나 잠겨 있는지, 그릴 대상이 마스크로 되어 있지 않은지 확인합니다. 위쪽 레이어에 가려져 있을 수도 있습니다.
  • 다른 레이어에 그리고 있었음: Ctrl+Z로 되돌리고, 3D의 우클릭 → "여기에 그린 레이어 선택"에서 그리려는 레이어를 다시 선택합니다.

그림자와 빛 겹치기(합성 모드·불투명도)

합성 모드는 아래 그림과 섞는 방식입니다. 그림자에는 "곱하기", 빛에는 "스크린"이나 "더하기(발광)"가 자주 쓰입니다.

  1. 그림자나 빛을 그릴 레이어를 선택합니다.
  2. 패널 위쪽의 합성 모드 칸에서 합성 모드를 선택합니다.
  3. 불투명도로 농도를 맞춥니다.

모두 28종류입니다. 칸 안에서는 다음 그룹으로 나뉘어 나열됩니다.

더하기(발광)·색상 닷지(발광)

  • 일반 더하기·색상 닷지와 달리 불투명도를 낮춘 곳이나 부드러운 붓의 가장자리에서도 강하게 빛납니다.
  • 더하기(발광)는 빛이 포화될 때까지 쌓이고, 색상 닷지(발광)는 밝은 곳일수록 강하게 빛납니다. 아래가 투명한 곳에서도 레이어의 색으로 빛납니다.
  • 레이어·폴더·조정 레이어의 합성 모드, 테두리의 합성, 브러시의 렌더링 모드에서 선택할 수 있습니다.
  • PSD에는 비슷한 합성 모드(선형 닷지·색상 닷지)로 저장하고, 레이어 이름 뒤에 "[glow]"를 붙입니다. PetaNuri3D에서 불러오면 발광으로 돌아옵니다. 다른 소프트웨어에서는 반투명한 부분이 보이는 방식이 달라집니다.

삐져나오지 않게 칠하기(클리핑·투명 픽셀 잠금·잠금)

밑칠 위에 그림자나 무늬를 칠할 때, 칠한 곳 밖으로 삐져나오지 않게 합니다. 모두 패널 위쪽의 아이콘으로 켜고 끕니다.

기능하는 일다른 전환 방법
클리핑(↳)이 레이어를 바로 아래 레이어의 칠해진 곳에만 표시합니다(아래 레이어가 기준이 됩니다)Ctrl+Alt+G·우클릭 → "아래 레이어에 클리핑"
투명 픽셀 잠금그려도 투명한 곳은 투명한 채로 남습니다(색만 바뀝니다)레이어 → 클리핑·보호 → "투명 픽셀 잠금 전환"
잠금그릴 수 없게 합니다레이어 → 클리핑·보호 → "잠금 전환"
  1. 밑칠 레이어를 선택하고 "추가"로 위에 레이어를 추가합니다.
  2. 패널 위쪽의 클리핑(↳) 아이콘을 누릅니다.
  3. 합성 모드를 "곱하기"로 하고 그림자를 칠합니다. 밑칠 밖으로는 나가지 않습니다.
클리핑한 그림은 남아 있으므로 밑칠을 넓히면 그곳에도 나타납니다. 투명 픽셀 잠금은 그 레이어의 그림 자체의 모양을 지킵니다.

폴더로 묶기

관련된 레이어를 폴더로 묶으면 목록이 짧아지고, 한꺼번에 표시·숨김이나 불투명도를 바꿀 수 있습니다.

  1. 묶을 레이어를 선택합니다(몇 장이든 가능).
  2. Shift를 누른 채 "폴더" 버튼을 누릅니다(Ctrl+Shift+G). 선택한 레이어가 폴더에 들어갑니다.
  • "폴더" 버튼만 누르면(Ctrl+G) 빈 폴더를 만듭니다.
  • 레이어 행을 폴더 행의 가운데로 드래그하면 안으로 들어가고, 위쪽 절반이나 아래쪽 절반으로 드래그하면 폴더의 위나 아래에 놓입니다.
  • 합성 모드 "통과"(처음 값)는 내용을 폴더 밖의 그림에 직접 겹칩니다. 다른 모드에서는 내용을 한 장으로 만든 다음 겹칩니다.
  • 폴더를 해제하려면 …(기타) 또는 우클릭의 "폴더 해제"를 사용합니다. 내용은 밖으로 나옵니다.
  • 폴더에도 마스크·테두리를 붙일 수 있습니다.

일부 가리기(레이어 마스크)

마스크는 레이어의 그림을 지우지 않고 가립니다. 가린 곳은 나중에 언제든 되돌릴 수 있습니다.

  1. 가리려는 레이어를 선택합니다.
  2. "마스크" 버튼 → "모두 표시 마스크 추가"를 선택합니다. 행에 마스크 썸네일이 붙습니다.
  3. 마스크 썸네일을 누릅니다. 그릴 대상이 마스크가 됩니다.
  4. 검정으로 그리면 가려지고, 흰색으로 그리면 보입니다. 회색은 반쯤 보입니다.
  5. 픽셀 썸네일을 누르면 그릴 대상이 그림으로 돌아옵니다.

마스크 조작 요령

  • Shift+마스크 썸네일로 사용·사용 안 함을 전환합니다(사용하지 않는 동안에는 빨간 사선이 표시됩니다).
  • Alt+마스크 썸네일로 마스크를 흑백으로 표시합니다.
  • 마스크 썸네일을 다른 레이어의 행으로 드래그하면 옮겨지고, Alt+드래그하면 복사됩니다. 조정 레이어의 마스크는 복사됩니다.
  • 붙여넣을 레이어에 마스크가 있으면 바꿔 넣습니다. 크기가 다르면 늘려서 넣습니다.
  • 선택 범위 채우기와 Alt/Ctrl+Backspace의 채우기도 마스크에는 색의 밝기로 들어갑니다.
  • 마스크 조작에는 환경 설정의 키 할당에서 키를 지정할 수 있습니다.

잘 안 될 때

  • 그려도 그림이 바뀌지 않음: 그릴 대상이 마스크 그대로입니다. 픽셀 썸네일을 눌러 그림으로 되돌립니다.
  • 마스크가 적용되지 않음: 마스크가 꺼져(빨간 사선) 있습니다. Shift+마스크 썸네일로 켭니다.
  • 마스크에 그려도 보이는 모습이 바뀌지 않음: 흰색으로 그리면 "보이기"입니다. 가릴 때는 검정으로 그리거나 지우개를 사용합니다.

목록을 보기 쉽게 하기(색 태그·썸네일)

레이어가 늘어나면 색 태그로 나누거나 썸네일을 크게 해서 찾기 쉽게 합니다.

  1. 색을 붙일 레이어를 선택합니다(몇 장이든 가능).
  2. 클리핑·잠금 아이콘 줄의 맨 왼쪽에 있는 색 동그라미와 ▾ 상자를 누릅니다(우클릭 → "색 태그"로도 가능).
  3. 없음·빨강·주황·노랑·초록·하늘·파랑·보라·회색 중에서 고릅니다. 행의 왼쪽에 굵은 색 띠가 붙습니다.
  • 폴더의 색은 안쪽 레이어의 왼쪽에 가는 선으로 이어집니다. 실행 취소는 한 번에 됩니다.
  • 색 태그가 있으면 목록 위에 "색으로 표시: 전체"와 사용 중인 색 동그라미가 나타납니다. 동그라미를 누르면 그 색의 레이어만 목록에 표시됩니다(그림은 바뀌지 않습니다). 다시 누르거나 "전체"를 누르면 돌아옵니다.
  • 색 태그는 작업 파일에 남습니다. PSD 내보내기·가져오기 Standard에서는 PSD 레이어의 색이 됩니다(하늘은 파랑이 됩니다).

목록의 크기·순서

  • …(기타) 또는 우클릭의 "썸네일 크기"에서 작게(24px)·보통(40px. 처음 값)·크게(64px)·아주 크게(96px)를 고를 수 있습니다.
  • …(기타)의 "버튼 줄을 위에 두기"로 아래의 버튼 줄을 목록 위로 옮길 수 있습니다.
  • …(기타)의 "펜 드래그로 레이어와 보조 도구 이동"을 끄면 펜 드래그가 목록 스크롤이 됩니다. Space+드래그는 언제나 스크롤입니다.
  • 패널의 경계를 아래로 드래그하면 목록을 넓힐 수 있습니다.
  • 어느 것이나 다음 실행 때도 그대로입니다.

반복 무늬 깔기

이미지나 무늬를 상하좌우로 반복해서 레이어 가득 깝니다. 옷감의 무늬 등에 사용합니다.

  1. 무늬를 깔 픽셀 레이어를 선택합니다. 현재 그림은 무늬로 바뀝니다.
  2. 레이어 속성의 "반복 무늬"에서 "무늬를 골라 깔기"를 누릅니다. 무늬 목록이 열립니다.
  3. "이미지 파일…"·"참고 이미지" 또는 아래에 나열된 무늬 그림에서 고릅니다. 무늬 그림은 전경색으로 칠한 무늬가 됩니다.
  4. 아래 표의 항목으로 배열 방식을 맞춥니다.

  • 이음매에서 무늬가 이어지지 않음: 양쪽 아일랜드의 방향·모양이 다른 이음매에서는 맞춰도 이어지지 않습니다.

한쪽 그림을 반대쪽에 옮기기(좌우 미러 복사)

대칭으로 그리는 것을 켜지 않고 칠한 부분을 3D 모델의 반대쪽으로 옮깁니다. UV가 좌우에서 달라도 모양으로 상대 위치를 찾아 옮깁니다.

  1. 옮길 레이어를 선택합니다.
  2. 레이어 → "좌우 미러 복사"를 선택합니다(레이어 행의 우클릭에도 있습니다).
  3. "왼쪽 → 오른쪽" 또는 "오른쪽 → 왼쪽"을 누릅니다. 옮겨 받는 쪽의 색은 바뀝니다.
  • 좌우는 모델 기준입니다(정면에서 보면 반대입니다). 중심은 "대칭으로 그리기"의 중심과 같습니다(좌우 대칭으로 그리기).
  • "새 레이어에 복사하기(복사한 부분만 들어감)"를 켜면 복사한 부분만 새 레이어에 들어갑니다.
  • 선택 범위가 있을 때는 "선택 범위의 그림을 반대쪽으로 복사하기" 또는 "선택 범위 안으로 복사하기"(선택 범위 안을 반대쪽 색으로 바꿈)를 선택합니다.
  • 마스크는 마스크 메뉴의 "마스크 좌우 미러 복사"로 옮깁니다.
  • 좌우의 상대를 찾을 수 없는 곳(한쪽에만 있는 것 등)은 그대로입니다. Ctrl+Z 한 번으로 되돌아갑니다.

가장자리 선 넣기(테두리) Standard

레이어의 그림 자체는 바꾸지 않고, 겹칠 때 가장자리 선을 넣습니다. 나중에 굵기나 색을 바꾸거나 끌 수 있습니다.

  1. 가장자리 선을 넣을 레이어를 선택합니다.
  2. 레이어 속성의 "넣기"를 누릅니다. 테두리 창이 표시됩니다.
  3. 크기·위치·색 등을 정합니다. 값을 움직이면 바로 보이는 모습이 바뀝니다.
  4. OK(Enter)로 확정합니다. 취소(Esc)하면 원래대로 돌아갑니다.
항목내용
크기굵기(텍스처의 px)
위치바깥쪽·안쪽·가운데
합성·불투명도·색가장자리 선이 겹치는 방식·농도·색
초기값으로 되돌리기모든 값을 초기값으로. 라벨을 더블클릭하면 그 값만 초기값으로 돌아갑니다

테두리 메뉴

레이어 → 테두리, 또는 레이어의 우클릭 → "테두리"에 나열됩니다. 테두리가 붙은 레이어의 행에는 "fx" 표시가 나타나고, 누르면 설정 창이 열립니다.

  • "테두리 설정": 창을 엽니다.
  • "테두리 표시": 값은 남겨 둔 채 표시·숨김을 전환합니다(레이어 속성의 "표시"와 같습니다).
  • "테두리 복사" "테두리 붙여넣기": 다른 레이어로 복사합니다. 여러 장을 선택했다면 모두에 붙여넣습니다.
  • "테두리 지우기": 테두리를 제거합니다.
  • "테두리를 픽셀로 굽기": 테두리가 포함된 그림으로 만들고 테두리를 제거합니다(폴더는 테두리째 한 장으로 병합).

적용되는 모양과 저장

  • 마스크를 적용한 뒤의 모양에 붙습니다. 클리핑한 레이어는 기준 레이어의 칠해진 곳 안에 들어갑니다.
  • 폴더(내용을 합친 모양)와 텍스트 레이어(다시 입력해도 그대로)에도 넣을 수 있습니다.
  • 아래 레이어와 병합·폴더 병합은 테두리를 굽고 나서 병합합니다.
  • 작업 파일에는 값째로 들어갑니다. PNG·머티리얼 내보내기는 테두리가 포함된 그림, PSD에서는 픽셀로 구운 레이어가 됩니다(PSD).
  • 이전 버전이나 PSD에서 붙은 다른 효과(드롭 섀도 등)는 보이는 모습 그대로 열립니다. 바꿀 수는 없지만, 레이어 속성의 "픽셀로 굽기"·"제거"는 할 수 있습니다.
테두리를 넣거나 바꾸거나 붙여넣는 것은 Standard부터입니다. Lite에서도 열어 둔 작업 파일의 테두리는 보이는 모습 그대로이며, 표시·숨김·복사·지우기·픽셀로 굽기는 할 수 있습니다.

잘 안 될 때

  • 가장자리 선이 아일랜드 가장자리에서 잘림·옆 아일랜드에 걸침: 테두리는 UV 위에서 계산합니다. 아일랜드 가장자리 밖으로 삐져나온 부분은 3D에서는 아일랜드 가장자리에서 잘려 보일 수 있습니다. 내보내면 아일랜드 밖의 부분은 번짐(패딩)과 같은 취급이 됩니다.

나중에 색 바꾸기(조정 레이어) Standard

아래 그림을 고쳐 쓰지 않고 밝기나 색의 보정을 겹칩니다. 값은 언제든 다시 바꿀 수 있습니다.

  1. 보정할 그림 바로 위에 해당하는 레이어를 선택합니다.
  2. 패널의 "조정" 버튼을 눌러 종류를 선택합니다. 조정 레이어가 만들어집니다.
  3. 레이어 속성 패널에서 값을 움직입니다. 움직이는 동안에는 그림만 바뀌고, 놓으면 한 번에 실행 취소할 수 있습니다.

종류는 15가지입니다: 색조/채도/명도, 밝기/대비, 레벨 보정, 계조 반전, 회색 음영, 포스터화, 임계값, 그라데이션 맵, 톤 커브, 색상 균형, 노출, 색온도, 활기, 특정 색 바꾸기, 노이즈 추가. 값의 내용은 필터와 같습니다.

  • 조정 레이어는 아래에 보이는 그림 전체에 적용됩니다.
  • 적용 범위는 마스크로 제한할 수 있습니다. 조정 레이어를 선택하면 그릴 대상은 마스크입니다. "선택 범위로 마스크 만들기"로 현재 마스크를 바꿔 넣을 수 있습니다.
  • 클리핑을 켜면 바로 아래 레이어에만 적용됩니다.
  • "아래 레이어와 병합"으로 보정을 아래 레이어의 픽셀로 구울 수 있습니다.
  • PSD에서는 톤 커브·색상 균형·활기·노출·그라데이션 맵을 조정 레이어인 채로 내보내고 가져옵니다.
  • Lite에서는 열어 둔 작업 파일의 조정 레이어 값은 볼 수 있지만 바꿀 수 없습니다(자물쇠 표시).
흐림·선명·모자이크처럼 주변 그림을 읽는 것은 조정 레이어가 되지 않습니다(무거워지기 때문). 필터로 적용합니다.

필터 적용하기 Standard

선택한 레이어의 그림 자체에 색 보정이나 흐림을 적용합니다. 조정 레이어와 달리 그림이 고쳐 쓰입니다(Ctrl+Z 한 번으로 되돌릴 수 있습니다).

  1. 필터를 적용할 레이어를 선택합니다.
  2. 메뉴 "필터" → 그룹 → 필터 이름을 선택합니다. 작은 창이 표시됩니다.
  3. 값을 움직입니다. 모델의 보이는 모습이 그 자리에서 바뀝니다.
  4. OK(Enter)로 확정합니다. 그만두려면 취소(Esc)입니다.

아일랜드 가장자리와 투명한 부분의 처리

  • 흐림·선명 필터는 UV 아일랜드 안에서만 계산합니다. 아일랜드 가장자리가 어두워지거나 옅어지지 않습니다. 이음매를 넘어 흐리게 할 때는 색 혼합 도구를 사용합니다(흐리기·손가락·색 혼합).
  • 모자이크는 투명도도 칸마다 평균을 내고, 선명하게는 투명도도 또렷하게 합니다. 노이즈 줄이기(중간값)는 투명한 곳 위의 점도 지웁니다.

  • 투명 픽셀 잠금 레이어에서는 투명도가 원래대로 유지됩니다.

  • 필터를 적용해도 변하지 않음: 숨김·잠금 레이어에는 적용되지 않습니다. 선택 범위가 다른 텍스처 세트에만 있을 때도 변하지 않습니다. 창의 "대상"과 "적용 안 함:"을 확인합니다.
  • 메뉴에 자물쇠 표시가 붙어 있음(Lite): 필터는 Standard부터입니다. 휘도를 투명도로 변환·패딩을 새 레이어에 만들기는 Lite에서도 사용할 수 있습니다.

그라데이션 맵으로 색 바꾸기 Standard

  1. 필터 → 계조 → "그라데이션 맵"을 선택합니다(조정 레이어라면 "조정" 버튼에서). 처음에는 전경색 → 배경색의 2색입니다.
  2. 프리셋에서 고르거나 색 지점을 추가해 색을 정합니다.
  3. OK(Enter)로 확정합니다.

흰색을 투명하게 만들기(휘도를 투명도로 변환)

흰 곳을 투명하게 하고, 어두운 곳을 검은 그림자로 남깁니다. AO의 그림자만 다른 색으로 하고 싶을 때 등에 사용합니다. Lite부터 사용할 수 있습니다.

  1. AO 등 바탕 이외의 그리는 레이어를 선택합니다. 잠금이나 투명 픽셀 잠금이 켜져 있으면 끕니다.
  2. 필터 → "휘도를 투명도로 변환"을 선택합니다. 흰색은 투명하게, 어두운 곳일수록 불투명한 검정이 됩니다.
  3. 그림자의 색을 바꿀 때는 투명 픽셀 잠금을 켜고 원하는 색으로 칠합니다. 그림자의 농담은 투명도로 남습니다.
선택한 레이어의 픽셀을 고쳐 씁니다(Ctrl+Z로 되돌릴 수 있습니다). 바탕·마스크·조정 레이어에는 사용할 수 없습니다. 원래 색을 유지한 채 투명하게 만드는 기능은 아닙니다.

아일랜드 밖으로 색을 넓힌 레이어 만들기(패딩을 새 레이어에 만들기)

현재 그림의 아일랜드 가장자리 색을 아일랜드 밖으로 넓힌 부분만 새 레이어에 넣습니다. 내보내기 번짐(패딩)을 레이어로 보거나 다시 그리고 싶을 때 사용합니다. 어느 에디션에서나 사용할 수 있습니다.

  1. 필터 → "패딩을 새 레이어에 만들기"를 선택합니다.
  2. "폭(px)"을 1~32로 정합니다.
  3. "만들기"를 누릅니다. 선택한 레이어 바로 위에 "패딩(8px)" 같은 이름의 레이어가 만들어집니다.
  • 모든 레이어를 겹친 색으로 만듭니다. 아일랜드 안쪽은 투명합니다.
  • Ctrl+Z 한 번으로 되돌릴 수 있습니다. 2D 캔버스에서는 만들 수 없습니다.
  • 내보내기 번짐은 내보내기 번짐(패딩)을 참고하세요.

선화로 밑칠 만들기(자동 채색)

선화로 구분된 곳마다, 놓아 둔 색 힌트로 나눠 칠합니다. 밑칠을 빠르게 만들 때 사용합니다.

  1. 레이어 → "자동 채색(색 힌트로 나눠 칠하기)"을 선택합니다. 3D 뷰의 왼쪽 위에 창이 표시됩니다.
  2. "선화"에서 선화 레이어를 선택합니다.
  3. "힌트 레이어 만들기"를 누릅니다. 힌트용 새 레이어가 선택됩니다.
  4. 힌트 레이어에 칠하고 싶은 색을 각각의 곳에 대충 놓습니다.
  5. "실행"을 누릅니다. 선화 바로 아래에 "자동 채색" 레이어가 만들어집니다(선 아래까지 칠합니다).

  • 패널은 표시 → 창에서 표시하거나 숨깁니다.

실행 취소할 수 없는 조작

그림(레이어·마스크·칠할 대상·머티리얼 설정)을 바꾸는 조작은 실행 취소할 수 있습니다. 보이는 모습만 바꾸는 조작과 앱의 설정은 실행 취소에 포함되지 않습니다.

  • 포함되지 않는 것: 텍스처 세트의 표시 켜기/끄기·표시 범위(숨기기·선택한 부분만 표시·모두 표시)·오브젝트 표시·블렌드 셰이프·시점·표시 형식·메시 선·컬러 세트의 추가와 정렬·보조 도구·설정·키 할당. 레이어의 표시는 그림의 일부이므로 되돌릴 수 있습니다.
  • 선택한 부분 숨기기(H)는 해제되는 선택 범위만큼이 한 단계에 들어갑니다. 숨긴 부분을 되돌리는 것은 "모두 표시"(Alt+H)입니다(표시 범위). 숨긴 직후의 Ctrl+Z는 첫 번째에는 알리기만 하고, 한 번 더 누르면 그 전의 칠을 되돌립니다.
  • 컬러 세트의 견본 삭제는 실행 취소할 수 있습니다.
다음 조작은 실행 취소할 수 없으므로 먼저 확인이 표시됩니다: 보조 도구 삭제·컬러 세트 삭제·키 할당 초기화·브러시 크기 목록 초기화. 텍스처의 해상도를 바꾸면 실행 취소 내역이 모두 사라집니다.

레이어 쉬게 하기(메모리 절약)

해상도 4096의 레이어를 많이 겹쳐도 무거워지지 않도록, 한동안 만지지 않은 레이어를 GPU 메모리에서 내려 보관합니다. 보이는 모습·내보내기·저장은 그대로입니다.

  • GPU에는 선택한 레이어와 그 아래를 합친 그림, 위를 합친 그림만 둡니다. 다른 레이어는 그리지 않는 동안 한 장씩 줄여서 보관합니다(칠하지 않은 곳은 보관하지 않습니다).
  • 쉬고 있는 레이어를 선택하거나 그리거나 실행 취소하거나 병합하거나 내보내면 그 자리에서 돌아옵니다. 많은 레이어를 다시 불러와야 하는 선택 방식에서는 "준비하는 중…"이 표시된 뒤에 전환됩니다(4096의 80장에서 0.1~0.3초 정도).
  • 위에 표준 이외의 합성 모드 레이어나 조정 레이어가 있으면 그만큼은 GPU에 남습니다.
  • 작업 파일을 열 때도 레이어는 쉬는 상태로 열립니다.
  • 끄려면 파일 → 환경 설정 → 그리기 → 성능의 "그리지 않는 레이어 쉬게 하기"를 해제합니다(처음에는 켜져 있음). 끄면 모든 레이어를 GPU에 둡니다.
선택하지 않은 텍스처 세트를 통째로 쉬게 하는 구조도 있습니다(텍스처 세트의 메모리 절약).
