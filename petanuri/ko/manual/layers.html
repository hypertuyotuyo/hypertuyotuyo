레이어

레이어는 텍스처 세트별로 겹쳐 있습니다. 2D 일러스트와 같은 감각으로 겹쳐 칠할 수 있습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

Lite·Standard·Pro와 Pro 업그레이드를 BOOTH에서 배포하고 있습니다.

레이어 기본

  • 패널 맨 위 제목 행에서 텍스처 세트를 전환할 수 있습니다(2개 이상일 때. 오른쪽에 해상도).
  • 그 아래에 합성 모드·불투명도, 클리핑·투명 픽셀 잠금·잠금 아이콘이 있습니다(누르면 전환. 색 있으면 켜짐).
  • 아래 아이콘 버튼: 추가·폴더·조정·복제·삭제·병합·마스크·한 단계 위로·한 단계 아래로·기타(펜을 대면 이름과 현재 키 표시).
  • 맨 아래 '바탕'은 새로 만들기에서 정한 색·이미지를 포함한 레이어입니다. 바탕에도 직접 그릴 수 있습니다.
  • 합성 모드는 26종입니다(일반·곱하기·스크린·오버레이·더하기·소프트 라이트·하드 라이트·색상·컬러·휘도 등).
  • 다중 선택: 이름을 Ctrl+ 클릭으로 한 장씩, Shift+ 클릭으로 사이 전체를 선택합니다. 표시·합성 모드·불투명도·클리핑·보호·잠금·삭제·복제·폴더에 넣기·병합을 한꺼번에 적용합니다(실행 취소 한 번).
  • 키만으로 선택: Alt＋](위 레이어)·Alt＋[(아래 레이어). 3D 우클릭 → '여기에 그린 레이어 선택'으로 누른 위치에 그린 레이어를 선택합니다.
  • 펜으로 레이어 행을 직접 드래그하여 재정렬합니다. 목록 스크롤은 Space+ 드래그입니다.
Lite는 텍스처 세트별로 바탕 포함 최대 레이어 4장 입니다(그리기 레이어와 조정 레이어를 셉니다. 폴더·마스크는 제외). 4장이 되면 패널 아래에 '레이어 4 / 4장(바탕 포함·Lite)'이 표시되고 '추가'·'복제'에 자물쇠가 표시됩니다. Standard부터 무제한 사용할 수 있습니다.
레이어가 많을 때는 패널 경계를 아래로 드래그해 목록을 넓힐 수 있습니다. 도킹·탭·독립 창에서도 높이에 맞춰 목록이 늘어나며 위 설정과 아래 조작 버튼은 유지됩니다.
색 태그(모든 버전): 레이어 행 왼쪽의 색 상자나 오른쪽 클릭 → 색 태그에서 없음·빨강·주황·노랑·초록·하늘·파랑·보라·회색을 고릅니다. 여러 개를 선택하면 함께 붙고 실행 취소는 한 번입니다. 색이 붙은 행은 왼쪽 띠와 행 색으로 알 수 있고, 폴더의 색은 안의 레이어까지 선으로 이어집니다.
색 태그가 있는 레이어가 있으면 목록 위에 “색으로 표시”와 사용 중인 색 동그라미가 나옵니다. 동그라미를 누르면 그 색의 레이어만 목록에 표시합니다. 색 태그는 작업 파일에 저장되며 PSD 내보내기·가져오기(Standard·Pro)에서는 Photoshop 레이어 색상과 연동합니다(하늘은 파랑이 됩니다).
…(기타)의 썸네일 크기에서 작게(24px)·보통(40px)·크게(64px)·아주 크게(96px)를 고를 수 있습니다. 같은 곳의 “버튼 줄을 위에 두기”로 아래 버튼 줄을 목록 위로 옮깁니다. 둘 다 다음 실행에도 유지됩니다.
여러 개 선택한 레이어 중 하나를 드래그하면 선택한 전부가 순서대로 움직입니다(폴더 행 가운데에 놓으면 폴더 안으로). 이름을 바꾸는 동안에는 마우스 드래그로 글자를 선택할 수 있습니다.
좌우 미러 복사(모든 버전): 레이어 → “좌우 미러 복사”(레이어 행의 오른쪽 클릭에도)로 한쪽에 그린 색을 3D 모델의 반대쪽에 복사합니다. “왼쪽 → 오른쪽”“오른쪽 → 왼쪽”(모델 기준 좌우). UV가 좌우로 달라도 상대 위치에 들어가며, 선택 범위가 있으면 그 안을 복사 대상으로 합니다. “새 레이어에 복사하기”를 켜면 복사한 부분만 새 레이어에 들어갑니다. Ctrl+Z 한 번으로 되돌립니다.

폴더·레이어 마스크

  • 폴더: '폴더' 버튼(Ctrl＋G)으로 만듭니다. Shift+ 버튼(Ctrl＋Shift＋G)으로 선택한 레이어를 폴더에 넣습니다. 행을 폴더 중앙으로 드래그하면 안에 들어갑니다. 합성 모드 '통과'(기본값) 이외의 모드는 내용물을 한 장으로 만든 후 겹칩니다.
  • 레이어 마스크: '마스크' 버튼 → 모두 표시/모두 숨김 마스크 추가(선택 범위에서도 가능). 마스크 썸네일을 누르면 마스크에 그릴 수 있습니다(그리기 = 표시·지우개 = 숨김).
  • Shift+ 마스크 썸네일로 활성/비활성 전환. '마스크 범위 표시'·반전·적용(픽셀에 베이크)·삭제도 가능합니다.
마스크(모든 버전): “마스크” 버튼·오른쪽 클릭의 “마스크” → “마스크 복사”, 다른 레이어에서 “마스크 붙여넣기”(다른 텍스처 세트에도). 마스크 썸네일을 다른 레이어 행으로 드래그하면 옮기고, Alt＋드래그로 복사합니다.
마스크에 그리면 그리기 색의 밝기가 그대로 보이는 양이 됩니다(흰색＝보이기·검정＝숨기기·회색＝절반). 이전 방식은 “마스크” → “마스크에 그리기 색의 밝기로 그리기”를 끕니다. “마스크를 흑백으로 표시”(Alt＋마스크 썸네일도)로 마스크만 흑백으로 볼 수 있고, “이 레이어의 밝기를 마스크로 복사”로 그린 흑백 그림을 마스크로 만들 수 있습니다.

레이어 속성

선택한 레이어 설정을 모은 패널입니다(기본 배치에서는 레이어 패널 바로 위).

  • 제목에 레이어 종류(레이어·폴더·텍스트 레이어·조정 레이어·칠할 대상 폴더 등)와 이름이 표시됩니다.
  • 조정 레이어: 값 항목. 슬라이더를 움직이는 동안 그림만 바뀌며 놓으면 한 번에 실행 취소할 수 있습니다.
  • 픽셀 레이어·폴더·텍스트 레이어: '테두리' 표시·'넣기'·'설정'.
  • 텍스트 레이어는 '텍스트 다시 입력', 마스크가 있는 레이어는 마스크 상태가 표시됩니다.
  • 합성 모드·불투명도·클리핑·투명 픽셀 잠금·잠금은 레이어 패널에서 변경합니다.
반복 무늬(모든 버전): 픽셀 레이어의 레이어 속성 “반복 무늬”에서 “무늬를 골라 깔기…”로 이미지 파일·참고 이미지·무늬(그리기 색)를 고르면 상하좌우로 반복하는 무늬로 레이어 전체에 깝니다(지금의 픽셀은 바뀌며 실행 취소할 수 있습니다). UV 이음매에 맞출 수도 있습니다.
반복 무늬: 맨 위 행에 지금 무늬의 그림과 이름이 나오고, 누르면 무늬 목록이 열립니다. 바로 아래의 “전경색으로 다시 칠하기”로 무늬 모양은 그대로 두고 지금의 전경색으로 바꾸며, “이미지 색으로 되돌리기”로 원래 색으로 돌립니다.

테두리 (레이어 외곽선) Standard

레이어 그림 자체를 바꾸지 않고 합성할 때 테두리를 더합니다. 나중에 굵기·색을 변경하거나 끌 수 있습니다.

  • 열기: 레이어 우클릭 → '테두리'·'레이어' 메뉴 → '테두리'·레이어 속성의 '넣기'·'설정'. 테두리가 있는 레이어 행에 'fx'가 표시되며 누르면 같은 창이 열립니다.
  • 설정: 크기(굵기. 텍스처 px)·위치(바깥·안쪽·중앙)·합성·불투명도·색. 값을 바꾸면 모습이 즉시 변경되며 OK(Enter)로 확정, 취소(Esc)로 원래 상태로 돌아갑니다.
  • 마스크 적용 후 형태에 적용됩니다. 클리핑 레이어는 기반의 칠해진 곳 안에 제한됩니다. 폴더·텍스트 레이어에도 적용할 수 있습니다.
  • 우클릭 → '테두리': 표시 전환·복사·붙여넣기(다중 선택이면 전체)·지우기·픽셀에 베이크.
  • 저장: 작업 파일에 값과 함께 포함됩니다. PNG·머티리얼 내보내기는 테두리 포함 그림, PSD는 테두리를 픽셀에 베이크한 레이어입니다.
테두리은 UV 위에서 계산하므로 아일랜드 가장자리 밖으로 나간 테두리가 3D에서 아일랜드 가장자리에 잘려 보일 수 있습니다.
테두리 추가·변경은 Standard부터 가능합니다. Lite에서도 작업 파일의 테두리 모습이 유지되며 표시·숨기기·복사·지우기·픽셀에 베이크가 가능합니다.

조정 레이어·필터 Standard

  • 조정 레이어: '조정' 버튼 → 색상·채도·명도/밝기·대비/레벨 보정/계조 반전/그레이스케일/포스터화/임계값/그라데이션 맵. 아래 그림을 변경하지 않고 보정합니다. 값은 레이어 속성 패널에서 바꿉니다. 마스크로 적용 범위를 제한하거나 클리핑으로 바로 아래 레이어에만 적용할 수 있습니다.
  • 필터('필터' 메뉴): 색상·채도·명도/밝기·대비/레벨 보정/포스터화/임계값/그라데이션 맵/흐리기(가우시안)/선명하게(언샵 마스크)/계조 반전/그레이스케일. 선택한 레이어에 적용됩니다('표시 중인 모든 텍스처 세트에 적용'도 가능).
  • 필터 창에서 값을 바꾸면 모델 모습이 즉시 변경되며 OK(Enter)로 확정, 취소(Esc)로 원래 상태로 돌아갑니다. 창이 열린 상태에서도 시점을 움직일 수 있습니다.
  • 흐리기·선명하게는 UV 아일랜드 안에서만 계산하므로 아일랜드 가장자리가 어두워지지 않습니다.
필터(Standard·Pro): 메뉴 “필터”를 색조 보정·계조·흐림·선명·노이즈·효과의 하위 메뉴로 정리하고, 톤 커브·색상 균형·색온도·활기·특정 색 바꾸기·노출·동작 흐림·방사형 흐림·하이 패스·노이즈 추가·노이즈 감소(미디언)·모자이크·선화 추출·엠보스를 추가했습니다.
조정 레이어에도 톤 커브·색상 균형·색온도·활기·특정 색 바꾸기·노출·노이즈 추가를 추가했습니다. PSD에서는 톤 커브·색상 균형·활기·노출을 조정 레이어 그대로 내보내고 불러옵니다. 조정 레이어의 마스크는 선택 범위로 만들 수 있습니다(지금 마스크를 교체).

휘도를 투명도로 변환

필터 → 휘도를 투명도로 변환은 Lite부터 사용할 수 있습니다. 흰 배경을 투명하게 하고 어두운 부분을 검은 그림자로 남깁니다. AO 그림자만 다른 색으로 바꿀 때 사용할 수 있습니다.

  1. AO 등 바탕 이외의 그리기 레이어를 선택합니다. 잠금이나 투명 픽셀 잠금이 켜져 있으면 해제합니다.
  2. '휘도를 투명도로 변환'을 실행합니다. 흰색은 투명하게, 어두운 곳일수록 불투명한 검은색이 됩니다.
  3. 그림자 색을 바꾸려면 변환 후 투명 픽셀 잠금을 켜고 원하는 색으로 칠합니다. 그림자 농담은 투명도로 남습니다.
조정 레이어가 아닌 선택한 레이어 픽셀을 변환하는 필터입니다. 바탕·마스크·조정 레이어에는 사용할 수 없습니다. 원래 색을 유지하며 투명하게 하는 기능은 아닙니다. Ctrl＋Z 로 되돌릴 수 있습니다.

그라데이션 맵 Standard

  • 어두운 곳 → 밝은 곳을 그라데이션 왼쪽 → 오른쪽 색으로 바꿉니다. 필터와 조정 레이어 모두에 있습니다.
  • 색 점 최대 32개: 바 클릭으로 추가·드래그로 이동·아래로 끌어내어 삭제·더블클릭으로 색 선택. 점별 불투명도·균등 배치·좌우 바꾸기.
  • 프리셋 240개(파랑·빨강·노을·무지개·파스텔·네온·메탈·피부·계절·사진 색보정·애니메이션 채색 등). 이름으로 찾을 수 있습니다. 현재 그라데이션은 '현재 것 저장'으로 내 프리셋에 저장합니다.
  • 작업 파일·PSD에도 색 점 그대로 유지됩니다.

그리기 도구와 베이크에도 같은 색·투명도 점 편집과 프리셋이 있습니다. 그리기 도구는 Lite부터, 베이크는 Pro입니다(그리기 도구의 그라데이션／베이크 그라데이션).

자동 채색(선화에서 밑칠)

  1. 레이어 → 자동 채색을 열고 '힌트 레이어 만들기'를 누릅니다.
  2. 힌트 레이어에 칠할 색을 각 위치에 대략 놓습니다.
  3. '실행'을 누르면 선으로 나뉜 영역별로 힌트 색으로 칠한 레이어가 선화 바로 아래에 생성됩니다(선 아래까지).
선은 보이는 면 위에서 닫히도록 그려 주세요. 끊기면 그곳으로 색이 새어 나옵니다. 'UV 이음매를 넘어 칠하기'로 몸 앞뒤가 별도 아일랜드여도 이어 칠할 수 있습니다.

작업 내역과 실행 취소

  • 오른쪽 '작업 내역' 패널에 지금까지의 조작이 표시됩니다. 행을 누르면 해당 조작 직후까지 한 번에 뒤로/앞으로 이동합니다.
  • 실행 취소 Ctrl＋Z·다시 실행 Ctrl＋Y(Ctrl＋Shift＋Z). 최대 30단계를 기록합니다.
  • 그림(레이어·마스크·칠할 대상·머티리얼 설정)을 바꾸는 조작은 실행 취소할 수 있습니다. 보기만 바꾸는 조작(표시 범위·오브젝트 표시·블렌드 셰이프·시점·표시 방식 등)과 앱 설정은 포함되지 않습니다.
  • 해상도를 변경하면 실행 취소 내역이 모두 지워집니다(변경 전 확인).

레이어 쉬게 하기(메모리 절약)

  • 4096 레이어를 여러 장 겹칠 때를 위해 한동안 사용하지 않은 레이어는 그리지 않는 동안 작게 보관합니다(GPU 메모리 절약). 모습·내보내기·저장은 유지됩니다.
  • 쉬는 레이어를 선택하거나 그리면 즉시 복원됩니다. 여러 레이어를 다시 불러올 때는 '준비하는 중…' 표시 후 전환됩니다.
  • 파일 → 환경 설정 → 그리기 → '성능'에서 끌 수 있습니다(기본 켜짐).
