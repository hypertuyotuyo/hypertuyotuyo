내보내기

칠한 텍스처를 Unity 등에서 사용하는 이미지(PNG·PSD)로 만듭니다. 작업 파일(.petanuri) 저장은 이어서 그리기 위한 것이며, 모델에 붙이는 이미지는 되지 않습니다. 이미지로 만드는 것이 "내보내기"입니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

먼저 이것만
  1. 파일 → 내보내기 → PNG로 내보내기(모든 세트)로 모든 텍스처를 한 번에 PNG로 만듭니다(자세히).
  2. 창의 "번짐(패딩)"은 처음 값인 8 px 그대로 두어도 됩니다. 게임 안에서 이음매에 선이 보이면 넓힙니다(자세히).
  3. 같은 폴더로 여러 번 내보낼 때는 "매번 묻지 않고 이 폴더로 내보내기"를 켭니다(자세히).
  4. 레이어를 나눈 채 전달할 때는 PSD로 내보냅니다 Standard(자세히).

PNG로 내보내기

텍스처 세트의 그림을 세트당 PNG 한 장으로 만듭니다. Unity 등에서 모델에 붙이는 것이 이 이미지입니다.

  1. 파일 → 내보내기 → "PNG로 내보내기(모든 세트)"를 선택합니다. 하나만 내보낼 때는 "PNG로 내보내기(선택 중인 세트)"입니다.
  2. 내보내기 창에서 "해상도", "번짐(패딩)", "내보내기 위치"를 확인하고 "내보내기"를 누릅니다.
  3. 저장 위치를 물으면 폴더를 선택합니다. 모든 세트일 때는 폴더를 한 번만 선택하면 됩니다.
  4. "○○을(를) 내보냈습니다"라고 표시되고, 내보낸 폴더가 탐색기에서 열립니다.

내보내지는 파일

파일 이름내용
<세트 이름>.png보이는 레이어를 겹친 그림. 세트 이름은 머티리얼의 이름입니다
<세트 이름>_main2nd.png·<세트 이름>_main3rd.png Pro메인 컬러 2nd/3rd 폴더가 있는 세트. 그 마스크를 칠했다면 _mask가 붙은 파일도 만들어집니다(메인 컬러 2nd·3rd)
<세트 이름>_normal.png Pro칠할 대상의 노멀 맵 폴더가 있는 세트(칠할 대상)
  • 같은 이름이 되는 세트는 _2, _3을 붙여 구분합니다.
  • 표시를 끈 세트도 모든 세트에 포함됩니다. 대상이 없는 세트(!)는 포함되지 않습니다. 필요할 때는 그 행을 우클릭하여 "PNG로 내보내기(아일랜드 밖으로 넓히지 않음)"로 내보냅니다(대상이 없는 세트).
  • 테두리 등의 효과는 효과가 포함된 그림이 됩니다. 간편 베이크 등으로 구운 빛·그림자·질감도 보이는 레이어의 색으로 들어갑니다.
  • 표시 범위나 오브젝트로 숨겨 놓았더라도 텍스처는 그대로 내보냅니다.
  • 텍스처 세트 행을 우클릭하여 "PNG로 내보내기"를 선택해도 그 세트를 내보낼 수 있습니다.

크기를 바꿔 내보내기

내보내기 창의 "해상도"에서 텍스처 세트의 해상도와 다른 크기로 만들 수 있습니다. "그대로(세트의 해상도)"·512×512·1024×1024·2048×2048·4096×4096·8192×8192 중에서 선택합니다.

  • 번짐은 세트의 해상도로 붙인 다음 축소·확대합니다.
  • PNG(선택 중인 세트·모든 세트)·선택한 레이어·UV 맵·머티리얼 내보내기에 적용됩니다. PSD에는 적용되지 않습니다(항상 세트의 해상도).
  • 그릴 때의 해상도를 바꾸는 것은 텍스처 세트 패널입니다(해상도 바꾸기).

잘 안 될 때

  • 게임 안에서 UV 이음매에 선이 보입니다: 번짐이 부족합니다. 8 px보다 넓혀서 다시 내보냅니다(번짐).
  • "○○이(가) 표시된 동안에는 내보낼 수 없습니다"라고 표시됩니다: 변형 틀·필터 미리보기 등이 표시되어 있습니다. 확정(Enter)하거나 취소(Esc)한 뒤에 내보냅니다.
  • "다른 읽기/쓰기 작업이 진행 중입니다"라고 표시됩니다: 저장·자동 저장·불러오기가 진행 중입니다. 끝난 뒤 다시 누릅니다.
  • "표시 처리가 멈춰서 내보낼 수 없습니다"라고 표시됩니다: 작업 파일이나 자동 저장에서 다시 연 다음 내보냅니다(메모리 절약).
  • "PNG로 내보낼 수 있는 텍스처 세트가 없습니다"라고 표시됩니다: 선택한 것이 대상이 없는 세트(!)입니다. 다른 세트를 선택하거나 레이어를 옮긴 뒤 내보냅니다.
  • 눌러도 "내보내기를 취소했습니다"가 됩니다: 내보내기 창이나 저장 위치 창에서 취소를 눌렀습니다. 창에서 바꾼 값도 원래대로 돌아갑니다.

선택한 레이어만 PNG로 만들기

선화만, 무늬만처럼 일부 레이어를 배경이 투명한 PNG로 만듭니다.

  1. 레이어 패널에서 내보낼 레이어를 선택합니다(Ctrl/Shift+클릭으로 몇 장이든 선택할 수 있습니다).
  2. 파일 → 내보내기 → "PNG로 내보내기(선택한 레이어)"를 선택합니다(레이어를 우클릭한 메뉴의 "선택한 레이어를 PNG로 내보내기", "이 레이어를 PNG로 내보내기"로도 가능합니다).
  3. 2장 이상일 때는 창의 "선택한 레이어"에서 "한 장씩(레이어마다 파일)" 또는 "겹쳐서 한 장으로"를 선택하고 "내보내기"를 누릅니다.
선택 방식파일 이름
한 장씩<세트 이름>_<레이어 이름>.png
겹쳐서 한 장으로<세트 이름>_layers.png(패널의 순서대로 합성 모드째 겹칩니다)
  • 배경은 투명합니다. 그린 부분만의 그림이므로 번짐은 붙이지 않습니다.
  • 이전 선택 방식을 기억합니다.
  • 2D 페인트에서는 사용할 수 없습니다. "PNG로 내보내기(선택 중인 세트)"로 내보냅니다(자세히).

UV 맵을 PNG로 내보내기

UV의 선을 PNG로 만듭니다. 다른 페인트 소프트에서 밑그림으로 겹쳐 그릴 때 사용합니다.

  1. 내보낼 텍스처 세트를 선택합니다.
  2. 파일 → 내보내기 → "UV 맵을 PNG로 내보내기(선택 중인 세트)"를 선택합니다(텍스처 세트 행의 우클릭 메뉴에도 있습니다).
  3. 창에서 아래 항목을 선택하고 "내보내기"를 누릅니다. <세트 이름>_uv.png가 만들어집니다.
항목선택할 수 있는 것
해상도그대로(세트의 해상도)·512~8192
선 색흰색·검정·전경색
바탕투명·검정·흰색(투명이면 다른 소프트에서 그림 위에 겹칠 수 있습니다)
선 굵기1·2·3·4·6·8px
섬 가장자리"섬 가장자리를 2배 굵기로 그리기"(처음에는 켜져 있습니다)
내보내기 위치다른 내보내기와 같습니다(자세히)
  • 2D 캔버스에는 UV가 없으므로 내보낼 수 없습니다. 3D 모델의 텍스처 세트를 선택하세요.
  • PetaNuri3D 안에서 UV 선을 보기만 하려면 UV 영역의 "UV 선"을 사용합니다(UV를 표시해 직접 칠하기).

PSD로 내보내기·가져오기 Standard

레이어를 나눈 채 PSD로 만듭니다. 다른 페인트 소프트에서 이어서 그릴 때나, 개변용 PSD로 배포할 때 사용합니다.

  1. 파일 → 내보내기 → "PSD로 내보내기(선택 중인 세트)" 또는 "PSD로 내보내기(모든 세트)"를 선택합니다.
  2. 내보내기 창에서 번짐과 내보내기 위치를 확인하고 "내보내기"를 누릅니다.
  3. <세트 이름>.psd가 만들어집니다. 끝나면 크기와 레이어 수가 표시됩니다.

PSD에 들어가는 것

  • 레이어·표시·불투명도·합성 모드·클리핑·투명 픽셀 잠금·폴더·레이어 마스크·색 태그(레이어의 색)를 유지합니다.
  • 조정 레이어도 조정 레이어 그대로 들어갑니다(그라데이션 맵은 색 지점 그대로). 색조·채도·명도의 "색상화"는 들어가지 않습니다.
  • 테두리는 픽셀로 구운 레이어로 씁니다. 텍스트 레이어는 일반 레이어가 됩니다.
  • 테두리·드롭 섀도·외부 광선만 있는 바탕 레이어와 클리핑한 레이어는 별개의 레이어로 씁니다. 효과만 구운 "(레이어 이름)(효과)" 레이어를 위에 추가합니다. 칠 불투명도·내부 효과 등이 있을 때는 한 장으로 합칩니다.
  • Pro 칠할 대상·노멀 맵·메인 컬러 2nd/3rd 폴더는 숨겨진 그룹으로 씁니다. PetaNuri3D에서 가져오면 원래대로 돌아옵니다.
  • 합성 이미지(PSD를 열지 않고 읽는 평평한 그림)에는 번짐이 붙습니다. 레이어 자체는 그린 그대로입니다.
조정 레이어의 수식은 다른 앱에서 열면 모습이 조금 달라질 수 있습니다.

PSD 가져오기

아바타에 딸려 오는 개변용 PSD를 가져와서 이어서 그릴 수 있습니다. 가져오면 그 세트의 레이어가 PSD의 내용으로 교체됩니다.

  1. 파일 → 가져오기 → "PSD 가져오기(레이어 교체)"를 선택합니다.
  2. PSD를 선택합니다. 파일 이름이 세트 이름과 같은 세트(body.psd → body)에 들어갑니다. 맞는 세트가 없으면 선택 중인 세트에 들어갑니다.
  • PSD를 창에 드롭해도 같은 방식으로 들어갑니다. 텍스처 세트 행에 드롭하면 그 세트에 들어갑니다(이미지나 PSD 추가하기).
  • 크기가 다르면 세트의 해상도에 맞춰 확대·축소합니다. 폴더·마스크·대응하는 조정 레이어는 그대로입니다.
  • 맞지 않는 합성 모드는 "표준"으로, 지원하지 않는 조정 레이어는 건너뛰고 오른쪽 아래에 주의 메시지를 표시합니다.
  • 실행 취소(Ctrl+Z) 1번으로 되돌릴 수 있습니다.
  • 새로 만들 때 시작을 "PSD"로 하여 가져올 수도 있습니다(3D 모델 열기).

내보내기 번짐(패딩)

UV 아일랜드 바깥으로 가장자리의 색을 넓혀서 내보냅니다. 넓히지 않으면 게임 안에서 축소나 밉맵이 적용될 때 UV 이음매(심)에 선이 보일 수 있습니다.

  1. 내보내기 창의 "번짐(패딩)"에서 넓힐 폭을 선택합니다.
  2. "내보내기"를 누릅니다.
선택할 수 있는 값내용
없음(아일랜드 바깥으로 넓히지 않음)아일랜드 바깥은 넓히지 않습니다(바탕이 보이고 있으면 바탕의 색)
4·8(처음 값)·16·32·64·128 px아일랜드 가장자리에서 그 폭만큼 색을 넓힙니다
아일랜드 바깥을 모두 채우기아일랜드 바깥을 모두 가장 가까운 아일랜드의 색으로 채웁니다
  • PNG·PSD의 합성 이미지·머티리얼 내보내기 이미지(메인 컬러·그림자 색·마스크·노멀 맵 등 전부)에 적용됩니다. PSD의 레이어 자체는 넓히지 않습니다.
  • 선택한 레이어의 PNG와 UV 맵에는 붙이지 않습니다.
  • 값은 UV 영역 왼쪽 아래의 "패딩"과 같은 값입니다. 어느 쪽에서 바꿔도 양쪽이 바뀝니다. UV 영역에서 1px 단위로 정한 값도 창에 나열됩니다(칠하는 범위와 패딩).
  • 아일랜드 바깥의 픽셀은 직선 거리로 가장 가까운 아일랜드 픽셀의 색이 됩니다. 비스듬한 가장자리도 계단 모양이 되지 않고 매끄럽게 넓어집니다.
  • 브러시 가장자리의 옅은 부분은 그린 곳으로 보지 않고, 불투명한 부분의 색을 넓힌 다음 옅은 부분을 위에 겹칩니다. 이음매에 바탕 색의 선이 나타나기 어려워집니다.
  • Unity 연동으로 보내는 그림도 내보내기 PNG와 같은 방식으로 넓힙니다(Unity에서 칠하기).
내보내기 전에 UV 영역의 "패딩 선"을 표시하면 어디까지 넓어지는지 눈으로 확인할 수 있습니다. 아일랜드 바깥도 직접 그리고 싶을 때는 칠하는 범위를 "패딩 안"으로 합니다(자세히).

내보낼 폴더

내보내기 창의 "내보내기 위치"에서 정해 둔 폴더로 매번 내보낼 수 있게 합니다. Unity 프로젝트의 Textures 폴더 등을 선택해 두면 편리합니다.

  1. 내보내기 창의 "폴더 선택"에서 폴더를 선택합니다.
  2. "매번 묻지 않고 이 폴더로 내보내기(같은 이름의 파일은 덮어쓰기)"를 켭니다.
  3. 다음부터 PNG·PSD·AO·.unitypackage 내보내기에서 저장 위치를 묻지 않고 그 폴더에 씁니다.
  • "제거"를 누르면 내보낼 때마다 저장 위치를 묻는 상태로 돌아갑니다.
  • 폴더를 정하지 않았을 때도 저장 위치 창은 이전에 내보낸 폴더에서 열립니다.
  • "내보낸 후 폴더 열기"는 처음부터 켜져 있습니다. 쓰기가 끝나면 그 폴더를 탐색기에서 엽니다. 열 필요가 없을 때는 끕니다.
  • 내보내는 동안에는 "내보내는 중…"이 표시되며, 끝날 때까지 조작이 멈춥니다.
  • 머티리얼의 폴더로 내보내기(Assets를 선택)는 이전에 선택한 Assets에서 열립니다.
  • 창에서 취소하면 창 안에서 바꾼 값(번짐·내보내기 위치 등)은 원래대로 돌아갑니다.
"매번 묻지 않고"일 때는 같은 이름의 파일이 확인 없이 덮어쓰기됩니다.

2D 페인트 그림 내보내기

모델을 사용하지 않는 2D 페인트의 그림도 PNG나 PSD로 만들 수 있습니다.

  • 캔버스 아래 바의 "PNG 내보내기"로 2D-paint.png를 만듭니다. 파일 → 내보내기 → "PNG로 내보내기(선택 중인 세트)"로도 같습니다.
  • Standard 레이어째 전달할 때는 파일 → 내보내기 → "PSD로 내보내기(선택 중인 세트)"로 2D-paint.psd를 만듭니다.
  • 모든 세트·선택한 레이어의 내보내기는 3D 모델의 텍스처 세트를 위한 것입니다. 2D 페인트에서는 사용할 수 없습니다.
  • 작업 파일 저장도 가능합니다(모델 없는 2D 페인트).
스탬프용 2D 캔버스의 그림은 모델 내보내기에 포함되지 않습니다. "스탬프로 등록"으로 스탬프를 만들어 사용합니다(스탬프용 2D 캔버스).

lilToon 머티리얼·AO 내보내기 Pro

  • lilToon 머티리얼은 파일 → 내보내기 → "머티리얼 내보내기(.unitypackage/폴더)"로 텍스처와 함께 내보냅니다. 창에는 번짐과 내보내기 위치 칸도 있습니다(머티리얼 내보내기).
  • 구운 AO는 필터 → 베이크 → "AO를 PNG로 내보내기(마지막으로 구운 결과)"로 <세트 이름>_AO.png를 만듭니다(AO 굽기).
