단축키와 펜 조작

키 목록과 펜·마우스·3D 마우스 조작을 설명합니다. 키는 모두 다시 할당할 수 있습니다. 이 페이지의 키는 처음 상태의 할당입니다. 필압이 작동하지 않거나 이상할 때의 해결 방법도 여기에 정리했습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

먼저 이것만
  1. F1을 누르면 현재의 키 목록이 표시됩니다. 열어 둔 채로 그릴 수 있습니다(자세히).
  2. 3D는 오른쪽 드래그나 Space+드래그로 회전하고, 휠로 줌합니다(자세히).
  3. 다른 소프트웨어와 같은 마우스 조작으로 하고 싶을 때는 카메라 조작 템플릿을 고릅니다(자세히).
  4. 키는 파일 → 환경 설정 → "키 할당"에서 바꿉니다(자세히).
  5. 펜으로 그려도 굵기가 바뀌지 않을 때는 필압이 작동하지 않을 때를 보세요.

단축키 목록 표시하기(F1)

현재의 키 목록을 떠 있는 창으로 표시합니다. 열어 둔 채로도 키가 작동하며, 3D·UV에 그릴 수 있습니다.

  1. F1을 누릅니다(도움말 → "단축키 목록"으로도 열 수 있습니다).
  2. 위쪽의 "검색" 칸에 키나 이름을 입력해서 좁힙니다.
  3. 닫을 때는 F1을 다시 누르거나 오른쪽 위의 ×를 누릅니다.
  • 키를 누르면 그 행이 살짝 빛나고, 아래쪽 가장자리에 "누른 키:"와 조작 이름이 표시됩니다.
  • 제목 줄을 드래그해서 움직이고(더블클릭하면 원래 위치), 오른쪽 아래 모서리로 크기를 바꿉니다. 다음에 열 때도 같은 상태입니다.
  • ▾로 접고, ◐로 투명하게 합니다(포인터가 바깥에 있을 때 흐려집니다).
  • 아래의 "키 할당 변경"으로 환경 설정의 키 할당을 엽니다.
  • 펜·마우스 조작도 목록에 들어 있으며, 선택한 카메라 조작 템플릿에 맞춰 바뀝니다.
  • 키를 다시 할당하면 메뉴·우클릭 메뉴·버튼 설명·이 목록에도 현재의 키가 표시됩니다.

도구 키로 잠시 도구 바꾸기

도구 키를 누른 채 그리면 누르고 있는 동안만 그 도구가 되고, 놓으면 이전 도구로 돌아갑니다. 펜으로 그리다가 지우개를 잠깐 쓸 때 등에 편리합니다.

  • 짧게 눌렀다 놓았을 때는 그 도구로 바뀐 채로 남습니다.
  • 길게 누른 뒤 놓았을 때는 그리지 않아도 이전 도구로 돌아갑니다.
  • 길게 누름으로 보는 시간은 파일 → 환경 설정 → 조작 → 키보드의 "길게 누름으로 볼 시간"에서 0.15~2초로 정할 수 있습니다(처음에는 0.5초).
  • 이 전환 자체를 하지 않으려면 같은 곳의 "도구 키를 길게 눌러 잠시 전환"을 끕니다.

카메라 조작 템플릿 선택하기

시점을 움직이는 마우스 할당을, 익숙한 소프트웨어에 맞춰 4가지 중에서 고를 수 있습니다.

  1. 파일 → 환경 설정 → "조작" → "카메라"를 엽니다.
  2. "카메라 조작 템플릿"에서 고릅니다. 고른 방식은 다음 실행에도 유지됩니다.
템플릿회전평행 이동줌

  • Alt + 마우스 버튼·Unity 방식은 3D 뷰에 적용됩니다. Alt가 카메라 조작이 되므로, 3D의 스포이트는 I 키로 사용합니다.
  • Alt + 마우스 버튼 방식에서는 Alt+Shift+왼쪽 드래그로 90°씩 회전하고(누른 곳에서 방향을 90°의 배수로 맞춤), Shift+오른쪽 드래그로 빛의 좌우를 돌립니다.
  • 펜의 사이드 버튼을 가운데 클릭으로 설정했을 때도 가운데 버튼과 같은 조작입니다. 펜 끝이 닿아 있는 동안 가운데 버튼을 누르면 그리기를 멈추고 시점 조작이 됩니다. 가운데 버튼을 놓은 뒤에는 펜 끝을 한 번 뗀 다음 새 선을 그립니다.

회전 중심·확대/축소 중심 바꾸기

모두 파일 → 환경 설정 → 조작 → "카메라"에 있습니다.

항목켜면
Space+드래그회전(기본값)이나 평행 이동을 고릅니다. Shift를 더하면 회전과 평행 이동이 바뀌고, Ctrl을 더하면 줌이 됩니다
마지막으로 칠한 곳을 중심으로 회전(처음에는 꺼짐)3D 뷰에서 칠한 선의 끝을 중심으로 회전합니다. 확대해서 세밀한 곳을 칠할 때, 칠하려는 곳이 화면 밖으로 달아나지 않습니다
회전을 시작할 때의 커서 위치를 중심으로 회전(처음에는 꺼짐)회전을 시작했을 때 커서 아래에 있는 모델의 점을 중심으로 회전합니다. 모델 밖에서 회전을 시작했을 때는 지금까지와 같습니다. 위의 항목과 둘 다 켜져 있을 때는 이쪽이 우선합니다
축 시점은 평행 투영(처음에는 켜짐)숫자 키패드 1·3·7이나 3D 내비의 축으로 볼 때는 평행 투영으로 합니다. 회전하면 원근 투영으로 돌아갑니다
키 확대/축소는 커서 중심(처음에는 꺼짐)키·3D 내비로 확대/축소할 때 커서 아래의 점을 중심으로 합니다

시점 바꾸기(숫자패드)

키보드의 숫자 키패드로 정해진 방향에서 볼 수 있습니다. 숫자 키패드가 없는 키보드에서는 3D 뷰 오른쪽 위의 아이콘이나 3D 내비를 사용합니다(3D 뷰 네 모서리).

Ctrl+숫자 키패드 4 / 6 / 8 / 2시점을 왼쪽 / 오른쪽 / 위 / 아래로 이동

펜 버튼·Windows Ink

펜 태블릿 드라이버에서 펜 버튼에 할당한 클릭을, 펜이 있는 위치의 클릭으로 받습니다. Windows Ink에서도 WinTab에서도 작동합니다.

버튼 할당PetaNuri3D에서의 동작
가운데 클릭누르고 있는 동안 펜을 움직이면 3D 시점이 회전합니다(펜을 띄워도 대고 있어도 회전합니다). 그리는 도중에 누르면 거기까지의 선에서 멈추고 회전합니다. UV 영역에서는 평행 이동입니다
오른쪽 클릭누른 채 움직이면 오른쪽 드래그(3D 회전 등), 움직이지 않고 놓으면 우클릭(메뉴)입니다
뒤로·앞으로마우스의 뒤로·앞으로 버튼으로 받습니다
  • 펜 끝과 동시(앞뒤 0.05초)에 들어온 오른쪽 클릭은 사용하지 않고 그리기를 우선합니다(펜 끝과 함께 오른쪽 클릭을 보내는 드라이버용). 가운데 클릭은 펜 끝과 동시에 들어와도 시점 조작이 됩니다.
  • 받는 것은 펜이 PetaNuri3D 창 근처에 있는 동안뿐입니다. 마우스의 실제 버튼에는 영향을 주지 않습니다.
  • 받고 싶지 않을 때는 파일 → 환경 설정 → 펜·입력 → 메뉴와 버튼의 "펜 사이드 버튼의 가운데·오른쪽 클릭 받기"를 끕니다(처음에는 켜짐). 끄면 드라이버의 클릭이 그대로 마우스 커서가 있는 곳으로 갑니다.

Windows Ink를 켜고 끌 때 달라지는 점

펜 태블릿 설정PetaNuri3D에서는
"Windows Ink 사용"을 켬(권장)필압과 기울기가 전달됩니다. 사이드 버튼을 누르고 움직이지 않은 채 놓으면 팝업 팔레트가 나타납니다
"Windows Ink 사용"을 끔펜이 마우스로 전달되어 필압이 오지 않습니다(필압이 작동하지 않을 때). 사이드 버튼도 마우스의 오른쪽 클릭으로 전달되므로, 환경 설정 → 조작 → 마우스의 "오른쪽 클릭" 설정을 따릅니다

잘 안 될 때

  • 사이드 버튼을 놓아도 3D가 계속 회전합니다: Esc를 누르거나 펜 끝으로 한 번 탭하면 멈춥니다.
  • 펜 끝으로 그릴 수 없거나, 계속 회전하는 일이 이어집니다: "펜 사이드 버튼의 가운데·오른쪽 클릭 받기"를 꺼 보세요.
  • 사이드 버튼으로 한 드래그가 도중에 멈춥니다: 펜 태블릿 드라이버 설정에서 사이드 버튼에 Space 키를 할당합니다. Space+펜 드래그로 회전할 수 있습니다.
  • 세밀한 곳을 그리고 있으면 메뉴가 제멋대로 나타납니다: 펜을 길게 눌러서 나타나는 것입니다. 펜·입력 → 메뉴와 버튼의 "펜으로 길게 누르면 메뉴 열기"를 끕니다(우클릭 메뉴).

3D 마우스로 시점 움직이기

키 할당하기

어떤 조작의 키든 바꿀 수 있습니다. 왼손 디바이스에 맞출 때 등에 사용합니다.

  1. 파일 → 환경 설정 → "키 할당"을 엽니다. 분류별 섹션에 조작과 키가 나열됩니다.
  2. 바꾸려는 조작의 "+"를 누릅니다. "키를 누르세요(Esc로 취소)"라고 표시됩니다.
  3. 사용할 키를 누릅니다. Ctrl·Alt·Shift와의 조합도 가능합니다.
  4. 다른 조작에서 사용 중인 키라면 "바꿔 달기"를 할지 묻습니다. 바꿔 달면 이전 조작에서는 해제됩니다.
  • 키 옆의 ×로 그 키를 해제합니다. "+"로 키를 추가하면 하나의 조작에 여러 키를 지정할 수 있습니다.
  • "초기값으로 되돌리기"로 그 조작만 기본 키로 되돌립니다.
  • "키 할당 초기화"로 전부 기본값으로 되돌립니다(확인한 뒤에. 실행 취소로는 되돌릴 수 없습니다).

우클릭으로 도구·보조 도구에 지정하기

  1. 도구 모음의 버튼이나 보조 도구의 타일을 우클릭합니다.
  2. "키 할당"을 선택합니다. 현재 키가 있으면 "키 할당 (현재: P)"처럼 표시됩니다.
  3. 사용할 키를 누릅니다. 이전 키는 해제되고 누른 키로 바뀝니다(Esc로 취소).
  • 보조 도구·도구 속성 패널의 제목이나 탭의 우클릭으로도 지정할 수 있습니다.
  • 보조 도구에 지정한 키를 누르면 그 도구의 그 보조 도구로 전환됩니다. 보조 도구를 삭제하면 그 키도 해제됩니다.
  • 지정한 키는 버튼·타일 이름 옆(말풍선)과 키 할당의 분류 "도구", "보조 도구"에 표시됩니다.
  • 같은 키를 여러 보조 도구에 지정할 때는 할당 창에서 "함께 사용(누를 때마다 전환)"을 선택합니다. 그 키를 누를 때마다 다음 보조 도구로 바뀝니다(예: G펜과 밀리펜에 Q).

할당 내보내기·가져오기

다른 PC로 가져갈 때나 백업을 만들어 둘 때 사용합니다.

  1. 키 할당 위의 "키 할당 내보내기"를 누릅니다. 현재 할당이 JSON 파일(PetaNuri3D-keymap.json)로 저장됩니다.
  2. 가져오는 쪽에서 "키 할당 가져오기"를 누르고 그 파일을 선택합니다.
  3. "바꿀까요?"라고 물으면 "불러오기"를 누릅니다. 현재 할당이 통째로 바뀝니다.
  • 파일에 없는 조작은 기본 키가 됩니다. 이 버전에 없는 조작의 할당은 사용하지 않습니다.

잘 안 될 때

  • 키를 눌러도 작동하지 않습니다: 메뉴를 열고 있는 동안은 앱의 단축키가 작동하지 않습니다. 메뉴를 닫은 뒤에 누릅니다.
  • 누른 키로 의도하지 않은 조작이 일어납니다: F1 목록을 열고 키를 누르면 아래쪽에 그 키의 조작이 표시됩니다.
  • 숫자 키패드에 지정했는데 작동하지 않거나, 윗줄 숫자로는 작동하지 않습니다: 숫자 키패드의 숫자와 윗줄의 숫자는 다른 키입니다. 사용하는 쪽으로 다시 할당합니다.
  • 새로 고침·인쇄·페이지 확대 키가 작동하지 않습니다: 브라우저 조작 키는 PetaNuri3D에서는 작동하지 않습니다.

필압이 이상할 때·작동하지 않을 때

필압은 파일 → 환경 설정 → 펜·입력의 "필압"에서 자신의 힘에 맞출 수 있습니다. 굵기가 전혀 변하지 않을 때는 먼저 필압이 전달되고 있는지(경로)를 확인합니다.

내 힘에 맞추기(시험 삼아 그려 보며 맞추기)

  1. 파일 → 환경 설정 → "펜·입력" → "필압"을 엽니다.
  2. "시험 그리기로 맞추기"를 누릅니다.
  3. 오른쪽 판에 평소 힘으로 선을 3개 이상 그립니다.
  4. "맞추기"를 누릅니다. 하한·상한·반응이 그 힘에 맞춰 정해집니다.
  5. 마음에 들지 않으면 "실행 취소"를 누릅니다.

펜 태블릿 설정에서 "Windows Ink 사용"을 꺼 두면 펜이 마우스로 전달되어 필압이 오지 않습니다. 해결 방법은 2가지이며, 둘 중 하나만 하면 됩니다.

  • 권장: 펜 태블릿 드라이버 설정 화면에서 "Windows Ink 사용"을 켭니다. 기울기도 전달됩니다.
  • Windows Ink를 끈 채로 사용할 때: 파일 → 환경 설정 → 펜·입력 → "태블릿"의 "필압 직접 읽기(WinTab)"를 켭니다(처음에는 꺼짐). 경로가 "WinTab"이 됩니다.
펜으로 그리고 있는데 필압이 오지 않는 것 같을 때는, 오른쪽 아래에 "필압이 전달되지 않습니다"라고 한 번만 알립니다. 마우스로 그리고 있을 때는 표시되지 않습니다. "다시 표시하지 않음"을 누르면 더 이상 표시되지 않고, "환경 설정 열기"를 누르면 펜·입력이 열립니다.

WinTab으로 필압 읽기

  • "필압 직접 읽기(WinTab)"를 켜면 펜 태블릿 드라이버의 WinTab에서 필압(과 기울기)을 읽습니다.
  • 펜을 가까이 대고 그렸을 때만 필압을 대체합니다. 마우스로 그릴 때는 그대로입니다. 펜의 지우개 쪽도 지우개가 됩니다.
  • "Windows Ink로 들어오는 펜에도 WinTab 필압 사용"(처음에는 켜짐): 펜이 Windows Ink로 전달될 때도 WinTab 값이 전달되고 있으면 그쪽의 필압·기울기를 사용합니다. 끄면 Windows Ink의 필압 그대로입니다.
  • WinTab을 사용하는 다른 그림 소프트웨어와 동시에 사용하면 필압이 전달되지 않을 수 있습니다.

잘 안 될 때

  • 세게 누르지 않으면 굵어지지 않거나, 살짝 대기만 해도 굵습니다: "시험 그리기로 맞추기"로 자신의 힘에 다시 맞춥니다. 직접 고친다면, 세게 눌러야 굵어질 때는 상한을 낮추고, 살짝 대기만 해도 굵을 때는 반응을 "단단함" 쪽으로 움직입니다.
  • 가볍게 그리면 선이 거의 보이지 않거나, 입·출이 너무 가늡니다: 펜·입력 → 필기감의 "입·출 만드는 방식"을 "길이로 입·출"로 합니다. 필압이 약한 곳도 1px보다 가늘어지지 않습니다.
  • 다른 브러시에서는 되는데 특정 브러시만 굵기가 바뀌지 않습니다: 그 보조 도구의 도구 속성에서 "필압으로 크기"가 꺼져 있지 않은지 확인합니다(브러시 세부 설정).
  • 마우스로 그리면 굵기가 바뀌지 않습니다: 마우스에는 필압이 없습니다. 마우스의 입·출은 항상 보조 도구의 "시작"·"끝" 길이로 만듭니다.
  • "WinTab에 빈자리가 없습니다"라고 표시되고 "필압 직접 읽기(WinTab)"가 꺼집니다: WinTab을 사용하는 다른 그림 소프트웨어를 닫거나, 펜 태블릿 드라이버(또는 PC)를 다시 시작한 뒤에 다시 켭니다. 드라이버에 따라서는, 닫지 않고 종료된 소프트웨어의 몫이 다시 시작할 때까지 돌아오지 않습니다.
  • "WinTab을 찾을 수 없습니다", "펜 태블릿을 찾을 수 없습니다"라고 표시됩니다: 펜 태블릿 드라이버가 설치되어 있는지, 펜 태블릿이 연결되어 있는지 확인합니다.
  • WinTab을 켰는데도 판을 눌러도 "현재 필압"이 "—(필압 없음)"인 채입니다: PetaNuri3D 창을 앞에 둔 채 판을 펜으로 몇 번 눌러 그립니다(전달되지 않으면 2번 누를 때마다 연결 방식을 바꿔 시험합니다). 그래도 안 되면 "WinTab 연결 방식"의 "다시 찾기"를 누르고 다시 그립니다.
  • WinTab을 켰더니 펜이 반응하지 않습니다: "태블릿"의 "WinTab 연결 방식"의 "다시 찾기"를 누르고 다시 그립니다. 기억해 둔 연결 방식을 지우고 처음부터 다시 찾습니다.
  • 펜 태블릿 드라이버에서 앱별 설정을 하고 있습니다: 앱별 설정에 PetaNuri3D(PetaNuri3D-win_x64.exe)를 추가했다면, 그쪽에서 필압이 꺼져 있지 않은지 확인합니다.
  • "WinTab은 동작하지만 펜 정보가 오지 않습니다"라고 표시됩니다: 아래의 "WinTab 상태 확인"으로 어디에서 멈춰 있는지 확인합니다.
  • 펜 태블릿 드라이버를 다시 설치하거나 업데이트하려고 합니다: PetaNuri3D를 닫은 뒤에 진행합니다. WinTab을 사용하고 있으면 드라이버 파일이 열린 채로 남습니다.
  • 선이 펜 끝보다 늦게 나옵니다: 펜·입력 → 지연 줄이기의 "펜 선 먼저 표시(지연 줄이기)"를 켜 봅니다(펜(Windows Ink)으로 그릴 때). "예측 임시 선"도 켜 둡니다(펜·입력 설정).

그래도 해결되지 않을 때(지원팀에 보내기)

  1. 파일 → 환경 설정 → 펜·입력 → "태블릿"의 "WinTab 상태 확인"을 누릅니다.
  2. PetaNuri3D 창 위에서 펜으로 선을 1개(2~3초) 긋습니다. wintab32.dll, 펜 태블릿 이름, 필압 단계, 수신 창구, 최근 5초 동안 받은 패킷 수, 마지막 필압 값, 그리고 어디에서 멈춰 있는지에 대한 판단이 표시됩니다(숫자는 1초마다 바뀝니다).
  3. "복사"를 누릅니다.
  4. 도움말 → "문의 (지원, 기능 요청, 버그 신고)"에서, 펜 태블릿 기종·드라이버 버전과 함께 붙여넣어 보냅니다(문의 방법).
'"필압 직접 읽기(WinTab)"를 켠 뒤 다시 확인하세요'라고 표시되면, 같은 곳의 "필압 직접 읽기(WinTab)"를 켠 뒤 다시 누릅니다.
