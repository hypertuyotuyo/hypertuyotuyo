단축키와 펜 조작

파일 → 환경 설정 → '키 할당'에서 모든 키를 다시 할당할 수 있습니다(왼손 입력 장치용). 이 페이지의 키는 기본 할당입니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

Lite·Standard·Pro와 Pro 업그레이드를 BOOTH에서 배포하고 있습니다.

이 페이지에서 “v1.2.0:”로 시작하는 설명은 공개 전 안내입니다. 현재 배포 버전은 v1.1.2입니다.

단축키 목록(F1)

  • F1 로 단축키 목록이 플로팅 창에 표시됩니다(도움말 메뉴에서도 가능). 열어 둔 채 키를 사용하고 3D·UV에 그릴 수 있습니다 . 다시 F1 또는 오른쪽 위 ×로 닫습니다.
  • 위 '검색' 항목에서 키나 이름으로 필터링합니다. 누른 키의 행이 잠시 강조되고 아래 끝에 '누른 키'가 표시됩니다.
  • 제목을 드래그하여 이동하고 오른쪽 아래 모서리로 크기를 바꿉니다(다음에도 유지). ▾로 접기·◐로 반투명 표시.
  • 키를 다시 할당하면 메뉴·우클릭·버튼 설명·이 목록도 현재 키로 표시됩니다.

키 할당

  • 파일 → 환경 설정 → '키 할당': 분류별 항목에서 +를 누른 후 키를 누르면 할당합니다. ×로 해제합니다. '초기값으로 되돌리기'는 해당 키를 기본값으로, '키 할당 초기화'는 전체를 기본값으로 되돌립니다(확인 후).
  • 도구 모음 버튼·보조 도구 타일·패널 제목 우클릭 → '키 할당'으로도 변경할 수 있습니다(Ctrl・Alt・Shift 와 조합도 가능). 다른 곳에서 사용하는 키라면 재할당할지 묻습니다.
“키 할당 내보내기”로 지금의 할당을 JSON으로 저장하고, “키 할당 가져오기”로 내보낸 것으로 통째로 바꿀 수 있습니다(다른 PC로 옮길 때 등).
v1.2.0: 같은 키를 여러 보조 도구에 붙일 때는 할당 창에서 “함께 사용(누를 때마다 전환)”을 고르면 그 키를 누를 때마다 다음 보조 도구로 바뀝니다(예: G펜과 밀리펜에 Q). “바꿔 달기”면 이전 보조 도구에서 빠집니다.

필압 이상·필압이 작동하지 않을 때

  1. 먼저 파일 → 환경 설정 → 펜·입력의 '필압'에서 맞춥니다. '시험 그리기로 맞추기'로 평소 힘으로 선을 3개 이상 그리고 '맞추기'를 누르면 하한·상한·반응을 자동으로 정합니다.
  2. 필압이 작동하지 않으면(굵기가 바뀌지 않음) 같은 곳의 판을 펜으로 눌러 '경로'를 확인합니다. '없음(마우스로 전달되고 있음)'이면 펜 태블릿 설정에서 'Windows Ink 사용'을 켜거나 펜·입력 → '태블릿'의 '필압 직접 읽기(WinTab)'를 켭니다.
  3. 그래도 이상하면 '태블릿'의 'WinTab 상태 확인'을 누르고 PetaNuri3D 창 위에서 펜을 움직입니다. 표시된 문구를 '복사'하여 펜 태블릿 모델·드라이버 버전과 함께 지원에 보내 주세요.
