Unity에서 칠하기·AI 연동

Unity에서 아바타를 선택해 PetaNuri3D를 실행하고, 그대로 칠할 수 있습니다. 저장하면 칠한 그림이 Unity에 반영됩니다. AI(MCP 클라이언트)에서 PetaNuri3D를 조작할 수도 있습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

Unity 연동과 AI 연동은 모든 에디션(Lite·Standard·Pro)에서 사용할 수 있습니다. AI 연동의 run_js만 Pro에서 사용할 수 있습니다(에디션 비교).

먼저 이것만
  1. 처음 한 번만 PetaNuri3D 폴더의 unity\PetaNuri3D-Unity.unitypackage를 Unity에 가져옵니다(자세히).
  2. Unity에서 아바타를 선택하고, 메뉴 막대에서 ぺたぬり3D → ぺたぬり3D で塗る(PetaNuri3D → PetaNuri3D로 칠하기)를 선택합니다(자세히).
  3. 칠한 다음 PetaNuri3D나 Unity에서 Ctrl+S를 누릅니다. 칠한 그림이 Unity에 반영됩니다(자세히).
  4. PetaNuri3D의 위치를 바꿨다면 Unity에서 PetaNuri3D의 위치를 다시 지정합니다(자세히).
  5. AI에서 조작할 때는 파일 → 환경 설정 → "AI 연동"에서 ON으로 설정합니다(자세히).

Unity에서 실행하여 칠하기

Unity의 아바타를 FBX로 내보내지 않고 그대로 칠할 수 있습니다. 원본 FBX·머티리얼·텍스처·prefab은 수정하지 않습니다.

  • 사용 환경: Unity 2022.3(VRChat 아바타 제작용 Unity). 같은 컴퓨터의 Unity에만 연결됩니다.
  • 칠할 수 있는 것은 FBX 메시뿐입니다(FBX가 아닌 형태는 PetaNuri3D에 표시되지 않습니다).

처음 한 번만: Unity에 애드온 설치하기

  1. PetaNuri3D 폴더 안의 "unity" 폴더를 엽니다. PetaNuri3D-Unity.unitypackage가 들어 있습니다.
  2. Unity에서 프로젝트를 연 채 PetaNuri3D-Unity.unitypackage를 Project 영역으로 드래그합니다(Assets → "Import Package" → "Custom Package"로도 가능합니다).
  3. 나타난 창에서 "Import"를 누릅니다.
  4. 위쪽 메뉴 막대에 ぺたぬり3D(PetaNuri3D)가 나타나면 설치된 것입니다.

애드온은 Assets/PetaNuri3D에 설치됩니다. 에디터 안에서만 동작하며, 업로드하는 아바타에는 포함되지 않습니다.

칠하기

  1. Unity에서 Hierarchy의 아바타(씬 안의 오브젝트) 또는 Project의 prefab을 선택합니다.
  2. 메뉴 막대에서 ぺたぬり3D → ぺたぬり3D で塗る(PetaNuri3D → PetaNuri3D로 칠하기)를 선택합니다(Hierarchy·Project의 우클릭 메뉴에도 있습니다). Unity의 메뉴 이름은 일본어로만 표시됩니다.
  3. 처음 한 번만 "Choose the PetaNuri3D program"이라는 메시지가 나타납니다. PetaNuri3D 폴더의 PetaNuri3D-win_x64.exe를 선택합니다.
  4. PetaNuri3D가 실행되고 Unity의 모델이 표시됩니다. 평소처럼 칠합니다.
  • 텍스처 세트는 머티리얼의 메인 텍스처마다 만들어집니다. 같은 텍스처를 사용하는 머티리얼은 하나의 세트가 되며, 칠한 그림은 모든 머티리얼에 반영됩니다.
  • 원본 텍스처가 그대로 바탕이 됩니다. 해상도도 원본 텍스처와 같습니다(Lite는 2048까지). 텍스처가 없는 머티리얼은 머티리얼의 색에서부터 칠하기 시작합니다.
  • Unity에서 숨겨진 것은 PetaNuri3D에서도 숨겨져 있습니다(오브젝트 패널에서 표시할 수 있습니다).
  • Unity에서 실행한 PetaNuri3D는 칠하기 전용 화면입니다. 제목은 "PetaNuri3D — Unity 연동 (아바타 이름)"이며, 새로 만들기·작업 파일 열기·최근 사용한 파일·모델 다시 불러오기·다른 이름으로 저장은 표시되지 않습니다.
  • "Paint with PetaNuri3D"를 한 번 더 누르면 열려 있는 PetaNuri3D가 앞으로 나옵니다(두 번째 창은 실행되지 않습니다).
  • Pro lilToon 머티리얼에서 "메인 컬러 2nd"와 "메인 컬러 3rd"를 사용하고 있으면 그 이미지(PSD도)·마스크·합성 모드·색도 함께 들어와 레이어 패널의 해당 폴더에 들어갑니다(메인 컬러 2nd·3rd). Lite·Standard에서는 들어오지 않습니다(Unity에서는 원래의 2nd·3rd 그대로 반영됩니다).

PetaNuri3D 창(처음 사용하는 분께 추천)

Unity 메뉴 막대에서 ぺたぬり3D → ぺたぬり3D の窓を開く(PetaNuri3D → PetaNuri3D 창 열기)를 선택하면, 위에서부터 차례로 확인하면서 칠할 수 있는 창이 열립니다.

영역내용
1. PetaNuri3D program (exe)현재 위치와 사용할 수 있는지 여부가 표시됩니다. "Choose"(선택), "Search"(찾기), "Show in Explorer"(위치 열기)가 있습니다(위치 다시 지정하기)
2. What to paint (prefab or scene avatar)prefab이나 아바타를 칸으로 드래그하거나, 선택한 다음 "Use selection"(선택 중인 항목 넣기)을 누릅니다. 칠할 수 있는 메시의 수와 텍스처 세트가 표시됩니다. 칠할 수 없을 때는 이유도 표시됩니다
3. Paint"Paint with PetaNuri3D"(PetaNuri3D로 칠하기)와 현재 상태가 표시됩니다(Not connected: 연결 안 됨, Starting: 실행 중, Connected: 연결됨, Disconnected: 끊김, Saved: 저장함, Finished: 끝남). 칠하는 동안에는 "Bring PetaNuri3D to front"(PetaNuri3D를 앞으로), "Save and show in Unity"(저장하고 Unity에 반영), "Finish"(끝내기), "Revert and finish"(원래 모습으로 되돌리고 끝내기), "Show painted files"(칠한 파일의 폴더 보기)도 표시됩니다
4. Where files go / Settings칠한 그림의 저장 위치(Assets/PetaNuri/), "Open Preferences"(Preferences 열기), 언어 전환

창 맨 아래에 애드온의 버전(PetaNuri3D와 같은 번호)이 표시됩니다.

칠한 그림을 Unity에 반영하기·끝내기

칠하는 동안에는 Unity의 모습이 바뀌지 않습니다. PetaNuri3D나 Unity에서 저장하면, 그 시점에 칠한 그림이 Unity에 반영됩니다.

  1. PetaNuri3D나 Unity에서 Ctrl+S를 누릅니다. 양쪽 모두 저장됩니다.
  2. Unity의 Scene 뷰에서 칠한 그림이 반영되었는지 확인합니다.
만들어지는 것위치(Unity 프로젝트 안)
작업 파일Assets/PetaNuri/(이름)/(이름).petanuri
칠한 텍스처Assets/PetaNuri/(이름)/Textures/의 PNG(칠한 텍스처만. 임포트 설정은 원본 텍스처에 맞춥니다)
머티리얼Assets/PetaNuri/(이름)/Materials/(원본 머티리얼의 복사본. 칠한 텍스처를 사용합니다)
메인 컬러 2nd/3rd ProTextures/의 _main2nd.png·_main3rd.png(Unity에서 가져온 것을 변경했을 때만. 마스크는 되돌려 보내지 않습니다)
  • Project의 prefab에서 시작했을 때는 prefab 베리언트(Prefab Variant)를 Assets/PetaNuri/(이름)/에 만들고, 그쪽을 칠합니다. 업로드할 때는 만들어진 "(이름) (PetaNuri)" prefab을 씬에 배치하여 사용합니다.
  • 다음에 "Paint with PetaNuri3D"를 다시 누르면 작업 파일을 열어 레이어째 이어서 칠할 수 있습니다.
  • Unity 연동으로 보내는 텍스처는 내보내기 PNG와 픽셀 단위까지 같습니다.

끝내기

  • PetaNuri3D를 닫으면 연동이 끝납니다. 닫을 때 "저장하고 종료"를 선택하면 칠한 그림을 Unity에 보낸 뒤 닫습니다.
  • 씬 안의 아바타를 칠한 경우 Unity가 "Keep"(이대로 사용) 또는 "Revert to original"(원래 모습으로 되돌리기)을 묻습니다. "Revert to original"을 선택해도 Assets/PetaNuri/의 파일은 남아 있으므로, 다시 칠하면 이어서 칠할 수 있습니다. Unity의 실행 취소(Ctrl+Z)로도 되돌릴 수 있습니다.
  • 한 번도 저장하지 않고 닫았을 때는 아무것도 묻지 않고 원래 모습으로 되돌리며, 만든 것도 삭제합니다.
  • Unity를 먼저 닫을 때는 "Save and Close"(저장하고 닫기), "Keep Open"(닫지 않음), "Close Without Saving"(저장하지 않고 닫기) 중에서 묻습니다.

주의할 점

  • 옷 색 바꾸기 등 머티리얼을 전환하는 애니메이션은 원본 머티리얼을 가리키고 있습니다. 칠한 그림을 사용할 때는 애니메이션의 머티리얼도 교체하세요.
  • 같은 아바타를 두 개의 Unity에서 동시에 칠하지 마세요.
  • Unity가 스크립트를 다시 읽는 동안(컴파일·Play 시작 시)에는 잠시 연결이 끊어지지만 곧바로 다시 연결합니다.

잘 안 될 때

  • 칠했는데 Unity의 모습이 바뀌지 않습니다: 저장하면 반영됩니다. PetaNuri3D나 Unity에서 Ctrl+S를 누르세요.
  • "Paint with PetaNuri3D"를 눌러도 실행되지 않거나 영어 페이지가 열립니다: 선택한 exe가 잘못되었습니다. PetaNuri3D의 위치 다시 지정하기에서 ZIP을 푼 폴더의 PetaNuri3D-win_x64.exe를 선택하세요.
  • "The PetaNuri3D program files (resources.neu) are not next to the selected file"이라고 표시됩니다: 선택한 exe 옆에 resources.neu가 없습니다. ZIP을 모두 푼 폴더의 exe를 다시 선택합니다.
  • "Unity 애드온과 PetaNuri3D의 버전이 맞지 않습니다"라고 표시됩니다: PetaNuri3D에 들어 있는 PetaNuri3D-Unity.unitypackage를 다시 가져옵니다. 메인 컬러 2nd/3rd를 전달하려면 같은 버전의 애드온이 필요합니다.
  • "All link ports (47360-47369) are in use"라고 표시됩니다: 다른 Unity를 닫은 다음 다시 누릅니다.
  • "The selection has no paintable meshes (FBX meshes)"라고 표시됩니다: FBX 메시를 가진 prefab이나 아바타를 선택하세요.
  • 그래도 연결되지 않습니다: Unity와 PetaNuri3D를 모두 다시 실행하세요. 자세한 내용은 PetaNuri3D의 unity 폴더에 있는 Unity連携の使い方.txt(일본어)를 참고하세요.

PetaNuri3D의 위치 다시 지정하기

Unity 애드온은 처음에 선택한 PetaNuri3D-win_x64.exe의 위치를 기억합니다. PetaNuri3D 폴더를 옮겼거나 새 버전을 다른 폴더에 풀었을 때는 위치를 다시 지정합니다.

  1. Unity 메뉴 막대에서 ぺたぬり3D → ぺたぬり3D の窓を開く(PetaNuri3D → PetaNuri3D 창 열기)를 선택합니다.
  2. "1. PetaNuri3D program (exe)"의 "Choose"(선택)를 누릅니다.
  3. 새 위치의 "PetaNuri3D" 폴더 안에 있는 PetaNuri3D-win_x64.exe를 선택합니다.
  4. 칸 아래에 "Found."가 표시되면 끝입니다. "No file at this location"이 표시되면 다시 선택합니다.
  • "Search"(찾기)를 누르면 바탕 화면·다운로드·문서·Program Files·각 드라이브의 최상위에 있는 "PetaNuri3D" 폴더에서 찾습니다. 찾은 항목의 "Use this"(이것을 사용)를 누르면 그 위치가 됩니다.
  • Unity의 Edit → "Preferences" → "PetaNuri3D"의 "PetaNuri3D program"에서도 수정할 수 있습니다.
  • 기억하고 있는 위치에 exe가 없을 때는 "Paint with PetaNuri3D"를 눌렀을 때 "Choose the PetaNuri3D program"이라는 메시지가 표시됩니다.
  • setup.exe로 설치했을 때의 위치는 %LOCALAPPDATA%\Programs\PetaNuri3D입니다(설치·실행하기).
ZIP 안의 exe나 다른 exe는 선택할 수 없습니다. 다운로드한 ZIP은 오른쪽 클릭 → "모두 추출"을 한 다음, 푼 폴더 안의 exe를 선택하세요.

AI로 조작하기(MCP)

AI(MCP 클라이언트)에서 PetaNuri3D를 조작할 수 있습니다. 그리기·색과 브러시·시점·레이어·화면 촬영·PNG 내보내기 등을 AI에게 부탁할 수 있습니다.

  1. 파일 → 환경 설정을 열고 왼쪽의 "AI 연동"을 누릅니다.
  2. "AI 연동(MCP) 사용"을 켭니다. ON 상태는 다음에 실행해도 유지됩니다.
  3. "연결 방법"의 "설정 예"에서 "복사"를 누릅니다.
  4. AI 쪽(MCP 클라이언트)의 MCP 설정에 복사한 내용을 붙여넣어 등록합니다.
  5. AI를 사용하기 시작합니다. 연결되면 화면 아래에 "AI 연동: MCP 서버에 연결되었습니다"가 표시됩니다.

연결 방법의 자세한 내용

항목값
이름petanuri3d
명령node(버전 20 이상이 필요합니다)
인수<PetaNuri3D 폴더>\mcp\server.mjs(창에는 실제 위치가 표시됩니다)
  • stdio 서버로 등록합니다. 서버는 AI 쪽에서 실행하며, PetaNuri3D가 같은 컴퓨터 안(127.0.0.1의 47321~47330번)으로 자동으로 연결하러 갑니다.
  • "상태"에 ON·OFF와 연결 여부가 표시됩니다. "지금 찾기"를 누르면 바로 연결하러 갑니다.
  • AI 세션이 몇 개든 모두 연결됩니다. PetaNuri3D를 2개 열어 두었을 때는 AI 쪽의 list_instances로 대상을 선택할 수 있습니다.
  • 다른 웹사이트에서는 연결할 수 없습니다. 사용하지 않을 때는 "AI 연동(MCP) 사용"을 해제하여 OFF로 합니다.

run_js 허용하기 Pro

run_js는 앱 안에서 임의의 프로그램(JavaScript)을 실행하는 명령입니다. AI 연동을 ON으로 해 두기만 해서는 동작하지 않습니다.

  1. 파일 → 환경 설정 → "AI 연동"을 엽니다.
  2. "run_js" 항목에서 "run_js(임의의 프로그램 실행) 허용"을 켭니다.
앱(exe)에서는 파일 삭제나 명령 실행도 할 수 있습니다. 신뢰할 수 있는 AI 클라이언트만 등록하세요. Standard에서는 run_js 항목이 표시되지 않습니다.

잘 안 될 때

  • AI가 "연결되지 않는다"고 합니다: "AI 연동(MCP) 사용"이 OFF인 경우가 많습니다. ON으로 하면 몇 초 안에 연결됩니다.
  • "이 파일을 찾을 수 없습니다"라고 표시됩니다: 배포물의 mcp 폴더를 앱(exe)과 같은 폴더에 두세요.
  • AI 쪽에서 서버가 실행되지 않습니다: node(버전 20 이상)가 설치되어 있는지 확인하세요.
  • run_js가 거부됩니다: Pro 에디션에서 "run_js(임의의 프로그램 실행) 허용"을 켰을 때만 동작합니다.
  • AI가 그릴 수 없다고 합니다: 포즈 모드에서는 stroke·fill_at을 사용할 수 없습니다. 페인트 모드로 돌아가세요.
