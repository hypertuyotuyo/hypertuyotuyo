Unity에서 칠하기·AI 연동

Unity에서 아바타를 선택하여 PetaNuri3D를 실행하고 바로 칠할 수 있습니다. 모든 버전(Lite·Standard·Pro)에서 사용할 수 있습니다.

스크린샷은 일본어 인터페이스입니다. 본문의 메뉴 이름은 선택한 앱 언어에 맞춰 안내합니다.

이 페이지의 내용
  • Unity에서 실행하여 칠하기
  • AI 연동(MCP)

Unity에서 실행하여 칠하기

  • Unity에서 prefab(아바타 등)을 선택하고 'ぺたぬり3D で塗る'(PetaNuri3D로 칠하기)를 누르면 PetaNuri3D가 실행되어 해당 모델을 칠할 수 있습니다.
  • 칠한 그림은 PetaNuri3D 또는 Unity에서 저장할 때 Unity 씬에 반영되며 칠한 텍스처가 Unity 프로젝트에 저장됩니다(칠하는 동안 Unity 모습은 바뀌지 않음).
  • 사용 환경: Unity 2022.3(VRChat 아바타 제작용 Unity). 같은 컴퓨터의 Unity에만 연결됩니다.

처음 한 번만: Unity에 애드온 설치

  1. PetaNuri3D 폴더의 'unity' 폴더에 PetaNuri3D-Unity.unitypackage가 있습니다.
  2. Unity에서 프로젝트를 연 채 PetaNuri3D-Unity.unitypackage를 Project 영역에 드래그합니다(Assets → 'Import Package' → 'Custom Package'도 가능).
  3. 'Import'를 눌러 위 메뉴 바에 'ぺたぬり3D'가 표시되면 설치 완료입니다(에디터 안에서만 실행되며 업로드할 아바타에는 포함되지 않음).

칠하기

  1. Unity에서 Hierarchy의 아바타(씬 안의 오브젝트) 또는 Project의 prefab을 선택합니다.
  2. 메뉴 바의 'ぺたぬり3D' → 'ぺたぬり3D で塗る'(PetaNuri3D로 칠하기)를 누릅니다(우클릭에도 있음). 처음 한 번만 PetaNuri3D 폴더의 PetaNuri3D-win_x64.exe를 선택합니다.
  3. PetaNuri3D가 실행되어 Unity 모델이 표시됩니다. 텍스처 세트는 머티리얼 메인 텍스처별로 생성되며 원래 텍스처가 그대로 바탕이 됩니다(해상도 유지. Lite는 최대 2048).
  4. PetaNuri3D 또는 Unity에서 저장(Ctrl＋S)하면 양쪽 모두 저장되며 칠한 그림이 Unity에 반영됩니다.
  • 작업 파일은 Assets/PetaNuri/(이름)/(이름).petanuri, 칠한 텍스처는 Assets/PetaNuri/(이름)/Textures/의 PNG(가져오기 설정은 원래 텍스처에 맞춤), 머티리얼은 같은 위치의 Materials/에 복사본을 만들어 사용합니다.
  • 원본 FBX·머티리얼·텍스처·prefab은 변경하지 않습니다. Project prefab에서 시작했다면 Prefab Variant를 만들어 해당 변형을 칠합니다.
  • Unity에서 실행한 PetaNuri3D는 칠하기용 화면이 됩니다(새로 만들기·작업 파일 열기·모델 다시 불러오기·다른 이름으로 저장은 표시되지 않음).
  • PetaNuri3D를 닫으면 연동이 종료되며 Unity가 '그대로 사용/원래 모습으로 복원'을 묻습니다(씬의 아바타를 칠한 경우).
  • 다음에 다시 'ぺたぬり3D で塗る'(PetaNuri3D로 칠하기)를 누르면 작업 파일을 열어 이어 칠할 수 있습니다.
자세한 과정이나 연결되지 않을 때는 PetaNuri3D의 unity 폴더에 있는 'Unity連携の使い方.txt'를 참고하세요.

AI 연동(MCP)

  • AI(MCP 클라이언트)에서 PetaNuri3D를 조작할 수 있습니다(그리기·색과 브러시·시점·레이어·화면 촬영·PNG 내보내기 등).
  • 기본은 OFF입니다. 사용하려면 파일 → 환경 설정 → 'AI 연동'의 'AI 연동(MCP) 사용'을 켭니다.
  • MCP 클라이언트에 stdio 서버로 등록합니다: 명령 node, 인수 <PetaNuri3D 폴더 >\mcp\server.mjs(node v20 이상). 설정 예시는 같은 곳의 '연결 방법'에 있으며 '복사'로 복사할 수 있습니다.
  • 서버는 AI 쪽에서 실행합니다. PetaNuri3D가 같은 컴퓨터의 정해진 포트에 자동으로 연결하며 연결되면 아래 힌트에 안내됩니다. 다른 웹사이트에서는 연결할 수 없습니다.
  • run_js(앱 안에서 임의의 프로그램을 실행하는 명령)는 Pro 전용입니다. ON만으로 실행되지 않으며 'run_js(임의의 프로그램 실행) 허용'을 켰을 때만 실행됩니다. 신뢰할 수 있는 AI 클라이언트만 등록하세요.
