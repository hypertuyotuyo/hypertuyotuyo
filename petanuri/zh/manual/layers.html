PetaNuri3D ／ 使用手册 ／ 图层

图层

图层按纹理集叠放。可以像绘制 2D 插画一样分层上色。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

Lite、Standard、Pro 和 Pro 升级包均已在 BOOTH 提供。

图层基础

  • 可从面板顶部标题行切换纹理集（有两个以上时，右侧显示分辨率）。
  • 下方为混合模式、不透明度，以及剪贴、锁定透明像素、锁定图标（点击切换，有颜色表示开启）。
  • 底部图标按钮：添加、文件夹、调整、复制、删除、合并、蒙版、上移一层、下移一层、其他（悬停笔尖显示名称和当前按键）。
  • 最下方“底色”保存新建时设置的颜色或图片，也能直接绘制到底色。
  • 26种混合模式（正常、正片叠底、滤色、叠加、相加、柔光、强光、色相、颜色、明度等）。
  • 多选：对名称使用 Ctrl＋点击逐个选择，用Shift＋点击选择连续范围。显示、混合模式、不透明度、剪贴、保护、锁定、删除、复制、放入文件夹、合并均可批量执行（一次撤销）。
  • 仅用按键选择：Alt＋]（上方图层）、Alt＋[（下方图层）。3D 右键 →“选择在此处绘制的图层”可选择点击位置的图层。
  • 用数位笔直接拖动图层行可排序。列表滚动使用 Space＋拖动。
Lite 每个纹理集最多4个图层（含底色）（计算绘制和调整图层，不计算文件夹、蒙版）。达到4个时，下方显示“图层 4 / 4（含底色・Lite）”，“添加”“复制”显示锁标记。Standard 起不限图层数。
图层较多时，可向下拖动面板边界扩展列表。停靠、选项卡和独立窗口均会随高度扩展，保留顶部设置和底部操作按钮。
颜色标签（所有版本）：用图层行左侧的颜色框，或右键 → 颜色标签，从无、红、橙、黄、绿、青、蓝、紫、灰中选择。选中多个图层时一起添加，撤销一次即可。带标签的行以左侧色条和行颜色显示，文件夹的颜色会以线条延伸到其中的图层。
有图层带颜色标签时，列表上方会显示“按颜色显示”和正在使用的颜色圆点。点击圆点即可只列出该颜色的图层。标签保存在项目中，PSD 导出与导入（Standard、Pro）时与 Photoshop 图层颜色互通（青色会变为蓝色）。
在 …（更多）的“缩略图大小”中可选择小（24px）、中（40px）、大（64px）、特大（96px）。同处的“将按钮栏放在上方”可把底部按钮栏移到列表上方。两者在重启后都会保留。
拖动多选图层中的任意一个，所有选中图层会按顺序一起移动（放在文件夹行中间即可放入文件夹）。重命名时可用鼠标拖动选择文字。

文件夹、图层蒙版

  • 文件夹：点击“文件夹”按钮（Ctrl＋G）创建。Shift＋按钮（Ctrl＋Shift＋G）将所选图层放入文件夹。将图层行拖到文件夹中央也可放入。除“穿透”（默认）外的混合模式，会先合成内部图层再叠加。
  • 图层蒙版：“蒙版”按钮 → 添加全显示／全隐藏蒙版（也可从选区创建）。点击蒙版缩略图即可绘制到蒙版（绘制＝显示、橡皮擦＝隐藏）。
  • Shift＋蒙版缩略图可启用／禁用。还可“显示蒙版范围”、反转、应用（烘焙到像素）、删除。

图层属性

集中显示当前图层设置的面板（默认布局在图层面板正上方）。

  • 标题显示图层类型（图层、文件夹、文字图层、调整图层、绘制目标文件夹等）和名称。
  • 调整图层：参数区域。拖滑块期间仅更新图像，松开后作为一次撤销步骤。
  • 像素图层、文件夹、文字图层：“描边”显示、“添加”“设置”。
  • 文字图层显示“重新输入文字”，带蒙版图层显示蒙版状态。
  • 混合模式、不透明度、剪贴、锁定透明像素、锁定在图层面板调整。
重复图案（所有版本）：在像素图层的图层属性“重复图案”中，通过“选择图案并铺满…”选择图像文件、参考图像或图案（使用绘制色），即可以上下左右重复的方式铺满图层（会替换现有像素，可撤销）。也可对齐 UV 接缝。

描边（图层轮廓） Standard

不改变图层图像本身，而在合成时添加描边。之后可改粗细、颜色或关闭。

  • 打开方式：图层右键 →“描边”、菜单“图层”→“描边”、图层属性“添加”“设置”。有描边的图层行显示“fx”，点击也可打开同一窗口。
  • 设置：大小（粗细，纹理 px）、位置（外侧、内侧、居中）、混合、不透明度、颜色。改值即时预览，OK（Enter）确认，取消（Esc）恢复原状。
  • 描边作用于蒙版后的形状。剪贴图层限制在底层已绘制区域内。也可用于文件夹和文字图层。
  • 右键 →“描边”：切换显示、复制、粘贴（多选则全部）、清除、烘焙到像素。
  • 保存：工程文件保留参数。PNG、材质导出为含描边的合成图，PSD 则将描边烘焙到图层像素。
描边在 UV 上计算，因此超出 UV 岛边缘的描边可能在 3D 中显示为在岛边缘断开。
添加、修改描边从 Standard 起可用。Lite 打开工程文件时保留描边显示，也可显示、隐藏、复制、清除、烘焙到像素。

调整图层、滤镜 Standard

  • 调整图层：“调整”按钮 → 色相、饱和度、明度／亮度、对比度／色阶／反相／灰度／色调分离／阈值／渐变映射。不会改写下方图像。参数在图层属性面板调整，可用蒙版限定范围，或剪贴到正下方图层。
  • 滤镜（“滤镜”菜单）：色相、饱和度、明度／亮度、对比度／色阶／色调分离／阈值／渐变映射／模糊（高斯）／锐化（USM）／反相／灰度。作用于选中图层（也可“应用于所有显示中的纹理集”）。
  • 滤镜窗口中，改值即时更新模型效果，OK（Enter）确认，取消（Esc）恢复原状。窗口打开时仍可调整视角。
  • 模糊和锐化仅在 UV 岛内计算，不会使岛边缘变暗。

亮度转为透明度

滤镜 → 亮度转为透明度从 Lite 起可用。将白色背景变透明，暗部保留为黑色阴影，适合仅为 AO 阴影换色。

  1. 选择 AO 等非底色的绘制图层。若已锁定或锁定透明像素，请先解除。
  2. 执行“亮度转为透明度”。白色变透明，越暗的区域成为越不透明的黑色。
  3. 修改阴影色时，在转换后锁定透明像素，再用自选颜色绘制。阴影浓淡会保留为透明度。
这是转换当前图层像素的滤镜，不是调整图层。不能用于底色、蒙版、调整图层，也不是保留原色进行透化的功能。Ctrl＋Z 可撤销。

渐变映射 Standard

  • 将暗部→亮部替换为渐变左侧→右侧的颜色。滤镜与调整图层均可使用。
  • 最多32个色标：点击色带添加、拖动移动、向下拖离删除、双击选色。可调整各点不透明度、均匀分布、左右互换。
  • 240个预设（蓝、红、夕阳、彩虹、柔彩、霓虹、金属、肌肤、季节、照片调色、动漫上色等）。可按名称查找。“保存当前”可将当前渐变加入个人预设。
  • 工程文件和 PSD 均保留色标。

绘制工具和烘焙也提供相同的颜色、透明度色标编辑与预设。绘制工具从 Lite 起可用，烘焙仅 Pro（绘制工具渐变／烘焙渐变）。

自动上色（从线稿生成底色）

  1. 打开 图层 → 自动上色，点击“创建提示图层”。
  2. 在提示图层各位置粗略放置要使用的颜色。
  3. 点击“执行”，在线稿正下方创建按线条分区并使用提示色填充的图层（延伸到线条下方）。
请在可见面上画闭合线条，断线处可能漏色。“跨越 UV 接缝填充”可让身体前后分属不同 UV 岛时也连续填充。

历史记录与撤销

  • 右侧“历史记录”面板列出操作。点击一行即可一次撤销或前进到该操作之后。
  • 撤销 Ctrl＋Z、重做 Ctrl＋Y（Ctrl＋Shift＋Z）。最多保留30步。
  • 改变图像的操作（图层、蒙版、绘制目标、材质设置）可撤销。仅改变显示的操作（显示范围、对象可见性、混合形状、视角、显示方式等）和应用设置不计入历史。
  • 改变分辨率会清空全部撤销历史（更改前需确认）。

图层休眠（节省内存）

  • 为便于叠加大量4096图层，暂时未使用的图层会在空闲时压缩保存，节省 GPU 内存。显示、导出和保存均不变。
  • 选中休眠图层或开始绘制时会立即恢复。重新加载大量图层时会显示“正在准备…”后切换。
  • 可在 文件 → 偏好设置 → 绘制 →“性能”关闭（默认开启）。
