图层

图层在每个纹理集中层层叠放。把底涂、阴影、图案分在不同的图层上，之后就可以再调整颜色和浓淡。叠加方式、蒙版、滤镜等作用于图层的功能也汇总在本页。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

先看这几点
  1. 点图层面板中的“添加”（Ctrl+Shift+N），添加新图层（详情）。
  2. 点击一行选中图层，就可以在其上绘制。用眼睛图标切换显示/隐藏，用不透明度调整浓淡（详情）。
  3. 画阴影时，给位于底涂之上的图层开启“剪贴”，并把混合模式设为“正片叠底”，就不会涂出范围（详情）。
  4. 想不擦除而是隐藏一部分时，使用图层蒙版（详情）。
  5. 出错时按 Ctrl+Z。在历史记录面板中，可以一次退回到前面好几步（详情）。

添加图层，分开绘制

绘制的内容会进入当前选中的图层。按部位分开图层，之后更容易删除或更改颜色。

  1. 点图层面板下方的“添加”。会在当前选中图层的上方新建一个图层。
  2. 点击想要绘制的图层所在的行，选中它。
  3. 开始绘制。
  4. 点击眼睛图标，可以切换显示/隐藏。
  5. 双击名称可以重命名（按 Enter 确定）。
Lite 版每个纹理集包括底色最多 4 个图层（计入绘制图层和调整图层，不计入文件夹和蒙版）。达到 4 个后，面板下方会显示“图层 4 / 4 张（含底色，Lite）”，并且“添加”“复制”上会出现小锁标记。

合并

  • 面板中的“合并”按钮，通常是向下合并；选中文件夹时是把文件夹合并为一个图层；选了多个图层时是合并所选图层。
  • 带描边的图层，会先把描边烘焙为像素，再进行合并。
  • 把调整图层向下合并，可以把调整效果烘焙进下方图层的像素。
  • Pro 在法线贴图文件夹中，可以合并从最下方起连续的可见图层。文件夹的不透明度须为 100%，文件夹的蒙版须保持停用（绘制目标）。

同时选择多个图层

  • 按住 Ctrl 点击名称，可逐个添加或取消；按住 Shift 点击，可选中中间的所有图层（Ctrl+点击缩略图是选区，两者不同）。
  • 选中多个图层时，显示、混合模式、不透明度、剪贴、锁定透明像素、锁定、颜色标签、删除、复制、放入文件夹（Ctrl+Shift+G）、合并都会对它们一起生效。撤销一次即可还原。
  • 拖动所选图层中的任意一个，全部图层会保持原有排列顺序一起移动。在文件夹所在行的中间松开，全部图层都会进入该文件夹。
  • “上移一层”“下移一层”一次只移动一个图层。复制、剪切也只对当前选中的一个图层生效。

通过按键或 3D 视图选择

  • 按 Alt+] 选中上方的图层，按 Alt+[ 选中下方的图层。
  • 在 3D 视图或 UV 视图中右键 → “选择在此处绘制的图层”，会列出点击处所绘制的可见图层。最上面的一个带有标记。被蒙版遮住的地方、不透明度为 0% 等看不见的图层不会列出。
  • 用移动·变形工具的“自动选择图层”也可以选择（移动·变形工具）。
  • 如果这样选中的行不在可见范围内，列表会滚动到能看到它的位置（已折叠的文件夹会展开）。要关闭这一行为，请取消勾选 …（其他）或列表右键菜单中的“滚动列表直到能看到用按键等选中的图层”。

操作不顺利时

  • 无法添加图层（Lite）：Lite 版每个纹理集最多 4 个图层（含底色）。删除或合并图层后，又可以添加了（版本）。
  • 画了却没有出现颜色：检查选中的图层是否被隐藏或锁定，以及绘制到的对象是否变成了蒙版。也可能是被上方的图层遮住了。
  • 画到了别的图层上：按 Ctrl+Z 撤销，然后在 3D 视图中右键 → “选择在此处绘制的图层”，重新选择想要绘制的图层。

叠加阴影与光（混合模式、不透明度）

混合模式决定图层与下方画面的混合方式。阴影常用“正片叠底”，光常用“滤色”或“相加（发光）”。

  1. 选中要绘制阴影或光的图层。
  2. 在面板上方的混合模式栏中选择混合模式。也可以将光标移到该栏并转动滚轮，切换到上一个或下一个混合模式（连续转动的操作按 1 次 Ctrl＋Z 即可恢复）。
  3. 用不透明度调整浓淡。

混合模式一览

共 28 种。在栏中，它们按以下分组排列。

分组混合模式
—正常
变暗变暗、正片叠底、颜色加深、线性加深、深色
变亮变亮、滤色、颜色减淡、相加（线性减淡）、相加（发光）、颜色减淡（发光）、浅色
对比叠加、柔光、强光、亮光、线性光、点光、实色混合
差值差值、排除、减去、划分
色彩色相、饱和度、颜色、明度

文件夹还有一个“穿透”（初始值）（文件夹）。

相加（发光）、颜色减淡（发光）

  • 与普通的相加、颜色减淡不同，即使在降低了不透明度的地方，或柔和画笔的边缘，也会强烈发光。
  • 相加（发光）会一直叠加到光饱和为止，颜色减淡（发光）则是越亮的地方发光越强。即使下方是透明的地方，也会以图层的颜色发光。
  • 可用作图层、文件夹、调整图层的混合模式，描边的混合，以及画笔的渲染模式。
  • 写入 PSD 时会使用相近的混合模式（线性减淡、颜色减淡），并在图层名后加上“[glow]”。在 PetaNuri3D 中导入时会还原为发光。在其他软件中，半透明部分的外观会有变化。

不超出范围地绘制（剪贴、锁定透明像素、锁定）

在底涂之上涂阴影或图案时，可以避免涂到已涂区域之外。每一项都通过面板上方的图标开启或关闭。

功能作用其他切换方式
剪贴（↳）仅在紧邻的下方图层已绘制的地方显示此图层（以下方图层为基底）Ctrl+Alt+G、右键 → “剪贴到下方图层”
锁定透明像素绘制时，透明的地方仍保持透明（只改变颜色）图层 → 剪贴与保护 → “切换锁定透明像素”
锁定使图层无法绘制图层 → 剪贴与保护 → “切换锁定”
  1. 选中底涂图层，用“添加”在其上方添加图层。
  2. 点击面板上方的剪贴（↳）图标。
  3. 把混合模式设为“正片叠底”，涂阴影。不会涂到底涂之外。
剪贴图层的内容依然保留，所以扩大底涂后，这些内容也会出现在扩大的部分。锁定透明像素则是保护该图层内容本身的形状。

整理到文件夹

把相关的图层整理到文件夹中，列表会变短，还能一起切换显示/隐藏或调整不透明度。

  1. 选中要整理的图层（数量不限）。
  2. 按住 Shift 点击“文件夹”按钮（Ctrl+Shift+G）。所选图层会进入文件夹。
  • 只点“文件夹”按钮（Ctrl+G）的话，会创建空文件夹。
  • 把图层行拖到文件夹行的中间，会放入其中；拖到上半部分或下半部分，则放到文件夹的上方或下方。
  • 混合模式“穿透”（初始值）会把内容直接叠加到文件夹外部的画面上。其他模式则先把内容合成为一个图层，再进行叠加。
  • 要取消文件夹，可用 …（其他）或右键菜单中的“解散文件夹”。内容会移到文件夹外。
  • 文件夹上也可以添加蒙版和描边。

隐藏一部分（图层蒙版）

蒙版可以在不擦除图层内容的情况下将其隐藏。被隐藏的部分，之后随时可以恢复。

  1. 选中要隐藏内容的图层。
  2. 点“蒙版”按钮 → 选择“添加显示全部蒙版”。该行会出现蒙版缩略图。
  3. 点击蒙版缩略图。绘制到的对象就变成蒙版。
  4. 用黑色绘制会隐藏，用白色绘制则显示。灰色为半透明显示。
  5. 点击像素缩略图，绘制对象就回到画面。

蒙版菜单

“蒙版”按钮、图层 → “蒙版”、右键菜单中的“蒙版”里，都有相同的项目。

项目作用
添加显示全部蒙版、添加隐藏全部蒙版添加白色（全部可见）或黑色（全部隐藏）的蒙版
从选区创建蒙版添加只显示选区内部的蒙版。对于调整图层，会替换现有的蒙版
绘制到蒙版将绘制对象设为蒙版
启用蒙版关闭后，蒙版不起作用，全部显示
显示蒙版范围给被隐藏的部分上色，使其显示出来
反转蒙版对调可见和隐藏的部分
左右镜像复制蒙版把蒙版的黑白内容复制到 3D 模型的另一侧（左右镜像复制）
应用蒙版（烘焙到像素）从画面中删除被隐藏的部分，并移除蒙版
删除蒙版移除蒙版（画面保持不变）
复制蒙版、粘贴蒙版把蒙版复制到其他图层。也可以粘贴到其他纹理集
将此图层的亮度复制为蒙版绘制出的黑白图像，可以用“粘贴蒙版”变成蒙版（透明的地方会被隐藏）
以黑白显示蒙版只把蒙版以黑白显示在 3D 和 UV 中
用绘制色的亮度绘制蒙版（白 = 显示、黑 = 隐藏）关闭后，无论颜色如何，画过的地方都会显示（隐藏要用橡皮擦）

蒙版操作技巧

  • Shift+点击蒙版缩略图，可切换启用/停用（停用期间显示红色斜线）。
  • Alt+点击蒙版缩略图，以黑白显示蒙版。
  • 把蒙版缩略图拖到其他图层的行上是移动，Alt+拖动是复制。调整图层的蒙版则是复制。
  • 如果粘贴目标已有蒙版，会被替换。大小不同的话，会拉伸后放入。
  • 选区的填充、Alt/Ctrl+Backspace 的填充，在蒙版中也是按颜色的亮度写入。
  • 蒙版的操作可以在偏好设置的键位设置中分配按键。

操作不顺利时

  • 画了但画面没有变化：绘制对象仍是蒙版。点击像素缩略图，回到画面。
  • 蒙版不起作用：蒙版处于停用状态（红色斜线）。Shift+点击蒙版缩略图即可启用。
  • 在蒙版上绘制，显示效果没有变化：用白色绘制是“显示”。要隐藏的话，请用黑色绘制，或使用橡皮擦。

让列表更易读（颜色标签、缩略图）

图层变多以后，可以用颜色标签分类，或放大缩略图，方便查找。

  1. 选中要加颜色的图层（数量不限）。
  2. 点击剪贴、锁定图标所在行最左侧的彩色圆点和 ▾ 框（也可以右键 → “颜色标签”）。
  3. 从无、红、橙、黄、绿、青、蓝色、紫、灰中选择。行的左侧会出现一条粗的彩色带。
  • 文件夹的颜色，会以细线延续到里面图层的左侧。撤销一次即可还原。
  • 有颜色标签时，列表上方会显示“按颜色显示：全”和所用颜色的圆点。点击圆点，列表中只显示该颜色的图层（画面不会改变）。再点一次或点“全”即可恢复。
  • 颜色标签会保存在工程文件中。在 PSD 的导出、导入 Standard 中，它们会对应 PSD 图层的颜色（青会变成蓝色）。

列表的大小与排列

  • 用 …（其他）或右键菜单中的“缩略图大小”，可以选择小（24px）、中（40px，初始值）、大（64px）、特大（96px）。
  • 用 …（其他）中的“将按钮栏放在上方”，可以把下方的按钮栏移到列表上方。
  • 关闭 …（其他）中的“用笔拖动来移动图层和辅助工具”后，用笔拖动将变为滚动列表。Space+拖动始终是滚动。
  • 向下拖动面板的边界，可以扩大列表。
  • 这些设置在下次启动后也保持不变。

铺重复图案

把图像或图案在上下左右方向重复，铺满整个图层。可用于衣服布料的花纹等。

  1. 选中要铺设花纹的像素图层。当前的画面会被花纹替换。
  2. 在图层属性的“重复图案”中点“选择图案并铺满”。会打开花纹列表。
  3. 从“图像文件…”“参考图”，或下方排列的图案画面中选择。图案会成为用前景色绘制的花纹。
  4. 用下表中的项目调整排列方式。

排列方式与颜色

项目作用
横向重复、纵向重复横向、纵向排列的数量（开启“保持纵横比”，则按相同比例更改）
横向偏移、纵向偏移、旋转（°）更改花纹的位置和方向
融合接缝让花纹的接缝不明显
镜像重复每隔一块左右、上下翻转排列。边缘不连续的图像也不会出现接缝
对齐 UV 接缝自动寻找接缝容易与花纹接缝对齐的大小（当前的 1/2～2 倍）和偏移
用前景色重新上色、恢复图像颜色保持花纹形状不变，改为当前的前景色。恢复后回到原来的颜色
转为普通图层移除排列设置，保留当前像素并转为普通图层
  • 最上面一行显示当前花纹的图和名称，点击会打开花纹列表。
  • 花纹显示在哪些位置，可以用蒙版来决定。
  • 排列方式和花纹会保存在工程文件中。可以用撤销还原。

操作不顺利时

  • 补画的部分消失了：铺设花纹之后补画的内容，在更改排列方式时会消失（更改前会弹出确认）。按 Ctrl+Z 可以还原。
  • 花纹在接缝处没有连上：在两侧 UV 岛的方向、形状不同的接缝处，即使对齐也无法连接。
  • 无法铺设：已锁定、锁定透明像素、已隐藏的图层，以及文字图层、法线贴图图像图层，都无法铺设。

把一侧的内容复制到另一侧（左右镜像复制）

把忘了开启对称绘制而涂的内容，复制到 3D 模型的另一侧。即使左右的 UV 不同，也会按形状找到对应位置来复制。

  1. 选中要复制的图层。
  2. 选择 图层 → “左右镜像复制”（图层所在行的右键菜单中也有）。
  3. 点“左半身 → 右半身”或“右半身 → 左半身”。复制目标一侧的颜色会被替换。
  • 左右以模型自身的方向为准（从正面看则相反）。中心与“对称绘制”的中心相同（左右对称绘制）。
  • 勾选“复制到新图层（仅包含复制的部分）”后，复制出的部分会放进新图层。
  • 有选区时，选择“将选区内容复制到另一侧”或“复制到选区内”（用另一侧的颜色替换选区内的内容）。
  • 蒙版请用蒙版菜单中的“左右镜像复制蒙版”来复制。
  • 找不到左右对应位置的地方（只存在于一侧的部分等）保持不变。按一次 Ctrl+Z 即可还原。

给边缘加上线条（描边） Standard

不改变图层内容本身，只在叠放时加上描边。之后还可以更改粗细和颜色，或关闭它。

  1. 选中要加描边的图层。
  2. 点图层属性中的“添加”。会出现描边窗口。
  3. 设置大小、位置、颜色等。数值一动，外观就会立即变化。
  4. 点 OK（Enter）确定。点取消（Esc）则恢复原状。

描边菜单

位于 图层 → 描边，或图层的右键菜单 → “描边”中。带描边的图层，其行上会出现“fx”标记，点击会打开设置窗口。

  • “描边设置”：打开窗口。
  • “显示描边”：保留数值，切换显示/隐藏（与图层属性中的“显示”相同）。
  • “复制描边”“粘贴描边”：复制到其他图层。如果选了多个图层，会粘贴到全部图层。

生成的形状与保存

  • 描边会加在应用蒙版之后的形状上。剪贴的图层，描边会收在基底已绘制的范围内。
  • 文件夹（内容合起来的形状）和文字图层（重新输入文字后也保持不变）也可以添加描边。
  • 向下合并和合并文件夹，会先烘焙描边再合并。
  • 工程文件中会连数值一起保存。导出 PNG、导出材质时是包含描边的画面，导出 PSD 时则是烘焙为像素的图层（PSD）。
  • 旧版本或 PSD 中带有的其他效果（投影等），会保持原有外观打开。不能更改，但可以在图层属性中“烘焙为像素”或“移除”。
添加、更改、粘贴描边需要 Standard 及以上版本。即使在 Lite 中，已打开的工程文件里的描边也保持原有外观，并且可以显示/隐藏、复制、清除、烘焙为像素。

操作不顺利时

  • 描边在 UV 岛边缘被截断，或延伸到相邻的岛上：描边是在 UV 上计算的。超出岛边缘的部分，在 3D 中可能会在岛边缘处被截断。导出后，岛外的部分与外扩（填充）的处理方式相同。

事后更改颜色（调整图层） Standard

在不改写下方画面的情况下，叠加亮度和颜色的调整。数值随时可以重新调整。

  1. 选中位于要调整画面正上方的图层。
  2. 点面板中的“调整”按钮，选择类型。会创建调整图层。
  3. 在图层属性面板中拖动数值。拖动过程中只有画面在变化，松开后可以一步撤销。

共有 15 种：色相/饱和度/明度、亮度/对比度、色阶、反相、灰度、色调分离、阈值、渐变映射、色调曲线、色彩平衡、曝光度、色温、自然饱和度、替换颜色、添加杂色。数值内容与滤镜相同。

  • 调整图层对下方看得见的全部画面生效。
  • 生效范围可以用蒙版限定。选中调整图层后，绘制到的对象就是蒙版。用“从选区创建蒙版”可以替换现有的蒙版。
  • 开启剪贴后，只对紧邻的下方图层生效。
  • 用“与下方图层合并”，可以把调整烘焙进下方图层的像素。
  • 在 PSD 中，色调曲线、色彩平衡、自然饱和度、曝光度、渐变映射会以调整图层的形式导出、导入。
  • 用“调整”按钮列表中的“纯色”可以创建单色图层。颜色可以在图层属性中更改。在 PSD 中也按纯色图层读写。
  • 在 Lite 中，已打开的工程文件里的调整图层，数值可以看到，但不能更改（带小锁标记）。
模糊、锐化、马赛克等需要读取周围画面的效果，不能做成调整图层（会变得很卡）。请用滤镜来应用。

UV 岛边缘与透明部分的处理

  • 模糊、锐化只在 UV 岛内部计算。岛的边缘不会变暗或变淡。要跨越接缝进行模糊时，请使用混色工具（模糊、涂抹、混色）。
  • 马赛克会按方格对透明度也求平均，锐化会让透明度也更清晰。减少杂色（中间值）也会消除透明部分上的点。
  • 提取线稿、浮雕、高反差保留，会把透明处当作白纸来判断明暗。提取线稿的线和高反差保留的结果，也会出现在原本透明的地方。
  • 在锁定透明像素的图层上，透明度保持原样。

  • 应用了滤镜但没有变化：对被隐藏或已锁定的图层不会应用。选区仅位于其他纹理集时，也不会有变化。请查看窗口中的“对象”和“不应用：”。
  • 菜单上带有小锁标记（Lite）：滤镜需要 Standard 及以上版本。亮度转为透明度、在新图层上生成边距，在 Lite 中也能使用。

图层休眠（节省内存）

为了在叠放大量分辨率 4096 的图层时也不卡顿，会把一段时间没有操作的图层从 GPU 内存中移出并另行保存。外观、导出和保存都不受影响。

  • GPU 中只放所选图层，以及下方合并后的画面和上方合并后的画面。其他图层在不绘制期间会逐个缩小保存（未绘制的部分不保存）。
  • 选中、绘制、撤销、合并、导出处于休眠的图层时，会当场恢复。在需要重新加载大量图层的选择方式下，会先显示“正在准备…”再切换（4096 的 80 个图层约需 0.1～0.3 秒）。
  • 如果上方有混合模式不是正常的图层或调整图层，这部分会留在 GPU 中。
  • 打开工程文件时，图层也是以休眠状态打开的。
  • 要关闭，请取消勾选 文件 → 偏好设置 → 绘制 → 性能 中的“让未绘制的图层休眠”（初始为开启）。关闭后，所有图层都会放在 GPU 中。
也有把未选中的纹理集整个休眠的机制（节省纹理集的内存）。
