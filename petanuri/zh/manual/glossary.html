PetaNuri3D ／ 使用手册 ／ 术语表

术语表

这里解释 PetaNuri3D 界面和本手册中出现的词语。每个词条的第一句话就是定义。详细用法请看各词条末尾的链接。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

字母、数字BDFGHJLMQSTWXYZ

字母、数字

2D 画布、2D 绘画
不使用 3D 模型，在方形 2D 区域中绘制的地方。有用来制作印章图像的“印章专用 2D 画布”，也有无需模型直接作画的“2D 绘画”。→ 印章专用 2D 画布、2D 绘画
AO Pro
指光线难以到达的位置（凹陷、重叠处、缝隙）的暗度。PetaNuri3D 会根据模型形状计算，并烘焙到图层上。→ 烘焙 AO
lilToon
VRChat 虚拟形象常用的 Unity 着色器（计算外观的机制）。在 Pro 版中，可以按这种外观确认效果，也能导入和导出材质。→ 最终效果与 lilToon 材质
MCP（AI 联动）
从 AI 应用操作 PetaNuri3D 的机制。在 文件 → 偏好设置 → AI 联动 中开启（初始为关闭）。→ AI 联动
MToon Pro
VRM 模型使用的着色器。在 Pro 版中，可以按这种外观确认最终效果（测试版）。→ 最终效果与 lilToon 材质
PSD Standard
可以保留图层分层状态保存的图像格式。在 PetaNuri3D 中，可用作新建时的底色，也可用于导出（Standard 及以上版本）。→ 导出为 PSD
UV
决定 3D 模型的面对应平面纹理哪个位置的展开图。在 PetaNuri3D 中，可以把 UV 显示在 3D 视图旁边，并直接在上面绘制。→ 显示 UV 并直接绘制
UV 岛
指 UV 上连成一片的面的集合。填充工具的“填充 UV 岛”会把点击处所在的整个 UV 岛涂满。→ 显示 UV 并直接绘制

B

版本（Lite、Standard、Pro）
PetaNuri3D 的 3 种版本。本手册在 Standard 及以上版本的功能处标注 Standard，在仅限 Pro 的功能处标注 Pro 标签。→ 版本

D

弹出调色板
按下数位笔侧键（右键）后，不移动笔直接松开时弹出的小窗口。仅用数位笔就能选择工具和颜色。→ 弹出调色板
导出
指把纹理图像（PNG、PSD）或材质，制作成可在其他应用中使用的形式。这与保存工程文件是不同的操作。→ 导出
对称绘制
在一侧绘制时，翻转后的另一侧也会同样绘制的功能。有 X（左右）、Y（前后）、Z（上下），按 M 可切换 X。→ 对称绘制
对象
指模型中的部件（头发、衣服、道具等网格）。在“对象”面板中，可以按部件进行隐藏或“仅显示此项”。→ 对象

F

法线贴图
按像素改变面的朝向，让表面看起来有凹凸的图像。缝线的褶皱和隆起，是在法线贴图文件夹中按高度绘制的（Pro）。→ 缝线
分辨率
指纹理一条边的像素数。新建时按每个纹理集在 32～4096 中选择（Lite 版最高 2048）。→ 更改分辨率
辅助工具
指同一工具中设置各不相同的笔具（以钢笔为例，有 G 笔、圆笔、针管笔等）。可以复制后制作自己的设置。→ 辅助工具

G

工程文件（.petanuri）
保存 PetaNuri3D 作业内容的文件。模型、所有图层和设置都存在一个文件里，打开后就能继续绘制。→ 保存、打开并继续
工具属性
指所选辅助工具的设置（大小、不透明度、硬度、防抖、笔压等）。每个辅助工具分别记忆。→ 画笔详细设置

H

绘制目标 Pro
在主颜色以外的阴影色、蒙版、法线贴图等 lilToon 纹理上，用平常的工具绘制时的绘制位置。它们会成为图层面板中的文件夹。→ 绘制目标
混合模式
决定图层内容如何叠加到下方内容上的规则（正常、正片叠底、滤色、叠加等共 28 种）。→ 混合模式
混合形状 Pro
指表情等模型形状的变化。变成该形状后就能进行绘制。→ 混合形状
混色
用来模糊、用手指涂开、混合已绘制颜色的工具（键 J）。辅助工具中有“模糊”“涂抹”“混色”等。→ 混色

J

剪贴
只在下方图层有内容的位置显示该图层的设置。用于在不超出范围的前提下叠加阴影或花纹。→ 剪贴
接缝
指在 3D 中相连、但在 UV 上分开的位置（UV 岛的边缘）。接缝线可用 Alt+W 切换显示。→ 接缝线

L

历史记录
按从旧到新的顺序排列可撤销操作的面板。点击某一行，会一次回到该操作之后的状态（最多 30 步）。→ 历史记录
滤镜 Standard
对所选图层的内容本身施加色调调整、模糊、噪点等的功能（菜单“滤镜”）。→ 滤镜

M

蒙版（图层蒙版）
用黑白绘制来决定图层哪里显示、哪里隐藏的东西。无需擦除内容就能将其隐藏（白＝显示，黑＝隐藏）。→ 图层蒙版
面板
装有颜色、图层、工具属性等内容的界面窗口。可以移动、合并为标签页、浮动和折叠。→ 移动面板
描边 Standard
不改变图层内容，在叠加时给边缘加上描边的效果。之后可以修改粗细和颜色，也可以关闭。→ 描边

Q

前景色、背景色
前景色是绘制时使用的颜色，背景色是另外备用的一种颜色。按 X 互换，按 D 恢复为黑色和白色。→ 选择颜色的方法
轻松烘焙 Pro
从适合皮肤、服装、道具的 12 种效果中选择，批量制作明暗和渐变底涂的功能。→ 轻松烘焙

S

锁定透明像素
只能在该图层已有内容的位置绘制、无法在透明位置绘制的设置。用于不改变形状，只替换已涂的颜色。→ 锁定透明像素

T

调整图层 Standard
不改写下方内容，而对其施加色相、亮度等调整的图层。之后还可以修改数值。→ 调整图层
图案
用前景色只绘制图案部分的笔（竖条纹、波点、维希格等共 15 种）。→ 图案
图层
像透明胶片一样叠放着绘制的每一张图。每个纹理集最底下都有一个底色图层。→ 图层
图层属性
排列所选图层各项设置的面板。调整图层的数值和描边的开关也在这里更改。→ 图层属性
图层休眠
指把一段时间没有操作的图层，在外观不变的情况下从 GPU 显存中移出的机制。叠放大量 4096 图层时效果明显（初始为开启）。→ 图层休眠

W

外扩（填充）
导出时，把 UV 岛边缘的颜色向岛外扩展。如果不扩展，缩小后接缝处可能会出现线条（默认 8px）。→ 外扩
网格线
把模型各个面的边叠加显示在 3D 上的显示方式。只显示 UV 岛边缘的是“接缝线”。→ 网格线
纹理
贴在 3D 模型表面的图像。在 PetaNuri3D 中，画在模型上的内容会写入纹理。→ 导出
纹理集
指每个材质对应的一张纹理及其图层的集合。使用同一张图像的材质会合并为一个纹理集。→ 纹理集
无对应材质的纹理集
指重新加载模型时，新模型中已不存在的材质所对应的纹理集。它不会被删除，而是以 ! 标记保留，可以把图层移到其他纹理集。→ 无对应材质的纹理集

X

显示范围
只在 3D 中显示所选的岛或面、隐藏其余部分的机制。被隐藏部分内侧的面会露出来，从而可以绘制。→ 显示范围
显示方式
指 3D 视图的显示种类（保持绘制颜色、二值卡通、明暗、最终效果等）。在 3D 视图左上角切换。→ 3D 视图四角
选区
指圈出并限定可绘制位置的范围。有选区时，只能在其中绘制。→ 选区

Y

也绘制背面和被遮挡的面
决定笔刷能够到达的位置，是否连看不见的背面和内侧的面也一起绘制的设置。位于工具属性中不透明度的正下方，每个辅助工具分别记忆。→ 也绘制背面
隐藏笔
把划过的面或 UV 岛从 3D 显示中隐藏的工具。隐藏前面的部分后，就能绘制原本因重叠而画不上的内侧面。按 Alt+H 可恢复全部显示。→ 隐藏笔
右键菜单
用鼠标右键点击时弹出的、列出该位置可用操作的菜单。内容会因 3D 视图、图层、纹理集等位置而异。→ 右键菜单

Z

主与副（纹理集）
指处于可立即绘制状态的 2 个纹理集。当前选中的是主，之前选中的是副，可以用一条线跨越两者绘制。→ 跨两个纹理集绘制
姿势模式 Pro
移动骨骼摆出姿势，并按该形状进行绘制的模式。用于腋下等在原始姿势下难以绘制的位置。→ 姿势模式
自动保存
每 5 分钟自动保存作业内容的机制。每份作业最多保留最新的 3 份，可通过 文件 → 从自动保存打开 恢复。→ 保存、打开并继续
自动上色
根据线稿和颜色的“提示”，为被线条分隔开的每个区域制作底涂的功能（图层 → 自动上色）。→ 自动上色
最终效果 Pro
3D 显示方式之一，用与 lilToon 相同的计算方式，显示加上阴影和边缘光等的外观（测试版）。→ 最终效果
