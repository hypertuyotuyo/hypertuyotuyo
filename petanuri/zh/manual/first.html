初次使用：花约 10 分钟试着给示例模型上色

用练习用的模型“Shinobu”，完整试做一遍：打开、旋转、绘制、左右对称、填充、保存与导出。任何版本（包括免费的 Lite）都能做。先跳过细节设置，完整做完一遍，就是本页的目标。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

需要准备的东西
  1. 装有 PetaNuri3D 的 Windows 电脑（安装方法见安装与启动）。
  2. 鼠标（带滚轮和右键的）或数位板。
  3. 不需要自己的模型。示例模型已内置在应用中。

1. 打开“Shinobu”

在启动画面中，打开练习用的模型。

  1. 启动 PetaNuri3D。
  2. 点击中间的“用示例试试”。
  3. 中间出现“Shinobu”后，准备完成。
  • 初次启动时会出现操作引导（教程）。可以按引导一步步进行，也可以点击“跳过”或按 Esc 关闭，继续按本页操作。
  • Shinobu 按部位划分成了多个纹理集（以一张纹理为单位的一组内容）。会自动切换到开始绘制处所在的纹理集，现在不必在意。
示例模型仅限用于试用 PetaNuri3D。请勿取出后分发，也不要用于其他用途。

2. 旋转查看

移动视角，让想上色的位置可见。

想做的事鼠标数位笔
旋转按住右键拖动按住侧键移动，或 Space+拖动
平移按住中键（滚轮）拖动Shift+Space+拖动
拉近、拉远转动滚轮Ctrl+Space+拖动
从正面查看小键盘的 1
查看整体F

左键（笔尖）用于绘制。不知所措时，按 F 回到整体视图。

想改成其他软件的习惯操作时，之后可以在“相机操作模板”中更改（相机操作模板）。

3. 添加用于绘制的图层

与原图（底色）分开绘制，即使画坏了，也只需删除该图层。

  1. 在想绘制的位置（例如头发）上按 Alt+右键。会选中该处的纹理集，并短暂地泛起一层颜色。
  2. 按 Ctrl+Shift+N。点击图层面板底部最左边的按钮也一样。
  3. 图层面板中会添加新图层，并处于选中状态。
Lite 版中，每个纹理集最多 4 个图层（含底色）。这个练习足够用。

4. 选择颜色并绘制

用钢笔在 Shinobu 的头发和耳朵上描画。

  1. 按 P，切换为钢笔。
  2. 在右侧的“色彩”面板中，点击喜欢的颜色。
  3. 用左键（笔尖）在 Shinobu 的头发上描画。
  4. 画坏了就按 Ctrl+Z 撤销一步。重做按 Ctrl+Y。
  • 线条粗细：按 [ 变细，按 ] 变粗。
  • 在 Shinobu 上按住 Alt 并点击，可以取该处的颜色（吸管）。
  • 想擦除时，按 E 切换为橡皮擦。

操作不顺利时

  • 用数位笔绘制，粗细却不变：未收到笔压（笔压不生效时）。
  • 画不出来、没有线条：请在图层面板中检查所选图层是否被隐藏或锁定。

5. 左右对称绘制

在脸的一侧绘制，另一侧也会出现同样的线条。

  1. 按 M。3D 视图左上角的 X 会亮起颜色。
  2. 在 Shinobu 脸的一侧（脸颊等）绘制。
  3. 另一侧也会出现同样的线条。
  4. 画完后，再按一次 M 关闭。

详细设置（前后、上下对称，对称中心的确定方法）见对称绘制。

6. 用填充一次涂满

把衣服的某一个部分一次涂成同一种颜色。

  1. 按 G，切换为填充。
  2. 在辅助工具面板中选择“填充 UV 岛”。
  3. 点击想涂的衣服。点击处相连的一整块（UV 岛）会用前景色填满。
  • 涂得比预想的大时，按 Ctrl+Z 撤销。只想填充线条围住的范围时，使用“填充封闭区域”（填充）。

7. 在 UV 中确认

查看画的线落在纹理图像的什么位置。

  1. 按 U。3D 视图旁会显示 UV（纹理的展开图）。
  2. 查看刚才画的线在 UV 上的位置。也可以直接在 UV 上绘制。
  3. 再按一次 U 关闭。
像项圈内侧这样因重叠而无法绘制的位置，用工具栏中的“隐藏笔”（眼睛加斜线的图标）划过，前面的面就会被隐藏，从而可以绘制。按 Alt+H 恢复全部显示（隐藏笔）。

8. 保存并导出纹理

PetaNuri3D 有两种操作：保留工作进度的“保存”，和生成纹理图像的“导出”。

  1. 按 Ctrl+S，保存为工程文件（.petanuri）。图层会保持分开，以后可以继续修改。
  2. 选择 文件 → 导出 → 导出 PNG（全部纹理集）。
  3. 在弹出的窗口中直接点击“导出”，选择保存位置。
  4. 每个纹理集会生成一张 PNG 图像（文件名为材质名称）。导出的文件夹会自动打开。

用于虚拟形象或游戏引擎（Unity 等）的是这些 PNG。工程文件是用来在 PetaNuri3D 中继续绘制的。
