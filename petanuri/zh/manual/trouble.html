遇到问题时

这里按症状整理了常见的问题，方便查找。每一行链接的目标页面里都有原因和解决方法。这里没有的话，请在上方的搜索框中输入症状的关键词。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

先看这几点
  1. 操作失误时，按 Ctrl+Z 撤销一步。想退回到更早的几步，请使用历史记录。
  2. 应用崩溃或卡住时，重新打开后选择 文件 → 从自动保存打开（详情）。
  3. 无法绘制时，先检查当前选中的图层，以及是否还残留着选区（无法绘制）。
  4. 仍无法解决时，可以通过 帮助 → “联系我们（支持、功能需求、错误报告）”发送（联系我们）。

启动与打开模型

  • 出现“Windows 已保护你的电脑”：因为应用没有签名，第一次启动时可能会出现。依次点击“更多信息”→“仍要运行”即可启动（安装与启动）。
  • 把模型拖放到窗口中打不开：打开模型之后，再拖放就不会打开了。请通过 文件 → 新建 打开（打开模型）。
  • 提示找不到纹理、提示有无法绘制的地方：在新建窗口中重新选择图像。没有 UV 的面等是无法绘制的（打开模型）。
  • 移动或更新 PetaNuri3D 之后，无法从 Unity 启动：请在 Unity 一侧重新选择 PetaNuri3D 的位置（重新选择位置）。
  • 面板和工具栏全都消失了：是被 Tab 隐藏了。再按一次 Tab 就会恢复（界面各部分）。
  • 找不到想用的面板，或布局乱了：从 显示 → 窗口 中调出，或恢复布局（面板一览、恢复布局）。
  • 透明部分显示为灰色或棋盘格、低分辨率的纹理显得模糊：这是显示设置的问题（光照与透明的显示方式）。
  • 无法在应用内更新到新版本：请从 BOOTH 下载 ZIP，手动更新（更新到新版本）。

无法绘制、画不到想要的位置

  • 划过去没有颜色、只有一部分能涂：原因可能是图层被隐藏或锁定、残留着选区等（画出第一笔）。
  • 涂不到选区之外、涂不到想要的位置：残留着选区。取消选区后再绘制（选区）。
  • 画了但画面没有变化：绘制到的对象是图层蒙版（图层蒙版）。
  • 选了颜色却只能涂出灰色：仍在对绘制目标（阴影色、蒙版等）进行绘制。点“返回颜色”即可恢复（绘制目标）。
  • 无法添加图层（Lite）：Lite 版每个纹理集最多 4 个图层（含底色）（图层）。
  • 一画就切换到了另一个纹理集：这是自动切换到开始绘制处的纹理集的功能。也可以关闭（选择要绘制的纹理集）。
  • 无法在其他纹理集上绘制、脖子交界处线条中断：检查跨两个纹理集绘制的设置（跨两个纹理集绘制、无法绘制时）。
  • 衣服下面或头发内侧涂不到：把靠前的面隐藏起来，就能涂到里面（显示范围、隐藏笔）。
  • 模型的一部分消失后没有恢复：那是被隐藏的部分。按 Alt+H 恢复全部显示。隐藏操作不会记入撤销历史（显示范围）。
  • 颜色涂到了厚度的另一侧：开启了“也绘制背面和被遮挡的面”（也绘制背面和被遮挡的面）。
  • 姿势模式下无法绘制：请参阅姿势模式。

线条、画笔、工具异常

  • 笔压不起作用、粗细不变，或表现异常：请按笔压不生效时的顺序检查。
  • 改成 WinTab 后笔没有反应，或提示“WinTab 没有空位”：请参阅笔压不生效时。
  • 松开侧键后 3D 视图仍在继续旋转：请参阅数位笔按键。
  • 画细节时，右键菜单自己弹出来：请参阅右键菜单。
  • 按键不起作用，或发生意料之外的操作：检查键位设置（键位设置）。
  • 放大后线条变细、斜面上线条被拉长、线条有延迟：这是画笔大小基准等设置的问题（调整绘制手感）。
  • 线条自己变直或变弯：被尺子吸附了（尺子）。
  • 左右对称时，另一侧偏移或画不出来：检查对称中心，以及对哪些工具无效（左右对称绘制）。
  • 填充漏到线外、线条边缘留有白色缝隙：用封闭间隙和扩展/收缩来解决（填充）。
  • 图章贴不上，或连白色方块也贴上了：请参阅图章。
  • 图案的花纹上下颠倒或横过来了：请参阅图案。
  • 输入文字后，按键也无法切换工具：正处于文字输入状态（文字）。
  • 使用移动工具时提示“此处没有已绘制的可见图层”：请参阅移动·变形工具。

撤销与效果异常

  • 有些操作按 Ctrl+Z 无法撤销：有些操作不会记入撤销历史（无法撤销的操作）。
  • 应用了滤镜但没有变化：请参阅滤镜。
  • 烘焙出的阴影重叠成两层、或过浓：请参阅烘焙后的调整。
  • 烘焙 AO 后，衣服下面的身体变得一片漆黑：请参阅烘焙 AO。

卡顿、停止响应、保存

  • 卡顿、无法绘制，或提示“显示处理已停止”：GPU 内存不足（节省内存）。
  • 应用崩溃或卡住了：重新打开后，通过 文件 → 从自动保存打开 恢复（保存）。
  • 出现“应用内部的读写已停止”，或保存窗口没有出现：请参阅保存、打开并继续。
  • 工程文件的名称带有“（有缺失）”：这是有一部分内容无法读取的文件。请另存为（保存）。
  • 纹理集上出现了 !，或重新加载后看不到画好的内容：这是无对应材质的纹理集。可以把图层移到其他纹理集。

导出、Unity、AI 联动

  • 在 Unity、VRChat 中能看到 UV 接缝处的线：加大导出时的外扩（填充）（外扩）。
  • 无法导出（出现“显示……时无法导出”等提示）：请参阅导出为 PNG。
  • 导出的材质在 Unity 中变成粉色：请参阅导出材质。
  • 出现“无法再添加”（绘制目标）：请参阅绘制目标。
  • 从 Unity 绘制后，外观没有变化：请参阅从 Unity 绘制。
  • AI 应用提示“无法连接”：可能是 AI 联动处于 OFF 状态（AI 联动）。

联系我们

如果本手册无法解决问题，或想提出功能需求、报告错误，可以在应用内发送。查明问题所需的信息（版本号、版本类型、运行环境）会自动填入文本中。

  1. 选择 帮助 → “联系我们（支持、功能需求、错误报告）”。
  2. 选择类型。会出现用于填写的栏位，以及已包含版本号等信息的文本。
  3. 填写空白处。
  4. 点“打开 BOOTH 店铺（文本已复制）”或“打开 Discord（文本已复制）”。文本会被复制，并打开发送位置。
  5. 粘贴到发送位置后发送。BOOTH 请从店铺页面下方的“联系店铺”发送；Discord 请加入服务器，粘贴到咨询频道中。
收到的功能需求的处理情况，汇总在需求与处理状况页面中。
