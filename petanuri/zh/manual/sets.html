纹理集与对象

模型的每个材质都会生成一个“纹理集”。一个纹理集对应一张纹理，图层和分辨率按纹理集分别保存。也可以按头发、服装等对象（网格）分别隐藏。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

先看这几点
  1. 在模型上开始绘制时，会自动切换到该处的纹理集。手动选择时，按 Alt+右键（详情）。
  2. 颈部接缝等两个纹理集的交界处，先在两个纹理集上各点一次再绘制，就能用一笔跨过去（详情）。
  3. 分辨率在纹理集面板中行右侧的栏里更改。因为会清除撤销历史，请先保存（详情）。
  4. 卡顿或无法绘制时，降低分辨率，或关闭其他应用（详情）。
  5. 想把衣服等整件隐藏时，点击对象面板中的眼睛按钮（详情）。

选择要绘制的纹理集

能绘制的是所选的纹理集。通常不需要重新选择，会自动切换到开始绘制处的纹理集。

  1. 在 3D 视图中，从想要上色的位置开始绘制。
  2. 如果起点在其他纹理集上，会先自动切换到该纹理集再绘制。笔尖旁边会显示纹理集的名称。
  • 手动选择时：在纹理集面板中点击该行、在模型上按 Alt+右键、使用 3D 右键菜单的“选择此纹理集”。也可以从 UV 区域右键菜单的“纹理集”中选择。
  • 重新选择后，该纹理集会在 3D 中柔和地着色一下再消失。由此可以知道哪里是该纹理集。
  • 休眠中的纹理集，在唤醒期间会显示“正在切换纹理集…”（2048 约 0.2 秒，4096 约 0.5–1.5 秒）。这期间笔的动作会被记住，唤醒后直接接着绘制，所以线条不会缺失。
  • 即使重新选择纹理集，撤销、重做也能继续使用。撤销其他纹理集的操作时，会选中那个纹理集。
  • 图层面板和 UV 区域显示的是所选纹理集的内容。

禁止自动切换

关闭 3D 视图左下角的“切换到所触及处”（也可以用 3D 右键菜单的“自动切换到开始绘制处的纹理集”）。关闭期间，即使从其他纹理集上开始绘制也不会切换，只能在主和副上绘制。

操作不顺利时

  • 绘制后跳到了别的纹理集：开始绘制的位置在其他纹理集上。不想切换时，请关闭“切换到所触及处”。
  • 无法在 3D 中绘制，光标变成禁止符号：光标所在处是未选中的纹理集，或者图层被锁定、被隐藏。原因会显示在光标下方。

跨两个纹理集绘制（主与副）

像颈部接缝那样，可以用一笔跨过脸和身体的纹理集交界处进行绘制。

  1. 在想要跨越的两个纹理集上各点一次（绘制或选择都可以）。
  2. 确认 3D 视图左下角的“跨纹理集绘制”已开启（默认开启）。
  3. 跨过交界处绘制。两个纹理集都能连续上色。
  • 保持唤醒、可以绘制的有两个：所选的纹理集（主）和上一个选中的纹理集（副）。名称显示在 3D 视图左下角，点击“副”会与“主”互换。
  • 在面板中，主所在的行为粉色，副所在的行为蓝色，并带有标签。
  • 在各个纹理集上，会绘制到该纹理集所选的图层。撤销一次，两边会一起撤销。
  • 笔尖没有落在的纹理集，画笔的圆不会溢出到那里。画眼睛时，也不会涂到皮肤上。模糊、涂抹、混色、液化也是一样。
  • 在 UV 区域，只会绘制到主纹理集。右下角会显示小小的副 UV（点击后副变为主）。

不跨集绘制、移除副集

  • 只想绘制到开始绘制的那个纹理集时，关闭左下角的“跨纹理集绘制”（也可以用 3D 右键菜单的“一笔跨越 2 个纹理集绘制”）。关闭后两个纹理集仍保持唤醒，所以可以马上来回切换。
  • 移除副集时，点击面板中副所在行的“副”标签右侧的 ×（也可以用副所在行右键菜单的“移除副集（不再一起绘制并休眠）”）。该纹理集会休眠，GPU 内存随之释放。
  • 移除后，左下角的副显示为“无”。选择其他纹理集后，当前的主又会成为副。
“副”与 lilToon 的主颜色 2nd 是两回事。

纹理集的生成方式

  • 每个材质会生成一个纹理集。使用同一图像的材质，会合并成一个纹理集。合并方式在新建界面中决定（打开 3D 模型）。
  • 选中合并后的纹理集时，面板中会显示“此纹理被 〇〇、〇〇 使用”。绘制后，会反映到所有相关材质。
  • VRM 的透明部分，沿用原图像的透明度和材质的透明设置。即使是同一张图像，透明设置不同的材质也会成为不同的纹理集。
  • 印章专用 2D 画布和 2D 绘画，是与模型纹理集分开的工作用纹理集。编辑期间，面板中会这样显示。它们会和工程文件一起保存，但不会包含在模型的导出中（印章专用 2D 画布）。

更改分辨率

纹理的大小（纵横的像素数）可以按纹理集分别更改。

  1. 先保存工程文件（Ctrl+S）。
  2. 在纹理集面板中，从行右侧的栏里选择分辨率（也可以用行右键菜单的“分辨率”）。
  3. 出现“更改分辨率会清除撤销历史。”时，点击“继续”。已绘制的内容会被放大或缩小到新的大小。
  • 可选 32、64、128、256、512、1024、2048、4096。Lite 最高 2048，Standard、Pro 最高 4096。
  • 32–256 适合像素画。即使是低分辨率，也能使用普通的图层、保存和 PNG 导出。256 及以下的纹理集，一开始就是按像素显示（详情）。
  • 只想在导出时改变大小，请使用导出窗口的“分辨率”（导出为 PNG）。
更改分辨率后，撤销（Ctrl+Z）的历史会全部清除。调低后，细节会变模糊。调高也不会增加细节。

操作不顺利时

  • 无法选择 4096：Lite 最高到 2048。Standard 及以上才能选择。
  • 出现“请在保存完成后再更改分辨率”：正在保存或自动保存。等完成后再重新选择。

替换底色图像、添加图像或 PSD

打开模型之后，也可以按纹理集替换底色图像，或导入图像、PSD。

  1. 在纹理集面板中，右键点击想放入文件的纹理集所在行（也可以用行右侧的“…”）。
  2. 从下表中选择项目，再选择文件。
项目说明
替换底色图像把底色图层的内容替换为所选图像（PNG、JPEG、WebP、BMP、GIF、TGA）。大小不同时，会按分辨率缩放。其他图层保持不变
将图像作为图层导入显示一个把所选图像放在该纹理集 UV 上的边框。按 Enter 会成为新图层。选择多张时，会逐张放置（贴图像）
导入 PSD（替换图层） Standard用 PSD 的图层替换该纹理集的图层（PSD）
加载 lilToon 材质（.mat） Pro把 .mat、.unitypackage 加载到该纹理集（加载 lilToon 材质）
  • 把图像、PSD、.mat 拖放到行上也能放入（放下的目标行会出现虚线边框）。只有一张图像时，会询问是“替换底色”还是“添加为图层”。
  • 没有选中的纹理集，也不必重新选择就能放入。所有这些操作都可以用撤销（Ctrl+Z）撤销。
  • 所选纹理集的底色，也可以通过 文件 → 导入 →“替换底色图像（所选纹理集）”来替换。

操作不顺利时

  • 出现“宽高比不同，已拉伸”：图像的宽高比与纹理不同。请使用正方形的图像。
  • 无法替换底色：底色图层被锁定，或者不存在。请解除锁定，或使用“将图像作为图层导入”。
  • 无法将图像添加为图层（Lite）：Lite 每个纹理集最多 4 个图层。请先合并或删除图层，再添加。

隐藏纹理集、按像素显示

可以按纹理集分别切换是否在 3D 中显示，以及像素的显示方式。

  • 用行左侧的勾选，切换是否在 3D 中显示该纹理集。也可以用行右键菜单的“仅显示此纹理集”“显示全部纹理集”。
  • 关闭显示的纹理集，纹理依然保留，会包含在全部纹理集的导出中。
  • 要按网格逐个隐藏时，请使用对象面板（详情）。

按像素显示纹理

在 3D 显示中，不对纹理插值，而是一个像素一个像素地以方块显示。适用于 32、64px 等低分辨率的纹理。

  1. 点击行的右键菜单（“…”）中的“按像素显示（不插值）”。
  2. 名称右侧会出现小方块标记。点击标记即可关闭。
  • 256px 及以下的纹理集，一开始就是开启的（自动）。自己手动开关过的纹理集，设置会保存在工程文件中。
  • 用“像素显示恢复为自动（256px 及以下时开启）”，可以把自己设定的开关恢复回去。
  • 一次切换所有纹理集时，用 显示 → 显示方式 →“所有纹理集按像素显示（不插值）”。
  • 这只是显示，绘制的内容和导出都不会改变。与像素笔一起使用，3D 中的像素也会显示为方块（绘制）。

隐藏对象、仅显示该对象

右侧的“对象”面板中，会列出模型的对象（头发、服装、饰物等网格）。可以这样使用：把整件衣服隐藏起来，绘制里面的身体。

  1. 在“对象”面板中，点击想隐藏的对象的眼睛按钮。它会从 3D 中消失。
  2. 想只显示某个对象时，按住 Alt 点击眼睛按钮或名称（再按一次 Alt+点击则全部显示）。
  3. 要恢复时，点击面板上方的“全部显示”，或按 Alt+H。
  • 如果有原始层级，会用缩进排列。每行有眼睛按钮、名称和所用纹理集的标签。
  • 点击名称，该对象会在 3D 中短暂高亮。点击标签，会选择该纹理集。
  • 行的右键菜单：仅显示此项、隐藏/显示、在 3D 中高亮、全部显示。3D 右键菜单中也有“隐藏此对象”“仅显示此对象”。
  • 隐藏的对象不会出现在 3D 中，点击也点不到，也不会被涂上。绘制背面和被遮挡的面、对称的另一侧、填充、渐变、图章也是如此。位于里面的东西可以直接看到并上色。
  • 纹理（图层）会保留。PNG、PSD、材质的导出也不会改变。
  • 隐藏期间，3D 下方的栏会显示“已隐藏 n 个对象”和“全部显示”。全部显示（Alt+H）会同时恢复显示范围和对象（显示范围）。
  • 隐藏状态会保存在工程文件中。隐藏、显示的操作不会进入撤销历史。
  • Pro 通过行右键菜单的“仅此对象使用另一个材质”“分配材质”，可以按对象拆分材质（拆分材质）。

显示预设

用面板下方的“保存当前状态”，可以把隐藏的对象整体命名并保存。Pro 中还会同时保存形态键的值。

  • 点击“调用”进入该状态（撤销一次即可恢复）。用“覆盖”改写为当前状态，在名称栏中改名，点击 × 删除。
  • 最多可保存 10 个，保存在工程文件中。混合形状面板中也会显示同样的列表。

节省 GPU 内存（卡顿时）

纹理会占用 GPU 的内存（VRAM）。4096 的纹理集或图层较多时会不够用，导致卡顿或无法绘制。PetaNuri3D 会让不使用的部分休眠，以腾出内存。

休眠的机制

  • 未选中的纹理集，外观保持不变，但会释放 GPU 内存而休眠。保持唤醒的只有主和副两个。
  • 选中休眠的纹理集后，2048 约 0.2 秒、4096 约 0.5–1.5 秒就能绘制。在面板中点击休眠的 4096 纹理集时，会显示“正在准备…”。
  • 保存、PNG/PSD 导出、AO、对所有纹理集应用的滤镜，对休眠的纹理集也照常生效。
  • 暂时没动过的图层，在不绘制期间也会被压缩保存（文件 → 偏好设置 → 绘制 → 性能 中的“让未绘制的图层休眠”。默认开启）。外观、导出、保存都不会变（图层休眠）。
  • 当前的用量，可通过纹理集面板上方的“GPU 内存估算”和每行的数字得知。

卡顿、无法绘制时

  1. 在纹理集面板上方查看 GPU 内存估算。GPU 内存的大致要求是：以 2048 绘制需要 4GB 以上，4096 需要 8GB 以上（运行环境）。
  2. 关闭游戏、浏览器、视频等使用 GPU 的其他应用。
  3. 降低不需要那么精细的纹理集的分辨率（更改分辨率）。
  4. 不跨集绘制时，移除副集让它休眠（移除副集）。
  5. 如果关闭了“让未绘制的图层休眠”，请开启。
  • 出现“显示处理已停止”：GPU 的显示处理被重置，已绘制的内容无法显示。从睡眠恢复或内存不足时会发生。此状态下无法绘制，也不会保存。请用窗口中的“从自动保存打开”或“重新打开工程文件”重新打开（之前的工程文件和自动保存不会丢失）。
  • 出现“显示处理已停止，无法导出”：与上一条相同。重新打开后再导出。
  • 每次选择纹理集都要等待：这是在唤醒休眠的纹理集。把经常来回切换的两个设为主和副，就不用等了。

无对应材质的纹理集（! 标记）

当前模型中不存在的材质所对应的纹理集，不会被删除，而是加上 ! 保留下来。可以把已绘制的图层移到其他纹理集。

出现这种情况，一是重新加载模型时，二是用名称不一致的模型，打开未包含模型（FBX）而保存的工程文件时。

  1. 在纹理集面板中，点击带 ! 的纹理集。会弹出“模型中没有的纹理集：〇〇”窗口。
  2. 在“要移动的图层”中选择图层（默认全选。也有“全选”和“全部取消”）。
  3. 在“目标”中选择纹理集（名称相近的纹理集会默认选中）。
  4. 点击“移动”。图层会按相同的顺序放入目标图层的最上方。
  • 文件夹、蒙版、剪贴、混合模式会原样移动。分辨率不同时，会缩放到目标的大小。UV 位置保持不变。
  • 勾选“在原纹理集中也保留（仅复制）”后，只复制，原纹理集中也会保留。
  • 没有图层的纹理集会消失。也可以用窗口中的“删除此纹理集”，连同已绘制的图层一起删除。这些操作都可以撤销。
  • 行的右键菜单中也有“将图层移到其他纹理集”“删除此纹理集”。
带 ! 的纹理集不会显示在 3D 中，也无法绘制。也不包含在全部纹理集的导出和 AO 中。需要仅此纹理集的图像时，可以用行右键菜单的“导出 PNG（不向 UV 岛外扩展）”或“导出为 PSD”Standard 导出。
