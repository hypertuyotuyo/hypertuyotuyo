图章、图案、凹凸、2D 画布

用于装饰、图案和缝线等重复性绘制的工具。绘制前都可在 3D 上预览落笔效果。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

本页内容
  • 装饰
  • 图章
  • 图案笔（服装图案）
  • 凹凸（缝线、褶皱）
  • 印章专用 2D 画布
  • 无需模型的 2D 绘画

装饰

  • 在划过的位置散布闪光、星星、心形、花、樱花、音符、雪花、圆点、泡泡、新月、菱形、四叶草和水滴。大小和方向会略有变化。
  • 使用前景色绘制。悬停在 3D 或 UV 上时会显示笔尖形状。

图章

  • 在工具属性“导入图像”添加 PNG 等图片，从列表选中后点击 3D 模型即可贴图。拖动时会按间隔连续贴图。
  • 工具属性顶部依次显示当前图片的大预览、列表、大小、角度。
  • 悬停在 3D 或 UV 上时，以实际大小、角度、颜色和不透明度半透明显示将贴入的图片（绘制前预览，不写入纹理）。移动方向前方还会淡淡显示下一张图片。
  • 按图片原色贴图（透明区域不绘制）。开启“用前景色绘制”时，仅使用图片形状，颜色为前景色。
  • 可调整大小、不透明度、间隔、角度、随机旋转、大小变化、散布、沿笔画方向旋转、笔压控制大小。导入图片会在下次启动时保留（最多60张）。
  • 左右对称在 3D 和 UV 区域均有效（镜像侧图片方向也会镜像）。

图案笔（服装图案）

  • 15 种图案：竖条纹、横条纹、斜条纹、圆点、小圆点、棋盘格、方格、苏格兰格、菱形格、人字纹、牛仔（斜纹）、针织、心形、星星、交叉线。
  • 仅以该图案形状绘制前景色的笔。图案在纹理上重复，不随视角移动（UV 扭曲处，图案也会扭曲）。
  • 工具属性顶部显示图案预览列表、“纹理大小”“图案强度”、反转明暗、应用方式。
  • 悬停在 3D 或 UV 上时，会在画笔圆内按实际大小半透明预览图案。调整“纹理大小”时，最后悬停位置会显示较大的圆形预览。
  • 相同图案也可从其他钢笔、毛笔的“纸张纹理”→“纹理”选择。
纹理角度（所有版本）：可用工具属性中的“纹理角度”旋转图案笔和纸张质感的图案（岛倒置或横置时也能对齐图案方向）。

凹凸（缝线、褶皱） Pro

  • 9 种：缝线（虚线、凹陷）、缝线（饱满）、接缝（沟槽）、滚边（隆起）、十字绣、锯齿缝线、铆钉、褶皱、凸起。
  • 绘制时会转入图层面板“法线贴图”文件夹（没有时会创建），以指定高度绘制。不会把黑色缝线写进颜色图层。高度可在工具属性调整。
  • 绘制完成后，点击 3D 视图上方中央“◀ 返回原图层”，恢复之前的图层、显示和工具。
  • 凹凸在最终效果显示中可见（不明显时，请提高“材质”面板的法线贴图强度）。导出时会输出法线贴图图片（绘制目标）。

印章专用 2D 画布

点击图章工具属性的“在 2D 画布中绘制”，打开图章专用工作纹理集。3D 视图会隐藏，在 UV 视图中编辑正方形画布。

  1. 可用钢笔、橡皮擦、填充、渐变等绘制。支持普通图层、文件夹、选区、撤销与重做。
  2. 在下方选择正方形分辨率（256〜4096。Lite 最高 2048）。
  3. “注册为图章”并输入名称。可见图层的合成效果会直接成为图章。返回模型编辑后，即可用该图章绘制。
  4. 不注册就返回时，点击“返回模型编辑”。已绘制的图层会与 .petanuri 工程文件一起保存。
  • 纹理集面板会提示正在编辑图章画布。它与模型的主、副纹理集分开处理。
  • 此工作纹理集不混入模型纹理集列表，也不会导出为模型纹理。
  • 可使用图章的“重新绘制此图像”，或列表右键 →“在 2D 画布中重新绘制”，编辑已注册图章。再次注册时可选择覆盖或另存名称。

无需模型的 2D 绘画

点击启动界面“用示例试试”下方的“开始 2D 绘画”并选择分辨率。这是无需 3D 模型、在透明底色正方形画布上绘制的附加模式，不从“新建”的模型设置中选择。

  • 在图层中绘制，可保存为 .petanuri 并再次打开继续工作。
  • 点击画布下方“导出 PNG”，可保存可见图层的合成图片。
  • 也可使用“注册为图章”。此模式注册后仍可继续 2D 绘画。
  • Lite 最高分辨率2048、最多4个图层（含底色）；Standard 和 Pro 最高分辨率4096。
依赖 3D 模型形状的烘焙、姿势、材质等功能不用于 2D 绘画。
