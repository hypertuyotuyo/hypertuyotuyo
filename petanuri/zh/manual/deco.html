图章、图案、缝线与 2D 画布

这些工具用于装饰、图像、服装图案、针脚等需要大量重复绘制的内容。把画好的内容做成图章的 2D 画布，以及不使用模型的 2D 绘画，也一并在这里介绍。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

先看这几点
  1. 要散布装饰，请在工具栏中选择“装饰”，选好闪光等样式后拖动绘制（详细说明）。
  2. 要贴图像，请在“图章”中点击“导入图像”添加 PNG，然后在 3D 视图上点击（详细说明）。
  3. 服装图案选择“图案”，针脚选择“缝线”，用前景色拖动绘制（图案、缝线）。
  4. 要把自己画的内容做成图章，请在图章的“在 2D 画布中绘制”里绘制，再点击“注册为图章”（详细说明）。
  5. 不使用模型绘制时，请从启动界面的“开始 2D 绘画”进入（详细说明）。

散布装饰（装饰）

在拖动经过的位置，用前景色散布小装饰。大小和方向会略有随机变化。

  1. 点击工具栏中的“装饰”。
  2. 在辅助工具中选择装饰。
  3. 选择前景色，在 3D 视图上拖动。
  • 装饰有闪光、星形、心形、花、樱花、音符、雪花、波点、泡泡、月牙、菱形、四叶草、水滴，以及 4 种蕾丝。
  • 将光标悬停在 3D 或 UV 视图上时，会显示笔尖的形状。
  • 与钢笔相同，大小、散布、随机旋转等可在工具属性中更改（设定绘制手感）。
  • “也绘制背面和被遮挡的面”默认关闭。左右对称绘制同样有效。

绘制蕾丝

“蕾丝（扇贝边）”“蕾丝（狗牙边）”“蕾丝（小花）”“蕾丝（网眼）”会让图案沿着线条排成带状。即使是曲线或尖锐的转角，在 3D 上也能连续。

  • 镂空处是透明的，用前景色绘制。线条的粗细就是图案的大小。
  • 选作图形工具的笔尖后，可以沿矩形或椭圆的轮廓绘制蕾丝（图形）。

贴上图像（图章）

把导入的图像贴到 3D 模型上。可用于标志、徽章、图案素材等。

  1. 点击工具栏中的“图章”。
  2. 用工具属性中的“导入图像”添加 PNG、JPEG 等图像（数量不限）。
  3. 在列表中选择图像。
  4. 在 3D 视图上点击，会贴上 1 个该图像。拖动则按间距连续贴上。
  • 悬停在 3D 或 UV 视图上时，将要贴上的图像会按当前的大小、角度、颜色和不透明度半透明地显示出来。这只是绘制前的预览，不会写入纹理。
  • 沿着移动的方向，下一个放置位置也会淡淡地显示出来。关闭“淡淡显示下一个放置位置”后，只显示当前位置的预览。
  • 图像按原色贴上（透明部分不会贴）。开启“用前景色绘制”后，只使用图像的形状，并用前景色绘制。
  • 辅助工具“图章（散布）”会让方向和位置随机变化并散布图像。
  • 只会贴在可见的面上，一笔对应一步撤销。在 UV 视图上也能贴。
  • 左右对称在 3D 和 UV 视图中都有效。对侧的图像也会呈镜像方向。

图章设置

工具属性的最上方依次是当前图像的大预览、图像列表、大小和角度。

项目内容
大小图像较长一边的长度
不透明度贴上时的浓度
间距拖动连续贴图时的间隔
角度、随机旋转图像的方向及其随机变化
大小随机、散布大小与位置的随机变化
沿线条方向旋转按拖动的方向旋转图像
笔压控制大小根据笔压改变大小
用前景色绘制（仅使用图像的形状）用前景色填涂图像的形状
淡淡显示下一个放置位置显示下一次贴图位置的预览（默认开启）
  • 导入的图像在下次启动后仍会保留（最多 60 张）。点击“移除此图像”可将其从列表中移除。
  • 自己画的内容也可以做成图章（2D 画布）。

操作不顺利时

  • 点击后什么也没贴上：没有选中图像。请用“导入图像”添加图像，再从列表中选择。请在模型可见的面上点击。
  • 连图像周围的白色方块也被贴上了：图像没有透明部分。请使用背景透明的 PNG。
  • 贴上的效果与预览略有不同：随机旋转、散布和随机变化不会反映在预览中。

绘制服装图案（图案）

这支钢笔用前景色只绘制图案的部分。图案在纹理上重复排列，所以移动视角也不会错位。

  1. 点击工具栏中的“图案”。
  2. 在辅助工具中，或在工具属性最上方的预览列表中选择图案。
  3. 选择前景色，在衣服上拖动绘制。
  • 图案共 15 种：竖条纹、横条纹、斜条纹、波点、小波点、棋盘格、维希格、苏格兰格、菱格纹、人字纹、牛仔布（斜纹）、针织、心形、星形、交叉线。
  • 悬停在 3D 或 UV 视图上时，画笔圆圈内会以前景色半透明地显示将要绘制的图案。
  • 通过“加载图案图像”，可以把喜欢的图像用作图案（越亮的地方越容易上色）。
  • 同样的图案也可以在其他钢笔、毛笔的“纸张纹理”中选择（纸张纹理）。

图案的大小、方向与浓度

项目内容
纹理大小单个图案的大小（%）。拖动调整时，会在最后悬停的位置以较大的圆显示预览
纹理角度旋转图案的角度（°）
图案强度图案的浓度
反转明暗互换绘制与不绘制的部分
应用方式“相乘（越亮处越容易上色）”或“相减（从暗处开始留空）”

操作不顺利时

  • 图案上下颠倒或横向了：因为 UV 岛本身是上下颠倒或横向的。请先用“纹理角度”调整方向，再绘制。
  • 图案变形：在 UV 扭曲的地方，图案也会随之变形。

描绘针脚（缝线）

绘制针脚这类沿线条重复排列的装饰。针脚会随线条的方向旋转。

  1. 点击工具栏中的“缝线”。
  2. 在辅助工具中选择针脚的种类。
  3. 选择前景色，在想加针脚的位置拖动。
辅助工具绘制内容
缝线（虚线）、针脚（饱满）、接缝、滚边、十字绣、之字形缝线、铆钉用前景色在当前图层中绘制针脚。在 2D 画布中也能使用
褶皱（柔和沟槽）、鼓起（柔和凸起） Pro以高度在法线贴图文件夹中绘制凹凸
  • 大小基准固定为“按屏幕可变”。
  • 在图形工具的笔尖中选择缝线后，可以沿矩形或曲线的轮廓排列针脚（图形）。

将针脚做成凹凸（法线贴图） Pro

  1. 开启工具属性中的“在法线贴图文件夹中绘制”。
  2. 用“高度（0 凹陷、50 平坦、100 凸起）”决定高度（仅在开启时显示）。
  3. 拖动绘制。会切换到图层面板的“法线贴图”文件夹（没有则新建）中，并按高度绘制。
  4. 绘制完成后，点击 3D 视图上方中间的“◀ 返回原图层”。图层、显示和工具都会恢复到切换之前的状态。
  • 褶皱和鼓起总是以高度绘制在法线贴图文件夹中。
  • 凹凸在“最终效果”显示中可以看到。看不清时，请调高材质面板中的“法线贴图强度”。
  • 导出后会成为法线贴图图像（绘制目标）。

把画好的内容做成图章（2D 画布）

在图章专用的方形画布上，可以用平时的工具和图层绘制，并直接注册为图章。

  1. 点击工具栏中的“图章”。
  2. 点击工具属性中的“在 2D 画布中绘制”。3D 视图会隐藏，方形画布会显示在 UV 视图中。
  3. 用钢笔、橡皮擦、填充、渐变等进行绘制。
  4. 点击下方的“注册为图章”，并输入名称。当前显示的各图层合并后的外观，会直接成为图章。
  5. 返回模型编辑，即可用该图章绘制。
  • 图层、文件夹、蒙版、选区和撤销都与平时一样可用。各版本的上限（Lite 最多 4 个图层）也相同。
  • 画布的分辨率在下方栏中选择（32–4096。Lite 最高 2048）。
  • 不注册直接返回时，点击“返回模型编辑”。已画的内容会保留。
  • 要修改已注册的图章，请点击图章工具属性中的“重新绘制此图像”，或右键点击列表中的图像 →“在 2D 画布中重新绘制”。重新注册时，选择“覆盖”或“以其他名称注册”。
  • 在列表中右键 →“在 2D 画布中新建绘制”也可以打开。
  • 画布的图层会与工程文件（.petanuri）和自动保存一起保存。
纹理集面板中会显示正在编辑 2D 画布。该画布不会出现在模型的纹理集列表中，也不会包含在 PNG、PSD 的导出中。

不使用模型，在 2D 中绘制（2D 绘画）

不打开 3D 模型，直接在方形画布上绘制的模式。从透明的底色开始，可以用平时的工具和图层绘制。

  1. 点击启动界面的“开始 2D 绘画”（位于“用示例试试”下方）。
  2. 在“新建 2D 绘画”窗口中选择画布大小（32 × 32 至 4096 × 4096）。
  3. 用钢笔、毛笔、渐变等进行绘制。
  4. 点击下方的“导出 PNG”，会把显示中各图层合并后的图像保存为带透明通道的 PNG。
  • 保存为工程文件（.petanuri）后，仍会以 2D 绘画的形式保留图层，可以继续绘制。
  • “注册为图章”也可以使用。注册之后，也能继续 2D 绘画。
  • Standard 通过 文件 → 导出 →“导出 PSD（所选纹理集）”，可以保留图层和文件夹导出为 PSD。
  • Lite 的分辨率最高 2048，包括底色在内最多 4 个图层。Standard 和 Pro 最高 4096，图层数量没有上限。
不会显示 3D 视图，也没有依赖模型形状的功能（烘焙、姿势、材质等）。
