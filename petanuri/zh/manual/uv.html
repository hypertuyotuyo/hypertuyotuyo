UV 区域与显示范围

在 3D 视图旁显示 UV（纹理展开图），两侧均可绘制。绘制服装下方身体或头发内侧时，通过显示范围隐藏前方部分。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

Lite、Standard、Pro 和 Pro 升级包均已在 BOOTH 提供。

显示 UV 区域

  • UV 有3种显示方式：仅3D、3D与UV并排、仅UV。仅3D时，点击视图右侧“UV”（U或 显示 → UV）可并排。拖边界可调整宽度。
  • 并排时，点击 UV 右上 × 隐藏 UV（仅3D），点击 3D 右上 × 隐藏3D（仅UV）。Shift＋U 可切换仅UV⇔并排。下次保留最后显示方式。
  • 显示当前纹理集 UV（左上名称），切换纹理集后同步更换。
  • UV 区域可使用钢笔、毛笔、橡皮擦、面填充、填充、封闭区域填充、渐变、图形、图章、吸管、模糊、涂抹。
  • 在 UV 区域操作时，3D 视图中画笔圆影响的面会显示红色高亮。在 3D 操作时，UV 区域显示红点指示绘制位置。
  • 滚轮缩放，中键拖动或Space＋拖动平移，UV 指引中的方块显示全部。“线”显示 UV 线，“UV 岛边缘”显示岛轮廓（▼ 设置颜色和浓度）。
  • UV 指引下排的 ⟲、⟳ 每次旋转15°（旋转后也可绘制）。
  • 标题“对称 X、Y、Z”与 3D 左上同步（左右对称绘制）。
  • UV 区域较窄时，标题放不下的按钮会收进“⋯”面板。
绘制范围（所有版本）：在 UV 区域左下选择“UV 内”“边距内”“全部”。UV 内与以前相同只涂岛内，边距内包括岛及其外侧的边距带，全部则可涂到纹理任意位置。除画笔、毛笔和橡皮外，图形、填充、渐变、图章、模糊和涂抹也遵循此范围（在 3D 视图中绘制时保持不变）。
左下的边距（0～128px 或全部）与导出时的边距相同。标题栏的“边距线”可显示距离岛边缘该宽度的外侧线。滤镜 → 在新图层上生成边距，可将岛边缘颜色向外扩展的部分单独生成到新图层（所有版本）。
3D／UV 小窗口（所有版本）：3D 与 UV 并排时，用右上 × 下方的按钮将该视图放入小窗口（另一方铺满）。UV 标题 ⋯ 中的“UV 放入小窗口（3D 全屏）”“3D 放入小窗口（UV 全屏）”效果相同。
小窗口可放在应用窗口内的任意位置，也可放在面板上方。拖动标题移动，拖动四边或四角调整大小。⇄ 交换，▣ 恢复并排显示，✕ 关闭小窗口一方。右上的锁可固定（再按一次解除）。缩小时，UV 会折叠绘制范围栏并缩小指引，3D 会缩小导航。
3D 中也绘制到岛外的填充区（所有版本）：在笔、毛笔、橡皮的工具属性中开启后，在 3D 中画完时会将线条按边距宽度扩展到 UV 岛外（不会进入相邻岛；撤销一次连同线条一起还原）。宽度“填充宽度（px）”与 UV 区域左下及导出边距共用。
从 UV 边缘绘制（Pro）：滤镜 →“从 UV 边缘绘制（新图层）”可按距 UV 岛边缘的距离，在新图层上用前景色生成线条或渐变。设置形状（线条、渐变）、方向（岛内侧、岛外侧、两侧）和距离（纹理 px）。有选区时只作用于选区内。

网格线与吸附

  • UV 标题“网格”可显示、隐藏格线。旁边 ▼ 设置格数（将纹理边长分为2、4、8、16、32、64、128）和吸附，也显示每格 px 数。
  • 线条仅用于显示，不写入绘制内容、保存或导出。
  • “移动/变换时吸附到网格”（默认开启，仅显示网格时生效）：在 UV 区域移动移动/变换工具、变换（Ctrl＋T）或贴 UV 图片的框时，四角或中心接近网格线会吸附。角边手柄、自由变换角点、扭曲网格点也吸附。
  • Ctrl 按住期间不吸附。3D 区域操作框不吸附。

UV 导航（缩放、移动）

UV 区域右上有与 3D 导航相似的导航控件，仅用数位笔即可操作。

  • 放大镜上下拖动缩放（向上放大）。抓手拖动平移。方形显示全部。
  • 拖上方手柄可自由移动，左侧、底边和左下角可调整大小。
  • “—”可收成小圆形图标，点击恢复（也可 显示 → UV → UV 导航）。
旋转（所有版本）：用指引下排的 ⟲、角度、⟳ 旋转（⟲、⟳ 每次 15°，点击角度恢复 0°，Shift＋滚轮每次 5°）。任意角度可左右拖动指引的旋转按钮（双击恢复 0°），或按住 Space＋Shift 拖动区域。
预设倍率（所有版本）：按 Ctrl＋1·2·3 将 UV 区域（打开 2D 画布时为画布）设为预设倍率（默认 100%、200%、50%；100% 即纹理 1 像素对应屏幕 1 px）。可在文件 → 偏好设置 → 操作的“预设倍率（UV·2D）”中更改。

超出 UV 岛时（跨接缝绘制）

  • 在 UV 区域绘制时，即使画笔圆超出 UV 岛，也不会绘制仅在 UV 上相邻的其他岛（3D 中相距较远）。
  • 标题中的“跨接缝绘制”（默认开启）：超出 UV 岛边缘的部分会沿 3D 接缝延续到对面连接的面，接缝处不断开。关闭则仅绘制当前 UV 岛（右键菜单、显示 → UV 也有相同开关）。
  • 绘制范围为“UV 内”时，UV 岛外（未被任何面使用的区域），画笔圆显示为淡虚线和 ×。从岛外开始的笔画在进入岛后生效。文字、图形、图章、渐变也可从岛外放置。

显示范围（仅显示选中部分、隐藏）

  1. 在 UV 或 3D 选择 UV 岛、面（按岛选择、按面选择、套索、顶点组等）。
  2. 使用 3D 左上显示范围图标、Shift＋H或 UV 标题“仅显示所选部分”，仅在 3D 显示选中区域。
  3. H（UV 标题“隐藏所选部分”）则隐藏选区。可多次叠加隐藏。
  4. Alt＋H 恢复显示全部。
  • “仅显示所选部分”后，改变选区会自动更新显示，无需再次点击（再次点击恢复显示全部）。
  • 隐藏后会取消选区，可直接绘制可见部分。原选区可通过 3D 下方［恢复选区］或 Ctrl＋Shift＋D 可撤销。
  • 3D 右键“隐藏此 UV 岛”“仅显示此 UV 岛”可直接隐藏或显示点击的岛（不改变选区和撤销历史）。
  • 显示范围图标 ▼：左侧“从选区”（仅显示选中部分、隐藏选中部分、也显示选中部分、隐藏笔）与“隐藏部分”（反转、显示全部、扩展／收缩、半透明显示），右侧“隐藏预设”（已保存列表）。未隐藏任何内容时从此操作。
隐藏部分不阻挡深度，可以绘制服装下面或头发内部的表面。无法直接在隐藏部分绘制，也无法用吸管或填充选取。启用隐藏面对称绘制后，3D绘制也可作用于隐藏的对称侧，还可隐藏整个对象（网格）（显示、隐藏对象）。
隐藏、显示操作不计入撤销（Ctrl＋Z）历史。恢复时显示全部或调用已保存隐藏预设。

隐藏笔、3D 下方工具条

绘制重叠布料后方等位置时，可直接隐藏划过部分。

  1. 选择左侧工具栏“隐藏笔”（也可用 3D 下方［隐藏笔］切换）。
  2. 辅助工具选择“按面隐藏”（四边面的2个三角形一起处理）或“按 UV 岛隐藏”（按整个 UV 岛）。
  3. 在 3D 划过的位置会隐藏，也可在 UV 区域点击隐藏。
  4. 再次点击［隐藏笔］恢复之前工具。
一次划过不会继续隐藏前方消失后新露出的后方面。要隐藏后方，请再划一次。

3D 下方中央工具条仅在存在隐藏部分或使用隐藏笔时显示。含［隐藏笔］［面｜岛］［隐藏预设 ▼］、当前状态（“隐藏预设：〇〇”“部分已隐藏（未保存的隐藏状态）”“仅显示所选部分”）及［显示全部］。

淡化显示周围

  • 存在隐藏部分时，用 3D 下方［半透明显示周围］显示已隐藏内容，方便参照周围绘制。
  • 旁边滑块调整浓度（5〜80%）。▼ 窗口“隐藏部分”中的“半透明显示”效果相同。
半透明显示的隐藏部分不能直接绘制。启用隐藏面对称绘制后，在3D绘制另一侧时也会作用于隐藏侧。

保存隐藏预设

为常用隐藏方式命名保存，可随时恢复相同显示。

  1. 隐藏需要隐藏的部分。
  2. 3D 下方［隐藏预设 ▼］（或显示范围 ▼ 窗口）→“保存当前隐藏预设”，输入名称（同名覆盖）。
  3. 在同一列表点击名称即可恢复该隐藏方式。
  • “管理隐藏预设（名称、删除）”可更名和删除。
  • 已保存隐藏预设与当前隐藏状态会存入工程文件（.petanuri），重新打开也可使用。

网格线、接缝线

  • 3D 左上图标（显示 → 线与尺子 → 网格线／接缝线）可显示多边形线和 UV 接缝、岛边缘。接缝线也可用 Alt＋W 切换。
  • 图标下 ▼ 可选择浓度、颜色（蓝、黑、白）、是否显示背面或后方线。
