UV 区域与显示范围

在 3D 视图旁并排显示 UV（纹理展开图），从哪一边都能绘制。衣服下的身体、头发内侧这类位于里面的面，用显示范围把前面的部分隐藏起来再绘制。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

先看这几点
  1. 按 U 在 3D 旁并排显示 UV。直接在 UV 上也能绘制（详情）。
  2. 用 UV 区域左下角的“绘制范围”，选择只在 UV 岛内绘制，还是绘制到外侧的边距（详情）。
  3. 绘制里面的部分时，选中 UV 岛或面，按 Shift+H（仅显示所选部分）或 H（隐藏所选部分）。按 Alt+H 恢复全部显示（详情）。
  4. 重叠的布料可以用“隐藏笔”划过来隐藏（详情）。
  5. UV 接缝的位置，可以用 Alt+W（接缝线）显示在 3D 上（详情）。

显示 UV 并直接绘制

在 UV 区域，可以直接在纹理的展开图上绘制。适用于 3D 中难以触及的位置，或想画直线的地方。

  1. 按 U（也可以用 3D 视图右端的“UV”，或 显示 → UV → UV（与 3D 并排））。3D 旁边会出现 UV 区域。
  2. 拖动交界处，调整宽度。
  3. 在 UV 区域中，像在 3D 里一样绘制。
  • 显示的是所选纹理集的 UV（左上角有名称）。重新选择纹理集后会切换（选择纹理集）。
  • 可用的工具：钢笔、毛笔、橡皮擦、多边形填充、填充、填充封闭区域、渐变、图形、图章、吸管、模糊、涂抹。
  • 操作 UV 区域期间，3D 视图中进入画笔圆圈的面会发红光。操作 3D 期间，UV 区域会用红点显示绘制位置。
  • 标题栏的“对称 X、Y、Z”与 3D 左上角的是同一个开关。在 UV 上绘制时，也会绘制到 3D 中沿相同轴对称折返的位置（左右对称绘制）。
  • 右下角会小小地显示副纹理集的 UV。点击后副变为主。用 ✕ 隐藏，用“显示副纹理集”恢复（主与副）。

把其中一边设为小窗口并排显示时，点击右上角 ✕ 下方的按钮。也可以用 显示 → UV →“UV 放入小窗口（3D 全屏）”“3D 放入小窗口（UV 全屏）”
  • 最后一次的显示方式，下次打开时仍然保持。
  • 小窗口只要在应用窗口内，也可以放在面板上方。拖动标题栏移动，拖动四边、四角改变大小。

  • 即使按 Tab 隐藏面板，小窗口也会保留。2D 画布不能设为小窗口。

显示 UV 线、UV 岛边缘、边距线

  • 用标题栏的“UV 线”显示 UV 的线，“岛边缘”显示 UV 岛的轮廓，“边距线”显示从 UV 岛边缘向外一个边距宽度的线，可分别切换显示和隐藏（边距）。
  • 用旁边的 ▼ 可以更改 3 种线的颜色和浓度（5–100%）。点击“恢复默认颜色”即可恢复。
  • UV 区域的右键菜单中也有同样的开关。
  • 想把 UV 的线做成图像，在其他软件中用作底稿时，用“将 UV 贴图导出为 PNG”（详情）。

按高度查看法线贴图文件夹

Pro 绘制目标为法线贴图时，UV 区域平时以法线贴图的颜色显示。开启 3D 右键 → 显示 →“以高度（灰色）显示法线贴图文件夹（UV）”后，会以灰色按绘制的高度显示。白色是凸起，黑色是凹陷处（绘制目标）。

操作不顺利时

  • 找不到标题栏的按钮：UV 区域较窄时，放不下的按钮会收进“⋯”。点击“⋯”即可显示。
  • 不显示 UV：打开 3D 模型后才能显示。请先打开模型。
  • 有画不上的地方：UV 被贴在一个点上的面、超出 0–1 范围的面、重叠超过 4 层的地方，无法绘制。打开时会在右下角提示。
  • UV 岛放在 0–1 范围之外：会映射到纹理重复后颜色相同的 0–1 范围内的位置来绘制。不会更改模型文件。

操作 UV 的显示（缩放、移动、旋转）

UV 区域用鼠标或只用数位笔都能操作。右上角的导航与 3D 导航形状相同。

UV 网格线与吸附

显示网格，用来对齐图案或贴章的位置。移动边框时，会吸附到网格线上。

  1. 点击 UV 区域标题栏的“网格”。网格会显示出来。
  2. 在旁边的 ▼ 中选择“格数”。把纹理的一边分成 2、4、8、16、32、64、128 份。
  3. 移动、变换的边框时，边框的 4 个角或中心，会吸附到附近的网格线上。
  • 每格多少 px 会显示在 ▼ 中（2048px 分成 16 份是 128px）。
  • 线只是显示，不会进入所绘图像、保存和导出。拉近时线也不会变粗。
  • “移动/变换时吸附到网格”默认就是开启的。只在显示网格时生效。
  • 吸附的对象是移动·变形工具、变换（Ctrl+T）、将图像贴到 UV 时的边框。角、边的控制柄，自由变换的角，变形的点也会吸附（变换）。
  • 按住 Ctrl 期间不会吸附。3D 区域上的边框也不吸附。
  • 也可以通过 显示 → UV →“UV 网格”来显示。还可以为吸附的开关分配按键（快捷键）。

绘制范围与边距（绘制到 UV 岛外）

在 UV 岛的外侧稍微扩展一点边缘的颜色，游戏中接缝处就不容易出现线条。这条扩展出来的带状区域称为边距。在 UV 区域的左下角，可以选择绘制到哪里为止。

  1. 在 UV 区域左下角的“绘制范围”中，点击“UV 内”“边距内”“全图”之一。
  2. 选“边距内”时，用下方的控制柄设定边距的宽度（0–128px）。
  3. 在 UV 区域中绘制。
绘制范围可绘制的位置
UV 内（默认）仅 UV 岛内。可使用“跨接缝绘制”（详情）
边距内UV 岛及其外侧的边距带之内。钢笔、图形等会溢出到相邻的 UV 岛
全图纹理的任何位置。会溢出到 UV 岛外和相邻的 UV 岛
  • 除了钢笔、毛笔、橡皮擦、多边形填充，图形、填充、渐变、图章、模糊、涂抹也遵循这个范围。在 3D 视图中绘制时不受影响。
  • “边距内”“全图”下的填充，会把涂的部分扩展到 UV 岛外。
  • 边距的值与导出扩边相同（“与导出共用”）。在任一处更改，两边都会改变。“全部”就是导出窗口中的“填满 UV 岛外的全部区域”（导出扩边）。
  • 左下角的栏可以用 ▼ 折小。即使折小，绘制范围和跨接缝绘制仍可使用。

在 3D 中画的线也扩展到边距

在钢笔、毛笔、橡皮擦的工具属性中开启“3D 中也绘制到岛外的填充区”。在 3D 中画完后，会把线向 UV 岛外扩展一个边距的宽度。

  • 不会进入相邻的 UV 岛。撤销一次，连线一起撤销。
  • 宽度是工具属性中的“填充宽度（px）”。与 UV 区域左下角、导出扩边的值相同。
  • 关闭时，只会从 UV 岛边缘稍微扩展一点。

创建仅含边距的图层

用 滤镜 →“在新图层上生成边距”，可以把当前图像（所有图层叠加后的颜色）的边缘颜色向 UV 岛外扩展出的部分，单独做成一个新图层。UV 岛内是透明的，图层会放在所选图层的正上方。

笔刷边缘的淡薄处不视为已绘制的地方，而是把不透明处的颜色扩展到 UV 岛外。UV 岛外的像素，取直线距离最近的 UV 岛像素的颜色，所以从斜边也能平滑地扩展。

超出 UV 岛时（跨接缝绘制）

有些地方在 UV 上是分开的，但在 3D 中是相连的。可以把从接缝溢出的部分，接着绘制到 3D 中相连的面上。

  • 在 UV 区域绘制时，即使圆圈溢出到 UV 岛外，也不会涂到只是在 UV 上相邻、而在 3D 中分开的其他 UV 岛。
  • 左下角的“跨接缝绘制”（默认开启）：从 UV 岛边缘接缝溢出的部分，会接着绘制到 3D 中与该接缝另一侧相连的面上。线条在接缝处不会断开。
  • 关闭后，只在正在绘制的 UV 岛内绘制。右键的“UV 岛外继续绘制到 3D 上相连的相邻部分”、显示 → UV 中也有同样的开关。
  • 跨接缝绘制仅在绘制范围为“UV 内”时可用。

从 UV 岛外开始绘制时

  • 绘制范围为“UV 内”时，在没有被任何面使用的地方，画笔的圆圈会变成淡淡的虚线并带有 ×。钢笔、毛笔、橡皮擦、多边形填充无法绘制。
  • 从 UV 岛外开始绘制的线，从进入 UV 岛的地方开始上色。
  • 文字、图形、图章、渐变，即使从 UV 岛外也能放置（上色的只有 UV 岛内）。

操作不顺利时

  • 出现“此图层无法跨接缝绘制”：剪贴图层（及其蒙版）是配合下方图层的形状来绘制的，所以不会延伸到接缝的另一侧。
  • “跨接缝绘制”无法点击：请把绘制范围设为“UV 内”。

显示范围（仅显示所选部分、隐藏）

衣服下的身体和头发内侧，会被前面的面挡住而画不了。用显示范围隐藏前面的部分，里面的面就能直接看到并绘制。

  1. 在 UV 区域或 3D 中，选择 UV 岛或面（用选区的“按 UV 岛选择”“按面选择”、套索、顶点组等）。
  2. 按 Shift+H（也可以用 3D 视图左上角的显示范围图标，或 UV 标题栏的“仅显示所选部分”）。3D 中只会显示所选部分。
  3. 只想隐藏前面的部分时，按 H（“隐藏所选部分”）。可以反复追加隐藏。
  4. 绘制完后，按 Alt+H 恢复全部显示。
操作说明
仅显示所选部分（Shift+H）只显示所选的 UV 岛、面。开着的状态下重新选择，不必再按一次，显示就会改变。再按一次则全部显示
隐藏所选部分（H）隐藏所选的 UV 岛、面。隐藏后选区会被取消，所以可以直接在可见处绘制
同时显示所选部分把已隐藏的部分中所选的部分恢复为可见
反转显示范围互换可见的部分和隐藏的部分
扩大、缩小把可见的部分，在 UV 上按设定的 px（1–64）扩大、缩小
全部显示（Alt+H）把隐藏的部分和隐藏的对象全部恢复显示
  • 这些都在 显示 → 显示范围，以及 3D、UV 右键菜单的“显示范围”中。
  • 被取消的选区，可用 3D 下方栏的［重新选择］或 Ctrl+Shift+D 恢复。
  • 隐藏的部分在 UV 区域会出现斜线。隐藏期间，“全部显示”会变成醒目的颜色。
  • 也可以按对象（网格）隐藏（显示、隐藏对象）。

仅隐藏、显示点击的 UV 岛（右键）

  • 3D 右键的“隐藏此 UV 岛”“仅显示此 UV 岛”，会直接隐藏、显示点击处的 UV 岛。选区和撤销历史不会改变。
  • 3D 右键的“选择此 UV 岛（选区）”，会把点击的 UV 岛设为选区。
  • UV 区域的右键菜单中有“选择此 UV 岛（选区）”“将此 UV 岛添加到选区”“仅在 3D 中显示此 UV 岛”“在 3D 中隐藏此 UV 岛”。这些是先选中该 UV 岛再显示或隐藏，所以选区会改变。

显示范围 ▼ 的窗口

点击 3D 视图左上角显示范围图标下方的 ▼，会弹出汇总显示范围操作的窗口。没有隐藏任何内容时，从这里操作。

  • 左上“从选区”：仅显示所选部分、隐藏所选部分、同时显示所选部分。“直接”下方是隐藏笔。
  • 左下“隐藏部分”：反转、全部显示、范围（px）与扩大、缩小、淡化显示周围。
  • 右侧“隐藏预设”：当前隐藏预设的名称，以及已保存的隐藏预设列表（保存隐藏预设）。
隐藏的部分不会遮挡后面，所以里面的面可以直接看到并绘制。隐藏的部分无法直接绘制，吸管和填充也不会拾取。在对称的 ▼ 中开启“在隐藏侧对称绘制（3D 画笔）”后，用 3D 的钢笔、画笔、橡皮擦、图章，也能对称地绘制到被隐藏部分的另一侧（左右对称绘制）。
隐藏、显示的操作不会进入撤销（Ctrl+Z）的历史。要恢复时，请全部显示，或调用已保存的隐藏预设。

操作不顺利时

  • 出现“请先选择 UV 岛或面”：什么都没有选中。用选区工具的“按 UV 岛选择”“按面选择”点击 3D 或 UV 区域，或用右键的“选择此 UV 岛（选区）”选中后再操作。UV 标题栏的按钮在选中之前会显示为淡色。
  • 按 Ctrl+Z 显示没有恢复：隐藏操作不会进入历史。用 Alt+H，或 3D 下方栏的“全部显示”恢复。
  • 隐藏后选区消失了：隐藏时选区会被取消。用 Ctrl+Shift+D（重新选择）即可恢复。
  • 模型的一部分不显示：仍通过显示范围或对象处于隐藏状态。用 Alt+H 恢复全部显示。隐藏的状态会保存在工程文件中，所以重新打开后仍是隐藏的。

划过即隐藏（隐藏笔）与 3D 下方的栏

绘制重叠布料的里面时，可以把划过的地方直接隐藏。不必事先创建选区。

  1. 选择左侧工具栏的“隐藏笔”（也可以用 3D 下方栏的［隐藏笔］开关）。
  2. 在辅助工具中选择“按面隐藏”（四边形的面会连同 2 个三角形一起）或“按 UV 岛隐藏”（按 UV 岛整体。一块布、一个部件等）。
  3. 在 3D 中划过，划过的地方就被隐藏。在 UV 区域点击也能隐藏。
  4. 再次点击［隐藏笔］，会回到之前的工具。
一次划过，不会隐藏前面被隐藏后露出的里面的面。想把里面也隐藏时，再划一次。

3D 下方的栏

3D 视图下方中间的栏，只在隐藏期间和使用隐藏笔期间出现。

  • 依次排列着［隐藏笔］［面｜岛］［隐藏预设 ▼］［重新选择］［淡化显示周围］，以及当前状态和［全部显示］。
  • 当前状态是“隐藏预设：〇〇”（保持已保存的隐藏预设）、“部分已隐藏（未保存的隐藏状态）”、“仅显示所选部分”之一。隐藏了对象时，还会显示“已隐藏 n 个对象”。
  • 点击［全部显示］，一次就恢复全部显示。

半透明显示已隐藏的部分

把隐藏的部分半透明地显示出来，就能一边确认周围一边绘制。

  1. 隐藏期间，点击 3D 下方栏的［淡化显示周围］。隐藏的部分会半透明显示。
  2. 用旁边的控制柄更改浓度（5–80%）。
  • 在显示范围 ▼ 窗口“隐藏部分”中的“淡化显示周围”也一样（0% 为不显示）。
  • 即使淡淡地显示，也不能直接在隐藏的部分上绘制。

保存隐藏预设

给常用的隐藏方式命名并保存，随时可以恢复到同样的隐藏方式。

  1. 隐藏想隐藏的部分。
  2. 点击 3D 下方栏的［隐藏预设 ▼］→“保存当前隐藏预设”，起个名字（同名则覆盖）。也可以从显示范围 ▼ 窗口保存。
  3. 在同一列表中点击名称，就会恢复到该隐藏方式。
  • 用“管理隐藏预设（名称、删除）”可以重命名和删除。
  • 保存的隐藏预设和当前的隐藏预设，会保存到工程文件（.petanuri）中。重新打开后仍可使用。

显示网格线与接缝线

把多边形的线、UV 的接缝（UV 岛边缘）叠加显示在 3D 上。绘制接缝附近时，可作为参考。

  1. 点击 3D 视图左上角的线形图标（也可以用 显示 → 线与尺子 → 网格线）。会显示多边形的线。
  2. 接缝线用旁边的按钮或 Alt+W 显示（显示 → 线与尺子 → 接缝线（UV 接缝、UV 岛边缘））。
  • 通过图标下方的 ▼，可以选择是否显示线、浓度（5–100%）、颜色（蓝、黑、白）、也显示背面和内侧的线（透视）、接缝线。
  • 平时只显示可见面的线。单面显示时，背向的面的线也不显示。
  • 3D 右键 → 显示 中也有同样的开关。
  • 想隐藏纹理、只用线条查看时，用 显示 → 显示方式 →“仅显示线框”。
  • 接缝线与图层的“描边”（给边缘加上线条）是两回事。

沿 UV 边缘绘制（从 UV 边缘绘制） Pro

按距 UV 岛边缘的距离，在新图层上生成线条或渐变。用于衣服边缘的描边，或只把边缘涂浓。

  1. 选择 滤镜 →“从 UV 边缘绘制（新图层）”。窗口打开期间，UV 和 3D 上会显示临时的线。
  2. 选择“图形”（线、渐变）和“方向”（岛内侧、岛外侧、两者）。
  3. 调整“宽度”“距边缘起点”“模糊”“不透明度”。数值一变，临时的线马上变化。
  4. 在“色彩”中选择前景色或“选择颜色”，再点击“创建”。会生成新图层。
  • 距离的单位是纹理的 px。渐变在边缘处浓，到宽度处变透明。
  • UV 岛相互相接的地方，不算边缘。如果有选区，则只在选区内生成。
  • 选“岛内侧”时，UV 岛外侧边缘（边距的宽度）也会以与最近的 UV 岛像素相同的浓度绘制。关闭“也绘制岛外侧边缘（边距）”则不绘制。
  • 选择“选择颜色”时，可从颜色集的色板或颜色栏中选取。透明色时，不会新建图层，而是从当前图层中擦除这条边缘。
  • 点击取消或按 Esc，临时的线就会消失。创建之后，撤销一次即可恢复。

glTF、glb、VRM 的 UV 方向

glTF 对图像上下的计数方式，与 FBX 等相反。PetaNuri3D 在打开 glTF、glb、VRM 时，会把 UV 上下翻转，使其与 FBX 方向一致。这与在 Blender、UniVRM 中加载时的方向相同。

  • 模型中包含的图像，会按原方向放入底色。
  • UV 区域的图像、导出的 PNG、PSD、UV 贴图，与原图像方向相同。在其他 3D 软件中可以直接对上。
  • 导入图像、PSD 时，也不翻转上下，原样导入。
