PetaNuri3D ／ 使用手册 ／ 轻松烘焙、质感与阴影

轻松烘焙、质感与阴影 Pro

根据模型形状计算阴影、光泽、织纹等并写入图层。可使用“轻松烘焙”一次完成初步润色，或用“烘焙”逐项添加效果。这些功能从 v1.1.0 起提供。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

Lite、Standard、Pro 和 Pro 升级包均已在 BOOTH 提供。

用轻松烘焙制作底层效果

  1. 打开模型，选择要处理的纹理集。底色和原纹理会保留，继续作为基础。
  2. 滤镜 → 轻松烘焙，在“效果”中选择肌肤、服装或道具等预设。
  3. 通过“预览”查看效果，调整“整体强度”“光的左右”“光照仰角”“高光量”。带织纹或色差的润色效果还会显示“材质细节”。
  4. 肌肤润色时，可按需指定添加红润的位置。
  5. “烘焙到图层组”来确认。每种效果的图层与透明的“细节绘制”图层会放入一个文件夹，可直接继续绘画。
在新建界面也可勾选“创建后打开轻松烘焙”并选择目标纹理集。默认不勾选。创建后会打开设置界面，预览使用临时图层显示，确认后才成为正式图层。

12 种润色效果

  • 皮肤：白皙・健康红润／温暖红润／淡雅插画风／有深度的阴影。组合柔和阴影、凹陷阴影和光泽；部分效果还会添加整体色调。
  • 服装：柔软布料／缎面风格／牛仔风格／皮革风格／淡雅色差。根据材质组合织纹、色差、光泽和边缘光。
  • 道具：硬质材料。添加凹陷阴影、清晰光泽与边缘光。
  • 通用：温暖光照／蓝色边缘光。为肌肤、服装或道具添加光照颜色。

预设会在保留原色的基础上叠加效果。若想让肤色与脸部一致，先匹配底色，再从较低烘焙强度开始，便于调整。

添加红润的位置

自行指定脸颊、手肘、膝盖等需要红润的位置。点周围会添加柔和红润，可通过“红润强度”“红润范围”调整，同时保留白皙感。

  1. 选择肌肤润色效果，点击“添加位置”，在 3D 视图指定位置。
  2. 要移动选中的点，可拖动 3D 视图移动手柄，或输入 X、Y、Z 坐标。
  3. 重复点击“添加位置”可添加多个位置，最多 16 个。在列表选中不需要的点，点击“删除所选位置”即可删除。
  4. 检查范围和强度后烘焙。红润会成为单独的“指定位置的红润”图层，之后可调整不透明度。
本功能不会自动识别脸颊或膝盖。未放置点时，不会添加局部红润。“红润范围”为相对于模型高度的比例。
启用“左右对称添加红润色”后，另一侧也会烘焙相同强度的血色，中心与绘制的X对称设置共用。移动原始点时另一侧同步移动，不重复中心或已有对称点。最多使用16处位置及其镜像，默认关闭。

单项烘焙与预览

如需逐项使用效果，请从滤镜 → 烘焙 → 各项功能打开。烘焙 AO也在此子菜单中。

  • 阴影、渐变、凹陷、边缘光、光泽、织纹在修改设置后会即时预览。目标为当前选中且可见的纹理集。勾选“应用于所有显示中的纹理集”可处理多个纹理集。
  • 预览中可转动视角查看。点击“烘焙到新图层”确认，点击“取消”或窗口 × 恢复原状。
  • 预览使用较低分辨率以保持流畅，确认时会按纹理集分辨率重新生成。细密织纹和阴影也请检查确认后的效果。
  • “投射阴影”“薄处透光色”“AO”需要先选目标和质量，再进行计算。会显示进度，可中途取消。
烘焙的是纹理颜色。烘焙后转动视角或移动其他软件中的灯光，已绘制的光影位置也不会改变。要检查底色，可使用“保持绘制颜色”。

柔和阴影、凹陷与凸起

烘焙柔和明暗

根据面方向与指定光照生成柔和阴影。通过“光的左右”“光照仰角”调整方向，通过“阴影范围”“边界柔和度”“阴影浓度”“阴影颜色”调整效果。可从斜上方、正上方、侧方或清晰阴影预设开始。

此功能本身不会生成头发或服装重叠所投射的阴影。处理重叠阴影时，可组合使用“烘焙投射阴影”。

增强凹陷与凸起

检测形状的弯曲，为凹陷添加阴影、凸起添加亮色。“细节宽度”为模型高度的比例。凹陷和凸起可分别设置强度与颜色。

  • 边界柔和度：让检测到的凹陷、凸起转换为颜色时的边界更平缓。
  • 阴影模糊：沿表面平滑阴影本身。细小锯齿明显时可提高此值。0 表示不模糊。
  • 提供柔和立体感／仅凹陷阴影／仅凸起亮部预设。
卡通阴影与天使光环（Pro）：滤镜 → 烘焙 中的“烘焙卡通阴影（第一层阴影/第二层阴影）”按光线方向将阴影清晰分成两层并生成新图层（可调两层的位置、浓度、颜色和边界模糊）。“烘焙天使光环（头发高光）”在所选纹理集（头发）的指定高度添加环状高光带（带宽、锯齿、边缘柔和度、观察方向）。
“强调凹陷与凸起”新增预设“主线（凹陷处的细线）”“主线（较粗、较柔和）”“棱线高光（凸起处的细线）”。

上下或点渐变

“烘焙上下或点渐变”可编辑颜色和透明度色标，通过“颜色分布”的按钮选择划分依据。

  • 表面方向：从朝下的面到朝上的面逐渐变色。适合表现下方反光或为朝上的面提亮。
  • 高度：从模型下方到上方逐渐变色。适合裙摆或发梢的颜色变化。
  • 距点距离：从指定中心向外逐渐变色。使用“在3D视图中指定中心”，可在模型表面或空白空间放置点。通过移动手柄或 X、Y、Z 坐标改变位置。

点距离的“扩散距离”为模型高度的比例。通过“边界位置”“混合宽度”“颜色浓度”调整分布。指定点之前无法确认点距离烘焙。

点击色带添加色标，为各色标设置颜色、位置和不透明度。240 种预设可按分类或名称查找。自定义渐变可通过“保存当前”注册。编辑方法与绘制工具渐变相同。

边缘光、光泽、织纹与色差

  • 烘焙边缘光：根据指定光照和观看方向，为轮廓附近的面添加光色。用“扩散”调整宽度，也可使用蓝色边缘或暖色逆光等预设。
  • 烘焙光泽高光：根据指定光照和观看方向添加光泽亮部。提高“扩散”可获得柔和光泽，降低则得到硬质材料的窄高光。提供肌肤、缎面、硬质材料预设。
  • 烘焙织纹与色彩变化：在“纹理”按钮中选择织纹或色差，调整大小、编号、颜色和强度。更改编号可改变图案分布。大小为模型高度的比例。
织纹按照 3D 空间的轴和面方向生成，而非沿 UV 线生成。要为袖子、裙摆等手动指定织纹方向，也可使用图案笔。这些烘焙用于颜色表现，不会生成法线贴图或实际反射参数。

光照投影、薄处透光色

烘焙投射阴影

  1. 打开 滤镜 → 烘焙 →“烘焙投射阴影”。
  2. 设置光照左右、上下方向，阴影柔和度、强度、颜色、阴影距离和质量。
  3. 逐纹理集选择“接收阴影”“投射阴影”。例如将阴影烘焙到 body，而让头发和服装仅投射阴影。
  4. 点击“烘焙到新图层”计算。按当前姿势的重叠关系生成阴影。

烘焙薄处透光色

向面内侧检测，为附近有另一侧面的薄处着色。适合有厚度的封闭耳朵、手指和道具等，添加柔和的透光色表现。

  1. 打开 滤镜 → 烘焙 →“烘焙薄处透光色”。
  2. 设置“薄度检测距离（cm）”“透光色强度”“透光色”“质量”，并勾选目标纹理集的“烘焙”。
  3. 点击“烘焙到新图层”计算。
开放的单层布片不适用于薄处透光色。若内侧有其他面，也会检测到与该面的距离，请检查结果并调整强度。这不是让光实际穿透材质的设置。

烘焙后的调整与保存

  • 烘焙效果为普通绘制图层。可降低图层不透明度、隐藏不需要的效果、用蒙版限定范围，或用橡皮擦局部擦除。
  • 轻松烘焙将效果分为独立图层，因此也可减弱阴影、保留红润。在“细节绘制”图层添加颜色，可继续绘画而不破坏烘焙结果。
  • 烘焙确认后可用 Ctrl＋Z 撤销。再次烘焙会新增图层。叠加过多时，可隐藏或删除旧效果进行对比。
  • .petanuri 格式保存可保留生成的所有图层。PNG 会合成可见效果，PSD 则可按图层导出（导出）。
