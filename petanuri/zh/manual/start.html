PetaNuri3D ／ 使用手册 ／ 入门

入门

本页介绍如何安装并启动 PetaNuri3D、打开 3D 模型，以及保存绘制的内容。各版本（Lite、Standard、Pro）的区别和更新到新版本的方法也汇总在这里。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

先看这几点
  1. 先解压整个 ZIP，然后用“PetaNuri3D”文件夹中的 setup.exe 安装，或直接运行 PetaNuri3D-win_x64.exe（详情）。
  2. 第一次使用的话，可以在启动界面点“用示例试试”，打开练习用的模型（详情）。
  3. 自己的模型请通过“新建”选择，并为每个纹理集设置分辨率和起始内容（详情）。
  4. 绘制之后按 Ctrl+S，保存为工程文件（.petanuri）。每 5 分钟还会自动保存一次（详情）。
  5. 要生成纹理图像，请使用“导出”（导出）。

运行环境

可在 Windows 电脑上运行。能运行 VRChat 的电脑，通常都能运行。

项目需要推荐（参考）
OSWindows 11（64 位）—
GPU支持 WebGL2（近几年的 NVIDIA、AMD、Intel GPU，并安装最新驱动程序）GPU 显存：以 2048 分辨率绘制建议 4GB 以上，4096 建议 8GB 以上
其他Microsoft Edge WebView2 运行时（Windows 11 自带）电脑内存 16GB 以上
  • Windows 10 也能运行，但不在支持范围内。
  • 当前的 GPU 内存估算显示在纹理集面板的上方。

操作不顺利时

  • 卡顿、无法绘制：GPU 内存不足。请降低纹理的分辨率，或关闭浏览器、游戏等其他应用（节省内存）。

安装与启动

先把从 BOOTH 下载的 ZIP（PetaNuri3D-＜版本＞-v＜版本号＞.zip）全部解压。“PetaNuri3D”文件夹中有主程序和 setup.exe。使用方法有两种。

用 setup.exe 安装（推荐）

  1. 双击“PetaNuri3D”文件夹中的 setup.exe。
  2. 选择安装位置、是否创建桌面图标、是否双击工程文件（.petanuri）打开，然后安装。不需要管理员权限（只为当前用户安装）。
  3. 从开始菜单（或桌面）启动。
setup.exe 会安装同一文件夹中的主程序。请不要单独取出 setup.exe，要连同整个文件夹一起使用。安装位置是 %LOCALAPPDATA%\Programs\PetaNuri3D。

免安装直接启动

  1. 把“PetaNuri3D”文件夹放到任意位置。
  2. 双击文件夹中的 PetaNuri3D-win_x64.exe。
exe 旁边的 resources.neu、mcp、tools、unity 也会用到。搬动时请连同整个文件夹一起移动。新版本请解压到新的文件夹中。

启动之后

中间出现“新建”“打开工程文件”“用示例试试”，就说明准备好了。最近使用的文件和自动保存也可以从这里打开。

  • 也可以把 3D 模型（FBX 等）或工程文件（.petanuri）拖放到启动界面中央的入口来开始。3D 模型会进入新建界面，工程文件则直接打开。
  • 设置（辅助工具、按键设置、窗口布局、颜色集、参考图等）保存在 %APPDATA%\PetaNuri3D 中，下次启动时会恢复。
  • 不再使用时，在 Windows 的“设置 → 应用 → 已安装的应用”中卸载“PetaNuri3D”。设置和工程文件不会被删除。

操作不顺利时

  • 出现“Windows 已保护你的电脑”：依次点击“更多信息”→“仍要运行”。因为应用没有签名，第一次启动时可能会出现。
  • 更换位置后 Unity 联动无法使用：请在 Unity 插件中重新选择它所记录的 exe 位置（从 Unity 绘制）。

教程与示例模型

第一次启动时，会出现操作指南（教程）。跟着提示，实际操作发光的地方，一步步进行。

  • 用 ← → 前后翻页，点“跳过”或按 Esc 可以退出。
  • 尚未打开模型时，可以选择“用示例模型试试”或“用自己的模型（稍后打开）”。用示例的话，可以依次试试旋转、绘制、左右对称和 UV。
  • 想再看一次，请选择 帮助 → “教程（操作指南）”。也可以在 文件 → 偏好设置 → 系统 中勾选“下次启动时显示教程”。

示例模型“Shinobu”

在启动界面点“用示例试试”即可打开。所有版本都能使用。模型是 A 字姿势，有 7 个纹理集，每个纹理集的底色里都放有原始颜色的图像。

示例模型仅用于试用 PetaNuri3D。请勿用于其他用途，也不要提取出来分发。

第一次使用的话，建议先看初次使用，把示例完整地涂一遍。不使用模型直接绘制时，请从启动界面的“开始 2D 绘画”开始（2D 绘画）。

打开 3D 模型（新建）

打开自己的 3D 模型，做好绘制前的准备。可以打开 FBX、glTF（合并为单个文件的形式）、GLB、VRM、OBJ 和 DAE。

  1. 点启动界面的“新建”，或选择 文件 → 新建（Ctrl+N），然后选择 3D 模型。
  2. 会按材质列出各个纹理集。为每个纹理集选择分辨率（32～4096 px，Lite 版最高 2048）。
  3. 为每个纹理集选择起始内容（底色）。可以混用不同的起始内容。
  4. 点“新建”，模型就会显示在 3D 视图中。想放弃的话，点“取消”或按 Esc。

起始内容（底色）的种类

起始内容内容
颜色把底色填充为单色后开始。默认是白色。选“模型颜色”，也可以使用材质的颜色。
图像以 PNG、JPEG 等图像作为底色。
PSD Standard按原样导入 PSD 的图层。
lilToon 材质 Pro从 .mat 或包含它的 .unitypackage 中加载设置、纹理和蒙版（加载 lilToon 材质）。
  • 如果模型使用的图像位于模型旁边（同一文件夹或 Texture 文件夹）或模型内部，会自动找到，并以“图像”开始。
  • 用上方的“批量”，可以统一所有纹理集的分辨率、让所有纹理集都以白色底色开始，或一次选择多张图像或 PSD。文件名与纹理集名相同的文件（body.psd → body）会放入该纹理集。把图像、PSD 或 .mat 拖放到这个界面，也会自动分配。
  • 使用相同图像的材质会合并为一个纹理集（也可以用该行的“合并 ▾”手动合并或取消合并）。合并后只需在一张纹理上绘制，所有材质上都会显示出来。
  • Pro 勾选“创建后打开轻松烘焙”并选择目标纹理集，打开后会弹出轻松烘焙窗口，可以先生成皮肤和服装的底涂，再进行细致绘制（轻松烘焙）。

操作不顺利时

  • 把模型拖放到窗口中打不开：打开模型之后，再拖放就不会打开了。请通过 文件 → 新建 或 文件 → 重新加载模型 打开。
  • 提示找不到纹理：在该行点“选择○○”，选择图像。
  • 有无法绘制的地方：如果模型存在没有 UV 的面等无法绘制的地方，打开时会在右下角提示。UV 位于 0～1 范围之外的部分，会画在重复平铺后颜色相同的位置上。

保存、打开并继续

绘制的内容保存为工程文件（.petanuri）。模型、全部图层和设置都包含在一个文件中。要生成纹理图像（PNG、PSD），请使用另外的“导出”。

想做的事操作
保存文件 → 保存工程文件（Ctrl+S）
另存为文件 → 另存为（Ctrl+Shift+S）
打开并继续文件 → 打开工程文件（Ctrl+O）。也可以拖放到窗口中打开
打开最近的工作文件 → 最近使用的文件
崩溃后恢复文件 → 从自动保存打开（每个工程最多保留最新的 3 个）
不带模型传递文件 → 不含模型（FBX）保存（打开时需选择本机的模型）
  • 标题栏中的“*”表示有未保存的更改。带着未保存的更改关闭时，会询问“保存并退出”“不保存并退出”或“取消”。
  • 每 5 分钟自动保存一次。
  • 菜单栏右侧的图标也可以执行新建、打开、保存、撤销和重做。

以快速格式保存

自动保存会采用不写入图层透明部分的“快速格式”。如果有很多只含线条的图层，保存会快得多。手动保存的工程文件，只要勾选 文件 → 偏好设置 → 绘制 → 性能 中的“以快速格式保存工程文件（可在 v1.2.0 及以后版本中打开）”，也会变成同样的格式。

操作不顺利时

  • 应用崩溃或卡住了：再点一次 × 就会退出（未保存的更改不会保留）。重新打开后，选择 文件 → 从自动保存打开，打开最近一次的自动保存。
  • 出现“应用内部的读写已停止”：电脑从睡眠中恢复后等情况下可能发生。请先退出并重新打开，再通过 文件 → 从自动保存打开 恢复。
  • 打开后名称带有“（有缺失）”：这是有一部分内容无法读取的工程文件。为避免覆盖原文件，保存时会变为“另存为”。
  • 保存窗口没有出现：请检查选择保存位置的窗口是否被其他窗口挡住了。如果持续超过 30 秒，按 × 或 Ctrl+S，可以选择“等待”或“停止上一次保存并继续”。
  • 在预览过程中保存，弹出了确认：在变形、滤镜等预览过程中保存时，会先询问“应用并继续”“放弃预览并继续”或“取消”。

重新加载模型

修改了 3D 模型（FBX 等）之后，可以保留已绘制的内容，只更新模型的形状。

  1. 选择 文件 → 重新加载模型（保留所绘内容）。
  2. 点“重新加载同一文件”或“选择文件”。
  3. 纹理集按材质名称匹配。同名的纹理集，图层和设置都会原样保留。

重新加载时会询问的内容

遇到这种情况出现的确认与选择方法
有纹理集的 UV 发生了变化“对齐绘画并更新”＝把已绘制的内容移到新 UV 的位置／“不对齐直接更新”＝绘制内容仍留在旧 UV 的位置／“取消更新”＝放弃重新加载
新增了材质只针对新增的纹理集行，出现与新建相同的界面。设置好分辨率和起始内容，点“加载”
模型的纹理（图像）发生了变化会按纹理集询问“要用新纹理替换底色吗？”。替换后，直接画在底色上的内容也会被替换
新模型中没有的材质该纹理集不会被删除，而是带着 ! 标记保留。点击它，可以把图层移到其他纹理集（无对应材质的纹理集）
重新加载后可以按一次 Ctrl+Z 撤销（前提是手头还有之前模型的内容）。但重新加载之前的操作历史会被清除。

版本（Lite、Standard、Pro）

PetaNuri3D 有 3 个版本。当前版本可以从窗口标题、启动界面的标签，以及 帮助 → “关于 PetaNuri3D”中看到。本手册用 Standard 标记 Standard 及以上版本才有的功能，用 Pro 标记仅限 Pro 的功能。没有标记的功能从 Lite 起就可以使用。

对比项Lite（免费）StandardPro
绘制、涂色、擦除、混色、填充、对称、UV、选区、变换、文字、尺子、自动上色、导出 PNG、保存工程文件、2D 绘画、亮度转为透明度、从 Unity 绘制○○○
图层（每个纹理集，含底色）最多 4 个不限图层数不限图层数
分辨率最高 2048最高 4096最高 4096
导入、导出 PSD—○○
滤镜、调整图层、描边—○○
导出、导入画笔设置（.petabrush）—○○
姿势、混合形状、顶点组——○
最终效果（lilToon、MToon 的外观）、材质设置、绘制目标、主颜色 2nd/3rd、加载和导出 lilToon 材质——○
轻松烘焙、明暗等烘焙、烘焙 AO、从 UV 边缘绘制——○
AI 联动 run_js（在应用中运行程序的命令）——○
  • Lite 中不能使用的功能，菜单和按钮会变淡，并带有小锁标记。点击后会显示哪个版本可以使用。
  • 在 Standard 中，不会显示仅限 Pro 的功能的入口（但会显示 帮助 → “升级到 Pro”）。
  • 不会添加水印。纹理集的数量没有上限。
  • 任何版本创建的工程文件都能打开。超过上限的图层，以及该版本无法使用的功能的设置，也不会被删除，会一直保留，保存后依然存在。
  • 价格和购买方式，请看介绍页的价格。Lite、Standard、Pro 以及升级到 Pro 的升级包，均通过 BOOTH 提供。

操作不顺利时

  • 无法添加图层（Lite）：Lite 版每个纹理集最多 4 个图层（含底色）。图层面板下方会显示“图层 4 / 4 张”。删除或合并图层后，就能再添加。

升级到 Pro Pro

从 Standard 升级到 Pro 时，请使用 BOOTH 上的“升级到 Pro”。

  1. 在 BOOTH 购买“升级到 Pro”，获得升级文件（PetaNuri3D-Pro.petapack）。
  2. 选择 帮助 → “升级到 Pro” → “选择文件”，选中该文件。也可以把它拖放到窗口中，或放在与 exe 相同的文件夹中。
  3. 立即变为 Pro，无需重新启动。工程文件和设置保持不变，下次启动后也是 Pro。
升级仅在 Standard 时可用（Lite 无法使用）。
升级文件不受版本号限制。安装一次后，即使把 PetaNuri3D 更新到新版本，也仍是 Pro。

更新到新版本

当前版本可以在启动界面的标题旁，以及 帮助 → “关于 PetaNuri3D”中查看。变更内容汇总在更新记录中。

  1. 启动时（每天最多一次），如果有新版本，会在画面右下角提示。
  2. 点“立即更新”，会从官方网站获取新版本并校验，确认一次后完成替换并重新启动。如果有未保存的更改，会在关闭前询问。
  • 选择 帮助 → “检查新版本”，可以随时检查。
  • 文件 → 偏好设置 → 系统 中的“有新版本时自动下载并替换”默认是勾选的。勾选时，启动时会自动获取，并询问“安装并重新启动”（获取过程中可以点“取消”中止）。取消勾选后，只有点“立即更新”时才会去获取。
  • 取消勾选“启动时检查更新”，启动时就不再检查。
  • 手动更新时，解压新的 ZIP 并运行 setup.exe（覆盖安装）。更换版本时也是一样。设置、工程文件、画笔和升级都可继续使用。
只检查版本号。作品和设置不会发送到任何地方。没有联网时不会显示任何内容。

操作不顺利时

  • 无法在应用内更新：如果无法从官方网站获取，会显示“在 BOOTH 下载”的提示。请从 BOOTH 下载 ZIP 手动更新。v1.2.1 及更早的 PetaNuri3D 也无法在应用内更新，请手动更新。

遇到问题或有功能需求，可以通过 帮助 → “联系我们（支持、功能需求、错误报告）”发送（如何联系我们）。
