PetaNuri3D ／ 使用手册 ／ 入门

入门

介绍启动 PetaNuri3D、打开 3D 模型、绘制并保存工程的流程，以及 Lite、Standard、Pro 的区别。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

Lite、Standard、Pro 和 Pro 升级包均已在 BOOTH 提供。

启动

  1. 解压下载的 zip，将 PetaNuri3D 文件夹放在自选位置（无需安装）。
  2. 双击文件夹中的 PetaNuri3D-win_x64.exe 。应用也需要同目录的 resources.neu，移动时请移动整个文件夹。
  3. 若出现“Windows 已保护你的电脑”，点击“更多信息”→“仍要运行”（因应用未签名，首次启动可能出现）。
  4. 中央出现“新建”“打开工程文件”“用示例试试”后即可使用（也可从此打开最近文件和自动保存）。
拖放即可开始（所有版本）：将 3D 模型（FBX、glTF／GLB、VRM、OBJ、DAE）或工程文件（.petanuri）拖放到启动界面中央的入口面板上，即可直接开始。3D 模型会进入新建界面（一同拖入的图片、PSD、.mat 会在该界面中分配），工程文件则直接打开。
当 3D 放入小窗口（UV 全屏）时，启动界面会显示在 UV 区域中不与小窗口重叠的位置。
运行环境为 Windows 11（64bit）。也可在 Windows 10 运行，但不属于支持范围。
设置（辅助工具、按键设置、窗口布局、颜色集、参考图等）保存在 %APPDATA%\PetaNuri3D，下次启动恢复。
发布形式（所有版本，v1.3.0 起）：从 BOOTH 下载的 ZIP（PetaNuri3D-＜版本＞-v＜版本号＞.zip）每个版本 1 个。解压整个 ZIP 后，“PetaNuri3D”文件夹中包含主程序和 setup.exe。双击 setup.exe 安装，或直接运行同一文件夹中的 PetaNuri3D-win_x64.exe。setup.exe 会安装同一文件夹中的主程序，因此请不要只取出 setup.exe，请连同整个文件夹一起使用。无需管理员权限（只安装给当前用户）。安装位置为 %LOCALAPPDATA%\Programs\PetaNuri3D，从开始菜单启动。安装时可以选择是否创建桌面图标，以及是否可以双击打开工程文件（.petanuri）。
更新版本或更换版本（Lite、Standard、Pro）时，只需运行新的 setup（覆盖安装；如正在运行请先关闭）。设置、项目文件、笔刷和升级保持不变。卸载时，在 Windows 的“设置 → 应用 → 已安装的应用”中卸载“ぺたぬり3D”（设置与项目文件不会被删除）。zip 仍可照常使用。
辅助程序（Windows）：关闭监视、笔侧键接收、WinTab 压感、3D 鼠标、提前显示笔画都在 PetaNuri3D 主程序（PetaNuri3D-win_x64.exe）内部运行。v1.2.0 之前它们是 tools 文件夹中的独立程序（close-watch.exe、wintab-pressure.exe、mouse3d.exe、ink-overlay.exe 等），从 v1.2.1 起不再存在（用 CUDA 烘焙 AO 的辅助 aobake-cuda.exe 只在烘焙时运行，保持不变）。用法和设置不变。用 setup 覆盖安装时，旧版本 tools 中的辅助程序会被删除。使用 zip 的用户请解压到新文件夹（旧文件夹 tools 中残留的辅助程序不会被使用，可以删除）。
从 zip 改为 setup 等导致应用位置变化时，请在 Unity 联动插件中重新选择一次 exe 的位置。

教程与示例模型

  • 首次启动显示操作教程（12步）。← → 前后切换，点击“跳过”或按 Esc 退出。
  • 再次查看可使用 帮助 →“教程”。也可在 文件 → 偏好设置 → 系统 开启“下次启动时显示教程”。
  • 未打开模型时启动教程，可选择“用示例模型试试”或“用自己的模型（稍后打开）”。选择示例后，可实际体验旋转、绘制、左右对称和 UV 操作。
  • 示例模型（獄門しのぶ）可从启动界面“用示例试试”打开（Lite 也可）。使用 A 姿势、7个纹理集，每个底色含原色图片（2048px）。
示例模型仅用于试用 PetaNuri3D。请勿用于其他用途，或提取后分发。

无需模型绘制时，可从启动界面“用示例试试”下方“开始 2D 绘画”开始（2D 绘画）。

新建（打开 3D 模型）

  1. 点击“新建”（文件 → 新建、Ctrl＋N）并选择 3D 模型。可打开 FBX、glTF（合并为单文件）、GLB、VRM、OBJ、DAE。
  2. 按材质显示纹理集。为每个纹理集指定分辨率（32～4096，Lite 最高 2048）和起始内容。
  3. 起始方式可选“色彩”（单色填充底色，默认白色，也可选“模型颜色”）、“图像”（PNG、JPEG 等）、“PSD”（保留图层，Standard）、“lilToon 材质”（.mat 或包含它的 .unitypackage，Pro）。各纹理集可使用不同起始方式。
  4. 点击“新建”，3D 视图显示模型。点击“取消”或按 Esc。
模型图片位于附近（同目录或 Texture 文件夹），或嵌入模型时，会自动找到并使用“图像”作为起始方式。
上方“批量”可统一分辨率，或批量选择图片、PSD、lilToon 材质。文件名与纹理集名相同的文件（body.psd → body）会导入对应纹理集。将图片、PSD、.mat 拖入此界面也会自动分配。
将 3D 模型拖放到启动界面中央的入口面板上即可打开（进入新建界面）。打开模型后等情况下，拖入窗口不会打开 3D 模型。请使用 文件 → 新建 或 重新加载模型。UV 超出0〜1时，会映射到纹理重复后颜色相同的位置绘制（不修改模型文件）。若模型存在无法绘制的位置，加载时会在右下提示。
Pro 设置底色后，可勾选“创建后打开轻松烘焙”并选择目标纹理集。创建后选择肌肤、服装等润色效果，再继续绘制。不会自动烘焙，而是预览后确认（轻松烘焙）。
glTF、glb、VRM 的方向（所有版本）：打开这些模型时会将 UV 上下翻转，与 FBX 方向一致。UV 视图中的图像、导出的 PNG、PSD 和 UV 贴图与原图方向相同。旧版本保存的项目在 3D 中外观不变，但 UV 视图会上下颠倒（重新保存后即为新格式）。
没有材质的 FBX 会按对象拆分为纹理集打开（以前合为一个）。同一 UV 被 5 个以上面重复使用的地方（如发束）也能在 3D 中绘制。

保存、打开并继续

  • 文件 → 保存工程文件（Ctrl＋S）将模型、全部图层和设置存入一个 .petanuri 文件。另存为使用 Ctrl＋Shift＋S。
  • 继续工作时，使用 文件 → 打开工程文件（Ctrl＋O）打开 .petanuri（也可拖入窗口），或 文件 → 最近文件。
  • 打开期间，中央显示“加载中…”、文件名和进度。
  • 标题中的“＊”表示存在未保存修改。
  • 每5分钟自动保存。应用意外关闭时，可从 文件 → 从自动保存打开 恢复（每个工程保留最近3份）。
部分内容无法读取的工程会以“（内容缺失）”附加名称打开。为避免覆盖原文件，保存会使用“另存为”。
自动保存采用不写入图层透明区域的快速格式，v1.1.2 及更早版本无法读取其中的图像。手动保存的项目仍为原格式；在文件 → 偏好设置 → 绘制 →“性能”中开启“以快速格式保存项目文件”后也会使用该格式。
界面卡住、点 × 无反应时，再按一次 × 即可退出（未保存的更改将会丢失）。睡眠恢复后等情况下若内部读写停止，自动保存与保存不会一直等待，而是给出提示。此时请先退出再重新打开，用文件 → 从自动保存打开 打开最近的自动保存。
在自动保存过程中进行保存、打开或退出时，会取消自动保存并优先执行手动操作（取消的部分会在下次自动保存时再保存）。当选择保存位置的窗口被其他窗口挡住等原因没有返回时，可通过 ×（或持续超过 30 秒后通过 Ctrl+S）选择“等待／取消上一次保存并继续”。只有内部读写没有响应时，也会提示用“另存为”保存到其他位置。
不含模型（FBX）保存（文件菜单，v1.3.0 起）：保存不含模型的小型工程文件（用于分发）。打开时选择本地的模型。覆盖保存此副本时也不会包含模型。

重新加载模型（保留所绘内容）

修改 3D 模型（FBX 等）后，可保留绘制内容，只更新形状。

  1. 选择 文件 → 重新加载模型。
  2. 点击“重新加载同一文件”或“选择文件”。
  3. 按材质名称匹配纹理集。同名纹理集保留图层和设置。
  • 如果有 UV 改变的纹理集，会询问“UV 已改变”（v1.3.0 起）。选择“对齐绘画并更新”会将已绘制的绘画对齐复制到新 UV，选择“不对齐直接更新”则保持在 UV 上的原位置，选择“取消更新”则停止重新加载。从 Blender、Unity 联动发来的形状会自动对齐，如有无法对齐的面会提示。形状变化很大的纹理集不会移动绘画，并会提示。
  • 新模型中没有对应材质的纹理集不会删除，而会保留并附加 ! 标记。点击可将图层迁移到其他纹理集（无对应材质纹理集）。
  • 新增材质时，重新加载前会显示与新建相同的界面，但仅列出新纹理集。指定分辨率、起始方式后点击“重新加载”。
重新加载可通过撤销一次恢复（前一个模型的内容仍在手边时，v1.3.0 起）。重新加载之前的操作历史会被清除。由 Unity 联动发来的形状的重新加载不会撤销，因为会与 Unity 场景不一致。
重新加载后，若有纹理集的模型纹理（图像）发生变化，会逐个询问“要用新纹理替换底色吗？”。替换时，直接画在底色上的内容也会被替换。替换可作为重新加载后的一步撤销。

从 Standard 升级到 Pro Pro

  1. 在 BOOTH 购买“升级到 Pro”，即可获得升级文件（PetaNuri3D-Pro.petapack）。
  2. 帮助 →“升级到 Pro”→“选择文件”，选中该文件（也可拖入窗口或放在 exe 同目录）。
  3. 立即成为 Pro（无需重新启动）。工程文件和设置保持不变，下次启动后也仍为 Pro。
升级只能在 Standard 上使用（Lite 无法使用）。升级文件不受版本限制（v1.3.0 起）。导入一次后，即使将 PetaNuri3D 更新到新版本也仍为 Pro，无需重新导入。v1.2.1 及以前购买的升级文件也可直接使用。

版本与新版本通知

  • 启动界面标题旁（如 v1.1.0）或 帮助 →“关于 PetaNuri3D”可查看当前版本号。
  • 启动时（每天最多一次）会在官网检查新版本。发现更新时右下通知（“打开下载页面”“稍后”“不提醒此版本”）。
  • 随时可使用 帮助 →“检查新版本”。取消 文件 → 偏好设置 → 系统 中“启动时检查更新”，即可关闭启动检查。
仅检查版本号，不发送作品或设置。未连接互联网时不显示提示。
在应用内更新（Windows，v1.3.0 起）：点击通知中的“立即更新”，会从官方网站获取新版本并校验（签名和内容），确认 1 次后关闭、替换并自动重新启动。如果没有关闭偏好设置 → 系统 → 启动中的“有新版本时自动下载并替换”，启动时会在右下角显示进度并下载（可用“取消”停止），下载完成后显示“安装并重新启动”的确认。如有未保存的更改，会在关闭前询问。无法从官方网站获取时，会改为“从 BOOTH 下载”的提示。
从 v1.2.1 及更早版本到 v1.3.0（Windows）：v1.2.1 及更早版本的应用无法找到新形式的 ZIP，因此仅这一次需要手动更新。请保存作品并关闭应用，解压从 BOOTH 下载的 ZIP，然后双击“PetaNuri3D”文件夹中的 setup.exe（会覆盖安装到之前用 setup 安装的位置）。更新到 v1.3.0 后，从下一个版本起即可在应用内更新。
联系我们（所有版本）：在帮助 →“联系我们（支持、功能需求、错误报告）”中选择类型，即可生成包含排查所需信息（版本、版本号、画面大小等，不含文件位置）的文本。填写空白处后点“复制”，再打开 BOOTH 商店或 Discord 发送。
