PetaNuri3D ／ 使用手册 ／ 入门

入门

介绍启动 PetaNuri3D、打开 3D 模型、绘制并保存工程的流程，以及 Lite、Standard、Pro 的区别。

启动

  1. 解压下载的 zip，将 PetaNuri3D 文件夹放在自选位置（无需安装）。
  2. 双击文件夹中的 PetaNuri3D-win_x64.exe 。应用也需要同目录的 resources.neu，移动时请移动整个文件夹。
  3. 若出现“Windows 已保护你的电脑”，点击“更多信息”→“仍要运行”（因应用未签名，首次启动可能出现）。
  4. 中央出现“新建”“打开工程文件”“用示例试试”后即可使用（也可从此打开最近文件和自动保存）。
运行环境为 Windows 11（64bit）。也可在 Windows 10 运行，但不属于支持范围。
设置（辅助工具、按键设置、窗口布局、颜色集、参考图等）保存在 %APPDATA%\PetaNuri3D，下次启动恢复。

教程与示例模型

  • 首次启动显示操作教程（12步）。← → 前后切换，点击“跳过”或按 Esc 退出。
  • 再次查看可使用 帮助 →“教程”。也可在 文件 → 偏好设置 → 系统 开启“下次启动时显示教程”。
  • 未打开模型时启动教程，可选择“用示例模型试试”或“用自己的模型（稍后打开）”。选择示例后，可实际体验旋转、绘制、左右对称和 UV 操作。
  • 示例模型（獄門しのぶ）可从启动界面“用示例试试”打开（Lite 也可）。使用 A 姿势、7个纹理集，每个底色含原色图片（2048px）。
示例模型仅用于试用 PetaNuri3D。请勿用于其他用途，或提取后分发。

无需模型绘制时，可从启动界面“用示例试试”下方“开始 2D 绘画”开始（2D 绘画）。

新建（打开 3D 模型）

  1. 点击“新建”（文件 → 新建、Ctrl＋N）并选择 3D 模型。可打开 FBX、glTF（合并为单文件）、GLB、VRM、OBJ、DAE。
  2. 按材质显示纹理集。为每个纹理集指定分辨率（512〜4096，Lite 最高2048）与起始内容。
  3. 起始方式可选“色彩”（单色填充底色，默认白色，也可选“模型颜色”）、“图像”（PNG、JPEG 等）、“PSD”（保留图层，Standard）、“lilToon 材质”（.mat 或包含它的 .unitypackage，Pro）。各纹理集可使用不同起始方式。
  4. 点击“新建”，3D 视图显示模型。点击“取消”或按 Esc。
模型图片位于附近（同目录或 Texture 文件夹），或嵌入模型时，会自动找到并使用“图像”作为起始方式。
上方“批量”可统一分辨率，或批量选择图片、PSD、lilToon 材质。文件名与纹理集名相同的文件（body.psd → body）会导入对应纹理集。将图片、PSD、.mat 拖入此界面也会自动分配。
不能通过拖入窗口打开 3D 模型。请使用 文件 → 新建 或 重新加载模型。UV 超出0〜1时，会映射到纹理重复后颜色相同的位置绘制（不修改模型文件）。若模型存在无法绘制的位置，加载时会在右下提示。
Pro 设置底色后，可勾选“创建后打开轻松烘焙”并选择目标纹理集。创建后选择肌肤、服装等润色效果，再继续绘制。不会自动烘焙，而是预览后确认（轻松烘焙）。

保存、打开并继续

  • 文件 → 保存工程文件（Ctrl＋S）将模型、全部图层和设置存入一个 .petanuri 文件。另存为使用 Ctrl＋Shift＋S。
  • 继续工作时，使用 文件 → 打开工程文件（Ctrl＋O）打开 .petanuri（也可拖入窗口），或 文件 → 最近文件。
  • 打开期间，中央显示“加载中…”、文件名和进度。
  • 标题中的“＊”表示存在未保存修改。
  • 每5分钟自动保存。应用意外关闭时，可从 文件 → 从自动保存打开 恢复（每个工程保留最近3份）。
部分内容无法读取的工程会以“（内容缺失）”附加名称打开。为避免覆盖原文件，保存会使用“另存为”。

重新加载模型（保留所绘内容）

修改 3D 模型（FBX 等）后，可保留绘制内容，只更新形状。

  1. 选择 文件 → 重新加载模型。
  2. 点击“重新加载同一文件”或“选择文件”。
  3. 按材质名称匹配纹理集。同名纹理集保留图层和设置。
  • 即使 UV 改变，已绘制图像仍保持 UV 位置贴到新形状（大幅移动 UV 的部分会错位）。
  • 新模型中没有对应材质的纹理集不会删除，而会保留并附加 ! 标记。点击可将图层迁移到其他纹理集（无对应材质纹理集）。
  • 新增材质时，重新加载前会显示与新建相同的界面，但仅列出新纹理集。指定分辨率、起始方式后点击“重新加载”。
重新加载会清空撤销历史。

  • Lite：不可用功能在菜单、按钮、右键菜单中变淡，并带有小锁标记。点击会说明适用版本。

  • 没有水印，不限制纹理集数量。
  • 可打开任意版本创建的工程文件。超出上限的图层、4096纹理集、该版本不支持的功能设置均不会删除，保存时也会保留。

从 Standard 升级到 Pro Pro

  1. 在 BOOTH 购买“升级到 Pro”，即可获得升级文件（PetaNuri3D-Pro.petapack）。
  2. 帮助 →“升级到 Pro”→“选择文件”，选中该文件（也可拖入窗口或放在 exe 同目录）。
  3. 关闭并重新启动 PetaNuri3D 后即变为 Pro，无需重新安装。工程文件和设置均保留，之后启动也保持 Pro。
升级仅适用于 Standard（Lite 不可用）。升级文件只能安装到同版本 PetaNuri3D。更新应用后，请重新下载并安装相同版本升级文件（版本不匹配时会在启动时提示，并以 Standard 运行）。

版本与新版本通知

  • 启动界面标题旁（如 v1.1.0）或 帮助 →“关于 PetaNuri3D”可查看当前版本号。
  • 启动时（每天最多一次）会在官网检查新版本。发现更新时右下通知（“打开下载页面”“稍后”“不提醒此版本”）。
  • 随时可使用 帮助 →“检查新版本”。取消 文件 → 偏好设置 → 系统 中“启动时检查更新”，即可关闭启动检查。
仅检查版本号，不发送作品或设置。未连接互联网时不显示提示。
