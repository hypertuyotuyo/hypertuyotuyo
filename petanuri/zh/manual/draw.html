PetaNuri3D ／ 使用手册 ／ 绘制

绘制

在 3D 视图直接用钢笔绘画。通过左侧工具栏选择工具，用辅助工具和工具属性调整手感。

先试着绘制

  1. 从 3D 视图模型上开始绘制时，会先自动切换到该位置的纹理集（如 body）再绘制（也可从右侧纹理集面板选择）。
  2. 在左侧工具栏选择钢笔（P），再从辅助工具选择“G 笔”等。
  3. 在颜色面板选色，在 3D 视图模型上绘制。
  4. 转动视角用右键拖动（数位笔侧键）或 Space＋拖动；缩放用滚轮。
在模型上使用 Alt＋右键也可选择该纹理集。详细信息请参阅纹理集页面。

也绘制背面和被遮挡的面

工具属性不透明度正下方的“也绘制背面和被遮挡的面”（橡皮擦为“也擦除背面和被遮挡的面”），以笔尖下可见表面为中心，在与画笔圆视觉大小相同的球体内，也绘制摄像机看不到的背面和内侧面。可一次绘制头发内侧、衣服重叠处、指缝等难以转到可见角度的位置。

  • 钢笔、毛笔、画笔集、橡皮擦、渐变默认开启。关闭时仅绘制可见面。
  • 装饰、图案、凹凸也有此功能（默认关闭）。模糊、涂抹、混色、图章使用屏幕上显示的颜色或图片，因此只影响可见面。
  • 硬度控制边缘模糊。图片笔尖（铅笔、粉笔、喷雾及多数画笔集等）也可使用。“沿表面绘画”按面方向定向，“匹配屏幕”则将屏幕所见笔尖形状投影到后方。
  • 选区、隐藏面、对称、锁定透明像素均正常生效。在 UV 区域绘制时无关（本来就能影响所有面）。
在有厚度的位置绘制时，可能触及另一侧。请注意画笔大小。

画笔详细设置

  • 上方“～”笔画为当前设置的示例，修改设置后会即时变化。
  • 大小基准：按辅助工具选择“遵循设置／固定纹理大小／随屏幕变化”。固定纹理大小时，无论视角远近，纹理上的笔画粗细相同。遵循设置时使用 文件 → 偏好设置 → 绘制 中的“画笔大小单位”（屏幕 px／纹理 px）。
  • 笔尖：圆形、方形、平笔、铅笔、粉笔、喷雾、水彩、毛笔、闪光、星星、心形及附带31个笔尖。“加载”可使用图片（白底黑色形状），或其他绘画软件的画笔文件（.abr、.gbr、.gih 及打包的 .zip）。
  • 累积绘制：同一位置叠加越多，颜色越浓（适合喷枪）。
  • 渲染模式：可使用正片叠底、滤色、叠加等26种模式绘制。还提供“绘制在后方（仅未绘制部分）”“变亮”“变暗”。
  • 防抖类型：平滑（延迟跟随）／1€（慢画时更强地抑制抖动，快画时减少延迟）／牵引（与笔尖保持少许距离跟随，抑制手部抖动）。
  • 入笔/出笔：让笔画起点和终点变细。出笔会在抬笔时将末端重绘为细线，绘制期间不会增加延迟。
  • 动态：速度控制粗细、粗细和浓度变化、倾倒控制粗细与浓度、倾斜和扭转旋转笔尖（倾倒和扭转仅支持发送相应数据的数位笔）。
  • 笔压曲线：分别移动粗细、浓度曲线上的点来调整响应。
  • 纸张纹理：纸张或画布纹理影响绘制浓度（附带6张、15种图案、自选图片）。贴合表面，不随视角移动。
左侧“画笔大小”面板可一键选择常用大小。以圆形和数字的小缩略图显示，缩窄面板时可收成一列。点击最后的铅笔图标或右键，可添加、移除当前大小。[ ] 也可改变大小（1〜1000）。
3D 绘画方式：“沿表面绘画”可减少斜面上的笔画拉伸，v1.1.0 中为未设置画笔的默认值。“匹配屏幕”从摄像机投影，斜面上的笔画会拉伸。可按辅助工具选择。保留已保存设置，不改变 UV 视图绘制方式。

模糊、涂抹、混色

  • 模糊：平滑划过的位置。“模糊范围”控制影响范围。
  • 涂抹：拖拽并延伸颜色。
  • 混色：拾取划过位置的颜色并带走，与前景色混合绘制。“颜料量”为0时，仅融合已有颜色。提高“颜色延伸”可延伸更远。
均在 3D 上计算，因此不会在 UV 接缝断开。模糊和涂抹也可用于 UV 区域（混色仅用于 3D 区域）。

填充、渐变、图形

  • 填充 UV 岛：填满点击的整个 UV 岛。整个材质：填满整个材质。
  • 填充封闭区域：点击线条围成的区域，在该 UV 岛内填充颜色相近的连通部分。可设置参考（所有图层／选中图层）、容差、“封闭间隙”（在线条断口停止）、“扩展”（延伸到线条下方）。
  • 多边形填充：用前景色填满划过的面。
  • 渐变：在 3D 视图从起点拖到终点。“也绘制背面和被遮挡的面”（默认开启）时，沿点击与松开位置连接的 3D 线，也影响背面和内侧面（如从发根到发梢）。Shift 以45°为步进。
  • 图形：绘制直线、矩形、椭圆、多边形（3〜12边），可填充或仅画边框。Shift 可画正方形、正圆；开启“从中心绘制”时起点为中心。曲线在拖动松开后移动来弯曲，再点击确认。曲线（连接点）每次点击添加点，双击或按 Enter 确认（“关闭”可连接成环并填充）。
在描线图层下方建立上色图层，可保留清晰线条。

使用多种颜色与透明度的方法见颜色与透明度渐变。

颜色与透明度渐变

渐变绘制工具从 Lite 起可用。在工具属性的“色彩”中选择“颜色和不透明度色标”，不再限于两色，可使用颜色与透明度组合的渐变。仍可选择“前景色→背景色”“前景色→透明”。

  1. 选择预设，或点击色带空白处添加色标。支持2〜32个点。
  2. 选中色标，修改颜色、位置和不透明度。也可拖动改变位置。再次点击选中点或双击可选色。
  3. 不需要的点可通过“删除色标”、Delete或拖离色带删除。还可使用“使用前景色”“均匀分布”“左右互换”。
  4. 240种预设可按分类和名称查找，包含透明渐变。列表可滚动。输入名称并点击“保存当前”即可保存自定义预设。
  5. 选择线性或圆形，在 3D 视图或 UV 上从起点拖到终点绘制。
渐变不透明度为0的区域会保留下方颜色。要擦除已绘制内容，请使用使用透明色绘画。要按高度或点距离给整个模型上色，Pro 的渐变烘焙很方便。

选择颜色、吸管

  • 色彩面板：用上方按钮切换5种选色方式（色环＋方块、色环＋三角、方块＋色相条、色盘＋明度条、滑块）。
  • 颜色值面板：前景色／背景色、HEX、屏幕取色、RGB／HSV 数值、不透明度。
  • 最近使用的颜色：最近实际绘制或拾取的12种颜色。点击设为前景色。
  • X 可交换前景色与背景色。
  • 吸管：Alt 按住时可从任意工具临时切换为吸管。
  • 从屏幕取色（Shift＋I）：可拾取屏幕任意位置的颜色，包括窗口外。
  • 颜色集：点击色样设为前景色。“＋当前前景色”可添加，拖动可排序。删除色样可撤销，也可读写 .gpl 调色板。
  • 参考图：打开、拖入、粘贴（Ctrl＋V）后显示，可用吸管取色。上方放大镜可缩放，“100%”恢复原大小，四角图标适应全部（仅用数位笔也可操作）。

使用透明色绘画（用相同画笔擦除）

颜色值面板的棋盘格按钮或 C 可切换透明色。用钢笔、毛笔、画笔集等画笔擦除选中绘制图层的颜色，保留笔尖形状、硬度、笔压和流量。

再次按 C 或选择普通前景色可恢复。锁定透明像素的图层不能擦除，需要先解除锁定。

透明色用于让画笔擦除，并非将所有工具变为擦除工具。

左右对称绘制

  1. 点击 3D 视图左上角的 X（左右）（也可按M 键）。
  2. 继续绘制时，另一侧也会出现相同内容。
  • Y（前后）、Z（上下）也可同时使用（X 与 Z 同时开启时影响4个位置）。
  • 通过 ▼ 将镜像中心设为“模型中心”“原点”“指定”。“指定”可输入数值（cm）或“在模型上点击以设定”。开启“吸附到顶点”时使用点击处最近的顶点位置。也可通过 3D 右键 →“对称绘制”→“将此处设为对称中心”指定。
  • “模型中心”的左右位置为形状最对称的位置（即使单侧有装饰或道具，也会定位到身体中央）。
  • ▼ 中的“对称对应点的搜索范围”（0〜3%，默认1%）：对于两侧形状略有差异的衣服，镜像位置无对应面时，会在此范围内找到最近的面作为另一侧绘制。
  • 工具属性顶部和UV 区域标题也有“对称 X、Y、Z”（与 3D 左上角同步）。不支持对称的工具不会显示此栏，3D 左上角 X、Y、Z 显示斜线。对于混色等仅在 UV 区域不支持的工具，会说明原因。

各工具支持情况（○ 支持、△ 有条件、× 不支持、― 无关）。在点击位置或绘制形状的镜像位置执行相同操作，只需撤销一次。

弹出调色板（仅用数位笔操作）

  • 在 3D 或 UV 上按数位笔侧键，不移动就松开，可在当前位置弹出圆形调色板（拖动仍用于旋转）。
  • 外圈：常用辅助工具（“＋”添加当前辅助工具，长按或右键移除，最多10个）。内圈：用色相环和方块选前景色，上方小圆为最近颜色，下方标签可上下拖动调整画笔大小。
  • 点击调色板外侧或按Esc 关闭。鼠标使用时，在 文件 → 偏好设置 → 操作，将“右键”设为弹出调色板（也可从右键菜单顶部“显示弹出调色板”打开）。

服装和道具也能绘制

不仅是虚拟形象的身体，服装和道具也可用同样工具绘制。以下为在 PetaNuri3D 中打开ののつよ系列服装、道具的效果。

若只想在局部（UV 岛）画线，请用选区“按 UV 岛选择”选中，再用“交叉”与条带形状相交后绘制（选区）。
