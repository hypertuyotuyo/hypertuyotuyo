从 Unity 绘制、AI 联动

在 Unity 中选择虚拟形象并启动 PetaNuri3D，就能直接绘制。保存后，绘制的内容会反映到 Unity。也可以通过 AI（MCP 客户端）操作 PetaNuri3D。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

Unity 联动和 AI 联动在任何版本（Lite、Standard、Pro）中都可以使用。只有 AI 联动的 run_js 需要 Pro 版本（版本对比）。

先看这几点
  1. 仅首次：把 PetaNuri3D 文件夹中的 unity\PetaNuri3D-Unity.unitypackage 导入 Unity（详细说明）。
  2. 在 Unity 中选择虚拟形象，点击菜单栏的“ぺたぬり3D”→“ぺたぬり3D で塗る”（即“用 PetaNuri3D 绘制”，详细说明）。
  3. 绘制后，在 PetaNuri3D 或 Unity 中按 Ctrl+S。绘制的内容就会反映到 Unity（详细说明）。
  4. 如果更改了 PetaNuri3D 的存放位置，请在 Unity 中重新选择 PetaNuri3D 的位置（详细说明）。
  5. 要通过 AI 操作，请在 文件 → 偏好设置 →“AI 联动”中开启（详细说明）。

从 Unity 启动绘制

无需导出 FBX，就能直接绘制 Unity 中的虚拟形象。不会改写原来的 FBX、材质、纹理和 prefab。

  • 适用环境：Unity 2022.3（制作 VRChat 虚拟形象所用的 Unity）。只能与同一台电脑上的 Unity 联动。
  • 只能绘制 FBX 的网格（不是 FBX 的形状不会显示在 PetaNuri3D 中）。

仅首次：在 Unity 中安装插件

  1. 打开 PetaNuri3D 文件夹中的“unity”文件夹。里面有 PetaNuri3D-Unity.unitypackage。
  2. 保持 Unity 项目打开，将 PetaNuri3D-Unity.unitypackage 拖到 Project 面板（也可以用 Assets →“Import Package”→“Custom Package”）。
  3. 在弹出的窗口中点击“Import”。
  4. 上方菜单栏出现“ぺたぬり3D”（即 PetaNuri3D）就表示安装好了。

插件会安装到 Assets/PetaNuri3D。它只在编辑器内运行，不会包含在上传的虚拟形象中。

绘制

  1. 在 Unity 中，选择 Hierarchy 里的虚拟形象（场景中的对象），或 Project 里的 prefab。
  2. 点击菜单栏的“ぺたぬり3D”→“ぺたぬり3D で塗る”（意为“用 PetaNuri3D 绘制”）。Hierarchy 和 Project 的右键菜单中也有同名项目。Unity 的菜单名称只以日语显示。
  3. 仅首次会出现“Choose the PetaNuri3D program”（请选择 PetaNuri3D 的位置）的提示，请选择 PetaNuri3D 文件夹中的 PetaNuri3D-win_x64.exe。
  4. PetaNuri3D 启动，并显示 Unity 中的模型。像平时一样绘制即可。
  • 纹理集按材质的主纹理生成。使用同一纹理的材质会合为 1 个纹理集，绘制的内容会反映到所有这些材质。
  • 原来的纹理会直接作为底色。分辨率也与原纹理相同（Lite 最高 2048）。没有纹理的材质，从材质的颜色开始绘制。
  • 在 Unity 中隐藏的对象，在 PetaNuri3D 中也是隐藏的（可在“对象”面板中显示）。
  • 从 Unity 启动的 PetaNuri3D 是专用于绘制的界面。标题为“PetaNuri3D — Unity 联动（虚拟形象名称）”，不会出现新建、打开工程文件、最近使用的文件、重新加载模型和另存为。
  • 再次点击“Paint with PetaNuri3D”（用 PetaNuri3D 绘制），已打开的 PetaNuri3D 会显示到最前面（不会启动第二个）。
  • Pro lilToon 材质如果使用了“主颜色 2nd”“主颜色 3rd”，其图像（包括 PSD）、蒙版、混合模式和颜色也会一并导入，并放入图层面板中对应的文件夹（主颜色 2nd、3rd）。Lite 和 Standard 不会导入（在 Unity 中仍按原来的 2nd、3rd 显示）。

PetaNuri3D 窗口（推荐初次使用者）

在 Unity 菜单栏的“ぺたぬり3D”→“ぺたぬり3D の窓を開く”（意为“打开 PetaNuri3D 窗口”）中，会打开一个可以从上到下逐项确认、再开始绘制的窗口。

栏内容
1. PetaNuri3D program (exe)（PetaNuri3D 的位置）显示当前位置以及能否使用。有“Choose…”（选择）、“Search”（查找）、“Show in Explorer”（打开位置）（重新选择位置）
2. What to paint (prefab or scene avatar)（要绘制的对象）把 prefab 或虚拟形象拖到栏中，或选中后点击“Use selection”（放入所选对象）。会显示可绘制的网格数量和纹理集。无法绘制时也会显示原因
3. Paint（绘制）“Paint with PetaNuri3D”（用 PetaNuri3D 绘制）按钮，以及当前状态（Not connected：未连接、Starting：启动中、Connected：已连接、Disconnected：已断开、Saved：已保存、Finished：已结束）。绘制期间还有“Bring PetaNuri3D to front”（把 PetaNuri3D 调到前面）、“Save and show in Unity”（保存并映射到 Unity）、“Finish”（结束）、“Revert and finish”（恢复原样并结束）、“Show painted files”（查看已绘制物的文件夹）
4. Where files go / Settings（保存位置与设置）绘制内容的保存位置（Assets/PetaNuri/）、“Open Preferences”（打开 Preferences）、语言切换

窗口最下方会显示插件的版本（与 PetaNuri3D 的版本号相同）。

将绘制内容反映到 Unity、结束

绘制期间，Unity 中的外观不会改变。在 PetaNuri3D 或 Unity 中保存后，当时绘制的内容才会反映到 Unity。

  1. 在 PetaNuri3D 或 Unity 中按 Ctrl+S。两边都会保存。
  2. 在 Unity 的场景视图中，确认绘制的内容已经反映出来。
生成的内容位置（在 Unity 项目中）
工程文件Assets/PetaNuri/（名称）/（名称）.petanuri
绘制后的纹理Assets/PetaNuri/（名称）/Textures/ 中的 PNG（仅限绘制过的纹理。导入设置与原纹理保持一致）
材质Assets/PetaNuri/（名称）/Materials/（原材质的副本，使用绘制后的纹理）
主颜色 2nd／3rd ProTextures/ 中的 _main2nd.png、_main3rd.png（仅在修改了从 Unity 导入的内容时生成。蒙版不会写回）
  • 从 Project 中的 prefab 开始时，会在 Assets/PetaNuri/（名称）/ 中创建该 prefab 的变体（Prefab Variant），并在变体上绘制。上传时，请把生成的“（名称） (PetaNuri)”prefab 放进场景使用。
  • 下次再点击“Paint with PetaNuri3D”（用 PetaNuri3D 绘制），会打开工程文件，保留图层并接着绘制。
  • 发送给 Unity 联动的纹理，与导出的 PNG 在像素上完全一致。

结束

  • 关闭 PetaNuri3D 即结束联动。关闭时选择“保存并退出”，会先把绘制的内容发送到 Unity，再关闭。
  • 绘制的是场景中的虚拟形象时，Unity 会询问“Keep”（直接使用）或“Revert to original”（恢复原样）。即使选择“Revert to original”，Assets/PetaNuri/ 中的内容也会保留，再次绘制即可接着来。也可以用 Unity 的撤销（Ctrl+Z）重新来过。
  • 一次也没保存就关闭时，不会询问，直接恢复原样，并删除已生成的内容。
  • 先关闭 Unity 时，会询问“Save and Close”（保存并关闭）、“Keep Open”（不关闭）或“Close Without Saving”（不保存并关闭）。

注意事项

  • 切换材质的动画（如换衣服颜色）指向的是原来的材质。使用绘制后的内容时，请把动画中的材质也换掉。
  • 请不要在两个 Unity 中同时绘制同一个虚拟形象。
  • Unity 重新加载脚本期间（编译、开始 Play 时），连接会短暂中断，但很快会重新连上。

操作不顺利时

  • 画了但 Unity 里的外观没有变化：保存时才会反映。请在 PetaNuri3D 或 Unity 中按 Ctrl+S。
  • 点击“Paint with PetaNuri3D”（用 PetaNuri3D 绘制）后没有启动，或打开了英文页面：所选的 exe 不对。请通过重新选择 PetaNuri3D 的位置，选择 ZIP 解压后文件夹中的 PetaNuri3D-win_x64.exe。
  • 提示“The PetaNuri3D program files (resources.neu) are not next to the selected file”（PetaNuri3D 的内容不存在）：所选 exe 旁边没有 resources.neu。请重新选择已完整解压的文件夹中的 exe。
  • 提示“Unity 插件与 PetaNuri3D 的版本不一致”：请重新导入 PetaNuri3D 附带的 PetaNuri3D-Unity.unitypackage。要传递主颜色 2nd／3rd，需要同一版本的插件。
  • 提示“All link ports (47360-47369) are in use”（用于连接的端口已全部被占用）：请先关闭其他 Unity，再点击一次。
  • 提示“The selection has no paintable meshes (FBX meshes)”（所选对象中没有可绘制的 FBX 网格）：请选择含有 FBX 网格的 prefab 或虚拟形象。
  • 仍然连不上：请重新启动 Unity 和 PetaNuri3D。详情请参阅 PetaNuri3D 的 unity 文件夹中的“Unity連携の使い方.txt”。

重新选择 PetaNuri3D 的位置

Unity 插件会记住最初选择的 PetaNuri3D-win_x64.exe 的位置。移动了 PetaNuri3D 文件夹，或把新版本解压到了其他文件夹时，需要重新选择位置。

  1. 点击 Unity 菜单栏的“ぺたぬり3D”→“ぺたぬり3D の窓を開く”（意为“打开 PetaNuri3D 窗口”）。
  2. 点击“1. PetaNuri3D program (exe)”（PetaNuri3D 的位置）中的“Choose…”（选择）。
  3. 选择新位置的“PetaNuri3D”文件夹中的 PetaNuri3D-win_x64.exe。
  4. 栏下方显示“Found.”（已找到）就完成了。如果显示“No file at this location”（此位置没有文件），请重新选择。
  • 点击“Search”（查找），会在桌面、下载、文档、Program Files 以及各驱动器根目录下名为“PetaNuri3D”的文件夹中查找。点击找到项的“Use this”（使用此项），就会把它设为当前位置。
  • 也可以在 Unity 的 Edit →“Preferences”→“PetaNuri3D”中的“PetaNuri3D program”（PetaNuri3D 的位置）里修改。
  • 记住的位置上没有 exe 时，点击“Paint with PetaNuri3D”（用 PetaNuri3D 绘制）会出现“Choose the PetaNuri3D program”（请选择 PetaNuri3D 的位置）的提示。
  • 用 setup.exe 安装时的位置是 %LOCALAPPDATA%\Programs\PetaNuri3D（安装与启动）。
不能选择 ZIP 中的 exe 或其他 exe。下载的 ZIP 请先右键 →“全部提取”，再选择解压后文件夹中的 exe。

通过 AI 操作（MCP）

可以通过 AI（MCP 客户端）操作 PetaNuri3D。绘制、颜色与画笔、视角、图层、屏幕截图、PNG 导出等，都可以拜托 AI 完成。

  1. 打开 文件 → 偏好设置，点击左侧的“AI 联动”。
  2. 勾选“使用 AI 联动（MCP）”。开启状态会保留到下次启动。
  3. 点击“连接方法”下“设置示例”中的“复制”。
  4. 在 AI 一侧（MCP 客户端）的 MCP 设置中，粘贴复制的内容并注册。
  5. 开始使用 AI。连接成功后，屏幕下方会显示“AI 联动：已连接到 MCP 服务器”。

连接方式的具体内容

项目值
名称petanuri3d
命令node（需要 20 或更高版本）
参数<PetaNuri3D 文件夹>\mcp\server.mjs（窗口中会显示实际位置）
  • 作为 stdio 服务器注册。服务器由 AI 一侧启动，PetaNuri3D 会自动连接到同一台电脑内（127.0.0.1 的 47321–47330 号端口）。
  • “状态”会显示 ON 或 OFF，以及是否已连接。点击“立即查找”会马上尝试连接。
  • 无论有多少个 AI 会话，都会全部连接。同时打开了 2 个 PetaNuri3D 时，可以在 AI 一侧用 list_instances 选择发送目标。
  • 无法从其他网站连接。不使用时，请取消勾选“使用 AI 联动（MCP）”，将其设为 OFF。

可以拜托 AI 做的事

分类命令
查看状态get_state（当前状态）、list_layers、screenshot（截取 3D 视图）、pick（屏幕上某一点有什么）、uv_to_screen、read_pixel（纹理的 1 个像素）
打开、导出open_fbx（打开 3D 模型）、export_png
绘制select_tool、set_color、set_brush、stroke（画 1 条线）、fill_at（填充 UV 岛）、pick_color（吸管）
图层与纹理集add_layer、select_layer、set_layer、select_set
视角与模式view（视角）、set_mode（切换绘制/姿势）
撤销undo、redo
Prolist_materials、material_edit（材质操作）、bake_ao（烘焙 AO）、run_js（见下）

允许 run_js Pro

run_js 是在应用内运行任意程序（JavaScript）的命令。仅开启 AI 联动时，它不会运行。

  1. 打开 文件 → 偏好设置 →“AI 联动”。
  2. 勾选“run_js”小节中的“允许 run_js（执行任意程序）”。
在应用（exe）中，甚至可以删除文件、执行命令。请只注册可信任的 AI 客户端。Standard 版不显示 run_js 小节。

操作不顺利时

  • AI 提示“无法连接”：多半是“使用 AI 联动（MCP）”处于 OFF。开启后几秒内就会连上。
  • 提示“找不到此文件”：请把发行包中的 mcp 文件夹放在与应用（exe）相同的文件夹中。
  • AI 一侧的服务器无法启动：请确认已安装 node（20 或更高版本）。
  • run_js 被拒绝：只有在 Pro 版本中勾选了“允许 run_js（执行任意程序）”后才能运行。
  • AI 说无法绘制：处于姿势模式时，不能使用 stroke 和 fill_at。请切换回绘制模式。
