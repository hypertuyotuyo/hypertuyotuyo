PetaNuri3D ／ 使用手册 ／ 从 Unity 绘制、AI 联动

从 Unity 绘制、AI 联动

在 Unity 选择虚拟形象并启动 PetaNuri3D，即可绘制。Lite、Standard、Pro 均可使用。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

本页内容
  • 从 Unity 启动绘制
  • AI 联动（MCP）

从 Unity 启动绘制

  • 在 Unity 选择 prefab（虚拟形象等），点击“ぺたぬり3D で塗る”（用 PetaNuri3D 绘制），即可启动 PetaNuri3D 并绘制该模型。
  • 绘制内容会在PetaNuri3D 或 Unity 保存时 反映到 Unity 场景，纹理存入 Unity 项目（绘制期间 Unity 外观不变）。
  • 适用于 Unity 2022.3（制作 VRChat 虚拟形象的 Unity），仅连接同一电脑上的 Unity。

仅首次需要：在 Unity 安装插件

  1. PetaNuri3D 目录的“unity”文件夹中有 PetaNuri3D-Unity.unitypackage。
  2. 保持 Unity 项目打开，将 PetaNuri3D-Unity.unitypackage 拖到 Project 面板（也可 Assets →“Import Package”→“Custom Package”）。
  3. 点击“Import”，上方菜单栏出现“ぺたぬり3D”即安装成功（仅在编辑器内运行，不加入上传的虚拟形象）。

绘制

  1. 在 Unity 选择 Hierarchy 中的虚拟形象（场景对象），或 Project 中的 prefab。
  2. 点击菜单栏“ぺたぬり3D”→“ぺたぬり3D で塗る”（用 PetaNuri3D 绘制，右键也有）。仅首次需选择 PetaNuri3D 文件夹中的 PetaNuri3D-win_x64.exe。
  3. PetaNuri3D 启动并显示 Unity 模型。按材质主纹理建立纹理集，原纹理直接作为底色（分辨率保留原值，Lite 最高 2048）。
  4. 在 PetaNuri3D 或 Unity 保存（Ctrl＋S）时，两边均会保存，绘制内容反映到 Unity。
  • 工程文件位于 Assets/PetaNuri/（名称）/（名称）.petanuri；纹理为 Assets/PetaNuri/（名称）/Textures/ 中的 PNG（导入设置与原纹理一致）；材质使用同目录 Materials/ 中的副本。
  • 不会改写原 FBX、材质、纹理或 prefab。从 Project prefab 开始时，会创建 Prefab Variant，并绘制该变体。
  • 从 Unity 启动的 PetaNuri3D 为专用绘制界面（不显示新建、打开工程文件、重新加载模型、另存为）。
  • 关闭 PetaNuri3D 后联动结束，Unity 会询问“保持使用／恢复原效果”（绘制场景内虚拟形象时）。
  • 再次点击“ぺたぬり3D で塗る”（用 PetaNuri3D 绘制），会打开工程文件并继续绘制。
详细步骤或连接问题请参阅 PetaNuri3D 的 unity 文件夹中“Unity連携の使い方.txt”。
Unity 联动插件的版本（与 PetaNuri3D 相同）显示在 Unity 中 PetaNuri3D 窗口下方及连接时的通知中。通过 Unity 联动发送的纹理与导出的 PNG 逐像素一致。

AI 联动（MCP）

  • 可从 AI（MCP 客户端）操作 PetaNuri3D（绘制、颜色与画笔、视角、图层、截图、导出 PNG 等）。
  • 默认 OFF。使用时在 文件 → 偏好设置 →“AI 联动”开启“使用 AI 联动（MCP）”。
  • 在 MCP 客户端注册为 stdio 服务器：命令 node，参数 <PetaNuri3D 文件夹>\mcp\server.mjs（node v20 及以上）。配置示例在同一区域“连接方法”中，可用“复制”获取。
  • 由 AI 侧启动服务器，PetaNuri3D 会自动连接本机固定端口，连接成功在下方提示区通知。其他网站无法连接。
  • run_js（在应用中运行任意程序的命令）仅 Pro 可用。仅开启联动不会运行，必须勾选“允许 run_js（执行任意程序）”。请仅注册可信 AI 客户端。
