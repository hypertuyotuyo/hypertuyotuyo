PetaNuri3D ／ 使用手册 ／ 最终效果与 lilToon 材质

最终效果与 lilToon 材质 Pro

可在与 lilToon 相同计算方式的效果中检查、绘制（阴影、MatCap、边缘光、轮廓线等），并将设置一同导出为材质。本页功能仅 Pro 可用。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

Lite、Standard、Pro 和 Pro 升级包均已在 BOOTH 提供。

“最终效果（lilToon 外观）”为 β 版。计算方式与 lilToon（2.3 系列）相同，但与 Unity 中的显示可能略有差异。

本页内容
  • 查看“最终效果”
  • 绘制阴影色、蒙版等（绘制目标）

  • 加载 lilToon 材质
  • 导出材质

查看“最终效果”

  • 用 3D 视图左上4个显示方式图标最右侧（也可右键 → 显示）切换为“最终效果”。
  • 阴影（阴影色1、阴影色2、边界色）、法线贴图、MatCap、MatCap 2nd、边缘光、逆光、边缘阴影、自发光、轮廓线采用与 lilToon（2.3 系列）相同方式计算。
  • 光照方向在显示方式 ▼ 或“材质”面板“显示与光照”调整。“光跟随相机”会保持相同受光角度，便于转动视角绘制。
  • “材质”面板参数名称与 lilToon 设置界面一致。“复制到其他材质”可让所有材质采用相同设置。
MToon效果预览（Pro，测试版）：在材质 → 显示与光照中选择MToon，可参考从VRM0/VRM1读取的阴影、边缘光、发光和轮廓绘制。调整支持撤销/重做并保存在项目中。
此功能用于绘制中的效果预览，不支持MToon材质完整往返导出，PNG/PSD和现有lilToon材质导出保持不变。UV动画静态显示，不支持的UV设置会提示原因并返回普通显示。

绘制阴影色、蒙版等（绘制目标）

  1. 用面板“绘制：”按钮（也可右键 → 绘制目标）选择目标。
  2. 图层面板主颜色上方会创建目标文件夹（如“阴影色 1”），并选中内部图层。与普通图层一样，可添加、删除、叠加、蒙版、剪贴。
  3. 用熟悉的钢笔、毛笔、填充、渐变、模糊、滤镜直接绘制。
  4. 点击上方中央“返回颜色”（或点击文件夹外图层），恢复普通颜色绘制。
绘制目标如何生效？
阴影色1、阴影色2绘制位置的阴影会变为该颜色（如肌肤红润、头发阴影的蓝色）
阴影蒙版白＝添加阴影、黑＝不添加阴影
阴影 AO越黑越容易出现阴影（领口、头发内侧、服装重叠处）
法线贴图按高度绘制。白色凸起、黑色凹陷（适合服装褶皱、缝线、发丝，凹凸工具也可）
MatCap 蒙版、轮廓线宽度白＝生效、黑＝不生效
边缘光颜色、自发光纹理乘以绘制颜色／仅绘制区域以所绘颜色发光
  • 还可绘制阴影色3、阴影模糊蒙版、色调调整蒙版、Alpha 蒙版、自发光蒙版、自发光2nd、逆光颜色、边缘阴影蒙版、轮廓线颜色、法线贴图2nd 蒙版和闪粉颜色（右键 → 绘制目标 → 其他蒙版）。
  • 仅读取亮度的绘制目标可通过上方中央的白、灰、黑切换。“仅查看此项”只显示该目标图像。“删除”恢复未绘制状态。
  • 一个材质的最终效果显示最多同时使用16张纹理（超出时会提示“无法再添加”）。

主颜色2nd、主颜色3rd

  • 在“材质”面板“主颜色 2nd”“主颜色 3rd”开启“启用”，图层面板顶部会创建同名文件夹。
  • 仅文件夹内图层成为主颜色2nd（3rd）纹理（不会混入主图像）。叠加方式（颜色、不透明度、混合模式、蒙版）在面板设置。
  • 导出时成为独立图片（<名称>_main2nd.png 等），材质中会分配到 lilToon“主颜色 2nd/3rd”。

拆分材质

  • 默认每个纹理集有一个同名材质。不拆分时没有变化。
  • 使用同一纹理（绘制图像），也可按对象修改阴影色、MatCap、边缘光、轮廓线等设置（例如保留头发纹理，仅让兽耳阴影变红）。
  • 拆分方式：右键对象面板行或 3D 中该对象 →“仅此对象使用另一个材质”。通过“分配材质”选择所用材质。
  • “材质”面板上方列表可添加、改名、删除、排序（顺序＝重叠处优先级）。在 3D 点击的位置会切换材质面板，下方状态栏显示“材质：名称（纹理集名）”。
  • 导出时每个材质生成一个 .mat（指向同一纹理）。

加载 lilToon 材质

  • 文件 → 导入 → 导入 lilToon 材质，选择 .mat 或包含它的 .unitypackage（也可拖入窗口）。也可在新建“起始内容”选择。
  • 会导入绘制模式、阴影、法线贴图、MatCap、边缘光、自发光、轮廓线、主颜色2nd／3rd 等设置及纹理（主颜色→底色，阴影色、蒙版等→绘制目标）。
  • 从 .mat 附近的项目寻找纹理。未找到的纹理会列出，需手动选择图片。
  • PetaNuri3D 未模拟的设置（光泽、毛发、模板等）会保留原值，导出时原样恢复。
  • 导出时保留原 .mat 的位置和 ID，仅更新修改后的设置和重绘纹理。

导出材质

  1. 选择 文件 → 导出 → 导出材质（也可用面板“导出”）。
  2. 选择导出材质、文件夹名、导出扩边。
  3. 导出为 .unitypackage，或直接写入文件夹（项目 Assets）。.unitypackage 可双击或拖入项目导入。
  • 包含材质（.mat）、主颜色图片、阴影色、蒙版、法线贴图、MatCap 图片，且已完成分配。
  • 同一工程使用相同文件夹名重新导出，会覆盖之前导入的内容（模型材质分配不变）。
导出的是 lilToon 材质。请先在目标项目安装 lilToon（否则材质会显示粉色）。
