PetaNuri3D ／ 使用手册 ／ 最终效果与 lilToon 材质

最终效果与 lilToon 材质 Pro

可以一边看着与 lilToon 相同计算的外观（阴影、MatCap、边缘光、轮廓线等）一边绘制。还可以绘制阴影色和蒙版，连同设置一起作为 lilToon 材质交给 Unity。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

这是 Pro 的功能。在 Lite 中，菜单和图标上会带锁形图标，“材质”面板里只显示说明。在 Standard 中不显示入口（版本对比）。“最终效果”是测试版，与 Unity 中的外观可能略有差别。

先看这几点
  1. 用 3D 视图左上角的显示方式图标切换为“最终效果”，就能以 lilToon 的外观绘制（详情）。
  2. 阴影、边缘光、轮廓线等设置，在右侧的“材质”面板中更改（详情）。
  3. 绘制阴影色或蒙版时，用面板中“绘制：”的按钮选择绘制目标。完成后点击“返回颜色”（详情）。
  4. 已有的 lilToon 材质，通过 文件 → 导入 → 加载 lilToon 材质，可连同设置一起载入（详情）。
  5. 交给 Unity 时，通过 文件 → 导出 → 导出材质 做成 .unitypackage（详情）。

边确认 lilToon 外观边绘制

把显示方式设为“最终效果”后，绘制的颜色上会叠加与 lilToon 相同计算的阴影和光。带去 Unity 之前，就可以看着最终效果来绘制。

  1. 在 3D 视图左上角的 5 个显示方式图标中，点击从右数第 2 个（最终效果）。
  2. 像平常一样绘制。绘制的颜色上会叠加阴影、边缘光、轮廓线等。
  3. 只想确认绘制的颜色时，切回最左边的“保持绘制颜色”。
  • 其他入口：显示 → 显示方式 →“最终效果（lilToon、MToon，测试版）”，3D 视图右键 → 显示，“材质”面板中的“显示最终效果（lilToon，测试版）”。
  • 显示的内容：阴影（阴影色 1、阴影色 2、阴影色 3、边界颜色）、法线贴图、MatCap、MatCap 2nd、边缘光、逆光、边缘阴影、自发光、轮廓线、反射、闪粉、各向异性反射、抖动、溶解、视差、AudioLink、色调调整。

在“材质”面板中更改设置

设置按材质分别保存。项目名称与 lilToon 设置界面的叫法一致。每次更改都可以撤销。

  • 未体现在显示中的设置（轮廓线的方向、主颜色 2nd/3rd 的溶解、用 AudioLink 移动顶点等），其数值和图像也会读写到 .mat 中。
  • 设置、绘制目标的内容、加载的 MatCap 图像，会保存到工程文件（.petanuri）中。

更改光照方向

  • 在“材质”面板“显示与光照”中的“光的左右”“光的高度”“光的强度”更改。也可以通过显示方式图标旁的 ▼ 更改（光照方向）。
  • 开启“光跟随相机”后，即使旋转视角，光照方式也保持不变，更便于绘制。关闭后，光固定在模型上。
  • 这个光仅用于确认外观。导出的材质的光，由在 Unity 中放置的光决定。

用 MToon 外观确认

可以一边用 MToon 外观确认 VRM 模型一边绘制（显示用预览，测试版）。

  1. 在“材质”面板的“显示与光照”中点击“MToon”。
  2. 点击“显示最终效果（MToon，测试版）”。
  3. 一边调整 MToon 用的颜色、阴影位置、清晰度、环境光、边缘、自发光、轮廓，一边绘制。
  • 如果 VRM0、VRM1 中有 MToon 设置，会以其颜色、阴影、边缘、自发光、轮廓和辅助图像为起点。没有的模型，则以标准外观开始。
  • “恢复原始 MToon 设置”只恢复外观的调整。绘制的图层不会消失。点击“lilToon”会回到 lilToon 的外观。
  • 调整可以撤销、重做，也会保存到工程文件。
MToon 只是用来确认的显示。PNG、PSD 按绘制的颜色导出，材质导出仍是 lilToon 用的。不会导出 MToon 材质或 VRM。

操作不顺利时

  • “最终效果”图标带锁，或没有该图标：这是 Pro 的功能。Lite 中带锁，Standard 中不显示。
  • 与在 Unity 中看到的略有不同：因为是测试版，光线或背景的差异可能造成区别。光仅用于确认，在 Unity 中由放置的光决定。
  • 切换为 MToon 后，又回到了普通显示：不支持更改了主图像的位置、倍率、旋转的 UV 设置，以及使用 UV0 以外 UV 的图像。返回时会告知原因。UV 动画会停止后再显示。
  • 想变透明的地方没有镂空：把“基本”中的渲染模式设为“镂空”或“半透明”。“不透明”下不会读取透明度。

绘制阴影色、蒙版、凹凸（绘制目标）

不只是主颜色，阴影色、阴影蒙版、法线贴图（凹凸）、自发光等图像，也能用平常的笔来绘制。每个绘制目标，会在图层面板中生成一个文件夹。

  1. 点击“材质”面板各分区的“绘制：”按钮，选择绘制目标（也可以通过右键 → 绘制目标 选择）。
  2. 在图层面板的主颜色上方，会生成该绘制目标的文件夹（例如“阴影色 1”），并选中其中的图层。
  3. 用平常的钢笔、毛笔、填充、渐变、模糊、滤镜来绘制。
  4. 点击 3D 视图上方中间的“返回颜色”，会回到普通的颜色绘制。点击文件夹外的图层也会返回。
绘制目标作用
阴影色 1、阴影色 2绘制处的阴影会变成该颜色（肌肤的红润、头发阴影的蓝调等）。未绘制处，是原色乘以设置中的阴影色
阴影蒙版白＝添加阴影，黑＝不添加阴影
阴影 AO越黑越容易出现阴影（脖颈、头发内侧、衣服重叠处）。烘焙 AO 后，也能写入这里
法线贴图按高度绘制。白色凸起、黑色凹陷、灰色平坦（用于衣服褶皱、缝线、发丝。绘制法线贴图）
MatCap 蒙版、MatCap 2nd 蒙版、轮廓线宽度白＝生效，黑＝不生效
边缘光颜色乘上绘制的颜色（黑色则消失）
自发光纹理只有绘制处会以绘制的颜色发光（乘上设置中的“自发光颜色”）

其他绘制目标

右键 → 绘制目标 → 其他蒙版（阴影色 3、色调调整、闪粉等）中也有列出。使用对应功能时可以绘制。

  • 阴影：阴影色 3、阴影模糊蒙版（绘制处的阴影交界更柔和）
  • 颜色与透明：色调调整蒙版（只修正绘制处）、Alpha 蒙版（绘制透过的方式）
  • 自发光：自发光蒙版、自发光 2nd 纹理、自发光 2nd 蒙版
  • 边缘与轮廓：逆光颜色、边缘阴影蒙版、轮廓线颜色
  • 质感：法线贴图 2nd 蒙版、闪粉颜色（黑色则不出现闪粉）、光滑度、金属度（白＝按设置，黑＝0）、反射颜色、各向异性反射遮罩、各向异性反射噪声
  • 其他：消融遮罩、消融噪声、视差高度（白＝近处，黑＝深处）、AudioLink 遮罩

绘制时顶部中间的一栏

全部填充用前景色把文件夹中正在绘制的图层全部涂满

绘制法线贴图（凹凸）

  1. 在“材质”面板的“法线贴图”中，勾选“使用法线贴图”。
  2. 点击“绘制：”中的“法线贴图”。图层最上方会生成“法线贴图”文件夹。
  3. 白色凸起，黑色凹陷。用模糊可以变柔和。强度之后可以用“法线贴图强度”调整。
  • 用其他软件制作的法线贴图图像：用“添加法线贴图图像”，或选中文件夹中的图层后把图像拖放到窗口中。会以法线的形式放入，而不是高度（图层带有“法线”标签）。DirectX 方向的图像，请勾选图层属性中的“DirectX 方向（绿色反转）”。
  • 用图案添加质感：把针织、牛仔布、帆布、人字纹等图案，铺成重复的凹凸。大小、旋转、接缝用图层属性中的“重复图案”更改。可以用蒙版决定添加的位置。
  • 选中文件夹中的图层期间，UV 区域不显示高度（灰色），而是显示法线贴图的颜色（蓝紫色）。可通过 右键 → 显示 →“以高度（灰色）显示法线贴图文件夹（UV）”切回灰色。
  • 也有绘制凹凸的工具（凹凸）。
  • 导出时，PNG 是一张 <名称>_normal.png，PSD 则在“法线贴图”组中保持图层分开。

操作不顺利时

  • 出现“无法再添加”：一个材质的最终效果显示中，可同时使用的纹理最多 16 个。关闭其他功能，或“清除”不用的绘制目标即可使用。
  • 选了颜色也只能用灰色绘制：正在绘制的是只读取明亮度的绘制目标。要回到普通的颜色，请点击“返回颜色”。
  • 无法删除、移动绘制目标的文件夹：文件夹无法删除。要连同绘制目标一起删除时，点击顶部中间的“清除”。

叠加主颜色 2nd、3rd

可以把 lilToon 的“主颜色 2nd”“主颜色 3rd”用的图，与主颜色的图分开绘制。想用另一张图像叠加图案或花纹时使用。

  1. 在“材质”面板的“主颜色 2nd”中，勾选“使用主颜色 2nd”。
  2. 图层面板最上方会生成“主颜色 2nd”文件夹。
  3. 选中文件夹，添加图层并绘制。把普通图层拖入文件夹中也可以。
  4. 在面板中决定叠加方式（颜色、不透明度、混合模式、反映光照亮度）。
  • 只有文件夹中的图层会成为 2nd（3rd）的纹理，不会混入主颜色的图。混合模式有 正常、相加、滤色、正片叠底。
  • 用绘制目标“主颜色 2nd 蒙版”，可以绘制叠加处（白）和不叠加处（黑）。
  • 文件夹不能移动、删除、复制。文件夹中有图层时，无法取消“启用”（清空文件夹后即可取消，文件夹也会消失）。
  • 导出时会成为单独的图像（<名称>_main2nd.png、<名称>_main3rd.png，以及绘制的蒙版）。PSD 中保持为文件夹，重新导入时会回到这个文件夹。在材质中，会进入 lilToon 的“主颜色 2nd/3rd”。

只更改部分对象的设置（拆分材质）

在同一纹理（绘制的图）不变的情况下，可以按对象更改阴影色、MatCap、边缘光、轮廓线等设置。例如，头发纹理不变，只让兽耳的阴影变红。

  1. 在 3D 视图中右键点击该对象，或右键点击对象面板中的行。
  2. 选择“仅此对象使用另一个材质”。会以对象的名称添加一个当前材质的副本并分配给它。
  3. 在“材质”面板中，更改该材质的设置。
  • 起初，每个纹理集有一个同名的材质。不拆分的话，什么都不会变。
  • 通过右键的“分配材质”或面板的“分配给对象”，可以选择使用哪个材质。可选的只有使用同一纹理集的材质。
  • 在面板上方的列表中，可以添加（当前材质的副本）、重命名、删除、上移、下移。纹理集的原始材质不能删除。
  • 列表的顺序就是优先级。同一位置有多个对象重叠时，会选中靠上的材质。
  • 点击 3D 中的位置，面板会切换到该位置的材质，下方状态栏会显示“材质：名称（纹理集名称）”。
  • 导出时，每个材质一个 .mat。纹理按纹理集各一组，指向同一份。

加载 lilToon 材质

加载虚拟形象上已有的 lilToon 材质，可以接着其设置和图像继续绘制。导出时，只有重新绘制的部分会写入原材质。

  1. 选择 文件 → 导入 →“加载 lilToon 材质（.mat、.unitypackage）”。
  2. 选择 .mat，或包含它的 .unitypackage。拖放到窗口中也可以。
  3. 选了多个时，在弹出的窗口中确认要放入的纹理集（会放入名称匹配的纹理集）。
  4. 如果有找不到的纹理，会列在列表中，请选择图像（不选则不放入就加载）。
  • 在新建的“起始内容”中也可以选择（起始内容的种类）。
  • 载入的设置：渲染模式、渲染面、主颜色、阴影、法线贴图、MatCap/2nd、边缘光、逆光、边缘阴影、自发光、轮廓线、主颜色 2nd/3rd 等。
  • 载入的图像：主颜色 → 底色图层（PSD 则连同图层），2nd/3rd → 对应的文件夹，阴影色、蒙版、边缘光颜色、自发光、轮廓线宽度、AO → 绘制目标，MatCap → MatCap，法线贴图 → 法线贴图文件夹（保持为法线）。
  • 纹理会从 .mat 附近的项目（Assets、Packages）中查找。首次需要几秒到十几秒。.unitypackage 则从其中查找。
  • 选择多个使用同一纹理的 .mat 时，它们会进入同一个纹理集，从第 2 个起成为独立的材质。
  • 加载可以撤销（1 步）。该纹理集的材质设置、绘制目标、底色图、主颜色 2nd/3rd 会被替换。

未还原的设置

PetaNuri3D 没有模拟的设置（模板、距离淡出、UV 动画、纹理平铺等），会在加载后通过“未还原的设置”列表告知。数值会原样保留，导出时也会原样写回。该列表也可以从面板的“lilToon：○○.mat”分区中查看。

写回原材质

  • 导出加载的材质时，会保持与原 .mat 相同的位置、相同的 ID，只改写更改过的设置行和重新绘制的纹理。没有更改的纹理不会导出。
  • 把 .unitypackage 导入项目后，原材质和纹理会当场被覆盖（对模型的分配保持不变）。
  • 重新绘制了原本不是 PNG 或没找到的纹理时，会在 .mat 旁边新建 PNG 并替换。
  • 想作为新材质导出时，点击面板中的“解除与加载来源的关联”。
这会覆盖原项目的文件。不想直接改写所购买虚拟形象的材质时，请先复制项目，或点击“解除与加载来源的关联”后再导出。

导出材质并交给 Unity

把 lilToon 用的材质（.mat）和绘制的图像一起导出。导入 Unity 后，就是已分配好纹理的材质。

  1. 选择 文件 → 导出 →“导出材质（.unitypackage／文件夹）”（也可以用“材质”面板中的“导出材质”）。
  2. 在“要导出的材质”中打勾。
  3. 设定“导出目标文件夹名（Assets 下）”、分辨率和“外扩（填充）”。
  4. 点击“导出为 .unitypackage”，选择保存位置。
  5. 在 Unity 中，双击生成的 .unitypackage，或拖入 Project 栏进行导入。
  • 包含的内容：材质（.mat），以及主颜色、阴影色、蒙版、法线贴图、MatCap 等图像。绘制目标只有在使用对应功能时才会包含。
  • “导出到文件夹”：选择 Unity 项目的 Assets，会连同 .meta 直接写入（仅应用（exe））。
  • 图像会向 UV 岛外，按“外扩（填充）”的宽度扩展颜色（导出扩边）。
  • 用相同的文件夹名重新导出同一工程时，之前导入的内容会被原样覆盖（对模型的分配保持不变）。
  • 带 ! 的纹理集（模型中不存在的纹理集）不会导出。
导出的是 lilToon（2.3 系列）用的材质。请在要导入的项目中事先装好 lilToon。

操作不顺利时

  • Unity 中材质变成粉红色：该项目中没有 lilToon。装上 lilToon 就能解决。
  • 无法使用“导出到文件夹”：只能在应用（exe）中使用。请导出为 .unitypackage。
  • 虚拟形象上没有反映：请把导出的材质分配到模型的材质栏。加载原 .mat 后导出时，原材质会被原样覆盖。
