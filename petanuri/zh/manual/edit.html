选区、变换、文字、尺子

用于限定绘制区域、移动已绘制内容、贴文字或图片。变换框可出现在 3D 模型和 UV 区域中。

选区

  1. 选择“选区”工具（S），从辅助工具选择形状。
  2. 在 3D 视图（或 UV 区域）拖动、描画或点击选择。
  3. 选择期间，绘制、填充、擦除、滤镜、渐变仅在选区内生效。外侧略微变暗，边界显示虚线。
  4. Ctrl＋D 可取消选择。
辅助工具选择方式
矩形、椭圆拖动
套索画线围出区域
折线点击放置点，点击起点、双击或按 Enter 闭合
自动选择与点击位置颜色相近的连通区域
按 UV 岛选择整个点击的 UV 岛
按面选择划过的整个面
选择笔、选择擦除用画笔描画来添加、减去
  • 开始点击时按 Shift＝添加、Alt＝减去、Shift＋Alt＝交集。
  • 开启“也选择背面和被遮挡的面”时，会选中屏幕形状对应区域直至背面的所有部分。环绕身体一周选择，适合绘制服装条纹。
  • “选区”菜单：全选 Ctrl＋A、反选 Ctrl＋Shift＋I、扩展／收缩／羽化边缘、选择图层已绘制区域、从选区创建蒙版、用前景色填充、清除内部（Delete）、显示虚线（Ctrl＋H）、恢复选区（Ctrl＋Shift＋D）。
  • 有选区时，不能绘制未选中的纹理集。
对图层缩略图使用 Ctrl＋点击，可将已绘制区域设为选区（Shift 添加、Alt 减去）。

选区工具条

有选区时，3D 区域下方会出现选区工具条。在左侧“选择中”标签之后排列图标按钮（悬停笔尖或光标可显示名称和快捷键）。

  • 取消（有颜色的按钮）、反选｜扩展、收缩、羽化边缘｜填充、清除｜转到新图层 ▾（复制／剪切）、其他 ▾（蒙版、仅显示选中部分、隐藏、虚线）。
  • 窄屏下，扩展、收缩、羽化边缘会合并到“范围 ▾”。

移动/变换工具

  1. 选择“移动·变形”工具（V）。
  2. 在 3D 模型（或 UV 区域）点击要移动的图像。会选择点击处有绘制内容的最上层图层，并显示该图像的框（“自动选择图层”；关闭则使用当前选中图层）。
  3. 按住并拖动可立即移动。拖角点缩放，拖上方圆点旋转。
  4. Enter 或切换其他工具来确认，按Esc 取消。点击框外会确认，并切换到点击位置的图层。
  • 若有选区，仅移动选区内部。确认后作为一次撤销步骤。
  • 在工具属性选择框形（缩放、旋转／自由变换／扭曲）及扭曲网格数量。
  • 点击文字图层会显示文字框（框内拖动可移动，双击可重新输入）。

变换（Ctrl＋T）与 3D 操作框

  • 变换（Ctrl＋T）：有选区时显示移动选区的框，否则移动整个图层。
  • 框会在 3D 区域（模型上待移动图像附近）和 UV 区域两侧显示。操作任一框，另一框也同步跟随。若图像在 3D 中可见，无需打开 UV 区域即可操作。
  • 拖动框内移动、拖角点缩放（Shift 可改变宽高比）、拖边单轴缩放、拖上方圆点旋转（Shift 以15°为步进）。还可左右、上下翻转。将边或角拖过对侧即可翻转。
  • 在 3D 操作框上也可使用右键、中键拖动、滚轮或Space＋拖动调整视角。视角变化时，框会跟随。
  • UV 区域显示网格线时，操作框会吸附网格（网格线与吸附）。

自由变换、扭曲

变换、移动/变换工具、添加图片、粘贴、向 3D／UV 贴图的框下工具条有3个图标（缩放、旋转／自由变换／扭曲）。

  • 自由变换：分别拖动4个角点改变形状（如透视效果般贴图）。
  • 变形：拖动网格点弯曲图像。网格为3×3（工具条也可选4×4、5×5）。
  • 两种方式均可拖动上方圆点或角外侧少许位置旋转（Shift 以15°为步进）。拖动内部移动整体。
  • 切换模式时保留形状。确认后作为一次撤销步骤（移动选区时也一样）。向 3D 贴图时，会将屏幕上的形状投影到可见面。

复制、剪切、粘贴

  • 复制（Ctrl＋C）・剪切（Ctrl＋X）：复制或剪切选区内部（无选区则为整个图层）。多选图层时也只处理当前选中的一个图层。
  • 粘贴（Ctrl＋V）：在同一 UV 位置粘贴到新图层，可立即变换。
  • 锁定、隐藏或锁定透明像素的图层不能剪切或清除（会提示原因）。

添加图片、贴图

  • 添加图像（文件 → 导入 → 将图片导入为图层、拖入图片、对外部复制的图片使用 Ctrl＋V）：显示图片摆放框。UV 区域打开时放在 UV 上，否则放在 3D 中央（投影到可见面）。保留宽高比和透明区域。
  • 调整框后按 Enter ，会加入以文件名命名的新图层。Esc 取消则不保留任何内容。框下工具条“铺满整个纹理”也可将图片拉伸至整个 UV（适合按 UV 尺寸绘制的图片）。
  • 将图像贴到 3D（编辑 → 将图片贴到 3D）：在 3D 上调整框，按Enter 投影到模型可见面。调整期间可以移动视角。“斜面也保持浓度”可避免斜面颜色变淡。
  • 将图像贴到 UV（编辑 → 将图片贴到 UV）：在 UV 区域调整框，贴入新图层。
左右对称和选区也有效。

文字

  1. 选择“文字”工具（T），点击 3D 视图（或 UV 区域）。
  2. 显示框和文字窗口，可立即在框上输入。也支持日语输入，转换候选显示在文字旁边。
  3. Ctrl＋Enter 确认（输入时的 Enter 用于换行）。Esc 第一次停止输入（框保留），第二次取消。
  • 在文字窗口设置字体、大小、颜色、粗体、斜体、竖排、行距、字距、对齐和描边。颜色直接使用颜色面板前景色，描边使用背景色。
  • 按字符修改：选中文字后修改颜色、大小、字体、粗体、斜体、字距、描边，只影响选中文字。不选择时修改会用于之后输入的文字。
  • 输入时，工具快捷键（如E 切换橡皮擦）不生效。移动框需按住 Ctrl 拖动。
  • 可选择本机安装的所有字体。也可导入字体文件（.ttf、.otf），仅本次运行有效。

重新输入文字（文字图层）

  • 选择“到新图层”贴入的文字（贴入 UV 时始终如此）会成为文字图层，图层列表中显示“T”标记。
  • 双击图层列表、右键 →“重新输入文字”、或用文字工具点击文字，可按贴入时的状态重新打开。各字符的颜色和大小也保留。
  • 在文字图层用钢笔等添加绘制内容后，标记会变为“T＋”。重新输入时会丢失后来绘制的内容，要保留请画在其他图层。
  • 右键 →“栅格化”可转为普通图层（不能重新输入）。文字数据也存入工程文件，重新打开后仍可重输。PSD 中保存为普通图层。

尺子

  • 让笔画吸附尺子。直线、曲线仅影响在尺子附近开始的笔画；同心圆、放射线、平行线则在任意位置有效。
  • 创建：直线、平行线用拖动，同心圆、放射线以点击位置为中心，曲线通过放置点后按 Enter 或双击完成。尺子圆点可拖动移动。
  • 3D 区域尺子固定在屏幕上，不随视角移动。UV 区域也可单独放置。
  • 显示 → 线与尺子 → 吸附尺子（Ctrl＋Alt＋R）可切换，也可删除尺子。
放置曲线控制点期间，按Ctrl＋Z 可撤销最后放置的一个点。Ctrl＋Y 或 Ctrl＋Shift＋Z 可重做控制点撤销。Enter或双击确认尺子后，快捷键恢复普通历史记录操作。
