选区、变换、文字、尺子

本页介绍如何用选区限定绘制范围、移动并改变已绘制内容的形状、把图像和文字贴到模型上，以及用尺子对齐线条。变换边框会同时出现在 3D 视图的模型上和 UV 视图中。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

先看这几点
  1. 用“选区”工具（S）圈选后，就只能在圈选范围内绘制。按 Ctrl+D 取消选择（详细说明）。
  2. 用“移动·变形”工具（V）按住模型上的内容，直接拖动即可移动（详细说明）。
  3. 更改大小和方向用 Ctrl+T。拖动角调整大小，拖动上方的圆点旋转，按 Enter 确定（详细说明）。
  4. 把图像拖放到窗口里，就能对齐边框后贴上（详细说明）。
  5. 用“文字”工具（T）点击模型，就能就地输入文字（详细说明）。

选择要绘制的区域（选区）

创建选区后，绘制、填充、擦除、滤镜和渐变都只在其中生效。想避免画出界时，就用选区。

  1. 选择“选区”工具（S）。
  2. 在辅助工具中选择选择方式（矩形、套索等）。
  3. 在 3D 视图或 UV 视图中，通过拖动、划过或点击来选择。选区外会稍微变暗，边界上会出现虚线。
  4. 换成钢笔等工具来绘制。选区之外不会被画上。
  5. 按 Ctrl+D 取消选择。

辅助工具与选择方式

辅助工具选择方式
矩形·椭圆拖动。
套索划过并圈住。
折线点击打点。点击起点、双击或按 Enter 封闭。
自动选择选择与点击处颜色相近、且相连的部分。
按 UV 岛选择整体选中点击处的 UV 岛。
按面选择整体选中划过的面。
选区笔、选区橡皮擦用笔刷划过来添加、削减（按住 Alt 期间则相反）。
  • 在 3D 视图中，只选择可见的面。勾选工具属性中的“也选择背面和被遮挡的面”，就会把与画面形状重叠的部分连背面一起全部选中。需要绕身体选一整圈、绘制服装条纹时，这样很方便。
  • 自动选择要在工具属性中设定“参考”（所有图层／所选图层）、“容差”和“抗锯齿（边缘平滑 1px）”。
  • 按面选择要设定“拾取范围”和“按四边形选择（将 2 个三角形视为 1 个面）”。

添加到选区、从选区减去

在工具属性的“选择方式”中，选择新建、添加、删除或交叉。开始按下时先按住按键，则只对这一次生效。

开始按下时的按键选择方式
无新建（替换当前选区）。只按下而不移动则取消选择
Shift添加（添加到当前选区）
Alt删除（从当前选区中削减）
Shift+Alt交叉（只保留重叠的部分）

其他选择方式

  • 按住 Ctrl 点击图层缩略图，会选中该图层已绘制的部分（按 Shift 添加，按 Alt 削减）。
  • 在 3D 视图中右键 →“选择此 UV 岛（选区）”，会选中点击处的 UV 岛。UV 视图的右键菜单中还有“将此 UV 岛添加到选区”。
  • 想一次选中与前景色相近的颜色，请使用选择所有相似颜色。

操作不顺利时

  • 画不到想画的位置：有选区时，选区之外无法绘制。按 Ctrl+D 取消选择。
  • 无法在其他纹理集上绘制：有选区时，无法在没有选区的纹理集上绘制。请取消选择，或使用能包含所有纹理集的“全选”（Ctrl+A）。
  • 背面没有被选中：在 3D 视图中只会选择可见的面。请勾选“也选择背面和被遮挡的面”。
  • 选区外太暗，看不清颜色：取消勾选 选区 →“使选区外变暗”，就只剩虚线（菜单）。

用选区栏操作

选择期间，3D 视图下方会出现选区栏（只显示 UV 时，则出现在 UV 视图下方）。左侧“选择中”标签的后面，排列着图标按钮。把笔尖或光标放到按钮上，就会显示按钮名称和按键。

按钮作用
取消选择（带颜色的按钮）取消选择。取消之后，也可以用“重新选择”（Ctrl+Shift+D）恢复
反转反转选区
扩展、收缩、羽化调整选区的形状。屏幕较窄时会合并到“范围 ▾”中
填充用前景色填充选区
清除清除选区内的内容
到新图层 ▾“复制到新图层”“剪切到新图层”
更多 ▾从选区创建蒙版、仅显示所选部分、隐藏所选部分、显示选区虚线、使选区外变暗
显示隐藏笔栏或尺子条时，选区栏会排在它们的上方。“仅显示所选部分”和“隐藏所选部分”属于显示范围的功能。

调整和使用选区（菜单“选区”）

菜单“选区”中，列有调整和使用选区的项目。3D 视图右键菜单的“选区”里，也有其中的大部分项目。

项目按键作用

恢复选区（上次取消的选区）Ctrl+Shift+D恢复到上次取消的选区

扩展选区、收缩选区—在 UV 上扩展或收缩 1～64px
羽化边缘—让边缘柔和 1～64px
选择图层的已绘制区域—选中所选图层中已绘制的部分

从选区创建蒙版—给所选图层添加选区形状的蒙版（蒙版）
将选区复制为新图层—把其中的内容复制到相同位置的新图层
将选区剪切为新图层—把其中的内容移到新图层
用前景色填充选区—用前景色填充其中

选择所有相似颜色

从整个纹理中，选出与前景色相近的部分。不相连的部分也会被选中。用于按底涂的颜色分别更改阴影色等情况。

  1. 用吸管（I）把想选的颜色设为前景色。
  2. 选择 选区 →“选择所有相似颜色（前景色）”。
  3. 用“容差（%）”决定选到多接近的颜色。
  4. 在“取色来源”中选择“全部图层”或“当前图层”。
  5. 在“选择方式”中选择“新选区”“添加”或“减去”，然后点击“选择”。

用单色填充、批量更改颜色

这是菜单“编辑”中的 3 个项目。有选区时作用于选区内，没有选区时作用于所选图层的整个范围。

项目按键作用
用前景色填充Alt+Backspace用前景色填满
用背景色填充Ctrl+Backspace用背景色填满
改为前景色（保留透明度）—只把已绘制部分的颜色改成当前的前景色。浓度（透明度）和透明的部分保持不变
  • “改为前景色”用于批量更改线稿的颜色。图层行的右键菜单中也有。
  • 在蒙版上绘制时，会按颜色的明暗来涂蒙版（白＝显示，黑＝隐藏）。
  • 在法线贴图文件夹内，会用灰色来更改。无法用于法线贴图图像图层（绘制目标）。

移动已绘制的内容（移动·变形工具）

在 3D 模型上按住内容，就能直接拖动。不用去找画在哪个图层上，点击处的图层会被自动选中。

  1. 选择“移动·变形”工具（V）。
  2. 在 3D 视图（或 UV 视图）中，点击想移动的内容。点击处最上面的已绘制图层会被选中，并显示该内容的边框。
  3. 按住拖动，就会立即移动。拖动角调整大小，拖动上方的圆点旋转。
  4. 按 Enter 或切换到其他工具即可确定。按 Esc 取消。

细节设置

  • 关闭工具属性中的“自动选择图层”后，移动的是当前选中的图层，而不是点击处的图层。
  • 点击边框外会确定，并切换到点击处的图层。
  • 有选区时，只移动其中的部分。确定算作 1 次撤销。
  • 在工具属性的“图形”中可以选择边框的形状（缩放·旋转／自由变换／变形），在“变形网格”中可以选择网格数（自由变换、变形）。
  • 点击文字图层会变成文字边框。拖动边框内可移动，双击可重新输入（重新输入文字）。

操作不顺利时

  • 显示“此处没有已绘制的可见图层”：隐藏的图层、被蒙版遮住的部分、不透明度为 0% 的内容，都不会被选中。请先在图层面板中选择图层，再关闭“自动选择图层”后移动。
  • 移动的是其他图层：有重叠时，最上面的图层会被选中。请选择想移动的图层，并关闭“自动选择图层”。

更改大小和方向（变换）

对选区内或整个图层的内容，显示用来更改大小和方向的边框。边框会同时出现在 3D 视图的模型上和 UV 视图中。

  1. 用选区圈住想变换的部分（对整个图层操作则不需要）。
  2. 选择 编辑 →“变换（在 3D/UV 上）”（Ctrl+T）。边框会出现。
  3. 拖动边框内移动，拖动角缩放，拖动上方的圆点旋转。
  4. 按 Enter 确定。要取消时按 Esc。

边框操作

操作效果
拖动边框内移动
拖动角缩放（按 Shift 可改变纵横比）
拖动边只向一个方向拉伸或压缩
拖动上方的圆点旋转（按 Shift 以 15° 为单位）
把边或角拖过对侧翻转
边框下方的栏水平翻转、垂直翻转、不透明度、边框的形状（自由变换、变形）
  • 无论抓住 3D 还是 UV 的边框，动作都相同，另一边也会跟着变化。如果要移动的内容在 3D 中可见，不打开 UV 视图，仅在 3D 中也能操作。内容不可见时会打开 UV 视图，结束后自动关闭。
  • 在 3D 边框上，也可以用右键拖动、中键拖动、滚轮、Space+拖动来移动视角。改变视角后，边框也会跟随。
  • 3D 边框会按边框正中的面来显示。跨过 UV 接缝时，会对齐到正中的 UV 岛。
  • UV 视图中显示网格线时，边框会吸附到格子上（UV 网格线与吸附）。
  • 选区也会一起移动。

同时移动另一侧（也对称）

已开启绘制对称、且选区位于单侧时，边框下方的栏中会出现“也对称”。开启后再移动，3D 的另一侧也会像镜子一样一起移动。另一侧原有的内容会被替换。

  • 移动·变形工具也是一样。
  • 左右两侧都被选中时、选区跨过中心时、没有选区时，不会出现。
  • 对称的开启方法请看左右对称绘制。

添加透视、弯曲（自由变换、变形）

用边框下方栏中的 3 个图标，切换边框的形状。可用于变换、移动·变形工具、添加图像、粘贴、将图像贴到 3D／UV（文字的边框中不显示）。

边框的形状操作
缩放·旋转拖动角调整大小，拖动上方的圆点旋转，拖动中间移动（边框操作）
自由变换分别拖动 4 个角来改变形状。内容会像透视一样贴合。角不会越过对侧，也不会形成凹陷的形状
变形拖动网格的点来弯曲内容。网格为 3×3，也可以在栏中改为 4×4 或 5×5
  • 自由变换和变形，也可以拖动上方的圆点或角的稍外侧来旋转（按 Shift 以 15° 为单位）。拖动中间可整体移动。
  • 按 缩放·旋转 → 自由变换 → 变形 的顺序切换，形状都会保留。切回缩放·旋转时，会把当前的形状画进内容，变成其外侧的矩形边框。
  • 也可以使用水平翻转、垂直翻转和不透明度。确定算作 1 次撤销（移动选区时也一样）。
  • 贴到 3D 时，会把在屏幕上弯曲出的形状投影到可见的面上。

复制、剪切、粘贴

复制或剪切选区内（没有选区则为整个图层）的内容，再粘贴。粘贴的内容会放进新图层。

操作按键作用
编辑 →“复制（选区内）”Ctrl+C复制所选图层的内容
编辑 →“剪切（选区内）”Ctrl+X复制后，删除原来的内容
编辑 →“粘贴”Ctrl+V在相同的 UV 位置，以新图层粘贴。可直接用边框移动
选区 →“将选区复制为新图层”“将选区剪切为新图层”—不显示边框，立即放入相同位置的新图层
  • 即使选中了多个图层，对象也只是所选的那 1 个图层。
  • 把在其他应用中复制的图像按 Ctrl+V，可对齐边框后贴上（添加图像）。

操作不顺利时

  • 无法剪切、无法清除：已锁定、隐藏、锁定透明像素的图层，不会执行剪切和清除（原因会显示在下方）。复制仍然可以进行。
  • 无法创建新图层（Lite）：Lite 版每个纹理集包含底色在内，最多 4 个图层（版本）。

贴图像

用边框对齐大小和位置，贴上标志或花纹图像。贴法有 3 种。

贴法开始方式边框出现的位置
添加图像文件 → 导入 →“将图像作为图层导入”、把图像拖放到窗口、在其他应用中复制图像后按 Ctrl+VUV 视图已打开时出现在 UV 上，关闭时出现在 3D 的正中（投影到可见的面）
将图像贴到 3D编辑 →“将图像贴到 3D”3D 视图（投影到可见的面）
将图像贴到 UV编辑 →“将图像贴到 UV”UV 视图
  1. 把图像拖放到窗口。会出现用来放置图像的边框。
  2. 移动边框，对齐大小和位置。也可以一边移动视角一边对齐。
  3. 按 Enter 确定。图像会放进以文件名命名的新图层。

边框下方的栏

  • 保持纵横比，以能放进可见范围的大小放置。透明的部分保持透明。
  • 按 Esc 取消的话，什么都不会留下。确定之后，撤销 1 次即可删除。
  • “铺满整个纹理”（添加图像时）：拉伸到整个 UV，放入新图层。用于按 UV 大小画好的图像。
  • “到新图层”（贴到 3D 时。初始为开启）：为每个被贴上的纹理集创建新图层。关闭后，则贴到当前图层。
  • “斜面也保持浓度”：即使是朝向侧面的面，也不会变淡地贴上。
  • 也可以使用水平翻转、垂直翻转、不透明度，以及边框的形状（自由变换、变形）。
  • 左右对称和选区也有效。

添加文字

在模型上就地输入文字并贴上。字体、大小、颜色也可以逐字更改。

  1. 选择“文字”工具（T）。在辅助工具中选择“横排文字”或“竖排”。
  2. 点击 3D 视图（或 UV 视图）。会出现边框和文字窗口（也可以从 编辑 →“添加文字”开始）。
  3. 直接输入即可。也可以输入日语，转换候选会显示在文字旁边。
  4. 按 Ctrl+Enter 确定（输入过程中的 Enter 是换行）。

文字窗口

  • 在这里设定字体、大小、颜色、粗体、斜体、竖排、行距、字距、对齐、描边。
  • 打开文字窗口期间，颜色面板的前景色就是文字颜色，背景色就是描边颜色。点击窗口中的颜色方块也可以选择。
  • 勾选标题处的“用滑块调整”后，大小、描边、行距、字距也可以用滑块调节。
  • 字体列表的下方，会以“此电脑的字体”为名，列出电脑中已安装的全部字体。
  • 用“加载字体”也可以使用字体文件（.ttf、.otf），仅在本次启动期间有效。
  • 窗口与边框重叠时，可以抓住窗口标题（“文字”）来移动。下次也会保持该位置。
  • 点击 UV 视图开始的话，文字会贴在 UV 上。

输入时的操作

操作作用
点击边框内（双击也可以）从点击处开始输入
← → ↑ ↓、Home、End移动输入位置（竖排时，↑ ↓ 在字之间前后移动，← 移到下一行）
Shift+方向键、在边框内拖动选择文字
Backspace、Delete删除文字
Ctrl+拖动移动边框（角、边、上方的圆点照常使用）
Esc第 1 次停止输入（边框会保留，可拖动移动）。第 2 次放弃文字
输入期间，按键快捷键（如 E 切换橡皮擦）无效。刚开始时全部文字处于选中状态，所以一输入就会被替换。

逐字更改颜色和大小

  • 选中文字后，再更改颜色（前景色、背景色）、大小、字体、粗体、斜体、字距、描边，就只有选中的文字会改变。
  • 不选择就更改的话，会用于接下来输入的文字。未处于输入状态时（按 Esc 之后等），全部文字都会改变。
  • 会改变哪些文字，显示在文字窗口的“更改颜色和大小时：”中。
  • 行距、对齐、竖排对全部文字生效。大小不同的文字会对齐下边线排列。

重新输入文字（文字图层）

勾选“到新图层”后贴上的文字会成为文字图层，图层列表中会带有“T”标记。贴到 UV 上的文字，始终是文字图层。之后可以更改文字、字体、颜色等，再重新贴上。

  1. 在图层列表中双击文字图层（右键 →“重新输入文字”也可以）。
  2. 文字窗口和边框会以贴上时的状态打开。逐字设置的颜色和大小也保持原样。
  3. 修改后按 Ctrl+Enter 重新绘制。可以用撤销恢复。
  • 在文字工具下点击文字，或使用工具属性中的“重新输入所选文字图层”，也可以开始。
  • 贴在 3D 上的文字，会先回到贴上时的视角，再显示边框。结束后会回到原来的视角。
  • 要重命名，请右键 →“重命名”。
  • 右键 →“栅格化（之后无法重新输入文字）”，会变成普通图层。
  • 它会包含在工程文件中，重新打开后也能重新输入。写入 PSD 时作为普通图层。

操作不顺利时

  • 按键后工具没有切换：输入文字期间，快捷键无效。请按 Esc 结束输入。
  • 重新输入后，补画的部分消失了：在文字图层上补画后，标记会变成“T+”。重新输入时补画的部分会消失，所以请先用 Ctrl+Z 撤销，把补画的部分分到另一个图层后，再重新输入。
  • 显示“找不到字体”：加载的字体只在本次启动期间有效。系统会改用其他字体重新输入，要恢复成原来的字体时，请用“加载字体”再加载一次。
  • 无法重新输入：关闭“到新图层”而贴到当前图层的文字，以及已栅格化的文字，都是普通的图像内容。

用尺子对齐线条

让绘制的线条吸附到尺子上，画出笔直的线，或指向中心的线。在 3D 视图和 UV 视图中都能使用。

  1. 选择“尺子”工具，在辅助工具中选择尺子的种类。
  2. 在 3D 视图或 UV 视图中创建尺子（创建方法见下表）。
  3. 换成钢笔等工具开始绘制。线条会沿着尺子。
辅助工具创建方法生效的线
直线尺拖动在附近（吸附距离内）开始绘制的线，会变成直线
曲线尺点击打点，按 Enter 或双击结束（按 Esc 取消）在附近开始绘制的线，会沿着曲线
同心圆尺点击处为中心无论在哪里绘制，都会与中心保持距离，成为圆
放射线尺点击处为中心无论在哪里绘制，都会成为指向中心的线
平行线尺拖动决定方向无论在哪里绘制，都会成为该方向的线

移动、关闭、删除尺子

  • 尺子上的圆点（端点、中心、点）可以拖动移动。吸附距离在工具属性中设定。
  • 3D 视图的尺子，即使移动视角也会保留在屏幕上。UV 视图中也可以另外放置。
  • 有尺子时，该区域下方的正中会出现一条栏（尺子的种类、“吸附”的开关、“删除”）。“删除”只会删除该区域的尺子。
  • 用 显示 → 线与尺子 →“吸附到尺子”（Ctrl+Alt+R）来切换。同一处的“删除尺子”可以删除尺子。
  • 在为曲线尺打点的过程中，可以用 Ctrl+Z 撤回最后一个点。用 Ctrl+Y 或 Ctrl+Shift+Z 可以重做。

操作不顺利时

  • 线条自动变直或变弯：尺子还留着。请关闭下方栏中的“吸附”，或用“删除”清除（也可以用 Ctrl+Alt+R 关闭）。
  • 线条不沿直线尺、曲线尺：尺子只对在其附近开始绘制的线生效。请在工具属性中加大吸附距离。
