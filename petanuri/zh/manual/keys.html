快捷键与数位笔操作

所有按键均可在 文件 → 偏好设置 →“按键设置”重新分配（适合左手控制器）。本页使用默认按键。

快捷键列表（F1）

  • F1 可在浮动窗口显示快捷键列表（也可从帮助菜单打开）。保持打开时按键仍有效，也可在 3D 和 UV 绘制。再次按 F1 或点击右上角 × 关闭。
  • 上方“搜索”可按键或名称筛选。按下的按键行会短暂高亮，下方显示“按下的按键”。
  • 拖动标题移动，拖右下角调整大小（下次打开保留）。▾ 折叠、◐ 半透明。
  • 重新分配按键后，菜单、右键、按钮说明和此列表均显示当前按键。

分配按键

  • 文件 → 偏好设置 →“按键设置”：在各分类点击＋后按键即可分配。× 移除。“恢复默认值”恢复该按键，“初始化按键设置”恢复所有按键（需确认）。
  • 也可右键工具栏按钮、辅助工具缩略图或面板标题 →“分配按键”修改（可与Ctrl・Alt・Shift 组合）。若该按键已被占用，会询问是否重新分配。

笔压异常或不生效时

  1. 先在 文件 → 偏好设置 → 数位笔与输入 的“笔压”调整。“通过试画校准”中以常用力度画至少3条线后点击“校准”，会自动确定下限、上限和响应。
  2. 若笔压不生效（粗细不变化），用数位笔点击同一区域的测试板，查看“输入路径”。若为“无（以鼠标形式传入）”，请在数位板设置开启“使用 Windows Ink”，或在 数位笔与输入 →“数位板”开启“直接读取笔压（WinTab）”。
  3. 仍有异常时，点击“数位板”中的“检查 WinTab 状态”，在 PetaNuri3D 窗口上移动数位笔。“复制”输出文字，与数位板型号、驱动版本一并发送给支持人员。
