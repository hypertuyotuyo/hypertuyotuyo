快捷键与数位笔操作

这里是按键一览，以及用数位笔、鼠标、3D 鼠标的操作方法。所有按键都可以重新分配。本页列出的按键是初始的分配。笔压不生效或异常时的解决办法，也汇总在这里。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

先看这几点
  1. 按 F1 会显示当前的按键列表。列表开着也能继续绘制（详细说明）。
  2. 3D 视图用右键拖动或 Space+拖动来旋转，用滚轮缩放（详细说明）。
  3. 想使用与其他软件相同的鼠标操作时，请选择相机操作模板（详细说明）。
  4. 按键在 文件 → 偏好设置 →“键位设置”中更改（详细说明）。
  5. 用数位笔绘制但粗细不变时，请看笔压不生效时。

显示快捷键列表（F1）

用浮动窗口显示当前的按键列表。窗口开着时，按键依然有效，也可以在 3D、UV 上绘制。

  1. 按 F1（也可以通过 帮助 →“快捷键列表”）。
  2. 在上方的“搜索”栏中输入按键或名称，筛选列表。
  3. 关闭时，再按一次 F1，或点击右上角的 ×。
  • 按下按键时，对应的行会稍微发光，下方边缘会显示“按下的键：”和操作名称。
  • 拖动标题可以移动窗口（双击恢复原来的位置），拖动右下角可以调整大小。下次打开时保持不变。
  • 点击 ▾ 折叠，点击 ◐ 变透明（指针在窗口外时会变淡）。
  • 下方的“更改按键设置”，会打开偏好设置中的键位设置。
  • 数位笔、鼠标的操作也包含在列表中，并会随所选的相机操作模板而变化。
  • 重新分配按键后，菜单、右键菜单、按钮提示以及这个列表，都会显示当前的按键。

这是在 3D 视图和 UV 区域中的操作。表格对应的是初始的相机操作（右键方式）。

操作作用

右键拖动（笔的侧键）3D 中为旋转，UV 区域中为平移
中键拖动平移
滚轮缩放
Shift+滚轮旋转画面（每次 5°）
Space+拖动旋转（可在偏好设置中与平移互换）
Shift+Space+拖动平移
Ctrl+Space+拖动缩放
不移动就松开右键鼠标为右键菜单，笔的侧键为弹出调色板（弹出调色板）
Shift+点击从上一笔的终点画直线
Ctrl+Alt+左右拖动画笔大小
Ctrl+右键拖动（笔的侧键）左右调整画笔大小，上下调整硬度

笔的橡皮擦端橡皮擦（使用橡皮擦工具的辅助工具设置）

  • 用 Ctrl+右键、左键拖动来改变数值，适用于用笔刷绘制的工具（钢笔、毛笔、橡皮擦、模糊等）。在任何相机操作模板下都可以使用。只有开始移动时的方向（左右或上下）所对应的数值会改变，数值会显示在下方的栏中。
  • 选中“抓手”工具期间，用左键或数位笔拖动即可移动画面（3D 为平移，按住 Ctrl 则为缩放）。
  • 不使用鼠标或数位笔的按键来移动视角时，请使用 3D 视图的 3D 导航（3D 导航）。

用工具键临时切换工具

按住工具键绘制时，仅在按住期间切换为该工具，松开后回到之前的工具。适合在用钢笔绘制的过程中，瞬间用一下橡皮擦等情况。

  • 短按后松开，则保持切换到该工具。
  • 长按后松开，即使没有绘制，也会回到之前的工具。
  • 视为长按的时间，可在 文件 → 偏好设置 → 操作 → 键盘 的“视为长按的时间”中设为 0.15～2 秒（初始为 0.5 秒）。
  • 要关闭这种临时切换本身，请关闭同一处的“长按工具键临时切换”。

选择相机操作模板

可以按自己习惯使用的软件，从 4 种模板中选择移动视角的鼠标分配。

  1. 打开 文件 → 偏好设置 →“操作”→“相机”。
  2. 在“相机操作模板”中选择。所选的方式下次启动时也会保留。
模板旋转平移缩放
右键方式（初始）右键拖动中键拖动滚轮
中键方式中键拖动Shift+中键拖动Ctrl+中键拖动
Alt＋鼠标按钮Alt+左键拖动Alt+中键拖动Alt+右键拖动
Unity 方式右键拖动、Alt+左键拖动中键拖动、Alt+中键拖动Alt+右键拖动（向下拖为拉近，向上拖为推远）
  • Space+拖动和滚轮，在任何模板下都可以使用。
  • Alt＋鼠标按钮和 Unity 方式作用于 3D 视图。因为 Alt 用于相机操作，所以 3D 中的吸管要用 I 键。
  • 在 Alt＋鼠标按钮方式下，按 Alt+Shift+左键拖动，会以 90° 为单位旋转（在点击处把方向对齐到 90° 的倍数），按 Shift+右键拖动，则旋转光的左右方向。
  • 把数位笔侧键设为中键点击时，操作与中键相同。笔尖接触期间按下中键，会停止绘制，变为视角操作。松开中键后，请先抬起笔尖，再画新的线。

这些都在 文件 → 偏好设置 → 操作 →“相机”中。

数位笔按键、Windows Ink

数位板驱动中分配给笔按键的点击，会作为笔所在位置的点击接收。无论是 Windows Ink 还是 WinTab 都有效。

按键分配在 PetaNuri3D 中的动作
中键点击按住期间移动笔，会旋转 3D 视角（笔悬空或接触都会旋转）。绘制过程中按下，会在当前画到的线处停下并开始旋转。在 UV 区域中为平移
右键点击按住并移动为右键拖动（旋转 3D 等），不移动就松开为右键点击（菜单）
后退、前进作为鼠标的后退、前进按钮接收
  • 与笔尖同时（前后 0.05 秒内）到达的右键点击不予使用，以绘制为优先（针对会和笔尖一起发送右键点击的驱动）。中键点击即使与笔尖同时到达，也会作为视角操作。
  • 只有笔靠近 PetaNuri3D 窗口期间才会接收。不会碰鼠标的真实按键。
  • 不想接收时，请关闭 文件 → 偏好设置 → 笔与输入 → 菜单和按钮 中的“接收笔侧键的中键／右键点击”（初始为开启）。关闭后，驱动的点击会直接作用于鼠标光标所在的位置。

开关 Windows Ink 会带来的变化

数位板的设置在 PetaNuri3D 中
开启“使用 Windows Ink”（推荐）能收到笔压和倾斜度。按下侧键后不移动就松开，会弹出调色板
关闭“使用 Windows Ink”笔会以鼠标形式传入，没有笔压（笔压不生效时）。侧键也会作为鼠标右键传入，因此遵循 偏好设置 → 操作 → 鼠标 中“右键”的设置

操作不顺利时

  • 松开侧键后 3D 仍一直旋转：按 Esc，或用笔尖点一下，就会停止。
  • 笔尖画不出来，或经常一直旋转：请试着关闭“接收笔侧键的中键／右键点击”。
  • 用侧键拖动时中途停止：在数位板驱动的设置中，给侧键分配 Space 键。用 Space+笔拖动即可旋转。
  • 画细节时菜单自己弹出来：这是笔长按触发的。请关闭 笔与输入 → 菜单和按钮 中的“用笔长按弹出菜单”（右键菜单）。

用 3D 鼠标移动视角

用 SpaceMouse 等可向 6 个轴移动的 3D 鼠标，可以移动光标所在区域（3D 视图、UV 区域、2D 画布）的视角。连接后，右下角会显示提示。

控制帽的动作3D 视图UV 区域、2D 画布
左右平推、下压、上提平移平移
向手前拉、向里推缩放缩放
扭转绕竖直轴旋转旋转
前后倾斜绕水平轴旋转—
左右倾斜旋转画面（开启“左右倾斜以旋转画面（3D）”时）—
  • 只有 PetaNuri3D 窗口位于前台，或光标位于窗口上时才会动作。绘制期间视角不会移动。
  • 驱动（3DxWare）无论是否安装都可以使用。

3D 鼠标设置

在 文件 → 偏好设置 → 操作 →“3D 鼠标”中更改。只有连接过 3D 鼠标时才会出现。

  • 使用 3D 鼠标、灵敏度、移动对象（旋转和平移／仅旋转／仅平移）
  • 反转平移方向、反转缩放方向、反转旋转方向、左右倾斜以旋转画面（3D）
  • 按钮 1（左）（初始为切换移动对象）、按钮 2（右）（初始为显示全部）。此外还可以选择：前视图、从反方向看、切换透视 / 平行、恢复画面旋转默认值、打开 3D 鼠标设置、不执行任何操作
  • 移动时忽略滚轮：驱动会随控制帽的动作一起发送滚轮信号，开启后在移动期间不使用它（避免缩放时一卡一卡）

操作不顺利时

  • 3D 鼠标的按钮不生效：按钮的分配只在驱动（3DxWare）未运行时生效。驱动运行时，按钮由驱动使用，所以请在驱动的设置中给按钮分配按键（例：F 为显示全部）。
  • 偏好设置中没有“3D 鼠标”：从未连接过就不会出现。连接后就会出现。
  • 缩放时一卡一卡：开启“移动时忽略滚轮”。

  • 在为曲线尺打点期间，用 Ctrl+Z 撤回最后一个点，用 Ctrl+Y、Ctrl+Shift+Z 重做（尺子）。
  • 教程期间，用 ← → 前后切换，用 Esc 退出。

分配按键

任何操作的按键都可以更改。适用于配合左手设备等情况。

  1. 打开 文件 → 偏好设置 →“键位设置”。每个分类一节，列出各个操作及其按键。
  2. 点击想更改的操作的“+”。会显示“请按一个键（Esc 取消）”。
  3. 按下想使用的键。也可以与 Ctrl、Alt、Shift 组合。
  4. 如果该键已用于其他操作，会询问是否“改为分配”。改为分配后，该键会从原来的操作上移除。
  • 点击按键旁边的 ×，可移除该键。用“+”添加按键，一个操作可以设置多个按键。
  • 点击“恢复默认值”，仅把该操作恢复为默认的按键。
  • “初始化按键设置”会把全部恢复为默认（先确认；无法用撤销恢复）。

通过右键为工具、辅助工具分配按键

  1. 右键点击工具栏的按钮，或辅助工具的图块。
  2. 选择“分配按键”。如果已有按键，会显示成“分配按键（当前：P）”这样。
  3. 按下想使用的键。原来的键会被取消，替换成所按的键（按 Esc 取消）。
  • 在辅助工具、工具属性面板的标题或标签上右键，也可以分配。
  • 按下分配给辅助工具的键，就会切换到该工具的该辅助工具。删除辅助工具时，对应的键也会被移除。
  • 分配的键，会显示在按钮、图块名称旁边（气泡提示）以及键位设置的分类“工具”“辅助工具”中。
  • 把同一个键分配给多个辅助工具时，请在分配窗口中选择“共用（每按一次切换）”。每按一次该键，就会切换到下一个辅助工具（例：给 G 笔和针管笔分配 Q）。

导出、导入按键分配

换到另一台电脑，或留一份备份时使用。

  1. 点击键位设置上方的“导出快捷键设置”。当前的分配会保存为 JSON 文件（PetaNuri3D-keymap.json）。
  2. 在导入的一侧，点击“导入快捷键设置”，选择该文件。
  3. 被问到“要替换吗？”时，点击“加载”。当前的分配会被整体替换。
  • 文件中没有的操作，会使用默认的按键。当前版本中不存在的操作，其设置不会被使用。

操作不顺利时

  • 按键没有反应：打开菜单期间，应用的快捷键无效。请关闭菜单后再按。
  • 按下的键触发了意想不到的操作：打开 F1 列表并按键，下方边缘会显示该键对应的操作。
  • 分配给小键盘的键无效，或用上排数字无效：小键盘的数字与上排的数字是不同的键。请为实际使用的那个重新分配。
  • 刷新、打印、页面缩放的键无效：浏览器的操作键在 PetaNuri3D 中无效。

笔压异常或不生效时

笔压可以在 文件 → 偏好设置 → 笔与输入 的“笔压”中，调整为适合自己的力度。粗细完全不变时，请先确认笔压是否传到（传输路径）。

按自己的力度校准（通过试画校准）

  1. 打开 文件 → 偏好设置 →“笔与输入”→“笔压”。
  2. 点击“通过试画校准”。
  3. 在右侧的板上，用平时的力度画 3 条以上的线。
  4. 点击“校准”。下限、上限、响应会根据该力度自动确定。
  5. 不满意的话，点击“撤销”。
项目含义
响应柔软＝力度轻也能画出较粗、较浓的线 ／ 坚硬＝只有用力按时才会变粗
下限比这更弱的力度，视为笔压 0
上限比这更强的力度，视为笔压 100%（数位笔的力度范围较窄时）
  • 用笔按右侧的板，会显示当前的笔压，以及经过响应处理后的值。
  • 每个辅助工具是否用笔压改变粗细、浓度（“笔压控制大小”“笔压控制不透明度”），以及笔压曲线，都在工具属性中更改。它们作用于这里的响应之后（画笔详细设置）。

确认笔压是否传到

  1. 用笔按 文件 → 偏好设置 → 笔与输入 中“笔压”的板。
  2. 查看板下方的“当前笔压”和传输路径。
路径显示含义

笔压不生效（粗细不变）时

如果在数位板的设置中关闭了“使用 Windows Ink”，笔会以鼠标形式传入，没有笔压。解决办法有 2 种，任选其一即可。

  • 推荐：在数位板驱动的设置界面中，开启“使用 Windows Ink”。倾斜度也会传入。
  • 在保持关闭 Windows Ink 的状态下使用时：开启 文件 → 偏好设置 → 笔与输入 →“数位板”中的“直接读取笔压（WinTab）”（初始为关闭）。路径会变为“WinTab”。
用笔绘制却似乎没有收到笔压时，右下角会提示一次“未收到笔压”。只用鼠标绘制时不会出现。点击“不再显示”后不再出现，点击“打开偏好设置”会打开笔与输入。

用 WinTab 读取笔压

  • 开启“直接读取笔压（WinTab）”后，会从数位板驱动的 WinTab 读取笔压（和倾斜度）。
  • 只有笔靠近并绘制时，才会替换笔压。用鼠标绘制时保持不变。笔的橡皮擦端也会变成橡皮擦。
  • “通过 Windows Ink 传入的笔也使用 WinTab 压感”（初始为开启）：笔通过 Windows Ink 传入时，只要收到了 WinTab 的值，也会使用它的笔压和倾斜度。关闭后，仍使用 Windows Ink 的笔压。
  • 与其他使用 WinTab 的绘画软件同时使用时，可能收不到笔压。

操作不顺利时

  • 不用力按就不变粗，或轻轻一碰就很粗：用“通过试画校准”，重新按自己的力度校准。手动调整的话，不用力按就不变粗时降低上限，轻碰就很粗时把响应往“坚硬”一侧调。
  • 轻轻画时线几乎看不见，或入笔收笔太细：把 笔与输入 → 笔触手感 中的“入笔收笔的方式”设为“按长度入笔收笔”。这样即使笔压很弱的位置，也不会细于 1px。
  • 其他画笔有效，只有某个画笔粗细不变：在该辅助工具的工具属性中，确认“笔压控制大小”有没有被关闭（画笔详细设置）。
  • 用鼠标绘制时粗细不变：鼠标没有笔压。鼠标的入笔收笔，始终由辅助工具的“入笔”“出笔”长度来产生。
  • 显示“WinTab 没有空位”，“直接读取笔压（WinTab）”被关闭：请关闭其他使用 WinTab 的绘画软件，或重启数位板驱动（或电脑），再重新开启。有些驱动中，未正常关闭的软件所占用的名额，在重启之前不会恢复。
  • 显示“找不到 WinTab”“找不到数位板”：请确认数位板驱动已安装、数位板已连接。
  • 已开启 WinTab，但按板时“当前笔压”仍是“—（无笔压）”：让 PetaNuri3D 窗口保持在最前，用笔在板上按几次来绘制（如果没有传到，每按 2 次会切换连接方式尝试）。仍然不行的话，点击“WinTab 连接方式”的“重新查找”，再绘制一次。
  • 开启 WinTab 后，笔没有反应：点击“数位板”中“WinTab 连接方式”的“重新查找”，再绘制一次。会清除记住的连接方式，从头重新查找。
  • 在数位板驱动中做了按应用的设置：如果在按应用的设置中添加了 PetaNuri3D（PetaNuri3D-win_x64.exe），请确认那里没有关闭笔压。
  • 显示“WinTab 正在运行，但没有收到笔的信息”：用下面的“检查 WinTab 状态”，确认卡在了哪里。
  • 想重装、更新数位板驱动：请先关闭 PetaNuri3D 再操作。使用 WinTab 时，驱动的文件会一直处于打开状态。
  • 线条比笔尖慢出现：试着开启 笔与输入 → 减少延迟 中的“提前显示笔画（减少延迟）”（用数位笔（Windows Ink）绘制时）。同时也开启“预测的临时线”（笔与输入的设置）。

仍无法解决时（发送给技术支持）

  1. 点击 文件 → 偏好设置 → 笔与输入 →“数位板”中的“检查 WinTab 状态”。
  2. 在 PetaNuri3D 的窗口上，用笔画一条线（2～3 秒）。会显示 wintab32.dll、数位板名称、笔压级别、接收端、最近 5 秒收到的数据包数、最后的笔压值，以及对卡在何处的判断（数值每秒更新）。
  3. 点击“复制”。
  4. 通过 帮助 →“联系我们（支持、功能需求、错误报告）”，连同数位板的型号、驱动的版本一起粘贴并发送（联系我们的方法）。
出现“请先开启“直接读取笔压（WinTab）”，再检查一次”时，请先开启同一处的“直接读取笔压（WinTab）”，再按一次。
