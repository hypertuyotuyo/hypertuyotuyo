PetaNuri3D ／ 使用手册 ／ 导出

导出

把绘制好的纹理做成可在 Unity 等中使用的图像（PNG、PSD）。保存工程文件（.petanuri）是为了继续绘制，不能直接贴到模型上。生成图像的操作就是“导出”。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

先看这几点
  1. 通过 文件 → 导出 → 导出 PNG（全部纹理集），一次把所有纹理导出为 PNG（详细说明）。
  2. 窗口中的“外扩（填充）”保持默认的 8 px 即可。如果在游戏中看到接缝处有线条，再调大（详细说明）。
  3. 如果要反复导出到同一个文件夹，请勾选“每次都不询问，直接导出到此文件夹”（详细说明）。
  4. 要保留图层分开传递，请导出为 PSD Standard（详细说明）。

可导出的内容，以及与工程文件的区别

各种导出都通过 文件 → 导出 选择。在纹理集所在行的右键菜单中，也可以只导出该纹理集。

想要的内容菜单
当前所选纹理集的纹理导出 PNG（所选纹理集）（详细说明）
全部纹理集的纹理导出 PNG（全部纹理集）（详细说明）
仅部分图层的图像导出为 PNG（所选图层）（详细说明）
UV 线条的底图将 UV 贴图导出为 PNG（所选集合）（详细说明）
保留图层分开的图像 Standard导出 PSD（所选纹理集）／（全部纹理集）（详细说明）
lilToon 材质 Pro导出材质（.unitypackage／文件夹）（详细说明）
AO 图像 Pro滤镜 → 烘焙 →“将 AO 导出为 PNG（最后一次烘焙的结果）”（详细说明）
工程文件（.petanuri）导出的 PNG
内容模型、全部图层、设置将可见图层叠加后的 1 张图像
可打开的应用只有 PetaNuri3DUnity、其他绘画软件等
操作文件 → 保存工程文件（Ctrl+S）文件 → 导出
导出的 PNG 无法还原成图层。为了以后修改，请同时保存工程文件（保存）。

导出为 PNG

把纹理集的图像导出为 PNG，每个纹理集 1 张。在 Unity 等中贴到模型上的就是这张图像。

  1. 选择 文件 → 导出 →“导出 PNG（全部纹理集）”。只导出一个时，选择“导出 PNG（所选纹理集）”。
  2. 在导出窗口中确认“分辨率”“外扩（填充）”和“导出位置”，然后点击“导出”。
  3. 被询问保存位置时，选择文件夹。导出全部纹理集时，只需选择一次文件夹。
  4. 显示“已导出 XX”，并用资源管理器打开导出的文件夹。

导出的文件

文件名内容
＜纹理集名＞.png将可见图层叠加后的图像。纹理集名就是材质的名称
＜纹理集名＞_main2nd.png、＜纹理集名＞_main3rd.png Pro含有主颜色 2nd／3rd 文件夹的纹理集。如果绘制了它们的蒙版，还会有带 _mask 的文件（主颜色 2nd、3rd）
＜纹理集名＞_normal.png Pro含有绘制目标中法线贴图文件夹的纹理集（绘制目标）
  • 名称相同的纹理集，会加上 _2、_3 加以区分。
  • 已关闭显示的纹理集也包含在“全部纹理集”中。无对应材质的纹理集（!）不包含在内。需要时，请在该行的右键菜单中选择“导出 PNG（不向 UV 岛外扩展）”来导出（无对应材质的纹理集）。
  • 描边等效果会连同效果一起导出。用轻松烘焙等烘焙出的光、影、质感，也会作为可见图层的颜色包含在内。
  • 即使用显示范围或对象隐藏了，纹理也会原样导出。
  • 在纹理集所在行的右键菜单中选择“导出为 PNG”，也可以导出该纹理集。

改变大小后导出

在导出窗口的“分辨率”中，可以选择与纹理集不同的大小。可选“保持不变（纹理集分辨率）”、512×512、1024×1024、2048×2048、4096×4096、8192×8192。

  • 先按纹理集的分辨率做外扩，再进行缩小或放大。
  • 对 PNG（所选纹理集、全部纹理集）、所选图层、UV 贴图和材质的导出有效。对 PSD 无效（始终是纹理集的分辨率）。
  • 更改绘制时的分辨率，要在纹理集面板中操作（更改分辨率）。

操作不顺利时

  • 在游戏中，UV 接缝处能看到线条：外扩不够。请调到大于 8 px 后重新导出（外扩）。
  • 提示“XX 显示期间无法导出”：变形框、滤镜预览等仍处于显示状态。请先确定（Enter）或取消（Esc），再导出。
  • 提示“正在执行其他文件读写操作”：保存、自动保存或加载正在进行中。请等完成后再点一次。
  • 提示“显示处理已停止，无法导出”：请从工程文件或自动保存重新打开后再导出（节省内存）。
  • 提示“没有可导出为 PNG 的纹理集”：当前所选的是无对应材质的纹理集（!）。请选择其他纹理集，或先移动图层再导出。
  • 点击后显示“已取消导出”：在导出窗口或保存位置窗口中点了取消。在窗口中更改过的值也会恢复原样。

仅将所选图层导出为 PNG

把线稿、图案等部分图层导出为背景透明的 PNG。

  1. 在图层面板中选择要导出的图层（按住 Ctrl 或 Shift 点击，可选任意多个）。
  2. 选择 文件 → 导出 →“导出为 PNG（所选图层）”（也可以用图层右键菜单中的“将所选图层导出为 PNG”或“将此图层导出为 PNG”）。
  3. 选择了 2 个以上时，在窗口的“所选图层”中选择“逐个（每个图层一个文件）”或“叠加为一张”，再点击“导出”。
选择方式文件名
逐个＜纹理集名＞_＜图层名＞.png
叠加为一张＜纹理集名＞_layers.png（按面板中的顺序，连同混合模式一起叠加）
  • 背景是透明的。因为只包含画过的部分，所以不做外扩。
  • 会记住上次的选择。
  • 2D 绘画中无法使用。请用“导出 PNG（所选纹理集）”导出（详细说明）。

将 UV 贴图导出为 PNG

把 UV 线条导出为 PNG。用于在其他绘画软件中叠加为底图进行绘制。

  1. 选择要导出的纹理集。
  2. 选择 文件 → 导出 →“将 UV 贴图导出为 PNG（所选集合）”（纹理集所在行的右键菜单中也有）。
  3. 在窗口中选择下列项目，点击“导出”。会生成 ＜纹理集名＞_uv.png。
项目可选内容
分辨率保持不变（纹理集分辨率）、512–8192
线的颜色白色、黑色、前景色
背景透明、黑色、白色（选透明时，可在其他软件中叠加到图像上）
线宽1、2、3、4、6、8px
UV 岛边缘“岛边缘以 2 倍粗细绘制”（默认开启）
导出位置与其他导出相同（详细说明）
  • 2D 画布没有 UV，因此无法导出。请选择 3D 模型的纹理集。
  • 只想在 PetaNuri3D 内查看 UV 线条时，用 UV 区域的“UV 线”即可（显示 UV 并直接绘制）。

导出、导入 PSD Standard

保留图层分开，导出为 PSD。用于在其他绘画软件中继续绘制，或作为改造用 PSD 分发。

  1. 选择 文件 → 导出 →“导出 PSD（所选纹理集）”或“导出 PSD（全部纹理集）”。
  2. 在导出窗口中确认外扩和导出位置，点击“导出”。
  3. 会生成 ＜纹理集名＞.psd。完成后会显示大小和图层数量。

PSD 中包含的内容

  • 图层、显示状态、不透明度、混合模式、剪贴、锁定透明像素、文件夹、图层蒙版和颜色标签（图层的颜色）都会保留。
  • 调整图层也会以调整图层的形式保留（渐变映射保持为色点形式）。色相/饱和度/明度中的“着色”不会保留。
  • 纯色图层也会以纯色图层的形式保留（保留颜色值、蒙版、混合模式、不透明度和剪贴）。
  • 描边会作为已栅格化到像素上的图层写入。文字图层会变成普通图层。
  • 仅有描边、投影、外发光的基底图层，以及被剪贴的图层，会分别写入。另外会在上方添加只烘焙了效果的“（图层名称）（效果）”图层。存在填充不透明度、内侧效果等时，会合并为 1 个图层。
  • Pro 绘制目标、法线贴图、主颜色 2nd／3rd 的文件夹，会作为隐藏的组写入。用 PetaNuri3D 导入时会恢复原样。
  • 合成图像（不打开 PSD 就能读取的扁平图像）会带有外扩。图层本身保持绘制时的样子。
调整图层的计算方式在其他应用中打开时，外观可能略有不同。

导入 PSD

可以导入虚拟形象附带的改造用 PSD，接着绘制。导入后，该纹理集的图层会被替换为 PSD 的内容。

  1. 选择 文件 → 导入 →“导入 PSD（替换图层）”。
  2. 选择 PSD。会导入到与文件名同名的纹理集（body.psd → body）。没有匹配的纹理集时，导入到当前所选的纹理集。
  • 把 PSD 拖放到窗口中，也会同样导入。拖放到纹理集所在行，则导入到该纹理集（添加图像或 PSD）。
  • 大小不同时，会按纹理集的分辨率缩放。文件夹、蒙版和支持的调整图层保持不变。
  • 不支持的混合模式会改为“正常”，不支持的调整图层会被跳过，并在右下角显示提示。
  • 纯色图层会按纯色图层读取。形状（带矢量蒙版）、文字、渐变、图案以及带图层效果的纯色图层，会读取为图像图层。
  • 撤销（Ctrl+Z）一次即可还原。
  • 新建时，也可以把起始内容设为“PSD”来导入（打开 3D 模型）。

导出扩边（填充）

向 UV 岛外扩展边缘的颜色后导出。不扩展的话，游戏中应用缩小或 mipmap 时，UV 接缝处可能会出现线条。

  1. 在导出窗口的“外扩（填充）”中选择扩展的宽度。
  2. 点击“导出”。
可选值内容
无（不向 UV 岛外扩展）UV 岛外不扩展（如果能看到底色，则是底色的颜色）
4、8（默认）、16、32、64、128 px从 UV 岛边缘向外扩展相应宽度的颜色
填满 UV 岛外的全部区域用最近的 UV 岛的颜色，填满 UV 岛外的全部区域
  • 对 PNG、PSD 的合成图像、材质导出的图像（主颜色、阴影色、蒙版、法线贴图等全部）有效。PSD 的图层本身不扩展。
  • 所选图层的 PNG 和 UV 贴图不做外扩。
  • 该值与 UV 区域左下角的“边距”相同。无论在哪边更改，两边都会同步变化。在 UV 区域中按 1px 为单位设定的值，也会列在窗口中（绘制范围与边距）。
  • UV 岛外的像素，会取直线距离最近的 UV 岛像素的颜色。斜边也不会出现阶梯状，而是平滑地扩展。
  • 笔触边缘的淡薄部分不视为已绘制，而是先扩展不透明部分的颜色，再把淡薄部分叠加在上面。这样接缝处就不容易出现底色的线条。
  • 通过 Unity 联动发送的图像，扩展方式与导出的 PNG 相同（从 Unity 绘制）。
导出前，在 UV 区域显示“边距线”，就能直观确认会扩展到哪里。如果想连 UV 岛外也手绘，请把绘制范围设为“边距内”（详细说明）。

导出位置的文件夹

在导出窗口的“导出位置”中，可以每次都导出到固定的文件夹。预先选好 Unity 项目的 Textures 文件夹等会很方便。

  1. 在导出窗口中点击“选择文件夹”，选择文件夹。
  2. 勾选“每次都不询问，直接导出到此文件夹（覆盖同名文件）”。
  3. 之后导出 PNG、PSD、AO、.unitypackage 时，不再询问保存位置，直接写入该文件夹。
  • 点击“移除”，会恢复为每次导出都询问保存位置。
  • 没有指定文件夹时，保存位置窗口也会从上次导出的文件夹打开。
  • “导出后打开文件夹”默认就是勾选的。写完后会用资源管理器打开该文件夹。不需要时请取消勾选。
  • 导出期间会显示“正在导出…”，直到完成前无法操作。
  • 导出材质到文件夹（选择 Assets）时，从上次选中的 Assets 开始。
  • 在窗口中取消的话，在窗口中更改过的值（外扩、导出位置等）会恢复原样。
选择“每次都不询问”时，同名文件会不经确认直接被覆盖。

导出 2D 绘画的图像

不使用模型的 2D 绘画的图像，也可以导出为 PNG 或 PSD。

  • 点击画布下方栏中的“导出 PNG”，会生成 2D-paint.png。用 文件 → 导出 →“导出 PNG（所选纹理集）”效果相同。
  • Standard 要保留图层传递，请用 文件 → 导出 →“导出 PSD（所选纹理集）”，生成 2D-paint.psd。
  • 导出全部纹理集和所选图层，是为 3D 模型的纹理集准备的。2D 绘画中无法使用。
  • 也可以保存工程文件（无需模型的 2D 绘画）。
图章专用 2D 画布的图像不会包含在模型的导出中。请通过“注册为图章”做成图章使用（图章专用 2D 画布）。

导出 lilToon 材质与 AO Pro

  • lilToon 材质通过 文件 → 导出 →“导出材质（.unitypackage／文件夹）”，连同纹理一起导出。窗口中也有外扩和导出位置的栏（导出材质）。
  • 烘焙好的 AO，通过 滤镜 → 烘焙 →“将 AO 导出为 PNG（最后一次烘焙的结果）”，生成 ＜纹理集名＞_AO.png（烘焙 AO）。
