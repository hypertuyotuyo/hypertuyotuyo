导出

将完成的纹理导出为图片或材质。菜单为 文件 → 导出。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

本页内容
  • 导出为 PNG
  • 导出、导入 PSD
  • 导出扩边（填充）
  • 导出文件夹
  • 导出材质

导出为 PNG

  1. 选择 文件 → 导出 → 导出 PNG。
  2. 在小窗口选择导出扩边和导出位置，点击“导出”。
  3. 可导出当前纹理集或全部纹理集。文件名为 <材质名>.png。
含主颜色2nd／3rd 文件夹的纹理集会分别导出 PNG。描边等效果会包含在合成图片中。
烘焙的光、影和质感作为可见图层颜色写入 PNG。图章用2D画布工作纹理集不会导出到模型纹理。无模型的2D绘画可从画布下方“导出 PNG”保存。
将所选图层导出为 PNG（所有版本）：图层右键“将此图层导出为 PNG”，选多张后“将所选图层导出为 PNG”，或文件 → 导出 → 导出 PNG（所选图层）。背景为透明。两张以上时选择“逐个”（<材质名>_<图层名>.png）或“叠加为一张”（<材质名>_layers.png）。
导出窗口中的“分辨率”可按不同于纹理集的大小（512～8192）缩放导出（PNG、所选图层、材质；边距先按纹理集分辨率添加再缩放）。
UV 贴图（所有版本）：文件 → 导出 →“将 UV 贴图导出为 PNG（所选集合）”（纹理集右键菜单中也有）可将 UV 线保存为 <材质名>_uv.png。可选择分辨率、线条颜色（白、黑、前景色）、背景（透明、黑、白）、线宽，以及是否“岛边缘以 2 倍粗细绘制”。

导出、导入 PSD Standard

  • 文件 → 导出 → 导出 PSD，可保留图层、可见性、不透明度、混合模式、剪贴、锁定透明像素、文件夹、图层蒙版和调整图层（渐变映射保留色标）。
  • 描边保存为已烘焙像素的图层。文字图层变为普通图层。绘制目标、法线贴图、主颜色2nd／3rd 文件夹保存为隐藏组（导入后恢复）。
  • 将 PSD 拖入窗口，会导入到名称与文件名相同的材质。也可从纹理集面板对应行导入。
  • 也可导入虚拟形象附带的修改用 PSD，接着绘制。
调整图层的计算方式在其他应用中可能略有不同。
PSD（Standard、Pro）：仅带描边、投影、外发光效果的底层与其剪贴图层不再合并，而是分别写出，并在上方添加只烘焙了效果的“（图层名）（效果）”图层（若有填充不透明度、叠加、内部效果等，则仍像以前一样合为一张）。

导出扩边（填充）

导出时将边缘颜色扩展到 UV 岛外。不扩展时，缩小或使用 Mipmap 可能使 UV 接缝出现细线。

  • 可选择无、4、8（默认）、16、32、64、128 px、填满 UV 岛外区域（导出窗口、材质导出窗口）。
  • 适用于 PNG、PSD 合成图和材质图片。PSD 图层本身保留绘制原状。

v1.1.0 中，4096px 图片选择“全部”时，也可填满空白区域直至边缘。

边距值与 UV 区域左下共用。笔刷边缘的淡色部分不再视为已绘制：先将不透明部分的颜色扩展到岛外，再把淡色部分叠加在上面（接缝处不易出现底色线条）。“在新图层上生成边距”也采用相同规则。
边距的扩展方式：岛外的像素取直线距离最近的岛内像素颜色（斜边也不会呈阶梯状，而是平滑扩展）。通过 Unity 联动发送的图像与导出的 PNG 相同。

导出文件夹

  • 导出保存位置对话框会从上次导出文件夹打开。
  • 可先通过导出窗口“选择文件夹”设置，勾选“不再询问，导出到此文件夹”后，PNG、PSD、AO、.unitypackage 导出时不再询问位置，直接写入该文件夹。点击“移除”恢复每次询问。
  • 导出材质到文件夹（选择 Assets）时，从上次选中的 Assets 开始。
开启“不再询问”时，同名文件会被覆盖。

“导出后打开文件夹”默认开启。完成后可在资源管理器查看图片，不需要时可取消勾选。确定保存位置后会显示“正在导出…”和进度。
