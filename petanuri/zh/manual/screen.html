界面、面板、偏好设置

介绍界面各处有什么、面板和工具栏的移动方式、3D 视图外观的切换，以及偏好设置的全部项目。面板的布局在下次启动时也会恢复。

截图使用日语界面，正文中的菜单名称与所选应用语言一致。

先看这几点
  1. 没有显示的面板，用 显示 → 窗口 调出（详细说明）。
  2. 拖动面板的标题栏，可以把它移到喜欢的位置（详细说明）。
  3. 3D 的外观，用 3D 视图左上角的显示方式图标切换（详细说明）。
  4. 搞不清布局时，选择 显示 → 窗口 →“恢复默认窗口布局”（详细说明）。
  5. 设置在 文件 → 偏好设置（Ctrl+Alt+Shift+K）中（详细说明）。

界面各处有什么（初始布局）

这是首次启动时的排列。中间是绘制区域（3D 视图），左右排列着面板。

  • 上方：菜单栏。“文件”的右侧有新建、打开、保存，以及撤销、重做按钮（无法操作时会变淡）。
  • 左侧：工具栏，以及辅助工具、工具属性、画笔大小、参考图。
  • 右侧：共 3 列。紧邻 3D 视图右侧的是纹理集、图层属性、图层。再往右是色彩、颜色值、颜色集｜最近使用的颜色（标签页）、历史记录。
  • 最右侧：把对象，以及 Pro 的面板（顶点组、材质、混合形状、姿势）收起为图标栏的一列。点击图标，该面板会向侧边弹出。

随窗口大小调整的排列

  • 窗口较矮（高度不足 860）时，纹理集面板会折叠。纹理集通过图层面板的标题切换。
  • 宽度不足 1400（1280×720、1366×768 等）时，颜色一列也会并入最右侧的图标栏，以保留更宽的 3D 视图。宽度不足 1100 时，各列会进一步变窄，图层属性也会收入图标栏。
  • 保持初始布局时，更改窗口大小会重新排布。移动、折叠面板等改过布局之后，就不会再重新排布。
  • 布局在下次启动时也会恢复。

恢复初始布局

  1. 选择 显示 → 窗口 →“恢复默认窗口布局”。
  2. 面板会恢复为适合当前窗口大小的初始布局。工具栏也回到左侧，工具的顺序也恢复默认。

操作不顺利时

  • 面板和工具栏全都不见了：被 Tab 隐藏了。再按一次 Tab，或选择 显示 →“显示/隐藏面板”。
  • 找不到想用的面板：在 显示 → 窗口 中，给该面板打上 ✓（面板一览）。它也可能被收在最右侧的图标栏里。
  • 放大窗口后排列没有变化：改过布局后不会重新排布。用“恢复默认窗口布局”，可以按当前大小重新调整。

显示与隐藏面板（面板一览）

面板通过菜单 显示 → 窗口 显示或隐藏。带 ✓ 的是已显示的面板。

  1. 打开 显示 → 窗口。
  2. 选择想显示的面板名称。会打上 ✓，面板随即显示。
  3. 要隐藏时，再选一次。在面板标题上右键 →“隐藏此面板”也可以隐藏。
面板用途
辅助工具选择工具中的种类（G 笔、柔和毛笔等）（工具与辅助工具）
工具属性所选辅助工具的粗细、硬度等设置（画笔详细设置）
画笔大小从常用粗细的列表中选择（绘制）
参考图显示边看边画的图像（参考图）
工具箱把工具图标排成网格，下方是前景色、背景色。默认是隐藏的（工具栏）
纹理集选择要绘制的纹理集、分辨率、内存估算（纹理集）
图层属性所选图层的混合模式、不透明度等（图层属性）
图层添加、叠放、选择图层（图层）
色彩选择前景色（选择颜色）
颜色值前景色、背景色、HEX、数值、不透明度（选择颜色）
颜色集常用颜色的色板（选择颜色）
最近使用的颜色最近绘制过、吸取过的 12 种颜色（选择颜色）
历史记录到目前为止的操作列表。点击某一行即可回到那一步（历史记录）
对象按模型的部件显示或隐藏（对象）
顶点组 Pro用顶点组创建范围（顶点组）
材质 ProlilToon 的设置、绘制目标、导出（lilToon 材质）
混合形状 Pro改变表情和体型的形状（混合形状）
姿势 Pro移动骨骼来摆姿势（姿势模式）
  • 显示 → 窗口 中还有“工具栏”“3D 导航（隐藏后用右下角的图标恢复）”“其他角度小窗口”“常用工具（3D 视图）”“常用工具（UV 视图）”“锁定面板布局”“恢复默认窗口布局”。
  • 按 Tab（显示 →“显示/隐藏面板”）可以同时隐藏或显示工具栏和面板。想更宽地看 3D 视图时使用。
  • Pro 的面板在 Lite 中带有锁的标记，并显示说明代替内容。在 Standard 中不会出现在列表里。

移动面板

面板可以排在 3D 视图的左右（竖列）和上下（横条），列数、条数不限。也可以不放进任何位置，让它浮动。

  1. 拖动面板的标题栏。会在可放入的位置出现线条或边框。
  2. 在想放的位置松开。松开的位置就是最终位置。
松开的位置结果
列、条的中段插入该列或该条（在可放入的位置出现线条。在条中，面板会横向并排）
列、条的边缘在其旁边新建一列或一条（边缘会出现粗线）
3D 视图边缘的边框（“在左侧添加列”“在右侧添加列”“放在上方”“放在下方”）在那一侧新建一列或一条
其他位置（3D 视图中央等）变成浮动窗口

更改宽度、高度

  • 拖动列与列、条与条之间的分界线，可以改变宽度和高度。双击分界线可恢复原状。
  • 左右列中的面板，拖动下边缘的把手可以改变高度（双击恢复为自动）。内容较长时会在面板内滚动。
  • 变空的列或条会消失，3D 视图随之变宽。
  • 辅助工具的图块和画笔大小，会随面板的宽度和高度改变排列。只有画笔大小的列或浮动窗口，最窄可以缩到图块 1 列的宽度（约 64px）。

浮动窗口

  • 拖动标题栏移动，拖动右下角的把手改变大小。点击标题栏可折叠。
  • 没有 ×。要隐藏时，用 显示 → 窗口，或在标题栏上右键 →“隐藏此面板”。
  • 面板只能放在应用窗口内，不能拿到应用之外的其他窗口里。

固定布局

  • 给 显示 → 窗口 →“锁定面板布局”打上 ✓ 后，面板将无法移动，也无法改变大小。可以防止误动。
  • 锁定期间，浮动窗口仍可拖动标题栏移动，也可以改变大小。
  • 浮动窗口可以用右上角的锁，单独固定或解除该窗口。固定后既不能移动，也不能改变大小（下次打开时也会记住）。

折叠面板、合并为标签页

把不用的面板缩小，可以更宽地使用其他面板和 3D 视图。

想做的事操作
只留标题栏（折叠）点击面板的标题栏。再点一次即可恢复。在条中折叠的面板，会变成只有标题栏的细长竖条
合并为标签页把标题栏拖到另一个面板的标题栏上。出现“放到此处以合并为标签页”时松开。用上方的标签页切换
折叠标签页再点一次当前选中的标签页
分离标签页把标签页拖到外面（也可以在标签页上右键 →“分离此标签页”）
整体移动标签页拖动标签页排列中的空白处
把列变成图标栏点击列上方的“<”或“>”。该列会变成只有图标的细条。再点一次即可恢复为原来的列
从图标栏中调出面板点击图标栏中的图标，只有该面板会向侧边弹出。点击外部、按 Esc 或再点同一个图标即可收回

工具栏、常用工具

工具栏默认在左侧。也可以放到工作区的上、下、右侧，或让它浮动。

  1. 拖动工具栏的把手（竖排时在上端，横排时在左端）。工作区的 4 条边会出现吸附位置。
  2. 在吸附位置松开，工具栏就会固定在那一边。放在上、下时横向排列，放不下时会换行。
  • 在吸附位置以外松开，工具栏会浮动。浮动的工具栏可用“横向”“纵向”切换排列，双击把手可回到之前的边。
  • 在按钮上右键 →“工具栏位置”，也可以选择 左、右、上、下、浮动。位置在下次启动时也会保留。
  • 在按钮上右键 →“工具栏图标大小”可选 大、小；“工具栏列数”可选“列数：自动”“列数：始终 1 列”。放不下的工具，可用滚轮、两端的箭头或用笔拖动来滚动查看。
  • 排序：拖动按钮（用笔也可以），按喜欢的顺序排列。稍微拖动后松开是排序，不拖动直接松开则是选中该工具。右键“恢复默认顺序”可恢复原来的顺序。
  • 界面颜色：用工具栏最末尾的太阳和月亮开关，切换浅色和深色（深色模式）。
  • 隐藏：取消 显示 → 窗口 →“工具栏”的 ✓。
  • 工具箱：通过 显示 → 窗口 →“工具箱”，可以显示把工具图标排成网格的面板。与其他面板一样，可以放进列或标签页，并随宽度换行。点击下方的前景色会打开“色彩”面板，点击背景色或 ⇄ 可互换，点击小的黑白图标或按 D 可恢复为黑、白。

常用工具栏

把常用的工具和辅助工具排在 3D 视图和 UV 视图上方的小条中，可以快速切换。

  1. 右键点击工具栏的按钮，或辅助工具（也包括画笔集的预设）。
  2. 选择“添加到常用”。图标会添加到条中。
  3. 点击条中的图标，就会切换到该工具或辅助工具。
  • 点击条中的“＋”可添加当前的辅助工具；已添加时显示“－”，可以移除（只用笔也能操作）。在图标上右键也可以移除。
  • 拖动左侧的点状把手可移动条，拖动图标可排序。
  • 在条上右键，有“纵向排列”“恢复默认位置”“隐藏此工具条”。点击 × 也可以隐藏。
  • 隐藏的条，可以通过 显示 → 窗口 →“常用工具（3D 视图）”“常用工具（UV 视图）”分别再次显示。

3D 视图四角的图标

3D 视图的四角排列着显示切换和视角的图标。带 ▼ 的图标，点击下方的 ▼ 会打开设置（按 Esc 或点击外部即可关闭）。

位置内容
左上网格线（网格线）、显示方式（外观）、单面/双面、对称绘制 X、Y、Z（对称绘制）、显示范围（显示范围）
上方中央切换绘制/姿势。处于姿势模式时变为骨骼操作（姿势）；正在绘制某个绘制目标时，变为该绘制目标的操作（绘制目标）
右上正面、背面、右、左、上、下、透视/正交 ▼、显示全部。3D 导航默认也在右上（3D 导航）
右下缩小 3D 导航时的图标、其他角度小窗口（其他角度小窗口）
左下切换到所触及处、主与副纹理集、跨纹理集绘制（跨两个纹理集绘制）
下方中央选区工具条（选区工具条）、隐藏期间的栏（隐藏笔）
  • 上方中央的条，拖动左侧的把手（⋮）可以移到任意位置。双击把手可回到原位。
  • 3D 视图较窄时，右上的图标会变成 2 排。仍然放不下时，会按 视角 → 显示范围 → 对称 → 单面/双面 → 显示方式 → 网格线 的顺序，收进左上的“⋯”面板。点击“⋯”即可展开。
  • 更窄时，左下的条会隐藏文字，只留图标；再窄就会收进“⋯”面板。宽窄取决于 3D 视图的宽度，而不是窗口的宽度。

更改视角（视野角度）

通过右上角透视/正交图标的 ▼，可以更改投影方式，以及透视投影的视野角度（5–120°）。数值越小越接近长焦，越大越接近广角。点击“恢复默认值”会恢复为 30°。

用 3D 导航移动视角

3D 导航是不用鼠标按钮和键盘就能移动视角的工具。只用笔绘制时很方便。

操作作用
点击轴的圆点（X、Y、Z）切换到该轴的视角（X＝右，-Y＝正面，Z＝上）。再点一次切换到反方向
拖动球旋转
上下拖动放大镜缩放
拖动抓手平移
左右拖动圆形箭头画面旋转（向右为顺时针。双击恢复为 0°）
球下方的 ⟲、角度、⟳点击 ⟲、⟳ 每次将画面旋转 15°。点击角度恢复为 0°
方形按钮显示全部
透视/平行按钮切换透视投影和正交投影
锁形按钮锁定相机方向（见下文）
  • 对齐到轴的视角时会变为正交投影，旋转后恢复为透视投影（可在 文件 → 偏好设置 → 操作 →“轴视角使用平行投影”中关闭）。
  • 也可以用键盘的小键盘切换视角（视角（小键盘））。

锁定相机方向

点击锁形按钮，只会停止视角的旋转。仍可平移和缩放。再点一次即可解除。用于保持确定好的方向，靠近或移动着绘制。

倾斜画面（画面旋转）

可以像倾斜一张纸那样倾斜 3D 视图，调到顺手的角度。

  • Shift+滚轮每次旋转 5°，3D 导航的 ⟲、⟳ 每次旋转 15°。左右拖动圆形箭头也可以旋转。
  • 光标位于 UV 区域上时，旋转的是 UV。
  • 旋转后，绘制、选择、平移、右键拖动旋转都照常可用。拖动会沿着看到的方向移动。
  • 在键位设置中的“向左旋转画面（15°）”“向右旋转画面（15°）”“恢复画面旋转默认值”也可以设置按键（默认没有按键）。

移动、缩小导航

  • 拖动上方的把手（…）可移到任意位置。双击回到右上。
  • 拖动左边缘、下边缘、左下角可以改变大小。也可以在 文件 → 偏好设置 → 界面 的“3D 导航大小”中更改。
  • 点击“—”缩小为右下角的图标。点击图标即可恢复（也可通过 显示 → 窗口 →“3D 导航（隐藏后用右下角的图标恢复）”）。
  • 可以在导航下方显示旋转和缩放滑块。请在 文件 → 偏好设置 → 界面 中开启“在导航中显示旋转、缩放滑块”（默认关闭）。3D 导航和 UV 的导引上都会显示。

用其他角度的小窗口同时查看

在 3D 视图中显示由另一台相机拍摄的小型 3D。可以边画边确认反面或侧面的样子。小窗口只用于查看，绘制仍在大的视图中进行。

  1. 点击 3D 视图右下角的“其他角度小窗口”图标（也可通过 显示 → 窗口 →“其他角度小窗口”）。
  2. 在小窗口的标题栏中选择方向（正面、右、背面、左、上、反向）。“反向”是大视图视角的反方向。
  • 在小窗口中拖动旋转，用中键或 Shift+拖动平移。
  • 用滚轮或 Ctrl+拖动（向上拖为靠近，适合用笔）拉近、拉远，双击显示全部。
  • 用标题栏移动，拖动左、上边缘和左上角改变大小。点击 ✕ 关闭。

将 3D 与 UV 设为小窗口

并排显示 3D 和 UV 时，可以把其中一个设为小窗口，更宽地使用另一个。

  1. 按 U 显示 UV，与 3D 并排（显示 UV 区域）。
  2. 点击想设为小窗口的一侧右上 ✕ 下方的按钮。该侧变为小窗口，另一侧占满整个区域。
  • 也可以用 显示 → UV →“UV 放入小窗口（3D 全屏）”“3D 放入小窗口（UV 全屏）”，或 UV 标题栏上的 ⋯ 做到同样的事。
  • 拖动标题栏移动小窗口，拖动四边和四角改变大小。只要在应用窗口内，也可以放在面板上方。
  • 点击 ⇄ 互换小窗口和全屏，点击 ▣ 恢复为并排显示，点击 ✕ 关闭小窗口一侧。
  • 用右上角的锁固定（既不能移动，也不能改变大小）。即使按 Tab 隐藏了面板，小窗口也会保留。

更改外观（显示方式、光照方向）

切换 3D 视图的外观。变化的只有外观，绘制的内容和导出的图像不会改变。

  1. 点击 3D 视图左上角的显示方式图标（也可以通过 显示 → 显示方式 选择）。
  2. 选择想用的方式。下次启动时也会以同样的方式打开。
显示方式外观

二值卡通用受光处和阴影两种颜色显示
明暗（可看出凹凸）打光使凹凸清晰可见。初次使用时以此方式打开

单面显示、双面显示

与同一排图标一起，或通过 显示 → 显示方式 选择。有“单面显示（不绘制背面）”和“双面显示（可见的背面也绘制）”。要在衣服内侧等背面绘制时，请设为双面（也绘制背面和被遮挡的面）。

更改光照方向

  1. 点击显示方式图标下方的 ▼。
  2. 拖动球来决定光线的来向。也可以用左右、高度的滑块更改。
  3. 开启“跟随相机”后，即使旋转视角，光照效果也保持不变。点击“恢复默认”可恢复原状。
  • 二值卡通、明暗、最终效果使用同一种光。在“保持绘制颜色”下看不到光。
  • Pro 与材质面板中的“显示与光照”是同一个值。
  • 相机操作为“Alt＋鼠标按钮”时，可以用 Shift+右键拖动来旋转光的左右方向。

透明部分的显示方式

  • 用橡皮擦或透明色绘制的地方，在 3D 中下面会显示棋盘格。关闭 显示 → 显示方式 →“以棋盘格显示透明处”后，会变成灰色。
  • 在纹理集所在行右键（或点“…”）→“Alpha 镂空（在 3D 中去掉透明处）”，可以选择透明的显示方式。有“无”、“镂空”（去掉不透明度低于 50% 的部分，露出后面）和“半透明”（按不透明度透出）。
  • Alpha 镂空也只影响外观，导出的图像不会改变。它会保存在工程文件中，也可以撤销。被镂空的地方在 3D 中无法点击，请在 UV 区域中绘制。

按像素显示纹理

在 3D 中不对纹理插值，而是按 1 个像素一个方块显示。适用于 32、64px 等低分辨率纹理和像素画。

  • 按纹理集分别切换：在纹理集行的 ⋯ 或右键 →“按像素显示（不插值）”。已开启的纹理集，该行会出现方块标记（点击可关闭）。
  • 256px 以下的纹理集一开始就是开启的（自动）。自己切换过的纹理集会保存在工程文件中，可以用“像素显示恢复为自动”恢复。
  • 通过 显示 → 显示方式 →“所有纹理集按像素显示（不插值）”，可以一次切换所有纹理集。
  • UV 区域在放大时始终按像素显示。

操作不顺利时

  • 带有阴影，看不清绘制的颜色：把显示方式设为“保持绘制颜色”。
  • 更改光照方向，外观却没有变化：在“保持绘制颜色”下看不到光。请改为二值卡通或明暗。
  • 变成透明的地方显示为灰色或棋盘格：这只是外观。想透过它看到后面时，请把纹理集的“Alpha 镂空”设为镂空或半透明。
  • 设为 Alpha 镂空后，那里无法绘制：被镂空的地方在 3D 中无法点击。请在 UV 区域中绘制，或把 Alpha 镂空恢复为“无”。
  • 低分辨率纹理在 3D 中显得模糊：开启该纹理集的“按像素显示（不插值）”。
  • 无法选择“最终效果”：这是 Pro 专用的显示方式（版本对比）。

右键菜单

操作不顺利时

  • 绘制细节时，菜单自己弹出来：这是笔的长按触发的。请关闭 文件 → 偏好设置 → 笔与输入 → 菜单和按钮 中的“用笔长按弹出菜单”。右键和笔侧键弹出的菜单不受影响。
  • 长按按钮会弹出菜单，导致无法点按：把同一处的“按钮上的长按”设为“按下松开即确定（默认）”。

弹出调色板（仅用数位笔操作）

这是一个圆形调色板，握着笔就能当场更改颜色、辅助工具和画笔大小。

  1. 在 3D 视图或 UV 区域上，按下笔的侧键。
  2. 笔不动，松开侧键。圆形调色板会在原地弹出（如果移动笔，则和以前一样是旋转、平移）。
  3. 用完后点击调色板外部（不会绘制）。按 Esc 或再轻点一次右键也可以关闭。
  • 外圈：常用的辅助工具。点击后切换并关闭。点击“＋”添加当前的辅助工具，长按或右键可移除（最多 10 个）。
  • 内侧：用色相环以及饱和度、明度的方块选择前景色。上方的小圆点是最近使用的颜色。
  • 下方的标签：上下拖动可更改画笔大小。
  • 用鼠标弹出时，请把 文件 → 偏好设置 → 操作 → 鼠标 中的“右键”设为“弹出调色板”（默认为“菜单”）。也可以用右键菜单最上方的“显示弹出调色板”弹出。
  • 在数位板设置中关闭了 Windows Ink 时，侧键也会作为鼠标右键传来，因此遵循上面“右键”的设置。

边看参考图边绘制

把资料图像显示在面板中，可以边看边画。也可以从图像中吸取颜色。

  1. 点击参考图面板的“打开”，选择图像。
  2. 用下方的缩略图切换已打开的图像。点击 × 关闭。
  • 通过 文件 → 导入 →“打开参考图”、拖放到面板中，或点击面板后按 Ctrl+V，也可以打开。
  • 吸取颜色：用吸管在图像上点击或拖动。松开后，该颜色会加入最近使用的颜色。
  • 移动：用抓手、中键、右键或 Space+拖动来移动，用滚轮缩放。
  • 显示方式：用上方的按钮可显示全部、左右翻转、旋转 90°。用放大镜的 ＋、－ 缩放（只用笔也可以），“100%”则让图像的 1 个像素对应屏幕的 1 个点。
  • 图像会以长边 1600px 保存，下次启动时也会恢复。

界面的通用操作

在任何面板、窗口中都通用的操作。

  • 按钮和项目的说明，把光标（笔尖）放在名称上就会显示。
  • 偏好设置、快捷键列表和确认窗口，可以拖动标题栏移动。用右上角的 × 或 Esc 关闭。
  • 菜单项和按钮，用笔按下后松开也能确定（可在笔与输入中更改）。
  • 笔的双击，即使第二次点击的位置略有偏移（12px、0.5 秒以内），也会当作双击。
  • 笔的橡皮擦端，在面板、窗口的操作（按钮、滑块、排序、拖动）中与笔尖效果相同。在绘制区域内则作为橡皮擦。
  • 浏览器的操作键（刷新、打印、页面缩放等）无效。界面上的文字无法选中（输入框除外）。
  • 当前版本无法使用的功能，菜单和按钮会变淡并带有锁的标记（版本对比）。

更改深色模式、配色、语言

在明亮的“浅色”和暗色的“深色”之间切换界面颜色。

  1. 点击工具栏最末尾（竖排时在下端，横排时在右端）的太阳和月亮开关。
  2. 在浅色和深色之间切换。
  • 在 文件 → 偏好设置 → 界面 → 显示 的“界面颜色”中也一样（默认为浅色）。
  • 要用按键切换时，请给键位设置中“显示”分类里的“深色模式”分配按键（分配按键）。

更改配色

在 文件 → 偏好设置 → 界面 → 显示 的“配色”中，可以更改界面底色、面板、按钮、文字、主要颜色、辅助色、3D 背景、UV 背景和工具栏颜色。

  • 浅色和深色分别保存。
  • 点击“恢复默认配色”可恢复为原来的颜色。

更改界面语言

在 文件 → 偏好设置 → 界面 → 语言 的“语言 / Language”中选择。有 日本語、English、한국어、中文（简体）、中文（繁體）。

偏好设置

这是整个应用的设置。通过 文件 → 偏好设置（Ctrl+Alt+Shift+K）打开。

  • 左侧是分类，右侧是各小节。点击小节的标题可展开或折叠（折叠状态下次也会保持）。
  • 项目的说明，把光标放在名称上就会显示。
  • 设置在下次启动时也会保留。

  • 笔的侧键汇总在数位笔按键、Windows Ink中。
