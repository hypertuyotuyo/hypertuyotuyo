v1.3.0

v1.3.0 准备发布中

发布日期未定

在应用内自动更新、修复从屏幕取色、蕾丝笔刷、UV 改变时对齐绘画

本页中 v1.3.0 的内容是发布前的预告。当前发布版本为 v1.2.1。

现在可以在应用内自动更新。此版本新增了绘制功能和联动功能，并修复了大量问题（原定的 v1.2.2 内容也包含在此版本中）。未特别注明的功能在所有版本（Lite、Standard、Pro）中均可使用。

重大变更

现在可以在应用内自动更新（Windows）

  • 有新版本时会显示通知，只需确认 1 次，即可完成下载、校验（签名和内容）、替换和重新启动也可以设置为启动时不自动下载（偏好设置 → 系统 → 启动）。无法从官方网站获取时，会像以前一样改为提示从 BOOTH 下载
  • 发布形式已改变：每个版本 1 个 ZIP。解压后的“PetaNuri3D”文件夹中包含主程序和 setup.exe请用 setup.exe 安装，或直接运行文件夹中的 PetaNuri3D-win_x64.exe（不要只取出 setup.exe，请连同整个文件夹一起使用）

注意（从旧版本更新的用户）

  • 从 v1.2.1 及更早版本更新时，仅这一次需要手动进行请保存作品并关闭应用，解压 ZIP，然后双击其中的 setup.exe（会覆盖安装到之前用 setup 安装的位置）。v1.2.1 及更早版本的“安装并重新启动”无法找到新形式的 ZIP
  • 已将 Standard 升级为 Pro 的用户，无需重新导入升级文件（今后更新后也仍为 Pro）
  • 请同时更新 Unity 联动插件 Pro为传递主颜色 2nd／3rd，更新了联动协议。旧插件仍可连接，但不会传递 2nd／3rd
  • 在旧版本中打开合并了法线贴图图像的工程文件时，颜色可能会变化几个色阶。请在 v1.3.0 中编辑

变更

绘制方式与文件处理

  • Pro 升级文件不再受版本限制（导入一次后，更新到新版本也仍为 Pro。以前购买的文件也可直接使用）
  • 印章图像不再缩小，按原始分辨率使用（以前会将长边缩小到 1,024px）
  • 取消了导入的笔刷笔尖和图案的保存数量上限
  • “跨纹理集绘制”时，笔刷不再溢出到笔尖未落在其上的纹理集（以前画眼睛时可能会涂到皮肤）
  • 可以选择不使选区外变暗的显示（菜单“选区 → 使选区外变暗”）

新功能

绘制与颜色

  • 改为前景色（保持透明度）：仅将已绘制部分的颜色改为当前前景色，适合为线稿换色（编辑菜单、图层右键）
  • 蕾丝笔刷（扇贝边、狗牙边、小花、网眼）：沿线条排列成带状，在曲线、拐角和 3D 上也能连贯
  • 图形工具可使用笔尖图像：可沿图形轮廓排列绘制缝线等
  • 模糊、涂抹、混色也可选择笔刷笔尖
  • 吸管放大镜：放大显示取色位置周围（3D、UV。可在工具属性中关闭）
  • 将选区内的绘画镜像复制到另一侧，蒙版也可左右镜像复制

模型与联动

  • 重新加载模型且 UV 改变时，将已绘制的绘画对齐到新 UV（Blender、Unity 联动时自动进行）
  • 不含模型（FBX）保存：用于分发的小型工程文件。打开时选择本地的模型
  • Unity 联动时也读取并写回 lilToon 的主颜色 2nd／3rd Pro
  • 合并法线贴图图像 Pro
  • 将 2D 绘画导出为 PSD Standard Pro

界面与操作

  • 3D 导航中的相机方向锁定（只停止旋转，仍可平移和缩放）
  • 导航下方的旋转、缩放滑块（偏好设置 → 界面 → 显示，也可在导航上右键）
  • 偏好设置的配色中新增“UV 背景”
  • 在工具栏上右键可选“列数：自动”“列数：始终 1 列”。放不下的工具可用滚轮等翻动
  • 繁体中文（中文（繁體））显示

问题修复

从屏幕取色（exe 版）

  • v1.2.1 中无法使用“从屏幕取色”（打开后总是立即被取消，有时还会显示“EyeDropper is not available”）不再使用显示引擎（WebView2）的吸管，改用 PetaNuri3D 自己的吸管。看着放大镜（放大画面和颜色值），单击或按 Enter／Space 取色。方向键每次移动 1 像素（按住 Shift 为 10 像素），按 Esc 或右键单击取消（取色基于开始时截取的画面，因此视频等会显示为静止）

保存与读取

  • 保存位置空间不足时，可能会用中途截断的文件替换工程文件并显示“已保存”（现在会保留原文件并提示）
  • 保存位置停止响应时，会一直显示“保存中…”而不作任何提示
  • 大型 PSD（超过约 115MB 或 50 个图层）因内存不足无法读取（Unity 联动时无法读取主颜色 2nd 的 PSD 也是这个原因）
  • 读取、导出大型 PSD 或保存大型工程文件时，画面会长时间卡住并占用大量内存
  • 不同作品的自动保存可能被归为同一组，导致之前作品的自动保存被删除
  • 重新加载模型后，隐藏的对象会全部重新显示
  • 在 2D 绘画中无法从菜单读取 PSD

绘制

  • 在头发和多层衣物上对称绘制时，另一侧会稍有偏移
  • 对称时使用涂抹，左右效果不同
  • 带着粗描边填补内侧漏涂处时，描边会呈锯齿状扩张
  • 用喷枪等以透明色轻轻擦除时，痕迹看起来很粗糙
  • PNG 导出时，即使将外扩（填充）设为 64、128px，也会停在 32px
  • Ctrl＋＝／Ctrl＋－ 无法放大、缩小

图层与合并

  • 合并包含底色的文件夹等操作时，底色的特殊处理（无法删除的底层）会丢失
  • 隐藏或锁定的图层、文件夹在合并时可能消失，或被意外合并
  • 解除文件夹时，文件夹的不透明度、混合模式和蒙版会被悄悄移除（现在移除时会提示）

联动

  • 导出到 Unity 时，若无法读取 Unity 正在使用的 .meta，可能会用新 ID 重写 Pro
  • 导出 lilToon 材质时，读取后在 Unity 中更改的设置会被还原 Pro
  • Blender 联动中无法创建覆盖前的副本时，会在没有副本的情况下覆盖
  • 还修复了其他细小问题

v1.2.1

最新

2026-10-15

WinTab 与笔的修复、辅助程序并入主程序、缝线、3D 鼠标与发光混合模式

根据 v1.2.0 用户的反馈，修复了问题并新增了一些功能。未特别注明的功能在所有版本（Lite、Standard、Pro）中均可使用。

重大变更

辅助程序已并入主程序（Windows）

  • tools 文件夹中的辅助程序（关闭监视、笔侧键、WinTab 压感、3D 鼠标、提前显示笔画）现在在 PetaNuri3D 主程序内部运行。用法和设置不变字体列表、Unity .meta 搜索、更新检查、打开导出文件也在主程序内部完成，不再启动 PowerShell 等
  • 用 setup 覆盖安装时，旧版本 tools 中的辅助程序会被删除。使用 ZIP 的用户请解压到新文件夹（用 CUDA 烘焙 AO 的辅助程序仍是独立程序）
  • “提前显示笔画”的窗口只在 PetaNuri3D 位于前台时显示

注意（从旧版本更新的用户）

  • 更新时，请先保存作品并关闭应用，再运行新的 setup 或解压新的 ZIP
  • 使用 v1.2.0 的用户，可通过应用中的新版本通知进行更新用“在 BOOTH 下载”下载 setup 压缩包后，即可通过“安装并重新启动”替换
  • 将 Standard 升级为 Pro 的用户，请同时重新安装 v1.2.1 的升级文件使用“安装并重新启动”时，如果也下载了升级文件，会一并替换
  • 重新安装或更新数位板驱动时，请先关闭 PetaNuri3D（使用 WinTab 时会一直打开驱动的文件）
  • 工具“凹凸”已更名为“缝线”（见下方“变更”）

变更

工具“凹凸”更名为“缝线”

  • 针脚（虚线、鼓起、拼缝、滚边、十字绣、锯齿、铆钉）用前景色绘制到当前图层（所有版本，2D 画布上也可以）想做成凹凸时，请开启工具属性中的“在法线贴图文件夹中绘制”（Pro；褶皱、鼓包照旧以高度绘制）
  • 旧版本保存的子工具中，未做更改的针脚会一次性切换为新动作（用前景色绘制）；更改过大小或名称的照旧以高度绘制

新功能

绘制与图层

  • 混合模式“相加（发光）”“颜色减淡（发光）”即使在降低不透明度处、柔软笔刷边缘或下方透明处，也会像发光一样明亮叠加（图层、文件夹、画笔绘制模式等）
  • 模糊会随涂抹、来回次数增加而融合（可在工具属性中恢复以前的效果）
  • 混色融合得更宽更柔和
  • 可关闭图章的“淡淡显示下一个放置位置”
  • “从 UV 边缘绘制”窗口新增预览和颜色选择 Pro
  • 图层列表自动滚动到用按键等选中的图层

界面与操作

  • 可用 3D 鼠标（3Dconnexion SpaceMouse 等六轴设备）操作视角（Windows）灵敏度等在 偏好设置 → 操作 → 3D 鼠标
  • 以开始旋转时光标所在处为中心旋转（偏好设置 → 操作 → 相机；默认关闭）
  • 可将 3D 模型或工程文件拖放到启动界面直接开始
  • 可关闭“用笔长按弹出菜单”“接收笔侧键的中键／右键点击”（偏好设置 → 笔与输入 → 菜单和按钮）

问题修复

保存与启动

  • 自动保存有时会卡住，导致无法手动保存或关闭（工程文件越大越容易发生）自动保存过程中也会优先手动保存；保存位置窗口没有返回时可选择“等待／取消上一次保存并继续”；自动保存本身也更轻量
  • 打开大的工程文件、PSD（超过 32MB）很慢
  • 画面卡住按两次 × 关闭后，后台有时会残留画面进程
  • 无法读取应用内容或启动时未连接成功时，有时会显示英文页面（已改为本地语言提示，并自动重新连接

笔与数位板

  • 开启“直接读取笔压（WinTab）”后，笔本身有时会完全没有反应（Wacom 等）更改了连接方式。不起作用时，请按 偏好设置 → 笔与输入 → 数位板 中的“WinTab 连接方式：重新查找”
  • WinTab 可用时，Windows Ink 的笔也会使用 WinTab 的压感（和倾斜）（可在同一位置关闭）
  • 笔侧键（数位屏、数位板；已在 Wacom、XP-Pen、Huion、GAOMON 上确认）：松开后 3D 仍在旋转／中键不起作用／拖动一点就停／笔尖无法绘制而变成旋转或平移／UV 区域中中键不起作用无法停止时，按 Esc 或用笔尖点击一次即可停止
  • 用笔在同一处持续涂抹时，有时会弹出右键菜单
  • 打开菜单时使用 Ctrl+＋／－或滚轮（包括数位屏的旋钮）会使整个应用界面放大缩小（重启前无法恢复）任何操作都不会再放大整个界面（偏好设置中的显示大小仍可使用）
  • 在 3D 中大幅放大并用细笔绘制时，线条有时会断开

其他

  • Unity 方式中 Alt+右键拖动的缩放方向与 Unity 相反（现在向下拖动为放大）
  • 套索填充在 UV 视图・2D 画布中不填充，在其他纹理集上无效
  • 马赛克、锐化、高反差保留等对透明区域上的线条无效 Standard Pro
  • “从 UV 边缘绘制”中，即使起点设为 0，岛边缘（内边距）也没有被绘制 Pro
  • 选择图层时，列表行会错位，靠下的图层被遮住
  • “选择在此处绘制的图层”在休眠的纹理集或不可见的位置无法正确选择
  • 重新分配的快捷键在菜单中显示不正确，或与旧版本中分配的快捷键重复
  • 选区很小时，移动、变形的“对称侧也”有时不显示
  • 在联系窗口中按 Enter 会关闭窗口
  • 英语、韩语、中文界面中，联系窗口文本的提问部分仍是日语
  • 还修复了其他细小问题

v1.2.0

已发布

2026-10-10

新增安装程序与新笔、小窗口与画面旋转以及 lilToon 设置

根据大家的需求，新增了许多功能。未特别注明的功能在所有版本（Lite、Standard、Pro）中均可使用。

重大变更

现在可以用安装程序安装

  • 解压 setup 压缩包，双击其中的 setup.exe 即可安装（无需管理员权限）
  • 从下次更新起，可直接用应用中的“安装并重新启动”更新
  • Standard、Pro 仍可像以前一样使用 ZIP 版

注意（从旧版本更新的用户）

  • 更新时，请先保存作品并关闭应用，再运行新的 setup 或解压新的 ZIP
  • 笔触手感的默认设置改为“仅靠压感入笔收笔”改回原来的手感：偏好设置 → 笔与输入 →“笔触手感”→“按长度入笔收笔”
  • 修正了 glTF、glb、VRM 的 UV 上下方向旧版本的项目文件在 UV 视图中的图像会上下颠倒（3D 外观不变）
  • 自动保存采用了新格式（v1.1.2 及更早版本无法读取 v1.2.0 的自动保存）
  • 将 Standard 升级为 Pro 的用户，请同时重新安装 v1.2.0 的升级文件

新功能

绘制

  • 液化笔（推动、膨胀、收缩、漩涡等，也支持对称）
  • 像素笔（对齐纹理像素清晰绘制）
  • 按像素显示纹理（按纹理集切换；256px 及以下默认开启）
  • 套索填充
  • 在 3D 中绘制也能涂到边距（最大 128px，平滑）
  • Ctrl＋拖动调整笔刷大小、硬度、不透明度和笔尖角度
  • 纹理角度、D 键将前景色／背景色恢复为黑／白、Alt／Ctrl＋Backspace 填充

选区、图层与蒙版

  • 选择所有相似颜色，选区的移动与变形也可对称
  • 图层左右镜像复制
  • 蒙版的复制、粘贴与黑白绘制
  • 将所选图层或 UV 贴图导出为 PNG，并可指定导出分辨率（512～8192）
  • 以棋盘格显示透明区域，以及 Alpha 镂空显示
  • 显示预设（为对象的显示／隐藏状态命名并保存）

界面与操作

  • 可将 3D 或 UV 之一放入小窗口（也可放在面板上方）
  • 画面旋转（可像纸张一样倾斜着画）
  • 抓手工具、用 Ctrl＋1·2·3 切换预设倍率
  • 工具箱面板、标尺栏
  • 笔按钮（中键、右键、后退／前进）在 Windows Ink 和 WinTab 下都能使用
  • 帮助 → 联系我们

滤镜与调整图层 Standard Pro

  • 色调曲线、色彩平衡、色温、自然饱和度、替换颜色、曝光度
  • 动感模糊、径向模糊、高反差保留、添加／减少杂色、马赛克、提取线稿、浮雕（可通过 PSD 往返保留的是色调曲线、色彩平衡、自然饱和度和曝光度）

Pro 新增功能 Pro

  • 大幅增加 lilToon 设置（反射、闪粉形状、各向异性反射、AudioLink 等，也支持 .mat 的读写）
  • 可将法线贴图图像和图案质感（针织、牛仔等）作为图层使用
  • 卡通阴影与天使光环的烘焙，以及主线等预设
  • 滤镜 →“从 UV 边缘绘制”
  • 姿势预设、混合形状的复制粘贴、加载 Unity 的 .anim

改进与修复

易用性

  • 绘制、撤销与自动保存更轻快（大型模型尤为明显）
  • 头发束等重复使用同一 UV 的部分也能在 3D 中绘制
  • 新增英语、韩语、中文翻译

问题修复

  • 有时无法用 × 关闭（卡住时按两次 × 即可关闭）
  • 睡眠恢复后自动保存可能停止，导致无法保存
  • 较大的项目文件（约 150MB 起）无法打开或无法从自动保存恢复
  • 在 UV 视图放大绘制时线条变淡；3D 变形（Ctrl＋T）的框不出现或跳动
  • 笔尖残留光标；用中键旋转会马上停止
  • 导出 PSD 时，带描边效果的图层与剪贴图层会合并为一张
  • 此外还修复了许多小问题

v1.1.2

已发布

2026-10-07

新增图层整理、UV 绘制范围与更多操作设置

  • 图层颜色标签（所有版本）：为图层和文件夹添加 8 种颜色标记以便整理。可一次应用到多个选中图层，列表上方的“按颜色显示”可只显示该颜色的图层。标签保存在项目中，PSD 导出与导入（Standard、Pro）时与 Photoshop 图层颜色互通。
  • UV 视图的绘制范围与边距（所有版本）：在左下选择“UV 内／边距内／全部”。除画笔、毛笔和橡皮外，图形、填充、渐变、图章、模糊和涂抹也遵循此范围。边距（0～32px 或全部）与导出共用同一数值，并可显示边距线。另新增“在新图层上生成边距”滤镜。
  • 重复图案（所有版本）：可在图层属性中，将图像文件、参考图像或图案以上下左右重复的方式铺满图层，也可对齐 UV 接缝。
  • 相机与显示（所有版本）：偏好设置 → 操作 → 相机新增“Unity 方式”。可在 3D 视图右上透视／平行的 ▼ 中将视角设为 5～120°，并新增隐藏纹理、仅显示网格线的显示方式。
  • 界面配色（所有版本）：在偏好设置 → 界面中更改窗口、面板、按钮、文字、强调色、3D 背景和工具栏的颜色。浅色与深色分别保存，可恢复初始配色。
  • 笔与操作（所有版本）：菜单和按钮可用笔按下后松开来确定（按钮上的长按行为可在偏好设置中选择）。新增长按按键临时切换工具的时间（0.15～2 秒）、快捷键设置的导出与导入，以及锁定面板布局。
  • 界面改进（所有版本）：菜单右侧新增新建、打开、保存与撤销、重做按钮。放不下的长菜单可在边缘滚动。对称绘制时显示对称参考线和对侧光标，常用工具栏可分别在 3D 与 UV 中显示。
  • 图层与纹理集（所有版本）：缩略图大小（小至特大）、将按钮栏放在上方的设置、多图层一起拖动、重命名时拖动选择文字。可移除纹理集的副集，重新加载模型时会询问纹理已变化的纹理集是否替换底色。
  • 绘制与语言（所有版本）：图形线宽与笔刷大小联动，参考图像吸管光标更易看清。补全英文、韩文、中文的缺失翻译，并在随附的使用说明中加入 v1.1.2 功能说明。
  • 修复：多边形填充与 3D 按面选择有时涂到远处三角形的问题、英文／韩文／中文下导出窗口等内容无法显示的问题、带边距导出时接缝偶尔出现线条的问题、剪贴图层颜色进入相邻 UV 岛的问题、不透明度滑块显示停止的问题等。

拓展绘制与操作方式的更新

  • 3D空间渐变（所有版本）：用普通渐变工具在模型表面或空白空间放置点，按与点的距离绘制。通过移动手柄、XYZ坐标、半径以及颜色/不透明度预设调整，在所选图层预览后应用。一次撤销即可恢复，取消则回到原图。普通空间渐变和 Pro 的点距离渐变烘焙新增距离环、颜色/不透明度色带和数值标签。拖动白色手柄调整扩散距离，拖动颜色手柄调整各颜色的位置，同时同步数值控件和颜色编辑器。引导可隐藏，烘焙的环位置也会反映边界位置和混合宽度。
  • 最低32px纹理（所有版本）：新建与调整分辨率支持32/64/128/256px，支持项目保存、重新打开和PNG导出。各版本最高分辨率保持不变。
  • 颜色辅助滑块（所有版本）：保留上方颜色区域和色相条，切换下方RGB/HSV滑块。重启后保留选择。
  • 相机操作（所有版本）：可选择右键式、中键式或 Alt 键式。也改善了笔侧键发送中键点击时的视角操作。
  • 隐藏面的对称绘制（所有版本）：在对称设置中启用后，3D画笔、笔刷、橡皮和印章也会作用于隐藏的对称面。默认关闭，不适用于UV绘制和填充。
  • VRM透明部分（所有版本）：保留VRM0/VRM1原始图像、透明设置、截断值和不透明度。透明设置不同的材质即使共用图像，也使用独立纹理集。
  • 外部笔刷笔尖（所有版本）：将ABR、GBR、GIH、图像和ZIP注册为子工具，也可读取SUT中可识别的PNG作为笔尖。不会完整复现原始设置、颜色和混色。SUT可能包含缩略图或其他素材。
  • MToon预览（Pro，测试版）：在材质的显示与光照设置中切换，参考VRM0/VRM1材质效果绘制。支持项目保存和撤销/重做。UV动画静态显示，不支持MToon材质的完整往返导出。
  • 血色左右对称（Pro）：轻松烘焙的血色位置新增左右对称选项，使用与绘制相同的X对称中心，移动点时另一侧同步移动。
  • 图层列表纵向扩展（所有版本）：修复面板向下扩展时列表停留在固定高度的问题，停靠、选项卡和独立窗口均随可用高度调整。
  • 绘制、操作和多语言修复：改善输入中笔刷大小跳变、倾斜表面的笔刷中心偏移、烘焙预览中的Alt相机操作、英文大小按钮及韩文烘焙按钮换行、外部笔刷错误消息和对称中心说明。
  • 精简说明（所有版本）：烘焙、渐变、笔刷和相机操作等较长的说明可通过圆形问号图标查看。支持悬停、点击、触控和键盘操作；当前点选提示和警告仍显示在界面中。

v1.1.0

已发布

2026年10月4日

轻松烘焙与绘制前的润色

新增“轻松烘焙（Easy Bake）”，可选择肌肤、服装和道具的润色效果。调整光照、光泽和布料质感后，即可继续绘制。还包含沿表面绘制、渐变，以及 v1.0.2 的导出改进。

轻松烘焙（Easy Bake） Pro

  • 12种润色预设：白皙且气色健康的肌肤、淡雅插画风肌肤、柔软布料、缎面、牛仔、皮革风服装，以及硬质道具等。保留原图层，将各效果创建为可编辑图层。
  • 指定添加红润的位置：可在 3D 视图放置最多16个点，并调整范围和强度。完成后会选中透明的“细节绘制”图层，可立即用画笔绘画。
  • 从新建界面进入：在选择底色的界面勾选“创建后打开轻松烘焙”。选择目标纹理集，预览后再确认。
  • 新增4种烘焙：边缘光、光泽高光、织纹与色差、薄处透光色。光照和光泽会按指定方向烘焙成颜色，不随视角变化。透光色会为封闭形状中的薄处添加颜色。
  • 整理滤镜菜单：将“轻松烘焙”放在分隔线下，单项功能集中在“烘焙”中。

绘制、擦除、渐变

  • 沿 3D 表面绘制已新增并设为默认。斜面和轮廓附近的笔画不易拉伸，圆笔尖的模糊也不易在折角处断开。仍可选择原有“匹配屏幕”方式。
  • 使用透明色绘画功能已新增。点击颜色面板的棋盘格按钮，或按 C 切换。擦除时保留画笔的笔尖、硬度和笔压。
  • 颜色与透明度渐变已新增。可用最多32点编辑颜色、位置和不透明度，从包括透明渐变在内的240种预设中选择。可用于 3D、UV 和 2D 画布。
  • 亮度转为透明度已加入滤镜菜单。白色变为透明，暗部保留为黑色阴影，便于仅为 AO 阴影换色。
  • 放置曲线尺控制点时，按Ctrl＋Z 可撤销最后一个控制点。避免撤销控制点时误删之前的笔画。

根据形状生成阴影 Pro

  • 烘焙柔和明暗：根据面方向和光照方向生成宽广的柔和阴影。可调整光照左右、上下方向、阴影范围、柔和度、颜色和强度，也提供预设。
  • 烘焙上下或点渐变：根据面方向、高度或到指定点的距离创建颜色与透明度渐变。中心可放在模型上或空间中，通过 3D 手柄或 XYZ 坐标移动。
  • 增强凹陷与凸起：为形状的凹陷添加阴影，为凸起添加亮色。“阴影模糊”会沿表面连接平滑阴影，也修复了 UV 接缝出现白线的问题。
  • 柔和投影：从光照方向生成投射的阴影。可选择投影与接收阴影的纹理集，也支持材质透明度。

阴影烘焙到新的透明图层中。烘焙后仍能像普通图层一样修改颜色和强度，擦除或继续绘制。

图章用画布与附加 2D 绘画功能

  • 将图章的“在 2D 画布中绘制”整合到普通 UV 视图和图层中。在专用正方形画布上绘画，可将合成效果直接注册为图章。
  • 从启动界面“用示例试试”下方，可开始无需 3D 模型的 2D 绘画。支持保留图层的保存与恢复、导出 PNG、注册图章。
  • 图章用画布与工程文件一起保存，导出模型纹理时会排除该画布。

操作与问题修复

  • 修复了阴影等预览保持打开时退出，导致退出确认窗口无法操作的问题。保存、退出或切换工程前，可选择确认或取消预览。
  • 在前方的确认窗口按 Enter・Esc 时，错误确认或取消后方预览的问题已修复。
  • 整理了预览期间的显示、前景色、保存等操作，为冲突操作显示禁用状态。也修复了切换其他滤镜或处理失败后，临时图层和操作限制未解除的问题。
  • 选择阴影预设后，会保留选中名称。渐变预设已去重，并整理为约3行的可滚动列表。
  • 2D 绘画专用按钮与文件菜单现使用同一 PNG 导出流程。
  • 使用条款（日语）已发布并附带于所有发行 ZIP 中。可查看生成纹理、插画的使用方式与应用再分发规定。
