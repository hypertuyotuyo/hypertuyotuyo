v1.1.1

最新

2026-10-05

拓展绘制与操作方式的更新

  • 3D空间渐变（所有版本）：用普通渐变工具在模型表面或空白空间放置点，按与点的距离绘制。通过移动手柄、XYZ坐标、半径以及颜色/不透明度预设调整，在所选图层预览后应用。一次撤销即可恢复，取消则回到原图。普通空间渐变和Pro的点距离渐变烘焙新增距离环、颜色/不透明度色带和数值标签。拖动白色手柄调整扩散距离，拖动颜色手柄调整各颜色的位置，同时同步数值控件和颜色编辑器。引导可隐藏，烘焙的环位置也会反映边界位置和混合宽度。
  • 最低32px纹理（所有版本）：新建与调整分辨率支持32/64/128/256px，支持项目保存、重新打开和PNG导出。各版本最高分辨率保持不变。
  • 颜色辅助滑块（所有版本）：保留上方颜色区域和色相条，切换下方RGB/HSV滑块。重启后保留选择。
  • 相机操作（所有版本）：可选择右键式、中键式或 Alt 键式。也改善了笔侧键发送中键点击时的视角操作。
  • 隐藏面的对称绘制（所有版本）：在对称设置中启用后，3D画笔、笔刷、橡皮和印章也会作用于隐藏的对称面。默认关闭，不适用于UV绘制和填充。
  • VRM透明部分（所有版本）：保留VRM0/VRM1原始图像、透明设置、截断值和不透明度。透明设置不同的材质即使共用图像，也使用独立纹理集。
  • 外部笔刷笔尖（所有版本）：将ABR、GBR、GIH、图像和ZIP注册为子工具，也可读取SUT中可识别的PNG作为笔尖。不会完整复现原始设置、颜色和混色。SUT可能包含缩略图或其他素材。
  • MToon预览（Pro，测试版）：在材质的显示与光照设置中切换，参考VRM0/VRM1材质效果绘制。支持项目保存和撤销/重做。UV动画静态显示，不支持MToon材质的完整往返导出。
  • 血色左右对称（Pro）：轻松烘焙的血色位置新增左右对称选项，使用与绘制相同的X对称中心，移动点时另一侧同步移动。
  • 图层列表纵向扩展（所有版本）：修复面板向下扩展时列表停留在固定高度的问题，停靠、选项卡和独立窗口均随可用高度调整。
  • 绘制、操作和多语言修复：改善输入中笔刷大小跳变、倾斜表面的笔刷中心偏移、烘焙预览中的Alt相机操作、英文大小按钮及韩文烘焙按钮换行、外部笔刷错误消息和对称中心说明。
  • 精简说明（所有版本）：烘焙、渐变、笔刷和相机操作等较长的说明可通过圆形问号图标查看。支持悬停、点击、触控和键盘操作；当前点选提示和警告仍显示在界面中。

笔中键操作已通过模拟输入和Huion设备验证，尚未在Wacom实机上确认。

v1.1.0

已发布

2026年10月4日

轻松烘焙与绘制前的润色

新增“轻松烘焙（Easy Bake）”，可选择肌肤、服装和道具的润色效果。调整光照、光泽和布料质感后，即可继续绘制。还包含沿表面绘制、渐变，以及 v1.0.2 的导出改进。

轻松烘焙（Easy Bake） Pro

  • 12种润色预设：白皙且气色健康的肌肤、淡雅插画风肌肤、柔软布料、缎面、牛仔、皮革风服装，以及硬质道具等。保留原图层，将各效果创建为可编辑图层。
  • 指定添加红润的位置：可在 3D 视图放置最多16个点，并调整范围和强度。完成后会选中透明的“细节绘制”图层，可立即用画笔绘画。
  • 从新建界面进入：在选择底色的界面勾选“创建后打开轻松烘焙”。选择目标纹理集，预览后再确认。
  • 新增4种烘焙：边缘光、光泽高光、织纹与色差、薄处透光色。光照和光泽会按指定方向烘焙成颜色，不随视角变化。透光色会为封闭形状中的薄处添加颜色。
  • 整理滤镜菜单：将“轻松烘焙”放在分隔线下，单项功能集中在“烘焙”中。

绘制、擦除、渐变

  • 沿 3D 表面绘制已新增并设为默认。斜面和轮廓附近的笔画不易拉伸，圆笔尖的模糊也不易在折角处断开。仍可选择原有“匹配屏幕”方式。
  • 使用透明色绘画功能已新增。点击颜色面板的棋盘格按钮，或按 C 切换。擦除时保留画笔的笔尖、硬度和笔压。
  • 颜色与透明度渐变已新增。可用最多32点编辑颜色、位置和不透明度，从包括透明渐变在内的240种预设中选择。可用于 3D、UV 和 2D 画布。
  • 亮度转为透明度已加入滤镜菜单。白色变为透明，暗部保留为黑色阴影，便于仅为 AO 阴影换色。
  • 放置曲线尺控制点时，按Ctrl＋Z 可撤销最后一个控制点。避免撤销控制点时误删之前的笔画。

根据形状生成阴影 Pro

  • 烘焙柔和明暗：根据面方向和光照方向生成宽广的柔和阴影。可调整光照左右、上下方向、阴影范围、柔和度、颜色和强度，也提供预设。
  • 烘焙上下或点渐变：根据面方向、高度或到指定点的距离创建颜色与透明度渐变。中心可放在模型上或空间中，通过 3D 手柄或 XYZ 坐标移动。
  • 增强凹陷与凸起：为形状的凹陷添加阴影，为凸起添加亮色。“阴影模糊”会沿表面连接平滑阴影，也修复了 UV 接缝出现白线的问题。
  • 柔和投影：从光照方向生成投射的阴影。可选择投影与接收阴影的纹理集，也支持材质透明度。

阴影烘焙到新的透明图层中。烘焙后仍能像普通图层一样修改颜色和强度，擦除或继续绘制。

图章用画布与附加 2D 绘画功能

  • 将图章的“在 2D 画布中绘制”整合到普通 UV 视图和图层中。在专用正方形画布上绘画，可将合成效果直接注册为图章。
  • 从启动界面“用示例试试”下方，可开始无需 3D 模型的 2D 绘画。支持保留图层的保存与恢复、导出 PNG、注册图章。
  • 图章用画布与工程文件一起保存，导出模型纹理时会排除该画布。

操作与问题修复

  • 修复了阴影等预览保持打开时退出，导致退出确认窗口无法操作的问题。保存、退出或切换工程前，可选择确认或取消预览。
  • 在前方的确认窗口按 Enter・Esc 时，错误确认或取消后方预览的问题已修复。
  • 整理了预览期间的显示、前景色、保存等操作，为冲突操作显示禁用状态。也修复了切换其他滤镜或处理失败后，临时图层和操作限制未解除的问题。
  • 选择阴影预设后，会保留选中名称。渐变预设已去重，并整理为约3行的可滚动列表。
  • 2D 绘画专用按钮与文件菜单现使用同一 PNG 导出流程。
  • 使用条款（日语）已发布并附带于所有发行 ZIP 中。可查看生成纹理、插画的使用方式与应用再分发规定。

v1.0.2

合并到 v1.1.0

制作：2026年10月4日

导出进度与 UV 岛外扩边

此版不单独发行，改进已整合到 v1.1.0。

  • 导出 PNG、PSD、AO、Unity 文件等时，现在会显示文件名和进度。
  • 导出后会打开文件夹，并选中已保存的文件。可在导出窗口关闭此功能。
  • 修复了将扩边设置为“填满 UV 岛外的全部区域”时，4096px 纹理发生错误而无法导出，以及远离 UV 岛的区域仍保持透明的问题。

已发布

2026年10月3日

合并纹理集与 Unity 联动改进

  • 新建时，使用同一图片的材质可合并为一个纹理集。绘制内容会反映到所有目标，只需导出一张纹理。
  • 新增从新建界面“合并”手动合并、重新拆分纹理集的操作。
  • Unity 联动窗口现显示应用位置、待绘制的网格和纹理，以及启动、连接和保存状态。也修复了可选中缺少必要文件的 exe 的问题。
  • 修复 Lite 中切换英语未生效的问题。
  • 应用更新通知现在会打开 BOOTH 商品页面。
