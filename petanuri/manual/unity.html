Unity から塗る・AI 連携

Unity でアバターを選んでぺたぬり3D を起動し、そのまま塗れます。どの版（Lite・Standard・Pro）でも使えます。

このページの内容
  • Unity から起動して塗る
  • AI 連携（MCP）

Unity から起動して塗る

  • Unity で prefab（アバターなど）を選んで「ぺたぬり3D で塗る」を押すと、ぺたぬり3D が起動してそのモデルを塗れます。
  • 塗った絵は、ぺたぬり3D か Unity で保存したときに Unity のシーンに映り、塗ったテクスチャが Unity のプロジェクトに入ります（塗っている間は、Unity の見た目は変わりません）。
  • 使えるもの：Unity 2022.3（VRChat のアバターを作る Unity）。同じパソコンの中の Unity とだけつながります。

はじめの 1 回だけ：Unity にアドオンを入れる

  1. ぺたぬり3D のフォルダの中の「unity」フォルダに、PetaNuri3D-Unity.unitypackage があります。
  2. Unity でプロジェクトを開いたまま、PetaNuri3D-Unity.unitypackage を Project の欄へドラッグします（Assets →「Import Package」→「Custom Package」でも）。
  3. 「Import」を押して、上のメニューバーに「ぺたぬり3D」が出れば入りました（エディターの中だけで動き、アップロードするアバターには入りません）。

塗る

  1. Unity で、Hierarchy のアバター（シーンの中の物）か、Project の prefab を選びます。
  2. メニューバーの「ぺたぬり3D」→「ぺたぬり3D で塗る」を押します（右クリックにもあります）。はじめての 1 回だけ、ぺたぬり3D のフォルダの PetaNuri3D-win_x64.exe を選びます。
  3. ぺたぬり3D が起動して、Unity のモデルが出ます。テクスチャセットはマテリアルのメインのテクスチャごとで、元のテクスチャがそのまま下地になります（解像度も元のまま。Lite は 2048 まで）。
  4. ぺたぬり3D か Unity で保存（Ctrl＋S）すると、両方が保存して、塗った絵が Unity に映ります。
  • 作業ファイルは Assets/PetaNuri/（名前）/（名前）.petanuri、塗ったテクスチャは Assets/PetaNuri/（名前）/Textures/ の PNG（取り込みの設定は元のテクスチャに合わせます）、マテリアルは同じ所の Materials/ に写しを作って使います。
  • 元の FBX・マテリアル・テクスチャ・prefab は書き換えません。Project の prefab から始めたときは、prefab の変種（Prefab Variant）を作って、そちらを塗ります。
  • Unity から起動したぺたぬり3D は、塗るための画面になります（新規作成・作業ファイルを開く・モデルを読み直す・名前を付けて保存は出ません）。
  • ぺたぬり3D を閉じると連携が終わり、Unity が「このまま使う／元の見た目に戻す」を聞きます（シーンの中のアバターを塗ったとき）。
  • 次にもう一度「ぺたぬり3D で塗る」を押すと、作業ファイルを開いて続きから塗れます。
くわしい手順・つながらないときは、ぺたぬり3D の unity フォルダの「Unity連携の使い方.txt」をご覧ください。

AI 連携（MCP）

  • AI（MCP クライアント）から、ぺたぬり3D を操作できます（描く・色とブラシ・視点・レイヤー・画面の撮影・PNG の書き出しなど）。
  • はじめは OFF です。使うときは ファイル → 環境設定 →「AI 連携」の「AI 連携（MCP）を使う」を入れます。
  • MCP クライアントに stdio のサーバーとして登録します：コマンド node、引数 <ぺたぬり3D のフォルダ>\mcp\server.mjs（node は v20 以上）。設定の例は、同じ所の「つなぎ方」にあり、「コピー」で写せます。
  • サーバーは AI 側が起動します。ぺたぬり3D が同じパソコンの中の決まった番号へ自動でつなぎに行き、つながると下のヒントに知らせが出ます。ほかのウェブサイトからはつなげません。
  • run_js（アプリの中で任意のプログラムを動かす命令）は Pro だけです。ON にしただけでは動かず、「run_js（任意のプログラムの実行）を許可する」を入れたときだけ動きます。信頼できる AI クライアントだけを登録してください。
