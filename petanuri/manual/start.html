ぺたぬり3D ／ マニュアル ／ はじめかた

はじめかた

ぺたぬり3D を起動して、3D モデルを開き、塗った作業を保存するまでの流れと、版（Lite・Standard・Pro）のちがいです。

Lite・Standard・Pro と Pro アップグレードを BOOTH で配布しています。

このページの「v1.2.0：」で始まる説明は公開前の案内です。現在の配布版は v1.1.2 です。

起動する

  1. ダウンロードした zip を展開して、PetaNuri3D フォルダを好きな場所に置きます（インストールはいりません）。
  2. フォルダの中の PetaNuri3D-win_x64.exe をダブルクリックします。同じフォルダの resources.neu も使うので、持ち運ぶときはフォルダごと動かしてください。
  3. 「PC が保護されました」と出たら、「詳細情報」→「実行」を押します（署名なしのアプリのため、はじめに出ることがあります）。
  4. 真ん中に「新規作成」「作業ファイルを開く」「サンプルで試す」が出たら準備完了です（最近使ったファイル・自動保存もここから開けます）。
動作環境は Windows 11（64bit）です。Windows 10 でも動きますが、サポートの対象外です。
設定（サブツール・キーの割り当て・ウィンドウの配置・カラーセット・参考画像など）は %APPDATA%\PetaNuri3D に保存され、次に起動したときに戻ります。
v1.2.0：インストーラー（全版）：BOOTH からダウンロードした setup の zip（PetaNuri3D-＜版＞-v＜バージョン＞-setup.zip）を展開して、中の setup（PetaNuri3D-＜版＞-v＜バージョン＞-setup.exe）をダブルクリックし、「次へ」で入れます。管理者の権限は要りません（自分のユーザーだけに入ります）。入る場所は %LOCALAPPDATA%\Programs\PetaNuri3D で、スタートメニューから起動します。デスクトップにアイコンを作るか、作業ファイル（.petanuri）をダブルクリックで開けるようにするかは、入れるときに選べます。
v1.2.0：新しいバージョンにするときや版（Lite・Standard・Pro）を替えるときは、新しい setup を実行するだけです（上書きします。起動していたら閉じてから入ります）。設定・作業ファイル・ブラシ・アップグレードはそのまま使えます。やめるときは Windows の「設定 → アプリ → インストールされているアプリ」で「ぺたぬり3D」をアンインストールします（設定と作業ファイルは消えません）。zip も今までどおり使えます。
v1.2.0：zip から setup に替えたときなど、ぺたぬり3D の置き場所が変わったときは、Unity 連携のアドオンが覚えている exe の場所を一度選び直してください。

チュートリアルとサンプルのモデル

  • はじめて起動すると、操作の案内（チュートリアル・12 の手順）が出ます。← → で前後、「スキップ」か Esc でやめられます。
  • もう一度見るときは ヘルプ →「チュートリアル」。ファイル → 環境設定 → システム の「次の起動でチュートリアルを見る」でも出せます。
  • モデルを開いていないときにチュートリアルを始めると、「サンプルのモデルで試す」か「自分のモデルで（あとで開く）」を選べます。サンプルなら、回す・描く・左右対称・UV を実際に触りながら進みます。
  • サンプルのモデル（獄門しのぶ）は、起動画面の「サンプルで試す」で開けます（Lite でも使えます）。A ポーズ・テクスチャセット 7 つで、各セットの下地に元の色の画像（2048px）が入ります。
サンプルのモデルは、ぺたぬり3D を試すためだけに使えます。ほかの用途に使ったり、取り出して配ったりしないでください。

モデルを使わずに描くときは、起動画面の「サンプルで試す」の下の「2D ペイントで描く」から始められます（2D ペイント）。

新規作成（3D モデルを開く）

  1. 「新規作成」（ファイル → 新規作成・Ctrl＋N）を押して、3D モデルを選びます。開けるのは FBX・glTF（1 つのファイルにまとめた物）・GLB・VRM・OBJ・DAE です。
  2. マテリアルごとのテクスチャセットが並びます。セットごとに解像度（32〜4096。Lite は 2048 まで）と始まりを決めます。
  3. 始まりは「色」（下地を 1 色で塗る。既定は白、「モデルの色」も選べます）・「画像」（PNG・JPEG など）・「PSD」（レイヤーごと。Standard）・「lilToon のマテリアル」（.mat か、それが入った .unitypackage。Pro）から選びます。セットごとに違う始まりを混ぜてかまいません。
  4. 「新規作成」を押すと、3D ビューにモデルが出ます。やめるときは「キャンセル」か Esc。
モデルが使っている画像がモデルのそば（同じフォルダや Texture フォルダ）にあるか、モデルの中に入っていれば、自動で見つけて「画像」で始まります。
上の「まとめて」で、解像度をそろえたり、画像・PSD・lilToon のマテリアルをまとめて選んだりできます。ファイル名がセット名と同じ物（body.psd → body）はそのセットに入ります。この画面に画像・PSD・.mat を落としても振り分けます。
3D モデルは、ウィンドウに落としても開きません。ファイル → 新規作成 か、モデルを読み直す から開いてください。UV が 0〜1 の外にあるモデルは、テクスチャのくり返しで同じ色になる位置に写して塗ります（モデルのファイルは変えません）。塗れない所があるモデルは、読み込んだときに右下で知らせます。
Pro 下地を決めたら、「作成後にお手軽ベイクを開く」にチェックを入れ、対象セットを選べます。作成後に肌・衣装などの仕上げを選んでから描き込めます。自動で焼くのではなく、プレビューを見て確定する方式です（お手軽ベイク）。
v1.2.0：glTF・glb・VRM の向き（全版）：glTF・glb・VRM のモデルは、開くときに UV を上下返して FBX と同じ向きにそろえます。UV ビューの絵・書き出す PNG・PSD・UV マップは元の画像と同じ向きになります。前の版で保存した作業ファイルは、3D の見た目はそのままで、UV ビューの絵は上下が入れ替わって見えます（保存し直すと新しい形になります）。
v1.2.0：マテリアルの入っていない FBX は、オブジェクトごとのテクスチャセットに分けて開きます（前は 1 つにまとまっていました）。同じ UV を 5 枚以上の面で使い回した所（髪の毛の束など）も、3D の上で塗れます。

保存する・続きを開く

  • ファイル → 作業ファイルを保存（Ctrl＋S）で、モデルと全部のレイヤー・設定が 1 つの .petanuri ファイルに入ります。名前を付けて保存は Ctrl＋Shift＋S。
  • 続きは ファイル → 作業ファイルを開く（Ctrl＋O）で .petanuri を開きます（ウィンドウに落としても開けます）。ファイル → 最近使ったファイル からも。
  • 開いている間は、画面の真ん中に「読み込み中…」とファイル名・進み具合が出ます。
  • タイトルの「＊」は、保存していない変更があるしるしです。
  • 5 分おきに自動保存しています。落ちてしまったときは ファイル → 自動保存から開く で戻せます（作業ごとに新しい 3 つまで）。
一部を読めなかった作業ファイルは、名前に「（欠けあり）」が付いて開きます。元のファイルを上書きしないよう、保存は「名前を付けて保存」になります。
v1.2.0：自動保存は、レイヤーの透明な所を書かない速い形で保存します。この形は v1.1.2 以前のぺたぬり3D では絵が読めません。手で保存する作業ファイルは今までどおりで、ファイル → 環境設定 → 描画 →「性能」の「作業ファイルを速い形で保存する」を入れると同じ形になります。
v1.2.0：画面が固まって × に反応しないときは、もう一度 × を押すと終了します（保存していない変更は失われます）。スリープから戻った後などに内部の読み書きが止まると、自動保存・保存は待ち続けずに知らせます。そのときは、いったん終了して開き直し、ファイル → 自動保存から開く で直前の自動保存を開いてください。

モデルを読み直す（描いた物は残す）

3D モデル（FBX など）を直したときに、描いた物を残したまま形だけ新しくできます。

  1. ファイル → モデルを読み直す を選びます。
  2. 「同じファイルを読み直す」か「ファイルを選ぶ」を押します。
  3. テクスチャセットはマテリアルの名前で合わせます。同じ名前のセットは、レイヤーも設定もそのまま残ります。
  • UV が変わっても、描いた絵は UV の上のまま新しい形に貼ります（UV を大きく動かした所は、絵がずれて見えます）。
  • 新しいモデルに無いマテリアルのセットは消さずに ! の印を付けて残します。押すと、レイヤーをほかのセットへ移せます（行き場のないセット）。
  • 新しく増えたマテリアルがあると、読み直す前に新規作成と同じ画面が、新しいセットの行だけで出ます。解像度と始まりを決めて「読み直す」を押します。
読み直すと、元に戻す（履歴）は消えます。
読み直したとき、モデルのテクスチャ（画像）が前と変わったセットがあると、「下地を新しいテクスチャに置き換えますか？」とセットごとに聞きます。置き換えると下地に直接描いた物も置き換わります。置き換えは読み直した後の 1 手として元に戻せます。

版（Lite・Standard・Pro）

ぺたぬり3D には 3 つの版があります。今の版は、左上の名前の横の札（Lite・Pro。Standard は札なし）と、ヘルプ →「ぺたぬり3D について」で分かります。

  • どの版で作った作業ファイルも開けます。上限より多いレイヤー・4096 のセット・その版で使えない機能の設定も、消さずにそのまま持っていて、保存しても残ります。

Standard から Pro にする（アップグレード） Pro

  1. BOOTH で「Pro へのアップグレード」を買うと、アップグレードのファイル（PetaNuri3D-Pro.petapack）が手に入ります。
  2. ヘルプ →「Pro にアップグレード」→「ファイルを選ぶ」で、そのファイルを選びます（ウィンドウに落とす・exe と同じフォルダに置く、でもかまいません）。
  3. ぺたぬり3D を閉じて、もう一度起動すると Pro になります。入れ直しはいりません。作業ファイルも設定もそのままで、次の起動からも Pro です。
アップグレードは Standard のときだけ使えます（Lite では使えません）。アップグレードのファイルは、同じバージョンの ぺたぬり3D にだけ入ります。ぺたぬり3D を新しいバージョンにしたときは、同じバージョンのアップグレードのファイルをダウンロードし直して入れてください（合わないときは、起動のときに知らせて Standard のまま動きます）。

バージョンと新しいバージョンのお知らせ

  • 今のバージョンは、起動画面の題名の横（v1.1.0 など）と、ヘルプ →「ぺたぬり3D について」で分かります。
  • 起動したとき（1 日に 1 回まで）、公式サイトで新しいバージョンが出ていないかを確かめます。新しければ画面の右下に知らせます（「入手先を開く」・「あとで」・「この版は知らせない」）。
  • ヘルプ →「新しいバージョンを確かめる」で、いつでも確かめられます。ファイル → 環境設定 → システム の「起動したときに新しいバージョンを確かめる」を外すと、起動のときは確かめません。
確かめるのはバージョンの番号だけです。作品や設定はどこにも送りません。インターネットにつながっていないときは何も出ません。
v1.2.0：インストールして再起動（Windows・この版の次の更新から）：お知らせの「BOOTH でダウンロード」で BOOTH のライブラリを開き、setup の zip をダウンロードすると、アプリがダウンロードのフォルダの setup（zip のままでも、展開したフォルダの中でもかまいません）を見つけて、お知らせが「インストールして再起動」に替わります。ほかの場所に保存したときは「ファイルを選ぶ」で選びます（zip のままでも選べます）。押すと新しいバージョンを入れて起動し直します。Standard に Pro のアップグレードを入れている方は、同じバージョンのアップグレードのファイルもダウンロードしておくと、一緒に入れ替わります。
v1.2.0：お問い合わせ（全版）：ヘルプ →「お問い合わせ（サポート・要望・バグ報告）」で種類を選ぶと、調べるのに要る情報（版・バージョン・画面の大きさなど。ファイルの場所は入れません）の入った文ができます。空いている所を書いて「コピー」し、BOOTH のショップか Discord を開いて送ってください。
