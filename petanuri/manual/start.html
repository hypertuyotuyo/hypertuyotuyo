ぺたぬり3D ／ マニュアル ／ はじめかた

はじめかた

ぺたぬり3D を起動して、3D モデルを開き、塗った作業を保存するまでの流れです。

開発中のツールです。画面・名前・操作は変わることがあります。画像はサンプルのモデルを使った開発中の仮の画面で、あとで差し替えます。版の分け方（Lite・Standard・Pro）は予定です。

このページの内容
  • 起動する
  • 新規作成（3D モデルを開く）
  • 保存する・続きを開く
  • モデルを読み直す（描いた物は残す）
  • バージョンと新しいバージョンのお知らせ
  • Standard から Pro にする（アップグレード）

起動する

  1. ダウンロードした PetaNuri3D フォルダを、好きな場所に置きます（インストールはいりません）。
  2. フォルダの中の PetaNuri3D-win_x64.exe をダブルクリックします。同じフォルダの resources.neu も使うので、持ち運ぶときはフォルダごと動かしてください。
  3. 「PC が保護されました」と出たら、「詳細情報」→「実行」を押します（署名なしのアプリのため、はじめに出ることがあります）。
  4. 真ん中に「新規作成…」「作業ファイルを開く…」が出たら準備完了です。
設定（サブツール・キーの割り当て・ウィンドウの配置・カラーセット・参考画像など）は %APPDATA%\PetaNuri3D に保存され、次に起動したときに戻ります。

新規作成（3D モデルを開く）

  1. 「新規作成…」（ファイル → 新規作成・Ctrl＋N）を押して、3D モデルを選びます。開けるのは FBX・glTF・GLB・VRM・OBJ・DAE です。3D モデルは、ここ（新規作成）から開きます。
  2. マテリアルごとのテクスチャセットが並びます。セットごとに解像度（512〜4096）と始まりを決めます。
  3. 始まりは「色」（下地を 1 色で塗る。既定は白、「モデルの色」も選べます）・「画像」（PNG・JPEG など）・「PSD」（レイヤーごと）から選びます。
  4. 「新規作成」を押すと、3D ビューにモデルが出ます。やめるときは「キャンセル」か Esc。
モデルが使っている画像がモデルのそば（同じフォルダや Texture フォルダ）にあるか、モデルの中に入っていれば、自動で見つけて「画像」で始まります。
上の「まとめて」で、解像度をそろえたり、画像・PSD をまとめて選んだりできます。ファイル名がセット名と同じ物（body.psd → body）はそのセットに入ります。画面に落としても振り分けます。
3D モデルは、ウィンドウに落としても開きません。ファイル → 新規作成 か、モデルを読み直す から開いてください。「作業ファイルを開く…」で開けるのは、保存した作業ファイル（.petanuri）です。
解像度 4096 は Standard からの予定です（Lite は 2048 まで）。

保存する・続きを開く

  • ファイル → 作業ファイルを保存（Ctrl＋S）で、モデルと全部のレイヤー・設定が 1 つの .petanuri ファイルに入ります。名前を付けて保存は Ctrl＋Shift＋S。
  • 続きは ファイル → 作業ファイルを開く…（Ctrl＋O）で .petanuri を開きます（ウィンドウに落としても開けます）。ファイル → 最近使ったファイル… からも。
  • タイトルの「＊」は、保存していない変更があるしるしです。
  • 5 分おきに自動保存しています。落ちてしまったときは ファイル → 自動保存から開く… で戻せます。

モデルを読み直す（描いた物は残す）

3D モデル（FBX など）を直したときに、描いた物を残したまま形だけ新しくできます。

  1. ファイル → モデルを読み直す… を選びます。
  2. 「同じファイルを読み直す」か「ファイルを選ぶ…」を押します。
  3. テクスチャセットはマテリアルの名前で合わせます。同じ名前のセットは、レイヤーも設定もそのまま残ります。
  • UV が変わっても、描いた絵は UV の上のまま新しい形に貼ります（UV を大きく動かした所は、絵がずれて見えます）。
  • 新しいモデルに無いマテリアルのセットは消さずに ! の印を付けて残します。押すと、レイヤーをほかのセットへ移せます。
  • 新しく増えたマテリアルがあると、読み直す前に新規作成と同じ画面が、新しいセットの行だけで出ます。解像度と始まりを決めて「読み直す」を押します。
読み直すと、元に戻す（履歴）は消えます。

バージョンと新しいバージョンのお知らせ

  • 今のバージョンは、起動画面の題名の横（v0.0.4 など）と、ヘルプ →「ぺたぬり3D について」で分かります。
  • 起動したとき（1 日に 1 回まで）、公式サイトで新しいバージョンが出ていないかを確かめます。新しければ画面の右下に知らせます（「入手先を開く」・「あとで」・「この版は知らせない」）。
  • ヘルプ →「新しいバージョンを確かめる…」で、いつでも確かめられます。「起動したときに新しいバージョンを確かめる」を外すと、起動のときは確かめません。
確かめるのはバージョンの番号だけです。作品や設定はどこにも送りません。インターネットにつながっていないときは何も出ません。

Standard から Pro にする（アップグレード） Pro

  1. BOOTH で「Pro へのアップグレード」を買うと、アップグレードのファイル（.petakey）が手に入ります。
  2. ヘルプ →「Pro にアップグレード…」→「ファイルを選ぶ…」で、そのファイルを選びます（ウィンドウに落とす・exe と同じフォルダに置いて起動する、でもかまいません）。
  3. その場で Pro になります。入れ直し・再起動はいりません。作業ファイルも設定もそのままで、次の起動からも Pro です。
アップグレードは Standard のときだけ使えます（Lite では使えません）。
