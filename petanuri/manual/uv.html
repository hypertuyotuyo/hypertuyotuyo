UV の区画と表示範囲

3D ビューのとなりに UV（テクスチャの展開図）を並べて、どちらからでも塗れます。服の下の体や髪の内側は、表示範囲で手前を隠して塗ります。

UV の区画を出す

  • UV の出し方は 3 つ：3D だけ・3D と UV を並べる・UV だけ。3D だけのときは、3D ビューの右端の「UV」（U・表示 → UV）で並べます。境目のドラッグで広さを変えられます。
  • 並べているときは、UV の区画の右上の × で UV を消す（3D だけ）、3D ビューの右上の × で 3D を消す（UV だけ）。Shift＋U で UV だけ ⇔ 並べるを切り替え。最後の出し方は次も同じです。
  • 出るのは、選んでいるテクスチャセットの UV です（左上に名前）。セットを選び直すと切り替わります。
  • UV の区画の上でも、ペン・筆・消しゴム・ポリゴン塗り・塗りつぶし・囲まれた所・グラデーション・図形・スタンプ・スポイト・ぼかし・指先が使えます。
  • UV の区画を触っている間は、3D ビューでブラシの円に入る面が赤く光ります。3D を触っている間は、UV の区画に塗る位置が赤い点で出ます。
  • ホイールで拡大縮小、中ドラッグ・Space＋ドラッグで移動、「全体」で全体表示。「線」で UV の線、「島の縁」で島の輪郭（▼ で色と濃さ）。
  • 見出しの ⟲・⟳ で 15° ずつ回せます（回したまま塗れます）。
  • 見出しの「対称 X・Y・Z」は、3D の左上と同じ切り替えです（左右対称で描く）。
  • UV の区画が狭いときは、見出しに入らないボタンを「⋯」の板にしまいます。

グリッド線と吸着

  • UV の区画の見出しの「グリッド」で、マス目を出す・隠す。隣の ▼ で、マスの数（テクスチャの 1 辺を 2・4・8・16・32・64・128 に分ける）と吸着を選びます。1 マスが何 px かも ▼ の中に出ます。
  • 線は表示だけで、描く絵・保存・書き出しには入りません。
  • 「移動・変形でグリッドに吸着する」（既定で入。グリッドを出しているときだけ）：UV の区画で移動・変形ツール・変形（Ctrl＋T）・画像を UV に貼るの枠を動かすと、枠の 4 隅か真ん中がマス目の線の近くで吸い付きます。角・辺のつまみ、自由変形の角、ワープの点も吸い付きます。
  • Ctrl を押している間は吸い付きません。3D の区画の上の枠では吸い付きません。

UV のガイド（ズーム・移動）

UV の区画の右上に、3D ナビと同じ形のガイドが出ます。ペンだけで操作できます。

  • 虫めがねを上下にドラッグで拡大・縮小（上で寄る）。手のひらをドラッグで移動。四角で全体表示。
  • 上のつまみで好きな場所へ動かし、左・下の端と左下の角で大きさを変えられます。
  • 「—」で小さな丸いアイコンにたたみ、押すと戻ります（表示 → UV → UV のガイド でも）。

島の外にはみ出したとき（つなげて塗る）

  • UV の区画で塗るとき、円が UV の島の外にはみ出しても、UV の上で隣にあるだけの別の島（3D では離れた所）には塗りません。
  • 見出しの「つなげて塗る」（はじめは入）：島の縁の継ぎ目からはみ出した分は、3D でその継ぎ目の向こうにつながる面へ続けて塗ります。継ぎ目で途切れません。切ると、描いている島の中だけに塗ります（右クリックのメニュー・表示 → UV にも同じ切り替え）。
  • UV の島の外（どの面にも使われていない所）では、ブラシの円が薄い点線と × になります。島の外から描き始めた線は、島に入った所から付きます。文字・図形・スタンプ・グラデーションは、島の外からでも置けます。

表示範囲（選んだ所だけ出す・隠す）

  1. UV の区画や 3D で、島・面を選びます（島で選択・面で選択・投げ縄・頂点グループなど）。
  2. 3D ビューの左上の表示範囲のアイコン・Shift＋H・UV の見出しの「選んだ所だけ表示」で、選んだ所だけが 3D に出ます。
  3. H（UV の見出しの「選んだ所を隠す」）なら、選んだ所を隠します。何度でも足して隠せます。
  4. Alt＋H で全部表示に戻ります。
  • 「選んだ所だけ表示」の後は、選択範囲を選び直すと、押し直さなくても表示が変わります（もう一度押すと全部表示）。
  • 隠すと選択範囲は外れます。見えている所にそのまま塗れます。外した選択範囲は、3D の下のバーの［選択範囲を戻す］か Ctrl＋Shift＋D で戻せます。
  • 3D の右クリックの「この島を隠す」「この島だけ表示」は、押した所の島をそのまま隠す・出します（選択範囲と元に戻すの履歴は変わりません）。
  • 表示範囲のアイコンの ▼：左に「選択範囲から」（選んだ所だけ表示・選んだ所を隠す・選んだ所も表示・隠すペン）と「隠した所」（反転・全部表示・広げる／狭める・薄く見せる）、右に「隠し方」（保存した隠し方の一覧）。何も隠していないときは、ここから操作します。
隠した所は奥行きにも入らないので、服の下の体・髪の内側など、奥の面が見えて塗れます。隠した所は塗られず、スポイトや塗りつぶしでも拾いません。オブジェクト（メッシュ）ごとに隠すこともできます（オブジェクトの表示・非表示）。
隠す・表示の操作は、元に戻す（Ctrl＋Z）の履歴には入りません。戻すときは全部表示にするか、保存した隠し方を呼び出します。

隠すペン・3D の下のバー

重なった布の奥を塗るときなどに、なぞった所をそのまま隠せます。

  1. 左のツールバーの「隠すペン」を選びます（3D の下のバーの［隠すペン］でも入り切りできます）。
  2. サブツールで「面で隠す」（四角形の面は三角形 2 枚まとめて）か「島で隠す」（UV の島ごと）を選びます。
  3. 3D でなぞった所が隠れます。UV の区画で押しても隠せます。
  4. ［隠すペン］をもう一度押すと、前のツールに戻ります。
1 回のなぞりでは、手前を隠して見えてきた奥の面までは隠しません。奥も隠したいときは、もう一度なぞります。

3D の下の真ん中のバーは、隠している間と隠すペンの間だけ出ます。［隠すペン］［面｜島］［隠し方 ▼］と、今の隠し方（「隠し方：〇〇」・「一部を隠しています（保存していない隠し方）」・「選んだ所だけ表示しています」）・［全部表示］が並びます。

周りを薄く見せる

  • 隠している間、3D の下のバーの［周りを薄く見せる］で、隠した所を半透明で見せます。周りを確かめながら描けます。
  • 横のつまみで濃さ（5〜80%）を変えます。▼ の窓の「隠した所」の「薄く見せる」でも同じです。
薄く見えていても、隠した所には塗れません。

隠し方の保存

よく使う隠し方に名前を付けてとっておき、いつでも同じ隠し方に戻せます。

  1. 隠したい所を隠します。
  2. 3D の下のバーの［隠し方 ▼］（か、表示範囲の ▼ の窓）→「今の隠し方を保存」で名前を付けます（同じ名前なら上書き）。
  3. 同じ一覧から名前を押すと、その隠し方に戻ります。
  • 「隠し方の整理（名前・削除）」で、名前の変更・削除ができます。
  • 保存した隠し方と今の隠し方は、作業ファイル（.petanuri）に入ります。開き直しても使えます。

メッシュの線・継ぎ目の線

  • 3D ビューの左上のアイコン（表示 → 線と定規 → メッシュの線／継ぎ目の線）で、ポリゴンの線と、UV の継ぎ目・島の縁を出せます。継ぎ目の線は Alt＋W でも切り替えられます。
  • アイコンの下の ▼ で、濃さ・色（青・黒・白）・裏側／奥の線も出すかを選べます。
