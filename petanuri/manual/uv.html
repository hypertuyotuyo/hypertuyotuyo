UV の区画と表示範囲

3D ビューのとなりに UV（テクスチャの展開図）を並べて、どちらからでも塗れます。

画面・名前・操作は変わることがあります。画像はサンプルのモデルを使った画面です。版の分け方（Lite・Standard・Pro）は予定です。

このページの内容
  • UV の区画を出す
  • 表示範囲（選んだ所だけ出して塗る）
  • メッシュの線・境界線

UV の区画を出す

  1. U キー（表示 → UV）で、3D の隣に UV の区画が出ます。境目のドラッグで広さを変えられます。
  2. 出るのは、選んでいるテクスチャセットの UV です（左上に名前）。
  3. UV の区画の上でも、ペン・筆・消しゴム・塗りつぶし・グラデーション・スポイト・ぼかし・指先などが使えます。
  • UV の区画を触っている間は、3D ビューでブラシの円に入る面が赤く光ります。3D を触っている間は、UV の区画に塗る位置が赤い点で出ます。
  • ホイールで拡大縮小、中ドラッグ・Space＋ドラッグで移動、「全体」で全体表示。「線」で UV の線、「島の縁」で島の輪郭。
  • 見出しの ⟲・⟳ で 15° ずつ回せます（回したまま塗れます）。

表示範囲（選んだ所だけ出して塗る）

  1. UV の区画や 3D で、島・面を選びます（島で選択・面で選択・投げ縄など）。
  2. 3D ビューの左上の表示範囲のアイコン・Shift＋H・UV の見出しの「選んだ所だけ表示」を押します。
  3. 選んだ所だけが 3D に出ます。Alt＋H で全部表示に戻ります。
隠した所は奥行きにも入らないので、服の下の体・髪の内側など、奥の面が見えて塗れます。隠した所は塗られません。

メッシュの線・境界線

  • 3D ビューの左上のアイコン（表示 → メッシュの線／境界線）で、ポリゴンの線と UV の継ぎ目を出せます。
  • アイコンの下の ▼ で、濃さ・色（青・黒・白）・裏側の線も出すかを選べます。
