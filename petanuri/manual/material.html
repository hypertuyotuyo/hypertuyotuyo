ぺたぬり3D ／ マニュアル ／ 仕上がりと lilToon のマテリアル

仕上がりと lilToon のマテリアル Pro

lilToon と同じ計算の見た目（影・マットキャップ・リムライト・輪郭線など）で確かめながら塗れて、設定ごとマテリアルとして書き出せます。このページの機能は Pro で使えます。

Lite・Standard・Pro と Pro アップグレードを BOOTH で配布しています。

このページの「v1.2.0：」で始まる説明は公開前の案内です。現在の配布版は v1.1.2 です。

「仕上がり（lilToon の見た目）」は β版です。lilToon（2.3 系）と同じ計算で見せていますが、Unity の中の見え方と少し違うことがあります。

このページの内容
  • 「仕上がり」で見る
  • 影色・マスクなどを塗る（塗る先）
  • メインカラー2nd・メインカラー3rd
  • マテリアルを分ける
  • lilToon のマテリアルを読み込む
  • マテリアルを書き出す

「仕上がり」で見る

  • 3D ビューの左上の、表示の形式の 4 つのアイコンの右端（右クリック → 表示）で「仕上がり」にします。
  • 影（影色 1・影色 2・境界の色）・ノーマルマップ・マットキャップ・マットキャップ 2nd・リムライト・逆光ライト・リムシェード・発光・輪郭線を、lilToon（2.3 系）と同じ計算で見せます。
  • 光の向きは、表示の形式の ▼ かパネル「マテリアル」の「表示と光」で。「カメラについてくる光」なら、視点を回しても当たり方が同じで塗りやすくなります。
  • パネル「マテリアル」の項目の名前は、lilToon の設定画面の呼び名にそろえています。「ほかのマテリアルにも写す」で全部を同じ設定にできます。
MToonの仕上がりプレビュー（Pro・β）：マテリアル → 表示と光でMToonを選びます。VRM0／VRM1から読み込んだ影・リム・発光・輪郭などを参考に描けます。調整はUndo／Redoでき、作業ファイルにも保存されます。
これは描画中の見た目を確認する機能です。MToon材質の完全な往復出力には対応せず、PNG／PSDと既存のlilToon用マテリアル出力は従来どおりです。UVアニメーションは静止表示で、扱えないUV設定は理由を知らせ通常表示へ戻します。
v1.2.0：lilToon の設定の追加（Pro）：リムライトの「ライトの方向の影響度」（直接光・間接光）、輪郭線の「ハイライト」「ライトの明るさを反映」、光沢設定（滑らかさ・金属度・反射率・リアル／トゥーンの光沢・環境光の反射・キューブマップ）、ラメの形、マットキャップの「カスタムノーマルマップ」「ノーマルマップの強度」、色調補正のグラデーションマップ、発光のグラデーション、異方性反射、ディザ、ディゾルブ、視差、AudioLink を、lilToon と同じ計算で見せます。
v1.2.0：音や時間で変わる物は、「音の強さ（この表示だけ）」「表示の時刻」の値で止めて見せます（書き出しには入りません）。輪郭線の向き・メインカラー2nd／3rd のディゾルブなど表示に入らない設定も、値と画像を .mat に読み書きします。

影色・マスクなどを塗る（塗る先）

  1. パネルの「塗る：」のボタン（右クリック → 塗る先 でも）で、塗る先を選びます。
  2. レイヤーのパネルのメインカラーの上に、その塗る先のフォルダ（例「影色1」）ができて、中のレイヤーが選ばれます。中はふつうのレイヤーと同じで、足す・消す・重ねる・マスク・クリッピングが使えます。
  3. いつものペン・筆・塗りつぶし・グラデーション・ぼかし・フィルターで、そのまま塗ります。
  4. 上の真ん中の「カラーに戻る」（かフォルダの外のレイヤーを押す）で、ふつうの色の塗りに戻ります。
塗る先どう効く？
影色 1・影色 2塗った所の影がその色になります（肌の赤み・髪の影の青みなど）
影マスク白＝影が付く・黒＝影を付けない
影 AO黒いほど影が出やすい（首元・髪の内側・服の重なり）
ノーマルマップ高さで塗ります。白で盛る・黒で彫る（服のしわ・縫い目・髪の筋に。凹凸のツールも）
マットキャップのマスク・輪郭線の幅白＝効く・黒＝効かない
リムライト色・発光テクスチャ塗った色を掛ける／塗った所だけが、塗った色で光る
  • ほかにも、影色3・影のぼかしマスク・色調補正マスク・アルファマスク・発光マスク・発光2nd・逆光ライトの色・リムシェードのマスク・輪郭線の色・ノーマルマップ2nd のマスク・ラメの色を塗れます（右クリック → 塗る先 → そのほかのマスク）。
  • 明るさだけを読む塗る先は、上の真ん中の 白・灰・黒 で持ち替えられます。「ここだけ見る」で、その塗る先の絵だけを表示します。「消す」で、塗る先を塗っていない状態に戻します。
  • 1 つのマテリアルの仕上がりの表示で同時に使えるテクスチャは 16 までです（超えるときは「これ以上追加できません」と出ます）。
v1.2.0：塗る先の追加（Pro）：「そのほかのマスク」に、滑らかさ・金属度・光沢の色・異方性反射のマスク・異方性反射のノイズ・ディゾルブのマスク・ディゾルブのノイズ・視差の高さ・AudioLinkのマスク を足しました（それぞれの設定を使っているとき）。
v1.2.0：ノーマルマップ画像のレイヤー（Pro）：ほかのソフトで作ったノーマルマップの画像も、ノーマルマップのフォルダの中にレイヤーとして入れられます（パネル「マテリアル」の「ノーマルマップの画像を足す」か、フォルダの中のレイヤーを選んで画像をウィンドウへドロップ）。DirectX の向きの画像は、レイヤープロパティの「DirectX の向き（緑が逆）」を入れます。読み込んだ .mat のノーマルマップも、このレイヤーになります。
v1.2.0：柄で質感を付ける（Pro）：マテリアルのノーマルマップの節の「柄で質感を付ける」で、ニット・デニム・キャンバス・ヘリンボーンなどの模様を、繰り返す凹凸としてフォルダに敷けます（大きさ・回す・つなぎ目はレイヤープロパティの「繰り返しの柄」、強さは「ノーマルマップ強度」）。フォルダの中のレイヤーを選んでいると、UV の区画は高さ（灰色）ではなくノーマルマップの色で見せます（表示 →「ノーマルマップのフォルダを高さ（灰色）で見る（UV）」で戻せます）。

メインカラー2nd・メインカラー3rd

  • パネル「マテリアル」の「メインカラー2nd」「メインカラー3rd」で「使う」にすると、レイヤーパネルの一番上に同じ名前のフォルダができます。
  • フォルダの中に入れたレイヤーだけが、メインカラー2nd（3rd）のテクスチャになります（メインの絵には混ざりません）。重なり方（色・不透明度・合成モード・マスク）はパネルで決めます。
  • 書き出しでは別々の画像（<名前>_main2nd.png など）になり、マテリアルでは lilToon の「メインカラー2nd／3rd」に入ります。

マテリアルを分ける

  • はじめは、テクスチャセット 1 つにつき同じ名前のマテリアルが 1 つです。分けなければ何も変わりません。
  • 同じテクスチャ（塗る絵）のまま、オブジェクトごとに影色・マットキャップ・リムライト・輪郭線などの設定を変えられます（例：髪のテクスチャのまま、ケモミミだけ影を赤く）。
  • 分け方：オブジェクトのパネルの行か、3D でそのオブジェクトの上を右クリック →「このオブジェクトだけ別のマテリアルにする」。「マテリアルを割り当てる」で、どのマテリアルを使うか選べます。
  • パネル「マテリアル」の上の一覧で、足す・名前を変える・消す・並べ替え（並び＝重なった所の優先度）。3D で触った所のマテリアルにパネルが切り替わり、下のステータスバーに「マテリアル：名前（テクスチャセット名）」が出ます。
  • 書き出しは、マテリアルごとに .mat が 1 つ（同じテクスチャを指します）。

lilToon のマテリアルを読み込む

  • ファイル → 読み込み → lilToon のマテリアルを読み込む で、.mat か、それが入った .unitypackage を選びます（ウィンドウへのドロップでも）。新規作成の「始まり」にも選べます。
  • 描画モード・影・ノーマルマップ・マットキャップ・リムライト・発光・輪郭線・メインカラー2nd／3rd などの設定と、テクスチャ（メインカラー → 下地、影色・マスクなど → 塗る先）が入ります。
  • テクスチャは .mat のそばのプロジェクトから探します。見つからないテクスチャは一覧に出るので、画像を選びます。
  • ぺたぬり3D がまねていない設定（光沢・ファー・ステンシルなど）は、値をそのまま残して、書き出すと元のまま戻ります。
  • 書き出すと、元の .mat と同じ場所・同じ ID のまま、変えた設定と描き直したテクスチャだけが書き換わります。
v1.2.0：.mat の読み込み・書き出しは、追加した設定にも対応します。メインの画像は URP・HDRP 用の別名（_BaseMap・_BaseColorMap）でも読み、書き出すときも入れます。

マテリアルを書き出す

  1. ファイル → 書き出し → マテリアルを書き出す（パネルの「書き出し」でも）を選びます。
  2. 書き出すマテリアルとフォルダ名、書き出しのにじみを選びます。
  3. .unitypackage に書き出すか、フォルダ（プロジェクトの Assets）へ直接書きます。.unitypackage は、ダブルクリックかドラッグでプロジェクトに読み込めます。
  • マテリアル（.mat）と、メインカラーの画像・影色・マスク・ノーマルマップ・マットキャップの画像が入り、割り当て済みになります。
  • 同じ作業を同じフォルダ名で書き出し直すと、前に読み込んだ物がそのまま上書きされます（モデルへの割り当てはそのまま）。
書き出すのは lilToon 用のマテリアルです。読み込む側のプロジェクトに lilToon を入れておいてください（入っていないとマテリアルがピンク色になります）。
