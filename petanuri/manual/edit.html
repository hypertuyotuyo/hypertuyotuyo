選択範囲・変形・文字・定規

塗る所を限ったり、描いた物を動かしたり、文字や画像を貼ったりする機能です。

開発中のツールです。画面・名前・操作は変わることがあります。版の分け方（Lite・Standard・Pro）は予定です。

このページの内容

  • 変形・コピーと貼り付け
  • 画像を貼る

  • 定規

選択範囲

  1. ツール「選択範囲」（S）を選び、サブツールで形を選びます。
  2. 3D ビュー（か UV の区画）でドラッグ・なぞる・クリックして選びます。
  3. 選んでいる間は、描く・塗る・消す・フィルター・グラデーションが選択範囲の中だけに効きます。外は少し暗く、境目に点線が出ます。
  4. Ctrl＋D で解除します。
サブツール選び方
長方形・楕円ドラッグ
投げ縄なぞって囲む
折れ線クリックで点を打ち、最初の点・ダブルクリック・Enter で閉じる
自動選択押した所と色の近い続いた所
島で選択押した UV の島を丸ごと
面で選択なぞった面を丸ごと
選択ペン・選択消しブラシでなぞって足す・削る
  • 押し始めに Shift＝追加・Alt＝削除・Shift＋Alt＝共通。
  • 「裏側・隠れた面も選ぶ」にすると、画面の形に写る所を裏まで全部選びます。体をぐるっと一周選んで、服のしましまを塗るときにべんりです。
  • メニュー「選択範囲」：すべてを選択 Ctrl＋A・反転 Ctrl＋Shift＋I・広げる／狭める／境界をぼかす・選択範囲からマスクを作る・描画色で塗る・中を消去（Delete）
レイヤーのサムネイルを Ctrl＋押すと、塗られている所を選択範囲にできます。

変形・コピーと貼り付け

  • 変形（Ctrl＋T）：UV の区画に枠が出ます。選択範囲があればその中を、無ければレイヤー全体を動かします。
  • 枠の中をドラッグで移動・角で拡大縮小・上の丸で回転（Shift で 15° 刻み）。左右反転・上下反転も。Enter で確定、Esc でやめる。
  • コピー（Ctrl＋C）・切り取り（Ctrl＋X）・貼り付け（Ctrl＋V）：同じ UV の位置に新しいレイヤーで貼って、そのまま変形できます。

画像を貼る

  • 画像を 3D に貼る：ほかのアプリでコピーした画像を Ctrl＋V（または 編集 → 画像を 3D に貼る…）。3D の上で枠を合わせ、Enter でモデルの見えている面に投影して貼ります。視点を動かしながら合わせてもかまいません。
  • 画像を UV に貼る：編集 → 画像を UV に貼る…。UV の区画の上で枠を合わせて、新しいレイヤーに貼ります。
左右対称と選択範囲も効きます。「斜めの面も濃く」で、斜めの面が薄くならないようにできます。

文字

  1. ツール「文字」（T）を選び、3D ビューを押します。
  2. 出てきた窓に文字を打ちます。書体・大きさ・色・太字・斜体・縦書き・行間・字間・揃え・縁取りを決められます。
  3. 枠を合わせて Enter（文字の欄の中では Ctrl＋Enter）で貼ります。
書体のファイル（.ttf・.otf）も読み込めます。貼った文字は画素になるので、後から打ち直すことはできません。

定規

  • 描く線を定規に吸い付かせます。直線・曲線は定規の近くで描き始めた線だけ、同心円・放射線・平行線はどこで描いても効きます。
  • 作り方：直線・平行線はドラッグ、同心円・放射線は押した所が中心、曲線は点を打って Enter。
  • 表示 → 定規に吸い付く（Ctrl＋Alt＋R）で切り替え、定規を消す。
