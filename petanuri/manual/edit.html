選択範囲・変形・文字・定規

塗る所を限ったり、描いた物を動かしたり、文字や画像を貼ったりする機能です。変形の枠は、3D のモデルの上にも UV の区画にも出ます。

選択範囲

  1. ツール「選択範囲」（S）を選び、サブツールで形を選びます。
  2. 3D ビュー（か UV の区画）でドラッグ・なぞる・クリックして選びます。
  3. 選んでいる間は、描く・塗る・消す・フィルター・グラデーションが選択範囲の中だけに効きます。外は少し暗く、境目に点線が出ます。
  4. Ctrl＋D で解除します。
サブツール選び方
長方形・楕円ドラッグ
投げ縄なぞって囲む
折れ線クリックで点を打ち、最初の点・ダブルクリック・Enter で閉じる
自動選択押した所と色の近い続いた所
島で選択押した UV の島を丸ごと

選択ペン・選択消しブラシでなぞって足す・削る
  • 押し始めに Shift＝追加・Alt＝削除・Shift＋Alt＝共通。
  • 「裏側・隠れた面も選ぶ」にすると、画面の形に写る所を裏まで全部選びます。体をぐるっと一周選んで、服のしましまを塗るときにべんりです。
  • メニュー「選択範囲」：すべてを選択 Ctrl＋A・反転 Ctrl＋Shift＋I・広げる／狭める／境界をぼかす・レイヤーの塗られている所を選択・選択範囲からマスクを作る・描画色で塗る・中を消去（Delete）・点線の表示（Ctrl＋H）・選択範囲を戻す（Ctrl＋Shift＋D）。
  • 選択中は、選ばれていないテクスチャセットには描けません。
レイヤーのサムネイルを Ctrl＋押すと、塗られている所を選択範囲にできます（Shift で足す・Alt で削る）。
似た色をすべて選ぶ（全版）：選択範囲 →「似た色をすべて選ぶ（描画色）」で、描画色に近い色の所をテクスチャ全体から選びます（つながっていなくても）。許容量・見る絵（全部のレイヤー／今のレイヤー）・選び方（新しく・足す・引く）を決められます。下塗りの色ごとに影色を変えるときなどに。

選択範囲のバー

選択している間は、3D の区画の下に選択範囲のバーが出ます。左の「選択中」の札の後ろに、アイコンのボタンが並びます（名前とキーは、ペン先・カーソルを置くと出ます）。

  • 解除（色の付いたボタン）・反転｜広げる・狭める・境界ぼかし｜塗る・消去｜新しいレイヤーへ ▾（コピー／切り取り）・その他 ▾（マスク・選んだ所だけ表示・隠す・点線）。
  • 狭い画面では、広げる・狭める・境界ぼかしが「範囲 ▾」にまとまります。

移動・変形ツール

  1. ツール「移動・変形」（V）を選びます。
  2. 3D のモデル（か UV の区画）で、動かしたい絵を押します。押した所に描いてあるいちばん上のレイヤーが選ばれ、その絵の枠が出ます（「自動でレイヤーを選ぶ」。切ると選んでいるレイヤー）。
  3. 押したままドラッグすると、すぐ動きます。角で大きさ、上の丸で回転。
  4. Enter か、ほかのツールに替えると確定、Esc でやめます。枠の外を押すと確定して、押した所のレイヤーへ移ります。
  • 選択範囲があれば、その中だけを動かします。確定は、元に戻す 1 回分です。
  • ツールプロパティで、枠の形（拡大・縮小・回転／自由変形／ワープ）とワープの格子の数を選べます。
  • 文字レイヤーを押すと文字の枠になります（枠の中をドラッグで移動、ダブルクリックで打ち直す）。

変形（Ctrl＋T）と 3D の上の枠

  • 変形（Ctrl＋T）：選択範囲があればその中を、無ければレイヤー全体を動かす枠を出します。
  • 枠は 3D の区画（モデルの上の、動かす絵のあたり）と UV の区画の両方に出ます。どちらの枠をつかんでも同じように動き、もう一方もついてきます。動かす絵が 3D で見えていれば、UV の区画を開かずに 3D だけで操作できます。
  • 枠の中をドラッグで移動・角で拡大縮小（Shift で縦横比を変えられます）・辺で片方だけ・上の丸で回転（Shift で 15° 刻み）。左右反転・上下反転も。辺や角を反対側より先まで引くと、裏返ります。
  • 3D の枠の上でも、右・中ドラッグ・ホイール・Space＋ドラッグで視点を動かせます。視点を変えても枠はついてきます。
  • UV の区画にグリッド線を出しているときは、枠がマス目に吸い付きます（グリッド線と吸着）。
3D の変形（全版）：3D で見えている細かい所の絵でも 3D の枠が出るようにし、枠の中をドラッグして離しても枠と絵が飛ばないようにしました（自由変形・ワープも）。
対称にも（全版）：描画の対称が入っていて選択範囲が片側にあるとき、下のバーに「対称にも」が出ます。入れたまま動かすと、3D の反対側も鏡に写して一緒に動きます（反対側の元の絵は置き換わります）。移動ツールも同じです。

自由変形・ワープ

変形・移動・変形ツール・画像を追加・貼り付け・画像を 3D／UV に貼る の枠の下のバーに、3 つのアイコン（拡大・縮小・回転／自由変形／ワープ）が並びます。

  • 自由変形：4 つの角をそれぞれドラッグして形を変えます（遠近のように絵が付きます）。
  • ワープ：格子の点をドラッグして絵を曲げます。格子は 3×3（バーで 4×4・5×5 も）。
  • どちらも、上の丸か角の少し外側をドラッグで回せます（Shift で 15° 刻み）。中をドラッグで全体を移動。
  • 切り替えても形はそのままです。確定は元に戻す 1 回分（選択範囲を動かしたときも）。3D に貼るときは、画面の上の形を見えている面に投影します。

コピー・切り取り・貼り付け

  • コピー（Ctrl＋C）・切り取り（Ctrl＋X）：選択範囲の中（無ければレイヤー全体）。レイヤーを複数選んでいるときも、対象は選択中の 1 枚だけです。
  • 貼り付け（Ctrl＋V）：同じ UV の位置に新しいレイヤーで貼って、そのまま変形できます。
  • ロック中・非表示・透明度を保護したレイヤーは、切り取り・消去をしません（理由を知らせます）。

画像を追加・画像を貼る

  • 画像を追加（ファイル → 読み込み → 画像をレイヤーとして読み込む・画像のドロップ・外からコピーした画像の Ctrl＋V）：画像を置く枠が出ます。UV の区画が開いていれば UV の上、閉じていれば 3D の真ん中（見えている面に投影）。縦横比はそのまま、透明な所は透明のままです。
  • 枠を合わせて Enter で、ファイル名の新しいレイヤーに入ります。Esc でやめると何も残りません。枠の下のバーの「テクスチャ全体に貼る」で、UV 全体に引き伸ばして入れることもできます（UV の大きさに描いた画像向け）。
  • 画像を 3D に貼る（編集 → 画像を 3D に貼る）：3D の上で枠を合わせ、Enter でモデルの見えている面に投影して貼ります。視点を動かしながら合わせてもかまいません。「斜めの面も濃く」で、斜めの面が薄くならないようにできます。
  • 画像を UV に貼る（編集 → 画像を UV に貼る）：UV の区画の上で枠を合わせて、新しいレイヤーに貼ります。
左右対称と選択範囲も効きます。

文字

  1. ツール「文字」（T）を選び、3D ビュー（か UV の区画）を押します。
  2. 枠と文字の窓が出て、すぐ枠の上で打てます。日本語の入力もそのまま使え、変換の候補は字の横に出ます。
  3. Ctrl＋Enter で確定します（打っている間の Enter は改行）。Esc の 1 回目で打つのをやめ（枠は残ります）、2 回目でやめます。
  • 文字の窓で、書体・大きさ・色・太字・斜体・縦書き・行間・字間・揃え・縁取りを決めます。色は色のパネルの描画色、縁取りは背景色がそのまま効きます。
  • 字ごとに変える：字を選んでから色・大きさ・書体・太字・斜体・字間・縁取りを変えると、その字だけ変わります。選ばずに変えると、これから打つ字に使います。
  • 打っている間は、キーのショートカット（E で消しゴムなど）は効きません。枠を動かすのは Ctrl を押しながらドラッグです。
  • 書体は、この PC に入っている書体を全部選べます。書体のファイル（.ttf・.otf）も読み込めます（その起動の間だけ）。

文字を打ち直す（文字レイヤー）

  • 「新しいレイヤーに」貼った文字（UV に貼った文字はいつも）は文字レイヤーになり、レイヤーの一覧に「T」の印が付きます。
  • レイヤーの一覧でダブルクリック・右クリック →「文字を打ち直す」・文字ツールで字の上を押す で、貼ったときの状態で開き直せます。字ごとの色・大きさもそのままです。
  • 文字レイヤーにペンなどで描き足すと、印が「T＋」になります。打ち直すと描き足した所は消えるので、残したいときは別のレイヤーに分けてください。
  • 右クリック →「画素にする」で、ふつうのレイヤーにします（打ち直せなくなります）。作業ファイルにも入るので、開き直しても打ち直せます。PSD にはふつうのレイヤーとして書きます。

定規

  • 描く線を定規に吸い付かせます。直線・曲線は定規の近くで描き始めた線だけ、同心円・放射線・平行線はどこで描いても効きます。
  • 作り方：直線・平行線はドラッグ、同心円・放射線は押した所が中心、曲線は点を打って Enter かダブルクリック。定規の丸はドラッグで動かせます。
  • 3D の区画の定規は、視点を動かしても画面に残ります。UV の区画にも別に置けます。
  • 表示 → 線と定規 → 定規に吸い付く（Ctrl＋Alt＋R）で切り替え、定規を消す。
曲線の制御点を置いている途中は、Ctrl＋Z で最後に置いた点を一つ戻せます。Ctrl＋Y または Ctrl＋Shift＋Z で点を戻す操作をやり直せます。Enter・ダブルクリックで定規を確定した後は、通常の履歴操作になります。
定規があるときは、その区画の下の真ん中に帯が出ます（定規の種類・吸い付くの入り切り・消す）。消すは、その区画の定規だけを消します。
