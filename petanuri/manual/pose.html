ポーズ・ブレンドシェイプ・頂点グループ Pro

3D モデルのボーン・ブレンドシェイプ・頂点グループを使って、T ポーズのままでは塗りにくい所を塗ります。

画面・名前・操作は変わることがあります。画像はサンプルのモデルを使った画面です。版の分け方（Lite・Standard・Pro）は予定です。

このページの内容
  • ポーズモード
  • ブレンドシェイプ
  • 頂点グループから範囲を作る

ポーズモード

  1. 3D ビューの上の真ん中の「ポーズ」を押します（ポーズモードの間は描きません）。
  2. 関節の点・メッシュ・右のパネル「ポーズ」の一覧で、ボーンを選びます。
  3. 出てきたつまみで回します（上の列で 回転／移動・つまみの向き を切り替え）。パネルで角度を数字で打ち込むこともできます。
  4. 「ペイント」に戻ると、そのポーズの形で塗れます（サンプルのモデルで 0.4 秒ほど）。
わきの下・腕の内側など、T ポーズでは描きにくい所にべんりです。「戻す」「全部戻す」で元の姿勢に。ポーズは作業ファイルに保存されます。

ブレンドシェイプ

  • 右のパネル「ブレンドシェイプ」に、モデルのブレンドシェイプ（シェイプキー）がメッシュごとに並びます。
  • つまみ（0〜100）で形が変わり、その形のまま表示・塗り・当たり判定が働きます。
  • 絞り込み・0 以外だけ・全部 0 に。値は作業ファイルに保存されます。

頂点グループから範囲を作る

  1. 右のパネル「頂点グループ」で、グループ（ボーンの重み）にチェックを入れます（いくつでも）。
  2. 「選択範囲にする」「足す」「引く」「この範囲だけ表示」を押します。
  3. 塗る範囲がそこだけになります。
「重みの強さで」を入れると、重みがそのまま塗る強さになって、境目がなめらかになります。
