書き出し

仕上がったテクスチャを、画像やマテリアルとして書き出します。メニューは ファイル → 書き出し です。

このページの内容
  • PNG で書き出す
  • PSD で書き出す・読み込む
  • 書き出しのにじみ（パディング）
  • 書き出し先のフォルダ
  • マテリアルを書き出す

PNG で書き出す

  1. ファイル → 書き出し → PNG で書き出す を選びます。
  2. 小さな窓で、書き出しのにじみと書き出し先を選んで「書き出す」を押します。
  3. 選んでいるセット、または全部のセットを書き出せます。ファイル名は <マテリアル名>.png です。
メインカラー2nd／3rd のフォルダがあるセットは、別々の PNG で書き出します。境界線などの効果は、効果込みの絵になります。
ベイクの光・影・質感は、見えているレイヤーの色として PNG に入ります。スタンプ用 2D キャンバスの作業用セットは、モデルのテクスチャ出力から除外します。モデルなしの 2D ペイントの PNG は、キャンバス下の「PNG を書き出す」から保存できます。

PSD で書き出す・読み込む Standard

  • ファイル → 書き出し → PSD で書き出す で、レイヤー・表示・不透明度・合成モード・クリッピング・透明度保護・フォルダ・レイヤーマスク・調整レイヤー（グラデーションマップは色の点のまま）を保ったまま書き出します。
  • 境界線は画素に焼いたレイヤーで書きます。文字レイヤーはふつうのレイヤーになります。塗る先・ノーマルマップ・メインカラー2nd／3rd のフォルダは、非表示のグループで書きます（読み込むと元に戻ります）。
  • PSD をウィンドウにドロップすると、ファイル名が同じマテリアルへ入ります。テクスチャセットのパネルの行から読み込むこともできます。
  • アバターに付いてくる改変用 PSD を読み込んで、続きから描くこともできます。
調整レイヤーの式は、ほかのアプリで開くと少し違う見た目になることがあります。

書き出しのにじみ（パディング）

UV の島の外へ、縁の色を広げて書き出します。広げないと、縮小やミップマップで UV の継ぎ目（シーム）に線が見えることがあります。

  • なし・4・8（既定）・16・32 px・島の外を全部埋める から選べます（書き出しの窓・マテリアルの書き出しの窓）。
  • PNG・PSD の合成画像・マテリアルの画像に効きます。PSD のレイヤーそのものは描いたままです。

v1.1.0 では、4096px の画像で「全部」を選んだときも、余白の最後まで埋めて書き出せます。

パディングの値は UV の区画の左下と共通です。筆の縁のうすい所は描いた所とみなさず、不透明な所の色を島の外へ広げてから、うすい所を上に重ねます（継ぎ目に下地の色の線が出にくくなりました）。「パディングを新規レイヤーに作る」も同じ決まりです。
Blender・Unity 連携へ送るテクスチャは、まだ前のパディングの決まりのままです（次の版で合わせます）。

書き出し先のフォルダ

  • 書き出しの保存先のダイアログは、前に書き出したフォルダから開きます。
  • 書き出しの窓の「フォルダを選ぶ」で決めておき、「毎回聞かずにこのフォルダへ書き出す」を入れると、PNG・PSD・AO・.unitypackage の書き出しで保存先を聞かずに、そのフォルダへ書きます。「外す」で、毎回聞くのに戻ります。
  • マテリアルのフォルダへの書き出し（Assets を選ぶ）は、前に選んだ Assets から開きます。
「毎回聞かずに」のときは、同じ名前のファイルは上書きされます。

「書き出したらフォルダを開く」は、初めから入っています。完了した画像をエクスプローラーで確認でき、不要ならチェックを外せます。保存先を決めた後は「書き出し中…」と進み具合を表示します。
