描く

3D ビューの上に、ペンで直接描きます。左のツールバーでツールを選び、サブツールとツールプロパティで描き味を決めます。

Lite・Standard・Pro と Pro アップグレードを BOOTH で配布しています。

まずは描いてみる

  1. 3D ビューのモデルの上で描き始めると、そこのテクスチャセット（例：body）へ自動で移ってから描きます（右のテクスチャセットのパネルで選んでもかまいません）。
  2. 左のツールバーでペン（P）を選び、サブツールで「G ペン」などを選びます。
  3. 色のパネルで色を選んで、3D ビューのモデルの上をなぞります。
  4. 回すときは右ドラッグ（ペンのサイドボタン）か Space＋ドラッグ、寄るときはホイールです。
モデルの上で Alt＋右クリックしても、そこのセットを選べます。くわしくはテクスチャセットのページへ。

ツールとサブツール

裏側・隠れた面にも塗る

ツールプロパティの不透明度のすぐ下の「裏側・隠れた面にも塗る」（消しゴムは「裏側・隠れた面も消す」）は、ペン先の下に見えている面を中心に、ブラシの円と同じ見た目の大きさの球の中を、カメラから見えない裏側・内側の面にも塗ります。髪の内側・服の重なり・指の間など、回り込んで見えにくい所を一度に塗れます。

  • ペン・筆・ブラシ集・消しゴム・グラデーションは、はじめから入です。切ると、見えている面だけに塗ります。
  • デコレーション・模様・凹凸にもあります（はじめは切）。ぼかし・指先・色混ぜ・スタンプは、画面に写っている色・画像を使うので、見えている面だけです。
  • 硬さで縁がぼけます。画像の先端（鉛筆・チョーク・スプレー・ブラシ集の多くなど）も使えます。「面に沿う」では面の向きに合わせ、「画面に合わせる」では画面に見える先端の形を奥へ投影します。
  • 選択範囲・隠した面・対称・透明度保護は、いつもどおり効きます。UV の区画で塗るときは関係ありません（もともと全部の面に付きます）。
厚みのある所を塗ると、反対側まで届くことがあります。ブラシの大きさに気を付けてください。

ブラシの細かい設定

  • 上の「～」の線は、いまの設定で引いた見本です。設定を変えるとその場で変わります。
  • 大きさの基準：サブツールごとに「設定どおり／テクスチャで固定／画面で可変」。テクスチャで固定にすると、寄っても引いてもテクスチャに同じ太さで塗ります。設定どおりは、ファイル → 環境設定 → 描画 の「ブラシの大きさの単位」（画面の px／テクスチャの px）に従います。
  • 先端：丸・四角・平筆・鉛筆・チョーク・スプレー・水彩・毛筆・キラキラ・星・ハートと、同梱の先端 31 個。「読み込む」で画像（白地に黒で描いた形）や、ほかのペイントソフトのブラシのファイル（.abr・.gbr・.gih、まとめた .zip）も使えます。
  • 描き足し：同じ所を重ねるほど濃くなります（エアブラシ向け）。
  • 描画モード：乗算・スクリーン・オーバーレイなど 26 種類で塗れます。「後ろに描く（まだ塗っていない所だけ）」「明るく」「暗く」もあります。
  • 補正の種類：なめらか（遅れて追う）／1€（ゆっくり描くときはぶれを強く抑え、速く描くときは遅れを減らす）／糸引き（ペン先から少し離れてついてくる。手の震えが消えます）。
  • 入り・抜き：描き始め・描き終わりを細くします。抜きは、ペンを離したときに線の最後を細く描き直すので、描いている間も遅れません。
  • 動き：速さで太さ・太さや濃さのばらつき・寝かせで太さや濃さ・ペンの傾きやねじれで先端を回す（寝かせ・ねじれは、それを送ってくるペンだけ）。
  • 筆圧の曲線：太さ・濃さそれぞれに、点を動かして効き方を決めます。
  • 紙の質感：塗る濃さに紙やキャンバスの目が入ります（同梱 6 枚・模様 15 種・好きな画像）。面に貼り付くので、視点を動かしてもずれません。
左の「ブラシサイズ」パネルで、よく使うサイズを一発で選べます。サイズは丸と数字の小さなタイルで、パネルを細くすると 1 列まで縮められます。タイルの最後の鉛筆か右クリックで、今のサイズを足す・外す。[ ] でもサイズを変えられます（1〜1000）。
3D の塗り方：「面に沿う」は斜めの面でも筆跡が伸びにくく、v1.1.0 では未設定のブラシの初期値です。「画面に合わせる」はカメラから投影するので、斜めの面では筆跡が伸びます。サブツールごとに選べます。保存済みの設定は引き継ぎ、UV ビューでの描き方は変わりません。
外部ブラシの先端を読み込む：サブツールの「読み込み」からABR・GBR・GIH・PNGなどの画像・SUT・ZIPを選びます。複数選択やパネルへのドロップも使え、登録後はそのまま描けます。全版で使えます。
取り込むのは先端画像と取得できる初期サイズ・間隔などです。元のブラシエンジン・筆圧・混色・色を完全再現するものではありません。SUTは内部の読み取れるPNGを使うため、縮小画像や先端以外の素材になる場合があります。読み込み後にツールプロパティで調整してください。
ABRは版1・2・6の画像先端、GBRは版1・2に対応。GIHの複数先端は個別に登録します。画像は透明度、または白を抜く形で先端にします。.petabrushの設定読み込み・書き出しはStandard以上です。

ぼかし・指先・色混ぜ

  • ぼかし：なぞった所をなめらかに。「ぼかしの広さ」で効く範囲が変わります。
  • 指先：色を引きずって伸ばします。
  • 色混ぜ：なぞった所の色を拾って運び、描画色と混ぜながら塗ります。「絵の具の量」が 0 なら、塗ってある色だけをなじませます。「色延び」を上げると長く伸びます。
どれも 3D の上で計算するので、UV の継ぎ目で割れません。ぼかし・指先は UV の区画でも使えます（色混ぜは 3D の区画だけ）。

塗りつぶし・グラデーション・図形

  • 島を塗る：押した UV の島を丸ごと塗ります。マテリアル全体：そのマテリアルを全部塗ります。
  • 囲まれた所を塗る：線で囲まれた所を押すと、その島の中で色の近い続いた所を塗ります。参照（すべてのレイヤー／選択中のレイヤー）・許容差・「隙間閉じ」（線の切れ目で止める）・「拡張」（線の下までもぐらせる）。
  • ポリゴン塗り：なぞった面を丸ごと描画色で塗ります。
  • グラデーション：3D ビューで始点から終点へドラッグします。「裏側・隠れた面にも塗る」（はじめから入）なら、押した所と離した所を結ぶ 3D の線に沿って、裏側・内側の面にも付きます（髪の根元から毛先へなど）。Shift で 45° 刻み。
  • 図形：直線・長方形・楕円・多角形（3〜12 角）を、塗りか枠線で。Shift で正方形・正円、「中心から描く」で始点が中心。曲線は、ドラッグして離した後に動かして曲げ、もう一度押して決めます。曲線（点をつなぐ）は押すごとに点を置き、ダブルクリックか Enter で決めます（「閉じる」で輪にして塗れます）。
塗る用のレイヤーを線のレイヤーの下に作ると、線がきれいに残ります。

複数の色・透明度を使う手順は色と透明度のグラデーションへ。

色と透明度のグラデーション

グラデーションの描画ツールは、Lite から使えます。ツールプロパティの「色」で「色と透明度の点」を選ぶと、2 色だけでなく、色と透明度を組み合わせたグラデーションで描けます。「描画色→背景色」「描画色→透明」も選べます。

  1. プリセットから選ぶか、帯の空いている所をクリックして色の点を足します。点は 2〜32 個です。
  2. 点を選び、色・位置・不透明度を変えます。位置はドラッグでも変えられます。選んだ点をもう一度タップするか、ダブルクリックすると色を選べます。
  3. 不要な点は「点を消す」・Delete・帯から引き離す操作で消します。「描画色を入れる」「均等に並べる」「左右を入れ替え」も使えます。
  4. 240 種類のプリセットはグループと名前で探せます。透明入りのプリセットもあります。一覧はスクロールできます。名前を付けて「今のを保存」で、自分のプリセットを残せます。
  5. 線形か円形を選び、3D ビューまたは UV の上で始点から終点へドラッグして描きます。
グラデーションの不透明度を 0 にした部分は、下の色を残します。すでに描いた色を消す場合は、透明色で描くを使います。高さや面の向きに沿う陰影を新しいレイヤーへ焼く場合は、Pro のグラデーションのベイクが便利です。

3D空間の点からグラデーションを塗る

通常のグラデーションでも、3D空間に置いた点から色を広げられます。モデルの外にも点を置けます。フィルターのベイクと違い、選択中の描画レイヤーへ適用します。

  1. 塗るレイヤーを選び、グラデーションツールのツールプロパティで「3D空間の点から塗る」を押します。「3D空間のグラデーション」の窓が開きます。
  2. 3Dビューでモデルの面や空いている空間をクリックして、中心の点を置きます。点を動かすには移動ハンドルをドラッグするか、X・Y・Zの座標を入力します。
  3. 半径で色の広がる距離を変え、色と透明度の点やプリセットで色合いを調整します。透明な部分では下の色が残ります。
  4. プレビューで確認して適用すると、選択中のレイヤーに描かれます。元に戻す1回で適用前へ戻せます。キャンセルするとレイヤーは元の絵に戻ります。

距離と色の範囲ガイド

外側の白いつまみをドラッグすると、色の広がる距離を変えられます。色のつまみは各色の位置を動かします。中心の移動ハンドルやXYZ座標はそのまま使え、つまみ・数値・色と透明度の編集は連動します。

輪は中心からの距離、帯は色と透明度を表します。各色の位置・色・不透明度の表示で確認できます。∅の付いた色は現在の範囲には現れません。ドラッグ中にEscを押すと、そのドラッグを取り消せます。

「範囲ガイドを表示」で輪・帯・色のつまみを表示／非表示にできます。中心の移動ハンドルは引き続き使えます。Proの「点からの距離」のグラデーションベイクにも同じガイドがあり、「境界の位置」「混ざる幅」を変えると輪や色の位置にも反映されます。

従来の線形・円形のドラッグ操作と、UV上のグラデーションは引き続き使えます。高さや面の向きに沿う陰影を新しいレイヤーへ焼く場合は、Proのグラデーションのベイクを使います。

色を選ぶ・スポイト

  • 色のパネル：上のボタンで、選び方を 5 種類から切り替えます（リング＋四角・リング＋三角・四角＋色相バー・円盤＋明度バー・スライダー）。
  • 色の値のパネル：描画色／背景色・HEX・画面から色を取る・RGB／HSV の数値・不透明度。
  • 最近使った色：実際に塗った色・取った色の 12 個。押すと描画色になります。
  • X で描画色と背景色を入れ替えます。
  • スポイト：Alt を押している間は、どのツールからでもスポイトになります。
  • 画面から色を取る（Shift＋I）：ウィンドウの外も含めて、画面のどこからでも色を取れます。
  • カラーセット：見本をタップで描画色に。「＋今の描画色」で足し、ドラッグで並べ替え。見本の削除は元に戻せます。.gpl のパレットも読み書きできます。
  • 参考画像：開く・落とす・貼り付け（Ctrl＋V）で表示して、スポイトで色を取れます。上の虫めがねで拡大・縮小、「100%」で等倍、四隅の印で全体に合わせます（ペンだけでも使えます）。
補助スライダーはRGB／HSVのボタンで切り替えます。上のカラーフィールドと色相バーの形は変わりません。HSVでは色相・鮮やかさ・明るさを調整でき、選んだ形式は次回起動にも残ります。
Altボタン式のカメラ操作では、3DのAltはカメラに使います。3DのスポイトはIキー、UVのスポイトは従来どおりAltでも使えます。

透明色で描く（同じブラシで消す）

色の値のパネルの市松模様のボタンか C で、透明色へ切り替えます。ペン・筆・ブラシ集などのブラシで、先端の形・硬さ・筆圧・流量を活かしたまま、選択中の描画レイヤーの色を消せます。

もう一度 C を押すか、普通の描画色を選ぶと戻ります。透明度を保護したレイヤーでは消せないので、消したいときは透明度保護を解除します。

透明色はブラシで消すための切り替えです。すべてのツールを消去に変える機能ではありません。

左右対称で描く

  1. 3D ビューの左上の X（左右）を押します（M キーでも）。
  2. そのまま描くと、反対側にも同じように入ります。
  • Y（前後）・Z（上下）も、いくつでも同時に使えます（X と Z なら 4 か所に入ります）。
  • ▼ で折り返しの中心を「モデルの中心」「原点」「指定」から選べます。「指定」は、数（cm）を入れるか「モデルの上を押して決める」で。「頂点に合わせる」なら、押した所にいちばん近い頂点の位置になります。3D の右クリック →「対称で描く」→「ここを対称の中心に」でも決められます。
  • 「モデルの中心」の左右は、形がいちばん左右対称になる所です（片側だけの飾りや小物があっても、体の真ん中になります）。
  • ▼ の「対称の相手を探す範囲」（0〜3%、既定 1%）：左右で少し形が違う服などで、折り返した所に面が無いとき、この範囲でいちばん近い面を反対側として塗ります。
  • ツールプロパティのいちばん上と、UV の区画の見出しにも「対称 X・Y・Z」があります（3D の左上と同じ切り替えです）。対称が効かない道具では、そこに対称の欄が出ず、3D の左上の X・Y・Z に斜線が付きます。色混ぜのように UV の区画でだけ効かない道具では、理由が出ます。

どの道具で効くか（○ 効く・△ 条件つき・× 効かない・― 関係ない）。押した所・描いた形の鏡の位置にも同じ操作をして、元に戻すは 1 回です。

△ グラデーション：3D の区画では、見えている面は直接の色のまま、鏡の側に入るのは見えていない面です。UV の区画では、透明を含むグラデーションで濃い方が入ります。「裏側・隠れた面にも塗る」が入のときは、どの面も 3D の線で直接付くので対称は使いません。
ポーズを付けているときも、元のポーズ（休みの姿勢）で対称の所に塗ります。腕を曲げていても、反対の腕の同じ所に入ります（ポーズ）。
「隠した側にも対称描画」を使う：対称の▼でチェックを入れ、片側を隠して見えている側を3Dで塗ると、隠した反対側にも同時に描けます。はじめはOFFです。ペン・ブラシ・消しゴム・スタンプに対応し、UV描画と塗りつぶしは対象外です。選択範囲外・ロックしたレイヤー・対象外のセットには描きません。

ポップアップパレット（ペンだけで使う）

  • 3D・UV の上で、ペンのサイドボタンを押して動かさずに離すと、その場に丸いパレットが出ます（ドラッグすると今までどおり回転）。
  • 外周：よく使うサブツール（「＋」で今のサブツールを足す、長押し・右クリックで外す。10 個まで）。内側：色相の輪と四角で描画色、上の小さな丸は最近使った色、下の札を上下にドラッグでブラシサイズ。
  • パレットの外を押す・Esc で閉じます。マウスで使うときは、ファイル → 環境設定 → 操作 の「右クリック」をポップアップパレットにします（右クリックのメニューの一番上の「ポップアップパレットを出す」でも出せます）。

服や小物にも

アバターの体だけでなく、衣装や小物も同じ道具で塗れます。下は、ののつよシリーズの衣装と小物をぺたぬり3D で開いた表示例です。

部分（UV の島）だけに線を引きたいときは、選択範囲の「島で選択」で部分を選び、「共通」で帯の形と重ねてから塗ります（選択範囲）。
