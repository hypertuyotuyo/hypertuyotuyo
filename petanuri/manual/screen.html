画面・パネル・環境設定

画面のどこに何があるか、パネルとツールバーの動かし方、3D ビューの見え方の切り替え、環境設定の全部の項目です。パネルの配置は次の起動でも戻ります。

まずはこれだけ
  1. 出ていないパネルは、表示 → ウィンドウ で出します（くわしく）。
  2. パネルは見出しをドラッグして、好きな所へ動かせます（くわしく）。
  3. 3D の見え方は、3D ビューの左上の表示の形式のアイコンで切り替えます（くわしく）。
  4. 配置がわからなくなったら、表示 → ウィンドウ →「ウィンドウの配置を初期に戻す」を選びます（くわしく）。
  5. 設定は ファイル → 環境設定（Ctrl＋Alt＋Shift＋K）です（くわしく）。

画面のどこに何があるか（はじめの配置）

初めて起動したときの並びです。真ん中が描く所（3D ビュー）で、左右にパネルが並びます。

  • 上：メニューバー。「ファイル」の右に、新規作成・開く・保存と、元に戻す・やり直しのボタンがあります（戻せないときは薄くなります）。
  • 左：ツールバーと、サブツール・ツールプロパティ・ブラシサイズ・参考画像。
  • 右：3 列です。3D ビューのすぐ右にテクスチャセット・レイヤープロパティ・レイヤー。その右に色・色の値・カラーセット｜最近使った色（タブ）・作業の履歴。
  • いちばん右：オブジェクトと、Pro のパネル（頂点グループ・マテリアル・ブレンドシェイプ・ポーズ）を、アイコンの帯にたたんだ列。アイコンを押すと、そのパネルが横に出ます。

窓の大きさに合わせた並び

  • 窓が低い（高さ 860 未満）ときは、テクスチャセットのパネルを畳みます。セットは、レイヤーのパネルの見出しで切り替えます。
  • 幅 1400 未満（1280×720・1366×768 など）では、色の列もいちばん右の帯にまとめて、3D ビューを広く残します。幅 1100 未満では、列をさらに細くし、レイヤープロパティも帯に入れます。
  • はじめの配置のままなら、窓の大きさを変えると組み直します。パネルを動かす・畳むなど配置を変えた後は、組み直しません。
  • 配置は次の起動でも戻ります。

はじめの配置に戻す

  1. 表示 → ウィンドウ →「ウィンドウの配置を初期に戻す」を選びます。
  2. パネルが、今の窓の大きさのはじめの配置に戻ります。ツールバーも左に戻り、ツールの並びも元の順になります。

うまくいかないとき

  • パネルもツールバーも全部消えた：Tab で隠れています。もう一度 Tab を押すか、表示 →「パレットを表示・隠す」を選びます。
  • 使いたいパネルが見当たらない：表示 → ウィンドウ で、そのパネルに ✓ を入れます（パネルの一覧）。いちばん右のアイコンの帯にたたまれていることもあります。
  • 窓を広げても並びが変わらない：配置を変えた後は、組み直しません。「ウィンドウの配置を初期に戻す」で、今の大きさに合わせ直します。

パネルを出す・隠す（パネルの一覧）

パネルは、メニューの 表示 → ウィンドウ で出し入れします。✓ が付いているのが、出ているパネルです。

  1. 表示 → ウィンドウ を開きます。
  2. 出したいパネルの名前を選びます。✓ が付いて、パネルが出ます。
  3. 隠すときは、もう一度選びます。パネルの見出しの右クリック →「このパネルを隠す」でも隠せます。

  • Tab（表示 →「パレットを表示・隠す」）で、ツールバーとパネルをまとめて隠す・出すができます。3D ビューを広く見たいときに使います。
  • Pro のパネルは、Lite では鍵の印が付き、中身の代わりに説明が出ます。Standard では一覧に出ません。

パネルを動かす

パネルは、3D ビューの左右（縦の列）と上下（横長の段）に、何列・何段でも並べられます。どこにも入れずに浮かせることもできます。

  1. パネルの見出しをドラッグします。入る所に線や枠が出ます。
  2. 置きたい所で離します。離した所で決まります。
離す所どうなるか
列・段の中ほどその列・段に差し込む（入る所に線が出ます。段の中ではパネルが横に並びます）
列・段の端その隣に新しい列・段を作る（端に太い線が出ます）
3D ビューの端の枠（「左に列を足す」「右に列を足す」「上に置く」「下に置く」）その側に新しい列・段を作る
それ以外（3D ビューの真ん中など）浮いたウィンドウになる

幅・高さを変える

  • 列と列・段と段の境目をドラッグすると、幅・高さが変わります。境目のダブルクリックで元に戻ります。
  • 左右の列のパネルは、下の端のつまみをドラッグで高さを変えられます（ダブルクリックで自動に戻す）。長い中身はパネルの中でスクロールします。
  • 空になった列・段は消えて、3D ビューが広がります。
  • サブツールのタイルやブラシサイズは、パネルの幅と高さに合わせて並びが変わります。ブラシサイズだけの列・浮いたウィンドウは、タイル 1 列の幅（約 64px）まで細くできます。

浮いたウィンドウ

  • 見出しをドラッグで動かし、右下のつまみで大きさを変えます。見出しのクリックで折りたたみます。
  • × はありません。隠すときは、表示 → ウィンドウ か、見出しの右クリック →「このパネルを隠す」です。
  • パネルはアプリの窓の中に置きます。アプリの外の別の窓には出せません。

配置を固定する

  • 表示 → ウィンドウ →「パネルの配置を固定」に ✓ を入れると、パネルを動かしたり大きさを変えたりしなくなります。うっかり動かすのを防げます。
  • 固定中も、浮いたウィンドウは見出しのドラッグで動かせて、大きさも変えられます。
  • 浮いたウィンドウは、右上の鍵で、そのウィンドウだけ固定・解除できます。固定すると動かず、大きさも変わりません（次に開いたときも覚えています）。

パネルをたたむ・タブにまとめる

使わないパネルを小さくすると、ほかのパネルや 3D ビューが広く使えます。

したいこと操作
見出しだけにする（折りたたむ）パネルの見出しをクリックします。もう一度クリックで戻ります。段の中で畳んだパネルは、見出しだけの細い縦長になります
タブにまとめる見出しを、別のパネルの見出しの上へドラッグします。「ここに重ねるとタブにする」と出たら離します。上のタブで切り替えます
タブを畳む選んでいるタブを、もう一度押します
タブを切り離すタブを外へドラッグします（タブの右クリック →「このタブを切り離す」でも）
タブをまとめて動かすタブの並びの空いている所をドラッグします
列をアイコンの帯にする列の上の「<」「>」を押します。列がアイコンだけの細い帯になります。もう一度押すと元の列に戻ります
帯からパネルを出す帯のアイコンを押すと、そのパネルだけが横に出ます。外を押す・Esc・同じアイコンでしまいます

ツールバー・よく使うツール

ツールバーは、はじめは左にあります。作業の場所の上・下・右に付けたり、浮かせたりできます。

  1. ツールバーのつまみ（縦のときは上の端、横のときは左の端）をドラッグします。作業の場所の 4 辺に受け口が出ます。
  2. 受け口で離すと、その端に付きます。上・下では横に並び、入りきらなければ折り返します。
  • 受け口以外で離すと浮きます。浮いたツールバーは「横」「縦」で並びを切り替え、つまみのダブルクリックで前の端に戻ります。
  • ボタンの右クリック →「ツールバーの置き場所」で、左・右・上・下・浮かせる も選べます。置き場所は次の起動にも残ります。
  • ボタンの右クリック →「ツールバーのアイコンの大きさ」で 大・小、「ツールバーの列」で「列：自動」「列：いつも 1 列」を選べます。入りきらない道具は、ホイール・端の矢印・ペンのドラッグで送れます。
  • 並べ替え：ボタンをドラッグ（ペンでも）して好きな順にします。少し動かしてから離すと並べ替え、動かさずに離すとそのツールを選びます。右クリックの「並びを初期に戻す」で元の順に戻ります。
  • 画面の色：ツールバーのいちばん後ろの太陽と月のスイッチで、ライトとダークを切り替えます（ダークモード）。
  • 隠す：表示 → ウィンドウ →「ツールバー」の ✓ を外します。
  • ツール一覧：表示 → ウィンドウ →「ツール一覧」で、ツールのアイコンを格子に並べたパネルを出せます。ほかのパネルと同じく列やタブに入れられ、幅に合わせて折り返します。下の描画色を押すと「色」のパネル、背景色か ⇄ で入れ替え、小さな白黒か D で黒・白に戻ります。

よく使うツールの帯

よく使うツールやサブツールを、3D ビューと UV ビューの上の小さな帯に並べて、すぐ持ち替えられます。

  1. ツールバーのボタンか、サブツール（ブラシ集のプリセットも）を右クリックします。
  2. 「よく使うに登録」を選びます。帯にアイコンが足されます。
  3. 帯のアイコンを押すと、そのツール・サブツールに切り替わります。
  • 帯の「＋」で今のサブツールを登録し、入っていれば「－」で外します（ペンだけでも使えます）。アイコンの右クリックでも外せます。
  • 左の点々のつまみで帯を動かし、アイコンのドラッグで並べ替えます。
  • 帯の右クリックで「縦に並べる」「位置を初期に戻す」「この帯を隠す」。× でも隠せます。
  • 隠した帯は、表示 → ウィンドウ →「よく使うツール（3D ビュー）」「よく使うツール（UV ビュー）」で、それぞれまた出せます。

3D ビューの四隅のアイコン

3D ビューの四隅に、表示の切り替えと視点のアイコンが並びます。▼ の付いたアイコンは、下の ▼ を押すと設定が開きます（Esc か外を押すと閉じます）。

場所あるもの
左上メッシュの線（メッシュの線）・表示の形式（見え方）・片面／両面・対称で描く X・Y・Z（対称で描く）・表示範囲（表示範囲）
上の真ん中ペイント／ポーズの切り替え。ポーズモードの間はボーンの操作（ポーズ）、塗る先を塗っている間は塗る先の操作（塗る先）に変わります
右上正面・背面・右・左・上・下・透視／平行 ▼・全体表示。3D ナビも、はじめは右上にあります（3D ナビ）
右下3D ナビを小さくしたときのアイコン・別の角度の小窓（別の角度の小窓）
左下触った所へ移る・メインとサブのテクスチャセット・またいで描く（2 つのセットをまたいで描く）
下の真ん中選択範囲のバー（選択範囲のバー）・隠している間のバー（隠すペン）
  • 上の真ん中の段は、左のつまみ（⋮）をドラッグで好きな所へ動かせます。つまみのダブルクリックで元の位置に戻ります。
  • 3D ビューが狭いと、右上のアイコンは 2 段になります。それでも入らないと、視点 → 表示範囲 → 対称 → 片面／両面 → 表示の形式 → メッシュの線 の順に、左上の「⋯」の板へしまいます。「⋯」を押すと出ます。
  • もっと狭いと、左下の帯は字を隠してアイコンだけになり、さらに狭いと「⋯」の板へ入ります。狭さは、窓ではなく 3D ビューの幅で決まります。

視野角を変える

右上の透視／平行のアイコンの ▼ で、投影の方式と、透視投影の視野角を 5〜120° で変えられます。小さいほど望遠、大きいほど広角です。「初期値に戻す」で 30° に戻ります。

3D ナビで視点を動かす

3D ナビは、マウスのボタンやキーを使わずに視点を動かす道具です。ペンだけで描くときに便利です。

操作すること
軸の丸（X・Y・Z）をタップその軸の視点（X＝右、-Y＝正面、Z＝上）。もう一度で反対側
球をドラッグ回転
虫めがねを上下にドラッグズーム
手のひらをドラッグ平行移動
丸い矢印を左右にドラッグ画面の回転（右で時計回り。ダブルクリックで 0° に戻す）
球の下の ⟲・角度・⟳⟲・⟳ で 15° ずつ画面を回す。角度を押すと 0° に戻る
四角のボタン全体表示
透視／平行のボタン透視投影と平行投影を切り替える
錠前のボタンカメラの向きのロック（下を見てください）
  • 軸の視点に合わせると平行投影になり、回すと透視投影に戻ります（ファイル → 環境設定 → 操作 →「軸の視点は平行投影」で切れます）。
  • キーボードのテンキーでも視点を変えられます（視点（テンキー））。

カメラの向きをロックする

錠前のボタンを押すと、視点の回転だけを止めます。平行移動と拡大縮小はできます。もう一度押すと解除します。決めた向きのまま、寄ったり動かしたりして塗るときに使います。

画面を傾ける（画面の回転）

3D ビューを紙のように傾けて、描きやすい角度にできます。

  • Shift＋ホイールで 5° ずつ、3D ナビの ⟲・⟳ で 15° ずつ回ります。丸い矢印を左右にドラッグしても回せます。
  • カーソルが UV の区画の上なら、UV を回します。
  • 回したまま、描く・選ぶ・平行移動・右ドラッグの回転がそのまま使えます。ドラッグは見た目の向きに動きます。
  • キー割り当ての「画面を左に回す（15°）」「画面を右に回す（15°）」「画面の回転を戻す」で、キーも付けられます（はじめはキーなし）。

ナビを動かす・小さくする

  • 上のつまみ（…）をドラッグで好きな所へ動かします。ダブルクリックで右上に戻ります。
  • 左の端・下の端・左下の角をドラッグで、大きさを変えます。ファイル → 環境設定 → インターフェイス の「3D ナビの大きさ」でも変えられます。
  • 「—」で小さくして、右下のアイコンにします。アイコンを押すと戻ります（表示 → ウィンドウ →「3D ナビ（隠すと右下のアイコンで戻す）」でも）。
  • ナビの下に、回転と拡大縮小のスライダーを出せます。ファイル → 環境設定 → インターフェイス の「ナビに回転・拡大縮小のスライダーを出す」を入れます（はじめは切）。3D ナビと UV のガイドの両方に出ます。

別の角度の小窓で同時に見る

3D ビューの中に、もう 1 台のカメラで見た小さな 3D を出します。描きながら、反対側や横からの見え方を確かめられます。小窓は見るだけで、描くのは大きい方です。

  1. 3D ビューの右下の、別の角度の小窓のアイコンを押します（表示 → ウィンドウ →「別の角度の小窓」でも）。
  2. 小窓の見出しで、向き（正面・右・背面・左・上・反対）を選びます。「反対」は、大きい方の視点の反対側です。
  • 小窓の中をドラッグで回し、中ボタンか Shift＋ドラッグで平行移動します。
  • ホイールか Ctrl＋ドラッグ（上へで寄る。ペン向け）で寄る・引く、ダブルクリックで全体表示です。
  • 見出しで動かし、左・上の端と左上の角で大きさを変えます。✕ で閉じます。

3D と UV を小窓にする

3D と UV を並べているとき、片方を小窓にして、もう片方を広く使えます。

  1. U で UV を出して、3D と並べます（UV の区画を出す）。
  2. 小窓にしたい方の右上の ✕ の下のボタンを押します。その方が小窓になり、もう一方が全体に広がります。
  • 表示 → UV →「UV を小窓に（3D を全体に）」「3D を小窓に（UV を全体に）」や、UV の見出しの ⋯ からも同じことができます。
  • 小窓は見出しのドラッグで動かし、四辺・四隅で大きさを変えます。アプリの窓の中なら、パネルの上にも置けます。
  • ⇄ で小窓と全体を入れ替え、▣ で並べた表示に戻し、✕ で小窓の方を閉じます。
  • 右上の鍵で固定します（動かず、大きさも変わりません）。Tab でパレットを隠しても、小窓は残ります。

見え方を変える（表示の形式・光の向き）

3D ビューの見え方を切り替えます。変わるのは見え方だけで、塗った絵と書き出す画像は変わりません。

  1. 3D ビューの左上の、表示の形式のアイコンを押します（表示 → 表示の形式 でも選べます）。
  2. 使いたい形式を選びます。次の起動も同じ形式で開きます。
表示の形式見え方
塗った色のまま（unlit）光を当てず、塗った色をそのまま見せます。色を確かめるとき
2 値トゥーン光の当たる所と影の 2 色で見せます
陰影（凸凹が分かる）凸凹が分かるように照らします。初めて使うときは、この形式で開きます
線だけ（ワイヤーフレーム）テクスチャを隠して、メッシュの線だけを見せます。ポーズ・ブレンドシェイプ・移動で形が変わっても、線がついてきます
仕上がり（lilToon・MToon の見た目・β版） Proマテリアルの設定を通した見た目です（「仕上がり」で見る）

片面表示・両面表示

同じアイコンの並びか、表示 → 表示の形式 で選びます。「片面表示（裏向きの面は描かない）」と「両面表示（見えている裏面にも塗る）」があります。服の内側など、裏側に塗るときは両面にします（裏側・隠れた面にも塗る）。

光の向きを変える

  1. 表示の形式のアイコンの下の ▼ を押します。
  2. 球をドラッグして、光の来る向きを決めます。左右・高さのつまみでも変えられます。
  3. 「カメラについてくる」を入れると、視点を回しても光の当たり方が同じになります。「初期に戻す」で元に戻ります。
  • 2 値トゥーン・陰影・仕上がりで、同じ光を使います。「塗った色のまま」では光は見えません。
  • Pro マテリアルのパネルの「表示と光」と同じ値です。
  • カメラ操作が「Alt ボタン式」のときは、Shift＋右ドラッグで光の左右を回せます。

透明な所の見え方

  • 消しゴムや透明色で塗った所は、3D では下に市松模様が見えます。表示 → 表示の形式 →「透明な所を市松模様で表示」を切ると、灰色になります。
  • テクスチャセットの行の右クリック（か「…」）→「アルファ抜き（3D で透明を抜く）」で、透明の見せ方を選べます。「なし」・「カットアウト」（不透明度 50% より薄い所を抜いて向こうを見せる）・「半透明」（不透明度のまま透かす）です。
  • アルファ抜きも見え方だけで、書き出す画像は変わりません。作業ファイルに残り、元に戻せます。抜いた所は 3D では押せないので、UV の区画で塗ります。

テクスチャをドットのまま表示する

3D でテクスチャを補間せず、1 画素ずつ四角く見せます。引いて細かく見える所は補間します。

  • テクスチャセットごとに、セットの行の ⋯ か右クリック →「ドットのまま表示（補間しない）」で切り替えます。入っているセットは、行に四角の印が出ます（押すと切れます）。
  • どのセットも、最初から入っています。自分で切り替えたセットは作業ファイルに残ります。表示だけの設定で、塗った絵と書き出しは変わりません。
  • 表示 → 表示の形式 →「全部のセットをドットのまま表示（補間しない）」で、全部のセットをまとめて切り替えます。
  • UV の区画は、寄るといつもドットのまま見えます。

うまくいかないとき

  • 影が付いて、塗った色が分かりにくい：表示の形式を「塗った色のまま」にします。
  • 光の向きを変えても見た目が変わらない：「塗った色のまま」では光は見えません。2 値トゥーンか陰影にします。
  • 透明にした所が灰色・市松模様に見える：見え方だけです。向こうを透かして見たいときは、テクスチャセットの「アルファ抜き」をカットアウトか半透明にします。
  • アルファ抜きにしたら、その所に塗れない：抜いた所は 3D では押せません。UV の区画で塗るか、アルファ抜きを「なし」に戻します。
  • 低い解像度のテクスチャが 3D でぼやける：そのセットの「ドットのまま表示（補間しない）」を入れます。
  • 「仕上がり」が選べない：Pro だけの表示です（版のちがい）。

ポップアップパレット（ペンだけで使う）

ペンを持ったまま、その場で色・サブツール・ブラシサイズを変えられる丸いパレットです。

  1. 3D ビューか UV の区画の上で、ペンのサイドボタンを押します。
  2. ペンを動かさずに離します。その場に丸いパレットが出ます（動かすと、今までどおり回転・平行移動です）。
  3. 使い終わったら、パレットの外を押します（描きません）。Esc か、もう一度右ボタンのタップでも閉じます。
  • 外周：よく使うサブツール。押すと持ち替えて閉じます。「＋」で今のサブツールを足し、長押し・右クリックで外します（10 個まで）。
  • 内側：色相の輪と、彩度・明度の四角で描画色を選びます。上の小さな丸は最近使った色です。
  • 下の札：上下にドラッグでブラシサイズを変えます。
  • マウスで出すときは、ファイル → 環境設定 → 操作 → マウス の「右クリック」を「ポップアップパレット」にします（はじめは「メニュー」）。右クリックのメニューの一番上の「ポップアップパレットを出す」でも出せます。
  • ペンタブの設定で Windows Ink を切っているときは、サイドボタンもマウスの右クリックとして届くので、上の「右クリック」の設定に従います。

参考画像を見ながら描く

資料の画像をパネルに出して、見ながら描けます。画像から色も取れます。

  1. 参考画像のパネルの「開く」を押して、画像を選びます。
  2. 下のサムネイルで、開いた画像を切り替えます。× で閉じます。
  • ファイル → 読み込み →「参考画像を開く」、パネルへの落とし込み、パネルを押してから Ctrl＋V でも開けます。
  • 色を取る：スポイトで、画像をクリックかドラッグします。離すと、その色が最近使った色に入ります。
  • 動かす：手のひら・中ボタン・右ボタン・Space＋ドラッグで移動、ホイールで拡大縮小します。
  • 見せ方：上のボタンで全体表示・左右反転・90° 回転。虫めがねの ＋・－ で拡大縮小し（ペンだけでも使えます）、「100%」で画像の 1 画素を画面の 1 点にします。
  • 画像は長辺 1600px にして保存し、次に起動したときも戻ります。

画面の共通の操作

どのパネル・窓でも同じように使える操作です。

  • ボタンや項目の説明は、カーソル（ペン先）を名前の上に置くと出ます。
  • 環境設定・ショートカット一覧・確認の窓は、見出しのドラッグで動かせます。右上の × か Esc で閉じます。
  • メニューの項目やボタンは、ペンで押し込んでから離しても決まります（ペン・入力で変えられます）。
  • ペンのダブルタップは、2 回目の位置が少しずれても（12px・0.5 秒まで）ダブルクリックとして受けます。
  • ペンの消しゴム側でも、パネル・窓の操作（ボタン・スライダー・並べ替え・ドラッグ）はペン先と同じに効きます。描く区画の中では消しゴムになります。
  • ブラウザの操作のキー（再読み込み・印刷・ページの拡大など）は効きません。画面の文字は選べません（入力欄は選べます）。
  • 今の版で使えない機能は、メニューやボタンが薄くなり、鍵の印が付きます（版のちがい）。

ダークモード・配色・言語を変える

画面の色を明るい「ライト」と暗い「ダーク」で切り替えます。

  1. ツールバーのいちばん後ろ（縦のときは下、横のときは右の端）の、太陽と月のスイッチを押します。
  2. ライトとダークが切り替わります。
  • ファイル → 環境設定 → インターフェイス → 表示 の「画面の色」でも同じです（はじめはライト）。
  • キーで切り替えるときは、キー割り当ての分類「表示」の「ダークモード」にキーを付けます（キーを割り当てる）。

配色を変える

ファイル → 環境設定 → インターフェイス → 表示 の「配色」で、画面の地・パネル・ボタン・文字・主な色・補助の色・3D 背景・UV 背景・ツールバーの色を変えられます。

  • ライトとダークで別々に保存します。
  • 「初期の配色に戻す」で元の色に戻ります。

画面の言語を変える

ファイル → 環境設定 → インターフェイス → 言語 の「言語 / Language」で選びます。日本語・English・한국어・中文（简体）・中文（繁體）があります。

環境設定

アプリ全体の設定です。ファイル → 環境設定（Ctrl＋Alt＋Shift＋K）で開きます。

  • 左に分類、右に節が並びます。節の見出しを押すと、開く・たたむが切り替わります（たたんだ節は次も同じ）。
  • 項目の説明は、名前の上にカーソルを置くと出ます。
  • 設定は、次の起動にも残ります。

環境設定に無い設定

次の設定は、使う所にだけあります。

  • 2 つのセットをまたいで描く：3D ビューの左下の「またいで描く」（メインとサブ）
  • UV の島の外へ続けて塗る：UV の区画の見出し・表示 → UV（島の外にはみ出したとき）
  • ペンのドラッグでレイヤー・サブツールを動かす：レイヤーの「…」
  • 書き出しのにじみと書き出し先：書き出しの窓（書き出しのにじみ）
  • 対称の相手を探す範囲：3D ビューの左上の対称の ▼（対称で描く）

うまくいかないとき

  • 「3D マウス」の節が無い：3D マウスを一度もつないでいないと出ません。つなぐと出ます。
  • 「ペンの線を先に表示」を入れても変わらない：ペン（Windows Ink）で描くときだけ効きます。マウス・タッチ・「筆圧を直接読む（WinTab）」のペンでは何もしません。起こせなかったときは、右下に理由を出して切れます。
