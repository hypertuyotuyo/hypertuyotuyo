v1.3.0

最新

2026-10-25

アプリの中から自動で更新、画面から色を取るの直し、レースのブラシ、UV が変わったときの絵合わせ

アプリの中から自動で更新できるようになりました。描く機能・連携の追加と、たくさんの不具合の修正を入れています。とくに書いていない物は全版（Lite・Standard・Pro）で使えます。

大きな変更

アプリの中から自動で更新できるようになりました（Windows）

  • 新しい版があるとお知らせが出て、確認 1 回で、ダウンロード・確認（署名・中身）・入れ替え・再起動まで行います起動のときに自動でダウンロードしない設定もあります（環境設定 → システム → 起動）。公式サイトから取れないときは、今までどおり BOOTH でダウンロードする案内に戻ります
  • 配布の形が変わりました：各版 ZIP 1 つです。展開した「PetaNuri3D」フォルダに本体と setup.exe が入っていますsetup.exe で入れるか、フォルダの PetaNuri3D-win_x64.exe をそのまま起動してください（setup.exe だけを取り出さず、フォルダごと使ってください）

ご注意（前の版から更新する方へ）

  • v1.2.1 以前からの更新は、今回だけ手で行ってください作業を保存してアプリを閉じ、ZIP を展開して、中の setup.exe をダブルクリックします（前に setup で入れた所に上書きで入ります）。v1.2.1 以前のアプリの「インストールして再起動」は、新しい形の ZIP を見つけられません
  • Standard を Pro にしている方は、アップグレードのファイルの入れ直しは要りません（これからも、更新しても Pro のままです）
  • Unity 連携のアドオンも新しくしてください Proメインカラー2nd／3rd を運ぶため、連携の約束を新しくしました。前のアドオンでもつながりますが、2nd／3rd は運ばれません
  • ノーマルマップ画像を結合した作業ファイルを前の版で開くと、色が数階調変わることがあります。v1.3.0 で編集してください

変更点

描き方・ファイルの扱い

  • Pro へのアップグレードのファイルが、バージョンに縛られなくなりました（一度入れれば、新しいバージョンにしても Pro のまま。今までに購入したファイルもそのまま使えます）
  • スタンプの画像を縮めずに、元の解像度で使うように（前は長辺 1,024px に縮めていました）
  • 読み込んだブラシの先端・模様の保存の数の上限を無くしました
  • 「またいで描く」で、ペン先が乗っていないテクスチャセットにはブラシがはみ出さないように（目を描くと肌まで塗られることがありました）
  • 選択範囲の外を暗くしない表示を選べるように（メニュー「選択範囲 → 選択範囲の外を暗くする」）

新機能

描く・色

  • 描画色に変える（透明度はそのまま）：描いてある所の色だけを今の描画色に。線画の色替えに（編集メニュー・レイヤーの右クリック）
  • レースのブラシ（スカラップ・ピコット・小花・網目）：線に沿った帯で並ぶので、曲線・角・3D でもつながります
  • 図形ツールで先端画像を使えるように：ステッチなどを図形の輪郭に沿って並べて描けます
  • ぼかし・指先・色混ぜでもブラシの先端を選べるように
  • スポイトの拡大鏡：取る所のまわりを拡大して見せます（3D・UV。ツールプロパティで切れます）
  • 選択範囲の絵を反対側へミラーコピー・マスクも左右にミラーコピー

モデル・連携

  • モデルを読み直して UV が変わったとき、描いた絵を新しい UV に合わせる（Blender・Unity 連携では自動）
  • モデル（FBX）を含めずに保存：配る用の小さな作業ファイル。開くと手元のモデルを選びます
  • Unity 連携で lilToon のメインカラー2nd／3rd も読み込み・書き戻し Pro
  • ノーマルマップ画像の結合 Pro
  • 2D ペイントの絵を PSD で書き出す Standard Pro

画面と操作

  • 3D ナビにカメラの向きのロック（回転だけ止めて、移動・拡大縮小はできる）
  • ナビの下に回転・拡大縮小のスライダー（環境設定 → インターフェイス → 表示。ナビの右クリックからも）
  • 環境設定の配色に「UV 背景」
  • ツールバーの右クリックで「列：自動」「列：いつも 1 列」。入りきらない道具はホイールなどで送れます
  • 繁体字中国語（中文（繁體））の表示

不具合修正

画面から色を取る（exe 版）

  • v1.2.1 で「画面から色を取る」が使えなかった（開いた直後に必ず取り消されていました。「EyeDropper is not available」と出ることも）表示エンジン（WebView2）のスポイトをやめて、ぺたぬり3D 自身のスポイトにしました。ルーペ（拡大と色の値）を見ながら、クリック・Enter・Space で取ります。矢印キーで 1 画素ずつ（Shift で 10 画素）、Esc・右クリックでやめます（始めたときの画面を写して取るので、動画などは止まって見えます）

保存・読み込み

  • 保存先の空きが足りないとき、途中で切れたファイルで作業ファイルを置き換えて「保存しました」と出ることがあった（元のファイルを残して知らせます）
  • 保存先の応答が止まると「保存中…」のまま何も知らせなかった
  • 大きい PSD（115MB・50 レイヤーを超えるような物）が、メモリが足りず読み込めなかった（Unity 連携でメインカラー2nd の PSD が読まれないのもこれが原因でした）
  • 大きい PSD の読み込み・書き出しや重い作業ファイルの保存で、画面が長く止まり、メモリを多く使っていた
  • 別々の作業の自動保存が同じ組になって、前の作業の分が消えることがあった
  • モデルを読み直すと、隠していたオブジェクトが全部見えるようになっていた
  • 2D ペイントで、メニューから PSD を読み込めなかった

描く

  • 髪や重ね着で、対称に描いたときに反対側が少しずれていた
  • 対称で指先を使うと左右で効き方が違った
  • 太い境界線を付けたまま内側の塗り残しを埋めると、境界線がガクガク広がった
  • エアブラシなどを透明色で使って薄く消すと、跡がざらついて見えた
  • PNG の書き出しで、まわりの広げ（パディング）を 64・128px にしても 32px で止まっていた
  • Ctrl＋＝／Ctrl＋－ で寄る・引くが効かなくなっていた

レイヤー・結合

  • 下地を含むフォルダの結合などで、下地の扱い（消せない土台）が無くなっていた
  • 非表示・ロック中のレイヤーやフォルダが、結合で消えたり、結合できてしまったりしていた
  • フォルダを解除すると、フォルダの不透明度・合成モード・マスクが黙って外れていた（外れるときは知らせます）

連携

  • Unity への書き出しで、Unity が使っている .meta を読めないとき、新しい ID で書き直してしまうことがあった Pro
  • lilToon のマテリアルを書き出すと、読み込んだ後に Unity で変えた設定が戻っていた Pro
  • Blender 連携の上書きの前の写しを作れなかったとき、写しなしで上書きしていた
  • ほかにも細かな不具合を直しました

v1.2.1

配布済み

2026-10-15

WinTab とペンの直し、補助を本体へ、ステッチ、3D マウスと発光の合成モード

v1.2.0 をお使いの方からの報告をもとに、不具合の修正と、いくつかの機能の追加をしました。とくに書いていない物は全版（Lite・Standard・Pro）で使えます。

大きな変更

補助のプログラムを本体の中に入れました（Windows）

  • tools フォルダの補助のプログラム（閉じる見張り・ペンのサイドボタン・WinTab の筆圧・3D マウス・ペンの線を先に表示）は、ぺたぬり3D の本体の中で動きます。使い方・設定は変わりません書体の一覧・Unity の .meta の検索・更新の確認・書き出したファイルを開く所も、PowerShell などを起こさずに本体の中で行います
  • setup で上書きすると、前の版の tools の補助は消えます。ZIP で使っている方は、新しいフォルダに展開してください（AO を CUDA で焼く補助は今までどおり別のプログラムです）
  • 「ペンの線を先に表示」の窓は、ぺたぬり3D が前にあるときだけ出ます

ご注意（前の版から更新する方へ）

  • 更新するときは、作業を保存してアプリを閉じてから、新しい setup を実行するか、新しい ZIP を展開してください
  • v1.2.0 をお使いの方は、アプリの新しいバージョンのお知らせから更新できます「BOOTH でダウンロード」で setup の zip をダウンロードすると、「インストールして再起動」で入れ替わります
  • Standard を Pro にしている方は、v1.2.1 のアップグレードも入れ直してください「インストールして再起動」のときは、アップグレードのファイルもダウンロードしておくと一緒に入れ替わります
  • ペンタブのドライバを入れ直す・更新するときは、ぺたぬり3D を閉じてから行ってください（WinTab を使っていると、ドライバのファイルを開いたままになります）
  • ツール「凹凸」は「ステッチ」になりました（下の「変更点」）

変更点

ツール「凹凸」が「ステッチ」に

  • 縫い目（点線・ふっくら・縫い合わせ・パイピング・クロスステッチ・ジグザグ・鋲）は、描画色で今のレイヤーに描きます（全版。2D キャンバスでも）凹凸にしたいときは、ツールプロパティの「ノーマルマップのフォルダに描く」を入れてください（Pro。しわ・ふくらみは今までどおり高さで描きます）
  • 前の版で保存したサブツールのうち、何も変えていない縫い目は 1 回だけ新しい動き（描画色で描く）になります。大きさや名前を変えた物は今までどおり高さで描きます

新機能

描く・レイヤー

  • 合成モード「加算（発光）」「覆い焼き（発光）」不透明度を下げた所・やわらかい筆の縁・下が透明な所でも、光るように明るく乗ります（レイヤー・フォルダ・ブラシの描画モードなど）
  • ぼかしは、なぞるほど・往復するほど溶け合うように（ツールプロパティで前の効き方に戻せます）
  • 色混ぜは、広くやわらかく溶け合うように
  • スタンプの「次に置く所を薄く表示」を切れるように
  • 「UV の縁から塗る」の窓にプレビューと色の選び方 Pro
  • キーなどで選んだレイヤーまで、レイヤーの一覧を自動で送る

画面と操作

  • 3D マウス（3Dconnexion SpaceMouse など、6 軸で動かす機器）で視点を動かせるように（Windows）感度などは 環境設定 → 操作 → 3D マウス
  • 回し始めたときのカーソルの所を中心に回す（環境設定 → 操作 → カメラ。はじめは切）
  • 起動画面に 3D モデル・作業ファイルを落として始められるように
  • 「ペンの長押しでメニューを出す」「ペンのサイドボタンの中・右クリックを受け取る」を切れるように（環境設定 → ペン・入力 → メニュー・ボタン）

不具合修正

保存・起動

  • 自動保存の途中で止まり、手で保存できない・閉じられないことがあった（作業ファイルが大きいほど起きやすい）自動保存の途中でも手の保存を先にし、保存先の窓が返ってこないときは「待つ／前の保存をやめて続ける」を選べるようにし、自動保存そのものも軽くしました
  • 大きい作業ファイル・PSD（32MB を超える物）を開くのが遅い
  • 画面が固まって × を 2 回押して閉じたとき、裏に画面のプロセスが残ることがあった
  • アプリの中身が読めないとき・起動でつながらなかったときに、英語のページが出ることがあった（日本語の案内にし、自動でつなぎ直します）

ペン・ペンタブ

  • 「筆圧を直接読む（WinTab）」を入れると、ペン自体が反応しなくなることがあった（Wacom など）つなぎ方を変えました。効かないときは、環境設定 → ペン・入力 → タブレット の「WinTab のつなぎ方：探し直す」を押してください
  • WinTab が効いていれば、Windows Ink のペンにも WinTab の筆圧（と傾き）を使うようにしました（同じ所で切れます）
  • ペンのサイドボタン（液タブ・ペンタブ。Wacom・XP-Pen・Huion・GAOMON で確かめました）：離しても 3D が回り続ける／中クリックが効かない／ドラッグが少し動いて止まる／ペン先で描けず回転や平行移動になる／UV の区画で中が効かない止まらなくなったときは、Esc か、ペン先で 1 回タップで止まります
  • ペンで同じ所を塗り続けると、右クリックのメニューが出ることがある
  • メニューを開いたまま Ctrl＋＋／－やホイール（液タブのダイヤルも）を使うと、アプリの画面全体が拡大・縮小された（再起動まで戻らない）どの操作でも画面全体は拡大しないようにしました（環境設定の表示サイズはそのまま使えます）
  • 3D でうんと寄って細いペンで塗ると、線が途切れることがある

そのほか

  • Unity 式の Alt＋右ドラッグのズームの向きが Unity と逆だった（下へドラッグで寄るようにしました）
  • 投げ縄で塗るが、UV ビュー・2D キャンバスで塗られない・ほかのテクスチャセットの上で効かない
  • モザイク・シャープ・ハイパスなどが、透明の上に描いた線に効かない Standard Pro
  • 「UV の縁から塗る」で、縁からの始まりを 0 にしても島の端（パディング）が塗られなかった Pro
  • レイヤーを選ぶと、一覧の行がずれる・下の方のレイヤーが隠れる
  • 「ここに描いたレイヤーを選ぶ」が、休んでいるセット・見えていない所で正しく選ばない
  • 割り当て直したキーがメニューに正しく出ない・前の版で割り当てたキーと二重になる
  • 選択範囲が小さいと、移動・変形の「対称にも」が出ないことがあった
  • お問い合わせの窓で Enter を押すと閉じてしまう
  • 英語・韓国語・中国語の画面で、お問い合わせの窓の文の問いかけが日本語のままだった
  • ほかにも細かな不具合を直しました

v1.2.0

配布済み

2026-10-10

インストーラーと新しいペン、小窓と画面の回転、lilToon の設定を追加

いただいた要望をもとに、たくさんの機能を追加しました。とくに書いていない物は全版（Lite・Standard・Pro）で使えます。

大きな変更

インストーラーで入れられるようになりました

  • setup の zip を展開して、中の setup.exe をダブルクリックで入ります（管理者の権限は不要）
  • 次の更新からは、アプリの「インストールして再起動」でそのまま更新できます
  • Standard・Pro は、これまでどおり ZIP でも使えます

ご注意（前の版から更新する方へ）

  • 更新するときは、作業を保存してアプリを閉じてから、新しい setup を実行するか、新しい ZIP を展開してください
  • 書き味の既定が「筆圧だけで入り抜き」になりました前の書き味に戻すとき：環境設定 → ペン・入力 →「書き味」→「長さで入り抜き」
  • glTF・glb・VRM の UV の上下の扱いを直しました前の版の作業ファイルは、UV ビューの絵が上下逆に見えます（3D の見た目は同じです）
  • 自動保存の形が新しくなりました（v1.1.2 以前では、v1.2.0 の自動保存は読めません）
  • Standard を Pro にしている方は、v1.2.0 のアップグレードも入れ直してください

新機能

描く

  • ゆがみペン（押し出す・膨らませる・縮める・渦など。対称にも対応）
  • ドットペン（テクスチャの画素に合わせてくっきり塗る）
  • テクスチャをドットのまま表示（テクスチャセットごとに切り替え。256px 以下は最初から）
  • 投げ縄で塗る
  • 3D で塗ってもパディングまで塗れる（最大 128px・なめらか）
  • Ctrl＋ドラッグでブラシサイズ・硬さ・不透明度・先端の角度を変更
  • 柄の角度、D キーで描画色・背景色を黒・白に、Alt／Ctrl＋Backspace で塗りつぶし

選択範囲・レイヤー・マスク

  • 似た色をすべて選ぶ、選択範囲の移動・変形を対称でも
  • レイヤーを左右にミラーコピー
  • マスクのコピー・貼り付け・白黒で描く
  • 選んだレイヤーや UV マップを PNG で書き出し、書き出しの解像度を指定（512〜8192）
  • 透明な所を市松模様で表示、アルファ抜きの見え方
  • 表示のプリセット（オブジェクトの表示・非表示を名前を付けて覚える）

画面と操作

  • 3D と UV の片方を小窓に（パネルの上にも置けます）
  • 画面の回転（紙のように傾けて描けます）
  • 手のひらツール、Ctrl＋1・2・3 で決まった倍率
  • ツール一覧のパネル、定規の帯
  • ペンのボタン（中クリック・右クリック・戻る／進む）が Windows Ink・WinTab のどちらでも効くように
  • ヘルプ →「お問い合わせ」

フィルター・調整レイヤー Standard Pro

  • トーンカーブ・カラーバランス・色温度・自然な彩度・特定色の置き換え・露光量
  • 移動ぼかし・放射状ぼかし・ハイパス・ノイズを加える／減らす・モザイク・線画抽出・エンボス（PSD で行き来できるのは、トーンカーブ・カラーバランス・自然な彩度・露光量です）

Pro の追加 Pro

  • lilToon の設定を大幅に追加（光沢・ラメの形・異方性反射・AudioLink など。.mat の読み書きにも対応）
  • ノーマルマップの画像や、柄の質感（ニット・デニムなど）をレイヤーとして使える
  • トゥーン影・天使の輪のベイク、主線などのプリセット
  • フィルター →「UV の縁から塗る」
  • ポーズのプリセット、ブレンドシェイプのコピー・貼り付け、Unity の .anim の読み込み

改善と修正

使いやすさ

  • 描く・元に戻す・自動保存を軽く（大きなモデルで特に）
  • 髪の束など、同じ UV を使い回した所も 3D で塗れるように
  • 英語・韓国語・中国語の訳を追加

不具合修正

  • × で閉じられないことがある（固まったときは × を 2 回で閉じます）
  • スリープ明けに自動保存が止まり、保存できなくなることがある
  • 大きい作業ファイル（150MB ほどから）を開けない・自動保存から戻せない
  • UV ビューで寄って描くと線が薄くなる、3D の変形（Ctrl＋T）の枠が出ない・飛ぶ

お手軽ベイクと、描き込み前の仕上げ

肌・衣装・小物の仕上げを選べる「お手軽ベイク（Easy Bake）」を追加しました。光・つや・生地の表情を調整してから、すぐに描き込めます。面に沿う描画、グラデーション、v1.0.2 の書き出し改善も含まれます。

お手軽ベイク（Easy Bake） Pro

  • 12種類の仕上げプリセット：色白で健康的な肌、淡いイラスト調の肌、柔らかな布・サテン・デニム・革風の衣装、硬い素材の小物など。元のレイヤーを保ったまま、各効果を編集できるレイヤーとして作ります。
  • 血色を足す場所を指定：3Dビューで最大16点を置き、広がりや濃さを調整できます。仕上げ後は透明な「描き込み」レイヤーが選ばれ、すぐにブラシで描けます。
  • 新規作成から使える入口：下地色を選ぶ画面で「作成後にお手軽ベイクを開く」を選べます。対象セットを選び、プレビューしてから確定できます。
  • 4種類のベイクを追加：縁の光、つやのハイライト、布目・色むら、薄い部分の透け色。光とつやは指定した方向の色として焼き込み、視点を動かしても変わりません。透け色は閉じた形の薄い部分に色を足す機能です。
  • フィルターメニューを整理：区切り線の下に「お手軽ベイク」を配置し、個別の機能は「ベイク」の中にまとめました。

描く・消す・グラデーション

  • 3D の面に沿う塗り方を追加し、初期値にしました。斜めの面や輪郭付近で筆跡が伸びにくく、丸い先端のぼかしも折れ目で切れにくくなります。従来の「画面に合わせる」も選べます。
  • 透明色で描く機能を追加しました。色パネルの市松ボタン、または C で切り替え。ブラシの先端・硬さ・筆圧を活かして消せます。
  • 色と透明度のグラデーションを追加しました。最大32点で色・位置・不透明度を編集でき、透明入りを含む240種類のプリセットから選べます。3D・UV・2D キャンバスで使えます。
  • 輝度を透明度に変換をフィルターメニューに追加しました。白い部分を透明に、暗い部分を黒い影として残すので、AO の影だけを色替えしやすくなります。
  • 曲線定規の点を置いている間、Ctrl＋Z で最後の制御点を戻せるようにしました。点の取り消し中に、その前に描いた絵を消してしまうことを防ぎます。

形から陰影を作る Pro

  • 柔らかい陰影を焼く：面の向きと光の方向から、広い柔らかな影を作れます。光の左右・上下、影の範囲・柔らかさ・色・濃さを調整でき、プリセットも用意しました。
  • 上下・ポイントのグラデーションを焼く：面の向き、高さ、指定した点からの距離で色と透明度のグラデーションを作れます。中心はモデル上にも空間にも置けて、3D のつまみや XYZ 座標で移動できます。
  • くぼみとふくらみを強調：形のくぼみに影、ふくらみに明るい色を付けられます。「陰影のぼかし」で面のつながりに沿ってなめらかにし、UV の継ぎ目で白い線が出る問題も修正しました。
  • 柔らかい落ち影：光の方向から落ちる影を作れます。影を落とすセットと受けるセットを選べて、マテリアルの透明度にも対応します。

陰影は新しい透明レイヤーに焼き込みます。焼いたあとも、通常のレイヤーとして色・濃さを変えたり、消したり描き足したりできます。

スタンプ用キャンバスと、おまけの 2D ペイント

  • スタンプの「2D キャンバスで描く」を通常の UV ビューとレイヤーに統合しました。正方形の専用キャンバスで描き、合成した見た目をそのままスタンプに登録できます。
  • 起動画面の「サンプルで試す」の下から、3D モデルなしの 2D ペイントを始められます。レイヤー付きの保存・再開、PNG 書き出し、スタンプ登録に対応します。
  • スタンプ用キャンバスは作業ファイルにまとめて保存し、モデル用テクスチャの書き出しからは除外します。

操作と不具合の修正

  • 陰影などのプレビューを開いたまま終了すると、終了確認が操作できなくなる問題を修正しました。保存・終了・作業の切り替え前に、プレビューを確定するか取りやめるか選べます。
  • 前面の確認窓で Enter・Esc を押したとき、背後のプレビューまで確定・取り消しされる問題を修正しました。
  • プレビュー中の表示・描画色・保存などの操作を整理し、競合する操作は無効表示にしました。別のフィルターへの切り替えや処理失敗のあとに、仮レイヤーや操作制限が残る問題も修正しました。
  • 陰影のプリセットを選んだあと、選んだ名前が表示に残るよう修正しました。グラデーションのプリセットは重複をなくし、約3行のスクロール一覧に整理しました。
  • 2D ペイントの専用ボタンとファイルメニューで、同じ PNG 書き出し処理を使うよう修正しました。
  • ツール用の利用規約を公開し、すべての配布 ZIP に同梱しました。作成したテクスチャ・イラストの利用と、アプリの再配布について確認できます。
