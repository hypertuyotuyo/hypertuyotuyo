v1.2.0

v1.2.0 公開準備中

2026-10-10

インストーラーと新しいペン、小窓と画面の回転、lilToon の設定を追加

このページの v1.2.0 の内容は公開前の案内です。現在の配布版は v1.1.2 です。

  • インストーラー（全版）：Windows 用の setup を追加しました。管理者の権限は要らず（ユーザーごとに入ります）、スタートメニューに登録され、作業ファイル（.petanuri）をダブルクリックで開けるようにもできます。新しい版の setup を実行すると上書きで更新し、設定・作業ファイル・ブラシ・アップグレードはそのまま使えます。ZIP もしばらく一緒に配布します。
  • アプリからの更新（Windows）：新しいバージョンのお知らせから BOOTH のライブラリを開き、ダウンロードした setup をアプリが見つけると「インストールして再起動」で入れ替えられます（この版の次の更新から使えます）。
  • 書き味（全版）：入り抜きを筆圧だけで作る「筆圧だけで入り抜き」を既定にし、書き始めの玉・書き終わりの糸が出にくくなりました。前から使っている方には起動時に 1 回だけ案内が出ます。環境設定 → ペン・入力 →「書き味」で「長さで入り抜き」に戻せます。
  • 描く道具（全版）：ゆがみペン（押し出す・膨らませる・縮める・渦・元に戻す）と、テクスチャの画素に合わせてくっきり塗るドットペンを追加。表示 → 表示の形式 →「テクスチャをドットのまま表示（補間しない）」で、小さいテクスチャも縁がぼやけずに見えます。
  • 塗り方（全版）：投げ縄で塗る、透明色での塗りつぶし・ポリゴン塗り・図形・グラデーション、3D ビューで塗るときもパディングまで塗る設定（パディングは 128px まで・なめらかな広がり）、Ctrl＋ドラッグでブラシの値、模様・紙の質感の柄の角度、D キーで既定の色、Alt／Ctrl＋Backspace で塗りつぶし。
  • 選択範囲・レイヤー・マスク（全版）：似た色をすべて選ぶ、選択範囲の移動・変形を対称でも、レイヤーを左右にミラーコピー、マスクのコピー・貼り付け・ドラッグ、マスクを白黒で描く・見る、繰り返しの柄を描画色で塗り直す。
  • 書き出し（全版）：選んだレイヤーを PNG で書き出す（1 枚ずつ／重ねて 1 枚に）、UV マップを PNG で書き出す、書き出しの解像度（512〜8192）。PSD では、境界線の付いたレイヤーとクリッピングしたレイヤーを 1 枚にまとめずに書くようにしました（Standard・Pro）。
  • 表示と画面（全版）：3D・UV の片方を小窓に（パネルの上にも置け、鍵で固定）、3D ビューの画面の回転と UV ビューの好きな角度、3D ナビと UV のガイドのボタンの並び、手のひらツール、決まった倍率（Ctrl＋1・2・3）、最後に塗った所を中心に回す、ツール一覧のパネル、透明な所の市松模様とアルファ抜き、表示のプリセット。
  • 操作（全版）：Windows Ink でもペンのボタン（中クリック）で 3D を回せるようにしました。同じキーを何個かのサブツールで使う、定規の帯、描けないときに理由を表示、ヘルプ →「お問い合わせ（サポート・要望・バグ報告）」。
  • フィルター・調整レイヤー（Standard・Pro）：トーンカーブ・カラーバランス・色温度・自然な彩度・特定色の置き換え・露光量、移動ぼかし・放射状ぼかし・ハイパス・ノイズ・モザイク・線画抽出・エンボスを追加し、メニューを小メニューに整理しました。調整レイヤーのマスクを選択範囲から作れます。
  • lilToon とマテリアル（Pro）：リムライトの方向の影響度、輪郭線のハイライト、光沢設定とキューブマップ、ラメの形、マットキャップのカスタムノーマルマップ、グラデーションマップ、発光のグラデーション、異方性反射、ディザ、ディゾルブ、視差、AudioLink を追加し、.mat の読み込み・書き出しに対応しました。塗る先も増えました。
  • ノーマルマップ・ベイク・ポーズ（Pro）：ノーマルマップ画像のレイヤー、柄で質感を付ける、ノーマルマップの色で見る、トゥーン影・天使の輪・主線のプリセット、UV の縁から塗る、ポーズのプリセット、ブレンドシェイプの値のコピー・貼り付けと .anim の読み込み。
  • モデルと軽さ（全版）：glTF・glb・VRM の UV の向きを直し、マテリアルの無い FBX をオブジェクトごとのセットに分けて開きます。当たり判定・面に沿うブラシ・元に戻すを速くし、自動保存は速い形になりました。
  • 不具合の修正：× で閉じられなくなることがある問題（固まったときは × を 2 回）、スリープ明けに自動保存が止まる問題、UV ビューで寄って描くと線が薄くなる問題、マスクを黒で塗りつぶしても隠れない問題、3D の変形（Ctrl＋T）で枠が出ない・飛ぶ問題、ペン先にカーソルが残る問題などを直しました。

ご注意：前の版で保存した glTF・glb・VRM の作業ファイルを開くと、3D の見た目は前と同じで、UV ビューの絵は上下が入れ替わって見えます（書き出す PNG は元のモデルと同じ向きになります）。

ご注意：v1.2.0 の自動保存は新しい速い形で保存するため、v1.1.2 以前のぺたぬり3D ではレイヤーの絵を読めません。手で保存する作業ファイルは今までどおりの形です。

v1.1.2

最新

2026-10-07

レイヤーの整理と UV の塗る範囲、操作の設定を追加

  • レイヤーの色タグ（全版）：レイヤーとフォルダに 8 色の印を付けて整理。複数選択にもまとめて付き、一覧の上の「色で表示」でその色のレイヤーだけを表示します。作業ファイルに保存し、PSD の書き出し・読み込み（Standard・Pro）では Photoshop のレイヤーカラーと行き来します。
  • UV ビューの塗る範囲とパディング（全版）：左下で「UV内／パディング内／全体」を選択。ペン・筆・消しゴムに加え、図形・塗りつぶし・グラデーション・スタンプ・ぼかし・指先も従います。パディング（0〜32px・全部）は書き出しと同じ値で、パディング線を表示。フィルター「パディングを新規レイヤーに作る」も追加しました。
  • 繰り返しの柄（全版）：レイヤープロパティから、画像ファイル・参考画像・模様を上下左右に繰り返す柄としてレイヤーに敷けます。UV の継ぎ目に合わせることもできます。
  • カメラと表示（全版）：環境設定 → 操作 → カメラに「Unity 式」を追加。3D ビュー右上の透視／平行の ▼ で視野角を 5〜120° に変更でき、テクスチャを隠してメッシュの線だけを見る表示も追加しました。
  • UI の配色（全版）：環境設定 → インターフェイスで、画面・パネル・ボタン・文字・差し色・3D 背景・ツールバーの色を変更。ライトとダークそれぞれに保存し、初期の配色に戻せます。
  • ペンと操作（全版）：メニューやボタンをペンで押し込んでから離しても決定できます（ボタンの上の長押しの動きは環境設定で選択）。キーの長押しで一時的に切り替えるまでの時間（0.15〜2 秒）、キー割り当ての書き出し・読み込み、パネル配置の固定を追加しました。
  • 画面の改善（全版）：メニューのすぐ右に新規作成・開く・保存と元に戻す・やり直しのボタン。画面に入らない長いメニューは端で送れます。対称で描く間は対称線と反対側のカーソルを表示し、よく使うツールは 3D・UV で別々に表示できます。
  • レイヤーとセット（全版）：サムネイルの大きさ（小・中・大・特大）、ボタンの列を上に置く設定、複数のレイヤーのまとめてドラッグ、名前の文字のドラッグ選択。テクスチャセットのサブを外せるようにし、モデルの読み直しでテクスチャが変わったセットは下地を置き換えるかを聞きます。
  • 描き味と言語（全版）：図形の線の太さがブラシサイズと連動し、参考画像のスポイトのカーソルを見やすくしました。英語・韓国語・中国語の訳の抜けを埋め、同梱の使い方.txt に v1.1.2 の説明を追加しました。
  • 不具合の修正：ポリゴン塗り・3D の面で選択で離れた三角形が塗られることがある問題、英語・韓国語・中国語で書き出しの窓などの中身が表示されない問題、パディングの書き出しで継ぎ目に線が出ることがある問題、クリッピングのレイヤーで隣の島に色が入る問題、不透明度のつまみの表示が止まる問題などを直しました。

v1.1.1

配布済み

2026-10-05

描画と操作の選択肢を追加

  • 3D空間のグラデーション（全版）：通常のグラデーションツールでモデルの面や空間に点を置き、点からの距離で塗れます。移動ハンドル・XYZ座標・半径と色／透明度プリセットで調整し、選択中のレイヤーへプレビュー後に適用。元に戻す1回で戻せ、キャンセルは元の絵に戻ります。通常の空間グラデーションとProの点からのグラデーションベイクに、距離の輪・色と透明度の帯・数値表示を追加。白いつまみで広がる距離、色のつまみで各色の位置を動かすと、数値や色の編集にも反映されます。ガイドは表示を切り替えられ、ベイクの境界の位置・混ざる幅にも対応します。
  • 32pxからのテクスチャ（全版）：32／64／128／256pxを新規作成と解像度変更に追加。作業ファイルの保存・再開とPNG出力にも対応。最大解像度は版ごとの従来値です。
  • カラー補助スライダー（全版）：上のカラーフィールドと色相バーを保ったまま、下のRGB／HSVスライダーを切り替え。選択を次回起動にも保持します。
  • カメラ操作（全版）：右ボタン式・中ボタン式・Altボタン式を選べます。ペンのサイドボタンが中クリックを送る場合の視点操作も改善しました。
  • 隠した側への対称描画（全版）：対称の設定で有効にすると、3Dのペン・ブラシ・消しゴム・スタンプで、隠した対称側にも描けます。既定はOFF。UV描画と塗りつぶしは対象外です。
  • VRMの透明部分（全版）：VRM0／VRM1の元画像と透明設定・カットオフ・不透明度を保持。透明設定が異なるマテリアルは同じ画像でも別のセットとして扱います。
  • 外部ブラシ先端（全版）：ABR・GBR・GIH・画像・ZIPをサブツールへ登録。SUT内の読み取れるPNG画像も先端として読み込めます。元の設定・色・混色の完全再現ではありません。SUTは縮小画像や先端以外の素材を含む場合があります。
  • MToonプレビュー（Pro・β）：マテリアルの「表示と光」で切り替え、VRM0／VRM1の材質を見ながら描けます。作業ファイルへの保存とUndo／Redoに対応。UVアニメーションは静止表示で、MToon材質の完全な往復出力には対応していません。
  • 血色の左右対称（Pro）：お手軽ベイクの「血色を足す場所」に「左右対称に血色を足す」を追加。描画と同じX対称中心を使い、点を動かすと反対側も追従します。
  • レイヤー一覧の縦拡張（全版）：パネルを下へ広げたとき、一覧が一定の高さで止まる問題を修正。ドッキング・タブ・独立ウィンドウでも高さに追従します。
  • 描き味・操作・多言語の修正：入力途中の筆サイズの跳ねと斜め面での筆中心のずれ、ベイク中のAltカメラ操作、英語のサイズボタンと韓国語のベイクボタンの折返し、外部ブラシのエラー通知と対称中心の説明を改善しました。
  • 説明表示の整理（全版）：ベイク・グラデーション・ブラシ・カメラ設定などの長い説明を丸い「？」から確認できます。ホバー・クリック・タッチ・キーボードに対応し、点指定の現在状態や警告は画面に残します。

v1.1.0

配布済み

2026年10月4日

お手軽ベイクと、描き込み前の仕上げ

肌・衣装・小物の仕上げを選べる「お手軽ベイク（Easy Bake）」を追加しました。光・つや・生地の表情を調整してから、すぐに描き込めます。面に沿う描画、グラデーション、v1.0.2 の書き出し改善も含まれます。

お手軽ベイク（Easy Bake） Pro

  • 12種類の仕上げプリセット：色白で健康的な肌、淡いイラスト調の肌、柔らかな布・サテン・デニム・革風の衣装、硬い素材の小物など。元のレイヤーを保ったまま、各効果を編集できるレイヤーとして作ります。
  • 血色を足す場所を指定：3Dビューで最大16点を置き、広がりや濃さを調整できます。仕上げ後は透明な「描き込み」レイヤーが選ばれ、すぐにブラシで描けます。
  • 新規作成から使える入口：下地色を選ぶ画面で「作成後にお手軽ベイクを開く」を選べます。対象セットを選び、プレビューしてから確定できます。
  • 4種類のベイクを追加：縁の光、つやのハイライト、布目・色むら、薄い部分の透け色。光とつやは指定した方向の色として焼き込み、視点を動かしても変わりません。透け色は閉じた形の薄い部分に色を足す機能です。
  • フィルターメニューを整理：区切り線の下に「お手軽ベイク」を配置し、個別の機能は「ベイク」の中にまとめました。

描く・消す・グラデーション

  • 3D の面に沿う塗り方を追加し、初期値にしました。斜めの面や輪郭付近で筆跡が伸びにくく、丸い先端のぼかしも折れ目で切れにくくなります。従来の「画面に合わせる」も選べます。
  • 透明色で描く機能を追加しました。色パネルの市松ボタン、または C で切り替え。ブラシの先端・硬さ・筆圧を活かして消せます。
  • 色と透明度のグラデーションを追加しました。最大32点で色・位置・不透明度を編集でき、透明入りを含む240種類のプリセットから選べます。3D・UV・2D キャンバスで使えます。
  • 輝度を透明度に変換をフィルターメニューに追加しました。白い部分を透明に、暗い部分を黒い影として残すので、AO の影だけを色替えしやすくなります。
  • 曲線定規の点を置いている間、Ctrl＋Z で最後の制御点を戻せるようにしました。点の取り消し中に、その前に描いた絵を消してしまうことを防ぎます。

形から陰影を作る Pro

  • 柔らかい陰影を焼く：面の向きと光の方向から、広い柔らかな影を作れます。光の左右・上下、影の範囲・柔らかさ・色・濃さを調整でき、プリセットも用意しました。
  • 上下・ポイントのグラデーションを焼く：面の向き、高さ、指定した点からの距離で色と透明度のグラデーションを作れます。中心はモデル上にも空間にも置けて、3D のつまみや XYZ 座標で移動できます。
  • くぼみとふくらみを強調：形のくぼみに影、ふくらみに明るい色を付けられます。「陰影のぼかし」で面のつながりに沿ってなめらかにし、UV の継ぎ目で白い線が出る問題も修正しました。
  • 柔らかい落ち影：光の方向から落ちる影を作れます。影を落とすセットと受けるセットを選べて、マテリアルの透明度にも対応します。

陰影は新しい透明レイヤーに焼き込みます。焼いたあとも、通常のレイヤーとして色・濃さを変えたり、消したり描き足したりできます。

スタンプ用キャンバスと、おまけの 2D ペイント

  • スタンプの「2D キャンバスで描く」を通常の UV ビューとレイヤーに統合しました。正方形の専用キャンバスで描き、合成した見た目をそのままスタンプに登録できます。
  • 起動画面の「サンプルで試す」の下から、3D モデルなしの 2D ペイントを始められます。レイヤー付きの保存・再開、PNG 書き出し、スタンプ登録に対応します。
  • スタンプ用キャンバスは作業ファイルにまとめて保存し、モデル用テクスチャの書き出しからは除外します。

操作と不具合の修正

  • 陰影などのプレビューを開いたまま終了すると、終了確認が操作できなくなる問題を修正しました。保存・終了・作業の切り替え前に、プレビューを確定するか取りやめるか選べます。
  • 前面の確認窓で Enter・Esc を押したとき、背後のプレビューまで確定・取り消しされる問題を修正しました。
  • プレビュー中の表示・描画色・保存などの操作を整理し、競合する操作は無効表示にしました。別のフィルターへの切り替えや処理失敗のあとに、仮レイヤーや操作制限が残る問題も修正しました。
  • 陰影のプリセットを選んだあと、選んだ名前が表示に残るよう修正しました。グラデーションのプリセットは重複をなくし、約3行のスクロール一覧に整理しました。
  • 2D ペイントの専用ボタンとファイルメニューで、同じ PNG 書き出し処理を使うよう修正しました。
  • ツール用の利用規約を公開し、すべての配布 ZIP に同梱しました。作成したテクスチャ・イラストの利用と、アプリの再配布について確認できます。

v1.1.0 に統合

作成：2026年10月4日

書き出しの進み具合と、島の外へのにじみ

この版は単独では配布せず、改善内容を v1.1.0 に含めています。

  • PNG・PSD・AO・Unity 用ファイルなどの書き出し中に、ファイル名と進み具合を表示するようにしました。
  • 書き出し後、保存したファイルを選んだ状態でフォルダを開くようにしました。書き出しの窓からオフにできます。
  • にじみを「島の外を全部埋める」にしたとき、4096px のテクスチャでエラーが出て書き出せない問題と、島から離れた部分が透明のまま残る問題を修正しました。

v1.0.1

配布済み

2026年10月3日

テクスチャセットをまとめる・Unity 連携の改善

  • 新規作成時、同じ画像を使うマテリアルを1つのテクスチャセットにまとめられるようにしました。描いた絵はすべての対象に反映され、テクスチャは1枚で書き出せます。
  • 新規作成の「まとめる」から、テクスチャセットを手動でまとめる・分け直す操作を追加しました。
  • Unity 連携の窓に、アプリの場所、塗るメッシュとテクスチャ、起動・接続・保存の状態を表示するようにしました。必要なファイルが欠けている exe を選べてしまう問題も修正しました。
  • Lite で英語への切り替えが反映されない問題を修正しました。
  • アプリの更新案内から BOOTH の商品ページを開くようにしました。
