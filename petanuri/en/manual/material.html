Final look and lilToon materials Pro

Paint while previewing lilToon-equivalent shadows, matcaps, rim light, outlines and more; export materials with their settings. Features on this page require Pro.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

Lite, Standard, Pro, and the Pro upgrade are available on BOOTH.

Final look (lilToon appearance) is beta. Uses lilToon 2.3-series calculations but may look slightly different in Unity.

On this page

View Final look

  • Choose Final look with the rightmost of the four display-mode icons at the 3D top left (also right-click → Display).
  • Shows shadows (shadow colors 1/2 and border color), normal maps, matcap, matcap 2nd, rim light, backlight, rim shade, emission and outlines using lilToon 2.3-series calculations.
  • Set light direction through the display-mode ▼ or Material → Display and light. Light follows camera keeps illumination consistent as you rotate the view for easier painting.
  • Material panel names match lilToon's Inspector terminology. Copy to other materials applies the same settings to all.
MToon appearance preview (Pro, beta): select MToon in Material → Display and lighting. Paint using shadows, rim lighting, emission, and outlines imported from VRM0/VRM1 as a guide. Changes support Undo/Redo and are saved in the project.
This feature previews appearance while painting. Full MToon material round-trip export is not supported; PNG/PSD and existing lilToon material exports remain unchanged. UV animation is static, and unsupported UV settings show an explanation before returning to the normal display.

Paint shadow colors and masks (paint targets)

  1. Choose a paint target with the panel's Paint: buttons (also right-click → Paint target).
  2. A target folder (such as Shadow color 1) appears above Main color in Layers, selecting a layer inside. Add, delete, stack, mask and clip layers as usual.
  3. Paint using your regular pens, brushes, fill, gradients, blur and filters.
  4. Return to color at the top center (or select a layer outside the folder) returns to regular color painting.
Paint targetWhat it does
Shadow color 1 / Shadow color 2Shadows in painted areas take that color (redness in skin, blue hair shadows etc.)
Shadow maskWhite = shadows on; black = shadows off
Shadow AODarker makes shadows more likely (neck, inside hair, overlapping clothes)
Normal mapPaint height: white raises, black carves (wrinkles, seams and hair strands; the Bump tool works too)
Matcap mask / Outline widthWhite = enabled; black = disabled
Rim light color / Emission textureMultiplies by painted color / Only painted areas glow in the painted color
  • Also paint shadow color 3, shadow blur mask, color-correction mask, alpha mask, emission mask, emission 2nd, backlight color, rim-shade mask, outline color, normal-map 2nd mask and glitter color (right-click → Paint target → Other masks).
  • For targets that read only brightness, use White/Gray/Black at the top center. View this only shows just that target. Delete resets it to unpainted.
  • Final look supports up to 16 textures at once per material (“Cannot add any more” appears at the limit).

Main color 2nd / Main color 3rd

  • Enable Main color 2nd/3rd in Material to create matching folders at the top of Layers.
  • Only layers inside each folder form that Main color 2nd/3rd texture (not mixed into the main artwork). Set color, opacity, blend mode and mask in the panel.
  • Exports separate images (<Name>_main2nd.png etc.), assigned to lilToon's Main color 2nd/3rd material slots.

Separate materials

  • Initially each texture set has one material with the same name. Nothing changes unless you separate them.
  • Keep shared textures/artwork while changing shadow colors, matcaps, rim light, outlines and other settings per object (such as red shadows only on animal ears sharing a hair texture).
  • Right-click an object row or the object in 3D → Give this object a separate material. Assign material chooses which material to use.
  • The top Material list supports add, rename, delete and reorder (order determines overlap priority). Touching the model switches to its material; the bottom status bar shows Material: name (texture set name).
  • Exports one .mat per material, referring to shared textures.

Load lilToon material

  • File → Import → Import lilToon material: choose .mat or a .unitypackage containing it (also drag/drop). Also selectable as the starting source for a new project.
  • Imports render mode, shadows, normal maps, matcaps, rim light, emission, outlines, Main color 2nd/3rd and textures (main color → Base; shadow colors/masks → paint targets).
  • Searches for textures in the project around the .mat. Missing textures are listed so you can select images.
  • Settings PetaNuri3D does not preview (specular, fur, stencil etc.) retain their values and are restored unchanged on export.
  • Export keeps the original .mat's location and ID, updating only changed settings and repainted textures.

Export materials

  1. Choose File → Export → Export materials (also Export in the panel).
  2. Choose materials, folder name and padding.
  3. Export .unitypackage or write directly to a folder (the project's Assets). Double-click or drag the .unitypackage to import into your project.
  • Includes .mat files plus main-color, shadow-color, mask, normal-map and matcap images, already assigned.
  • Exporting the same project again with the same folder name overwrites previously imported assets, preserving model assignments.
These materials require lilToon. Install lilToon in the receiving project first (otherwise materials appear pink).
