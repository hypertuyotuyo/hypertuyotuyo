Layer

Layers stack separately for each texture set. Paint in layers just like a 2D illustration.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

Layer basics

  • Switch texture sets in the top panel header (when there are 2 or more; resolution appears at right).
  • Below are blend mode, opacity, clipping, transparency lock and lock icons (click to toggle; colored means enabled).
  • Bottom icon buttons: Add, Folder, Adjustment, Duplicate, Delete, Merge, Mask, Move up, Move down, More (hover for names and current keys).
  • The bottom Base layer contains the color/image chosen at creation. Paint directly on it too.
  • 26 blend modes (Normal, Multiply, Screen, Overlay, Add, Soft light, Hard light, Hue, Color, Luminosity and more).
  • Multiple selection: Click names with Ctrl to select individual layers, or Shift to select a range. Visibility, blend mode, opacity, clipping, protection, lock, delete, duplicate, grouping and merge apply together (one Undo).
  • Select with keys only: Alt＋] (layer above), Alt＋[ (layer below). In 3D, right-click → Select layer painted here selects a layer with artwork at the clicked point.
  • Drag layer rows directly with a pen to reorder. Scroll the list with Space + drag.
Lite allows up to 4 layers including the base, per texture set (paint/adjustment layers count; folders/masks do not). At 4 layers, the panel shows Layers 4 / 4 (including base, Lite), and Add/Duplicate show locks. Standard and above allow unlimited layers.

Folders and layer masks

  • Folder: Create with the Folder button (Ctrl＋G).Shift + button (Ctrl＋Shift＋G) groups selected layers into a folder. Drag a row to a folder's center to place it inside. Modes other than the default Pass through first composite contents into one image.
  • Layer mask: Mask button → Add show-all/hide-all mask (also from a selection). Click the mask thumbnail to paint it (paint reveals; eraser hides).
  • Shift + mask thumbnail toggles enabled/disabled. Also show mask area, invert, apply (rasterize) or delete.

Layer properties

A panel gathering settings for the selected layer (just above Layers in the default layout).

  • The header shows type (paint layer, folder, text layer, adjustment layer, paint-target folder etc.) and name.
  • Adjustment layer: value controls. While dragging a slider only the image changes; releasing creates one Undo step.
  • Raster layers, folders and text layers: Stroke visibility, Add and Settings.
  • Text layers show Edit text; masked layers show mask status.
  • Change blend mode, opacity, clipping, transparency lock and lock in the Layers panel.

Stroke (layer outline) Standard

Adds an outline during compositing without changing the layer artwork. Adjust width/color or turn it off later.

  • Open via layer right-click → Stroke, Layer menu → Stroke, or Add/Settings in Layer properties. Layers with strokes show fx; clicking it opens the same dialog.
  • Settings: Size (width in texture px), Position (outside/inside/center), Blend, Opacity, Color. Changes preview immediately; OK (Enter) applies, Cancel (Esc) restores.
  • Follows the shape after masking. Clipped layers stay within their base's painted area. Available on folders/text layers too.
  • Right-click → Stroke: toggle visibility, copy, paste (to all selected layers), clear, rasterize.
  • Saving: project files preserve settings. PNG/material exports include the stroke; PSD writes it into rasterized layers.
Strokes are calculated in UV, so those extending past island edges may appear cut off at those edges in 3D.
Adding/editing strokes requires Standard or above. Lite preserves strokes in opened projects and can show/hide, copy, clear or rasterize them.

Adjustment layers and filters Standard

  • Adjustment layers: Adjustment button → Hue/saturation/lightness, Brightness/contrast, Levels, Invert, Grayscale, Posterize, Threshold, Gradation map. Corrects without rewriting artwork below. Edit in Layer properties; restrict with masks or clip to the layer directly beneath.
  • Filters (Filter menu): Hue/saturation/lightness, Brightness/contrast, Levels, Posterize, Threshold, Gradation map, Gaussian blur, Sharpen (unsharp mask), Invert, Grayscale. Applies to the selected layer (Apply to all visible texture sets also available).
  • Filter values preview immediately on the model; OK (Enter) applies, Cancel (Esc) restores. You can move the view while the dialog stays open.
  • Blur/sharpen calculate within each UV island, keeping island edges from darkening.

Convert luminance to opacity

Filter → Convert luminance to opacity is available in Lite and above. Turns white backgrounds transparent and retains dark areas as black shadows. Useful for recoloring only AO shadows.

  1. Select a paint layer other than Base, such as AO. Disable lock and transparency lock if enabled.
  2. Run Convert luminance to opacity. White becomes transparent; darker areas become more opaque black.
  3. To recolor shadows, enable transparency lock after converting, then paint any color. Shadow intensity remains as opacity.
This filter converts the selected layer's pixels; it is not an adjustment layer. Unavailable for Base, masks and adjustment layers. It does not retain original colors while making them transparent.Ctrl＋Z undoes it.

Gradation map Standard

  • Maps dark → light areas to colors from the gradient's left → right. Available as both a filter and adjustment layer.
  • Up to 32 color stops: click the bar to add, drag to move, pull downward to delete, double-click for color. Per-stop opacity, distribute evenly and reverse are available.
  • 240 presets (blue, red, sunset, rainbow, pastel, neon, metal, skin, seasons, photo grading, anime coloring and more). Search by name. Save current adds your gradient to My presets.
  • Project files and PSDs preserve color stops.

Drawing tools and bakes use the same color/opacity editor and presets. Drawing is available in Lite and above; baking requires Pro (drawing tool's gradient／Baked gradients).

Auto fill (base colors from line art)

  1. Open Layer → Auto fill and click Create hint layer.
  2. Roughly place each desired color on the hint layer where it belongs.
  3. Click Run to create a layer just below the line art, filling each enclosed area with its hint color (including beneath lines).
Close your lines on visible faces. Gaps let color leak. Paint across UV seams fills continuously even when front/back body areas are separate islands.

History and Undo

  • History on the right lists past operations. Click a row to jump backward/forward to the state after that operation.
  • Undo Ctrl＋Z / Redo Ctrl＋Y(Ctrl＋Shift＋Z). Up to 30 steps are recorded.
  • Operations changing artwork (layers, masks, paint targets, material settings) can be undone. Display-only changes (visible area, object visibility, blend shapes, view, display mode etc.) and app settings are excluded.
  • Changing resolution clears all Undo history (confirmation is shown first).

Unload layers (save memory)

  • To support many 4096 layers, inactive layers are stored compactly between strokes to save GPU memory. Appearance, exports and saving remain unchanged.
  • Selecting/drawing on an unloaded layer restores it immediately. Loading many layers shows Preparing… before switching.
  • Disable under File → Preferences → Drawing → Performance (on by default).
