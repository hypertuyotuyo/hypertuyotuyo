PetaNuri3D / Manual / Export

Export

Turns the textures you painted into images (PNG, PSD) to use in Unity and elsewhere. Saving a project file (.petanuri) is for continuing to paint later. It does not produce an image to apply to the model. "Export" is what makes images.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

Start with this
  1. Choose File → Export → Export PNG (all sets) to export every texture as a PNG at once (Details).
  2. You can leave "Padding" in the window at the default 8 px. Increase it if you see lines at seams in the game (Details).
  3. If you export to the same folder over and over, turn on "Export to this folder without asking each time" (Details).
  4. To hand it over with the layers kept separate, export a PSD Standard (Details).

Export as PNG

Turns the picture of each texture set into one PNG per set. This is the image you apply to the model in Unity and so on.

  1. Choose File → Export → Export PNG (all sets). To export just one set, choose "Export PNG (selected set)" instead.
  2. In the export window, check "Resolution", "Padding" and "Destination", then click "Export".
  3. If you are asked where to save, choose a folder. For all sets, you choose the folder only once.
  4. A message "Exported (name)" appears, and the folder you exported to opens in Explorer.

Files that are exported

File nameWhat it is
<set name>.pngThe picture made by stacking the visible layers. The set name is the material name
<set name>_main2nd.png, <set name>_main3rd.png ProFor sets that have a Main color 2nd/3rd folder. If you painted their masks, files ending in _mask are exported too (Main color 2nd and 3rd)
<set name>_normal.png ProFor sets that have a normal map folder as a paint target (Paint targets)
  • Sets that would get the same name are told apart with _2, _3 and so on.
  • Sets whose display is turned off are included in "all sets". Orphaned sets (!) are not. When you need one, export it with "Export PNG (no bleed outside islands)" in the right-click menu on its row (Orphaned sets).
  • Effects such as Stroke are exported with the effects applied. Light, shadow and material look baked with Easy Bake and so on are also included, as colors of the visible layers.
  • Textures are exported as they are, even if you have hidden things with the visible area or objects.
  • You can also export a set with "Export as PNG" in the right-click menu on its row in the Texture sets panel.

Export at a different size

With "Resolution" in the export window, you can export at a size different from the texture set's resolution. Choose from "Unchanged (texture set resolution)", 512×512, 1024×1024, 2048×2048, 4096×4096 and 8192×8192.

  • Bleed is added at the set's resolution first, and then the image is scaled down or up.
  • This applies to PNG (selected set and all sets), selected layers, UV map and material exports. It does not apply to PSD (always the set's resolution).
  • To change the resolution you paint at, use the Texture sets panel (Change the resolution).

If it doesn't work

  • Lines appear at UV seams in the game: The bleed is not wide enough. Increase it beyond 8 px and export again (Bleed).
  • "Can't export while (name) is shown" appears: A transform frame, a filter preview or similar is open. Confirm (Enter) or cancel (Esc) first, then export.
  • "Another read/write operation is in progress" appears: Saving, Autosave or loading is in progress. Wait until it finishes, then try again.
  • "Display processing has stopped, so it can't export" appears: Reopen your project file or an autosave, then export (Memory savings).
  • "No texture set can be exported as PNG" appears: The set you have selected is an orphaned set (!). Select another set, or move its layers, and then export.
  • It says "Export canceled" when I click: You clicked Cancel in the export window or the save window. Values you changed in the window go back as they were.

Export only the selected layers as PNG

Exports only some layers, such as just the line art or just a pattern, as a PNG with a transparent background.

  1. In the Layers panel, select the layers to export (Ctrl/Shift+click to select as many as you like).
  2. Choose File → Export → Export as PNG (selected layers). You can also use "Export selected layers as PNG" or "Export this layer as PNG" in a layer's right-click menu.
  3. For two or more layers, choose "One by one (a file per layer)" or "Combine into one image" under "Selected layers" in the window, then click "Export".
ChoiceFile name
One by one<set name>_<layer name>.png
Combine into one image<set name>_layers.png (stacked in the panel's order, using each blend mode)
  • The background is transparent. Because the picture contains only what you painted, no bleed is added.
  • It remembers your previous choice.
  • It is not available in 2D painting. Export with "Export PNG (selected set)" instead (Details).

Export the UV map as PNG

Exports the UV lines as a PNG. Use it as a base sketch to overlay when you paint in another paint app.

  1. Select the texture set you want to export.
  2. Choose File → Export → Export UV map as PNG (selected set). It is also in the right-click menu on the texture set row.
  3. Choose the options below in the window and click "Export". <set name>_uv.png is created.
SettingChoices
ResolutionUnchanged (texture set resolution), 512 to 8192

BackgroundTransparent, black, white (if transparent, you can overlay it on a picture in other software)

DestinationSame as other exports (Details)
  • A 2D canvas has no UV, so it cannot be exported. Choose a texture set of a 3D model.
  • To just look at the UV lines inside PetaNuri3D, use "UV lines" in the UV pane (Show UV and paint directly).

Export/import PSD Standard

Exports a PSD with the layers kept separate. Use it to keep painting in another paint app, or to hand out as an editable PSD.

  1. Choose File → Export → Export PSD (selected set) or Export PSD (all sets).
  2. In the export window, check the padding and destination, then click "Export".
  3. <set name>.psd is created. When it finishes, the size and the number of layers are shown.

What goes into the PSD

  • Layers, visibility, opacity, blend modes, clipping, Lock transparency, folders, layer masks and color tags (layer colors) are kept.
  • Adjustment layers go in as adjustment layers (a Gradation map keeps its color stops). The "Colorize" option of Hue/Saturation/Lightness is not included.
  • Solid color layers also go in as solid color layers (the color value, mask, blend mode, opacity, and clipping are kept).
  • Stroke is written as a layer baked into pixels. Text layers become ordinary layers.
  • A base layer that has only Stroke, Drop shadow or Outer glow, and clipped layers, are written separately as they are. A layer named "(layer name)（効果）" (the Japanese word for "effects") is added above, with only the effects baked in. When there is a fill opacity, an inner effect or the like, everything is merged into one layer.
  • Pro The folders for paint targets, Normal map and Main color 2nd/3rd are written as hidden groups. They are restored when you import into PetaNuri3D.
  • The composite image (the flat picture you get without opening the PSD) gets bleed. The layers themselves stay as you painted them.
Adjustment-layer calculations may look slightly different in other apps.

Import a PSD

You can import the editable PSD that comes with an avatar and keep painting from it. When you import it, the layers of that set are replaced with the contents of the PSD.

  1. Choose File → Import → Import PSD (replace layers).
  2. Choose the PSD. It goes into the set whose name matches the file name (body.psd → body). If no set matches, it goes into the selected set.
  • You can also drop a PSD onto the window. If you drop it on a texture set row, it goes into that set (Add images or PSDs).
  • If the size is different, it is scaled to the set's resolution. Folders, masks and supported adjustment layers stay as they are.
  • Blend modes that do not match become "Normal", unsupported adjustment layers are skipped, and a notice appears at the bottom right.
  • Solid color layers are read as solid color layers. Shapes (with a vector mask), text, gradients, patterns, and solid color layers with layer effects are read as image layers.
  • One Undo (Ctrl+Z) brings it back.
  • When you create a new project, you can also set the starting point (Base) to "PSD" and import it (Open a 3D model).

Export bleed (padding)

Spreads the edge colors outward beyond the UV islands when exporting. Without it, lines may show at UV seams in the game when the texture is scaled down or mipmaps are applied.

  1. In the export window, choose the width to spread under "Padding".
  2. Click "Export".
ValueWhat it does
None (don't extend outside islands)Does not spread outside the islands (if a base is visible, you get the base color)
4, 8 (default), 16, 32, 64, 128 pxSpreads color outward from the island edges by that width
Fill everything outside islandsFills everything outside the islands with the color of the nearest island
  • It applies to PNGs, the composite image of a PSD, and the images from a material export (Main color, shadow color, masks, normal map and all the rest). The layers inside a PSD are not spread.
  • It is not added to PNGs of selected layers or to UV maps.
  • The value is the same as "Padding" at the bottom left of the UV pane. Changing either one changes both. Values you set in 1 px steps in the UV pane also appear in the window (Paint area and padding).
  • A pixel outside an island takes the color of the nearest island pixel, measured in a straight line. Diagonal edges spread smoothly, without stair-steps.
  • The thin, faint edge of a brush stroke is not counted as painted. The color of the opaque areas is spread first, and then the faint areas are laid on top. This makes lines in the base color less likely to appear at seams.
  • The image sent by the Unity link is spread the same way as an exported PNG (Paint from Unity).
Before you export, turn on "Padding line" in the UV pane to see how far the color will spread. If you also want to paint by hand outside the islands, set the paint area to "In padding" (Details).

Export folder

Use "Destination" in the export window to export to the same folder every time. It is handy to choose something like the Textures folder of your Unity project.

  1. In the export window, choose a folder with "Select folder".
  2. Turn on "Export to this folder without asking each time (overwrites files with the same name)".
  3. From then on, PNG, PSD, AO and .unitypackage exports are written to that folder without asking where to save.
  • "Remove" goes back to being asked where to save every time you export.
  • Even when you have not chosen a folder, the save window opens at the folder you last exported to.
  • "Open the folder after exporting" is on from the start. When writing finishes, the folder opens in Explorer. Turn it off if you do not need that.
  • While exporting, "Exporting…" is shown and you cannot do anything else until it finishes.
  • For exporting materials to a folder (choose Assets), the window opens at the Assets folder you chose last time.
  • If you cancel in the window, the values you changed in it (padding, destination and so on) go back as they were.
When "Export to this folder without asking each time" is on, files with the same name are overwritten without a check.

Export a 2D painting

A 2D painting, which uses no model, can also be exported as a PNG or PSD.

  • Click "Export PNG" in the bar below the canvas to make 2D-paint.png. File → Export → Export PNG (selected set) does the same.
  • Standard To hand it over with the layers kept, choose File → Export → Export PSD (selected set) to make 2D-paint.psd.
  • Exporting all sets or selected layers is for the texture sets of 3D models. It is not available in 2D painting.
  • You can also save a project file (2D painting without a model).
A picture drawn on the 2D canvas for stamps is not included in the model's exports. Use "Register as stamp" to turn it into a stamp (2D canvas for stamps).

Export lilToon materials and AO Pro

  • Export lilToon materials together with their textures using File → Export → Export materials (.unitypackage / folder). The window also has padding and destination fields (Export materials).
  • Export a baked AO as <set name>_AO.png with Filters → Bake → Export AO as PNG (last bake result) (Bake AO).
