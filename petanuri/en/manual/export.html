Export

Export finished textures as images or materials through File → Export.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

On this page
  • Export as PNG
  • Export/import PSD
  • Export bleed (padding)
  • Export folder
  • Export materials

Export as PNG

  1. Choose File → Export → Export PNG.
  2. Choose padding and destination in the small dialog, then click Export.
  3. Export the selected set or all sets. Filenames are <material name>.png.
Sets with Main color 2nd/3rd folders export separate PNGs. Strokes and other effects are included in the image.
Baked light, shadows and surface appearance become visible layer colors in PNG. Stamp working sets are excluded from model texture exports. In model-free 2D painting, save PNG using Export PNG below the canvas.

Export/import PSD Standard

  • File → Export → Export PSD preserves layers, visibility, opacity, blend modes, clipping, transparency lock, folders, layer masks and adjustment layers (gradation maps retain color stops).
  • Strokes are written as layers with the effect rasterized. Text layers become regular layers. Paint-target, normal-map and Main color 2nd/3rd folders are written as hidden groups (restored on import).
  • Drop a PSD onto the window to import into the material matching its filename. Also import from a Texture sets panel row.
  • Import an avatar's customization PSD to continue painting.
Adjustment-layer calculations may look slightly different in other apps.

Export bleed (padding)

Expands edge colors outside UV islands during export. Without padding, downscaling/mipmaps may reveal lines at UV seams.

  • Choose None, 4, 8 (default), 16, 32 px or Fill all space outside islands (in export/material-export dialogs).
  • Affects PNG, PSD composite images and material textures. Individual PSD layers remain as painted.

In v1.1.0, All fills the entire margin even for 4096px images.

The padding value is shared with the lower left of the UV pane. Faint brush edges no longer count as painted: opaque colors are spread outside islands first, then faint edges are layered on top, so seams are less likely to show base-color lines. Create padding on a new layer uses the same rule.
Textures sent through the Blender and Unity links still use the previous padding rules; this will be aligned in the next version.

Export folder

  • The save-location dialog opens in the last export folder.
  • Set a folder with Choose folder in the export dialog, then enable “Always export to this folder without asking” to send PNG, PSD, AO and .unitypackage exports there without prompting. Clear removes the fixed destination and restores prompting.
  • Material folder exports (choose Assets) open at the last selected Assets folder.
When exporting without asking, files with the same names are overwritten.

Open folder after export is enabled by default. Inspect completed images in Explorer; uncheck if unwanted. After choosing a destination, Exporting… and progress are shown.
