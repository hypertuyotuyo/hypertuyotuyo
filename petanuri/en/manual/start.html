Getting started

This page covers installing and launching PetaNuri3D, opening a 3D model and saving your work. It also covers the differences between editions (Lite, Standard and Pro) and updating to a new version.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

Start with this
  1. Extract the whole ZIP, then either install with setup.exe in the "PetaNuri3D" folder or run PetaNuri3D-win_x64.exe directly (details).
  2. If this is your first time, you can open a practice model with "Try the sample" on the startup screen (details).
  3. To use your own model, choose it with "New", then pick a resolution and a starting point for each texture set (details).
  4. After painting, press Ctrl+S to save to a project file (.petanuri). Autosave also runs every 5 minutes (details).
  5. To turn your painting into texture images, use "Export" (Export).

System requirements

PetaNuri3D runs on a Windows PC. If your PC can run VRChat, it will usually run PetaNuri3D too.

ItemRequiredRecommended (guideline)
OSWindows 11 (64-bit)—
GPUWebGL2 support (an NVIDIA, AMD or Intel GPU from the last few years, with the latest driver)GPU memory: 4 GB or more to paint at 2048, 8 GB or more at 4096
OtherMicrosoft Edge WebView2 Runtime (included with Windows 11)16 GB or more of PC memory
  • PetaNuri3D also runs on Windows 10, but it isn't supported.
  • The current GPU memory estimate appears above the Texture sets panel.

If it doesn't work

  • It's slow, or you can't paint: Your GPU is running out of memory. Lower the texture resolution, or close other apps such as your browser and games (Memory savings).

Install and launch

First, extract the whole ZIP you downloaded from BOOTH (PetaNuri3D-<edition>-v<version>.zip). The "PetaNuri3D" folder contains the app and setup.exe. There are two ways to use it.

Install with setup.exe (recommended)

  1. Double-click setup.exe in the "PetaNuri3D" folder.
  2. Choose where to install, whether to add a desktop icon, and whether double-clicking a project file (.petanuri) opens it. You don't need administrator rights (it installs for your user only).
  3. Launch it from the Start menu (or the desktop).
setup.exe installs the app from the same folder. Don't take setup.exe out on its own; use the whole folder. It installs to %LOCALAPPDATA%\Programs\PetaNuri3D.

Launch without installing

  1. Put the "PetaNuri3D" folder anywhere you like.
  2. Double-click PetaNuri3D-win_x64.exe in the folder.
The app also uses resources.neu, mcp, tools and unity next to the exe. When you move it, move the whole folder. Extract a new version into a new folder.

After launching

You're ready when "New", "Open project file" and "Try the sample" appear in the middle. You can also open recent files and autosaves from here.

  • You can also start by dropping a 3D model (FBX etc.) or a project file (.petanuri) onto the entrance in the middle of the startup screen. A 3D model goes on to the New screen; a project file opens right away.
  • Your settings (sub tools, key bindings, window layout, color sets, reference images and so on) are saved in %APPDATA%\PetaNuri3D and come back the next time you launch.
  • To remove the app, uninstall "PetaNuri3D" in Windows "Settings → Apps → Installed apps". Your settings and project files aren't deleted.

If it doesn't work

  • "Windows protected your PC" appears: Click "More info", then "Run anyway". The app isn't code-signed, so this can appear the first time.
  • Unity link stops working after you moved the app: Select the exe location again, once, in the Unity add-on, which remembers where the exe is (Paint from Unity).

Tutorial and sample model

The first time you launch, a guided tour (tutorial) appears. You follow it by actually touching the highlighted spots.

  • Use ← → to go back and forward. To quit, choose "Skip" or press Esc.
  • When no model is open, you can choose "Try with the sample model" or "With my own model (open later)". With the sample, you can try rotating, drawing, symmetry and UV in turn.
  • To see it again, choose Help → "Tutorial (guided tour)". You can also turn it on with File → Preferences → System, "Show the tutorial on next startup".

The sample model "Shinobu"

Open it with "Try the sample" on the startup screen. It's available in every edition. It's in an A-pose and has 7 texture sets, and each set's base contains an image of the original colors.

You may use the sample model only to try PetaNuri3D. Don't use it for any other purpose, and don't extract it or give it to others.

If you're new, we recommend painting the sample once all the way through in First steps. To draw without a model, start from "Start a 2D painting" on the startup screen (2D painting).

Open a 3D model (New)

Open your own 3D model and get ready to paint. You can open FBX, glTF (packed into a single file), GLB, VRM, OBJ and DAE.

  1. Click "New" on the startup screen, or choose File → New (Ctrl+N), then pick a 3D model.
  2. The texture sets, one for each material, are listed. Choose a Resolution for each set (32 to 4096 px; Lite goes up to 2048).
  3. Choose what each set will Start with (the base). You can mix different starting points.
  4. Click "Create" and the model appears in the 3D view. To cancel, click "Cancel" or press Esc.

Types of starting point (Base)

Start withWhat it does
ColorStarts with the base filled in one color. The default is white. "Model color" uses the material's color instead.
ImageUses a PNG, JPEG or similar image as the base.
PSD StandardImports the PSD layers as they are.
lilToon material ProImports settings, textures and masks from a .mat, or from a .unitypackage that contains one (Load a lilToon material).
  • If the images the model uses are next to the model (in the same folder or a Texture folder) or inside the model, they're found automatically and the set starts with "Image".
  • With "Bulk" at the top, you can set the same resolution for all sets, start all sets with a white base, or choose images and PSDs in one go. A file named the same as a set (body.psd → body) goes into that set. Dropping images, PSDs or .mat files onto this screen sorts them out the same way.
  • Materials that use the same image are combined into one texture set. (Use "Merge ▾" on a row to merge or separate them by hand.) When they're merged, you paint on one texture and it shows on all the materials.
  • Pro Turn on "Open Easy Bake after creation" and choose the target sets, and the Easy Bake window opens once the model loads. You can make an undercoat for skin and clothes before painting in detail (Easy Bake).

If it doesn't work

  • Dropping a model on the window doesn't open it: Once a model is open, dropping another one does nothing. Open it with File → New or File → Reload model.
  • A message says a texture wasn't found: Choose the image with "Choose <name>" on the row.
  • Some areas can't be painted: If the model has areas you can't paint, such as faces without UVs, a notice appears at the lower right when you open it. Areas whose UVs are outside the 0 to 1 range are painted at the position where the texture repeats to the same color.

Save and resume

Your work is saved to a project file (.petanuri). The model and all layers and settings go into one file. Making texture images (PNG, PSD) is a separate step: "Export".

To do thisDo this
SaveFile → Save project file (Ctrl+S)
Save under another nameFile → Save as (Ctrl+Shift+S)
Open your work to continueFile → Open project file (Ctrl+O). You can also drop the file onto the window
Open recent workFile → Recent files
Recover after a crashFile → Open from autosave (the newest 3 for each project)
Hand it over without the modelFile → Save without model (FBX) (when it's opened, you choose your own copy of the model)
  • An asterisk (*) in the title means there are unsaved changes. If you close with unsaved changes, you're asked "Save and quit", "Quit without saving" or "Cancel".
  • Autosave runs every 5 minutes.
  • You can also create, open, save, undo and redo from the icons at the right end of the menu bar.

Save in the fast format

Autosave uses a "fast format" that doesn't write the transparent areas of layers. If you have many layers with only lines, saving is much faster. Project files you save by hand use the same format if you turn on "Save project files in the fast format (opens in v1.2.0 or later)" in File → Preferences → Painting → Performance.

If it doesn't work

  • The app crashed or froze: Click × again to quit (unsaved changes are lost). Reopen the app and use File → Open from autosave to open the latest autosave.
  • "The app's internal file access has stopped" appears: This can happen after the PC wakes from sleep. Quit, reopen the app and recover your work with File → Open from autosave.
  • A file opened with "(incomplete)" added to its name: Part of that project file couldn't be read. To avoid overwriting the original file, saving becomes "Save as".
  • The save dialog doesn't come back: Check whether the dialog for choosing where to save is hidden behind another window. If it lasts longer than 30 seconds, click × or press Ctrl+S to choose "Wait" or "Stop the previous save and continue".
  • A confirmation appeared when you saved during a preview: While previewing a transform, filter or similar, you're first asked "Apply and continue", "Discard preview and continue" or "Cancel".

Reload the model

When you've fixed a 3D model (FBX etc.), this keeps your painting and updates only the shape.

  1. Choose File → Reload model (keep painting).
  2. Click "Reload the same file" or "Choose file".
  3. Texture sets are matched by material name. Sets with the same name keep their layers and settings as they are.

Questions asked when reloading

When this happensThe prompt and your choices
A set's UV changed"Update and fit painting" = moves your painting to the new UV positions / "Update without fitting" = leaves the painting at the old UV positions / "Cancel update" = stops the reload
New materials were addedThe same screen as New appears, with rows for the new sets only. Choose a resolution and a starting point, then click "Reload"
The model's texture (image) changedFor each set, it asks "Replace the base with the new texture?" If you replace it, anything you painted directly on the base is replaced too
A material is missing from the new modelThat set isn't deleted; it stays with a ! mark. Click it to move its layers to another set (Orphaned sets)
You can undo a reload with one Ctrl+Z (when the previous model's contents are still available). However, the history of operations from before the reload is cleared.

Editions (Lite, Standard, Pro)

PetaNuri3D comes in three editions. You can see your current edition in the window title, on the badge on the startup screen, and in Help → "About PetaNuri3D". In this manual, features available in Standard and above are marked with Standard, and Pro-only features with Pro. Features without a badge work from Lite.

CompareLite (free)StandardPro
Drawing, painting, erasing, blending colors, fill, symmetry, UV, selections, transforms, text, rulers, auto fill, PNG export, saving project files, 2D painting, converting luminance to opacity, painting from Unity✓✓✓
Layers (per texture set, including the base)Up to 4UnlimitedUnlimited
ResolutionUp to 2048Up to 4096Up to 4096
PSD import and export—✓✓
Filters, adjustment layers, strokes—✓✓
Exporting and importing brush settings (.petabrush)—✓✓
Poses, blend shapes, vertex groups——✓
Final look (how lilToon and MToon appear), material settings, paint target, Main color 2nd/3rd, loading and exporting lilToon materials——✓
Easy Bake, baking shading and the like, Bake AO, Paint from UV edges——✓
AI integration run_js (a command that runs a program inside the app)——✓
  • Features that Lite can't use are dimmed in menus and on buttons, with a small lock icon. Click one to see which edition unlocks it.
  • In Standard, entry points for Pro-only features aren't shown (Help → "Upgrade to Pro" is shown).
  • There's no watermark. There's no limit on the number of texture sets.
  • You can open project files made in any edition. Layers beyond the limit, and settings for features your edition can't use, are kept rather than deleted and remain when you save.
  • For prices and how to buy, see Price on the introduction page. Lite, Standard, Pro and the upgrade to Pro are distributed on BOOTH.

If it doesn't work

  • You can't add a layer (Lite): Lite allows up to 4 layers per texture set, including the base. Below the Layers panel it shows "Layers 4 / 4". Delete or merge a layer and you can add one again.

Upgrade to Pro Pro

To go from Standard to Pro, use "Upgrade to Pro" on BOOTH.

  1. Buy "Upgrade to Pro" on BOOTH to get the upgrade file (PetaNuri3D-Pro.petapack).
  2. Choose Help → "Upgrade to Pro" → "Choose file" and select that file. You can also drop it onto the window, or place it in the same folder as the exe.
  3. You become Pro on the spot, with no restart. Your project files and settings stay as they are, and you're Pro from the next launch too.
The upgrade works only on Standard (it can't be used on Lite).
The upgrade file isn't tied to a version. Once you've applied it, you stay on Pro even after updating PetaNuri3D to a newer version.

Update to a new version

You can see the current version next to the title on the startup screen and in Help → "About PetaNuri3D". Changes are listed in the Changelog.

  1. When you launch the app (at most once a day), a notice appears at the lower right of the screen if there's a new version.
  2. Click "Update now" and the app fetches the new version from the official site, verifies it, replaces the old one after a single confirmation and restarts. If you have unsaved changes, it asks before closing.
  • You can check any time with Help → "Check for updates".
  • File → Preferences → System, "Automatically download and install new versions", is on from the start. When it's on, the app fetches the update at launch and asks "Install and restart" (you can stop it with "Cancel" while it's downloading). If you turn it off, the app fetches the update only when you click "Update now".
  • If you turn off "Check for updates at startup", the app doesn't check when it launches.
  • To update by hand, extract the new ZIP and run setup.exe (it installs over the old one). The same goes for switching editions. Your settings, project files, brushes and upgrade carry over.
Only the version number is checked. Your artwork and settings are never sent anywhere. When you're offline, nothing appears.

If it doesn't work

  • You can't update from inside the app: If the app can't fetch the update from the official site, a "Download on BOOTH" notice appears. Get the ZIP from BOOTH and update by hand. PetaNuri3D v1.2.1 and earlier can't update from inside the app either, so update those by hand.

If you have a problem or a request, you can send it from Help → "Contact (support, feature requests, bug reports)" (How to contact us).
