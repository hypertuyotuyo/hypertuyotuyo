Getting started

From launching PetaNuri3D and opening a model to saving your painting, plus the differences between Lite, Standard and Pro.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

Lite, Standard, Pro, and the Pro upgrade are available on BOOTH.

Launch

  1. Extract the downloaded zip and place the PetaNuri3D folder anywhere (no installation needed).
  2. Inside the folder, double-click PetaNuri3D-win_x64.exe . It also uses resources.neu from the same folder, so move the entire folder when relocating.
  3. If Windows protected your PC appears, choose “More info” → “Run anyway” (may appear initially because the app is unsigned).
  4. Ready when New, Open project and Try a sample appear in the center (recent files/autosaves open here too).
Requires Windows 11 (64-bit). Runs on Windows 10 too, which is not supported.
Settings (sub tools, keys, layout, color sets, reference images etc.) are stored in %APPDATA%\PetaNuri3D and restored at next launch.
Installer (all editions): extract the setup zip downloaded from BOOTH (PetaNuri3D-<edition>-v<version>-setup.zip), double-click the setup inside (PetaNuri3D-<edition>-v<version>-setup.exe), and follow Next. No administrator rights are needed (it installs for your user only) into %LOCALAPPDATA%\Programs\PetaNuri3D; start it from the Start menu. During setup, you can choose whether to create a desktop icon and whether to open projects (.petanuri) by double-click.
To update or switch editions (Lite, Standard, Pro), just run the new setup (it installs over the old one; close the app first if it is running). Settings, projects, brushes, and upgrades are kept. To remove it, uninstall “ぺたぬり3D” from Windows Settings → Apps → Installed apps (settings and projects are not deleted). The zip still works as before.
If the app’s location changes (for example, switching from the zip to the setup), choose the exe again once in the Unity link add-on.

Tutorial and sample model

  • First launch shows a 12-step tutorial. ← → moves back/forward; Skip or Esc exits.
  • Help → Tutorial shows it again. Also enable File → Preferences → System → Show tutorial next launch.
  • Starting the tutorial without a model lets you choose Try the sample model or Use my model (open later). With the sample, practice rotation, drawing, symmetry and UV as you go.
  • Sample model (獄門しのぶ) opens through Try a sample at startup (available in Lite). It uses an A-pose and 7 texture sets, each with original 2048px color textures as Base.
The sample model may only be used to try PetaNuri3D. Do not use it for other purposes or extract and redistribute it.

To draw without a model, choose Start a 2D painting below Try a sample at startup (2D painting).

New project (open a 3D model)

  1. Click New (File → New or Ctrl＋N) and select a 3D model. Supports FBX, glTF (self-contained file), GLB, VRM, OBJ and DAE.
  2. Each material has a Texture set entry. For each set, choose Resolution (32–4096; up to 2048 in Lite) and Start with.
  3. Choose Color (one-color base; white by default, Model color also available), Image (PNG/JPEG etc.), PSD (with layers; Standard), or lilToon material (.mat or containing .unitypackage; Pro). Different sets may use different starting sources.
  4. Click New to show the model in 3D. Cancel with Cancel or Esc.
Model textures are found automatically when embedded or near the model (same folder or Texture folder), starting those sets from Image.
Batch at the top sets resolutions together or selects multiple images/PSDs/lilToon materials. Matching filenames go to matching sets (body.psd → body). Dropped images/PSDs/.mat files are assigned too.
Dropping a 3D model onto the window does not open it. Use File → New or Reload model. UVs outside 0–1 are mapped to equivalent repeating-texture positions for painting (model files stay unchanged). Unpaintable areas are reported at bottom right on import.
Pro After choosing bases, enable Open Easy Bake after creating and select target sets. Choose a skin/outfit finish before detail painting. Baking is not automatic: preview and apply it yourself (Easy Bake).
glTF, glb, and VRM orientation (all editions): these models now have their UVs flipped vertically on open to match FBX. The UV view, exported PNG and PSD, and UV maps match the original images. Projects saved in an earlier version look the same in 3D, but the UV view appears flipped (saving again updates them).
FBX files without materials now open with one texture set per object (previously one set). Areas where the same UV is reused by five or more faces (such as hair strands) can also be painted in 3D.

Save and resume

  • File → Save project (Ctrl＋S) stores the model, all layers and settings in one .petanuri file. Save as uses Ctrl＋Shift＋S.
  • Resume through File → Open project (Ctrl＋O) with a .petanuri file (drag/drop also works), or File → Recent files.
  • While opening, the center shows Loading…, filename and progress.
  • An asterisk * in the title indicates unsaved changes.
  • Autosaves every 5 minutes. After a crash, recover through File → Open autosave (up to 3 latest per project).
Partially unreadable projects open with (incomplete) in the name. Saving uses Save as to avoid overwriting the original.
Autosave now uses a faster format that skips transparent areas of layers. Its images cannot be read by v1.1.2 or earlier. Manually saved projects keep the previous format; turn on “Save projects in the fast format” under File → Preferences → Painting → Performance to use it for them too.
If the app freezes and does not respond to ×, press × again to quit (unsaved changes are lost). If internal file access stalls, for example after sleep, autosave and saving report it instead of waiting forever. Quit, reopen, and use File → Open from autosave to open the latest autosave.

Reload model (keep painting)

After editing a 3D model (such as FBX), update its shape while keeping your painting.

  1. Choose File → Reload model.
  2. Click Reload same file or Choose file.
  3. Texture sets match by material name. Matching sets retain layers and settings.
  • Artwork stays at its UV positions on the new shape, even if UVs change (large UV changes make artwork appear misaligned).
  • Sets for materials absent from the new model are kept with a ! marker. Click to move their layers to other sets (Orphan sets).
  • For newly added materials, the new-project screen appears before reload with only new-set rows. Choose resolution/source and click Reload.
Reloading clears Undo history.
After reloading, if a set’s model texture (image) has changed, you are asked per set whether to replace the base with the new texture. Replacing also replaces anything painted directly on the base. The replacement can be undone as one step after the reload.

Upgrade Standard to Pro Pro

  1. Purchase Upgrade to Pro on BOOTH to get PetaNuri3D-Pro.petapack.
  2. Help → Upgrade to Pro → Choose file selects it (also drop it onto the window or place beside the exe).
  3. Close and relaunch PetaNuri3D to activate Pro, with no reinstall. Projects/settings remain and future launches stay Pro.
Upgrades apply only to Standard, not Lite. The upgrade file must match the app version. After updating PetaNuri3D, download/install the matching upgrade again (a mismatch is reported at startup and the app runs as Standard).

Version and update notices

  • Check the version beside the startup title (such as v1.1.0) or in Help → About PetaNuri3D.
  • At startup (at most once a day), checks the official site for updates. If newer, notifies at bottom right (Open download page / Later / Don't notify for this version).
  • Help → Check for updates checks anytime. Disable File → Preferences → System → Check for updates on startup to stop automatic startup checks.
Only the version number is checked. Artwork and settings are never sent. Offline, nothing appears.
Install and restart (Windows, from the update after this version): “Download on BOOTH” in the notice opens your BOOTH library. After you download the setup zip, the app finds the setup in your downloads folder (still zipped or in the extracted folder) and the notice changes to “Install and restart”, which installs the new version and restarts. If you saved it elsewhere, pick it with “Choose file” (the zip works too). If you have the Pro upgrade on Standard, also download the upgrade file for the same version so it is replaced too.
Contact (all editions): in Help → Contact (support, feature requests, bug reports), choose a type to get a text with the details we need (edition, version, screen size, and so on; file locations are not included). Fill in the blanks, click Copy, and send it from the BOOTH shop or Discord.
