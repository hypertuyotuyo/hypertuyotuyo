Paint from Unity and AI integration

Select an avatar in Unity, launch PetaNuri3D and paint directly. Available in all editions (Lite/Standard/Pro).

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

On this page
  • Launch from Unity and paint
  • AI integration (MCP)

Launch from Unity and paint

  • Select a prefab (such as an avatar) in Unity and choose “ぺたぬり3D で塗る” (Paint with PetaNuri3D) to launch the app with that model.
  • Your painting updates in the Unity scene when you save in PetaNuri3D or Unity . Painted textures enter the Unity project (Unity’s appearance does not change while painting).
  • Supports Unity 2022.3 (used for VRChat avatars). Connects only to Unity on the same computer.

One-time setup: install the Unity add-on

  1. PetaNuri3D-Unity.unitypackage is in the unity folder inside PetaNuri3D.
  2. With the Unity project open, drag PetaNuri3D-Unity.unitypackage into Project (or Assets → Import Package → Custom Package).
  3. Click Import. Setup is complete when “ぺたぬり3D” (PetaNuri3D) appears in the top menu bar (editor-only; not included in uploaded avatars).

Paint

  1. Select an avatar in Hierarchy (scene object) or a prefab in Project.
  2. Choose “ぺたぬり3D” → “ぺたぬり3D で塗る” (PetaNuri3D → Paint with PetaNuri3D) from the menu bar (also right-click). First time only, select PetaNuri3D-win_x64.exe in the app folder.
  3. PetaNuri3D launches with the Unity model. Texture sets follow material main textures; original textures become Base (original resolution, capped at 2048 in Lite).
  4. Save in PetaNuri3D or Unity (Ctrl＋S) to save both and update the painting in Unity.
  • Projects: Assets/PetaNuri/(name)/(name).petanuri. Painted textures: PNGs in Assets/PetaNuri/(name)/Textures/ (import settings match originals). Copied materials go in Materials/ alongside them.
  • Original FBX, materials, textures and prefabs remain unchanged. Starting from a Project prefab creates a Prefab Variant to paint instead.
  • Launched from Unity, PetaNuri3D shows a dedicated painting interface (New, Open project, Reload model and Save as are hidden).
  • Closing PetaNuri3D ends integration. For scene avatars, Unity asks Keep using this / Restore original appearance.
  • Choose “ぺたぬり3D で塗る” (Paint with PetaNuri3D) again to reopen the project and continue.
For detailed instructions or connection trouble, see Unity連携の使い方.txt in the app's unity folder.

AI integration (MCP)

  • AI/MCP clients can control PetaNuri3D (drawing, colors/brushes, views, layers, screenshots, PNG export etc.).
  • Off by default. Enable File → Preferences → AI integration → Enable AI integration (MCP) to use it.
  • Register a stdio server in your MCP client: command node, argument <PetaNuri3D folder>\mcp\server.mjs (Node v20 or later). Connection instructions there include example settings with a Copy button.
  • The AI client starts the server. PetaNuri3D automatically connects to a fixed port on the same computer and reports connection in the bottom hint. Other websites cannot connect.
  • run_js (runs arbitrary programs inside the app) requires Pro . Enabling MCP alone is insufficient; enable Allow run_js (arbitrary program execution) too. Register only trusted AI clients.
