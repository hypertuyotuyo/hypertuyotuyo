Paint from Unity and AI integration

Select an avatar in Unity, start PetaNuri3D, and paint it right away. When you save, your painting shows up in Unity. You can also control PetaNuri3D from an AI (an MCP client).

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

The Unity link and AI integration are available in every edition (Lite, Standard and Pro). Only run_js in AI integration is available in Pro (Edition comparison).

Start with this
  1. Only the first time, import unity\PetaNuri3D-Unity.unitypackage from the PetaNuri3D folder into Unity (Details).
  2. In Unity, select your avatar, then choose ぺたぬり3D → ぺたぬり3D で塗る (PetaNuri3D → Paint with PetaNuri3D) from the menu bar (Details).
  3. After you paint, press Ctrl+S in PetaNuri3D or Unity. Your painting shows up in Unity (Details).
  4. If you move PetaNuri3D to a different place, choose its location again in Unity (Details).
  5. To control it from an AI, turn on File → Preferences → AI integration (Details).

Launch from Unity and paint

You can paint a Unity avatar as it is, without exporting an FBX. The original FBX, materials, textures and prefabs are never changed.

  • Supports Unity 2022.3 (the version used for VRChat avatars). It connects only to Unity on the same computer.
  • Only FBX meshes can be painted. Shapes that are not from an FBX do not appear in PetaNuri3D.

One-time setup: install the add-on in Unity

  1. Open the "unity" folder inside the PetaNuri3D folder. It contains PetaNuri3D-Unity.unitypackage.
  2. With your project open in Unity, drag PetaNuri3D-Unity.unitypackage into the Project window (or use Assets → Import Package → Custom Package).
  3. Click "Import" in the window that appears.
  4. If ぺたぬり3D (PetaNuri3D) appears in the menu bar at the top, the add-on is installed.

The add-on is installed in Assets/PetaNuri3D. It works only inside the editor and is not included in the avatar you upload.

Paint

  1. In Unity, select the avatar in Hierarchy (the object in the scene) or a prefab in Project.
  2. In the menu bar, choose ぺたぬり3D → ぺたぬり3D で塗る (PetaNuri3D → Paint with PetaNuri3D). It is also in the right-click menus of Hierarchy and Project. The Unity menu names are in Japanese only.
  3. Only the first time, a message "Choose the PetaNuri3D program" appears. Choose PetaNuri3D-win_x64.exe in the PetaNuri3D folder.
  4. PetaNuri3D starts and shows the model from Unity. Paint as usual.
  • A texture set is made for each material's main texture. Materials that use the same texture share one set, and what you paint shows on all of those materials.
  • The original texture becomes the base as is, and the resolution is the same as the original texture (Lite is limited to 2048). For a material with no texture, you start painting from the material color.
  • Objects hidden in Unity are also hidden in PetaNuri3D (you can show them in the Objects panel).
  • PetaNuri3D launched from Unity is a screen just for painting. The title is "PetaNuri3D — Unity link (avatar name)", and New, Open project file, Recent files, Reload model and Save as are not shown.
  • If you choose "Paint with PetaNuri3D" again, the open PetaNuri3D comes to the front (a second copy is not started).
  • Pro If a lilToon material uses "Main color 2nd" or "Main color 3rd", their images (including PSD), masks, blend modes and colors come in too, and go into those folders in the Layers panel (Main color 2nd and 3rd). They do not come in with Lite or Standard (in Unity, the original 2nd and 3rd still show as they were).

The PetaNuri3D window (recommended for first-timers)

In the Unity menu bar, choose ぺたぬり3D → ぺたぬり3D の窓を開く (PetaNuri3D → Open the PetaNuri3D window) to open a window that lets you check each step from the top as you paint.

SectionWhat it does
1. PetaNuri3D program (exe)Shows the current location and whether it can be used. Has "Choose", "Search" and "Show in Explorer" (Choose the location again)
2. What to paint (prefab or scene avatar)Drag a prefab or avatar into the field, or select it and click "Use selection". The number of paintable meshes and the texture sets are shown. If it cannot be painted, the reason is shown too

The add-on version (the same number as PetaNuri3D) appears at the bottom of the window.

Show your painting in Unity and finish

While you paint, Unity's look does not change. When you save in PetaNuri3D or Unity, what you painted at that moment shows up in Unity.

  1. Press Ctrl+S in PetaNuri3D or Unity. Both save.
  2. Check in Unity's Scene view that your painting appears.
What is createdLocation (inside the Unity project)
Project fileAssets/PetaNuri/(name)/(name).petanuri
Painted texturesPNGs in Assets/PetaNuri/(name)/Textures/ (painted textures only; the import settings match the original textures)
MaterialsAssets/PetaNuri/(name)/Materials/ (copies of the original materials that use the painted textures)
Main color 2nd/3rd Pro_main2nd.png and _main3rd.png in Textures/ (only when you changed what came in from Unity; masks are not written back)
  • If you started from a prefab in Project, a prefab variant (Prefab Variant) is created in Assets/PetaNuri/(name)/ and that is what you paint. When you upload, place the resulting "(name) (PetaNuri)" prefab in the scene and use it.
  • Next time you choose "Paint with PetaNuri3D", the project file opens and you can continue painting with the layers intact.
  • The textures sent to the Unity link are identical, pixel for pixel, to the exported PNG.

Finish

  • Closing PetaNuri3D ends the link. If you choose "Save and quit" when you close, your painting is sent to Unity before PetaNuri3D closes.
  • If you painted an avatar in the scene, Unity asks "Keep" or "Revert to original". Even if you choose "Revert to original", the files in Assets/PetaNuri/ remain, so you can pick up where you left off by painting again. You can also go back with Unity's Undo (Ctrl+Z).
  • If you close without ever saving, it reverts to the original look without asking and deletes what it created.
  • If you close Unity first, you are asked "Save and Close", "Keep Open" or "Close Without Saving".

Things to watch for

  • Animations that switch materials, such as outfit color changes, point to the original materials. When you use your painting, replace the materials in those animations too.
  • Do not paint the same avatar in two Unity editors at the same time.
  • While Unity reloads scripts (compiling, or the start of Play mode), the link drops for a moment, but it reconnects right away.

If it doesn't work

  • I painted, but Unity's look does not change: It shows up when you save. Press Ctrl+S in PetaNuri3D or Unity.
  • Nothing starts when I choose "Paint with PetaNuri3D", or an English page opens: The exe you chose is wrong. Use Choose the PetaNuri3D location again and choose PetaNuri3D-win_x64.exe in the folder where you extracted the ZIP.
  • "The PetaNuri3D program files (resources.neu) are not next to the selected file" appears: There is no resources.neu next to the exe you chose. Choose the exe in the folder where you extracted the whole ZIP.
  • "The Unity add-on and PetaNuri3D versions don't match" appears: Import the PetaNuri3D-Unity.unitypackage that comes with PetaNuri3D again. To carry Main color 2nd/3rd, you need the add-on of the same version.
  • "All link ports (47360-47369) are in use" appears: Close the other Unity editors and try again.
  • "The selection has no paintable meshes (FBX meshes)" appears: Select a prefab or avatar that has FBX meshes.
  • It still does not connect: Restart both Unity and PetaNuri3D. For details, see Unity連携の使い方.txt (in Japanese) in PetaNuri3D's unity folder.

Choose the PetaNuri3D location again

The Unity add-on remembers the location of the PetaNuri3D-win_x64.exe you chose first. If you moved the PetaNuri3D folder, or extracted a new version into a different folder, choose the location again.

  1. In the Unity menu bar, choose ぺたぬり3D → ぺたぬり3D の窓を開く (PetaNuri3D → Open the PetaNuri3D window).
  2. Click "Choose" under "1. PetaNuri3D program (exe)".
  3. Choose PetaNuri3D-win_x64.exe inside the "PetaNuri3D" folder in the new location.
  4. If "Found." appears below the field, you are done. If "No file at this location" appears, choose again.
  • Click "Search" to look for "PetaNuri3D" folders on the Desktop, in Downloads, in Documents, in Program Files and at the root of each drive. Click "Use this" on the one you want, and that becomes the location.
  • You can also change it in Unity under Edit → Preferences → PetaNuri3D, in "PetaNuri3D program".
  • If the exe is missing from the remembered location, a message "Choose the PetaNuri3D program" appears when you choose "Paint with PetaNuri3D".
  • If you installed with setup.exe, the location is %LOCALAPPDATA%\Programs\PetaNuri3D (Install and launch).
You cannot choose an exe inside a ZIP, or a different exe. Right-click the downloaded ZIP → Extract All, then choose the exe inside the extracted folder.

Control it from AI (MCP)

You can control PetaNuri3D from an AI (an MCP client). You can ask the AI to draw, change colors and brushes, move the view, work with layers, take screenshots, export a PNG and more.

  1. Open File → Preferences and click "AI integration" on the left.
  2. Turn on "Use AI integration (MCP)". It stays ON the next time you start.
  3. Under "How to connect", click "Copy" in "Example settings".
  4. Paste what you copied into the MCP settings on the AI side (the MCP client) and register it.
  5. Start using the AI. When it connects, "AI integration: connected to the MCP server" appears at the bottom of the screen.

How the connection works

ItemValue
Namepetanuri3d
Commandnode (version 20 or later is required)
Arguments<PetaNuri3D folder>\mcp\server.mjs (the window shows the actual location)
  • Register it as a stdio server. The AI side starts the server, and PetaNuri3D connects to it automatically on the same computer (127.0.0.1, ports 47321 to 47330).
  • "Status" shows ON or OFF, and whether it is connected. "Search now" tries to connect right away.
  • It connects to every AI session, however many there are. If you have two PetaNuri3D windows open, you can choose the target with list_instances on the AI side.
  • Websites cannot connect to it. When you are not using it, turn off "Use AI integration (MCP)" to set it to OFF.

What you can ask the AI to do

CategoryCommands
Check the stateget_state (current state), list_layers, screenshot (capture the 3D view), pick (what is at a point on the screen), uv_to_screen, read_pixel (one pixel of a texture)
Open and exportopen_fbx (open a 3D model), export_png
Drawselect_tool, set_color, set_brush, stroke (draw one stroke), fill_at (fill an island), pick_color (eyedropper)
Layers and setsadd_layer, select_layer, set_layer, select_set
View and modeview (the viewpoint), set_mode (toggle between paint and pose)
Undoundo, redo
Prolist_materials, material_edit (material operations), bake_ao (bake AO), run_js (see below)

Allow run_js Pro

run_js is a command that runs arbitrary code (JavaScript) inside the app. It does not work just because AI integration is ON.

  1. Open File → Preferences → AI integration.
  2. In the "run_js" section, turn on "Allow run_js (run arbitrary code)".
In the app (exe), it can even delete files and run commands. Register only AI clients you trust. The run_js section is not shown in Standard.

If it doesn't work

  • The AI says it cannot connect: "Use AI integration (MCP)" is often OFF. Turn it ON and it connects within a few seconds.
  • "This file was not found" appears: Put the mcp folder from the download in the same folder as the app (exe).
  • The server does not start on the AI side: Check that node (version 20 or later) is installed.
  • run_js is refused: It works only in the Pro edition, and only when "Allow run_js (run arbitrary code)" is turned on.
  • The AI says it cannot draw: stroke and fill_at cannot be used in Pose mode. Go back to Paint mode.
