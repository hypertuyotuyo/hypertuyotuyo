Shortcuts and pen controls

A list of keys, plus how to work with a pen, mouse and 3D mouse. Every key can be reassigned. The keys on this page are the initial assignments. It also gathers the fixes for pen pressure that doesn't work or feels wrong.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

Start with this
  1. Press F1 to show the current list of keys. You can keep drawing while it is open (details).
  2. In 3D, rotate with right-drag or Space+drag, and zoom with the wheel (details).
  3. If you want mouse controls like those of other software, choose a camera control template (details).
  4. Change keys in File → Preferences → "Key bindings" (details).
  5. If the line thickness doesn't change when you draw with a pen, go to When pen pressure doesn't work.

Show the shortcut list (F1)

Shows the current list of keys in a floating window. Keys keep working while it is open, so you can still draw in 3D and UV.

  1. Press F1 (or choose Help → "Shortcut list").
  2. Type a key or a name in the "Search" box at the top to narrow the list.
  3. To close it, press F1 again or click the × at the top right.
  • When you press a key, its row lights up briefly, and "Key pressed:" and the name of the action appear at the bottom edge.
  • Drag the header to move the window (double-click it to return it to its original position) and drag the bottom-right corner to resize it. It opens the same way next time.
  • Click ▾ to collapse it and ◐ to make it see-through (it fades when the pointer is outside).
  • Click "Change key bindings" at the bottom to open the key bindings in Preferences.
  • Pen and mouse controls are in the list too, and they change to match the camera control template you have chosen.
  • When you reassign keys, the menus, right-click menus, button descriptions and this list all show the current keys.

Switch tools temporarily with a tool key

If you draw while holding a tool key, you get that tool only while the key is held, and the previous tool returns when you release it. This is handy when you want to use the eraser for a moment while drawing with a pen.

  • If you press and release the key quickly, the tool stays switched.
  • If you hold the key for a while and then release it, the previous tool returns even if you haven't drawn.
  • You can set the time that counts as a hold from 0.15 to 2 seconds with "Hold time" in File → Preferences → Controls → Keyboard (0.5 seconds by default).
  • To turn off this temporary switching altogether, turn off "Hold a tool key to switch temporarily" in the same place.

Choose a camera control template

You can choose from four mouse assignments for moving the view, to match the software you are used to.

  1. Open File → Preferences → "Controls" → "Camera".
  2. Choose one under "Camera control template". Your choice is kept the next time you start the app.
TemplateRotatePanZoom
Right-button style (default)Right-dragMiddle-dragWheel
Middle-button styleMiddle-dragShift+middle-dragCtrl+middle-drag
Alt + mouse buttonsAlt+left-dragAlt+middle-dragAlt+right-drag
Unity styleRight-drag, Alt+left-dragMiddle-drag, Alt+middle-dragAlt+right-drag (down to move in, up to move out)
  • Space+drag and the wheel work with every template.
  • Alt + mouse buttons and Unity style apply to the 3D view. Because Alt operates the camera, use the I key for the eyedropper in 3D.
  • With Alt + mouse buttons, Alt+Shift+left-drag rotates in 90° steps (snapping the direction to a multiple of 90° at the point you click), and Shift+right-drag rotates the light left/right.
  • If you set the pen's side button to middle click, it works the same as the middle button. If you press the middle button while the pen tip is down, drawing stops and it becomes a view control. After you release the middle button, lift the pen tip once before you start a new stroke.

Pen buttons and Windows Ink

Clicks that you assign to pen buttons in the pen tablet driver are received as clicks at the pen's position. This works with both Windows Ink and WinTab.

Button assignmentWhat PetaNuri3D does
Middle clickWhile it is held, moving the pen rotates the 3D view (it rotates whether the pen is hovering or touching). If you press it in the middle of a stroke, the stroke stops there and the view rotates. In a UV pane, it pans
Right clickHold and move for a right-drag (to rotate 3D and so on); release without moving for a right click (the menu)
Back, ForwardReceived as the mouse's Back and Forward buttons
  • A right click that arrives at the same time as the pen tip (within 0.05 seconds before or after) is ignored, and drawing takes priority (for drivers that send a right click together with the pen tip). A middle click works as a view control even when it arrives at the same time as the pen tip.
  • Clicks are received only while the pen is near the PetaNuri3D window. Real mouse buttons are left alone.
  • If you don't want them received, turn off "Receive middle/right clicks from the pen side button" in File → Preferences → Pen & input → Menus and buttons (on by default). When it is off, the driver's click goes to the mouse cursor's position as it is.

What changes when Windows Ink is on or off

Pen tablet settingIn PetaNuri3D
Turn on "Use Windows Ink" (recommended)Pen pressure and tilt arrive. If you press the side button and release it without moving, the popup palette appears
Turn off "Use Windows Ink"The pen arrives as a mouse and no pressure comes through (When pen pressure doesn't work). The side button also arrives as a mouse right click, so it follows the "Right-click" setting under File → Preferences → Controls → Mouse

If it doesn't work

  • 3D keeps rotating after you release the side button: Press Esc or tap once with the pen tip to stop it.
  • You can't draw with the pen tip, or it keeps rotating: Try turning off "Receive middle/right clicks from the pen side button".
  • Dragging with the side button stops partway: In your pen tablet driver's settings, assign the Space key to the side button. You can then rotate with Space+pen drag.
  • A menu appears on its own while you draw fine details: It is being opened by a long press of the pen. Turn off "Long press with the pen opens the menu" in Pen & input → Menus and buttons (Right-click menu).

Move the view with a 3D mouse

A 6-axis 3D mouse such as a SpaceMouse can move the view of the pane under the cursor (the 3D view, a UV pane or the 2D canvas). A notice appears at the bottom right when you connect one.

  • It moves when the PetaNuri3D window is in front or the cursor is over the window. It doesn't move while you draw.
  • It works whether or not the driver (3DxWare) is installed.

3D mouse settings

Change them in File → Preferences → Controls → "3D mouse". The section appears only if you have connected a 3D mouse before.

  • Use 3D mouse, Sensitivity, What to move (Rotate and pan / Rotate only / Pan only)
  • Invert pan direction, Invert zoom direction, Invert rotation direction, Tilt left/right to rotate the screen (3D)
  • Button 1 (left) (switches what to move by default) and Button 2 (right) (Frame all by default). You can also choose Front view, View from opposite side, Toggle perspective / orthographic, Reset view rotation, Open 3D mouse settings, or Do nothing.
  • Ignore the wheel while moving: ignores the wheel events that the driver sends together with cap movement while you are moving it (so zooming doesn't stutter).

If it doesn't work

  • The 3D mouse buttons don't work: The button assignments work only when the driver (3DxWare) isn't running. When it is running, the driver uses the buttons, so in the driver's settings assign a key to a button (for example, F for Frame all).
  • "3D mouse" isn't in Preferences: It doesn't appear until you have connected a 3D mouse at least once. It appears after you connect one.
  • Zooming stutters: Turn on "Ignore the wheel while moving".

Other keys

  • In menus and right-click menus, you can move with ↑↓←→, Enter and Esc. While a menu is open, the app's shortcuts don't work.
  • While you are placing the points of a curve ruler, Ctrl+Z undoes the last point, and Ctrl+Y or Ctrl+Shift+Z redoes it (Ruler).
  • During the tutorial, ← → go back and forward, and Esc quits it.

Assign keys

You can change the key for any action. Use this when you adapt the keys to a left-hand device, for example.

  1. Open File → Preferences → "Key bindings". The actions and their keys are listed in a section for each category.
  2. Click "+" next to the action you want to change. "Press a key (Esc to cancel)" appears.
  3. Press the key you want to use. Combinations with Ctrl, Alt and Shift work too.
  4. If the key is used for another action, you are asked whether to "Reassign". When you do, the key is removed from the previous action.
  • Click the × next to a key to remove it. If you add keys with "+", you can give one action several keys.
  • "Reset to defaults" returns just that action to its default key.
  • "Reset key bindings" returns everything to the defaults (it asks you to confirm first, and Undo can't bring the old assignments back).

Assign from the right-click menu on tools and sub tools

  1. Right-click a toolbar button or a sub tool tile.
  2. Choose "Assign key". If it already has a key, it appears like "Assign key (current: P)".
  3. Press the key you want to use. The previous key is removed and replaced with the one you pressed (Esc cancels).
  • You can also assign keys by right-clicking the header or tab of the Sub tool and Tool properties panels.
  • When you press a key assigned to a sub tool, it switches to that sub tool of that tool. If you delete the sub tool, its key is removed too.
  • Assigned keys appear next to the name of the button or tile (in the tooltip) and under the "Tools" and "Sub tool" categories of the key bindings.
  • To give the same key to several sub tools, choose "Share (cycle on each press)" in the assign window. Each time you press that key, it cycles to the next sub tool (for example, Q for G-pen and Fineliner).

Export and import assignments

Use this when you move to another PC, or want to keep a backup.

  1. Click "Export key bindings" above the key bindings. Your current assignments are saved to a JSON file (PetaNuri3D-keymap.json).
  2. On the receiving side, click "Import key bindings" and choose that file.
  3. When asked "Replace the current key bindings with the ones in this file?", click "Load". Your current assignments are replaced entirely.
  • Actions that aren't in the file get their default keys. Entries for actions that don't exist in this version are not used.

If it doesn't work

  • A key does nothing when you press it: While a menu is open, the app's shortcuts don't work. Close the menu, then press the key.
  • A key triggers an action you didn't expect: Open the F1 list and press the key. The action for that key appears at the bottom edge.
  • You assigned a numpad key and it doesn't work, or it doesn't work from the top row: Numpad digits and top-row digits are different keys. Reassign the one you use.
  • The keys for reload, print and page zoom don't work: Browser shortcuts don't work in PetaNuri3D.

Pen pressure is wrong or doesn't work

You can adjust pen pressure to your own touch under "Pen pressure" in File → Preferences → Pen & input. If the thickness doesn't change at all, first check whether pressure is arriving (the path).

Adjust to your touch (calibrate with test strokes)

  1. Open File → Preferences → "Pen & input" → "Pen pressure".
  2. Click "Calibrate with test strokes".
  3. On the pad on the right, draw 3 or more lines with your usual pressure.
  4. Click "Calibrate". The minimum, maximum and response are set to fit your touch.
  5. If you don't like the result, click "Undo".
ItemMeaning
ResponseSoft = thick and dark even with light pressure / Firm = thick only when you press hard
MinPressure weaker than this is treated as pressure 0
MaxPressure stronger than this is treated as 100% pressure (for pens with a narrow pressure range)
  • When you press the pad on the right with the pen, it shows the current pressure and the value after the response is applied.
  • For each sub tool, you change in tool properties whether pressure changes the thickness and density ("Pen pressure to size", "Pen pressure to opacity") and the pressure curve. These are applied after the response set here (Detailed brush settings).

Check that pressure is arriving

  1. Press the "Pen pressure" pad in File → Preferences → Pen & input with the pen.
  2. Look at "Current pressure" under the pad, and at the path.
Path shownMeaning
Windows InkPressure is arriving
WinTabPressure is arriving via "Read pen pressure directly (WinTab)"
None (arriving as a mouse)Pressure isn't arriving. See "When pressure has no effect (size doesn't change)" below

When pressure has no effect (size doesn't change)

If "Use Windows Ink" is turned off in your pen tablet settings, the pen arrives as a mouse and no pressure comes through. There are two fixes, and either one is enough.

  • Recommended: In your pen tablet driver's settings screen, turn on "Use Windows Ink". Tilt arrives too.
  • If you keep Windows Ink off: Turn on "Read pen pressure directly (WinTab)" in File → Preferences → Pen & input → "Tablet" (off by default). The path becomes "WinTab".
If it looks like you are drawing with a pen but pressure isn't arriving, a notice "Pen pressure is not arriving" appears once at the bottom right. It doesn't appear if you are just drawing with a mouse. "Don't show again" stops it from appearing, and "Open preferences" opens Pen & input.

Read pressure with WinTab

  • When you turn on "Read pen pressure directly (WinTab)", pressure (and tilt) is read through the WinTab of your pen tablet driver.
  • It replaces pressure only when you draw with the pen close to the screen. Drawing with a mouse is unchanged. The eraser end of the pen works as the eraser too.
  • "Use WinTab pressure for Windows Ink pens too" (on by default): even when the pen arrives via Windows Ink, if WinTab values are arriving, it uses those pressure and tilt values. When it is off, it keeps the Windows Ink pressure.
  • If you use it at the same time as another drawing app that uses WinTab, pressure may not arrive.

If it doesn't work

  • You have to press hard to get thickness, or even a light touch is thick: Calibrate again to your touch with "Calibrate with test strokes". To adjust by hand, if you have to press hard to get thickness, lower the max; if even a light touch is thick, move the response toward "Firm".
  • Light strokes are almost invisible, or the taper is too thin: Under Pen & input → Stroke feel, set "How tapering is made" to "Taper by length". Parts with weak pressure then never get thinner than 1px.
  • It works with other brushes, but the thickness doesn't change for one brush: In that sub tool's tool properties, check that "Pen pressure to size" isn't turned off (Detailed brush settings).
  • The thickness doesn't change when you draw with a mouse: A mouse has no pressure. For a mouse, the taper is always made from the "Taper start" and "Taper end" lengths of the sub tool.
  • "The pen tablet driver has no free WinTab slots" appears and "Read pen pressure directly (WinTab)" turns off: Close other drawing apps that use WinTab, or restart your pen tablet driver (or the PC), and then turn it on again. With some drivers, the slot used by an app that quit without closing properly doesn't come back until you restart.
  • "WinTab not found" or "Pen tablet not found" appears: Check that the pen tablet driver is installed and that the tablet is connected.
  • You turned on WinTab, but "Current pressure" stays at "— (no pressure)" when you press the pad: With the PetaNuri3D window in front, press and draw on the pad with the pen a few times (if nothing arrives, it tries switching the connection method every two presses). If it still doesn't work, click "Search again" under "WinTab connection", and draw again.
  • The pen doesn't respond after you turn WinTab on: Click "Search again" under "WinTab connection" in "Tablet", and draw again. It forgets the connection method it remembered and searches from scratch.
  • You have per-app settings in your pen tablet driver: If you have added PetaNuri3D (PetaNuri3D-win_x64.exe) to the per-app settings, check there that pressure isn't turned off.
  • "WinTab is running, but no pen data is arriving" appears: Use "Check WinTab status" below to find out where it is stopping.
  • You want to reinstall or update the pen tablet driver: Close PetaNuri3D first. While WinTab is in use, the driver's files stay open.
  • Lines appear late behind the pen tip: Try turning on "Show pen strokes early (reduce lag)" under Pen & input → Reduce lag (when drawing with the pen via Windows Ink). Also turn on "Predicted preview line" (Pen & input settings).

If it still isn't fixed (send to support)

  1. Click "Check WinTab status" under File → Preferences → Pen & input → "Tablet".
  2. Draw one line (2 to 3 seconds) with the pen over the PetaNuri3D window. It shows wintab32.dll, the pen tablet name, the pen pressure levels, the receiver (WinTab context), the number of packets that arrived in the last 5 seconds, the last pen pressure (raw value), and an assessment of where it is stopping (the numbers change every second).
  3. Click "Copy".
  4. Choose Help → "Contact (support, feature requests, bug reports)", paste it together with your pen tablet model and driver version, and send it (How to contact us).
When the message "Turn on 'Read pen pressure directly (WinTab)', then check again" appears, turn on "Read pen pressure directly (WinTab)" in the same place, and then click the button again.
