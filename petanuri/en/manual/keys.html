Shortcuts and pen controls

Rebind every key through File → Preferences → Key bindings (useful for shortcut devices). This page shows default bindings.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

Lite, Standard, Pro, and the Pro upgrade are available on BOOTH.

Shortcut list (F1)

  • F1 opens a floating shortcut list (also available in Help).Keys remain active and you can draw in 3D/UV while it is open. Press F1 again or the top-right × to close.
  • Filter by key or name in Search at the top. Pressed keys briefly highlight their rows and appear under Pressed key at the bottom.
  • Drag the header to move; drag the bottom-right corner to resize (remembered next time). ▾ collapses; ◐ makes it translucent.
  • Rebinding updates menus, right-click menus, button tips and this list to your current keys.

Assign keys

  • File → Preferences → Key bindings: in each category, click + then press a key to assign; × removes. Reset to defaults restores that key; Reset key bindings restores all after confirmation.
  • Also right-click a toolbar button, sub-tool tile or panel header → Assign key (Ctrl・Alt・Shift combinations supported). If a key is already used, you are asked whether to reassign it.

Incorrect or missing pen pressure

  1. First adjust Pressure under File → Preferences → Pen & input. In Calibrate with test strokes, draw at least 3 lines using your normal pressure, then click Calibrate to automatically set minimum, maximum and response.
  2. If pressure is missing (size stays constant), press the test pad with the pen and inspect Input path. If it says None (received as mouse), enable Windows Ink in your tablet settings, or Pen & input → Tablet → Read pressure directly (WinTab).
  3. If still incorrect, click Check WinTab status under Tablet and move the pen over PetaNuri3D. Copy the report and send it to support with your tablet model and driver version.
