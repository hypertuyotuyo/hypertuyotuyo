Texture sets and objects

A "texture set" is created for each material of the model. One set is one texture, and each set has its own layers and resolution. You can also hide objects (meshes) such as hair and clothing one by one.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

Start with this
  1. When you start drawing on the model, PetaNuri3D switches automatically to the set at that spot. To choose one by hand, use Alt+right-click (details).
  2. To cross the border between two sets, such as the neck seam, touch each set once and then draw. A single stroke can then cross the border (details).
  3. Change the resolution in the field at the right of a row in the Texture sets panel. This clears the undo history, so save first (details).
  4. If it gets slow or you can't paint, lower the resolution or close other apps (details).
  5. To hide a whole piece such as clothing, click the eye button in the Objects panel (details).

Choose the set to draw on

You can paint on the selected texture set. Normally you don't need to select it again, because PetaNuri3D switches automatically to the set where you start drawing.

  1. In the 3D view, start drawing on the area you want to paint.
  2. If you start on a different set, PetaNuri3D switches to that set and then draws. The set name appears near the pen tip.
  • To choose one by hand: click a row in the Texture sets panel, Alt+right-click on the model, or use "Select this set" in the 3D right-click menu. You can also choose from "Texture set" in the right-click menu of the UV pane.
  • When you select a set again, that set glows softly in 3D and then fades, so you can see which area belongs to it.
  • While a set that was resting wakes up, "Switching texture set…" appears (about 0.2 seconds at 2048, about 0.5 to 1.5 seconds at 4096). Pen movement during that time is remembered and painted once the set is awake, so lines are not cut off.
  • Undo and redo keep working after you change sets. If you undo an operation on another set, that set becomes selected.
  • The Layers panel and the UV pane show the layers and UV of the selected set.

Stop it switching automatically

Turn off "Switch on touch" at the bottom left of the 3D view (or "Switch to the set where you start drawing" in the 3D right-click menu). While it is off, starting to draw on another set does not switch to it, and you can paint only on the main and the sub.

If it doesn't work

  • Painting switched me to another set: You started drawing on another set. If you don't want it to switch, turn off "Switch on touch".
  • I can't paint in 3D and the cursor shows a no-entry shape: The pointer is over a texture set that isn't selected, or the layer is locked or hidden. The reason appears under the cursor.

Paint across two sets (main and sub)

You can paint across the border between the face and body sets, such as at the neck seam, with a single stroke.

  1. Touch each of the two sets you want to paint across, once (paint on it or select it).
  2. Check that "Paint across" at the bottom left of the 3D view is on (it is on by default).
  3. Draw across the border. You can paint both sets in one continuous stroke.
  • Two sets stay awake and paintable: the selected set (Main) and the set you selected before it (Sub). Their names appear at the bottom left of the 3D view, and clicking Sub swaps it with Main.
  • In the panel, the Main row is pink and the Sub row is blue, each with a badge.
  • Each set is painted on the layer selected in that set. A single undo reverts both.
  • The brush circle does not spill onto a set that the pen tip is not on. If you draw the eyes, the skin is not painted too. The same goes for Blur, Smudge, Blend and Liquify.
  • In the UV pane, you paint only on the Main set. A small Sub UV appears at the bottom right (click it to make the Sub the Main).

Paint without crossing and remove the sub

  • To paint only on the set where you started, turn off "Paint across" at the bottom left (or "Draw across 2 sets in one stroke" in the 3D right-click menu). Both sets stay awake even when it is off, so switching back and forth is quick.
  • To remove the Sub, click the × to the right of the "Sub" badge on the Sub row in the panel (or "Remove sub (stop painting together and let it sleep)" in the right-click menu of the Sub row). That set goes to sleep and frees GPU memory.
  • After you remove it, the Sub at the bottom left shows "None". If you select another set, the current Main becomes the Sub again.
"Sub" is different from lilToon's Main color 2nd.

Reading the Texture sets panel

The "Texture sets" panel on the right lists the sets, one per row. Right-click a row, or click the "…" at the right of the row, to bring up the operations for that set in one place.

How sets are formed

  • One set is created for each material. Materials that use the same image are combined into one set. You decide how to combine them on the New screen (Open a 3D model).
  • When you select a combined set, the panel shows "This texture is used by" followed by the material names. What you paint shows up on all those materials.
  • For transparent areas of a VRM, the transparency of the original image and the material's transparency settings are carried over. Even with the same image, materials with different transparency settings become separate sets.
  • The 2D canvas for stamps and 2D painting use working sets that are separate from the model's sets. While you are editing one, the panel says so. They are saved in the project file along with everything else and are not included when you export the model (2D canvas for stamps).

Change the resolution

You can change the size of the texture (the number of pixels across and down) for each set.

  1. Save the project file first (Ctrl+S).
  2. In the Texture sets panel, choose a resolution from the field at the right of the row (or "Resolution" in the row's right-click menu).
  3. If "Changing the resolution clears the undo history." appears, click "Continue". Your painting is scaled to the new size.
  • You can choose 32, 64, 128, 256, 512, 1024, 2048 or 4096. Lite goes up to 2048, and Standard and Pro go up to 4096.
  • 32 to 256 are meant for pixel art. Even at a low resolution, ordinary layers, saving and PNG export work. Sets of 256 or less are shown as pixels from the start (details).
  • If you only want to change the size when exporting, use "Resolution" in the export window (Export as PNG).
Changing the resolution clears the whole undo (Ctrl+Z) history. Lowering it blurs fine detail. Raising it doesn't add detail.

If it doesn't work

  • I can't choose 4096: Lite goes up to 2048. You can choose it in Standard and above.
  • "Change the resolution after saving finishes" appears: Saving or autosave is in progress. Choose again when it has finished.

Replace base images and add images or PSDs

Even after you have opened the model, you can replace the base image of each set and import images or PSDs.

  1. In the Texture sets panel, right-click the row of the set you want to import into (or use the "…" at the right of the row).
  2. Choose an item from the table below, then choose a file.
ItemWhat it does
Replace base imageReplaces the picture on the base layer with the image you choose (PNG, JPEG, WebP, BMP, GIF or TGA). If the size differs, it is scaled to match the resolution. Other layers are left as they are
Import image as layerShows a frame for placing the chosen image on that set's UV. Press Enter to make it a new layer. If you choose several, they are placed one at a time (Paste an image)
Import PSD (replace layers) StandardReplaces that set's layers with the layers of the PSD (PSD)
Load lilToon material (.mat) ProLoads a .mat or .unitypackage into that set (Load a lilToon material)
  • You can also drop an image, PSD or .mat onto a row (a dotted frame appears on the row you are dropping onto). With a single image, you are asked whether to "Replace base" or "Add as layer".
  • You can import into a set you haven't selected, without selecting it. All of these can be undone with Undo (Ctrl+Z).
  • For the selected set, you can also replace the base image with File → Import → "Replace base image (selected set)".

If it doesn't work

  • "Stretched because the aspect ratio differs" appears: The aspect ratio of the image differs from the texture. Use a square image.
  • I can't replace the base: The base layer is locked or doesn't exist. Unlock it, or use "Import image as layer".
  • I can't add an image as a layer (Lite): Lite allows up to 4 layers per set. Merge or delete layers, then add it.

Hide a set and show it as pixels

For each texture set, you can switch whether it appears in 3D and how its pixels look.

  • Use the check at the left of a row to show or hide that set in 3D. You can also use "Show only this set" and "Show all sets" in the row's right-click menu.
  • A set you hide keeps its texture as it is, and it is still included when you export all sets.
  • To hide by mesh, use the Objects panel (details).

Show textures as pixels

In the 3D display, this shows the texture as square pixels, one at a time, without interpolation. It is meant for low-resolution textures such as 32 px or 64 px.

  1. In the row's right-click menu ("…"), click "Show as pixels (no interpolation)".
  2. A small square icon appears to the right of the name. Click the icon to turn it off.
  • Sets of 256 px or less have it on from the start (automatic). A set you have turned on or off yourself keeps that choice in the project file.
  • "Reset pixel display to automatic (on for 256px or less)" undoes the choices you made yourself.
  • To switch all sets at once, use Display → Shading → "Show all sets' textures as pixels (no interpolation)".
  • This only changes the display. Your painting and exports don't change. Used together with the Pixel pen, the pixels look square in 3D too (Draw).

Hide objects or show only one

The "Objects" panel on the right lists the model's objects (meshes such as hair, clothing and props). You can use it, for example, to hide a whole piece of clothing and paint the body underneath.

  1. In the Objects panel, click the eye button of the object you want to hide. It disappears from 3D.
  2. To show only that object, hold Alt while you click its eye button or name (hold Alt and click again to show everything).
  3. To bring them back, click "Show all" at the top of the panel or press Alt+H.
  • If the original has a hierarchy, it is shown indented. Each row has an eye button, the name and a badge for the texture set it uses.
  • Click a name to make that object glow briefly in 3D. Click a badge to select that texture set.
  • Row right-click: Show only this, Hide / Show, Highlight in 3D, Show all. The 3D right-click menu also has "Hide this object" and "Show only this object".
  • Hidden objects don't appear in 3D, can't be hit by a click, and aren't painted. The same goes for Also paint back and hidden faces, the opposite side of Symmetry, Fill, Gradient and Stamp. Whatever lies behind a hidden object is visible and paintable as it is.
  • The textures (layers) remain. Exports of PNG, PSD and materials don't change either.
  • While objects are hidden, the bar under the 3D view shows "n object(s) hidden" and "Show all". Show all (Alt+H) restores both the visible area and the objects (Visible area).
  • The hidden state is saved in the project file. Hiding and showing are not recorded in the undo history.
  • Pro With "Give only this object a separate material" and "Assign material" in the row's right-click menu, you can split materials by object (split materials).

Display presets

Use "Save current state" at the bottom of the panel to remember the set of hidden objects under a name. In Pro, the shape key values are remembered too.

  • Click "Load" to apply that state (a single undo reverts it). "Overwrite" replaces it with the current state, you can rename it in the name field, and × deletes it.
  • You can store up to 10, and they are saved in the project file. The same list also appears in the Blend shapes panel.

Save GPU memory (when it is slow)

Textures use GPU memory (VRAM). With 4096 sets or many layers it can run out, which makes things slow or stops you from painting. PetaNuri3D frees memory by letting items you aren't using go to sleep.

How resting works

  • Sets you haven't selected are put to sleep, which frees GPU memory without changing how they look. Only two are awake: the Main and the Sub.
  • When you select a sleeping set, you can paint after about 0.2 seconds at 2048 or about 0.5 to 1.5 seconds at 4096. If you click a sleeping 4096 set in the panel, "Preparing…" appears.
  • Saving, PNG/PSD export, AO and filters that apply to all sets work on sleeping sets as they are.
  • Layers you haven't touched for a while are also kept in a shrunken form while you aren't drawing (File → Preferences → Painting → Performance, "Rest layers you aren't drawing on", on by default). Appearance, export and saving don't change (Rest layers).
  • You can see the current amount in the "GPU memory estimate" at the top of the Texture sets panel and in the numbers on each row.

When it is slow or you can't paint

  1. Check the GPU memory estimate at the top of the Texture sets panel. As a guide, you need at least 4 GB of GPU memory to paint at 2048 and at least 8 GB for 4096 (System requirements).
  2. Close other apps that use the GPU, such as games, browsers and video.
  3. Lower the resolution of sets that don't need that much detail (Change the resolution).
  4. If you aren't painting across sets, remove the Sub to let it sleep (Remove sub).
  5. If you had turned "Rest layers you aren't drawing on" off, turn it on.
  • "Display processing stopped" appears: The GPU's display processing was restarted, and your painting can no longer be shown. It happens when resuming from sleep or when memory runs out. You can't paint in this state, and nothing is saved. Reopen with "Open from autosave" or "Reopen project file" in the window (your previous project file and autosave are left intact).
  • "Display processing has stopped, so it can't export" appears: Same as above. Reopen, then export.
  • I wait every time I select a set: A sleeping set is being woken up. If you set the two sets you switch between as the Main and the Sub, you won't have to wait.

Orphaned sets (! mark)

Sets for materials that aren't in the current model are kept, marked with !, rather than deleted. You can move the layers you painted to another set.

This happens when you reload the model, and when you open a project file that was saved without the model (FBX) together with a model whose names don't match.

  1. In the Texture sets panel, click the set that has a !. The "Set not in the model: (set name)" window opens.
  2. Choose layers with "Layers to move" (all of them are selected at first; there are also "Select all" and "Deselect all").
  3. Choose a set with "Destination" (a set with a similar name is selected at first).
  4. Click "Move". The layers go to the top of the destination's layers, in the same order.
  • Folders, masks, clipping and blend modes are carried over as they are. If the resolution differs, the layers are scaled to the destination size. UV position stays the same.
  • If you check "Also keep in the original set (copy only)", the layers are only copied and also remain in the original set.
  • A set with no layers left disappears. You can also use "Delete this set" in the window to delete it together with the layers you painted. All of these can be undone.
  • The row's right-click menu also has "Move layers to another set" and "Delete this set".
A set with a ! doesn't appear in 3D and can't be painted on. It is also left out of exporting all sets and of AO. If you need the picture of only that set, use "Export PNG (no bleed outside islands)" or "Export as PSD" Standard in the row's right-click menu.
