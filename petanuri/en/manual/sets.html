Texture sets and objects

A texture set is created per material, each with its own layers and resolution. Also hide individual model objects (meshes).

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

On this page
  • Select a texture set
  • Main and sub (paint across two sets)
  • Replace base images and add images/PSDs
  • Show/hide objects
  • Memory savings
  • Orphan sets (! marker)

Select a texture set

  • In the 3D view, starting a stroke on another set automatically switches to it before painting. Its name appears beside the pen tip.
  • Unloaded sets show Switching texture set… while loading. Pen movement is remembered and painted once ready, so strokes are not lost.
  • Disable automatic switching with Switch to touched set at the 3D bottom left (also in right-click menu).
  • Select manually too: click a panel row, use Alt + right-click on the model, or choose Select this set from the context menu. Selecting briefly highlights the set in 3D.
  • Checkboxes toggle visibility; the right field changes resolution (512–4096; Lite up to 2048). Resolution changes clear Undo history, with confirmation first.
  • Undo/Redo remain available across set changes.
The stamp 2D canvas is a special working set. It stays out of the model list; the panel indicates when it is being edited. Edited separately from main/sub, but saved in the same project (2D canvas for stamps).

Main and sub (paint across two sets)

  • Two sets remain loaded and paintable: the selected set (Main) and the previously selected set (Sub). Names appear at the 3D bottom left (click sub to swap with main). Panel rows show main in pink and sub in blue.
  • One stroke can span both. For seams between face and body, touch both once before painting. One Undo restores both.
  • To paint only the starting set without crossing, disable “Paint across sets” at the bottom left (same toggle in the context menu).
UV painting affects only main. A small sub UV preview appears at bottom right (click to make sub main).

Replace base images and add images/PSDs

Right-click a Texture sets row or click its right-side …:

  • Replace base image: Replaces that set's Base artwork with the selected image (PNG, JPEG, WebP, BMP, GIF, TGA). Different sizes are resized to the set resolution.
  • Import image as layer: Opens a frame to position the image on that set's UV (Enter adds it to a new layer).
  • Import PSD (replace layers): Replaces that set's layers with PSD layers (Standard).
  • Load lilToon material: Imports .mat/.unitypackage into that set (Pro).
  • Also drop images, PSDs and .mat files onto rows. Import into unselected sets too. All can be undone.

Show/hide objects

Objects on the right lists meshes such as hair, clothes and accessories, indented by original hierarchy. Each row has an eye button, name and texture-set labels.

  • Eye toggles hide/show.Alt + click shows only that object; again shows all. The 3D context menu also offers Hide this object and Show only this object.
  • Click a name to briefly highlight the object in 3D; click a label to select its texture set.
  • Hidden objects are absent from 3D, hit testing and painting (including back/hidden-face painting, mirrored symmetry, fill and gradients). Objects behind become visible and paintable.
  • Textures/layers remain, and PNG/PSD/material exports are unchanged. Hidden state is saved in projects. Show all with Alt＋H .

Memory savings

  • Unselected sets are unloaded to free GPU memory while retaining their displayed appearance.
  • Reselecting restores painting in about 0.2 seconds at 2048 or 0.5–1.5 seconds at 4096.
  • Saving, export, AO and all-set filters still work on unloaded sets.

Orphan sets (! marker)

Reloading the model preserves sets for materials missing from the new model, marking them with ! .

  1. Click a set marked !.
  2. Choose layers to move (all initially) and a destination set, then click Move.
  3. Layers appear at the destination's top in the same order. Keep in original set copies instead of moving.
! sets do not appear in 3D, cannot be painted and are excluded from export/AO. Delete this set removes them.
