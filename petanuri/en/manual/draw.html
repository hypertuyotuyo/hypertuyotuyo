Draw

Draw directly on the 3D model with the pen. This page covers choosing tools, setting how a brush feels, choosing colors, fill, gradients, shapes and drawing symmetrically.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

Start with this
  1. On the toolbar at the left, select Pen (P), then choose "G-pen" in the Sub tool panel (Details).
  2. Choose a color in the Color panel and trace over the model in the 3D view. The app automatically switches to the texture set where you start drawing (Details).
  3. Change the thickness with [ ] or with the Brush size panel on the left (Details).
  4. To erase, use the Eraser (E), or press C to switch to the transparent color and erase with the same brush (Details).
  5. To draw the same thing on both sides, click the "X" at the top left of the 3D view (M) (Details).

Draw your first stroke

Once you open a model, you can draw right away. You don't have to select a texture set first: the app automatically switches to the texture set where you start drawing (for example, body).

  1. Click "Pen" on the toolbar at the left (P).
  2. Choose "G-pen" in the Sub tool panel.
  3. Choose a foreground color in the Color panel.
  4. Trace over the model in the 3D view. A line appears where you traced.
  5. To rotate, right-drag (the pen's side button) or Space+drag. To zoom in, use the wheel.
  6. If you make a mistake, press Ctrl+Z to undo one stroke at a time.

Controls while drawing

  • Shift+click: Draws a straight line from the end of the previous line.
  • Ctrl+Alt+drag left or right: Changes the brush size.
  • Ctrl+right-drag (pen side button): Dragging left or right changes the brush size, and up or down changes the hardness. Ctrl+dragging with the pen tip changes the opacity left or right and the tip angle up or down.
  • If you draw with the eraser end of the pen, it erases.
  • Alt+right-click on the model to select the texture set at that spot (Select a texture set).
  • You can draw on the UV view with the same tools (UV and visible area).

For camera control schemes and other keys, see Pen and mouse controls.

If it doesn't work

  • Nothing is painted when you trace: The reason appears in the bar at the bottom of the screen. You can't draw on hidden layers, locked layers or folders. Select a layer you can draw on in the Layers panel (Layers).
  • Color doesn't appear in only some areas: You can't draw outside the selection or on hidden areas. On a layer with Lock transparency on, you can't draw on transparent areas.
  • You can't draw on other texture sets: "Switch to the set where you start drawing" is off. Turn it on from the right-click menu in the 3D view. When there is a selection, you can't draw on sets that are not selected.
  • Pen pressure doesn't change the thickness: Check whether "Pen pressure to size" in Tool properties is on. If it's on and nothing changes, see When pen pressure doesn't work.

Add, reorder and assign keys to sub tools

The values in Tool properties are remembered for each sub tool. To keep the same pen at different thicknesses, duplicate it and give the copy another name.

  • The icons under the sub tool list let you, from the left, "Duplicate", "Name", "Delete", "Reset", "Export", "Export all" and "Import". Right-clicking gives the same options.
  • You can also rename by double-clicking. Drag to reorder (this works with the pen as is).
  • "Small", "Medium" and "Large" above the list change the tile size. Making the tiles smaller gives more room to the Tool properties below.
  • Right-click a toolbar button or a sub tool tile → "Assign key" to give it any key you like. To give the same key to several sub tools, choose "Share (cycle on each press)", and each press moves to the next sub tool.
  • Standard With "Export", "Export all" and "Import", you can exchange brush settings as .petabrush files. Imported tip images are included. You can also import a .petabrush by dropping it onto the window.
Deleting a sub tool can't be undone. In Standard and above, you can keep a copy first with "Export".

Import brushes from other paint apps

  1. Click "Import" under the sub tool list.
  2. Choose .abr, .gbr, .gih, .sut, images (such as PNG), or a .zip that bundles them. You can choose any number of files.
  3. A sub tool that uses the tip is added and selected. You can draw with it right away.
  • You can also import by dropping files onto the Sub tool panel. If you drop an image onto the 3D or UV view, it is treated as an image, not a brush.
  • What is imported is the tip shape and name, the initial size and, when it can be read, the spacing and anti-aliasing. The original app's stroke feel, color mixing and color are not carried over, so adjust them in Tool properties.
  • .abr supports image tips in versions 1, 2 and 6, and .gbr supports versions 1 and 2. .gih uses up to 128 frames at random. .sut makes a tip from the image inside (it may contain things such as a reduced preview image).
  • The limit is 64 MB per file. For a .zip, it is 512 files and 64 MB after extraction. If a format can't be read, the reason is shown.
  • You can import in any edition. Imported tips and sub tools are kept after the next launch.

Brush collection (bundled brushes)

The "Brush collection" on the toolbar contains 33 textured brushes. They are a brush set published under CC0 (public domain), converted to this app's settings. You can use them freely, both for your artwork and commercially.

  • Airbrush (large) / Basic spread / Oval brush / Pressure-width brush / Detail brush / Pencil H (sketch) / Mechanical pencil / Pencil 2B / Fine brush (grainy) / Ink brush line art / Fine brush (hard edge, rock texture) / Block brush (layering) / Flat brush (layering) / Charcoal (soft) / Round brush (layering) / Layering (textured) / Shaping (textured) / Thick ink brush (textured) / Ink brush (tilt for volume) / Ink brush (blending in) / Rake brush (grainy) / Impasto (canvas) / Watercolor edge / Scattered texture / Canvas rub / Dry scratch / Splatter (large) / Splatter (light) / Squiggle / Textured base / Large sponge / Grainy noise / Leaves
  • The blurs and smudges from the same collection (Rake blur (smudge), Textured blur, Flat blur) are under "Blend", and the erasers (Eraser (chalk tip), Kneaded eraser (soft)) are under "Eraser".
  • The "Bundled brushes" tips (31) and the "Built-in" paper textures (6) can also be used with other sub tools.
  • The feel is not exactly the same as the original brushes.

Draw pixel art (Pixel pen)

The Pen's "Pixel pen" paints crisply as many pixels as the brush size, snapped to the pixel grid of the texture. A size of 1 paints 1 pixel and 3 paints 3×3, and colors do not mix. It suits pixel art and low-resolution textures such as 32 or 64 px.

  • The size is in texture px. Pen pressure and taper do not change the thickness.
  • In the 3D view, it paints only inside the island of the face visible at the center of the pen tip. Symmetry also works (it paints the same pixel on the other side too).
  • Other pens paint the same way if you turn on "Pixel (crisp, snapped to the texel grid)" in Tool properties.
  • If you show the texture as pixels, the pixels also look square in 3D (⋯ on the texture set row → "Show as pixels (no interpolation)"; see Texture sets).

Set the thickness (brush size, size basis)

  • In the "Brush size" panel on the left, click a frequently used size to select it. Clicking changes only the size (set opacity and hardness in Tool properties).
  • The pencil at the end of the size tiles, or a right-click, gives "Add current size", "Remove selected" and "Reset". "Remove this size" in the right-click menu removes the tile you clicked right away.
  • The panel wraps by width, so if you make it narrow it shrinks down to one column.
  • [ ] also change the thickness. In the key bindings you can also assign keys to "Next larger size in the brush size list" and "Next smaller size in the brush size list".
  • When a shape tool is selected, this changes the shape's line width (up to 500). With Polygon fill and Select by face, it changes the "Pick radius" (up to 200).

The "Size basis" decides how thickness behaves when you zoom in or out. You choose it for each sub tool.

Keep lines from stretching on slanted faces (3D brush projection)

Choose it with "3D brush projection" for Pen, Brush, Brush collection, Eraser and Blur. "Follow the surface" (the default) makes lines less likely to stretch on slanted faces and edges, and image tips also line up with the direction of the face. "Match the screen" projects from the camera, so lines stretch on slanted faces.

When you draw in the UV view, both work the same way.

Choose the tip

  • Click "Tip" to choose. There are round, square, flat brush, pencil, chalk, spray, watercolor, ink brush, sparkle, star and heart tips, plus 31 bundled brush tips.
  • With "Load" in the tip list, you can also make a tip from an image (a PNG or JPEG with a black shape on a white background), from brushes of other paint apps (.abr, .gbr, .gih, .sut), or from a .zip that bundles them.
  • For image tips, "Angle", "Random rotation" and "Rotate along stroke" appear.

Add a paper texture

If you choose a "Paper texture" for Pen, Brush, Eraser and so on, paper or canvas grain is added to the darkness of the paint. It repeats over the texture, so it sticks to the surface and doesn't slide when you move the view.

  • You can choose from the 6 built-in textures and the 15 patterns (the same designs as Pattern). With "Import texture" you can also use any image (lighter areas take more paint).
  • Adjust it with "Texture scale", "Texture angle", "Texture strength" and "Invert texture brightness". Where a UV island is upside down or sideways, use "Texture angle" to match the direction of the pattern.
  • "Apply mode" is either "Multiply (brighter areas take more paint)" or "Subtract (dark areas drop out first)".

  • Start/end taper: The length over which the start and end of a stroke are thinned. The end taper redraws the end of the line thinner when you lift the pen, so there is no lag while you draw.
  • Motion: "Speed to size", "Size jitter", "Opacity jitter", "Tilt to size", "Tilt to opacity", "Rotate tip by pen tilt direction" and "Rotate tip by pen twist". Tilt and twist work only with pens that send them.
  • Pressure curve (size/opacity): Move the points to decide how pen pressure responds (horizontal is pressure, vertical is size or opacity). Double-click to return to a straight line.
  • Stroke feel: In File → Preferences → Pen & input → "Stroke feel", "How tapering is made" lets you choose "Taper by pressure only (default)" or "Taper by length". Taper by pressure only makes a blob at the start or a thread-like tail at the end less likely (for pens only. A mouse always tapers by length).

If it doesn't work

  • Lines get thinner when you zoom in and thicker when you zoom out: Set "Size basis" to "Fixed on texture".
  • Lines stretch on slanted faces: Set "3D brush projection" to "Follow the surface".
  • Lines appear after a delay behind the pen tip: Lower "Stabilization", or set "Stabilization type" to "1€ (strength varies with speed)". Also try "Show pen strokes early (reduce lag)" under "Reduce lag" in File → Preferences → Pen & input.
  • A blob forms at the start of a stroke, or a tail appears at the end: Set the stroke feel to "Taper by pressure only (default)".
  • Thin lines remain at UV seams: Turn on "Paint into padding outside islands in 3D too".

Also paint back and hidden faces

This paints areas that are hard to see because they wrap around, such as the inside of hair, overlapping clothing and the gaps between fingers, all at once. Turn it on and off with "Also paint back and hidden faces" just below Opacity in Tool properties (for the Eraser, "Also erase back and hidden faces").

  • Centered on the face visible under the pen tip, it also paints the back and inside faces that the camera can't see, within a sphere that looks the same size as the brush circle.
  • Pen, Brush, Brush collection, Eraser and Gradient are on from the start. Decoration, Pattern and Stitch are off at first. When it is off, only the visible faces are painted.
  • It isn't available for Blur, Smudge, Blend and Stamp (because they use the colors or image shown on the screen). It doesn't matter in the UV view (it already applies to all faces).
  • Hardness blurs the edge. Image tips attach to the inner faces in the same shape you see on the screen.
  • Selection, hidden areas, symmetry and Lock transparency work as usual.
If you paint a thick part, the paint reaches the other side. Make the brush smaller, or turn it off to paint only the visible faces.

How it differs from "Single-sided" and "Double-sided" display

"Single-sided" and "Double-sided" at the top left of the 3D view switch the display. With "Double-sided", back-facing faces are also displayed, and you can paint the back faces you can see. "Also paint back and hidden faces" is what paints faces the camera can't see (The four corners of the 3D view).

Choose colors and use the eyedropper

The color you draw with (the foreground color) is chosen with the Color panel, the Color values panel, Recent colors or Color sets. Whichever you use, it becomes the same foreground color.

  • Color: Buttons at the top switch the picker type. There are 5: "Ring + square", "Ring + triangle", "Square + hue bar", "Disc + value bar" and "Sliders (RGB/HSV)".
  • Color values: The foreground and background colors, HEX, picking a color from the screen, RGB/HSV numbers and opacity. The ▾ on the right expands the numbers and ▴ collapses them.
  • Recent colors: The last 12 colors you actually painted with or picked (newest first). Click one to make it the foreground color.
  • When the RGB/HSV sliders appear below the color picker, switch between them with the "RGB" and "HSV" buttons. The format you choose is kept after the next launch.

Foreground and background colors

  • X (or ⇄) swaps the foreground and background colors.
  • D (or the small button at the bottom left of the two squares) resets the foreground color to black and the background color to white.
  • Alt+Backspace fills with the foreground color, and Ctrl+Backspace fills with the background color. If there is a selection, it fills inside it. If not, it fills the whole of the selected layer.

Pick a color with the eyedropper

  • The eyedropper (I) picks the color where you click. The sub tools are "Sample displayed color" (the color you see) and "Sample from layer" (the color of the selected layer).
  • While you hold Alt, any tool acts as the eyedropper. If the camera controls are set to Alt + mouse buttons, use I in the 3D view.
  • You can also pick a color with right-click in the 3D view → "Pick color here".
  • Raising "Sample area" takes the average of the surrounding colors.
  • While the eyedropper is in use, a round magnifier appears at the cursor. The frame in the middle is where the color is taken from, and the outer ring is the color you get. You can turn it off with "Show magnifier" in Tool properties.
  • With the Alt + mouse buttons and Unity style camera controls, pressing Alt over 3D does not show the magnifier (it appears for the I key eyedropper, and in the UV pane it also appears with Alt).

Pick a color from anywhere on the screen

  1. Click the eyedropper icon in the Color values panel (Shift+I). A magnifier and a loupe showing the color values appear.
  2. Click the spot you want. You can pick from outside the window too. Enter and Space also pick.
  • The arrow keys move 1 pixel at a time (10 pixels with Shift). Esc or right-click cancels.
  • It picks from a snapshot of the screen taken when you started, so videos and the like look frozen.

Color set

  • Click a swatch to make it the foreground color. "+ Current color" adds one, drag to reorder, and double-click to name a swatch.
  • "Replace" and "Delete" act on the selected swatch. You can undo deleting a swatch with Ctrl+Z. "Small", "Medium" and "Large" change the swatch size.
  • The "…" menu lets you create, duplicate, rename and delete sets, export (JSON / .gpl palette) and import. A .gpl can be imported by dropping it anywhere on the window.
  • Drag while holding Space to scroll the list (for pens).

Pick a color from a reference image

  • In the Reference image panel, bring up an image by clicking "Open", dropping a file onto the panel, or clicking the panel and pressing Ctrl+V.
  • Click or drag on the image to pick that color. When you release, it goes into Recent colors.
  • The magnifier icon at the top zooms in and out, "100%" sets actual size, and the corner icon fits the whole image. It can also be operated with the pen alone.
  • The image you bring up comes back the next time you launch.

Draw with transparency (erase with the same brush)

Use the checkerboard button in the Color values panel, or C, to make the foreground color transparent. You can then erase color from the current layer while keeping the tip, hardness and pen pressure of Pen, Brush, Brush collection and so on.

  • To switch back, press C or the checkerboard button again. Clicking the foreground color square or choosing a color also switches back.
  • With the transparent color, Fill (Fill island, Whole material, Fill enclosed area), Polygon fill and Shape also erase the area they would paint.
  • Gradient erases more strongly toward the foreground-color side.
  • Stamp does not erase, even with the transparent color.
You can't erase on a layer with Lock transparency on. To erase, turn off Lock transparency first.

Paint symmetrically

When you draw on one side, the same thing appears on the other. Use it when you draw the same shape on both sides, such as the left and right of a face or clothing.

  1. Click "X" (left/right) at the top left of the 3D view (M).
  2. Draw on one side of the model. The same thing appears on the other side.
  • "Y" (front/back) and "Z" (up/down) can also be used in any combination at the same time (X and Z together paint in 4 places).
  • You can also toggle it from the Edit menu, or with right-click in the 3D view → "Paint symmetrically".
  • "Symmetry X/Y/Z" also appears at the very top of Tool properties and in the heading of the UV view (it is the same switch as the one at the top left of the 3D view).
  • One Undo reverses both sides together.

Set the mirror center

The ▼ next to X, Y and Z lets you choose the mirror center from "Model center", "Origin" and "Custom". Use it when the center is off from the middle of the body, for example with an outfit-only FBX.

  • Model center: For left/right, this is the place where the shape is most symmetric. Even if there are decorations or accessories on one side only, it stays at the middle of the body.
  • Origin: Mirrors at the origin of the coordinates.
  • Custom: Enter the center as X, Y and Z in cm, or use "Click on the model to set" to use the point you click. If "Snap to vertex" is on (the default), the position of the vertex nearest to the point you clicked is used.
  • You can also set it with right-click in the 3D view → "Paint symmetrically" → "Set symmetry center here".
  • When you set it, the mirror plane appears semi-transparent in 3D for about 2 seconds. The custom position is saved in the project file.

If it doesn't work

  • It appears at a shifted spot on the other side: The mirror center is off. Set the center to "Origin" or "Custom" with ▼ (Set the mirror center).
  • It doesn't appear on part of the other side: The shape differs slightly between left and right there. Raise "Mirror partner search range" in ▼.
  • It doesn't appear on the other side after you hide one side: Turn on "Mirror painting on hidden parts (3D brushes)" in ▼.
  • Drawing in the UV view doesn't appear on the other side: If the other side is in a different texture set (material), it doesn't appear in the UV view. Draw in the 3D view.
  • X, Y and Z have a slash through them: Symmetry doesn't work with the current tool (Which tools it works with).

Blur, smear and mix colors

The Blend tool (J) blends the colors you painted. All of its sub tools calculate on the 3D surface, so they don't break at UV seams.

Sub toolWhat it doesMain settings
Blur, Blur (strong, wide), Blur (weak, edges only)Smooths where you trace. The more you trace and the more you go back and forth, the more the colors melt together"Blur spread", "Blend more with each pass", "3D brush projection"
Smudge, Smudge (strong stretch), Smudge (soft)Drags the color and stretches it"Strength"
Blend, Blend (smooth), Blend (thick)Picks up the color where you trace and carries it, painting while mixing with the foreground color"Paint amount", "Color stretch", "Sample color from all layers"
Rake blur (smudge), Textured blur, Flat blurThese are the blur and smudge sub tools from the bundled Brush collection—
  • How strongly it acts is set with "Strength" (it corresponds to opacity for other brushes).
  • "Paint amount" is the proportion of foreground color. At 0, it only blends the colors that are already painted. Raising "Color stretch" carries the picked-up color further.
  • "Blend more with each pass" (on by default): The more times you trace the same spot, the more it melts together. It keeps working even if you keep rubbing without lifting the pen (once the amount moved in one stroke passes a limit, it works at half strength). When it is off, going over the same spot within one stroke does not make it stronger.
  • When "3D brush projection" for Blur is "Follow the surface", the area that gets blurred has the same shape as the pen.
  • You can also choose a tip in Tool properties for Blur, Smudge and Blend.
  • Blur and Smudge can also be used in the UV view. Blend is available only in the 3D view.

Distort what you drew (Liquify)

This distorts the existing drawing where you trace. Use it when you want to adjust the shape of a line a little.

Sub toolWhat it does
PushDrags the drawing in the direction you move
Bloat, PinchSpreads the traced area outward, or pulls it inward
Twirl (right), Twirl (left)Twists clockwise or counterclockwise
UndoGradually returns the traced area to the drawing as it was before liquify began
  • "Strength" (it also changes with pen pressure), "Hardness" (how the edge acts) and the brush size are the same as for other brushes. Bloat, Pinch, Twirl and Undo act in proportion to the length you trace.
  • Each stroke can be undone with one press of Ctrl+Z. The drawing doesn't get blurry however many times you trace.
  • In the 3D view, it connects across UV breaks. The closer you zoom in, the finer it acts.
  • In the UV view, it distorts only inside UV islands.
  • It respects Selection and Lock transparency. Symmetry also works.

Fill large areas (Fill)

Fill (G) fills a UV island, an area enclosed by lines and so on in one go. If you create the layer to fill below the line layer, the lines stay clean.

Sub toolWhat it fills
Fill islandThe whole UV island you click
Whole materialThe whole material you click
Fill enclosed areaAn area enclosed by lines: the connected area of similar color within that island (Details)
Lasso fillThe area you enclose by dragging (Details)
Polygon fillThe whole face you trace (Details)

With Fill island and Whole material, you can change "Anti-aliasing (island edges)" and the opacity.

Fill an area enclosed by lines

  1. Create a layer to fill below the line art layer and select it.
  2. Choose the Fill sub tool "Fill enclosed area".
  3. Set "Reference" in Tool properties to "All layers" (when you drew the lines on another layer).
  4. Click the area you want to fill. It stops at the lines and is filled with the foreground color.
SettingDetails
ReferenceLooks for the lines to stop at in the artwork of "All layers" or "Selected layer"
ToleranceHow much color difference is treated as the same
Close gaps0 to 5. Thickens the lines so that small breaks stop the fill (n closes breaks up to about 2n px)
Expand/contract-3 to 3. + makes the fill go under the lines and removes the white gap between the fill and the lines
Anti-aliasing (smooth edges by 1px)Smooths the edge of the fill

Fill an area with the lasso

Drag to enclose an area in the 3D view, UV view or 2D canvas, and the enclosed area is filled with the foreground color. The current selection is kept as it is, and one Undo reverts the fill.

If you enclose an area on a different texture set in the 3D view, it switches to the set that appears most in the enclosed area and then fills.

Fill face by face (Polygon fill)

This fills the whole face you trace with the foreground color. The pick radius is the size of the circle at the pen tip. If you turn off "Fill per quad (2 triangles as 1 face)", it fills triangle by triangle.

If you turn on "Mesh wireframe" at the top left of the 3D view, you can see the face boundaries (Mesh wireframe).

If it doesn't work

  • The fill goes beyond the lines: There is a break in the line. Raise "Close gaps".
  • A white gap remains next to the line: Set "Expand/contract" to +.
  • It doesn't stop at the lines on another layer: Set "Reference" to "All layers".
  • The lines get thinner or chipped: If you fill on the same layer as the lines, the fill covers the lines by the "Expand/contract" amount. Press Ctrl+Z, create a layer to fill below the lines, and fill again.

Paint with gradients

This paints so that colors change gradually. In the 3D view, drag from the start point to the end point.

  1. Click "Gradient" on the toolbar.
  2. Choose a sub tool ("Color and opacity", "Foreground → background", "Foreground → transparent" or "Radial (foreground color to transparent)").
  3. In Tool properties, choose "Linear" or "Radial" for "Shape".
  4. In the 3D view, drag from the start point to the end point. Release to paint.
  • Linear goes in the direction from the start point to the end point. For Radial, the start point is the center and the length of the drag is the radius. Hold Shift for 45° steps.
  • When "Also paint back and hidden faces" is on (the default), the gradient also applies to the back and inside faces along the 3D line connecting the point you pressed and the point you released (for example, from the roots of hair to its tips). When it is off, only visible faces are painted.
  • It paints the selected layer of the selected texture set. Areas outside the selection and hidden areas are unchanged.
  • You can also draw by dragging in the UV view.

Build it with color and opacity stops

If you set "Color" in Tool properties to "Color and opacity stops", you can paint with a gradient made of several colors and opacities.

  1. Click an empty spot on the bar to add a color stop (2 to 32).
  2. Select a stop and change its position and opacity. You can also change the position by dragging the stop.
  3. Click the selected stop again, or double-click it, and choose a color.
  • Remove a stop with "Remove stop", Delete, or by dragging it down away from the bar. "Use foreground color", "Distribute evenly" and "Swap left/right" are also available.
  • With "Presets ▾", you can choose from 240 presets (some include transparency). You can search by group and name.
  • With "Save current", you can keep your own preset (My presets).
  • Where the opacity is 0, the color below remains. To erase painted color, use the transparent color.
To bake shading that follows height or surface orientation into a new layer, the Pro gradient bake is handy.

Spread from a point in 3D space

Place a center on a face of the model or in the space outside it, and spread color by 3D distance from there. The color does not change when you move the view.

  1. Select the layer to paint.
  2. Click "Paint from a 3D point" in the Gradient Tool properties. The "3D spatial gradient" window opens.
  3. In the 3D view, click a face of the model or an empty spot to place the center.
  4. Set how the color spreads with "Spread distance" and the color and opacity stops or presets. It appears on the selected layer right away.
  5. Click "Paint on layer" to confirm.
  • After you confirm, one Undo reverts it. If you cancel, the layer goes back to the original drawing.
  • This is an operation for 3D models. On the 2D canvas, draw with an ordinary drag.

Move the center and set the spread distance

  • Move the center by dragging the arrows, the plane or the handle at the center, or by entering X, Y and Z coordinates.
  • Use "Pick center in 3D view" to place it again, and "Clear center" to remove it. While you are placing a point, press Esc to cancel.
  • When you place it in space, it goes at the same depth as the current center (or the model's center if there is none yet).
  • "Spread distance" is a percentage (%) of the model's height.
  • Selection, hidden areas, Lock transparency and masks are respected.

Draw shapes

With the Shape tool, you draw lines, rectangles, ellipses, polygons and curves in the foreground color. You can draw in both the 3D view and the UV view.

  1. Click "Shape" on the toolbar and choose a form with the sub tool.
  2. In the 3D view, drag from the start point to the end point.
  3. When you release, it is drawn in the foreground color.
Sub toolHow to draw
LinearConnects the two points you drag. Shift gives 45° steps
Rectangle, Ellipse, PolygonFills the inside. Shift gives a square, a circle or an undistorted regular polygon
Rectangle (outline), Ellipse (outline), Polygon (outline)Draws only the outline
CurveAfter you drag and release, moving the mouse bends the line. Press again or press Enter to confirm
Curve (connect points)Each click places a point (up to 24) and makes a smooth line through the points. Double-click or press Enter to confirm, and press Backspace to remove the last point
  • With "Draw from center" on, the start point becomes the center.
  • The number of "Corners" of a polygon is 3 to 12. A corner points up, and with an even number of corners the top and bottom are flat.
  • With Curve (connect points), turning on "Close (make a loop)" makes a loop, and setting "Painting style" to "Fill" fills the inside. You can use it to fill a free-form shape.
  • "Line width" is linked to the brush size (up to 500). Changing it from the brush size list, [ ] or the popup palette has the same effect. It is kept for each Shape sub tool and does not change the pen's size.
  • If you choose an image tip in Tool properties, it is placed along the outline of the shape (stitches, lace and so on). Choose "Round" to go back to an ordinary line.
  • It applies only to visible faces and counts as one Undo step. While drawing, press Esc to cancel.

Change color and size with the pen only (popup palette)

If you press and release the pen's side button without moving the pen, a round palette appears on the spot. You can choose frequently used sub tools, the foreground color and the brush size while holding the pen.

How to bring it up, how to use each part and the setting for bringing it up with a mouse are covered in Popup palette.
