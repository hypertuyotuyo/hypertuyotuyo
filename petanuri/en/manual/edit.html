Selections, transforms, text and rulers

Restrict painting areas, move artwork and paste text/images. Transform frames appear on both the 3D model and UV view.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

Notes beginning with “v1.2.0:” on this page are a release preview. The currently available version is v1.1.2.

Selection

  1. Select the Selection tool (S), then choose a shape in Sub tool.
  2. Drag, trace or click in 3D or UV to select.
  3. While selected, drawing, filling, erasing, filters and gradients affect only inside the selection. Outside is dimmed and a dotted outline marks the boundary.
  4. Ctrl＋D deselects.
Sub toolSelection mode
Rectangle / EllipseDrag
LassoTrace an enclosure
PolylineClick to place points; close at the first point, with a double-click or Enter
Auto selectConnected areas with colors similar to the clicked point
Select by islandThe entire clicked UV island
Select by faceEntire traced faces
Selection pen / Selection eraserAdd/remove by brushing
  • At the start, hold Shift to add, Alt to subtract, or Shift＋Alt to intersect.
  • “Select back and hidden faces too” selects everything matching the screen shape, including the back. Select all around the body to paint clothing stripes more easily.
  • Selection menu: Select all Ctrl＋A, Invert Ctrl＋Shift＋I, Expand / Shrink / Feather, Select painted areas, Create mask from selection, Fill with foreground color, Clear inside (Delete), Show selection outline (Ctrl＋H), Restore selection (Ctrl＋Shift＋D).
  • While a selection is active, you cannot draw on unselected texture sets.
Click a layer thumbnail while holding Ctrl to select its painted areas (Shift to add, Alt to subtract).
v1.2.0: Select all similar colors (all editions): Select → Select all similar colors (foreground color) selects areas close to the foreground color across the whole texture, even if they are not connected. Set the tolerance, the source (all layers / current layer), and the mode (new, add, subtract). Handy for changing shadow colors per base color.

Selection bar

During selection, a bar appears below the 3D view. Icon buttons follow the Selected label (hover with a pen/cursor for names and keys).

  • Deselect (colored button), Invert | Expand, Shrink, Feather | Fill, Clear | To new layer ▾ (Copy/Cut), More ▾ (Mask, Show selected only, Hide, Outline).
  • On narrow screens, Expand, Shrink and Feather are grouped under Area ▾.

Move/transform tool

  1. Select Move/transform (V).
  2. Click the artwork to move on the model or UV. The topmost painted layer there is selected and framed (Automatically select layer; when off, uses the selected layer).
  3. Drag immediately to move it. Corners scale; the top circle rotates.
  4. Enter or switching tools applies; Esc cancels. Clicking outside the frame applies and selects the layer at that location.
  • If a selection exists, only that area moves. Applying uses one Undo step.
  • Choose the frame mode (scale/rotate, free transform or warp) and warp grid size in Tool properties.
  • Clicking a text layer opens its text frame (drag inside to move; double-click to edit text).

Transform (Ctrl+T) and the 3D frame

  • Transform(Ctrl＋T): opens a frame for the selection, or the entire layer if nothing is selected.
  • The frame appears in both 3D (near the artwork on the model) and UV. Either frame moves the artwork identically and the other follows. If the artwork is visible in 3D, work entirely in 3D without opening UV.
  • Drag inside to move, corners to scale (Shift allows changing aspect ratio), edges to scale one axis, or the top circle to rotate (Shift for 15° steps). Flip horizontally/vertically too. Drag an edge/corner past the opposite side to flip.
  • Even over the 3D frame, move the view with right/middle drag, wheel or Space + drag. The frame follows view changes.
  • With the UV grid shown, the frame snaps to grid lines (Grid and snapping).
v1.2.0: 3D transform (all editions): the 3D frame now appears even for small visible details, and the frame and image no longer jump when you release a drag inside the frame (also for free transform and warp).
v1.2.0: Mirror too (all editions): with painting symmetry on and a selection on one side, “Mirror too” appears in the bottom bar. Moving with it on also moves the mirrored opposite side in 3D (the original painting there is replaced). The Move tool works the same way.

Free transform and warp

Three icons (scale/rotate, free transform, warp) appear below frames for Transform, Move/transform, Add image, Paste and Paste on 3D/UV.

  • Free transform: Drag the four corners independently to reshape artwork with a perspective-like effect.
  • Warp: Drag grid points to bend the artwork. Default 3×3 grid (4×4 and 5×5 available in the bar).
  • Both rotate by dragging the top circle or just outside a corner (Shift for 15° steps). Drag inside to move the whole frame.
  • Switching modes preserves the shape. Applying uses one Undo step, including transformed selections. When pasting in 3D, the screen-space shape is projected onto visible faces.

Copy, cut and paste

  • Copy(Ctrl＋C) · Cut(Ctrl＋X): the selection, or the whole layer if none. Even with multiple layers selected, only the active layer is affected.
  • Paste(Ctrl＋V): pastes to a new layer at the same UV position, ready to transform.
  • Locked, hidden or transparency-locked layers cannot be cut or cleared (a reason is shown).

Add and paste images

  • Add image (File → Import → Import image as layer, drop an image or paste an externally copied image with Ctrl＋V): opens a placement frame. If UV is open, it appears there; otherwise at the 3D center (projected onto visible faces). Aspect ratio and transparency are preserved.
  • Position the frame and press Enter to add a new layer named after the file. Esc cancels without leaving anything. “Paste across entire texture” below the frame stretches it across all UVs (for images drawn at UV size).
  • Paste image onto 3D (Edit → Paste image on 3D): position the frame in 3D, then press Enter to project onto visible faces. Move the view while positioning if needed. “Keep angled faces opaque” prevents fading on angled faces.
  • Paste image onto UV (Edit → Paste image on UV): position the UV frame and paste to a new layer.
Symmetry and selections apply too.

Text

  1. Select Text (T), then click in 3D or UV.
  2. A frame and text dialog appear; type directly in the frame. Japanese input works normally, with conversion candidates beside the text.
  3. Ctrl＋Enter applies (while typing, Enter inserts a line break). Esc first ends typing but keeps the frame; press again to cancel.
  • Set font, size, color, bold, italic, vertical writing, line/character spacing, alignment and stroke in the dialog. Foreground color controls text; background color controls the stroke.
  • Per-character formatting: Select characters before changing color, size, font, bold, italic, spacing or stroke to affect only those characters. Without a selection, changes affect future typing.
  • While typing, tool shortcuts (E for Eraser, for example) are disabled. To move the frame, hold Ctrl while dragging.
  • Choose any font installed on this PC. Import .ttf/.otf font files too (for the current session only).

Edit text (text layers)

  • Text pasted “To new layer” (always for UV text) becomes a Text layer marked T in the layer list.
  • Double-click in the layer list, right-click → Edit text, or click text with the Text tool to reopen its original settings. Per-character colors/sizes are preserved.
  • Drawing onto a text layer changes its badge to T+. Editing text removes added artwork, so put details on another layer to preserve them.
  • Right-click → Rasterize converts it to a regular layer (text is no longer editable). Text data is saved in project files, remaining editable after reopening. PSD exports use regular raster layers.

Ruler

  • Snap strokes to rulers. Straight/curve rulers affect only strokes begun near them; concentric/radial/parallel rulers work anywhere.
  • Create straight/parallel rulers by dragging; concentric/radial rulers center on the clicked point. For curves, place points, then press Enter or double-click. Drag ruler circles to move them.
  • 3D rulers stay on screen when the view moves. Place separate rulers in UV too.
  • View → Lines and rulers → Snap to ruler (Ctrl＋Alt＋R) toggles snapping; Delete ruler removes it.
While placing curve control points, press Ctrl＋Z to remove the last point. Ctrl＋Y or Ctrl＋Shift＋Z redoes that point removal. Enter or double-click applies the ruler; afterwards normal history controls resume.
v1.2.0: When a ruler exists, a bar appears at the bottom center of that pane (ruler type, snapping on/off, delete). Delete removes only that pane’s ruler.
