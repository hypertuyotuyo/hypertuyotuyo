Poses, blend shapes and vertex groups Pro

Use bones, blend shapes and vertex groups to paint places hard to reach in a T-pose. Features on this page require Pro.

Screenshots show the Japanese interface. Menu names in the text follow the selected app language.

Notes beginning with “v1.2.0:” on this page are a release preview. The currently available version is v1.1.2.

On this page
  • Pose mode
  • Humanoid bone colors
  • Pose symmetry
  • Blend shapes
  • Create selections from vertex groups

Pose mode

  1. Click Pose at the top center of 3D (painting is disabled in Pose mode).
  2. Select a bone via joint points, the mesh or the Pose panel list on the right.
  3. Rotate with the handles (top row switches rotation/move and handle orientation). Also enter numeric angles in the panel.
  4. Return to Paint to paint in that pose.
Useful for underarms and inner arms that are hard to paint in a T-pose. Reset/Reset all restores the original pose. Poses are saved in project files.
Painting symmetrically while posed follows the rest-pose symmetry. Bent arms still paint matching areas on the opposite arm (Paint symmetrically).
v1.2.0: Pose presets (Pro): Save current state at the bottom of the Pose panel stores the current pose under a name (up to 10). Load applies it (one undo reverts), and you can overwrite, rename, or delete presets. They are saved in the project.

Humanoid bone colors

  • Humanoid Body bone joints (hips, spine, chest, neck, head, shoulders, arms, legs and feet) appear as larger orange points, fingers are green; other bones (hair, skirt, tail and other secondary-motion bones) are small blue points.
  • Humanoid bones near the clicked point take priority over other bones.
  • The Pose panel list uses matching colored markers. “Humanoid only” hides secondary-motion bones, showing only body and hands.
Humanoid detection uses bone names and may miss some naming conventions.

Pose symmetry

  • “Symmetric pose” mirrors movement to the opposite bone when enabled.
  • “Copy left → right” / “Copy right → left” copies a pose to the opposite side (left/right refer to the character; one Undo).
  • Available in the top-center row, Pose panel and right-click menu.
  • Pairs use names (Left/Right, .L/.R, _L/_R, trailing L/R etc.). If names do not identify a pair, bones at symmetrical rest-pose positions are paired.

Blend shapes

  • Blend shapes on the right lists model blend shapes (shape keys). With multiple meshes, choose one in the top dropdown.
  • Sliders (0–100) change the shape; display, painting and hit testing all use the resulting shape.
  • Filter, Non-zero only and Reset all to 0 are available. Values are saved in project files.
v1.2.0: Copy values and Paste copy the current non-zero values to restore later or on another model. Load .anim applies the first frame of a Unity facial animation (.anim), matching meshes by name. Save current state at the bottom stores hidden objects and shape key values together as a display preset.

Create selections from vertex groups

  1. In Vertex groups on the right, check groups (bone weights), as many as needed.
  2. Click Make selection, Add, Subtract or Show this area only.
  3. Painting is restricted to that area.
Use weight strength makes weights directly control painting strength for smooth boundaries.
