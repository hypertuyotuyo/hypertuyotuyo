v1.3.0

v1.3.0 in preparation

Release date to be announced

Automatic updates from inside the app, a fix for picking colors from the screen, lace brushes, and fitting your painting when UVs change

The v1.3.0 information on this page is a preview before release. The current release is v1.2.1.

You can now update automatically from inside the app. This version adds drawing and integration features and fixes many bugs (it also includes everything planned for v1.2.2). Unless noted otherwise, features are available in all editions (Lite, Standard, Pro).

Major changes

Automatic updates from inside the app (Windows)

  • When a new version is out, a notice appears, and with a single confirmation the app downloads it, verifies it (signature and contents), replaces itself, and restartsYou can also turn off automatic downloading at startup (Preferences → System → Startup). If the update cannot be fetched from the official site, the app falls back to the usual guidance to download from BOOTH
  • The distribution format has changed: each edition is now a single ZIP. The extracted “PetaNuri3D” folder contains the program and setup.exeInstall with setup.exe, or run PetaNuri3D-win_x64.exe in the folder directly (do not take setup.exe out on its own; use the whole folder)

Notes (if you are updating from an earlier version)

  • Updating from v1.2.1 or earlier must be done by hand this one timeSave your work, close the app, extract the ZIP, and double-click setup.exe inside (it installs over the place where you installed with setup before). The Install and restart feature of v1.2.1 and earlier cannot find the new ZIP format
  • If you upgraded Standard to Pro, you do not need to install the upgrade file again (it stays Pro after future updates too)
  • Please also update the Unity integration add-on ProThe integration protocol was updated to carry Main color 2nd/3rd. The previous add-on still connects, but 2nd/3rd are not transferred
  • If you open a project file with merged normal map images in an earlier version, colors may shift by a few levels. Please edit it in v1.3.0

Changes

Drawing and file handling

  • The Pro upgrade file is no longer tied to a version (once installed, you stay Pro even after updating; files you purchased before also keep working)
  • Stamp images are now used at their original resolution without shrinking (previously the long side was reduced to 1,024 px)
  • Removed the limit on how many imported brush tips and patterns can be saved
  • With Paint across, the brush no longer spills onto texture sets the pen tip is not on (painting eyes could also paint the skin)
  • You can choose not to darken outside the selection (menu Selection → Darken outside the selection)

New features

Drawing and color

  • Change to foreground color (keep transparency): changes only the painted areas to the current foreground color, handy for recoloring line art (Edit menu, layer right-click)
  • Lace brushes (scallop, picot, small flowers, mesh): the pattern runs as a band along the stroke, so it stays connected around curves, corners, and in 3D
  • Brush tip images in the Shape tool: draw stitches and more lined up along the outline of a shape
  • Brush tips can now be chosen for Blur, Smudge, and Blend too
  • Eyedropper magnifier: shows a magnified view around the spot you pick (3D and UV; can be turned off in tool properties)
  • Mirror copy the selected artwork to the opposite side, and mirror copy masks left/right

Models and integration

  • When you reload a model and its UVs have changed, your painting is fitted to the new UVs (automatic with the Blender and Unity integrations)
  • Save without the model (FBX): a small project file for sharing. When opened, you choose the model on your computer
  • The Unity integration also loads and writes back lilToon Main color 2nd/3rd Pro
  • Merging normal map images Pro
  • Export 2D paintings as PSD Standard Pro

Interface and controls

  • Camera orientation lock in the 3D navigator (stops only rotation; panning and zooming still work)
  • Rotation/zoom sliders under the navigator (Preferences → Interface → Display, or right-click the navigator)
  • UV background in the Preferences color scheme
  • Right-click the toolbar for Columns: Auto or Columns: Always 1. Tools that do not fit can be scrolled with the wheel and more
  • Traditional Chinese (中文（繁體）) display

Bug fixes

Pick color from screen (exe version)

  • In v1.2.1, Pick color from screen could not be used (it was always canceled right after opening, sometimes showing “EyeDropper is not available”)PetaNuri3D now uses its own eyedropper instead of the display engine’s (WebView2). Watch the loupe (magnified view and color values) and click or press Enter/Space to pick. Arrow keys move one pixel at a time (10 with Shift); Esc or right-click cancels (it picks from a capture of the screen taken when you start, so videos and the like appear frozen)

Saving and loading

  • When the destination ran out of space, a truncated file could replace the project file while “Saved” was shown (the original file is now kept and you are notified)
  • When the destination stopped responding, the app stayed on “Saving…” without telling you
  • Large PSDs (over about 115 MB or 50 layers) could not be loaded due to insufficient memory (this was also why the Main color 2nd PSD was not loaded via the Unity integration)
  • Loading or exporting large PSDs and saving heavy project files froze the screen for a long time and used a lot of memory
  • Autosaves of separate works could end up in the same group, deleting the earlier work’s autosaves
  • Reloading a model made all hidden objects visible again
  • In 2D painting, PSDs could not be loaded from the menu

Draw

  • On hair and layered clothing, the mirrored side was slightly off when drawing symmetrically
  • Smudge worked differently on the left and right when symmetry was on
  • Filling gaps inside a layer with a thick border made the border spread out in a jagged way
  • Lightly erasing with the airbrush and similar tools in the transparent color left a grainy look
  • In PNG export, padding stopped at 32 px even when set to 64 or 128 px
  • Ctrl+= / Ctrl+- stopped zooming in and out

Layers and merging

  • Merging a folder containing the base and similar operations removed the base’s special status (the undeletable bottom layer)
  • Hidden or locked layers and folders could disappear when merging, or could be merged when they should not
  • Ungrouping a folder silently dropped its opacity, blend mode, and mask (you are now notified when they are dropped)

Integration

  • When exporting to Unity, a .meta file in use by Unity could be rewritten with a new ID if it could not be read Pro
  • Exporting a lilToon material reverted settings you had changed in Unity after loading it Pro
  • If the backup before overwriting in the Blender integration could not be made, the file was overwritten without a backup
  • Other minor bugs were fixed too

v1.2.1

Latest

2026-10-15

WinTab and pen fixes, helpers moved into the main program, Stitch, 3D mouse and glow blend modes

Based on reports from v1.2.0 users, this update fixes bugs and adds several features. Anything not marked otherwise is available in all editions (Lite, Standard, and Pro).

Major changes

Helper programs now run inside the main program (Windows)

  • The helper programs in the tools folder (close watcher, pen side button, WinTab pressure, 3D mouse, show pen stroke first) now run inside the PetaNuri3D executable. Usage and settings are unchangedThe font list, Unity .meta search, update check and opening exported files are also handled inside the main program without launching PowerShell or similar
  • Installing over an older version with setup removes the old helpers in tools. If you use the ZIP, extract it into a new folder (the CUDA AO baking helper remains a separate program)
  • The “Show pen stroke first” overlay now appears only while PetaNuri3D is in front

Notes (if you are updating from an earlier version)

  • Before updating, save your work and close the app, then run the new setup or extract the new ZIP
  • If you use v1.2.0, you can update from the new-version notice in the appUse “Download on BOOTH” to download the setup zip, then “Install and restart” replaces the app
  • If you upgraded Standard to Pro, install the v1.2.1 upgrade again as wellWhen using “Install and restart,” download the upgrade file too and it is replaced at the same time
  • Close PetaNuri3D before reinstalling or updating your tablet driver (with WinTab in use, the driver’s files stay open)
  • The Bump tool is now called Stitch (see “Changes” below)

Changes

The Bump tool is now Stitch

  • Stitches (dotted, puffy, seam, piping, cross stitch, zigzag, rivet) now draw in the foreground color on the current layer (all editions; also on the 2D canvas)To make bumps instead, turn on “Draw in the normal map folder” in Tool properties (Pro; Wrinkle and Bulge still draw by height)
  • Among sub tools saved by an earlier version, unchanged stitch tools switch once to the new behavior (drawing in the foreground color); ones whose size or name you changed keep drawing by height

New features

Drawing and layers

  • Blend modes “Add (glow)” and “Color dodge (glow)”They brighten as if glowing even where opacity is lowered, at soft brush edges, and over transparent areas (for layers, folders, brush drawing modes, and more)
  • Blur now blends more the more you stroke back and forth (the old behavior can be restored in Tool properties)
  • Color mix now blends more widely and softly
  • The stamp’s “Show the next placement faintly” can now be turned off
  • Preview and color selection in the “Paint from UV edges” window Pro
  • The layer list scrolls automatically to a layer selected with keys and the like

Interface and controls

  • Move the view with a 3D mouse (a six-axis device such as the 3Dconnexion SpaceMouse) (Windows)Sensitivity and more: Preferences → Controls → 3D mouse
  • Orbit around the point under the cursor when orbiting starts (Preferences → Controls → Camera; off by default)
  • Start by dropping a 3D model or project file onto the startup screen
  • “Long press with the pen opens the menu” and “Receive middle/right clicks from the pen side button” can now be turned off (Preferences → Pen & input → Menus and buttons)

Bug fixes

Saving and startup

  • Autosave could get stuck, making it impossible to save manually or close (more likely with large project files)Manual saves now take priority even during an autosave, you can choose “Wait / Cancel the previous save and continue” when the save-location window does not come back, and autosave itself is lighter
  • Large project files and PSDs (over 32 MB) were slow to open
  • After closing a frozen window by pressing × twice, a display process could remain in the background
  • An English page could appear when the app’s contents could not be read or the startup connection failed (now a localized message, and it reconnects automatically)

Pen and pen tablet

  • Turning on “Read pressure directly (WinTab)” could make the pen stop responding entirely (Wacom and others)The connection method has changed. If it does not work, press “WinTab connection: Search again” in Preferences → Pen & input → Tablet
  • When WinTab is working, WinTab pressure (and tilt) is now also used for Windows Ink pens (can be turned off in the same place)
  • Pen side button (pen displays and tablets; tested with Wacom, XP-Pen, Huion and GAOMON): 3D kept rotating after release / middle click did not work / dragging moved a little and stopped / the pen tip rotated or panned instead of drawing / middle did not work in the UV viewIf the view does not stop, press Esc or tap once with the pen tip
  • Painting the same spot with the pen for a while could open the right-click menu
  • Using Ctrl+plus/minus or the wheel (including pen display dials) while a menu was open zoomed the whole app window (and it stayed that way until restart)The whole window no longer zooms with any input (the display size setting in Preferences still works)
  • Painting with a thin pen while zoomed far in on 3D could leave gaps in the line

Other fixes

  • The zoom direction of Alt+right-drag in Unity style was the opposite of Unity (dragging down now zooms in)
  • Lasso fill did not fill in the UV view or 2D canvas, and did not work over other texture sets
  • Mosaic, Sharpen, High Pass, and others had no effect on lines drawn over transparency Standard Pro
  • In “Paint from UV edges,” the island rim (padding) was not painted even with the start distance set to 0 Pro
  • Selecting a layer shifted the rows in the list or hid layers near the bottom
  • “Select layer painted here” did not select correctly on unloaded sets or in areas that are not visible
  • Reassigned keys were not shown correctly in menus, or clashed with keys assigned in an earlier version
  • With a small selection, “Also on the mirrored side” in Move/Transform sometimes did not appear
  • Pressing Enter in the contact window closed it
  • In the English, Korean and Chinese interfaces, the prompts in the contact window text were still in Japanese
  • Other minor bugs were fixed too

v1.2.0

Released

2026-10-10

Installer, new pens, small view windows and rotation, and more lilToon settings

Based on your requests, this update adds many new features. Anything not marked otherwise is available in all editions (Lite, Standard, and Pro).

Major changes

You can now install with an installer

  • Extract the setup zip and double-click the setup.exe inside to install (no administrator rights needed)
  • From the next update, you can update right from the app with “Install and restart”
  • Standard and Pro are also still available as a ZIP, as before

Notes (if you are updating from an earlier version)

  • Before updating, save your work and close the app, then run the new setup or extract the new ZIP
  • The default stroke feel is now “Taper by pressure only”To switch back: Preferences → Pen & input → “Stroke feel” → “Taper by length”
  • The vertical orientation of UVs in glTF, glb, and VRM models has been fixedIn projects from earlier versions, the UV view image appears upside down (they look the same in 3D)
  • Autosave uses a new format (v1.1.2 and earlier cannot read v1.2.0 autosaves)
  • If you upgraded Standard to Pro, install the v1.2.0 upgrade again as well

New features

Draw

  • Liquify pen (push, bloat, pinch, twirl, and more; works with symmetry)
  • Pixel pen (paints crisp pixels aligned to the texture)
  • Show textures as pixels (toggle per texture set; on by default for 256px or less)
  • Lasso fill
  • Painting in 3D can also fill the padding (up to 128px, smooth)
  • Ctrl+drag to change brush size, hardness, opacity, and tip angle
  • Pattern angle, D to reset the foreground/background colors to black/white, and Alt/Ctrl+Backspace to fill

Selections, layers, and masks

  • Select all similar colors, and move or transform selections with symmetry
  • Mirror copy layers left/right
  • Copy and paste masks, and paint masks in black and white
  • Export selected layers or UV maps as PNG, and set the export resolution (512–8192)
  • Checkerboard display of transparent areas and an alpha cutout view
  • Display presets (save object visibility under a name)

Interface and controls

  • Put either the 3D or UV view in a small window (it can also sit over panels)
  • View rotation (tilt the view like paper while you draw)
  • Hand tool, and zoom presets with Ctrl+1/2/3
  • Toolbox panel and ruler bar
  • Pen buttons (middle click, right-click, back/forward) now work with both Windows Ink and WinTab
  • Help → Contact

Filters and adjustment layers Standard Pro

  • Curves, Color Balance, Color Temperature, Vibrance, Replace Color, and Exposure
  • Motion Blur, Radial Blur, High Pass, Add/Reduce Noise, Mosaic, Extract Lines, and Emboss(Curves, Color Balance, Vibrance, and Exposure round-trip through PSD)

Pro additions Pro

  • Many more lilToon settings (reflection, glitter shapes, anisotropic reflection, AudioLink, and more; also supported in .mat import and export)
  • Use normal map images and pattern textures (knit, denim, and more) as layers
  • Toon shade and angel ring baking, plus presets such as line art
  • Filters → Paint from UV edges
  • Pose presets, copying and pasting blend shapes, and loading Unity .anim files

Improvements and fixes

Usability

  • Lighter painting, undo, and autosave (especially with large models)
  • Areas that reuse the same UVs, such as hair strands, can now be painted in 3D
  • Added English, Korean, and Chinese translations

Bug fixes

  • The app sometimes could not be closed with × (if it freezes, press × twice)
  • Autosave could stall after sleep, so saving stopped working
  • Large projects (from about 150 MB) could not be opened or restored from autosave
  • Strokes got thin when zoomed in on the UV view, and the 3D transform (Ctrl+T) frame did not appear or jumped
  • A cursor was left at the pen tip, and rotating with middle click stopped right away
  • PSD export merged a layer with a stroke effect and its clipped layers into one
  • Many other small bugs were fixed

v1.1.2

Released

2026-10-07

Layer organization, UV paint areas, and more control settings

  • Layer color tags (all editions): mark layers and folders with eight colors. Tags apply to multiple selections, and “Show by color” above the list shows only layers with that color. Tags are saved in projects and map to Photoshop layer colors when exporting or importing PSD (Standard and Pro).
  • UV view paint area and padding (all editions): choose In UV, In padding, or Whole at the lower left. Pens, brushes, and erasers follow it, as do shapes, fills, gradients, stamps, blur, and smudge. Padding (0–32px or all) shares the export value and can be shown as a line. A new filter creates padding on a new layer.
  • Repeating patterns (all editions): from Layer properties, fill a layer with an image file, reference image, or texture repeated in all directions. Patterns can also be fitted to UV seams.
  • Camera and display (all editions): Preferences → Controls → Camera adds a Unity-style template. The perspective/orthographic ▼ at the upper right of the 3D view sets the field of view from 5° to 120°, and a new wireframe-only display hides textures.
  • UI color schemes (all editions): Preferences → Interface lets you change the colors of the window, panels, buttons, text, accent, 3D background, and toolbar. Light and dark themes are saved separately and can be reset.
  • Pen and controls (all editions): menus and buttons can be confirmed by pressing and releasing the pen (long-press behavior on buttons is configurable). Added a hold time for temporary tool switching (0.15–2 s), key binding export/import, and a panel layout lock.
  • Interface improvements (all editions): New, Open, Save, Undo, and Redo buttons sit right of the menus. Long menus scroll at their edges. Symmetry painting shows symmetry guides and a mirrored cursor, and favorite tool bars can be shown separately for 3D and UV.
  • Layers and sets (all editions): thumbnail sizes (small to extra large), an option to place the button row on top, dragging multiple layers together, and drag-selecting text while renaming. Sub texture sets can be removed, and reloading a model asks whether to replace the base for sets whose texture changed.
  • Painting and languages (all editions): shape line width now follows brush size, and the reference image eyedropper cursor is easier to see. Missing English, Korean, and Chinese translations were filled in, and the bundled guide describes v1.1.2 features.
  • Fixes: polygon fill and 3D face selection sometimes painting a distant triangle, export and About dialogs showing no content in English, Korean, and Chinese, occasional seam lines in padded exports, color leaking into neighboring islands on clipping layers, the opacity slider freezing, and more.

v1.1.1

Released

2026-10-05

More ways to paint and navigate

  • Spatial gradient (all editions): place a point on the model or in empty space with the regular gradient tool and paint by distance from it. Adjust movement handles, XYZ coordinates, radius, and color/opacity presets, then preview and apply to the selected layer. One Undo restores the result; Cancel restores the original painting. Regular spatial gradients and Pro’s point-distance gradient bake gain distance rings, a color/opacity rail, and value labels. Drag the white radius handle or colored stop handles to update the numeric controls and color editor together. Guides can be hidden, and bake guide positions reflect the boundary position and blend width.
  • Textures from 32px (all editions): 32/64/128/256px options for new projects and resizing, with project save/reopen and PNG export. Each edition retains its existing maximum resolution.
  • Auxiliary color sliders (all editions): switch the lower sliders between RGB and HSV while keeping the upper color field and hue bar. The choice persists after restart.
  • Camera controls (all editions): choose right-button, middle-button, or Alt-button controls. Camera movement also works better when a pen side button sends a middle click.
  • Mirror painting on hidden faces (all editions): enable the option in symmetry settings to include hidden mirrored faces for 3D pens, brushes, erasers, and stamps. Off by default; UV painting and fills are excluded.
  • VRM transparency (all editions): preserve original images, transparency settings, cutoffs, and opacity for VRM0/VRM1. Materials with different transparency settings use separate texture sets even when they share an image.
  • External brush tips (all editions): register ABR, GBR, GIH, images, and ZIP files as sub tools. Readable PNG images embedded in SUT files can also become tips. Original settings, colors, and mixing are not fully reproduced. SUT images may be previews or other materials rather than original tips.
  • MToon preview (Pro, beta): switch in the material display and lighting settings to paint with VRM0/VRM1 material appearance. Supports project saving and Undo/Redo. UV animation is shown as a still frame; full MToon material round-trip export is not supported.
  • Mirrored blush (Pro): Easy Bake gains a mirrored blush option. It uses the same X symmetry center as painting, and the opposite point follows when you move a point.
  • Layer list expansion (all editions): fixed the list stopping at a fixed height when the panel is expanded downward. It follows the available height when docked, tabbed, or in a separate window.
  • Painting, controls, and translations: improved brush-size jumps during input, brush-center offsets on angled surfaces, Alt camera controls during bake previews, English size button and Korean bake button wrapping, external brush error messages, and symmetry-center descriptions.
  • Compact help (all editions): Read longer explanations for baking, gradients, brushes and camera controls from a round question-mark icon. Supports hover, click, touch and keyboard controls. Current point-picking instructions and warnings remain visible.

v1.1.0

Released

October 4, 2026

Easy Bake and finishing before detail painting

Added Easy Bake with finishes for skin, outfits and accessories. Adjust light, highlights and fabric appearance, then start painting details immediately. Includes surface-aligned painting, gradients and the export improvements from v1.0.2.

Easy Bake Pro

  • 12 finish presets: fair skin with a healthy blush, soft illustrated skin, soft fabric/satin/denim/leather-style outfits, and hard-surface accessories. Preserves original layers and creates editable layers for each effect.
  • Choose where to add blush: Place up to 16 points in the 3D view and adjust spread and strength. After finishing, a transparent “Detail painting” layer is selected so you can immediately paint with a brush.
  • Available when creating a project: Select “Open Easy Bake after creating” on the base-color screen. Choose target sets and preview before applying.
  • 4 new bake types: Rim light, specular highlights, fabric texture/color variation and thin-area translucency color. Light and highlights are baked as colors from the chosen direction and stay fixed when the view moves. Translucent tint adds color to thin parts of closed shapes.
  • Organized the Filter menu: Easy Bake is below a separator; individual functions are grouped under Bake.

Drawing, erasing and gradients

  • Surface-aligned 3D painting is now available and enabled by default. Strokes stretch less on angled faces and near silhouettes; round-tip blur stays more continuous at corners. The existing “Screen-aligned” mode is still available.
  • Draw with transparency is now available. Toggle with the checkerboard button in the color panel or C . Erase using the brush's tip, hardness and pressure response.
  • Color and opacity gradients are now available. Edit color, position and opacity at up to 32 stops, and choose from 240 presets including transparency. Works in 3D, UV and 2D canvas.
  • Convert luminance to opacity was added to the Filter menu. White becomes transparent and dark areas remain black shadows, making it easier to recolor only AO shadows.
  • While placing curve-ruler points, Ctrl＋Z now removes the last control point. Undoing points no longer erases artwork drawn before them.

Create shading from shape Pro

  • Bake soft shading: Create broad soft shadows from face normals and light direction. Adjust light azimuth/elevation and shadow range, softness, color and strength; presets are included.
  • Bake gradients by orientation, height or point: Create color and opacity gradients based on face direction, height or distance from a point. Place the center on the model or in empty space; move it with 3D handles or XYZ coordinates.
  • Enhance cavities and bulges: Add shadows to cavities and light colors to ridges. “Shading blur” smooths along connected surfaces. Fixed white lines at UV seams.
  • Soft cast shadows: Create cast shadows from the light direction. Choose casting and receiving sets; material transparency is supported.

Shading is baked onto new transparent layers. Afterwards, change color/strength, erase or add details as with any regular layer.

Stamp canvas and bonus 2D painting

  • Integrated the stamp's “Draw in 2D canvas” with the regular UV view and layers. Draw on a dedicated square canvas and register the composited result directly as a stamp.
  • Below “Try a sample” on the startup screen, start 2D painting without a 3D model. Supports saving/resuming with layers, PNG export and stamp registration.
  • Stamp canvases are saved in the project file and excluded from model texture exports.

Controls and bug fixes

  • Fixed an unresponsive quit confirmation when exiting with a shading or other preview open. Before saving, quitting or switching projects, choose to apply or cancel the preview.
  • Fixed an issue where pressing Enter・Esc in the front confirmation dialog also applied or canceled the preview behind it.
  • Organized display, foreground-color and saving controls during previews; conflicting actions are disabled. Fixed temporary layers and restrictions remaining after switching filters or failed processing.
  • The selected shading preset name now remains visible. Removed duplicate gradient presets and organized them into a scrolling list about three rows tall.
  • 2D painting's dedicated button and File menu now use the same PNG export process.
  • Terms of use (Japanese) are published and included in every distribution ZIP. They cover use of created textures/illustrations and redistribution of the app.
