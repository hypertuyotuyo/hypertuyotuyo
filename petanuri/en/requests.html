PetaNuri3D / Requests and status

Feature requests and status

Please check here before contacting us. Requests we have received so far are sorted into “Done,” “Planned,” “Under consideration,” and “Not planned.”

As of 2026-10-11 (latest version: v1.2.0).

Done Planned v1.2.1 Under consideration Not planned

Our approach

  • PetaNuri3D is made for painting anime-style colors on 3D models with ease.
  • It is not meant to replace other 3D painting software. We do not try to match every feature and control of other software.
  • We read every request. Items “Under consideration” are not a promise that they will be added, or of when.

Done

Available

Unless noted, these work in every edition (Lite, Standard, Pro). See the manual for how to use them and the changelog for fixed bugs.

v1.2.0

  • Tilt the view like paper while drawing (view rotation in the 3D view; the UV view can also be turned to any angle)
  • Liquify pen (warp painted art to fix it)
  • Fill the area you circle with the lasso (Lasso fill)
  • Paint into the padding outside islands when painting in the 3D view too
  • Paint in 3D on areas where five or more faces share the same UV (such as hair strands)
  • Orbit around the last painted spot (Preferences; off by default)
  • Change brush size, hardness, opacity, and tip angle with Ctrl+drag
  • Hand tool
  • Preset zoom levels (Ctrl+1, 2, 3 in the UV view and 2D canvas; set the levels in Preferences)
  • Assign one key to several sub tools and cycle through them with each press
  • Move the 3D and UV views with middle or right clicks assigned to pen buttons
  • Foreground and background colors, and the D key to reset them to black and white
  • Fill with the foreground or background color using Alt+Backspace / Ctrl+Backspace
  • Paint and view masks in black and white (white = show, black = hide, gray = half)
  • Paste the brightness of an image (a black-and-white image) as a mask
  • Copy and paste just the mask, or drag it to another layer
  • Create an adjustment layer mask from the selection
  • Curves, Color Balance, and Exposure (as filters and adjustment layers) Standard Pro
  • Mirror-copy a layer left to right (mirrored across the 3D model, even when the left and right UVs differ)
  • Move and transform selections symmetrically on the other side too
  • Export only the selected layers as PNG
  • Export the UV map (UV lines) as PNG
  • Pattern angle for the pattern pen and paper texture
  • Blur can also “Follow the surface”
  • Save object visibility under a name (Display presets; in Pro, shape key values too)
  • Save poses under a name (Pose presets) Pro
  • Copy and paste blend shape values, and load facial expression animations (.anim) Pro
  • Load a normal map image made elsewhere as a layer Pro
  • Add surface texture (bump) with patterns such as knit or denim Pro
  • More lilToon settings: reflections, glitter shape, outline highlights, direct and indirect light for rim light, and custom normal maps for MatCap Pro
  • Load FBX files without materials as one texture set per object
  • Check the Unity link add-on version in the Unity editor

v1.1.2

  • Lock the panel and toolbar layout (no accidental moves)
  • Change the UI colors (besides light and dark, choose colors for each part)
  • Field of view for the 3D view
  • Undo and redo buttons (to the right of the menus)
  • A camera preset that pans with the middle button and orbits with the right button
  • Exporting and importing key bindings
  • Wireframe-only display
  • Symmetry line and mirrored cursor display
  • Tile images and patterns as a repeating fill (can follow UV seams; seams between islands facing different directions will not connect)
  • Paint in the UV view while seeing the paint area and padding
  • Apply a color tag to several layers at once
  • Select text in the layer name field by dragging the mouse
  • When reloading a model, ask whether to replace the base if its texture has changed
  • A cursor for using the eyedropper on reference images

v1.1.1

  • Load brush tip images from other painting software (.abr, .gbr, etc.; the original brush settings are not reproduced)
  • Camera control presets (right-button, middle-button, and Alt-button styles)

  • Assign shortcuts to tools such as selection tools (key bindings in Preferences)
  • Pan the 3D view with Space+drag (Preferences → Camera; without changing settings, Shift+Space+drag also pans)
  • Change brush size with Ctrl+Alt+drag
  • Draw while looking at a reference image, and pick colors from it
  • Apply artwork such as tattoos (Stamp, Paste image)
  • Paint bumps and export a normal map Pro

Under consideration

Undecided

Whether and when these will be added has not been decided.

  • Solid color layers (layers whose color is easy to change later)
  • Make reference images semi-transparent to use as a rough guide
  • Display transparent meshes such as blush or bang shadows with Multiply
  • Preview of fluffy fur
  • Preview of shaders other than lilToon
  • Apply surface textures such as normal maps per UV island
  • Move panels, the 3D view, or the UV view into separate windows outside the app window (for now they can be small windows inside the app window)
  • Place the toolbar anywhere between the screen edges
  • Move the view with two-finger gestures on touchpads and touch screens
  • A button on the 3D view navigation to lock the view direction
  • Pan with a pen button while the pen is hovering
  • Preview GIF images animated like lilToon Main Color 2nd and 3rd
  • Versions for platforms other than Windows, such as iPad or MacIf we do it, it will be only after updates have fully settled down.

Not planned

No plans

The first line is the request; the second line is the reason.

  • Change a filter’s settings after applying it (making Gaussian blur and similar filters into adjustment layers)This is difficult with the current design. Some, such as Curves and Color Balance, can be changed later as adjustment layers.
  • Vector pen (lines whose points and curves can be edited after drawing)PetaNuri3D paints by transferring lines drawn in the 3D view onto the UV texture. Because of this structure, it is hard to redraw a vector line correctly every time it is edited, across UV island borders, across texture sets, and where a pose changes the shape, so we decided not to include it.
  • Vector masksDropped together with the vector pen.
  • Switch to another tool only while Ctrl or Shift is heldIt would conflict with existing controls (Ctrl+drag and Shift+click for straight lines). Drawing while holding a tool’s key switches tools only while the key is held.
  • Import the layer structure of other software as isWorking with other apps would require checking each app’s license, and the maintenance would become enormous. Images (PNG, PSD) can be imported.
  • Load FBX files directly from packages (.unitypackage) that contain 3D modelsWorking with other apps would require checking each app’s license, and the maintenance would become enormous.
  • Convert materials of other shaders to lilToon for displaySupporting other shaders would require checking each shader’s license, and the maintenance would become enormous.
  • Transfer painted art to new UVs after the UVs are redoneWhen UVs change, positions in the art no longer correspond, so it cannot be transferred cleanly.
  • Create or play GIF animationsPetaNuri3D is not animation software.
