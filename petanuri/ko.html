01 — EXAMPLES

의상도, 소품도.

아바타의 몸뿐 아니라 의상·액세서리·소품까지, UV가 있는 3D 모델이라면 칠할 수 있습니다. 아래는 노노츠요 시리즈의 의상과 소품을 PetaNuri3D로 연 표시 예시입니다(텍스처는 원래 모델의 것입니다).

평소와 같은 채색 방법

03 — FEATURES

할 수 있는 일

3D 모델의 텍스처를 2D 일러스트와 같은 감각으로 그리는 도구입니다.

3D 모델에 직접 칠하기

시점을 돌려 보이는 위치에 펜으로 그릴 수 있습니다. 그린 내용은 UV 텍스처에 그대로 적용됩니다.

뒷면·가려진 면에도 닿습니다

머리카락 안쪽이나 겹친 옷처럼 잘 보이지 않는 곳에도 브러시가 닿습니다. 앞쪽을 숨기고 안쪽을 칠할 수도 있습니다.

UV를 찾지 않고 그리기

UV 영역을 옆에 배치하면 3D와 UV 어느 쪽에서든 칠할 수 있습니다. 이음매를 넘어도 선이나 흐리기 효과가 끊어지지 않습니다.

그린 그림을 3D 위에서 이동

이동·확대/축소·회전·자유 변형·워프를 모델 위의 틀로 바로 조작할 수 있습니다. 텍스트도 그 자리에서 입력할 수 있습니다.

펜만으로 조작

필압을 지원합니다. 사이드 버튼으로 시점을 돌리고 그 자리에 뜨는 팔레트로 색과 브러시를 바꿀 수 있습니다.

좌우 대칭으로 그리기

M 키로 좌우 대칭을 켭니다. X·Y·Z를 조합할 수 있으며 UV 영역에 칠할 때도 적용됩니다.

Unity에서 실행하여 칠하기

Unity에서 아바타를 선택하고 'ぺたぬり3D で塗る'(PetaNuri3D로 칠하기)를 실행하세요. 저장하면 Unity에 반영됩니다. 원본 파일은 변경하지 않습니다(모든 버전).

레이어를 유지하며 PSD로 주고받기 Standard

합성 모드 26종·폴더·마스크·조정 레이어를 유지한 채 PSD를 읽고 쓸 수 있습니다.

lilToon 모습으로 확인 Pro

그림자·림 라이트·매트캡·윤곽선이 있는 표시(β 버전)로 칠하고 머티리얼을 .unitypackage로 내보낼 수 있습니다.

포즈를 취한 채 칠하기·AO 베이크 Pro

본을 움직여 포즈를 만들고 그 상태로 칠할 수 있습니다. 빛이 닿기 어려운 곳의 어두움을 계산하여 레이어로 만들 수 있습니다.

04 — SCREEN

화면과 사용법

자주 쓰는 화면 4가지를 소개합니다. 자세한 조작 방법은 매뉴얼을 참고하세요.

3D × UV

3D와 UV를 나란히 놓고 어느 쪽에서든 칠하기

3D 뷰에서 칠한 내용은 옆의 UV 영역에 즉시 반영됩니다. UV 영역에서 브러시를 움직이면 3D의 해당 위치가 빨갛게 표시됩니다.

  • 펜·붓·채우기·그라데이션·흐리기 등을 UV 위에서도 사용할 수 있습니다
  • UV 영역에 격자선을 표시하고 이동·변형 틀을 격자에 스냅할 수 있습니다
  • '선택한 부분만 표시'·숨기기 펜·오브젝트별 표시로 옷 아래의 몸이나 머리카락 안쪽도 칠할 수 있습니다
LAYERS

2D 일러스트와 같은 레이어 조작

클리핑·투명 픽셀 잠금·폴더·레이어 마스크·합성 모드 26종을 지원합니다. 텍스트는 다시 입력할 수 있는 텍스트 레이어가 됩니다.

  • 텍스처를 PNG로 내보내기. PSD는 레이어를 유지 Standard
  • 레이어 테두리(테두리)·조정 레이어·필터를 나중에 수정할 수 있는 형태로 Standard
  • 아바타에 포함된 편집용 PSD를 가져와 이어서 그릴 수 있습니다 Standard
  • 내보내기 번짐(패딩)으로 이음매에 선이 덜 생기는 텍스처 만들기
BRUSH

애니메이션 채색부터 두꺼운 채색까지 지원하는 브러시

G펜·둥근 펜·입출 펜부터 수채화 번짐·모필·두꺼운 채색용 브러시 모음까지. 색 혼합·손가락·흐리기도 3D 위에서 사용할 수 있습니다.

  • 펜 5종·붓 12종·브러시 모음 33종·색 혼합 12종·장식 13종
  • 옷 무늬를 칠하는 패턴 펜 15종·스탬프·도형. 칠하기 전에 적용 위치에 미리보기가 표시됩니다
  • 봉제선과 주름을 그리는 요철 도구 Pro
POSE

포즈·블렌드 셰이프를 적용한 채 칠하기 Pro

본을 회전하여 포즈를 만들고 그 상태로 칠할 수 있습니다. 표정 블렌드 셰이프를 움직인 상태에서도 그릴 수 있습니다.

  • 관절 점·메시·목록에서 본을 선택하고 손잡이로 회전합니다
  • 정점 그룹(본 가중치)으로 칠할 범위를 만들 수 있습니다

08 — FAQ

자주 묻는 질문

어디에서 구매하나요?
BOOTH 상품 페이지에서 판매합니다. Lite는 무료, Standard는 2,500엔, Pro는 4,000엔입니다. 11/2까지 출시 기념 할인으로 Standard는 1,500엔, Pro는 3,000엔입니다.
무료 Lite 버전만으로도 사용할 수 있나요?
네. 3D에 직접 그리기·브러시·스탬프·패턴·좌우 대칭·UV 영역·선택 범위·변형·텍스트·PNG 내보내기·작업 파일 저장·Unity에서 실행 등 평소 채색에 쓰는 기능을 Lite에서 사용할 수 있습니다. 레이어는 텍스처 세트별로 바탕을 포함하여 최대 4장, 해상도는 최대 2048입니다. 워터마크는 없습니다.
VRChat 아바타에 사용할 수 있나요?
네. VRChat 등에서 쓰는 3D 아바타·의상·소품(FBX·VRM 등)을 열어 텍스처를 3D 위에 직접 그릴 수 있습니다. 그린 텍스처는 PNG·PSD로 내보내 Unity에 넣을 수 있습니다. Unity에서 아바타를 선택하고 'ぺたぬり3D で塗る'(PetaNuri3D로 칠하기)를 누르면 PetaNuri3D가 실행되며 저장할 때 Unity에 반영됩니다(모든 버전). Pro는 lilToon 머티리얼을 .unitypackage로 내보낼 수 있습니다.
원본 아바타 파일이 변경되나요?
아니요. Unity에서 칠할 때도 원본 FBX·머티리얼·텍스처·prefab은 변경하지 않으며 칠한 결과는 Unity 프로젝트의 Assets/PetaNuri/에 저장됩니다. PetaNuri3D만 사용할 때도 모델 파일은 읽기만 합니다.
다른 3D 소프트웨어나 페인트 소프트웨어 없이도 사용할 수 있나요?
네. PetaNuri3D만으로 모델을 열고 칠하고 텍스처를 PNG로 내보낼 수 있습니다. 레이어를 유지하여 마무리하려면 PSD로 내보내고(Standard부터) 사용하는 페인트 소프트웨어에서 이어서 그릴 수 있습니다.
Standard 구매 후 Pro로 업그레이드할 수 있나요?
네. BOOTH의 'Pro로 업그레이드'에서 받은 파일을 Standard에 넣고 다시 실행하면 Pro가 됩니다. 작업 파일과 설정도 유지됩니다. 자세한 내용은 매뉴얼을 참고하세요.
다른 샵의 아바타나 의상에도 사용할 수 있나요?
FBX 등의 3D 모델에 UV(텍스처 펼치기)가 있으면 칠할 수 있습니다. 모델 데이터의 이용 조건은 각각의 약관을 확인하세요.
Mac에서 사용할 수 있나요?
현재는 Windows만 지원합니다(Windows 11. Windows 10에서도 실행되지만 지원 대상이 아닙니다).
'Windows의 PC 보호'가 표시됩니다
서명되지 않은 앱이므로 처음 실행할 때 표시될 수 있습니다. '추가 정보' → '실행'으로 실행할 수 있습니다.시작 방법도 참고하세요.
새 버전은 어떻게 확인하나요?
실행 시(하루 최대 1회) 새 버전이 있는지 확인하여 화면 오른쪽 아래에 알려줍니다. 버전 번호만 확인하며 작품이나 설정은 어디에도 전송하지 않습니다. 최신 정보는 X(@Yak_HyperTYTY)에서도 안내합니다.
하이퍼 츠요츠요 홈 PetaNuri3D 매뉴얼 BOOTH 샵 X(@Yak_HyperTYTY) 업데이트 내역 이용약관 (일본어)

PetaNuri3D 개발에는 AI 에이전트(코드를 작성하는 AI)를 사용합니다. 이미지 생성 AI는 사용하지 않습니다.
