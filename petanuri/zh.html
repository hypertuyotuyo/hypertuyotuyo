03 — FEATURES

功能介绍

以绘制 2D 插画的手感，为 3D 模型绘制纹理的工具。

直接在 3D 模型上绘画

转动视角，用钢笔在看到的位置绘制。笔画直接写入 UV 纹理。

也能绘制背面和被遮挡的面

画笔能直接触及头发内侧、衣服重叠处等不易看到的位置，也可隐藏前方部分来绘制后方。

无需寻找 UV 即可绘画

将 UV 区域放在旁边，即可在 3D 和 UV 两侧绘制。跨过接缝时，笔画和模糊效果也不会断开。

在 3D 模型上移动已绘制的内容

可直接用模型上的操作框移动、缩放、旋转、自由变换和扭曲。文字也能就地输入。

仅用数位笔即可操作

支持笔压。用侧键转动视角，通过就地弹出的调色板切换颜色和画笔。

左右对称绘制

按 M 键开启左右对称。可组合 X、Y、Z，在 UV 区域绘制时也有效。

从 Unity 启动绘制

在 Unity 选中虚拟形象并点击“ぺたぬり3D で塗る”（用 PetaNuri3D 绘制）。保存后会反映到 Unity。不会改写原文件（所有版本均可使用）。

通过 PSD 往返编辑并保留图层 Standard

PSD 导入、导出可保留 26 种混合模式、文件夹、蒙版和调整图层。

查看 lilToon 风格效果 Pro

可在带有阴影、边缘光、MatCap 和轮廓线的显示中绘制（β 版），并将材质导出为 .unitypackage。

保持姿势绘制和烘焙 AO Pro

移动骨骼设置姿势后，可保持该形态绘制。也可计算光线不易到达位置的暗部并生成图层。

04 — SCREEN

界面与用法

介绍 4 个常用界面。详细操作请参阅使用手册。

3D × UV

并排显示 3D 和 UV，可在任一侧绘制

3D 视图中的笔画会立即反映到旁边的 UV 区域。在 UV 区域移动画笔时，3D 模型对应位置会显示红色提示。

  • 钢笔、毛笔、填充、渐变、模糊等工具也可在 UV 上使用
  • UV 区域可显示网格线，使移动、变换框吸附到网格
  • 使用“仅显示所选部分”、隐藏笔和按对象显示，也能绘制服装下面的身体和头发内侧
LAYERS

与 2D 插画相同的图层操作

支持剪贴、锁定透明像素、文件夹、图层蒙版和 26 种混合模式。文字会成为可重新输入的文字图层。

  • 纹理可导出 PNG，PSD 则能保留图层 Standard
  • 图层描边、调整图层和滤镜，可在之后继续修改 Standard
  • 导入虚拟形象附带的修改用 PSD，接着绘制 Standard
  • 导出时扩边（Padding），减少纹理接缝处的细线
BRUSH

从动漫平涂到厚涂的画笔

从 G 笔、圆笔、入笔/出笔笔，到水彩晕染、毛笔和厚涂画笔集。混色、涂抹和模糊也能在 3D 模型上使用。

  • 5 种钢笔、12 种毛笔、33 种画笔集、12 种混色工具、13 种装饰
  • 绘制服装图案的 15 种图案笔、图章和图形。绘制前会在落笔位置显示预览
  • 绘制缝线和褶皱的凹凸工具 Pro
POSE

保持姿势和混合形状绘制 Pro

旋转骨骼设置姿势后，可保持该形态绘制。调整表情混合形状后，也能继续绘制。

  • 从关节点、网格或列表选中骨骼，并用手柄旋转
  • 从顶点组（骨骼权重）创建绘制区域

08 — FAQ

常见问题

在哪里购买？
BOOTH 商品页面有售。Lite 免费，Standard 为 2,500 日元，Pro 为 4,000 日元。发售纪念优惠截至 11/2，期间 Standard 为 1,500 日元、Pro 为 3,000 日元。
只用免费的 Lite 版也可以吗？
可以。直接在 3D 上绘画、画笔、图章、图案、左右对称、UV 区域、选区、变换、文字、导出 PNG、保存工程文件、从 Unity 启动等日常绘制功能，Lite 均可使用。每个纹理集最多 4 个图层（含底色），最高分辨率 2048。没有水印。
可以用于 VRChat 虚拟形象吗？
可以。打开 VRChat 等使用的 3D 虚拟形象、服装和道具（FBX、VRM 等），即可直接在 3D 上绘制纹理。绘制的纹理可导出为 PNG、PSD 并导入 Unity。在 Unity 选中虚拟形象并点击“ぺたぬり3D で塗る”（用 PetaNuri3D 绘制），会启动 PetaNuri3D，保存后反映到 Unity（所有版本均可使用）。Pro 还可将 lilToon 材质导出为 .unitypackage。
会改写原虚拟形象文件吗？
不会。从 Unity 绘制时也不会改写原 FBX、材质、纹理、prefab。绘制内容会存入 Unity 项目的 Assets/PetaNuri/。单独使用 PetaNuri3D 时，也只会读取模型文件。
没有其他 3D 软件或绘画软件也能使用吗？
可以。仅用 PetaNuri3D 即可打开模型、绘制并将纹理导出为 PNG。若想保留图层继续润色，可导出 PSD（Standard 起可用），再使用自己的绘画软件接着绘制。
购买 Standard 后可以升级到 Pro 吗？
可以。将 BOOTH“升级到 Pro”提供的文件安装到 Standard，并重启应用即可变为 Pro。工程文件和设置均会保留。详细信息请参阅使用手册。
可以用于其他店铺的虚拟形象或服装吗？
只要是有 UV（纹理展开）的 FBX 等 3D 模型，即可绘制。请分别确认模型数据的使用条款。
能在 Mac 使用吗？
目前仅支持 Windows（Windows 11。也能在 Windows 10 运行，但不属于支持范围）。
出现“Windows 已保护你的电脑”
因为应用未签名，首次启动时可能出现此提示。点击“更多信息”→“仍要运行”即可启动。入门也可参考。
如何得知新版本发布？
启动时（每天最多一次）会检查是否有新版本，并在界面右下角通知。检查时仅获取版本号，不会发送作品或设置。最新消息也会在 X（@Yak_HyperTYTY）公布。
