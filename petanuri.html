01 — EXAMPLES

服も、小物も。

アバターの体だけでなく、衣装やアクセサリー・小物まで、UV のある 3D モデルなら塗れます。下は、ののつよシリーズの衣装と小物をぺたぬり3D で開いた表示例です（テクスチャは元のモデルのもの）。

塗り方はいつもどおり

ペンで線を引き、塗りつぶしで色を置き、クリッピングしたレイヤーに影とつやを重ねる。2D のイラストと同じ手順を、そのまま 3D の上で進められます。

03 — FEATURES

できること

3D モデルのテクスチャを、2D のイラストと同じ感覚で描くためのツールです。

3D モデルに直接塗れる

視点を回して、見たままの場所にペンで描けます。描いた内容はそのまま UV テクスチャに入ります。

裏側・隠れた面にも届く

髪の内側や服の重なりなど、見えにくい所にもブラシがそのまま届きます。手前を隠して奥を塗ることもできます。

UV を探さずに描ける

UV の区画を横に並べれば、3D と UV のどちらからでも塗れます。継ぎ目をまたいでも線やぼかしが割れません。

描いた絵を 3D の上で動かせる

移動・拡大縮小・回転・自由変形・ワープを、モデルの上の枠でそのまま操作できます。文字もその場で打てます。

ペンだけで操作できる

筆圧に対応。サイドボタンで視点を回し、その場に出るパレットで色とブラシを切り替えられます。

左右対称で描ける

M キーで左右対称に。X・Y・Z を組み合わせられ、UV の区画で塗るときにも効きます。

Unity から起動して塗れる

Unity でアバターを選んで「ぺたぬり3D で塗る」。保存すると Unity に映ります。元のファイルは書き換えません（どの版でも）。

レイヤーを保ったまま PSD で往復 Standard

合成モード 26 種・フォルダ・マスク・調整レイヤーを保ったまま PSD で読み書きできます。

lilToon の見た目で確認できる Pro

影・リムライト・マットキャップ・輪郭線付きの表示（β版）で塗り、マテリアルを .unitypackage で書き出せます。

ポーズを付けたまま塗れる・AO を焼ける Pro

ボーンを動かしてポーズを付け、その形のまま塗れます。光が届きにくい所の暗さを計算して、レイヤーにできます。

04 — SCREEN

画面と使い方

よく使う画面を 4 つ紹介します。くわしい操作はマニュアルへ。

3D × UV

3D と UV を並べて、どちらからでも塗れる

3D ビューで塗った内容は、となりの UV の区画にすぐ反映されます。UV の区画でブラシを動かすと、3D 側の当たる場所が赤く表示されます。

  • ペン・筆・塗りつぶし・グラデーション・ぼかしなどは UV の上でも使えます
  • UV の区画にグリッド線を出して、移動・変形の枠をマス目に吸い付かせられます
  • 「選んだ所だけ表示」・隠すペン・オブジェクトごとの表示で、服の下の体や髪の内側も塗れます
LAYERS

2D のイラストと同じレイヤー操作

クリッピング・透明度保護・フォルダ・レイヤーマスク・合成モード 26 種に対応しています。文字は打ち直せる文字レイヤーになります。

  • テクスチャは PNG で書き出し。PSD ならレイヤーを保ったまま Standard
  • レイヤーの縁取り（境界線）・調整レイヤー・フィルターは、後から直せる形で Standard
  • アバターに付いてくる改変用 PSD を読み込んで、続きから描けます Standard
  • 書き出しのにじみ（パディング）で、継ぎ目に線が出にくいテクスチャに
BRUSH

アニメ塗りから厚塗りまでのブラシ

G ペン・丸ペン・入り抜きペンから、水彩にじみ・毛筆・厚塗り向けのブラシ集まで。色混ぜ・指先・ぼかしも 3D の上で使えます。

  • ペン 5 種・筆 12 種・ブラシ集 33 種・色混ぜ 12 種・デコレーション 13 種
  • 服の柄を塗る模様のペン 15 種・スタンプ・図形。塗る前に、付く所に見本が出ます
  • 縫い目やしわを描く凹凸のツール Pro
POSE

ポーズ・ブレンドシェイプのまま塗る Pro

ボーンを回してポーズを付け、その形のまま塗れます。表情のブレンドシェイプを動かした状態でも描き込めます。

  • 関節の点・メッシュ・一覧からボーンを選び、つまみで回します
  • 頂点グループ（ボーンの重み）から塗る範囲を作れます

08 — FAQ

よくある質問

どこで買えますか？
BOOTH の商品ページで販売しています。Lite は無料、Standard は 2,500 円、Pro は 4,000 円です。11/2 までは発売記念セールで、Standard は 1,500 円、Pro は 3,000 円です。
無料の Lite 版だけでも使えますか？
はい。3D に直接描く・ブラシ・スタンプ・模様・左右対称・UV の区画・選択範囲・変形・文字・PNG 書き出し・作業ファイルの保存・Unity からの起動など、ふだんの塗りに使う機能は Lite で使えます。レイヤーはテクスチャセットごとに下地を含めて 4 枚まで、解像度は 2048 までです。透かしは入りません。
VRChat のアバターに使えますか？
はい。VRChat などで使われる 3D アバターや衣装や小物（FBX・VRM など）を開いて、テクスチャを 3D の上に直接描けます。描いたテクスチャは PNG・PSD で書き出して Unity に入れられます。Unity でアバターを選んで「ぺたぬり3D で塗る」を押すと、ぺたぬり3D が起動して、保存したときに Unity に映ります（どの版でも）。Pro では、lilToon のマテリアルを .unitypackage で書き出せます。
元のアバターのファイルは書き換えられますか？
いいえ。Unity から塗るときも、元の FBX・マテリアル・テクスチャ・prefab は書き換えず、塗った物は Unity のプロジェクトの Assets/PetaNuri/ に入ります。ぺたぬり3D だけで使うときも、モデルのファイルは読むだけです。
ほかの 3D ソフトやペイントソフトが無くても使えますか？
はい。ぺたぬり3D だけで、モデルを開いて塗り、テクスチャを PNG で書き出すところまでできます。レイヤーを残したまま仕上げたいときは、PSD で書き出して（Standard から）お使いのペイントソフトで続きを描けます。
Standard を買った後に Pro にできますか？
はい。BOOTH の「Pro へのアップグレード」で手に入るファイルを Standard に入れて、起動し直すと Pro になります。作業ファイルも設定もそのままです。くわしくはマニュアルをご覧ください。
ほかのショップのアバターや衣装でも使えますか？
FBX などの 3D モデルで、UV（テクスチャの展開）があれば塗れます。モデルのデータの利用条件は、それぞれの規約をご確認ください。
Mac で使えますか？
いまのところ Windows だけです（Windows 11。Windows 10 でも動きますが、サポートの対象外です）。
「PC が保護されました」と出ました
署名なしのアプリなので、はじめて起動するときに出ることがあります。「詳細情報」→「実行」で起動できます。はじめかたもご覧ください。
新しいバージョンはどうやって分かりますか？
起動したとき（1 日に 1 回まで）に、新しいバージョンが出ていないかを確かめて、画面の右下でお知らせします。確かめるのはバージョンの番号だけで、作品や設定はどこにも送りません。最新の情報は X（@Yak_HyperTYTY）でもお知らせします。
